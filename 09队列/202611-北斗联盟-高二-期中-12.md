# 题目 12

某 Python 程序段如下：

```python
a = [6,8,2,9,1,3]
total = 0; max = 0; c = 0
for i in range(len(a)):
    total = total + a[i]
    c = c + 1
    if c >= 3:
        if total > max:
            max = total
        total = total - a[i-2]
print(max)
```

该程序段运行后，输出的结果是（   ）

- A. 16

- B. 19

- C. 12

- D. 13

---

## 答案

**正确答案：** B

---

## 解析

程序维护相邻 3 个元素之和，依次为 16、19、12、13，最大为 19。
