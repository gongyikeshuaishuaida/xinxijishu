# 题目 12

有如下 Python 程序段：

```python
import random
n = 6; q = [1] * n; head, tail = 0, 1
while head < tail:
    s = q[head]
    if random.randint(0, 1) == 1:  #①
        head += 1  #②
    elif tail < n:
        q[tail] = s + 1
        tail += 1
    else:
        break  #③
```

![[attachments/202608G12名校协作体_12_随机函数表.jpg]]

运行程序后，下列说法正确的是（   ）

- A. 变量 q 的值可能是 `[1, 1, 2, 2, 3, 4]`
- B. 若①处条件改为 `int(random.random())==1`，q 的值可能为 `[1, 2, 3, 4, 5, 1]`
- C. 若变量 q 的值为 `[1, 2, 2, 3, 1, 1]`，则②处语句 `head+=1` 执行了 3 次
- D. 若删除③处矩形框内的代码，q 的值可能为 `[1, 2, 3, 4, 4, 4]`

---

## 答案

**正确答案：** D

---

## 解析

队列按 head 指向的元素逐个处理：随机分支为 1 时出队并移动 head，否则在队尾追加加 1 的元素，队列满且不能出队时由 break 结束。逐项分析各个可能序列可知 D 的序列可以出现；其余选项与 head、tail 的推进关系不符。
