# 题目 10

有如下 Python 程序段：

~~~python
s="abcdefghij"
q=[""]*10
head, tail=0, 0
for i in range(len(s)):
    if i%3==1:
        head+=1
    else:
        q[tail]=s[i]
        tail+=1
while head!=tail:
    print(q[head], end=" ")
    head+=1
~~~

运行上述 Python 程序后，输出的值为（   ）

- A. a c d f g i j
- B. d e f g h i j
- C. g h
- D. f g i j

## 答案

**正确答案：** D

## 解析

下标为 1、4、7 的字符不入队，只使队首指针前移；其余字符依次入队为 a、c、d、f、g、i、j。循环结束时 head=3，队列从下标 3 开始输出，所以结果为 f、g、i、j，即 D。
