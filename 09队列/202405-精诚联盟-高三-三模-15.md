# 题目 15

15.海港接货点每秒可能有一批商品到达。程序要统计过去一个小时内共有几个国家（地区）的商品及各国数量，并按数量从多到少显示。初始数据按到达时刻递增排列，同一时刻数据在同一行。

![[attachments/202405精诚联盟高三_15_统计示例表.jpg]]

（1）对于示例表中第3604秒时刻，一共有 ______ 个不同国家（地区）的商品。

（2）主程序使用队列 `q` 保存到达时刻和国家序号，`c` 保存商品数量与排名位次，`rank` 用于按数量排序：

```python
delta = 1 * 60 * 60
for i in range(n):
    t = int(line[0])
    while head != tail:
        if ______①______:
            x = q[head][1]
            c[x][0] -= 1
            if c[x][0] == 0:
                ans -= 1
            move_bottom(x)
            head += 1
        else:
            break
    for s in line[1:]:
        x = toInt(s)
        c[x][0] += 1
        if c[x][0] == 1:
            ______②______
            c[x][1] = ans
```

（3）`move_top(x)` 中，当数量变大需要向前插入时：

```python
def move_top(x):
    num = c[x][0]
    i = c[x][1] - 1
    while num > rank[i][0]:
        ______③______
        rank[i+1] = rank[i]
        i -= 1
    ______④______
    c[x][1] = i + 1
```

---

## 答案

**正确答案：** （1）3；（2）① `t-q[head][0] >= delta`；② `ans += 1`；（3）③ `c[rank[i][1]][1] = i+1`（或等价）；④ `rank[i+1] = [num,x]`

---

## 解析

队列头部保存最早到达商品，当前时刻与其相差至少3600秒时出队，才保持“过去一小时”的窗口。第3604秒排除第1秒数据后，仍有 HK、SG、AU 三个国家。新国家第一次出现时 `ans` 加一；插入排序移动 rank 元素后同步更新 c 中旧排名，循环结束把新元素写入插入位置。
