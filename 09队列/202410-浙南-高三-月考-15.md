# 题目 15

礼品盒包装包含若干有前置依赖的环节。每个结点表示一个环节，结点上的数字表示所需时间；有多条边指向同一环节时，必须完成全部前置环节才能开始。

图a为示例，图b为依赖数据，图c为待计算任务：

![[attachments/202410浙南_15_环节依赖图表.jpg]]

（1）图c所示礼品盒包装所需要的总时间为 ______①______ 分。

（2）定义 `insert(data)` 找出每个环节的所有前置环节：

```python
def insert(data):
    n = len(data)
    q = []
    task = [-1] * (n + 1)
    for i in range(n):
        cur = data[i][0]
        data[i][0] = task[cur]
        task[cur] = i
        if cur not in q:
            q.append(cur)
    return q, task
```

若 `data=[[1,2,-1],[2,1,1],[3,8,2],[4,5,2],[5,3,1],[6,3,5],[6,3,3],[6,3,4],[7,1,6]]`，调用后 `task[6]` 的值为 ______②______。

（3）完善主程序：

```python
"""读取数据，存入列表data，环节data[i][0]依赖于环节data[i][2]，
data[i][1]存放环节完成所需时间，代码略。"""
q, task = insert(data)
head, tail = 0, len(q)
q = q + [0] * 1000
f = [0] * 1000  # f[i]存放该环节结束时间
sta = [False] * 1000
res = 0
while head != tail:
    ______①______
    head += 1
    p = task[c]
    if data[p][2] == -1:
        f[c] = data[p][1]
        sta[c] = True
    else:
        while p != -1:
            j = data[p][2]
            if ______②______:
                f[c] = f[j] + data[p][1]
            elif not sta[j]:
                q[tail] = c
                tail += 1
                break
            p = data[p][0]
        task[c] = data[task[c]][0]
        if p == -1:
            ______③______
    if f[c] > res:
        res = f[c]
print("总时间为", res)
```

---

## 答案

**正确答案：** （1）13；（2）7；（3）① `c=q[head]`；② `sta[j] and data[p][1]+f[j]>f[c]`；③ `sta[c]=True`

---

## 解析

总完成时间是依赖图中的最长路径，图c最长为 `V1→V2→V5→V6`，耗时 `2+6+2+3=13`。`insert` 将同一当前环节的记录以头插法串联，最后一条环节6记录索引为7。主程序取队首任务，只有前置环节已完成且能形成更晚结束时间时更新 `f[c]`；全部前置处理完后标记当前环节完成。
