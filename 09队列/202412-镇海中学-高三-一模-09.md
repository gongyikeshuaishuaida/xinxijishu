# 题目 09

有如下函数定义：

```python
def func(nums, k):
    que = [0] * k
    head, tail = 0, 0
    result = []
    for i in range(len(nums)):
        if head < tail and i - que[head] >= k:
            head += 1
        while head < tail and nums[i] > nums[que[tail - 1]]:
            tail -= 1
        que[tail] = i
        tail += 1
        if i >= k - 1:
            result.append(nums[que[head]])
    return result
```

假设输入的 `nums` 为 `[1,3,-1,-3,5]`，`k` 的值为 3，调用该函数以后，函数返回的结果为（   ）

- A. `[3,3,5,5,5]`
- B. `[-1,-3,-3]`
- C. `[3,3,5]`
- D. `[-1,-3,-3,-3,-3]`

---

## 答案

**正确答案：** C

---

## 解析

队列中保存当前长度为 `k` 的窗口内候选最大值的下标，且对应元素从队首到队尾单调递减。三个窗口 `[1,3,-1]`、`[3,-1,-3]`、`[-1,-3,5]` 的最大值依次为 3、3、5，故返回 `[3,3,5]`。
