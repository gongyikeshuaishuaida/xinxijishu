# 题目 11

有如下 Python 代码：

```python
head = 4; tail = 3
a = [3, 6, 7, 12, 4]
n = len(a)
while (head + 1) % n != tail:
    if a[head] % 3 != 0:
        head = (head + 1) % n
    else:
        a[tail] = a[head] // 3
        head = (head + 1) % n
        tail = (tail + 1) % n
print(a[head])
```

执行上述代码后，输出的内容是（  ）

A．2

B．7

C．3

D．4

## 答案

**正确答案：** A

## 解析

按循环队列的首尾指针模拟：从 `head=4` 开始，遇到 3 的倍数就把其三分之一写入队尾并同时移动两个指针，最终 `head` 指向的数组元素为 2。
