# 题目 10

有如下 Python 程序段：

```python
import random
que = ["a", "b", "c", "d", "", "", "", "", "", ""]
head = 0
tail = 4
ans = ""
for i in range(5):
    if random.randint(0, 1) == 0:
        ans += que[head]
        que[tail] = que[head]
        head += 1
        tail += 1
    else:
        head += 1
```

执行程序段后，`ans` 的值不可能是

- A. `"bcc"`
- B. `"aa"`
- C. `"bcdb"`
- D. `"abcd"`

## 答案

**参考答案：** A

## 解析

程序按照随机结果决定丢弃队首元素或输出并复制到队尾。复制后的元素只能在后续队首再次被访问，逐一分析 5 次操作的可能路径可知 `"bcc"` 无法形成，其他字符串均存在相应的随机路径。
