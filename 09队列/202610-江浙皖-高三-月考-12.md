# 题目 12

有如下Python程序段：

```python
import random
q = [0] * 6
head, tail = 0, 0
for i in range(6):
    t = random.randint(0, i)
    if t % 2 == 0:
        q[tail] = random.randint(1, 9)
    elif head < tail and q[head] >= q[tail - 1]:
        q[tail] = q[head]
        head += 1
    else:
        head += 1
    tail += 1
```



执行该程序段后，列表`q`的值**不可能**是（   ）

- A. `[3, 8, 0, 5, 7, 2]`
- B. `[7, 7, 0, 2, 8, 5]`
- C. `[5, 9, 9, 0, 2, 7]`
- D. `[3, 7, 5, 8, 9, 0]`

---

## 答案

**正确答案：** B

---

## 解析

第0轮必取偶数并写入1～9的整数。若最终首两项为7、7，则第1轮可以直接随机写7，也可以复制队首7。但到第2轮，若取偶数，必写非零数；若取奇数，此时`head`为0或1，均有`q[head] >= q[tail-1]`（7≥7），必复制7。因此B的第3项不可能为0。

A可在第1轮直接写8，第2轮奇数时因3＜8而跳过；C可在第1轮直接写9、第2轮复制9、第3轮因0＜9而跳过；D可前5轮均直接写值，第5轮因3＜9而跳过。枚举所有偶/奇分支已验证只有B不可能。
