# 题目 13

某英文逐词翻译软件不区分大小写。翻译过程中，软件会将最近出现过的一些单词存入内存；若内存中有该单词则直接翻译，否则查外存词典并将该单词存入内存。内存存满时清空最早进入内存的单词，腾出单元存放新单词。编程模拟该翻译过程，输入一个仅含英文、逗号或空格字符的英语句子，以句号结束，计算需要去外存查找多少次词典。翻译开始前内存为空。示例内存容量为 5 时，需要查找 12 次。

（1）若内存容量改为 7，则需要去外存查找 ______①______ 次词典。

（2）实现上述功能的 Python 程序如下，请在划线处填入合适的代码。

```python
m = int(input("请输入内存容量:"))
s = input("请输入英语句子:")
dic = {}
head = tail = 0
word = ""
for ch in s:
    if ch == " " or ch == "," or ch == ".":
        if word not in dic or ______②______:
            if tail - head == m:
                head = head + 1
            dic[word] = tail
            tail += 1
        word = ""
    else:
        if "A" <= ch <= "Z":
            ch = ______③______
        word += ch
print("需要去外存查找", ______④______, "次词典")
```

---

## 答案

**正确答案：** ① 10；② `dic[word] < head`；③ `ch.lower()`；④ `tail`

---

## 解析

句子中的单词依次为 If、you、have、an、apple、and、I、have、an、apple、we、both、have、one、apple。容量为 7 时按 FIFO 模拟共有 10 次未命中。字典保留被淘汰单词的旧下标，只有 `dic[word] < head` 时才表示它已经不在内存；大写字母用 `lower()` 转为小写；每次未命中 `tail` 加 1，所以查找次数就是 `tail`。
