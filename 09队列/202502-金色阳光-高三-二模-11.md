# 题目 11

有如下 Python 程序段：

```python
que = ["A", "B", "C", "D", "E", "F", "G"]
head = 0
tail = 6
k = 0
n = len(que)
m = int(input())
while head != tail:
    k = k + 1
    t = que[head]
    head = (head + 1) % n
    if k == m:
        print(t, end="")
        k = 0
    else:
        que[tail] = t
        tail = (tail + 1) % n
```

该程序段运行后，若输入 `m` 的值为 2，则输出结果是

- A. `BDFACE`
- B. `BDFCAE`
- C. `BDF AECG`
- D. `BDFACGE`

## 答案

**参考答案：** B

## 解析

程序每处理一个元素就计数，计数到 2 时输出该元素并清零，否则将元素移到队尾。按循环队列逐步模拟，输出顺序为 `B、D、F、C、A、E`，因此选择 B。
