# 题目 15

15.某地区物流总站通过条形码采集货物信息，按目的地分站编号把货物分流到各分站待配送队列。当某分站待配送货物总重量达到当前货车最大承重时，按先扫描先配送；扫描结束后再配送剩余货物。

![[attachments/202405-桐浦富兴-高二-期中-15_横排1_2_3.png]]

（1）若将货车 `hc1` 的最大承重改为 2100 kg，则 `hc1` 配送的货物 ID 为 ______。

（2）分流代码如下，请填空：

```python
st = []
for i in range(n):
    st.append([0])
head = [1] * n; tail = [1] * n
for i in range(len(data)):
    k = data[i][1] - 1
    st[k].append(i)
    tail[k] += 1
    ______①______
    trans()
```

（3）补全配送判断代码：

```python
def findmax(st):
    t = 0
    for i in range(1, len(st)):
        if ______①______:
            t = i
    return t

def trans():
    global st, head, tail, hct, hc
    while True:
        maxt = findmax(st)
        if st[maxt][0] < hc[hct]:
            break
        remain = hc[hct]; info = []
        while ______②______ and remain > data[st[maxt][head[maxt]]][2]:
            tmp = st[maxt][head[maxt]]
            info.append(int(data[tmp][0]))
            remain -= data[tmp][2]
            ______③______
            head[maxt] += 1
        hct += 1
```

---

## 答案

**正确答案：** （1）`[0,1,5,6]`；（2）`st[k][0]+=data[i][2]`；（3）①`st[i][0]>st[t][0]`；②`head[maxt]!=tail[maxt]`；③`st[maxt][0]-=data[tmp][2]`

---

## 解析

每个分站队列的第 0 项维护总重量，后续项按扫描顺序存储货物下标。将 hc1 改为 2100 kg 后，在扫描到 ID 6 时分站 1 的货物 0、1、5、6 总重达到 2100 kg，按队首顺序配送。`findmax` 选择累计重量最大的分站；装货循环必须先保证队列非空，再装入不会超过剩余承重的货物；配送后扣减该分站总重量。
