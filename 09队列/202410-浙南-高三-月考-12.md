# 题目 12

有如下 Python 程序段：

```python
s = input()
d = [-1] * 10
head = tail = 0
n = len(s)
for i in range(n):
    if d[int(s[i])] < head:
        if tail - head == 3:
            head += 1
        d[int(s[i])] = tail
        tail += 1
```

若执行程序后，`d=[-1,4,6,5,3,-1,-1,-1,-1,-1]`，则输入的 `s` 值可能是（   ）

- A. `"6954132"`
- B. `"11114132"`
- C. `"1324132"`
- D. `"41341322"`

---

## 答案

**正确答案：** C

---

## 解析

程序用时间戳表示数字最近一次进入容量为3的队列的位置；当旧时间戳小于 `head` 时才重新加入。逐项模拟 `1324132`，最终1、4、3、2的时间戳分别为4、3、5、6，与给定 `d` 一致。
