# 题目 12

有如下 Python 程序段：

```python
from random import randint

q = [1, 2, 14, 5, 6, 7, 9, 10]
head = 0
tail = len(q) - 1
ans = 0
m = randint(1, 3)
q += [0] * m
for i in range(m):
    for j in range(2 ** i - 1):
        head += 1
    ans += q[head]
    q[tail] = q[head]
    head += 1
    tail += 1
```

执行该程序段后，变量 `ans` 的值不可能是（   ）
- A. 1
- B. 15
- C. 24
- D. 34

---

## 答案

**正确答案：** D

---

## 解析

m 只能取1、2、3。逐次模拟队首移动与累加，ans 分别可能为1、15、24，因此不可能得到34。
