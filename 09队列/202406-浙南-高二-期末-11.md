# 题目 11

有如下 Python 程序段：

    a = [3, 1, -6, 0, -1, 5, 2, -5, 1, 3]
    n = len(a); q = [0] * n
    head, tail = 0, 0
    for i in range(0, n):
        if head < tail:
            if q[head] + a[i] > 0:
                q[tail] = q[tail-1] + a[i]
                tail += 1
            else:
                head = tail
        else:
            if a[i] > 0:
                q[tail] = a[i]
                tail += 1
    print(tail - head)

执行后输出结果为

- A. 2
- B. 3
- C. 5
- D. 6

---

## 答案

**正确答案：** A

---

## 解析

逐项模拟队列中连续正和片段的维护，最后队列有效区间长度 tail-head 为 2。
