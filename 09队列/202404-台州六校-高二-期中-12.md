# 题目 12

有如下 Python 程序段，执行后输出结果是（   ）

```python
a = "Python"
q = [0] * 6
head, tail = 0, 0
i = len(a) - 1
while i >= 0:
    if i % 3 != 0:
        q[tail] = a[i]
    else:
        q[tail] = q[head]
        head += 1
    tail += 1
    i -= 1
print(q[head:tail])
```

- A. `['n', 't', 'y', 'o']`
- B. `['t', 'y']`
- C. `['n', 'o', 't', 'y']`
- D. `['n', 'o', 'n', 't', 'y', 'o']`

---

## 答案

**正确答案：** A

---

## 解析

按 `i=5,4,3,2,1,0` 依次写入队列，`i=3` 和 `i=0` 时复制队首并移动 `head`，最后切片 `q[2:6]` 得到 `['n', 't', 'y', 'o']`。
