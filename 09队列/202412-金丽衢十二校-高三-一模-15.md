# 题目 15

使用某浏览器浏览网页时，高速缓存（cache）的存储机制如下：

① 在内存中只会保留最近浏览过的 `k` 个网页。

② 当连续浏览的网页数达到 `k` 个时，会将最近 `k` 个网页中访问频率最高的网页存入 cache。

③ 当网页第一次存入 cache，或存入 cache 的新网页与已存网页不同时，称为改写一次 cache。

现获取了某天按序浏览过的 `n` 个网页信息并存储在 `page` 中，输入 `k` 的值，求当天网页浏览过程中 cache 被改写的次数。

设 `n=6`、`k=3`，按序浏览的各网页信息如下图所示；当连续浏览网页数达到 3 个时，开始将最近 3 个网页中访问频率最高的网页存入 cache，存入情况和改写情况分别如下图所示。

![[attachments/202412金丽衢十二校_15_网页缓存图a-c.png]]

（1）由题意可知，若仅将图中网页名称为 `p4` 的网页访问频率改为 5，则网页浏览过程中 cache 改写的次数为 ______①______。

（2）定义如下 `count(result)` 函数，参数 `result` 的每个元素是依序加入到 cache 的最近 `k` 个网页中访问频率最高的网页名称。函数的功能是根据 `result` 返回 cache 的改写次数，请在程序中划线处填入合适的代码。

```python
def count(result):
    ans = 1
    tmp = result[0]
    for i in range(1, len(result)):
        if result[i] != tmp:
            ans += 1
            ______①______
    return ans
```

（3）实现求改写 cache 次数的部分 Python 程序如下，程序中用到的列表函数与方法如第 15 题图 d 所示，请在程序中划线处填入合适的代码。

![[attachments/202412金丽衢十二校_15_函数方法表.png]]

```python
def find(data, k):
    result = []  # 依序存储最近浏览的 k 个网页中访问频率最高的网页名称
    que = [-1] * 100
    head = tail = 0
    for i in range(len(data)):
        while ______①______:
            head += 1
        while tail > head and data[que[tail - 1]][1] < data[i][1]:
            tail -= 1
        que[tail] = ______②______
        tail += 1
        if i >= k - 1:
            result.append(data[que[head]][0])
    return result
```

读取内存存储网页数的上限并存入变量 `k`；读取当天浏览的网页数并存入变量 `n`；依序读取当天浏览的 `n` 个网页信息并存入列表 `page` 的 `page[0]` 至 `page[n-1]` 中。`page[i]` 包含 2 个数据项，`page[i][0]`、`page[i][1]` 分别存放网页名称及网页访问频率，代码略。

```python
result = find(page, k)
ans = ______③______
print(ans)  # 输出改写 cache 的次数
```

## 答案

**参考答案：**

- （1）3
- （2）`tmp=result[i]`
- （3）① `tail>head and que[head] <= i-k`；② `i`；③ `count(result)`

## 解析

对每个长度为 `k` 的滑动窗口，队列 `que` 保存候选下标，并维护访问频率从队首到队尾的单调性。窗口右移时，若队首下标已经满足 `que[head] <= i-k`，就将其移出；再从队尾删除访问频率不高于当前网页的候选，最后把当前下标 `i` 入队。窗口形成后，队首对应当前窗口中访问频率最高的网页。

原图中的网页序列为 `p1(4), p2(2), p3(2), p1(4), p4(3), p5(6)`。若将 `p4` 的频率改为 5，三个窗口得到的最高频网页依次为 `p1、p4、p5`，所以改写 3 次。`count` 中每次发现当前名称与前一名称不同，都应先把 `tmp` 更新为当前名称；最终对 `result` 调用 `count` 即可得到改写次数。
