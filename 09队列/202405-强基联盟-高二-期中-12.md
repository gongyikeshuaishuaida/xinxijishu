# 题目 12

12.有如下 Python 程序段：

```python
que=[""]*20
head=tail=0
s=input("请输入待加密字符：")
for i in s:
    que[tail]=i; tail+=1
s1=""
while head!=tail:
    if head%2==0:
        s1=s1+que[head]
    else:
        que[tail]=que[head]; tail+=1
    head+=1
print(s1)
```

输入字符串 `"python"`，输出结果是（ ）

- A.`python`
- B.`ptoyhn`
- C.`ptoynh`
- D.`hnyotp`

---

## 答案

**正确答案：** C

---

## 解析

队列按下标处理：偶数下标字符直接输出，奇数下标字符追加到队尾。处理 `python` 后输出 `p、t、o、y、n、h`，即 `ptoynh`。
