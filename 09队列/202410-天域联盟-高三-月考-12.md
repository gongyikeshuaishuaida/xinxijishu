# 题目 12

有如下 Python 程序段：

```python
from random import randint
n = 5
q = [0] * n
head = tail = randint(0, n - 1)
while head != (tail + 1) % n:
    num = randint(1, n)
    if q[head] != num:
        q[tail] = num
        tail = (tail + 1) % n
    else:
        q[head] = 0
        head = (head + 1) % n
```

执行后，列表 `q` 可能为（   ）

- A. `[1,2,3,4,5]`
- B. `[3,0,1,4,1]`
- C. `[5,0,1,2,3]`
- D. `[1,0,0,4,3]`

---

## 答案

**正确答案：** C

---

## 解析

循环队列保留一个空位来区分队空和队满，结束时最多有 4 个非零元素；队列有效区域连续（可跨数组末尾回绕），空位在 `tail`。C 符合这种状态约束。
