# 题目 12

12.有如下 Python 程序段，队列 `q` 初始为 `['A','B','C','D','E','O']`，用栈 `s` 模拟随机入栈/出栈：

```python
from random import randint
q = ['A','B','C','D','E','O']
head = 0; tail = 4; top = -1
s = ['0'] * 5
for i in range(5):
    t = randint(0, 1)
    if t == 0 and head < tail:
        top += 1; s[top] = q[head]
    elif t == 1 and top != -1:
        s[top] = '0'; top -= 1
    head += 1
```

执行后，`s` 的值可能是（ ）

- A.`['B','E','O','O','O']`
- B.`['A','D','O','O','O']`
- C.`['B','D','O','O','O']`
- D.`['A','C','O','O','O']`

---

## 答案

**正确答案：** B

---

## 解析

按随机序列逐步模拟，只有选项 B 能由合法的入栈/出栈操作得到；其余选项要么跳过队首元素，要么出现不符合栈后进先出的保留顺序。
