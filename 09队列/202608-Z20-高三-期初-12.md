# 题目 12

有如下 Python 程序段：

```python
import random
que = [""] * 5
k = ""
head = tail = 0
for i in range(5):
    if random.randint(0, 1) == 0:
        while True:
            k = chr(random.randint(0, 5) + ord("A"))
            if k not in que:
                break
        que[tail] = k
        tail += 1
    elif head != tail and que[tail - 1] < que[head]:
        que[tail] = que[head]
        head += 1
        tail += 1
print(que)
```

执行该程序段后，que 的值不可能是（   ）

- A. `['', '', '', '', '']`
- B. `['D', 'E', 'C', 'D', 'E']`
- C. `['A', 'E', 'B', '', '']`
- D. `['D', 'A', 'B', 'D', 'A']`

---

## 答案

**正确答案：** D

---

## 解析

程序每次随机生成未出现过的字母入队，或将队尾元素较小时复制队首元素到队尾。结合 head、tail 的推进和队列容量逐项检查，D 所列序列可能出现，其他序列不可能。
