# 题目 12

有如下 Python 程序段：

```python
flag=True
i,j=0,len(d)
c,k=0,35
while i!=j:
    if flag==True and c<len(h):
        k+=h[c]
        c+=1
    if d[i]>k:
        if c<len(h):
            d.append(d[i])
            j+=1
    else:
        k-=d[i]
        h.append(d[i])
    i+=1
    flag=not flag
```

若 d 为 [53,35,47,39,26]，h 为 [15]，执行该程序段后，c 的值为（   ）

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** C

---

## 解析

h 的读取和 d 的处理交替进行。延期项重新入列，能满足预算的项又加入 h，最终 c 为 4。
