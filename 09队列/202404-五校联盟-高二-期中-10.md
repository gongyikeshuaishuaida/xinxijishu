# 题目 10

有如下 Python 程序段：

```python
a = [5, 4, 2, 1, 3, 6]
q = [0] * 6
head = tail = 0
for i in range(len(a)):
    if a[i] % 2 == 1:
        q[tail] = a[i]
        tail = tail + 1
    elif head < tail:
        head += 1
print(tail - head)
```

执行该程序段后，输出结果为（   ）

- A. 0
- B. 1
- C. 2
- D. 3

## 答案

**正确答案：** B

## 解析

奇数依次入队 5、1、3，tail 最终为 3；偶数 4 使 head 从 0 变为 1，偶数 2 因 head 不小于 tail 不再出队，偶数 6 再使 head 变为 2，最终 tail-head=1。
