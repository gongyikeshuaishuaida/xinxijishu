# 题目 15

某珠宝设计师推出“开盲盒得宝石项链”活动：开盲盒得 `n` 颗宝石（宝石类型不超过26种，用小写英文字母表示），设计师按开出顺序将宝石串成项链，首尾以搭扣相连成环，如第15题图a所示。项链中连续的一段宝石称为子串，允许跨过搭扣回绕到开头继续取；由于同一颗宝石不可重复出现，子串的长度不超过 `n`。

顾客想知道所有宝石互不相同的最长子串及其长度，若这样的子串有多个，输出起点编号最大的一个。为此约定：以宝石的开出顺序编号，以字符串 `s` 表示项链，首字符位置记为0，最末字符位置记为 `n-1`；子串的起点指其首颗宝石在 `s` 中的位置（跨搭扣的子串按回绕前首字符的位置计）。

![[attachments/202611环大罗山联盟高二_15_图1.png]]

例如，总长度为6的项链表示为环形字符串“acacbb”（如第15题图a），满足宝石不重复的最长子串有“acb”（起点为2）、“bac”（起点为5，跨搭扣），最终输出“bac”。

为规避复杂的环形枚举，可采用“倍长法”：将项链复制一份接在原项链末尾，得到双倍串 `t = "acacbbacacbb"`（如第15题图b），则环形子串“bac”恰好对应 `t` 中的连续段 `t[5:8]`，无需回绕判断。请回答下列问题：

(1) 环形字符串“abc”表示项链，“a”为字串起点，符合题意的由不重复宝石组成的最长子串是______。

(2) 实现上述功能的 Python 程序段如下，请在划线处填入合适的代码。

```python
def unique(s):
    n = len(s)
    t = s + s
    last = [-1] * 26  # 记录宝石出现的索引，-1表示该宝石尚未出现过
    left = start = ans = 0
    sub = ""
    for right in range(______①______):
        idx = ord(t[right]) - ord('a')
        if last[idx] >= left:
            ______②______
        last[idx] = right
        ______③______
        if left < n and length >= ans:
            ans = length
            start = left
            ______④______
    return ans, sub
ss = input("请输入代表项链中宝石的小写字母：")
max_len, max_sub = unique(ss)
print("最长子串长度：", max_len, "最长子串为：", max_sub)
```

---

## 答案

**正确答案：** (1) `cab`（参考答案）；(2) ① `2*n-1`（或 `len(t)-1`）；② `left = last[idx] + 1`；③ `length = right - left + 1`；④ `sub = t[start:start + ans]`。

---

## 解析

倍长后扫描下标0～2n-2即可覆盖每个原串起点的最长合法区间。若当前字符在窗口内已出现，left跳至上次位置之后。left单调不减，以≥更新答案能保留更大的起点。对于abc，最长长度3，原串起点最大的为2，对应cab。

原小问写“a为字串起点”，若理解为限定所求子串从a开始，则应为abc；参考答案cab采用总体规则“同长取起点编号最大”。保留原文并注明这一表述歧义。
