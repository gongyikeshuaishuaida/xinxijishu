# 题目 09

9.有1个队列，队首到队尾的元素依次为 `a,b,c,d,e`。约定：`T` 操作是队首元素出队后再入队，`Q` 操作是队首元素出队。经过 `TTTQTTQ` 操作后，队列中队首到队尾的元素依次为（ ）

A.`b,d,e`　B.`b,e,c`　C.`c,e,a`　D.`a,c,b`

---

## 答案

**正确答案：** C

---

## 解析

逐步处理：`abcde → bcdea → cdeab → deabc → eabc → abce → bcea → cea`，最终队列为 `c,e,a`。
