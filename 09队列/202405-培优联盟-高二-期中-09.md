# 题目 09

9.用列表模拟队列，程序如下：

```python
a=[3,4,5,6,7]
head=0; tail=len(a)
a += [0]*100
while head+2 <= tail:
    if a[head] % 2 == 0:
        a[tail] = a[head]//2
        head += 1; tail += 1
    elif a[head] <= 5:
        head += 1
    else:
        a[head] -= 5
print(a[head])
```

程序运行后输出结果是（ ）

- A.0
- B.1
- C.2
- D.3

---

## 答案

**正确答案：** B

---

## 解析

按队列规则逐项处理，3、5等元素出队，偶数元素折半后入队，循环结束时 `head` 指向的值为1，故选 B。
