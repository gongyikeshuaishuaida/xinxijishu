# 题目 15

某餐厅共有 m 位厨师，可同时按多个不同订单做菜。每位厨师一次只能处理一个订单，且同一订单必须由一位厨师全程负责完成。顾客订单陆续到达，若到达时有空闲厨师，则分配一位厨师开始制作，并在完成后释放厨师；否则订单进入等待队列。队列按照先到先服务的原则，当有厨师空闲时，将优先处理队列中最早到达的订单。请回答下列问题。

（1）若餐厅晚上 18:00 开始营业，共有 3 位厨师当值，当晚订单到达情况如下表所示，则所有订单完成的总耗时为 ______。

第15题订单表

（2）订单列表 ord 存储订单到达情况，每个元素前两项为订单号（格式如“D001”）和到达时间（格式如“18:05”）。需要按到达时间升序排列，同一时间到达的订单号小的在前。

```python
def sort_ord(ord):
    n = len(ord)
    for i in range(n-1):
        for j in range(0, n-1-i):
            if ord[j][1] > ord[j+1][1]:
                ord[j], ord[j+1] = ord[j+1], ord[j]
```

①（单选）若调用该函数能实现功能，则排序前 ord 必须符合的特征是：同一时间到达的订单，______。

- A. 订单号大的在前，且连续相邻
- B. 订单号大的在前，可不相邻
- C. 订单号小的在前，且连续相邻
- D. 订单号小的在前，可不相邻

②（多选）若排序前不符合上述特征，需修改判断条件：

```python
if ord[j][1] > ord[j+1][1] or ord[j][1] == ord[j+1][1] and __________:
```

划线处可填：

- A. `ord[j][0] > ord[j+1][0]`
- B. `ord[j][0] < ord[j+1][0]`
- C. `int(ord[j][0][1:]) > int(ord[j+1][0][1:])`
- D. `ord[j][1] < ord[j+1][1]`

（3）根据订单需求分配厨师的 Python 程序如下，订单数据 data 已按到达时间排序，每个元素包含订单号、到达时间（已转化为分钟）、所需时长、是否完成、完成时间，m 为厨师总数。函数返回最后一个订单的完成时间。

```python
def proc(data, m):
    chef_free = [0] * m
    queue = []
    idx = 0
    n = len(data)
    current_time = 0
    while idx < n or queue:
        while __________:  #①
            queue.append(idx)
            idx += 1
        if not queue and idx < n:
            current_time = data[idx][1]
            continue
        chefs = []
        for i in range(m):
            if chef_free[i] <= current_time:
                chefs.append(i)
        while chefs and queue:
            order_idx = queue.pop(0)
            chef_idx = chefs.pop(0)
            if current_time > chef_free[chef_idx]:
                start_time = current_time
            else:
                start_time = chef_free[chef_idx]
            __________  #②
            chef_free[chef_idx] = finish_time
            data[order_idx][3] = True
            data[order_idx][4] = finish_time
        next_event = float("inf")
        if idx < n:
            if data[idx][1] < next_event:
                next_event = data[idx][1]
        for i in range(m):
            if chef_free[i] < next_event:
                next_event = chef_free[i]
        __________  #③
    finish = 0
    for i in range(n):
        if data[i][4] > finish:
            finish = data[i][4]
    return finish
```

---

## 答案

**正确答案：** （1）115 分钟（或 1 小时 55 分钟）；（2）①D；②A、C；（3）① `idx < n and data[idx][1] <= current_time`；② `finish_time = start_time + data[order_idx][2]`；③ `current_time = next_event`

---

## 解析

18:00 D001 开始，18:10 D002、18:15 D003 分别由空闲厨师处理；D004 在 18:20 到达等待，D005 在 18:30 到达等待。18:40 厨师空闲后处理 D004，18:45 另一厨师处理 D005，最后在 19:55 完成，总耗时 115 分钟。排序题要求时间升序且同一时间订单号小的在前，原稳定排序需预先保持该相对顺序（D），若不满足则按订单号升序比较（A 或数值比较 C）。程序用到达时间把订单加入队列，完成时间为开始时间加制作时长，下一事件更新 `current_time`。
