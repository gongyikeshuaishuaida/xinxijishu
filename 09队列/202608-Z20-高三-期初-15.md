# 题目 15

近日长征十号乙火箭发射并回收成功，某兴趣小组利用计算机开展仿真推演火箭发射回收过程。现假设所有仿真推演任务分 A、B 两类，数量为 n，编号 0～n-1，各任务完成需不同时长（小时）的算力单元。算力单元每小时释放一次，同一时刻只能进行一项任务。各任务每次仅能占用 1 小时算力单元，该小时仿真推演结束后，此任务重新排队等待下一轮算力分配。各任务只有完成所需时长的算力计算，才能结束。若同一时刻有多组仿真任务时，提交时刻早的任务优先分配算力。编写程序模拟每类任务分配算力过程，输出每个任务完成的时刻（单位：小时）。图 a 为任务原始数据表，图 b 为算力分配表，请回答下列问题。

![[attachments/202608-Z20-高三-期初-15_横排1_2.png]]

（1）若仅推演 A 类算力分配（不计算 B 类），则图 b 在时刻 3 时，算力队列为 ______。

（2）定义如下函数 fini：

```python
def fini(groups, tag):
    j = 0
    a = []
    while j <= len(groups) - 1:
        if groups[j][0] == tag:
            a.append(groups[j])
        j += 1
    return a
```

完整任务列表 groups = `[["A", 0, 3], ["B", 1, 4], ["A", 2, 2], ["B", 3, 5], ["A", 4, 1], ["B", 5, 3]]`，执行 `total=len(fini(groups,"A"))` 后，total 的值为 ______。

（3）程序功能：模拟其中一类仿真推演任务运行过程，输出每个任务全部完成的时刻（单位：小时）。部分 Python 程序如下，请在划线处填入合适的代码。

```python
def control(groups, tag):
    data = fini(groups, tag)
    total = len(data)
    for i in range(total):
        data[i].append(-1)
    ans = [0] * total
    num = 0; time = 0; done = 0
    while num < total or done < total:
        if num < total and data[num][1] <= time:
            if num == done:
                __________  #①
                data[tail][3] = num
            else:
                data[num][3] = data[tail][3]
                data[tail][3] = num
            tail = num
            num += 1
        if num > done:
            __________  #②
            data[head][2] -= 1
            if data[head][2] == 0:
                ans[head] = time
                __________  #③
                done += 1
            else:
                tail = data[tail][3]
        time += 1
    return ans
```

所有任务数据存入 `groups` 列表，`groups[i][0]` 为任务类型，`groups[i][1]` 为任务提交时刻，`groups[i][2]` 为任务所需算力，数据按到达时刻升序排列。

---

## 答案

**正确答案：** （1）2、3（或 `[2,3]`）；（2）3；（3）① `tail=num`（或 `tail=done`）；② `head=data[tail][3]`；③ `data[tail][3]=data[head][3]`

---

## 解析

只推演 A 类时，按提交时刻和每小时轮转规则，到时刻 3 的队列为 `[2,3]`。`fini` 筛出任务类型为 A 的 0、2、3 号任务，共 3 个。`control` 用 `data[i][3]` 作为循环队列指针：首个任务到达时先令 `tail=num`，再链接新任务；每小时减少队首任务剩余算力，完成后将 `head` 移到队首后继（并用 `data[tail][3]=data[head][3]` 删除已完成队首），否则把队首移到队尾。
