# 题目 11

有如下 Python 程序段：

```python
que = [""] * 10
que[0] = s[0]
head = 0; tail = 1; c = 0
for i in range(len(s)):
    if "0" <= s[i] <= "9":
        c = int(s[i])
    else:
        if chr(ord(que[head]) + c) >= que[tail - 1]:
            que[tail] = s[i]
            tail += 1
            if tail - head >= 3:
                head += 1
```

若 `s = 'p4y6t9h7o1n'`，执行程序段后，队列内元素依次为（   ）

- A. y、t
- B. t、h
- C. h、o
- D. o、n

---

## 答案

**正确答案：** C

---

## 解析

程序以 `head` 指向队首、`tail` 指向队尾后一个位置维护队列；数字作为偏移量，只有偏移后的队首字母不小于当前队尾字母时才入队，长度达到 3 时出队。按给定字符串模拟，最后队列为 h、o。
