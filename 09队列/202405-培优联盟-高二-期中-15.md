# 题目 15

15.流水线产品随机进入两条分支线处理，汇合时优先选择排队较长的支线，长度相同选支线1；每条支线最多容纳5个产品。指令 `in` 投入产品，`out` 取产品汇入主线，特殊情况下需互换指令。

![[attachments/202405培优_15_流水线示意图.jpg]]

（1）支线中的数据采取什么数据结构最合理？（数组/队列/链表/栈）

（2）产品依次进入 `a、b、c、d`，则汇合后输出顺序可能是：A.`dabc` B.`cdab` C.`badc`。

（3）`minq` 寻找两条支线中当前产品数量较少的线路：

```python
def minq(h,t):
    n0=t[0]-h[0]
    return min(n0, n1)
```

（4）补全模拟程序：

```python
head=[0]*2; tail=[0]*2
i=k=0
while i<len(order):
    if ______①______:
        n=minq(head,tail)
        if n==5:
            order[i]="out"
        else:
            num=rnd(head,tail)
            ______②______ = goods[k]
            k+=1; i+=1; tail[num]+=1
    elif order[i]=="out":
        if tail[0]-head[0]+tail[1]-head[1]==0:
            order[i]="in"
        else:
            num=find(que,head,tail)
            head[num]+=1; i+=1
    if i==len(order) or k==len(goods):
        while tail[0]-head[0]>0 and tail[1]-head[1]>0:
            if ______③______:
                print(que[1][head[1]])
                head[1]+=1
            else:
                print(que[0][head[0]])
                head[0]+=1
        break
```

---

## 答案

**正确答案：** （1）队列；（2）C；（3）`n1=t[1]-h[1]`；（4）① `order[i]=="in"`；② `que[num][tail[num]]`；③ `tail[0]-head[0] < tail[1]-head[1]`

---

## 解析

分支线按先入先出处理，适合队列。长度相同选支线1、较长优先的规则使 `badc` 成为可能顺序。`minq` 返回第二条队列长度需先计算 n1；入队写入队尾位置，输出分支2的条件是分支1长度更短。
