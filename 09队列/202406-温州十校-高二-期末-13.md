# 题目 13

斐波那契数列满足 `F(1)=1`、`F(2)=1`、`F(n)=F(n-1)+F(n-2)`（`n≥3`）。程序使用长度为 3 的循环队列计算第 n 项，请回答并填空：

~~~python
q = [1, 1, -1]
head = 0
tail = 2
n = int(input("请输入 n 的值 (3≤n≤100):"))
for i in range(n - 1):
    ______①______ = q[head] + q[(head + 1) % 3]
    tail = (tail + 1) % 3
    head = ______②______

print("斐波那契数列的第 n 项为", ______③______)
~~~

（1）程序中组织数据采用的数据结构为 ______④______（填字母：A.队列 / B.链表 / C.栈）。

---

## 答案

**正确答案：** ①`q[tail]`；②`(head+1)%3`；③`q[head]`；④A

---

## 解析

新项写入队尾位置，队尾和队头都按长度 3 循环移动；每次循环用当前队头和下一个元素相加得到下一项，最后队头位置保存第 n 项。因此 ①为 `q[tail]`，②为 `(head+1)%3`，③为 `q[head]`，数据结构是队列。
