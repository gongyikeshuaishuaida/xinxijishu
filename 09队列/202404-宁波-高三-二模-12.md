# 题目 12

12.有如下 Python 程序段：

```python
li = [2, 3, 1] + [0] * 10
head = 0
tail = 3
for i in range(2):
    t = li[head]
    head += 1
    for j in range(2):
        if t < li[head]:
            li[tail] = t
            t = li[head]
        else:
            li[tail] = li[head]
        head += 1
        tail += 1
    li[tail] = t
    tail += 1
print(li[head:tail])
```

执行后输出结果是（ ）

- A. `[2, 1, 3]`
- B. `[1, 3, 2]`
- C. `[3, 2, 1]`
- D. `[1, 2, 3]`

---

## 答案

**正确答案：** D

---

## 解析

程序每轮从队头取出元素，与后续两个元素比较并按从小到大重新排入队尾；两轮后队列为 `[1,2,3]`，故选 D。
