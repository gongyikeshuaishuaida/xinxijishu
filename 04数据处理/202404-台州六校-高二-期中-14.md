# 题目 14

分析浙江省旅游景区数据，图14-1为数据表，图14-2为各城市景区数量柱形图。

![[attachments/202404台州六校_14_景区数据表.jpg]]

（1）“等级”列部分数据出现 ______①______ 问题（A.数据缺失 B.数据重复 C.数据异常 D.格式不一致）。将类似 `3A` 修改为 `AAA`，两处横线代码相同：

```python
for i in range(len(df)):
    grade = ______②______
    if "1" <= grade[0] <= "5":
        ______②______ = "A" * int(grade[0])
```

可选：A. `df.等级[i]`；B. `df["等级"][i]`；C. `df[i]["等级"]`；D. `df["等级"][i]`；E. `df.at[i, "等级"]`。

（2）查询某地市的景区名称，并导出 Excel：`y = ______③______`。

（3）统计每个地市景区数量并按数量降序绘制柱形图：

```python
df1 = df.groupby("地市", as_index=False).______④______()
# 按数量降序后绘图
plt.bar(______⑤______, ______⑥______)
```

![[attachments/202404台州六校_14_景区柱形图.jpg]]

---

## 答案

**正确答案：** ① D；② A、D、E；③ `df[df.地市 == x]`；④ `count`；⑤ `df1.index`；⑥ `df1.数量`

---

## 解析

`3A` 与 `AAA` 表示方式不统一，属于格式不一致。访问 DataFrame 单元格可用列属性、列名索引或 `at`。按地市筛选得到查询结果；`groupby(...).count()`统计数量，再用索引和数量列绘制柱形图。
