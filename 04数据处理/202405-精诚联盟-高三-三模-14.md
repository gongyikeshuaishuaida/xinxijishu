# 题目 14

14.小林用 Python 分析无人超市销售数据“销售清单.xlsx”。

![[attachments/202405-精诚联盟-高三-三模-14_横排1_2.png]]

（1）要分析“生鲜”类商品单次销售额最高的数据，以下方法可以实现的是（ ）

- A.对 `df` 按金额降序排序，取最前面的数据
- B.对 `df` 按品类升序排序保存到 `dfs`，再对 `dfs` 按金额降序排序取最前面的数据
- C.先筛选品类为“生鲜”的数据 `dfs`，再按金额降序排序取最前面的数据

（2）统计每月销售总额最大值：

```python
if prevm != 0 and ______①______:
    ______②______
prevm = m
if maxe < f[prevm]:
    maxe = f[prevm]
```

（3）统计每个品类总销售额并绘制柱形图：

```python
dfg = df.groupby("______③______")["金额"].sum()
x = dfg.index
y = ______④______
plt.bar(x, y)
```

---

## 答案

**正确答案：** （1）C；（2）① `maxe < f[prevm]`；② `maxe = f[prevm]`；（3）③ `品类`；④ `dfg.values`

---

## 解析

先筛选“生鲜”再排序才能排除其他品类。按支付时间排序后，遇到新月份时先比较已结束月份的总额；按品类分组求和得到 Series，横轴为索引、纵轴使用 `dfg.values`。
