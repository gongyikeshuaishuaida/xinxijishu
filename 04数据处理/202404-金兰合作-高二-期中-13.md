# 题目 13

13.某中学高一年级完成一次 7 选 3 意向调查，数据存储在 `xk.csv` 中，其中 1 代表选择该科目，0 代表弃选。

![[attachments/202404金兰合作_13_选科数据表.jpg]]

（1）统计各科人数：

```python
for i in df.index:
    for j in df.columns[3:]:
        if df.at[i, j] == 1:
            ______①______
```

（2）按各科选报人数占比绘图：

![[attachments/202404金兰合作_13_选科人数图.jpg]]

```python
df1 = pd.DataFrame({"学科": dic.keys(), "人数占比": dic.values()})
df1 = df1.sort_values("人数占比", ascending=______①______)
plt.title("各科选考人数占比")
```

（3）查询输入组合 `cx` 的选报人数：

```python
for i in range(len(xkzh)):
    if ______①______:

```


---

## 答案

**正确答案：** （1）① `dic[j] += 1`；（2）① `False`；② `df1.学科, df1.人数占比`；（3）`xkzh[i] == cx`

---

## 解析

每出现一次选科标记就将对应学科的计数加一，①为 `dic[j]+=1`；图表按占比降序排列，升序参数填 `False`，横纵坐标使用 `df1.学科,df1.人数占比`；查询时逐条比较组合，条件为 `xkzh[i]==cx`。
