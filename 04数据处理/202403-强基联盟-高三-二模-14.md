# 题目 14

某竞赛获奖名单已公布，现要对获奖情况进行数据处理和分析。

第14题图 a 为获奖名单数据表：

![[attachments/202403强基联盟_14_获奖名单.jpg]]

（1）将获奖名单读取到 DataFrame 对象 `df` 中，若要统计浙江省内获得满分 400 分的总人数，下列方法正确的是（单选，填字母）。

- A. 从 `df` 中筛选出省份为“浙江”的数据，再筛选总分为 400 的数据，最后对“姓名”列使用 `count()` 统计人数
- B. 按“总分”降序排列后筛选浙江数据，最后对“姓名”列使用 `sum()` 统计人数
- C. 按“总分”分组并统计总人数，再筛选省份为“浙江”的总人数

（2）提取的部分数据如下图 b。小陆想统计各省份一等奖获奖学生的准考证号，存储在字典 `dic` 中，`h` 为一等奖分数线。请填空。

![[attachments/202403强基联盟_14_获奖表b.jpg]]

```python
i = 0
dic = {}
while i < len(lst):
    if ______①______:
        city = lst[i][0]
        if city in dic:
            dic[city] += "," + lst[i][1]
        else:
            ______②______
    i += 1
```

（3）新增“获奖等级”列并保存到 `data.xlsx`，如下图 c。程序要统计一等奖人数最多的前 5 个省份并绘制图 d，请填空。

![[attachments/202403-强基联盟-高三-二模-14_横排3_4.png]]

```python
df = pd.read_excel("data.xlsx")
df1 = ______①______                 # 选取一等奖数据
df2 = df1.groupby("省份").count()
df2.rename(columns={"姓名": "获奖人数"}, inplace=True)
g = df2.sort_values("获奖人数", ascending=False).head(5)
plt.bar(______②______)              # 绘制柱形图
```

## 答案

**正确答案：** （1）A；（2）① `lst[i][2] >= h`；② `dic[city] = lst[i][1]`；（3）① `df[df["获奖等级"]=="一等奖"]`；② C（`g.index, g.获奖人数`）。

## 解析

统计浙江满分人数应先按省份和总分筛选，再对姓名列计数。遍历列表时只处理达到一等奖分数线的记录，并把同一省份的准考证号用逗号连接。分组统计后按获奖人数降序取前五名，`groupby` 后省份成为索引，柱形图横轴应使用 `g.index`，纵轴使用获奖人数列。
