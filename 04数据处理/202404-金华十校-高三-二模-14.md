# 题目 14

14.某博物馆一天 24 小时温湿度数据导出存储在 `data.xlsx` 文件中，部分数据如图所示（时间格式为“时:分:秒”）。现对采集到的数据进行处理和分析。

（1）为了对温湿度数据进行整理，保存每分钟的温度和湿度数据到列表 `tp` 和 `hd` 中，并筛选出每个小时的最大温湿度值作为数据分析对象，程序如下，请在划线处填入合适的代码。

```python
import pandas as pd
df = pd.read_excel("data.xlsx")
df.insert(0, "小时", "")
tp, hd = [], []
for i in df.index:
    t = df.at[i, "时间"]
    df.at[i, "小时"] = ______①______
    tp.append(df.at[i, "温度"])
    hd.append(df.at[i, "湿度"])
dft = df.groupby("______②______", as_index=False).max()
print(dft)
```

（2）标准规定：温度 `18-25°C` 且湿度为 `40-50%` 为适宜的温湿度。若第 `i` 分钟的温度 `tp[i]` 和湿度 `hd[i]` 都达到要求就属于“温湿度适宜”，否则属于“温湿度不适宜”。下列判断中正确的是（多选，填字母）。

- A. `18 <= tp[i] <= 25 and 40 <= hd[i] <= 50` 时温湿度适宜
- B. `18 <= tp[i] <= 25 or 40 <= hd[i] <= 50` 时温湿度适宜
- C. `(tp[i] > 25 or tp[i] < 18) and (hd[i] > 50 or hd[i] < 40)` 时温湿度不适宜
- D. `(tp[i] > 25 or tp[i] < 18) or (hd[i] > 50 or hd[i] < 40)` 时温湿度不适宜

（3）为了统计出一天中“温度不适宜”的最长持续时间 `s`，程序如下，请在划线处填入合适的代码：

```python
i = j = 0
n = len(tp)
s = t = 0
while ______①______:
    while i < n and 18 <= tp[i] <= 25:
        i += 1
    j = i
    while j < n and (tp[j] < 18 or tp[j] > 25):
        j += 1
    ______②______
    if t > s:
        s = t
    i = j + 1
print(s)
```

---

## 答案

**正确答案：** （1）① `t[0:2]`；② `小时`；（2）A、D；（3）① `i < n`；② `t = j - i`

---

## 解析

（1）`t[0:2]` 取出时间字符串的小时部分，分组字段为“小时”。

（2）温度和湿度都在适宜范围内才是适宜，A 正确；只要温度或湿度超出范围就不适宜，D 正确。

（3）外层循环应遍历全部数据，填 `i < n`（或 `i <= n-1`）；内层找到一段不适宜区间后，其持续长度为 `t = j - i`。
