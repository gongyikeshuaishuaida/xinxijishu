# 题目 14

公交公司将某站台4月份的客流数据导出到文件 `data.xlsx` 中，部分数据如第14题图a所示（统计时段为每天6:00—22:00，每10分钟一条记录）。请回答下列问题：

![[attachments/202611金华十校高三_14_图1.png]]

(1) 为分析该站台4月份每天的到达总人数变化情况，绘制如第14题图b所示的线形图，并找出到达总人数最多的一天。实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
import pandas as pd

df = pd.read_excel("data.xlsx")

plt.plot(df1["日"], df1["到达人数"])  # 绘制线形图
# 设置绘图参数，显示如图b所示的线形图，代码略
i = 0
for j in range(len(df1)):
    if df1.at[j, "到达人数"] > df1.at[i, "到达人数"]:
        ______②______
print("到达总人数最多的是", df1.at[i, "日"], "日")
```

(2) 将该站台某工作日6:00—22:00每10分钟的“净增候车人数”（到达人数-上车人数，可为负数）按时间顺序存入列表 `a`。现要找出候车压力最大的连续时段，即：连续若干个统计时段的净增候车人数之和最大的区间，输出该最大总和及区间的起止下标（若有多个，输出最晚出现的）。若列表 `a` 为 `[3, -1, 4, -2, -5, 2, 3]`，则最大总和为______。

(3) 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 读入净增候车人数数据，按时间顺序存储于列表a中，代码略
maxs = a[0]  # 最大总和
cur = 0  # 当前区间的累计和
start = 0  # 当前区间的起始下标
s = e = 0  # 最大区间的起止下标
for i in range(len(a)):
    if cur <= 0:
        ______①______
        start = i
    else:
        cur += a[i]
    if ______②______:
        maxs = cur
        s = start
        ______③______
print(maxs, s, e)
```

---

## 答案

**正确答案：** (1) ① `日`；② `i = j`；(2) 6；(3) ① `cur = a[i]`；② `cur >= maxs`；③ `e = i`。

---

## 解析

按日分组求和，遍历记录最大到达人数所在行。最大连续子段和中，旧累计和非正时从当前元素重新开始；用≥更新相同最大值，可保留更晚出现的区间，同时更新终点。示例最大段为[3,-1,4]，和为6。
