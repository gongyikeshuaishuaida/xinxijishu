# 题目 13

13.小陆下载浙江省2023年普通高校招生普通类第一段平行投档分数线，数据存放在“分数线.xlsx”中。

数据表截图如下：

![[attachments/202404浙南_13_成绩数据表上.jpg]]
![[attachments/202404浙南_13_成绩数据表下.jpg]]

（1）以下对常见数据问题的处理正确的是（多选）：

A.数据缺失通常采用平均值、中间值或概率统计值填充缺失值
B.多数据源合并集成时产生的数据重复，可以直接删除重复数据
C.数据异常可根据实际情况进行修改
D.不同来源的数据格式不一致，保留一种格式的数据，其他格式的数据删掉即可

（2）输入学校名称，找出该学校的所有数据：

```python
school = input("请输入学校名称：")
if school in list(df.学校名称):
    zz = ______①______
```

（3）按“地区”统计招生计划数并按计划数降序排序：

```python
df1 = ______②______
df2 = df1.______③______("计划数", ascending=False)
```

选项：

A.`df.groupby("地区",as_index=False).计划数.count()`
B.`df.groupby("地区",as_index=False).计划数.sum()`
C.`df.groupby("地区").计划数.count()`
D.`df.groupby("地区").计划数.sum()`

![[attachments/202404浙南_13_学校计划数输出.jpg]]

（4）取招生人数最少的5个地区绘制柱形图：

```python
data = ______④______
plt.______⑤______(data.地区, data.计划数, label="计划数")
```

![[attachments/202404浙南_13_计划数柱形图.jpg]]

---

## 答案

**正确答案：** （1）AC；（2）① `df[df["学校名称"]==school]`（或 `df[df.学校名称==school]`）；（3）② B；③ `sort_values`；（4）④ `df2.tail()`（或 `df2[-5:]`）；⑤ `bar`

---

## 解析

缺失值可按数据特点填补，异常值可结合实际修改；重复数据不能不加判断地删除，格式不一致也应转换统一而非直接丢弃。按学校筛选行用布尔条件；按地区统计招生计划应求和并保留地区列，再用 `sort_values` 降序排列，`tail()` 取排序后计划数最少的5行，用 `bar` 绘图。
