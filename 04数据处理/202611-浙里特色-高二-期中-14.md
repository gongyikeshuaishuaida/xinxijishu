# 题目 14

某校学生的课外运动积分存储在文件“jifen.xlsx”中，数据表包含学号、班级、积分三列，如第 14 题图 a所示，现要对这份运动积分数据做数据分析，请回答下列问题：

![[attachments/202611浙里特色高二_14_图1.png]]

（1）新增一列 “积分等级”，划分规则：积分＞10 记为“优秀”，6≤积分≤10记为“合格”，积分＜6 记为“待提升”。实现该功能的 Python 程序如下，请将划线处代码补充完整。

```python
import pandas as pd
df = pd.read_excel("jifen.xlsx")
rank_list=[]
for i in range(len(df)):
    if ______①______:
        rank_list.append("优秀")
    elif df["积分"][i] >= 6:
        rank_list.append("合格")
    else:
        rank_list.append("待提升")
df["积分等级"] = ______②______
```

（2）现要统计每个班级的积分总和，找出积分总和最高的前 6 个班级，按照班级总积分降序排序，绘制如图 b 所示的柱状图。

![[attachments/202611浙里特色高二_14_图2.png]]

实现该功能的 Python 程序如下，请选择合适代码填入划线①、②、③（单选，填字母）。

```python
df1 = ______①______    # 按班级分组，计算各班积分总和
df2 = ______②______    # 按总积分降序排序
df3=df2.head(6)
plt.bar(______③______)
plt.show()
```

可选代码：

- A. `df.groupby("班级",as_index=False)["积分"].sum()`
- B. `df.groupby("班级")["积分"].sum()`
- C. `df1.sort_values("积分",ascending=True)`
- D. `df1.sort_values("积分",ascending=False)`
- E. `df3.班级,df3.积分`
- F. `df2.班级,df2.积分`

---

## 答案

（1）① `df["积分"][i]>10`，② `rank_list`。

（2）① A，② D，③ E。

---

## 解析

先用大于 10 划分优秀，再用大于等于 6 划分合格。按班级分组求和并保留班级列，降序排序取前六行，用这六行的班级和积分绘图。
