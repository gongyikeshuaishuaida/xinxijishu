# 题目 14

某市居民阶梯电价按年用电量分三档。小明从平台收集 2023 年每天用电量，整理在 data.csv 中，要统计每月用电量、电费和全年电费。

![[attachments/202406浙南_14_阶梯电价表.jpg]]
![[attachments/202406-浙南-高二-期末-14_横排2_3.png]]

（1）从 data.csv 读取数据并绘制各月用电量图，补全：

    df = df.sort_values("日期", ascending=True)
    m = []
    for item in ______①______:
        m.append(item[5:7])
    df["月份"] = m
    df_g = df.groupby("月份", as_index=False).用电量.sum()
    plt.plot(______②______)

（2）根据每月用电量计算开始超过第一档 L1 和第二档 L2 的月份，补全：
    
    def find(s, L1, L2):
        t = 0; flag = False; p = [12, 12]
        for i in range(len(s)):
            t += s[i]
            if ______③______:
                p[0] = i; flag = True
            if t > L2:
                p[1] = i; break

（3）计算每月电费和全年电费时，补全：
    
    fee[i] = (level[m] - (total - t)) * price[m] + ______④______

---

## 答案

**正确答案：** （1）① df["日期"]；② df_g.月份, df_g.用电量；（2）③ t > L1 and flag == False；（3）④ (total - level[m]) * price[m+1]。

---

## 解析

日期列切片 item[5:7] 得到月份字符串，按月份分组求和后绘制月份与用电量。find 函数只在累计电量首次超过 L1 时记录位置，并继续寻找 L2。跨越档位的月份先按当前档位计费至档位上限，超出部分按下一档价格计算。
