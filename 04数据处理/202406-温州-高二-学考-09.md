# 题目 09

某家庭 2023 年全年的支出保存在“家庭支出.xlsx”文件中，部分数据如下图。编写 Python 程序，统计今年支出最大类别的相关数据。方框中代码由下列语句中的部分语句组成，正确的选项是（   ）

![[attachments/202406温州_09_家庭支出表.jpg]]

```python
import pandas as pd
df = pd.read_excel("家庭支出.xlsx")
print(df)
```

候选语句：

① `df = df.groupby("类别").sum()`

② `df = df.groupby("金额").sum()`

③ `df = df.sort_values("金额", ascending=True).tail(1)`

④ `df = df.sort_values("金额", ascending=False).head(1)`

⑤ `df = df.max()`

- A.①③
- B.①⑤
- C.④①
- D.②③

---

## 答案

**正确答案：** C

---

## 解析

需要先得到金额最大的记录，再按“类别”汇总相关数据，必要语句是④和①。选项 C 给出了这两条语句；按题目给出的候选组合核定为 C。
