# 题目 14

某班级使用 Excel 整理各同学的加分、扣分情况，从“卫生、上课、早晚读、作业、日常”5个方面评分，A～F 分别对应 3、2、1、-1、-2、-3 分，N 表示 0 分。数据如下：

![[attachments/202410丽水五校_14_班级加扣分表.jpg]]

班主任筛选总分不为 0 的同学，按小组汇总并绘制总分前 3 名：

![[attachments/202410丽水五校_14_小组总分柱形图.jpg]]

（1）（2）补全程序中的①～④：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_excel("班级名单.xls")
fs = {"A": 3, "B": 2, "C": 1, "D": -1, "E": -2, "F": -3}
qnum = df.columns[2:7]
for i in ______①______:
    s = 0
    for j in qnum:
        if "A" <= df.at[i, j] <= "F":
            a = ______②______
            s = s + fs[a]
    df.at[i, "总分"] = s
print(df)

df1 = ______③______
df2 = df1.groupby("小组", as_index=False).总分.sum()
df3 = df2.sort_values(______④______).head(3)
______⑤______
plt.title("小组总分前 3 情况")
plt.bar(x, y, label="总分情况")
plt.legend()
plt.show()
```

（3）方框处最合适的是 ______⑤______（单选，填字母）。

- A. `x=df3.小组`，`y=df3.总分`
- B. `x=df3.index`，`y=df3.总分`
- C. `x=df3.index`，`y=df3.values`
- D. `x=df3.小组`，`y=df3.values`

---

## 答案

**正确答案：** ① `df.index`；② `df.at[i, j]`；③ `df[df.总分 != 0]`；④ `"总分", ascending=False`；⑤ A

---

## 解析

遍历 DataFrame 的行索引用 `df.index`，单元格值通过 `df.at[i,j]` 取得。筛选总分非零的行后按小组求和，再按“总分”降序取前三。柱形图的横轴应为小组列、纵轴应为总分列。
