# 题目 14

某中学高一年级完成一次“7 选 3”意向调查，数据存储在 `xk73.xlsx` 中，其中 1 代表选择科目，0 代表弃选科目。

第14题图 a：

![[attachments/202403浙江四校_14_选课数据.jpg]]

（1）用 pandas 计算各科选课人数占总人数比例，请填空。

```python
df = pd.read_excel("______①______")
a = [""] * len(df)
dic = {"物":0, "化":0, "生":0, "政":0, "历":0, "地":0, "技":0}

for i in df.index:
    for j in df.columns[3:]:
        if df.at[i, j] == 1:
            dic[j] += 1
            a[i] = ______②______

for i in dic.keys():
    dic[i] = round(dic[i] / len(df) * 100, 2)
```

（3）查询某种七选三组合的人数。若输入组合存储在 `cx` 中，请填空：

```python
cx = input("请输入需要查询的选课组合：")
cnt = 0
for i in range(len(a)):
    if ______③______:
        cnt = cnt + 1
print(f"选择{cx}组合的同学共有：{cnt}人")
```

## 答案

**正确答案：** （1）① `xk73.xlsx`；② `a[i] + j`；（2）① B；② E；（3）① `a[i] == cx`。

## 解析

读取文件名为 `xk73.xlsx`。遍历所选科目时把科目字母追加到该生的组合字符串 `a[i]`，并统计每科人数。图 b 按比例降序排列，横轴为 `df1.学科`、纵轴为 `df1.人数占比`。查询时直接比较每名学生组合字符串与输入组合。
