# 题目 14

某校为支持学生学习进步，允许每位学生从语数英物化生政史地技 10 门科目中选择不超过两门作为补弱科目，数据存储在 `student.xlsx` 中。

![[attachments/202404五校_14_选科数据.jpg]]

（1）筛选补弱科目数超出两门的学生记录：

```python
df = pd.read_excel("student.xlsx")
df_err = df[______]
```

（2）整理数据并统计各班各科选择人数及比例：

```python
km = ["语文","数学","英语","物理","化学","生物","政治","历史","地理","技术"]
df1 = df.groupby("班级").______①______
df2 = df1.drop(["姓名","科目数"], axis=1)
g = df2.sum()
for k in km:
    per = ______②______ / len(df) * 100
    print(k, "比例为:", round(per, 2), "%")
x = ______③______
y = g.values
plt.bar(x, y)
```

（3）上面程序产生的各科人数柱形图如图：

![[attachments/202404五校_14_各科人数柱形图.jpg]]

## 答案

**正确答案：**

- （1）`df.科目数>2`（`df.科目数>=3`、`df["科目数"]>2` 等价）
- （2）① `count()`；② `g[k]`；③ `g.index`（或 `km`）

## 解析

先按科目数筛选出大于 2 的错误记录。按班级分组后调用 `count()`，删除姓名和科目数列并求和得到各科选择人数；比例分子为当前科目对应的 `g[k]`，柱形图横轴可使用 `g.index` 或科目列表 `km`。
