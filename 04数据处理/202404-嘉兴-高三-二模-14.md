# 题目 14

14.某学校高二年级举办投篮比赛，每人投球 5 次，比赛数据存储在 `scores.csv` 文件中，“投球情况”中 1 表示投中，0 表示投失。计分规则为：投中得 1 分，投失不得分；若连续投中，该球得分为前一球得分的 2 倍。请回答下列问题：

（1）若某同学投球情况是“11011”，则得分是 ______ 分。

（2）自定义函数 `fcount` 功能是根据计分规则计算投球得分。实现上述功能的程序代码如下，请在划线处填入合适的代码。

```python
def fcount(data):
    total = 0
    temp = 0
    for i in range(len(data)):
        if ______①______:
            temp = 1
        elif data[i] == '1':
            ______②______
        else:
            temp = 0
        total += temp
    return total
```

## 答案

**正确答案：** （1）6；（2）① `data[i]=="1" and temp==0`；② `temp=2*temp`（或 `temp*=2`）；（3）`df1.at[i,"投球情况"]`（等价写法可）；（4）① `mean()`；② CD

---

## 解析

（1）投球情况 `11011` 的得分依次为 1、2、0、1、2，总分为 6。

（2）当当前投中且前一球得分为 0 时，本球得 1 分；连续投中时，本球得分为前一球的 2 倍；投失则将连续状态清零。因此 ①为 `data[i]=="1" and temp==0`，②为 `temp=2*temp`（或 `temp*=2`）。

（3）`df1.at[i,'投球情况']` 取得当前行的投球字符串，作为 `fcount` 的参数。

（4）`groupby("班级", as_index=False).mean()` 计算各班平均分；按平均分降序取前 5 名时，C、D 两种写法都正确。
