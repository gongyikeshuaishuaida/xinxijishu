# 题目 14

高一年级 9 个班进行“七选三”预选科，每班一个 Excel 文件存储选科数据。“1”表示选择该科目，空白表示未选择。

![[attachments/202404-杭州-高三-二模-14_横排1_2.png]]

（1）定义 `check(dfs)` 检查选考科目数，返回错误数据行对应的学生序号。

```python
def check(dfs):
    erlst = []
    for i in range(len(dfs)):
        xk_sum = 0
        for j in dfs.columns[2:]:
            dyg = ______①______
            if dyg == 1:
                xk_sum += dyg
        if xk_sum != 3:
            erlst.append(______②______)
    return erlst
```

① 正确代码为（单选）：A. `dfs.at['i','j']`；B. `dfs.at['j','i']`；C. `dfs.at[i,j]`；D. `dfs.at[j,i]`。

② 划线处应填入合适代码。

（2）若检查无误，统计每班同时选择“物理”和“化学”的人数，存入字典 `ans`：

```python
for i in range(1,10):
    filename = str(i) + '.xlsx'
    df = pd.read_excel(filename)
    errlist = check(df)
    if errlist != []:
        print('请检查文件', filename, '中序号为', errlist, '的学生')
    else:
        ______③______  # 筛选同时选择物理和化学的数据记录存入 dfl
        ans[str(i)+'班'] = [______④______]
```

③ 正确代码段为 ______③______（多选，填字母）：

- A.
```python
dfl = df[df['物理'] == 1]
dfl = dfl[dfl['化学'] == 1]
```
- B.
```python
dfl = df[df['物理'] == 1]
dfl = df[df['化学'] == 1]
```
- C.
```python
dfl = df[df['化学'] == 1]
dfl = dfl[dfl['物理'] == 1]
```
- D.
```python
dfl = df[df['化学'] == 1]
dfl = df[df['物理'] == 1]
```

④ 划线处应填入合适代码。

![[attachments/202404杭州_14_图c图d_统计图.png]]

（3）根据`ans`创建并转置DataFrame，绘制图示柱形图。⑤处应填入 ______⑤______（单选，填字母）：

- A. `adf.人数, adf.班级`
- B. `adf.班级, adf.人数`
- C. `adf.人数, adf.index`
- D. `adf.index, adf.人数`

## 答案

**正确答案：**

- （1）① C（`dfs.at[i,j]`）；② `i+1`
- （2）③ A、C；④ `len(dfl)`（或 `len(dfl.index)`）
- （3）⑤ D（`adf.index, adf.人数`）

## 解析

DataFrame 的 `at` 用行、列标签或位置变量访问当前单元格，故用 `dfs.at[i,j]`。学生序号比 DataFrame 的零起始行号大 1。连续两次布尔筛选可交换顺序，A、C 都保留同时选择物理和化学的记录；人数用筛选后 DataFrame 的长度统计。柱形图横轴为班级索引、纵轴为人数，因此选择 D。
