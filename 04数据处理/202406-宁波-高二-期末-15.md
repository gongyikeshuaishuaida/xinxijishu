# 题目 15

15.某旅游城市推出 24 小时环岛观光车服务，按发车时间升序记录每辆车的乘客省份，统计截至发车时最近 24 小时内的不同省份数。

![[attachments/202406宁波_15_观光车来源表.jpg]]

（1）第 4 辆车在第 1445 分钟发车，车内 6 名乘客来自上海市、上海市、浙江省、浙江省、浙江省、山东省，则此时有 ______①______ 个不同省份。

（2）函数 updata(loc,flag,ans)：

~~~python
def updata(loc,flag,ans):
    if flag==True:
        for i in loc:
            if i in info:
                info[i]+=1
            else:
                info[i]=1
                ______②______
    else:
        for i in loc:
            info[i]-=1
            if ______③______:
                ans-=1
    return ans
~~~

（3）主程序：

~~~python
info={}
______④______
ans,start=0,0
for i in range(n):
    for k in range(start,i):
        if t[i]-t[k]<1440:
            break
        ans=updata(prov[k],False,ans)
        ______⑤______
    ans=updata(prov[i],True,ans)
~~~


---

## 答案

**正确答案：** ①5；②ans+=1；③info[i]==0；④n=len(t)（或 n=len(prov)）；⑤start=k

---

## 解析

当前 24 小时窗口中合并历史乘客和本车乘客后共有 5 个不同省份。某省份第一次进入字典时才使计数加 1，所以函数空格为 ans+=1；移出车辆后计数变为 0 时才使答案减 1，即 info[i]==0。主程序先令 n 为 t 或 prov 的长度，窗口左界移到 k，对应 n=len(t)（或 n=len(prov)）和 start=k。
