# 题目 15

某超市统计分析2023年1—4季度国产商品销售额占比。所有商品销售数据存储在“已售商品.csv”中，按售出时间升序排序；条形码编号中前3位表示国家代码，690—699代表中国。

第15题图a：

![[attachments/202401-丽水-高二-期末-15_横排1_2.png]]

（1）图中数据出现“20230132”，属于（单选，填字母）数据问题：A.数据缺失/B.数据重复/C.逻辑错误。

（2）定义函数判断该商品是否属于“国产”：

~~~python
def contryinfo(tym):
    data=int(tym[0:3])
    if ______①______:
        return 0  # 表示该商品属于“国产”
    else:
        return 1
~~~

（3）定义函数计算该商品所属季度：

~~~python
def jdinfo(t):
    month=int(t[4:6])
    return ______②______
~~~

（4）统计程序如下，请在划线处填入合适的代码。

~~~python
sales=[[0,0,0,0],[0,0,0,0]]
for k in range(len(lst)):
    i=jdinfo(lst[k][0])
    j=contryinfo(lst[k][1])
    ______③______

df=pd.DataFrame(sales,columns=['第一季度','第二季度','第三季度','第四季度'],index=['国产','非国产'])
df=df.T
df['国产商品占比']=______④______
plt.plot(df.index, ______⑤______)
~~~

---

## 答案

**正确答案：** （1）C；（2）① 690<=data<=699；（3）② (month+2)//3-1；（4）③ sales[j][i]+=float(lst[k][2])*int(lst[k][3])；④ df['国产']/(df['国产']+df['非国产'])*100；⑤ df.index,df.国产商品占比（或 df['国产商品占比']）。

---

## 解析

“20230132”中的月份为01但日期为32日，不符合日期规则，属于逻辑错误。函数先取条形码前三位并判断是否在690—699之间；月份转换为季度下标时，用 (month+2)//3-1 把1—3月映射为0、4—6月映射为1，以此类推。j 表示国产/非国产行，i 表示季度列，因此应把销售价乘销售数量累加到 sales[j][i]。转置后每行是一季度，国产商品占比为国产销售额除以总销售额再乘100，最后绘制“国产商品占比”列。
