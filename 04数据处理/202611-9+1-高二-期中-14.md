# 题目 14

某社区在沿江步道布设了“智慧步道”系统，居民刷脸即可记录当日步数。系统把一周内各居民在各小区的打卡数据保存在 step.xlsx 中，部分数据如第 14 题图 a 所示。

![[attachments/2026119+1高二_14_图1.png]]

（1）为提醒居民加强锻炼，需将日步数低于 6000 步的记录，在其“姓名”前加“△”标识；并筛选出日步数不少于 15000 步的“健步达人”记录输出。请在划线处填入合适的代码。



```python
df = pd.read_excel("step.xlsx")
for i in df.index:
    if ______①______:
        df.at[i, "姓名"] = "△" + df.at[i, "姓名"]
dfx = ______②______
print(dfx)
```



（2）社区需统计各小区居民的平均日步数，按平均步数从高到低排列后输出，并绘制柱形图（如第 14 题图 b 所示）。请完成下列程序。

![[attachments/2026119+1高二_14_图2.png]]



```python
dfm = df.______①______.步数.mean()
dfs = dfm.______②______
print(dfs)
plt.title("各小区平均日步数")
plt.bar(______③______)
plt.show()
```



①划线①处应填入的代码是 ______。



- A. `groupby("小区", as_index=False)`



- B. `groupby("步数", as_index=False)`



- C. `groupby("小区", as_index=True)`



- D. `groupby("步数", as_index=True)`

②划线②处应填入的代码是 ______。



- A. `sort_values("步数", ascending=True)`



- B. `sort_values("步数", ascending=False)`



- C. `sort_values("小区", ascending=True)`



- D. `sort_values("小区", ascending=False)`

③（多选）划线③处能正确绘制柱形图的代码可以是 ______。



- A. `dfs.小区, dfs.步数`



- B. `dfs["小区"], dfs["步数"]`



- C. `dfs."小区", dfs."步数"`



- D. `dfs[小区], dfs[步数]`

（3）根据统计结果，平均日步数不低于 10000 步的“健步小区”共有 ______ 个。

---

## 答案

（1）① `df.at[i,"步数"] < 6000`；② `df[df["步数"] >= 15000]`。

（2）① A；② B；③ A、B。

（3）3。

---

## 解析

逐行修改姓名时以该行步数判断；筛选“达人的整行记录”需使用布尔索引。按小区分组求均值并保留小区为普通列，按步数降序排序；绘图的横纵数据可用属性或字符串列名索引取得。柱形图中有 3 个小区达到 10000 步。
