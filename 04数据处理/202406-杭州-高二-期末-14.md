# 题目 14

14.小华搭建花房光照强度和湿度监测系统原型。智能终端连接光敏传感器和湿度传感器，每分钟采集一次数据，经 IoT 模块发送至 Web 服务器，客户端使用浏览器实时查看数据，系统采用 B/S 架构。

![[attachments/202406杭州_14_花房监测系统图.jpg]]

（1）图中 A 处的设备为（单选）：A.光敏传感器 / B.湿度传感器 / C.IoT 模块。

（2）系统使用 GET 方式上传光照强度 135、湿度 45，URL 为 `http://192.168.0.1:8080/s?w=135&d=45`。服务器代码中：

- A.`@app.route("/")`

- D.`app.run(host="192.168.0.1:8080")`

（3）系统正常工作一段时间后，页面中湿度数值异常而光照强度等正常（服务器和网络无故障），写出两个可能原因。

## 答案

**正确答案：** （1）A。
（2）① C；② F。
（3）湿度传感器故障、湿度传感器与智能终端连接异常、环境湿度长期不变等合理原因任两项。
（4）③ D、E；④ `y[i]=t`。

---

## 解析

A 处连接智能终端与外部传感器，按图为光敏传感器。URL 路径 `/s` 对应路由，服务器监听 IP 和端口应分别传给 `host`、`port`。单个传感器或其连接故障会造成单项数据异常。筛选光照强度记录可写成 `df[df.类型=='光照强度']` 或 `df[df['类型']=='光照强度']`，每个星期统计后把计数写入 `y[i]`。
