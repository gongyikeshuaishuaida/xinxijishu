# 题目 13

小帅收集某超市2023年的销售数据，分析某月销售情况并绘制柱形图。部分数据和图表如下：

![[attachments/202401湖州_13_图1.jpg]]

程序如下：

```python
import pandas as pd
import matplotlib.pyplot as plt
df=pd.read_csv("超市销售数据.csv")
df.insert(0,"月份","")
for i in ______①______:
    data=str(df.at[i,"销售日期"])
    df.at[i,"月份"]=data[4:6]
m=int(input("请输入需查询的月份:"))
if m>=10:
    month=str(m)
else:
    month="0"+str(m)
g=df[______②______]
g=g.groupby("大类名称",as_index=False)["销售金额"].sum()
g=______③______
x=g["大类名称"]
y=______④______
plt.bar(x,y)
```

（1）为提取“销售日期”中月份数据，①处应填（单选，填字母：A.`df.index` / B.`df.values` / C.`df.columns`）。

（2）补全②、④处代码。

（3）③处实现按“销售金额”降序排列后取前10项，下列代码中能正确实现的有（多选）：

- A. `g.sort_values("销售金额",ascending=False).tail(10)`
- B. `g.sort_values("销售金额",ascending=False).head(10)`
- C. `g.sort_values("销售金额",ascending=True)[:11]`
- D. `g.sort_values("销售金额",ascending=False)[:10]`

---

## 答案

**正确答案：** （1）A；（2）② `df["月份"]==month`；④ `g["销售金额"]`；（3）B、D

---

## 解析

（1）需要逐行读取“销售日期”并写回“月份”列，遍历DataFrame行标签应使用 `df.index`。

（2）筛选月份列等于输入月份字符串的记录，条件为 `df["月份"]==month`；柱形图纵轴应取分组结果中的销售金额列 `g["销售金额"]`。

（3）按降序排序后取前10行可用 `head(10)` 或切片 `[:10]`，所以B、D正确；`tail(10)`取到的是末尾低值，升序切片也不是降序前10。
