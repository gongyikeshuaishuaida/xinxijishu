# 题目 14

14.某地区居民水费采用阶梯水价制度。

![[attachments/202406-绍兴-高一-期末-14_横排1_2.png]]

（1）当用水量 v 超过 300 吨时，水费模型中相应表达式为 ______①______。

（2）根据阶梯价格表计算水费，适合采用 ______②______（A.顺序结构 / B.分支结构 / C.循环结构）。

（3）以下代码中能正确实现阶梯水费计算的是 ______③______（多选，填字母）。

- A. 使用 if / elif / else 按 v<180、v<300、否则分段
- B. 两个独立 if 后接 else
- C. 三个互斥 if 分别判断 v<180、180<=v<300、v>=300
- D. 用 v>=180 or v<300 作为第二阶梯条件

（4）不管输入多少用水量，输出都显示字母 f，原因是 ______④______（A.输入语句错误 / B.价格设置错误 / C.print 参数填写错误）。

---

## 答案

**正确答案：** ①180×2.97+120×3.78+(v-300)×6.21；②B；③AC；④C

---

## 解析

第三阶梯应累计前两档的 180 和 120 吨，再按第三档单价计算超出部分，表达式为 180×2.97+120×3.78+(v-300)×6.21。分支结构适合按区间判断，A 和 C 的条件互斥且覆盖完整区间；print 中把 f 写在引号内只是输出字面量，原因是 C。
