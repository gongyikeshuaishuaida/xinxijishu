# 题目 14

某早餐店老板收集了 2 月份顾客购买早餐的数据，存储在 breakfast.xlsx 文件中，部分界面如下图。

![[attachments/202403精诚联盟_14_早餐数据.jpg]]

（1）在对数据进行处理的过程中，下列说法正确的有 ______①______（多选，填字母）。

- A. 第 2 行数据存在数据缺失问题，可以通过忽略缺失值对其进行简单的处理
- B. 第 3 行的下单时间数据存在逻辑错误
- C. 第 4 行和第 5 行两行数据重复，可以直接删除其中一行
- D. 只能通过 Python 语言编程，才能进行数据分析与挖掘

（2）将数据整理后，老板想统计 2 月某一类别商品在各时段（下单时间第 1～10 位为日期，第 12～16 位为时间，时间中小时数相同的为同一时段）的订单数量。Python 程序如下，请在划线处填入合适的代码。

```python
import pandas as pd
import matplotlib.pyplot as plt
df = pd.read_excel("breakfast.xlsx")
time = []
food = input('请输入想要查询的商品类别：')
df = ______②______
for i in df.index:
    time.append(______③______)
df['下单时段'] = time
df1 = df.groupby('下单时段', as_index=False)['订单编号'].count()
df1 = df1.rename(columns={'订单编号': '订单数量'})
```

（3）若老板需了解该类别的商品订单数量最多的前三个时段，并对处理后的数据进行可视化操作，效果如下图所示。请回答并填空。

![[attachments/202403精诚联盟_14_柱形图.jpg]]

①方框所示的代码可填入的有 ______④______（多选，填字母）。

- A. `df1.sort_values('订单数量', ascending=False).head(3)`
- B. `df1.sort_values('订单数量', ascending=False)[0:3]`
- C. `df1.sort_values('订单数量').tail(3)`
- D. `df1.sort_values('订单数量')[-1:-4:-1]`

②请在 `plt.bar` 的划线处填入合适的代码。

```python
df2 = ______④______
plt.bar(______⑤______)
plt.title(food + '订单数量最多的前三个时段')
```

## 答案

**正确答案：** ① AB；② `df[df['商品类别'] == food]`；③ `df.at[i, '下单时间'][11:13]`（或等价写法）；④ ABD；⑤ `df2.下单时段, df2.订单数量`（或相应列索引表达式）

## 解析

第 2 行有缺失值可以先忽略；第 3 行日期为 2 月 31 日，属于逻辑错误；第 4、5 行虽然看似相同但订单编号等字段仍需结合业务确认，不能直接删除；数据分析也可以使用表格软件等工具。先按商品类别筛选，再从下单时间字符串中截取小时；取订单数前三名可以用降序头部、升序尾部或倒序切片，柱形图横轴为时段、纵轴为订单数量。
