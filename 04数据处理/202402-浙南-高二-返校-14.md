# 题目 14

某校高一学生的社团报名数据存储在 `stbm.xlsx` 文件中。

![[attachments/202402-浙南-高二-返校-14_横排1_2.png]]

（1）统计各社团报名人数，找出报名人数最多的三个社团并创建图表。部分程序如下，请在划线处填入合适代码。

```python
import pandas as pd
import matplotlib.pyplot as plt
df = pd.read_excel("stbm.xlsx")
df1 = df.groupby("______①______", as_index=False).count()
# 删除 df1 的“班级”列，并将列标题“姓名”重命名为“人数”，代码略
df2 = df1.sort_values("人数", ascending=False)
df3 = df2.______②______
plt.bar(df3.社团, ______③______)
plt.title("报名人数最多的前三个社团")
plt.show()
```

（2）受场地限制，每个社团开展活动人数上限为 45 人。超过 45 人的社团分成若干班级，每班人数按一定规则分配。部分程序如下，请在划线处填入合适代码。

```python
for i in stdic:
    if stdic[i] > 45:
        n = (stdic[i] - 1) // 45 + 1
        num = []; x = stdic[i] // n
        for j in range(n):
            if j == n - 1:
                num.append(______)
            else:
                num.append(x)
        stdic[i] = num
print(stdic)
```

（3）若“动漫社”实际报名人数为 98 人，利用上述程序段进行分班后得到的结果为（单选，填字母）

A．“动漫社”：[32, 33, 33]

B．“动漫社”：[32, 32, 34]

## 答案

**正确答案：** （1）① `社团`；② `head(3)`；③ `df3.人数`；（2）`stdic[i]-(n-1)*x`（或 `x+stdic[i]%n`）；（3）B。

## 解析

按“社团”分组并计数，人数降序后取前三行，柱形图纵轴使用 `人数`。98 人需要 3 个班，`x=98//3=32`，最后一个班补足为 `98-32×2=34`，所以选 B。
