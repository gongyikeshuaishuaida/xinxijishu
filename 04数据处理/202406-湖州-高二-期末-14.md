# 题目 14

14.某小学搭建智慧跳绳测试系统。监测终端内置传感器和 IoT 模块，学生跳绳数据经监测终端传输至服务器，用户通过浏览器查询成绩。

![[attachments/202406湖州_14_智慧跳绳框架图.jpg]]
![[attachments/202406-湖州-高二-期末-14_横排2_3.png]]

（1）下列功能需要在监测终端程序中实现的是 ______①______（多选，填字母）：

- A.采集传感器上的数据
- B.处理浏览器访问请求
- C.与无线 WiFi 建立连接
- D.直接向数据库写入数据

（2）编号为 1 的监测终端采集到数据值 150，提交数据到 Web 服务器的 URL 为 http:// ______②______。

（3）根据男生每分钟 109 个、女生每分钟 117 个的达标条件，补充程序：

~~~python
import pandas as pd

data=[]
for i in df.index:
    if df.at[i,"性别"]=="男" and df.at[i,"数量"]>=109:
        data.append(1)
    elif df.at[i,"性别"]=="女" and df.at[i,"数量"]>=117:
        data.append(1)
    else:
        data.append(0)
df["达标"]=data
df1=df.groupby("班级", as_index=False)["达标"].______③______
t=[41,42,42,42,42,42,43]
df1.insert(2,"达标率%",0)
for i in range(len(df1)):
    df1.at[i,"达标率%"]=round(______④______,2)
~~~

（4）从达标率中选出前三个班级，方框处应填入的正确代码为 ______⑤______（多选，填字母）：

- A.df2=df1.sort_values("达标率%", ascending=False).head(3)
- B.df2=df1.sort_values("达标率%", ascending=True).tail(3)
- C.df2=df1.sort_values("达标率%", ascending=True)[0:3]
- D.df2=df1.sort_values("达标率%", ascending=False)[0:3]

---

## 答案

**正确答案：** ①AC；②192.168.1.100:8080/input?id=1&num=150；③sum()；④df1.at[i,"达标"]/t[i]*100；⑤AD

---

## 解析

监测终端负责采集传感器数据并建立无线连接，浏览器请求和数据库写入由服务器端处理。URL 由服务器地址、端口和子页面路径及参数组成。按班级对“达标”列求和，再除以各班总人数并乘 100 得达标率。降序取前三项或升序取最后三项都得到前三名，因此选择 A、D。
