# 题目 12

12.某校师生对校园十件新闻投票，选出投票数最高的 3 件新闻。每位师生投票项不能超过 5 项，超过 5 项作为废票；表中“1”表示投了该新闻，“0”表示没有投该新闻。

（1）根据投票数据表，投票人序号 ______①______ 的投票数据无效，应作为废票。

（2）主程序选出投票数最高的 `n` 件新闻，请完善代码：

```python
for r in tpdata:
    if check(r):
        tjtp(r)
for i in range(n):
    p = ______②______
    flag[p] = True
    rst.append(xws[p])
```

（3）判断一条投票数据是否有效：

```python
def check(tp):
    t = 0
    for i in range(1, m + 1):
        if tp[i] == '1':
            ______③______
    if t > 5:
        return False
    return True
```

（4）在 `count` 中找到尚未选出且票数最大的新闻索引：

```python
def getmax():
    maxtp = 0
    for i in range(m):
        if ______④______ and count[i] > maxtp:
            maxtp = count[i]
            maxp = i
    return maxp
```

## 答案

**正确答案：** ①20241293；②`getmax()`；③`t += 1`；④`flag[i] == False`

---

## 解析

投票人 20241293 在新闻 2、3、5、6、9、10 上均投了“1”，共 6 项，超过 5 项所以无效。每轮从未选出的新闻中取得票数最大索引；统计投票项时每遇到一个“1”就累加一次；`flag` 用于跳过已经选出的新闻。
