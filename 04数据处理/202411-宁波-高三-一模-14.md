# 题目 14

小明收集了 12 月份的部分热门电影数据，并将其存储在 movies.xlsx 文件中，部分数据如下图所示。

![[attachments/202411宁波_14_电影数据表.png]]

（1）观察图中“上映日期”列数据，存在的问题是 ______①______（单选，填字母）。

- A. 数据缺失
- B. 数据重复
- C. 逻辑错误
- D. 格式不一致

（2）小明想要输出类型为“剧情”且时长小于 120 分钟的数据记录。部分 Python 程序如下，请在划线处填入合适的代码。

~~~python
import pandas as pd
df = pd.read_excel("movies.xlsx")
df = df[df['类型'] == '剧情']
df = ______②______
print(df)
~~~

（3）小明想要统计每种类型的电影数量，按降序排序以后，绘制电影类型排行榜的柱形图（如下图所示）。部分 Python 程序如下，请在程序中划线处填入合适的代码。

![[attachments/202411宁波_14_柱形图.png]]

~~~python
import matplotlib.pyplot as plt
df3 = df.groupby(______③______, as_index=False).count()
df3 = df3.drop(['上映日期', '主演', '时长'], axis=1)  # 删除列
df3 = df3.rename(columns={'电影名称':'数量'})  # “电影名称”列重命名为“数量”
df3 = df3.sort_values('数量', ascending=______④______)
plt.title('电影类型排行榜')
plt.xlabel('类型')
plt.ylabel('数量')
______⑤______
plt.legend()
plt.show()
~~~

（4）上述程序方框中应填入的正确代码为（   ）（单选，填字母）。

- A. plt.bar(df3.index, df3.数量)
- B. plt.bar(df3.类型, df3.数量)
- C. plt.bar(df3.index, df3.数量, label='数量')
- D. plt.bar(df3.类型, df3.数量, label='数量')

---

## 答案

（1）① D

（2）② df[df['时长']<120]

（3）③ 类型　④ False

（4）⑤ D

---

## 解析

“12/19”与其他“12月××日”记录的日期格式不一致，故选 D。先筛选类型为“剧情”，再用布尔索引保留时长小于 120 的记录。按“类型”分组计数并以降序排列时 ascending=False；横坐标应使用类型列，图例“数量”由 label='数量' 产生，故柱形图代码选 D。
