# 题目 14

14.小红收集某高中期中考试成绩并计算位次。规则为：总分高者优先；总分相同则语数总分（语文+数学）高者优先；前两项都相同则比较语文、数学中的单科较高成绩。数据表如下：

![[attachments/202405-北斗联盟-高二-期中-14_横排1_2.png]]

（1）在 `read_data` 函数中增加“语数总分”列，并按“总分”降序、“语数总分”降序排序：

```python
def read_data(datafile):
    df = pd.read_excel(datafile)
    df["语数总分"] = ______①______
    df = df.sort_values(["总分", "语数总分"], ______②______, ignore_index=True)
    return df
```

（2）主程序中，若当前学生与下一学生总分相同，则继续按语数总分分组；请补全两处代码：

```python
while i <= len(df1)-2:
    if ______①______:
        df1.at[i,"名次"] = i+1; i = i+1
    else:
        ...
        sort1(i,j-1,df1)
        ______②______
```

---

## 答案

**正确答案：** （1）① `df["语文"]+df["数学"]`；② `ascending=False`；（2）① `df1.at[i,"总分"]!=df1.at[i+1,"总分"]`；② `i=j`

---

## 解析

先计算语数总分，再按两个关键字降序排序。遍历时总分不同可直接确定当前位次；同总分时找出语数总分相同的连续区间交给 `sort1` 处理，处理后令 `i=j` 跳到下一组。
