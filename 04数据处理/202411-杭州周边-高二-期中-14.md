# 题目 14

14. 某学校高二段学生的图书借阅记录保存在“jieyue.xlsx”文件中，部分数据如第14题图a所示。现要统计出某月图书借阅量最高的5个班级，并绘制如第14题图b所示的柱形图。

![[attachments/202411-杭州周边-高二-期中-14_横排1_2.png]]

```python
import pandas as pd

df = pd.read_excel("jieyue.xlsx")
```

（1）在划线处填上合适的代码。

（2）程序的方框中应填入的正确代码为（多选，填字母）。

- B. `df1.head(5)`

---

## 答案

**参考答案：**

- ① `date[5:7]`（或等价写法）
- ② `df["月份"] == month`
- ③ `班级`
- ④ `df1.借阅书籍` 或 `df1["借阅书籍"]`
- ⑤ `df1.head(5)` 或 `df1[:5]`
- （2）BC

---

## 解析

日期字符串采用“年-月-日”格式，`date[5:7]` 取出两位月份。用布尔条件筛选输入月份，再按“班级”分组统计借阅书籍数量并降序排列；排序后前5行就是数量最高的班级，因此 `head(5)` 和 `[:5]` 都正确。柱形图的纵坐标使用统计后的“借阅书籍”列。
