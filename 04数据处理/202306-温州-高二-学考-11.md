# 题目 11

一次考试共12题，1—10题为单选题，11—12题为非选择题。阅卷系统将每道小题得分导出到 `xxcj.xlsx`，部分数据和第10题各班级均分图如下：

![[attachments/202306-温州-高二-学考-11_横排1_2.png]]

（1）读取Excel文件中的数据赋值给 `df`，补全代码（单选，填字母）。

```python
import pandas as pd
df = pd.______①______("xxcj.xlsx")
```

- A. `read_excel`
- B. `to_excel`
- C. `read.excel`
- D. `read_xlsx`

（2）分析某小题的每个班级均分情况，补全代码。

```python
df1 = df.groupby("班级").______②______
df1 = df1.drop('考号', axis=1)
```

（3）输入 `10` 生成图中折线图，补正绘图代码。

```python
tno = input("请输入题号：")
plt.plot(______③______, df1[tno], label="各班级均分")
```

（4）从图中可以看出，第10题超过年级均分的班级个数为 ______④______。

---

## 答案

**正确答案：** （1）A；（2）`mean()`；（3）`df1.index`；（4）7

---

## 解析

（1）`pandas.read_excel()`用于从Excel文件读取数据，`to_excel()`用于写出数据，故选A。

（2）按“班级”分组后求各列平均值，应使用 `mean()`。

（3）分组后的班级名称保存在分组结果的索引中，横坐标应使用 `df1.index`。

（4）逐一比较折线与年级均分水平线，02、03、04、07、10、12、13班在水平线上方，共7个班级。
