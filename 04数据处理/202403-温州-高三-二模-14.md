# 题目 14

小温对 5 个景区进行网络问卷调查，问卷中的“环境”“硬件”“服务”“交通”选项及分值一致，导出数据如图 b。数字 `i` 表示问卷中的第 `i` 个选项。

![[attachments/202403温州_14_问卷数据.jpg]]

（1）各项分值为 `qz=[2.5,2,1.5,1,0.5]`。若要统计每份问卷对应景区的评分，下列代码正确的是（   ）

- A. `df["评分"] = qz[df["环境"]] + qz[df["硬件"]] + qz[df["服务"]] + qz[df["交通"]]`
- B. `df["评分"] = df[["环境","硬件","服务","交通"]].sum(axis=1)`
- C. 逐行取四项选项编号，并用 `qz[a-1]` 等索引转换为分值后相加写入“评分”列

（2）找出 18—39 岁年龄段游客评分均值最高的景区，请填空：

```python
jq = ["雁荡山", "楠溪江", "渔寮", "南麂列岛", "氡泉"]
df1 = df[______①______]
df2 = df1.groupby("景区", as_index=False)["评分"].mean()
df2 = df2.sort_values(______②______, ascending=False)
print(jq[df2["景区"][0] - 1])
```

（3）根据 `df2` 中评分数据绘制如图 c 所示的垂直柱形图。图中横轴为景区名称，纵轴为各景区评分与均值的差值。

![[attachments/202403温州_14_均差柱形图.jpg]]

请选择加框处代码：

- A. `x=jq; y=df2["评分"]`
- B. `x=df2["景区"]; y=df2["均差"]`
- C. `x=jq1; y=df2["均差"]`
- D. `x=df2.index; y=df2["评分"]`

## 答案

**正确答案：** （1）C；（2）① `df["年龄"] == 2`；② `评分`；（3）C。

## 解析

问卷选项是编号，必须先用 `qz` 数组转换成分值再求和。筛选年龄列为 2（18—39 岁），按景区分组求平均，再按评分降序排序。绘图时 `jq1` 保存景区名称，纵轴使用每个景区的 `均差`。
