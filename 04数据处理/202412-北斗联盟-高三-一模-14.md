# 题目 14

在第 13 题智能环境监测系统中，增加特定环境的温度监测功能，每小时采集一次温度数据。数据格式记为 `[tm,tp]`，其中 `tm`、`tp` 分别为时刻与温度，`tm` 的数据范围为 0～23，`tp` 的数据范围为 5～45。例如 `[12,36]` 表示 12 点时检测到的温度为 36℃。

编写程序，获取当前时刻温度，参照预警标准，进行启动预警；若温度达到更高一级标准或同等级则进行更新预警。预警示例如下：

![[attachments/202412北斗联盟_14_预警示例.png]]

各级预警标准如下：

- I 级预警：24 小时内当气温升至 40℃及以上；
- II 级预警：24 小时内当气温升至 37℃及以上；
- III 级预警：24 小时内当气温升至 35℃及以上。

请回答下列问题：

（1）第 14 题图中预警的各时刻数据如下：`[2,35]`、`[5,41]`、`[5,x]`、`[6,40]`、`[3,29]`、`[10,41]`，则 `x` 的值可能是 `______①______`（单选，填字母）。

- A. 30
- B. 36
- C. 38
- D. 41

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
limit = [40,37,35]
pre = -1                 # 存储前一次预警的数据，初始化状态为 -1
while True:
    # 采集一次数据，存入列表 d，d[0] 存储时刻，d[1] 存储温度，代码略
    if d[0] == 0:        # 每日 0 时初始化
        ______②______
    for i in range(3):
        if d[1] >= limit[i]:
            if ______③______:
                if pre == -1:
                    # 启动预警信息，代码略
                else:
                    # 更新预警信息，代码略
                pre = d[1]
            elif i>0 and pre<limit[i-1] or i==0:  # 同级别时
                # 更新预警信息，代码略
                ______④______
            break
    # 延时 1 小时，代码略
```

## 答案

**正确答案：**

- （1）B（36）
- （2）② `pre=-1`；③ `pre<limit[i]`；④ `pre=d[1]`

## 解析

预警记录按日期和时刻排列：25 日 2 时温度 35℃启动 III 级预警，25 日 5 时 41℃更新为 I 级；26 日 5 时应启动 III 级预警，因此 `x` 应达到 35℃但低于 37℃，选 B 的 36℃。每日 0 时应清除上一日的预警状态，所以第一个空填 `pre=-1`。当当前温度达到第 `i` 级标准且上一次记录尚未达到该级标准时启动或更新预警，条件为 `pre<limit[i]`；同等级更新后将 `pre` 设为当前温度，填 `pre=d[1]`。
