# 题目 14

小张为叔叔的鲫鱼养殖鱼塘搭建了水体溶解氧含量监测系统。该系统的智能终端获取传感器数据，通过无线通信方式将数据传输到 Web 服务器，服务器将水体溶解氧含量传感器采集的数据存储到数据库，并与阈值进行判断后通过智能终端控制氧气泵。用户通过浏览器查询实时和历史数据。

（1）用户通过浏览器查询数据时，访问了该系统的 ______①______（单选，填字母：A. 智能终端 / B. 数据库 / C. 氧气泵控制程序）。

（2）下列关于该系统中服务器和客户端的说法，正确的是 ______②______（单选，填字母）。

- A. 搭建该系统需要编写服务器和客户端程序
- B. 数据在服务器与客户端之间双向传输
- C. 不能在服务器端访问该系统

（3）小张发现数据库中近期存在大量连续低于阈值下限值的水体溶解氧含量数据记录，不利于鲫鱼生存，可能的原因是 ______③______（多选，填字母）。

- A. 氧气泵制氧能力不足
- B. 客户端数据处理异常
- C. 智能终端与服务器通信中断
- D. 水体溶解氧含量传感器故障

（4）请写出两种可提升鱼塘水体溶解氧含量检测精准性的方法。

## 答案

**正确答案：** ①B；②B；③AD；（4）选择精度高的溶解氧传感器、增加监测点、提高检测频率、合理放置传感器位置等合理方法；⑤ `dfg = dfg.groupby("日期", as_index=False)["氧含量"].count()` 前的方框整体填入顺序为 ⑦ `BADEC`、`BAEDC` 或 `BAECD`；⑥ `dfg["日期"], dfg["氧含量"]`

## 解析

用户通过浏览器查询的是服务器存储的数据，因此访问数据库，①选 B。该系统采用 B/S 架构，数据既要由客户端传到服务器，也要由服务器返回处理或控制结果，②选 B。数据库中仍有连续低值记录，说明数据能够传到服务器，可能原因是氧气泵制氧能力不足或传感器故障，③选 AD。提高传感器精度、增加监测点、提高采样频率和合理选择安装位置都能提升检测精准性。

数据处理的顺序首先筛选氧含量低于 5 的记录（B），再按日期分组计数（A），然后筛选异常次数大于 2（D），按异常次数降序排序（E），最后取前 3 条（C）。因此 `BADEC` 正确；将 D、E、C 调整为 `BAEDC` 或 `BAECD` 也符合依赖关系。柱形图横轴为日期、纵轴为异常次数，所以 `plt.bar` 的参数为 `dfg["日期"], dfg["氧含量"]`。
