# 题目 10

阅读智能垃圾站材料，回答第10题。用Python进行图像二值化处理的核心代码如下：

```python
img = np.array(Image.open("lianlian.jpg").convert("L"))
rows, cols = img.shape
for i in range(rows):
    for j in range(cols):
        if img[i, j] > 190:
            img[i, j] = 1 # 1代表将该像素点设置为白色
        else:
            img[i, j] = 0 # 0代表将该像素点设置为黑色
```

图1为原始图片，图2为以上代码运行的结果；改变加框处条件后，以下说法正确的是（   ）

![[attachments/202306-温州-高二-学考-10_横排1_2_3_4.png]]

- A. 改为 `img[i, j] < 100`，生成图3
- B. 改为 `img[i, j] > 250`，生成图4
- C. 改为 `img[i, j] < 190`，生成图3
- D. 改为 `img[i, j] < 100`，生成图4

---

## 答案

**正确答案：** C

---

## 解析

原程序把灰度值大于190的像素设为白色，其余设为黑色。将条件改为 `<190` 后，黑白判定区域互换，结果对应图3。阈值改为 `<100`或`>250`还会改变参与转换的灰度范围，不能得到题目所示图4，因此选C。
