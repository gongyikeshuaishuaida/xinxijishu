# 题目 14

小王正在设计一个智能花园管理系统，旨在优化植物生长条件并提供友好的用户界面来监控和管理花园。他在实验室搭建了一个模拟系统，该系统能够监测花园中的土壤湿度和光照强度，并在出现异常（如土壤过干或过湿、光照过强或过弱）时发出警报及自动控制，用户可以通过浏览器查看光照、湿度的实时监测结果和历史数据。系统包括土壤湿度传感器、光照强度传感器、智能终端、执行器（如水泵和遮阳篷）以及一台 Web 服务器。

（1）该模拟系统中，一个智能终端 ______（单选，填字母：A．只能连接一个传感器 / B．可以连接多个传感器）。

（2）通过网页查看历史数据，发现查询到的所有数据都是一周前的，以下故障与该现象有关的是 ______（单选，填字母）。

- A. Web 服务器上搭建的网站停止运行
- B. 某个湿度传感器故障
- C. 智能终端连接的路由器故障

（3）下列关于该系统设计的说法，正确的有 ______（多选，填字母）。

- A. 传感器可以使用无线的方式将数据传到智能终端
- B. 为服务器设置动态 IP 地址
- C. 该模拟系统需要编写客户端程序
- D. 控制执行器的指令可以由服务器发出，也可以由智能终端发出

（4）不同种类的花卉需要的土壤湿度是不一样的。为使系统能控制不同的湿度，请写出一种可行的解决方法。

（5）小明将该系统 2024 年的湿度数据导出，部分数据如图 1 所示，现统计各传感器总浇水次数，并将其可视化，如图 2 所示。部分程序如下，请在划线处填入合适代码。

y = []
for x in sensors:
    df1 = ______①______
    df1 = df1[df1.是否浇水 == 'Yes']

## 答案

**参考答案：**

- （1）B
- （2）C
- （3）AD
- （4）为不同种类的花卉分别安装传感器并设置不同的阈值（或其他合理方案）
- （5）① `df[df.传感器编号==x]`；② `sensors,y`

## 解析

一个智能终端可以连接多个传感器。所有历史数据都滞后一周，说明实时数据上传链路可能中断，智能终端连接的路由器故障与此现象有关。传感器可无线连接智能终端，控制指令也可以由服务器或智能终端发出；服务器一般应配置固定 IP，模拟系统不一定需要专门编写客户端程序。对不同花卉设置不同传感器或阈值即可实现差异化控制。代码先按传感器编号筛选，再保留“是否浇水”为 `Yes` 的记录，`plt.bar` 使用 `sensors` 作为横坐标、`y` 作为纵坐标。
