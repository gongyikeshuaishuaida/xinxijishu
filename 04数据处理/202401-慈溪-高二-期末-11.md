# 题目 11

某公司7月销售数据存放在 `sell.xlsx` 中。现在要筛选货主“谢小姐”的订单，按产品名称统计订单总价并绘制柱形图，数据和图表如下：

![[attachments/202401-慈溪-高二-期末-11_横排1_2.png]]

（1）筛选货主数据，补全代码（单选，填字母）。

- A. `df["货主"]=="谢小姐"`
- B. `df[df.货主=="谢小姐"]`
- C. `df[df["货主"]]=="谢小姐"`

```python
df1 = ______①______
```

（2）补全按产品分组和按总价降序排序的代码。

```python
df2 = df1.groupby("产品名称", as_index=False).______②______
df3 = df2.sort_values("总价", ______③______)
```

---

## 答案

**正确答案：** （1）B；（2）② `sum()`；③ `ascending=False`

---

## 解析

（1）`df[df.货主=="谢小姐"]`先生成布尔筛选条件，再从DataFrame中选出符合条件的行，故选B。

（2）同一产品可能有多条订单，需要按“产品名称”分组并对“总价”求和，填 `sum()`；柱形图按总价从高到低排列，`sort_values`的参数应为 `ascending=False`。
