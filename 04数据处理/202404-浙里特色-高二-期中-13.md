# 题目 13

13.小明收集了上周信息技术学科考试成绩的数据，如图 a 所示。

![[attachments/202404浙里特色_13_成绩数据表.jpg]]

（1）观察上表，小明做了如下操作，其中属于数据整理的是（多选，填字母）：

A.删除重复行第5行　B.验证并修改 D2 单元格数据　C.通过公式计算全班平均分　D.重新设置 C3 单元格格式

（2）为了分析每个班级每小题的平均分，程序中 `df1=` 处应填（单选，填字母）：

A.`df.groupby("平均分").mean()`　B.`df.mean()`　C.`df.groupby("班级").mean()`　D.`df["班级"].mean()`

（3）利用 Python 绘制各班各小题得分率图表，程序中划线①和②处应填入合适代码。

![[attachments/202404浙里特色_13_得分率图.jpg]]

```python
bj = input("请输入班级：")
plt.figure(figsize=(10, 5))
list = []
for i in range(12):
    s = "xx" + str(i + 1)
    list.append(df1.at[bj, s] / 2 * 100)
plt.bar(range(1, 13), ______①______)  # 绘制垂直柱形图
plt.title(bj + "各小题得分率")
plt.______②______("题号")
plt.ylabel("得分率")

```

---

## 答案

**正确答案：** （1）ABD；（2）C；（3）① `list`；② `xlabel`

---

## 解析

删除重复记录、纠正单元格数据和重新设置格式都属于数据整理；按班级分组并求均值应使用 `groupby("班级").mean()`；柱形图的高度序列为 `list`，横坐标名称用 `plt.xlabel("题号")`。
