# 题目 14

王老师对某次全国竞赛获奖数据进行分析，数据如下图。

![[attachments/202407金华十校_14_获奖数据表.jpg]]

（1）统计各省份高二年级 200 分以上（含 200 分）同学的平均成绩，可行操作是（单选）：
- A. 先筛选高二年级记录，再按省份分组计算总分平均分，最后筛选大于等于 200 分的记录
- B. 先筛选大于等于 200 分的记录，再按省份分组计算总分平均分，最后筛选高二年级记录
- C. 先筛选大于等于 200 分的记录，再筛选高二年级记录，最后按省份分组计算总分平均分

（2）若要统计获奖人数超过 50 人的省份总分平均分并制作柱状图，请补全代码。图示如下：

![[attachments/202407金华十校_14_省份平均分柱状图.jpg]]

```python
df1 = df.sort_values("省份")
name = []
ave = []
t, c = "", 0
for i in df1.index:
    if df1.at[i, "省份"] == ______①______:
        cnt += df1.at[i, "总分"]
        c += 1
    else:
        if c >= 50:
            name.append(t)
            ave.append(round(cnt / c, 2))

        cnt = df1.at[i, "总分"]
        ______②______
if c >= 50:
    name.append(t)
    ave.append(round(cnt / c, 2))
plt.bar(______③______, ave)
plt.title("获奖人数超过50人的省份平均分")
plt.show()
```

---

## 答案

**正确答案：** （1）C；（2）① t；② c = 1；③ name。

---

## 解析

筛选条件应先作用于原始记录，再分组求平均，因此顺序为先总分、再年级、最后省份分组。分组循环中用 t 保存当前省份，c 统计当前组人数；切换到新省份后重新令 c=1，柱状图横坐标使用省份名称列表 name。
