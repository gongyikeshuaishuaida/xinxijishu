# 题目 14

14.浙江某地3月共享单车骑行数据存于 `bike.xlsx`。需要把时间转换为分钟、过滤2分钟内无效数据、统计收益和各类型骑行次数。

![[attachments/202405-五校联盟-高三-三模-14_横排1_2.png]]

（1）`trans(t)` 读取“2024/03/01 21:12”中的小时和分钟，将其转换为分钟：

```python
def trans(t):
    n = len(t)
    for i in range(n):
        if t[i] == ' ':
            p = i
        if t[i] == ':':
            q = i
    time = ______
    return time
```

（2）统计收益并过滤骑行时间小于2分钟的记录。补全收益累加语句，并选择过滤代码：

- 收益累加：`dic[______] += fee`
- A.`df[df.fee==0]`
- B.`df = df.时长 > 0`
- C.`df[df['骑行时长']>=2]`
- D.`df.drop(df.骑行时长<2)`

（3）按单车类型统计骑行次数并降序排序：

```python
df1 = df.groupby('单车类型', as_index=False).骑行时长.______①______
df2 = df1.sort_values('______②______', ascending=False)
plt.bar(df2.单车类型, df2.骑行时长)
```

---

## 答案

**正确答案：** （1）`int(t[p+1:q])*60+int(t[q+1:])`；（2）`dic[df.at[i,"单车类型"]]`；C；（3）①`count()`；②`骑行时长`

---

## 解析

先定位日期后的空格和时刻中的冒号，再分别截取小时、分钟并换算。收益按单车类型累加；骑行时间小于2分钟的记录过滤掉，保留 `>=2` 的数据。分组后用 `count()` 统计次数，按骑行时长列降序排序。
