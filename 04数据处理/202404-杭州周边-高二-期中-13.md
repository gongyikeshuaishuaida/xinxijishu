# 题目 13

13.小华采集了 2024 年 2 月份全国主要城市空气质量数据，部分数据如图 a 所示。

![[attachments/202404杭州周边_13_AQI数据表.jpg]]

（1）图 a 中第 6 行和第 7 行是同一城市、同一站点的两条记录，应执行（单选，填字母）：

- A. 删除第 6 行数据
- B. 删除第 7 行数据
- C. 删除 6、7 两行数据
- D. 合并 6、7 两行的数据

（2）输入省名或市名，计算 AQI 平均值并绘图。程序中 ①②处为：

```python
def sx(name):
    id = -1
    if name in df.省.values:
        id = id + 1
    elif name in df.市.values:
        id = ______①______
    return id

sq = ["省", "市", "站点"]
idx = sx(s)
dfs = df[df[sq[idx]] == s]
dfs = dfs.groupby(______②______, as_index=True).mean()
```

（3）加框处应填入的正确代码为（单选，填字母）：

- A. `dfs.index, dfs.AQI`
- B. `df.index, df.AQI`
- C. `dfs.sq[idx+1], dfs.AQI`
- D. `df.sq[idx+1], df.AQI`

![[attachments/202404-杭州周边-高二-期中-13_横排2_3.png]]

（4）由图 b 可知，2024 年 2 月浙江省空气质量最好的是温州市。

---

## 答案

**正确答案：** （1）D；（2）① `1`（或 `id+2`、`abs(id)`）；② `sq[idx+1]`；（3）A；（4）温州市

---

## 解析

第 6、7 行的主键字段相同而数据可合并，故（1）D；省对应 `sq[0]`，市对应 `sq[1]`，所以 ①可填 `1`，分组列为 `sq[idx+1]`；绘图应使用筛选后的 `dfs` 的索引和 AQI 列，故（3）A；图 b 中温州市柱形值最低，空气质量最好。
