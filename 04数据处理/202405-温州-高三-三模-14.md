# 题目 14

14.学校植物实验室的环境光线监测系统由光线传感器、智能终端、IoT 模块和 Web 服务器组成；服务器统计每日白天（8～16点）平均光照强度，光照不足时向智能终端发送打开补光灯命令。

![[attachments/202405-温州-高三-三模-14_横排1_2.png]]

（1）该系统平台架构的优势是（填字母）：A.降低服务器负荷 / B.方便系统升级和维护 / C.降低通信开销和开发难度。

（2）关于服务器、智能终端、客户端，正确的是（多选）：

- A.浏览器获取数据来源于本地客户端
- B.服务器可以处理浏览器的请求
- C.智能终端可以通过 IoT 模块以无线方式连接服务器
- D.服务器可以对执行器直接发送指令

（3）Flask 服务端路由为 `/input`，主机 `192.18.108.173`、端口 `8080`，参数名为 `id` 和 `lig`。光线传感器编号2、光线值930时，提交数据的 URL 是（填字母）：

- A.`http://192.18.108.173:8080/data?id=2&lig=930`
- B.`http://192.18.108.173:8080/input?senorlog=2&light=930`
- C.`http://192.18.108.173:8080/input?id=2&lig=930`
- D.`http://192.18.108.173:8080/data?sensorlog=2&light=930`

（4）IoT 模块损坏后，描述系统可能出现的两种异常情况。

（5）读取 `data.csv`，按日期提取月份并统计每月补光灯正常工作的天数，补全：

```python
df = pd.read_csv('data.csv')
df['月份'] = ''
for i in df.index:
    df.at[i, '月份'] = df.at[i, '日期'][5:7]
dfg = df.groupby('月份', as_index=False).______①______
```

筛选补光灯正常工作的数据，正确代码为（多选）：

- A.`df = df[df['时长'] != 0]`
- B.`df = df.时长 > 0`
- C.逐行判断 `时长==0` 并用 `df.drop(i)` 删除
- D.排序后取末尾 n 行

---

## 答案

**正确答案：** （1）B；（2）BC；（3）C；（4）如浏览器数据不再更新、数据库数据不更新、智能终端与服务器不能传输数据、服务器向补光灯发出的开/关命令不能执行等；（5）①`count()`；②AC

---

## 解析

B/S 平台便于服务器端集中升级和维护。浏览器请求由服务器处理，智能终端可通过 IoT 无线通信；服务器不能绕过智能终端直接控制执行器。URL 必须同时匹配路由和参数名。IoT 损坏会中断终端与服务器之间的数据和控制指令。按月份分组后用 `count()` 统计记录数，A、C 都能删除时长为0的记录，B 不是合法筛选结果，D 不能保证得到正常工作天数。
