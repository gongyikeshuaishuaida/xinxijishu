# 题目 12

有如下 Python 程序段：

```python
a = [3, 4, 5, 9, 8, 15, 10, 2, 7, 6]
k = 3; key = 20
msq = 0; left = 0; sum = 0
for right in range(len(a)):
    sum += a[right]
    while sum > key or right - left + 1 >= k:
        sum -= a[left]; left += 1
    if sum > msq:
        msq = sum
```

程序运行后，变量 `msq` 的值为（   ）

- A. 17
- B. 19
- C. 20
- D. 32

---

## 答案

**正确答案：** A

---

## 解析

程序用滑动窗口维护总和不超过 20 且长度小于 3 的连续子数组，并记录其中的最大和。运行过程中满足条件的最大窗口和为 17，因此 `msq` 的值为 17，选 A。
