# 题目 15

某英文字母序列 data 的加密、解密过程如下。

“加密”过程为：先将 data 加上后缀“$”（“$”比 data 中所有字符都要小）得到字符串 S0，取出 S0 首字符放至 S0 末尾得到新字符串 S1，重复上述操作，一轮结束后得到所有新字符串；对这些字符串进行升序排序后，依次取它们的末尾字符组合得到加密结果。例如对“banana”加密，结果为“annb$aa”，具体过程如第 15 题图 a 所示。

![[attachments/202411绍兴_15_加密过程图.png]]

“解密”则通过还原加密结果得到 data。例如，先将“annb$aa”还原为“banana$”，再去掉“$”得到“banana”。编写程序实现上述功能，程序中用到的列表函数与方法如第 15 题图 b 所示。

![[attachments/202411绍兴_15_列表方法表.png]]

请回答下列问题：

（1）若 data 为“ababa”，经过“加密”处理后结果为 ______①______。

（2）“加密”处理的相关函数如下：

~~~python
def compute(data):
    a=[]; b=[]
    n=len(data)
    for i in range(n):
        a.append([i,data[i:n]+data[0:i]])
    # 对 a 数组中的所有字符串升序排序，代码略
    for i in a:
        b.append(i[0])
    return b

def trans(data):
    data=data+"$"
    b=compute(data)
    n=len(b); s=""
    for i in range(n):
        ______③______
        if j<0:
            j=j+n
        s+=data[j]
    return s
~~~

其中，compute 函数中应选择数据项 ______②______（单选，填字母：A. a[i][0] / B. a[i][1]）作为排序关键字对 a 数组升序排序；trans 函数中划线处应填入合适代码。

（3）实现“解密”功能的部分 Python 程序如下，请在划线处填入合适的代码。

~~~python
def invert(tran_data):
    n=len(tran_data)
    a=[]
    for i in range(n):
        a.append(i)
    for i in range(n-1):
        for j in range(n-i-1):
            if tran_data[a[j]] > tran_data[a[j+1]]:
                a[j],a[j+1] = a[j+1],a[j]
    shift=[0]*n
    ______④______
    b=[[] for i in range(128)]    # 创建列表 b，共 128 个元素，每个元素均为空列表
    for i in range(n):
        b[ord(tran_data[i])].append(i)
    for i in range(n):
        ______⑤______
    decoded=""
    for i in range(n):
        x=shift[x]
        decoded=decoded+tran_data[x]
    return decoded
~~~

在 compute 函数中，加框处代码若修改为 [i, data[i:n]]，是否影响该函数返回结果？请说明原因。

---

## 答案

**正确答案：** （1）① abb$aa；（2）② B；③ j=b[i]-1；（3）④ x=a[0]；⑤ shift[i]=b[ord(tran_data[a[i]])].pop(0)；不影响，因为比较字符串时，$ 比 data 中所有字符都要小。

## 解析

data 为 ababa 时，补上 $ 后形成 ababa$ 的循环移位串，按字典序排序后依次取末字符，得到 abb$aa。compute 中应按字符串 data[i:n]+data[0:i] 排序，因此选择 a[i][1]，即 B。trans 中 b[i] 是排序后字符串对应的原始起始位置，取其前一个位置即可得到该行的末字符；若位置为负数，再加 n 回到字符串尾部。

解密时，a 经过排序后 a[0] 是首字符为最小字符的行，先令 x=a[0]；b 按字符记录 tran_data 中各位置，使用 pop(0) 依次建立 shift 映射，随后沿 shift 链恢复原字符串。将循环移位串改写为 [i, data[i:n]] 不会改变排序结果，因为补入的 $ 小于 data 中所有字符，包含 $ 的后缀仍然排在相应位置，返回的起始位置序列不变。
