# 题目 06

材料背景如下：临品书坊内的电子书阅读机通过网络访问区中心图书馆，书坊还提供 Wi-Fi。

下列关于该系统中网络技术的说法，正确的是

- A. 单个书坊内的多台电子书阅读机一定是通过调制解调器组成了局域网
- B. 电子书阅读机访问区中心图书馆时涉及到的通信协议必定有 TCP/IP 协议
- C. 该书坊的 Wi-Fi 设备开启了 DHCP 功能，因此读者的手机连接 Wi-Fi 就无需 IP 地址
- D. 该系统中的网络资源不包含硬件资源

---

## 答案

**正确答案：** B

---

## 解析

跨网络访问中心图书馆时通常使用 TCP/IP 协议族。调制解调器不是组建局域网的必需设备，DHCP 是自动分配 IP 地址而不是取消 IP 地址，网络资源也包括硬件资源。
