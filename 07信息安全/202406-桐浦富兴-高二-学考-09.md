# 题目 09

系统背景：小李家大棚葡萄园安装了智能滴灌系统。智能终端通过湿度传感器采集土壤湿度数据并上传到 Web 服务器，服务器将数据保存到数据库；当湿度低于或超过阈值时，智能终端控制灌水器自动调节。系统通过光猫接入互联网，小李用浏览器输入账号和密码登录，连续 3 次密码错误会锁定账号。

9. 根据系统背景，下列说法不正确的是（ ）

- A.该系统的执行器由 Web 服务器直接控制
- B.该系统的身份认证技术是用户名+口令认证技术
- C.为了提高系统的安全性，可以给该系统的使用者设置不同的权限
- D.小李通过手机访问该系统时，手机与 Web 服务器通信时，需遵循网络协议

---

## 答案

**正确答案：** A

---

## 解析

执行器应由智能终端或控制器根据阈值控制，Web 服务器负责数据服务和远程交互，不是直接驱动灌水器。其余说法分别符合口令认证、权限管理和网络通信规则。
