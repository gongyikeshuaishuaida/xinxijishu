# 题目 02

下列关于人工智能的说法，正确的是（   ）

- A. 符号主义需要在与环境的交互中不断学习
- B. 测试机器是否具有智能的方法只有图灵测试
- C. 常用的深度学习是模拟人类大脑处理数据的机制
- D. 手工构造知识库+推理引擎的“专家系统”是行为主义的典型代表

## 答案

**正确答案：** C

## 解析

深度学习以神经网络为基础，模拟人类大脑处理数据的机制，属于联结主义。符号主义强调符号推理，图灵测试不是唯一的智能测试方法，知识库加推理引擎的专家系统属于符号主义。
