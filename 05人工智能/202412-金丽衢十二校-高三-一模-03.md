# 题目 03

下列关于人工智能的说法，正确的是（   ）

- A. 强化学习需要学习者事先知道最终答案
- B. 人脸识别技术不需要事先手工构造知识库
- C. 可以通过图灵测试测试机器智能水平的高低
- D. 有人参与的人工智能一定属于混合增强智能

## 答案

**正确答案：** C

## 解析

图灵测试通过观察机器与人的交互表现来判断机器是否表现出类似人的智能。强化学习依靠与环境交互获得反馈，不要求事先给出最终答案；人脸识别仍需要数据、特征或模型等学习过程；有人参与并不必然意味着系统属于混合增强智能。
