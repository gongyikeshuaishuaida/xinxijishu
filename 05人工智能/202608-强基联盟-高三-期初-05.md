# 题目 05

阅读下列材料，回答第 05 题。

某智慧校园门禁系统采用人脸识别技术。学生在入学时录入面部信息并绑定校园卡账号。进出校门时，摄像头抓拍人脸，系统将抓拍的人脸与数据库中的信息比对，验证通过后自动开门并记录通行时间。管理员可查看各时段通行记录，并对异常时段（如深夜）出入的学生进行标记。

下列关于人脸识别技术在该系统中应用的描述，正确的是（   ）

- A. 摄像头拍摄到的图像是结构化数据
- B. 光照变化、面部遮挡等因素不会影响人脸识别的准确率
- C. 系统通过深度学习模型自动提取人脸特征，属于联结主义人工智能方法
- D. 人脸识别属于生物特征识别，防伪性好，不需要任何附加设施

---

## 答案

**正确答案：** C

---

## 解析

摄像头拍摄的图像属于非结构化数据，光照和遮挡会影响识别准确率。深度学习通过多层神经网络自动提取人脸特征，属于联结主义人工智能方法。人脸识别需要摄像头等附加设施采集图像，因此 C 正确。
