# 题目 15

有一个内存大小为 `n` 的内存条，起始为空，每次进来一个任务会占用空余的最前面的一段或多段内存，删除任务则解除它占用的所有内存部分。

例如：`n=100`

![[attachments/202412镇海中学_15_图1.png]]

![[attachments/202412镇海中学_15_图2.png]]

（1）已知内存大小为 100 的 `n` 且当前情况为 `[10,20)`、`[20,25)`、`[30,45)`、`[70,75)`。现在任务：进内存 S021 30，所有占用的内存区间为 ______①______。

（2）在划空处填上合适代码：

```python
a = []      # 保存元素存储情况
dict1 = {}  # tmp=0 时任务名按顺序对应为 0,1,2,...以便列表作为元素下标
ans = []

def add(name, v):
    start = 0
    i = 0
    while i < len(a):
        now = a[i][0] - start
        if now >= v:
            a.insert(i, [start, start + v])
            ans[name].append(start)
            i += 1
            break
        elif ______①______:
            a.insert(i, [start, a[i][0]])
            ans[name].append(start)
            v -= now
            i += 1
        ______②______
        i += 1

def find(key):
    L = 0
    R = len(a) - 1
    while L < R:
        m = (L + R) // 2
        if a[m][0] == key:
            ______③______
        elif a[m][0] < key:
            L = m + 1
        else:
            R = m - 1

def delete(name):
    for i in range(len(ans[name])):
        t = ______④______
        a.pop(t)

n = int(input())
a.append([n + 1, n + 1])

while 1:
    T = input().split()
    if T[0] == '进内存':  # T[1]表示占用的任务名，T[2]表示任务内存大小
        dict1[T[1]] = tmp
        ans.append([])
        add(dict1[T[1]], int(T[2]))
        tmp += 1
    elif T[0] == '删除':
        delete(dict1[T[1]])
    else:
        break
    print(a)
```

---

## 答案

（1）`[0,10)`、`[25,30)`、`[45,60)`

（2）① `now != 0`；② `start = a[i][1]`；③ `return m`；④ `find(ans[name][i])`

---

## 解析

（1）程序按地址从小到大使用最早的空闲段。先分配 `[0,10)` 共 10 个单位，再分配 `[25,30)` 共 5 个单位，剩余 15 个单位分配为 `[45,60)`。

> 来源校正：公众号的答案汇总行将第一段写为 `[10,20)`，但其后续详细解析明确写为 `[0,10)`，也与题干和程序的“空余的最前面”规则一致，因此本题记为 `[0,10)`。

（2）`now` 是当前已占用段与前一结束位置之间的空闲长度。当它大于 0 但不足以容纳全部需求时，应用完该空闲段，所以①填 `now != 0`。处理完当前区间后，下一次搜索应从当前已占用段的末尾开始，故②填 `start = a[i][1]`。`find` 找到起始地址等于 `key` 的区间时返回其下标 `m`；删除时用任务保存的每个起始地址查找并弹出对应区间。
