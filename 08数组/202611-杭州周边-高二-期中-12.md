# 题目 12

有如下 Python 程序段：

```python
n=len(q)
res=[]
r=0
i=0
while i<n:
    st=q[i][0]
    ed=q[i][1]
    if st>r:
        res.append([st,ed])
    else:
        if ed>r:
            res[-1][1]=ed
    r=res[-1][1]
    i+=1
```

若 `q=[[1,2],[3,7],[4,5],[6,9],[10,10]]`，运行该程序段后，则 `res[1][1]` 的值为（   ）

- A. 2
- B. 7
- C. 9
- D. 10

---

## 答案

**正确答案：** C

---

## 解析

区间 [3,7] 与 [4,5]、[6,9] 合并，第二个合并区间为 [3,9]。
