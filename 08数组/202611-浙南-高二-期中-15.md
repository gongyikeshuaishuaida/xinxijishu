# 题目 15

某货架共有 n个格子，编号为 0～n-1，每个格子同时只能存放一件货物。系统已获取所有货物数据，每件货物会有一个预存放位置。存放时，如果该格子当前已经被存放，则向右逐个查找，如果找不到则再从预存放位置向左逐个查找。若找到空格子则存入该格子，否则查找失败。现编写Python 程序，用于记录货物存放后的实际位置，并统计查找失败的货物名称。

![[attachments/202611浙南高二_15_图1.png]]

（1）若货架有 3 个格子，初始为空，5 件货物数据如第 15 题图所示，则存放失败的货物数量为 ______ 件。

(2)定义如下judge(ed,st)函数，ed 为当前格子开始空闲的时间，判断当前格子在时间为 st时是否为空，请在划线处填入合适代码。



```python
def judge(ed, st):
    ______①______
    if ed <= st:
        ans = True
    return ans
```



(3)实现上述功能的 Python 代码如下，请在划线处填入合适代码

"""获取格子数量存入 n，即将到达的货物数据存入列表 task，task 每个元素有 5 个数据项，分别为货物名称、预存放位置、到达时间、离开时间和实际存放位置（初值为-1），例如[["A",1,6,10,-1],…]"""

## 答案

（1）1。

（2）① `ans = False`。

（3）① `j = loc`；② `a[j] = ed`；③ `j == len(a)`（或 `j >= len(a)`）。

---

## 解析

格子记录的离开时间不大于当前到达时间时可用。每件货物从预存放位置开始，先向右搜索；到达右边界后切换到预存放位置左侧向左搜索，找到后更新格子的空闲起始时间并保存实际位置，均找不到才记失败。
