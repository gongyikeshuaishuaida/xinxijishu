# 题目 12

有如下Python程序段：

```python
from random import randint
n = len(a)
d = [0] * (n + 1)
result = a[:]
for i in range(2):
    L = randint(0, n-1)   # 随机生成一个[0,n-1]范围的整数
    R = randint(L, n-1)
    x = randint(0, n//2) * 2
    d[L] += x
    d[R+1] -= x
for i in range(n):
    if i > 0:
        d[i] += d[i-1]
    result[i] += d[i]
```

若列表`a=[1,2,3,4,5]`，运行该程序段后，`result`的值不可能是（   ）

- A. `[1, 2, 3, 4, 5]`
- B. `[1, 2, 5, 7, 5]`
- C. `[3, 8, 5, 6, 5]`
- D. `[5, 6, 11, 12, 9]`

---

## 答案

**正确答案：** B

---

## 解析

程序进行两次区间加法，x只能取0、2、4；差分数组累加还原后，每个位置的增量仍为偶数。B中第4个元素由4变7，增量3为奇数，故不可能。A可两次x=0；C可在下标0—3加2、下标1加4；D可在下标0—4加4、下标2—3再加4。
