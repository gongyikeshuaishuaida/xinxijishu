# 题目 15

某图书馆自习区内有 10 个座位（座位号从 1 至 10）实行 “线上预约选座”。系统按提交顺序保存了若干条预约记录，每条记录含座位号、开始时刻与结束时刻（时刻均为开馆后的分钟数，且保证每条预约记录的开始时刻<结束时刻）。若两条记录座位号相同且占用时段有重叠，则判定为一次冲突（如：[10,30]和[25,50]存在冲突，但[10,30]和[30,50]不存在冲突）。另外系统还需统计被预约次数最多的座位号（若有多个座位的被预约次数并列最多，则输出座位号最小的）。

![[attachments/2026119+1高二_15_图1.png]]

（1）若有 6 条如第 15 题图所示的预约记录，则共存在 ______ 次冲突。

（2）判断两个时段 `[a1,a2]` 与 `[b1,b2]` 是否重叠的函数如下，若两个时段有重叠则函数返回 True，否则返回 False。划线处应填 ______（单选，填字母）。



```python
def overlap(a1, a2, b1, b2):
    if ______①______:
        return True
    return False
```





- A. `a1 < b1 and a2 < b2`



- B. `a1 < b2 or b1 < a2`



- C. `a1 < b2 and b1 < a2`



- D. `a2 < b1 and b2 < a1`

（3）主程序如下，请在划线处填入合适的代码。




## 答案

（1）3。

（2）C。

（3）① `overlap(st[i], et[i], st[j], et[j])`；② `c[seat[k]] += 1`。

（4）① `last = end[i]`。

---

## 解析

只比较相同座位的预约，开始时刻分别早于对方结束时刻才算重叠，首尾相接不冲突。双重循环每对只检查一次，给定记录有 3 对冲突。按座位号累计次数，严格大于更新最大值可保留较小座位号。安排尽可能多的单座位预约，按结束时刻优先选择，每安排一条就把 last 更新为其结束时刻。
