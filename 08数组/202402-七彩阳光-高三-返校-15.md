# 题目 15

某工厂加工四种产品，编号依次为 1～4，产品 1 用于生产产品 2，产品 2 用于生产产品 3，产品 3 用于生产产品 4。四种产品日产量分别为 100、100、100、50，第 0 天现存量依次为 46、20、0、0。工厂需要在第 4 天交付 100 件产品 4；临时订单当天下单、当天交付，只有不影响固定订单按期交付时才接单。

![[attachments/202402七彩阳光_15_订单数据.jpg]]

（1）结合题干描述，若临时订单信息如图所示，则被工厂接单的单号为 ______（多个单号用逗号分隔）。

（2）定义函数 `daynum(day, prto)`，用于生成第 0 天到第 `day` 天各产品的存量结构图。调用函数，若 `day=4`，则程序段中加框语句执行 ______ 次。

```python
def daynum(day, prto):
    for i in range(day):
        prto += [[0, -1], [0, -1], [0, -1], [0, -1]]
        p = 3; tmp = prto[i * 4 + p][0]
        prto[i * 4 + p][1] = (i + 1) * 4 + p
        while p >= 1:
            s = prto[i * 4 + p - 1][0]
            if s > prnum[p]:
                s = prnum[p]
            prto[(i + 1) * 4 + p][0] = tmp + s
            tmp = prto[i * 4 + p - 1][0] - s
            prto[i * 4 + p - 1][1] = (i + 1) * 4 + p
            p -= 1
            prto[(i + 1) * 4 + p][0] = tmp + prnum[p]
        return prto
```

## 答案

**正确答案：** （1）No1、No2、No4；（2）1；（3）① `wz = z * 4 + x - 1`；② `y = y - (g - prnum[x])`；③ `n = len(data)`

---

## 解析

图中临时订单中 No1、No2、No4 不会破坏第 4 天产品 4 的固定交付，No3 会使后续产品 4 库存不足。`daynum` 的加框语句在 `p=3` 时执行，`day=4` 时共执行 1 次。`check` 中①用订单的产品编号、数量和下单时间定位存量结构图节点；②扣除不会影响后置产品日产量的部分；③先得到订单数 `n`，后续循环才能逐条检查订单。
