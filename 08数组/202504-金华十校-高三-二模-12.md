# 题目 12

有如下 Python 程序段：

```python
import random
k = random.randint(2, 5)
i = s = cnt = 0
m = -1
for j in range(len(a)):
    s += a[j]
    if a[j] % 2 == 1:
        cnt += 1
    while (j - i + 1) > k or cnt > 1:
        if a[i] % 2 == 1:
            cnt -= 1
        s -= a[i]
        i += 1
    m = max(m, s)
```

若 `a` 为 `[3, 10, 6, 1, 8, 2, 5, 4]`，运行程序后 `m` 的值不可能的是（   ）

- A. 16
- B. 19
- C. 25
- D. 28

---

## 答案

**正确答案：** D

---

## 解析

程序维护长度不超过随机值 `k` 且至多包含一个奇数的连续子数组，并记录其最大和。`k` 取 2、3、4、5 时，`m` 分别可能为 16、19、25、27，因此 28 不可能出现。
