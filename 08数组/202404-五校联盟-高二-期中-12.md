# 题目 12

有如下 Python 程序段：

```python
import random
a = [0] * 5
i = 0
flag = True
while i < 5:
    a[i] = random.randint(1, 8)
    if i % 2 == 1:
        a[i] = a[i] + a[i-1]
        flag = not flag
    elif a[i] % 2 == 0 and flag == False:
        i -= 1
    i += 1
```

执行该程序段后，列表 a 的值不可能是（   ）

- A. [5, 12, 1, 3, 2]
- B. [3, 11, 3, 10, 1]
- C. [4, 5, 5, 11, 7]
- D. [3, 4, 6, 7, 7]

## 答案

**正确答案：** D

## 解析

到达偶数下标 2 时，前一个奇数下标 1 已使 flag 变为 False；若随机数为偶数，程序会将 i 减 1 后再加 1，重复生成该位置。因此最终写入 a[2] 的数必为奇数，D 的 a[2]=6 为偶数，不可能。
