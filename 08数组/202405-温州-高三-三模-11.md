# 题目 11

11.有如下 Python 程序段：

```python
from random import randint
s, i, ans = 1, 0, 0
k = randint(10, 24)
for j in range(len(nums)):
    s = s * nums[j]
    while s >= k:
        s = s / nums[i]
        i += 1
    ans += j - i + 1
```

若 `nums=[2,3,4,5]`，执行后变量 `ans` 的值不可能是（ ）

- A.4
- B.5
- C.6
- D.7

---

## 答案

**正确答案：** A

---

## 解析

随着窗口右端扩展，while 循环不断移除左端元素，`ans` 累加每一步满足乘积小于 k 的连续子数组数量。枚举 k 的 10～24 取值可得 5、6、7 等结果，但不能得到 4。
