# 题目 14

某轮灌系统可将 n 个培养箱（编号 0～n-1）湿度维持在一定范围内。系统实时采集培养箱湿度值，并从 0 号培养箱开始以第 14 题图所示的顺序查找湿度值低于下限的培养箱进行补水，直至湿度值达到上限，每次仅对一个培养箱补水，随后从该培养箱的下一个继续查找，并做同样处理，循环往复。

![[attachments/202611湖丽衢高三_14_图1.png]]

（1）若需要将培养箱湿度维持在 55～68。某时刻 0 至 4 号培养箱的湿度值依次为 52，61，68，57，53。2 号培养箱刚完成补水，则下一个补水的培养箱编号为 ▲ （单选：A. 0 / B. 4）。

（2）实现上述功能的部分 Python程序如下，请在划线处填入合适的代码。

```python
# 读取培养箱数量n、湿度下限low和上限high，代码略
______①______
pos=-1
while True:
    # 获取各培养箱湿度值，存入变量data，格式如[57,53,61,50,49]，代码略
    if cur!=-1 and data[cur]>=high:
        pos=cur
        cur=-1
        # 关闭指定培养箱阀门，代码略
    if cur==-1:
        ______②______
        for j in range(n):
            i=(i+1)%n
            if ______③______:
                cur=i
                # 开启指定培养箱阀门，代码略
                break
    # 延时，代码略
```

---

## 答案

（1）B。

（2）① `cur=-1`，② `i=pos`，③ `data[i]<low`。

---

## 解析

当前没有正在补水的培养箱时，用上一个结束位置作为起点，先加 1 再取模，最多遍历 n 个箱。2 号之后先看 3 号，57 不低于 55，再看 4 号，53 满足补水条件。
