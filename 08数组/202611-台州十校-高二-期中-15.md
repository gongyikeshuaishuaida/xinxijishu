# 题目 15

对于持续风力的计算，气象站一般采用每分钟采集离地 10 米高度风速，计算 2 分钟平均持续风力的方式来计算。具体计算规则如下：

取连续两分钟的风速求平均值；下一组计算时，向后移动 1 分钟，舍弃最早 1 分钟数据，纳入新一分钟数据。示例：风速序列 `[a,b,c]`，第一组取 (a,b)，第二组取 (b,c)。


![[attachments/202611台州十校高二_15_图1.png]]

(1) 现有一组每分钟风速数据：`[12,28,38,22,25]`。

①请写出上述风速数据的所有数据组______①______（格式：（a，b）（c，d））。

②请写出全部满足红色预警条件的数据组______②______（格式：（a，b）（c，d））。

(2) 下面 Python 程序实现红色预警数量统计功能，请完成代码填空。

```python
# 统计红色台风预警记录
count = 0
wind = [12, 28, 38, 18, 32, 42, 25, 26]  # wind列表存放每分钟风速
for i in range(______①______):
    v1 = wind[i]
    v2 = wind[i+1]
    v_avg = (v1 + v2) / 2  # 计算2分钟平均持续风力
    if ______②______:
        count = ______③______
print("满足红色预警的记录数：", count)
```

---

## 答案

**正确答案：** (1) ①(12,28)(28,38)(38,22)(22,25)；②(28,38)；(2) ① `len(wind)-1`（或7）；② `v_avg >= 32.7`；③ `count+1`。

---

## 解析

按相邻两分钟建立长度2的滑动窗口，共n-1组。红色预警要求两分钟平均风速不小于32.7m/s；给定四组中仅(28,38)的平均风速33满足条件，计数应包含等号。
