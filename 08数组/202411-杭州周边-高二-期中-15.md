# 题目 15

15. 图像加密问题。图像加密是保护图像数据安全和隐私的重要手段，其中用卷积运算对图像进行加密处理是一种常见的有效方法，其具体步骤如下：

1）获取图像像素数据和一个用于加密的卷积核，如第15题图a所示。

2）边缘填充：为使卷积运算后的图像尺寸与原图像尺寸相同，可在原图像的四周填充0。

3）元素逐点相乘：将卷积核放置在填充后图像的左上角，获得一个与卷积核尺寸相同的滑动窗口，将窗口内图像元素与卷积核中对应位置的元素进行逐点相乘，如第15题图b所示。

4）求和与结果存储：将窗口内所有乘积相加，得到一个数值，将该数值作为新图像的像素值，如第15题图c所示。

5）移动窗口并遍历整个图像：将卷积核从左到右、从上到下在图像上滑动。每次滑动1个位置，重复步骤3）和步骤4），直到卷积核遍历整个图像。

```python
def pad_data(data):
    data_h = len(data)
    data_w = len(data[0])
    arr = [[0] * (data_w + 2) for k in range(data_h + 2)]
    for i in range(data_h):
        for j in range(data_w):
            if data[i][j] != 0:
                arr[i + 1][j + 1] = data[i][j]
    return arr
```

## 答案

**参考答案：**

- （1）4
- （2）13
- （3）① `s=0`；② `img[ni][nj] * ker[ki][kj]`；③ `apply(data,ker,i,j)`

## 解析

（1）图中滑动窗口对应位置的乘积相加后，右侧新图像中标出的像素值为4。

（2）双重循环访问5×5个原像素，只有像素值不为0时才执行方框内赋值。给定数据中非零元素数量为 `3+3+3+2+2=13`，所以执行13次。

（3）卷积窗口求和需要先将累加器初始化为0，再用图像窗口元素与卷积核对应元素相乘并累加；外层 `con` 函数在每个窗口位置调用 `apply`，因此填入三处代码即可完成卷积。
