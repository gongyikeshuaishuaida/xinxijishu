# 题目 09

9.数组元素 `a[0]` 至 `a[n-1]` 依次存放 n 个数据，现删除下标为 `x` 的元素。程序如下，方框中应填入的正确代码为（ ）

```python
for i in range(x+1, n, -1):
    ______
n -= 1
```

- A.`a[i+1] = a[i]`
- B.`a[i] = a[i+1]`
- C.`a[i-1] = a[i]`
- D.`a[i] = a[i-1]`

---

## 答案

**正确答案：** C

---

## 解析

删除下标 x 后，应将后续元素依次向前覆盖，即从后向前令 `a[i-1]=a[i]`，避免覆盖尚未移动的数据。
