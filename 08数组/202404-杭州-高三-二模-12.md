# 题目 12

列表 `nums` 有 `n(n>1)` 个非零整型元素，要查找乘积最大的连续序列。程序输出最大乘积 `mx`，方框处应填入的正确代码为（   ）：

```python
k = 0                     # 变量k存储负数的个数
st = ed = -1
mx = 1
ml = m2 = 1
for i in range(0, len(nums)):
    if nums[i] < 0:
        k += 1
        # 下面方框处填空
for i in range(0, len(nums)):
    mx *= nums[i]
if k % 2 != 0:
    for t in nums[0:ed]:
        ml *= t
    for t in nums[st+1:len(nums)]:
        m2 *= t
    mx = max(ml,m2)
print(mx)
```

选项：

- A.
```python
if st == -1:
    st = i
ed = i
```
- B.
```python
if ed == -1:
    ed = i
st = i
```
- C.
```python
if st == -1:
    st = i
else:
    ed = i
```
- D.
```python
if ed == -1:
    ed = i
else:
    st = i
```

## 答案

**正确答案：** A

## 解析

需要记录第一个负数下标 `st` 和最后一个负数下标 `ed`。负数个数为奇数时，最大正积只能去掉包含第一个负数的前缀，或去掉包含最后一个负数的后缀；A 正好在第一次遇到负数时设置 `st`，并持续更新 `ed`。
