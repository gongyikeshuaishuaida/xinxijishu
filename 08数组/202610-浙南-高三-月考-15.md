# 题目 15

某高中创客社团只有一台3D打印机，开学初收到了`n`件打印任务。每件任务有各自的打印时长（单位：小时）和取件截止时间。打印机同一时间只能打印一件作品，且每件任务必须连续打印、不能中断（打印机全天24小时运行）。现要编写程序模拟打印过程，使得能在取件截止时间前完成的任务数量最多。

具体规则：先按取件截止时间升序排序，按序选择打印任务，若能在取件截止时间前完成，就加入打印计划，否则替换计划中打印时长最大的任务（若新任务打印时长不低于计划中的各任务时长，则不替换）。

例如，有5件打印任务信息如下表：

![[attachments/202610浙南_15_图1.png]]

首先选择任务2，打印时间从第1小时到第2小时，能在取件截止时间第3小时前完成，加入打印计划。任务4可在取件截止时间前完成，也可加入计划……按上述规则执行后，最多能完成编号为2、4、5的3件任务。

(1) 任务信息存储在`tasks`列表中，其中每个元素由打印时长和取件截止时间2个数据项组成。若`tasks = [[5, 5], [1, 6], [2, 7], [4, 9]]`，能在取件截止时间前完成的最多任务数是______。

(2) 下列程序段的功能是根据每个任务的取件截止时间，对`tasks`中的元素进行升序排序。请在划线处填入合适的代码。

```python
def b_search(a, key, left, right):
    while left <= right:
        mid = (left + right) // 2
        if a[mid][1] > key[1]:
            right = mid - 1
        else:
            left = mid + 1
    return left

def insert_sort(a):
```

## 答案

(1) 3。

(2) `i - 1, pos - 1, -1`。

(3) ① `total + tasks[i][0] <= tasks[i][1]`；② `max_dur > tasks[i][0]`；③ `total += tasks[i][0] - max_dur`（或 `total = total + tasks[i][0] - max_dur`）。

---

## 解析

(1) 先接收时长5和1的任务，总时长为6；时长2的任务加入后为8，超过截止时间7，因此用时长2替换已选任务中时长5的任务，总时长降为3。最后加入时长4的任务，总时长为7，不超过截止时间9，共完成3件任务。

(2) `b_search` 找到第一个截止时间大于待插入任务的位置 `pos`。从 `i-1` 到 `pos` 逆序移动元素，给 `a[pos]` 腾出位置，故 `range` 参数为 `i - 1, pos - 1, -1`。

(3) ①判断加入当前任务后能否按时完成，截止时刻完成也允许，使用 `<=`。不能直接加入时，只有当前任务时长严格小于已选任务的最大时长才值得替换，因此②使用 `max_dur > tasks[i][0]`。替换后数量不变，总时长减去旧任务时长、加上新任务时长，得到③。按截止时间升序处理，并在数量相同的计划中尽量缩短总时长，为后续任务留出更多时间。
