# 题目 09

列表 `a` 包含 `n` 个互不相等的正整数。求其中任意两个元素之和的最大值，程序段如下：

```python
s = 0
b = a[0]
for i in range(1, n):
    ______①______
    ______②______
print(s)
```

可填语句为：

- ① `b = max(a[i], a[i-1])`
- ② `b = max(b, a[i])`
- ③ `s = max(s, a[i] + b)`
- ④ `s = max(s, a[i] + a[i-1])`

划线处应选择的代码顺序是（   ）

- A. ③②
- B. ③①
- C. ④②
- D. ④①

## 答案

**正确答案：** A

## 解析

先用 ②持续维护已扫描元素的最大值 `b`，再用 ③将当前元素与此前最大值求和并更新 `s`。由于列表元素互不相等，当前元素不可能与自身重复配对。
