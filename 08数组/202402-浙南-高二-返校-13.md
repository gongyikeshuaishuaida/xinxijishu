# 题目 13

仓库有一排 `n` 个连续相邻的货位，编号依次为 `0~n-1`，用于放置 A、B 两种类型的箱子。现将两类箱子分区域放置，A 类型在前，B 类型在后，并保持原到达先后顺序，重新摆放后的结果如下图。

![[attachments/202402-浙南-高二-返校-13_横排1_2.png]]

（1）若 `n=10`，箱子到达顺序为 `ABAABBBAAA`，相邻货位之间的距离为 1，在根据题意重新摆放的过程中 A 类箱子需搬动的距离总和为 ______。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 读取箱子信息，存入 lst 列表，lst=[["B",1],["A",2],......]，代码略
n = len(lst)
x = []
______①______
k = 0
while k < n:
    if lst[k][0] == "B":
        x.append(lst[k])
        c += 1
    else:
        lst[k-c] = ______②______
    k += 1
for i in range(______③______, n):
    lst[i] = x[i-n+c]
print("重新摆放后的结果是：", lst)
```

## 答案

**正确答案：** （1）14；（2）① `c = 0`；② `lst[k]`；③ `n-c`（或 `k-c`）。

## 解析

A 箱子按到达顺序移动到前部后，各 A 的目标位置与原位置之差的绝对值之和为 14。程序用 `c` 记录已经遇到的 B 箱子数量：遇到 A 时把它前移到 `k-c`，遇到 B 时暂存到 `x`；最后从 `n-c` 位置开始依次放回 B 箱子。
