# 题目 12

列表 `lst` 长度为 20，如图所示，其中 `lst[5]`～`lst[15]` 各元素的值均为小于等于 0 的随机整数。执行如下程序段，输出结果是

![[attachments/202504湖丽衢_12_图1.jpg]]

```python
n = len(lst)
p = lst[0]
for i in range(0, n):
    tmps = 0
    j = i
    while (j + 1) % n != i:
        tmps += lst[j]
        if tmps > p:
            p = tmps
        j = (j + 1) % n
print(p)
```

- A. 10
- B. 12
- C. 16
- D. 19

---

## 答案

**正确答案：** C

## 解析

程序从每个位置出发，逐步累加循环数组中的连续片段并取最大值。最大连续片段为 `lst[19]` 至 `lst[4]`，其和为 `5 + 2 - 3 + 9 + 1 + 2 = 16`，因此输出 16。
