# 题目 15

某商超周年庆典，面向消费者发放不同金额的现金抵扣券。消费者在该商超消费时可以使用已获取的抵扣券进行现金抵扣。规则是每次消费只能使用一张抵扣券，且抵扣券金额必须小于该次的消费金额。

例如，小明获取到的抵扣券面值与数量如下图。若干次消费金额分别为“45、85、60、15”，小明可以分别选择面值为“30、50、20、10”的抵扣券，所以实际付款 95，抵扣券优惠 110。

![[attachments/202403金丽衢十二校_15_抵扣券数据.jpg]]

编写程序：给定小明获取到的抵扣券面值与数量，以及每次的消费金额，输出实际支付金额与抵扣券优惠金额。请回答下列问题。

（1）若仅将图中的30元面值数量修改为2，则对于题面中的消费“45、85、60、15”，实际付款为 ______①______。

（2）定义如下 `b_sort(lst)` 函数，参数 `lst` 的每个元素由优惠券面值和对应的优惠券数量 2 个数据项组成。函数根据优惠券面值对 `lst` 进行升序排序。

```python
def b_sort(lst):
    n = len(lst)
    for i in range(n - 1):
        flag = True
        for j in range(0, n - i - 1):
            if lst[j][0] > lst[j + 1][0]:
                lst[j], lst[j + 1] = lst[j + 1], lst[j]
                flag = False
        if flag:
            break
    return lst
```

调用该函数，若 `lst` 为 `[[30, 1], [50, 1], [20, 3], [10, 2]]`，请回答两个问题。

① 虚线框中的程序段第1次执行后，关于`lst`中的抵扣券面值，下列说法正确的是 ______②______（单选，填字母）。

- A. `lst[0][0]` 数值最小
- B. `lst[0][0]` 数值最大

- D. `lst[3][0]` 数值最大

② 虚线框中的程序段执行的次数为 ______③______。

（4）若仅将`b_sort(lst)`函数功能修改为根据优惠券面值对`lst`进行降序排序，能否正确实现题目描述功能？______⑦______（单选，填字母：A.能；B.不能）。

## 答案

**正确答案：** ① 85；② D；③ 3；④ `a[i][0] >= x or a[i][1] == 0`；⑤ `a[t][1] += 1`；⑥ `ans += p - k`；⑦ B

## 解析

（1）30 元券增至两张后，可依次使用 30、50、30、10 元券，优惠 120 元，消费总额 205 元，实际付款 85 元。（2）第一轮冒泡后最大面值 50 元移到 `lst[3]`，所以选 D；列表中存在逆序对，外层程序段共执行 3 次。（3）券面值必须严格小于消费额且数量大于 0，因此搜索条件为 `a[i][0] >= x or a[i][1] == 0`；已有面值券数量加一；使用券后实际支付增加 `p-k`，优惠增加 `k`。（4）搜索从末端向前找小于消费额的券，升序排序才能优先找到不超过消费额的最大可用券，改为降序会破坏贪心选择，因此不能。
