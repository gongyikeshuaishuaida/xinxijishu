# 题目 15

某高校同一天安排了多个班次的送站校车，每名学生只能预约一个座位。学生填写最迟出发时刻，系统将发车时刻不晚于该时刻的最晚班次作为该学生的首选班次。发车前，系统分两轮分配座位，每轮均按预约提交顺序处理：

① 第一轮：若首选班次有空位，则安排至该班次；否则暂不安排。

② 第二轮：对第一轮未安排的学生，从早于其首选班次且仍有空位的班次中，选择发车时刻最晚的一个班次进行安排；若无符合条件的班次，则不予安排。例如，12:00、12:15、12:30、12:45四个班次各剩1个空位，5名学生的预约及两轮结果见第15题图a。

![[attachments/202611绍兴高三_15_图1.png]]

请回答下列问题：

(1) 若仅将第15题图a中预约序号1的最迟出发时刻修改为12:45，然后重新进行两轮分配，则预约序号2所分配班次的发车时刻为______。

(2) 为判断是否需加开班次，定义如下函数 `full(batches, k)`：找最早出现的连续 `k` 个无空位班次，找到就返回其中第一个班次的下标，找不到就返回-1。列表 `batches` 的每个元素包含两个数据项，依次为发车时刻和剩余空位，列表已按发车时刻升序排列；`k` 为正整数。

```python
def full(batches, k):
    c = 0
    for i in range(len(batches)):
        if batches[i][1] == 0:
            c = c + 1
            if c == k:
                return i - k + 1
        else:
            c = 0
    return -1
```

①各班次剩余空位依次为1,0,0,1,0,0,0,2，调用 `full(batches, 3)` 返回值为______①______。

②若 `batches` 长度为100，调用 `full(batches, 3)` 返回-1，则语句“`c = c + 1`”最多执行______②______次。

## 答案

**正确答案：** (1) 12:00；(2) ①4；②67；(3) ① `batches[q][0] > reqs[i][0]`；② `near[q] = q - p`；③ `reqs[i][1] = fst[i] - near[fst[i]]`。

---

## 解析

第一轮按提交顺序占据首选班次，第二轮才回退寻找更早的空位。修改后预约序号2需回退至12:00。连续3个无空位班次首次起于下标4。若全程不出现连续3个零，每3项最多2个零，100项最多67个。near保存当前位置与最近有空位班次的距离，直接相减可得到班次序号。
