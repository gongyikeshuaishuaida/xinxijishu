# 题目 15

某学校举行游园活动，有 n 个限时活动项目（如 5 分钟夹珠），每个项目从上午 8:30 开始，结束时间不一定相同。参加前一个活动后，需间隔 10 分钟再参加下一个活动，每个同学不能同时进行两个及两个以上的活动。程序从结束时间最早的活动项目开始选择；若完成该项活动的时间不超过结束时间就选择，否则考虑替换之前选中的活动，使已选项目的总时间尽可能少。

（1）若活动项目数据如下图所示，则最多可以参加的活动项目数量为 ______。

![[attachments/202403宁波十校_15_活动数据.jpg]]

（2）定义如下 `time()` 函数，参数中的结束时间格式为“时:分”，请在划线处填入合适的代码。

```python
def time():
    for x in activity:
        y = x[3]
        for j in range(len(y)):
            if y[j] == ":":
                break
        t = ______①______
        x[3] = t - 510
```

（3）定义如下 `sort(x)` 函数，参数 x 为活动项目数据，按照结束时间进行升序排序。下列选项中，可填入方框中的正确代码是（   ）

- A. `if lst[j] > lst[j+1]: lst[j], lst[j+1] = lst[j+1], lst[j]`
- B. `if lst[j] < lst[j-1]: lst[j], lst[j-1] = lst[j-1], lst[j]`
- C. `if lst[j][3] < lst[j-1][3]: lst[j], lst[j-1] = lst[j-1], lst[j]`
- D. `if lst[j][3] > lst[j+1][3]: lst[j], lst[j+1] = lst[j+1], lst[j]`

（4）实现程序功能的部分代码如下，请在划线处填上合适的代码。

```python
time()
sort(activity)
que = [""] * n
head = tail = 0
total = 0
for i in range(n):
    if total + activity[i][2] <= activity[i][3]:
        que[tail] = activity[i]
        tail += 1
        total += activity[i][2] + 10
    elif head != tail and que[head][2] > activity[i][2]:
        ______①______
        head += 1
        que[tail] = activity[i]
        tail += 1
        temp = que[tail - 1]
        j = tail - 2
        while ______②______:
            que[j + 1] = que[j]
            j -= 1
        que[j + 1] = temp
```

## 答案

**正确答案：** （1）3；（2）① `int(y[0:j]) * 60 + int(y[j+1:len(y)])`；（3）C；（4）① `total += activity[i][2] - que[head][2]`；② `j >= head and temp[2] >= que[j][2]`。

## 解析

先将结束时间换算成相对 8:30 的分钟数。4 个活动按结束时间排序后可选出 3 个。排序时按第 4 个数据项（结束时间）升序比较相邻元素，故选 C。替换时移出队首活动并更新总时长，再将新活动插入已按结束时间组织的位置，循环条件保证插入后顺序正确。
