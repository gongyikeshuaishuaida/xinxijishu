# 题目 15

有如下 Python 程序：

```python
n = len(a)
s = [0] * (n + 1)
for i in range(1, n + 1):
    s[i] = s[i - 1] + a[i - 1]
max = s[0]
for i in range(0, n):
    for j in range(i + 1, n + 1):
        if s[j] - s[i] > max:
            max = s[j] - s[i]
print(max)
```

若列表 `a = [9, -6, 8, 7, -7, 2, 3, -2]`，则输出的结果为（   ）

- A. 95
- B. 23
- C. 18
- D. 14

---

## 答案

**正确答案：** C

---

## 解析

数组 `s` 是 `a` 的前缀和，内层循环枚举所有连续子数组，`s[j]-s[i]` 就是区间 `a[i:j]` 的和。给定数据的前缀和为 `0、9、3、11、18、11、13、16、14`，最大区间和为 18，因此输出 18，选 C。
