# 题目 12

列表 `a` 有 `n` 个元素，将列表 `a` 的前 `p` 个元素（`1≤p≤n`）与后 `n-p` 个元素对调，且不改变这 `p` 个元素（或 `n-p` 个元素）之间的相对位置。例如，`a=[1,2,3,4,5]`，当 `p=2` 时，对调后的结果为 `a=[3,4,5,1,2]`。实现上述功能的部分 Python 程序段如下：

```python
p = int(input("p="))
st1 = 0; ed1 = p - 1
st2 = p; ed2 = len(a) - 1
while st1 <= ed1 and st2 <= ed2:
    i = st1; j = st2
    while i <= ed1 and j <= ed2:
        a[i],a[j] = a[j],a[i]
        i += 1; j += 1
    if i <= ed1:
        st1 = i
    elif j <= ed2:
        st1 = i
        ______①______
    else:
        break
```

方框中可选的代码为：

- ① `ed1 = j`
- ② `ed1 = j - 1`
- ③ `st2 = j`
- ④ `st2 = j - 1`

则选填的正确代码为（   ）

- A. ①③
- B. ①④
- C. ②③
- D. ②④

## 答案

**正确答案：** C

## 解析

当第二段剩余元素仍需参与下一轮交换时，`st2` 应更新为当前的 `j`，即选择 ③；此时第一段的有效末端应退回到 `j-1`，即选择 ②。因此正确组合为 ②③，选择 C。
