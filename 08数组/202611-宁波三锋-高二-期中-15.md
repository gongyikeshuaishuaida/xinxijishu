# 题目 15

某校举办迎新晚会。所有节目演出结束后，观众现场投票。每位观众在选票上填写自己最喜爱的一个节目编号（为 1～30 之间的整数），再将选票投入 A票箱或 B票箱。投票结束后需要清点选票，请编写程序完成选票统计工作。具体要求如下：

①合并选票：将 A、B 两个投票箱内的选票合并，按节目编号非降序排列，存入新列表；新列表的元素个数即为本次投票的总票数；

②奖项评定：得票数超过总票数一半的节目获得“最受欢迎奖”；若无这样的节目，输出“无”。

（1）若 A 箱 6 张选票，工作人员已按节目编号整理成非降序排列：`A=[15,15,15,15,22,22]`；B 箱有 4 张选票，尚未整理：`B=[15,22,15,15]`，合并并排序后列表 C 为 ______①______；获“最受欢迎奖”的节目编号是 ______②______。

（2）要实现将列表 A 与列表 B 合并为升序列表 C，部分 Python 程序如下，请在划线处填入合适代码。

```python
A.sort()    # 将 A 箱选票按节目编号升序排序
B.sort()    # 将 B 箱选票按节目编号升序排序
C=[]
i=0
j=0
while ______①______:
    if ______②______:
        C.append(A[i]); i+=1
    else:
        C.append(B[j]); j+=1
C+=A[i:]+B[j:]
```

（3）小李编写了如下统计程序，请在划线处①填入合适的代码，并改正加框处②代码。

```python
cnt={}    # 统计得票数
for x in C:
    if x in cnt:
        cnt[x]+=1
    else:
        ______①______
ans="无"    # 过半判定
for x in cnt:
    if cnt[x]>=len(C)/2:    # ② 原卷加框
        ans=str(x)
print("最受欢迎奖:",ans)
```

---

## 答案

（1）① `[15,15,15,15,15,15,15,22,22,22]`，② 15。

（2）① `i<len(A) and j<len(B)`，② `A[i]<=B[j]`。

（3）① `cnt[x]=1`，② `cnt[x]>len(C)//2`。

---

## 解析

两个有序列表都未读完时，每轮将较小首项加入 C，再追加尚未处理的一侧。第一次读到节目编号时记 1，之后递增。15 号共 7 票，严格超过半数。
