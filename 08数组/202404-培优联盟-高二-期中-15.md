# 题目 15

某单位有多个部门，部门编号为 $0\sim n-1$，人数不尽相同。现举行某项活动，需要将所有人重新分组。分组前按部门人数由少到多升序排列，从人数最少的部门开始，按每 $m$ 人一组划分；最后一组若不足 $m$ 人，则该组不参加活动，转做后勤。

第 15 题图 a：

![[attachments/202404培优联盟_15_图1.jpg]]

按部门人数由少到多排列后进行分组：

![[attachments/202404-培优联盟-高二-期中-15_横排2_3.png]]

（1）若仅将第 15 题图 a 中 1 号部门的员工人数修改为 2，则分组后第 2 组内的部门是 ______。（填写部门编号，多个编号用逗号隔开）

（2）定义如下 `rank(a)` 函数，其功能是返回一个按部门人数升序排列的部门编号列表。

```python
def rank(a):
    n = len(a)
    p = [0] * n  # 各部门初始排名号为 0
    b = [0] * n
    for i in range(n):
        for j in range(i + 1, n):
            if a[i] > a[j]:
                p[i] += 1
            else:
                p[j] += 1
        b[p[i]] = i
    return b
```

若 `a` 的值是 `[5, 3, 4, 1]`，执行 `rank(a)`，函数中双层循环结束后 `p` 列表的值是 ______。

（3）实现分组的部分 Python 程序如下，请在划线处填入合适代码。

```python
def group(a, m):
    b = rank(a)
    n = len(a)
    gnum = 0
    c = [[]]
    ______①______
    for i in range(n):  # 共 n 个部门
        tot += a[b[i]]
        c[gnum].append(b[i])
        while ______②______:
            tot = tot - m
            c.append([])
            ______③______
            if tot > 0:
                c[gnum].append(b[i])

    # 判断最后一个部门的分组情况
    if tot > 0:  # 最后一个部门有剩余且不足 m 人
        c.pop()
        print(tot, "人转做后勤")
    print("团建共有", gnum, "组，分组情况为：", c)
```

---

## 答案

（1）`0, 5, 4`（顺序不作要求）

（2）`[3, 1, 2, 0]`

（3）① `tot = 0`；② `tot >= m`；③ `gnum += 1`

---

## 解析

（1）修改后各部门人数为 `[3,2,2,1,6,4]`。按人数升序依次装入每组 7 人，第二组涉及 0、5、4 号部门。

（2）`p[i]` 记录第 `i` 个部门之前应有多少个更小（或按程序规则排在它前面）的元素。对 `[5,3,4,1]` 两两比较后，各元素名次为 `[3,1,2,0]`。

（3）`tot` 是当前累计但尚未划出完整小组的人数，初值为 0。只要 `tot >= m` 就能再组成一组，每形成一组便令 `gnum` 加 1；若同一部门人数跨组，剩余人数仍记录到下一组中。
