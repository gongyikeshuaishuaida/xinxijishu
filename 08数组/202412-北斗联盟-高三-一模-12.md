# 题目 12

有如下 Python 程序段：

```python
a=[1,5,2,7,9,6,8,28,10]
n=len(a);c=[1]*n;p=[-1]*n
for i in range(1,n):
    for j in range(i-1,-1,-1):
        if a[j]<a[i] and c[j]>=c[i]:
            c[i]=c[j]+1;p[i]=j
maxlen=max(c)
for i in range(n-1,-1,-1):
    if maxlen==c[i]:
        m=i
tot=0
while m!=-1:
    tot+=a[m];m=p[m]
print(tot)
```

运行该程序段后，输出的结果是（   ）

- A. 27
- B. 32
- C. 45
- D. 50

## 答案

**正确答案：** C

## 解析

数组 `c` 记录以每个位置结尾的最长递增子序列长度，`p` 记录对应前驱。程序得到的最大长度为 5，从后向前寻找时最后确定的末位置是 `7`，回溯下标链 `7→6→5→2→0`，对应元素为 `28、8、6、2、1`，总和为 `45`，所以选 C。
