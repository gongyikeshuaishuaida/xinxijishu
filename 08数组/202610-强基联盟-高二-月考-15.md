# 题目 15

某服务器记录了用户提交的计算任务，每个任务包含三个信息：`[任务ID, 开始时间, 结束时间]`（时间均为正整数）。该服务器一个时间段只能执行一项任务，如果两个不同的任务在时间上有重叠，就会发生冲突，例如：任务1`["T1",10,20]`和任务2`["T2",15,25]`存在冲突，但任务1`["T1",10,20]`和任务3`["T3",20,30]`不算冲突（首尾相接，未发生时间重叠）。为了找出引发冲突最多（与它时间重叠的任务数量最多）的任务，编写如下Python程序，输出引发冲突最多的任务ID及冲突次数（若冲突最多的任务有多个则输出开始时间最早的）。

（1）若有如下4个任务：`["T1",10,25]`，`["T2",20,30]`，`["T3",5,15]`，`["T4",30,40]`，则冲突最多的任务ID是______。

（2）自定义函数`conf()`，实现判断两个任务是否有冲突的功能，请在划线处填入合适的代码。

```python
def conf(task1,task2):
    start1,end1=task1[1],task1[2]
    start2,end2=task2[1],task2[2]
    if ______①______:
        return True
    return False
```

（3）实现上述功能的部分Python程序如下，请在划线处填入合适的代码。

```python
'''
```

---

## 答案

（1）T1。

（2）①`start2<end1`（原参考答案，适用于开始时间已排序且第一个任务不晚于第二个任务的调用）。

（3）①`n=len(tasks)`；②`counts[tasks[i][0]]+=1`；③`maxid=tid`。

---

## 解析

（1）T1与T2、T3重叠，冲突次数为2；其余任务的冲突次数更少。首尾相接不算重叠。

（2）第（3）问先按开始时间升序排序，并只比较i<j的任务，因此start1<=start2；对于有正时长的任务，只需判断start2<end1。等号不能取，否则会把首尾相接判为冲突。

原第（2）问单独称函数可以“判断两个任务是否有冲突”，未限定实参顺序。参考答案只检查start2<end1，作为通用函数不充分：先传["T1",20,30]、再传["T2",5,10]时会误判为冲突。一般的正时长区间应判断`start1<end2 and start2<end1`，或`max(start1,start2)<min(end1,end2)`。参考答案原样保留，并注明它在主程序中的排序前提。

（3）①取得任务总数；②冲突的一对任务需要分别增加双方计数，j一方已有语句，所以空白应增加i一方；③记录目前最高冲突次数的任务ID。counts按已排序tasks插入任务，遍历时保持插入顺序；只在严格大于时替换结果，因此冲突次数相同保留开始时间最早者。假定任务ID唯一，且结束时间晚于开始时间。
