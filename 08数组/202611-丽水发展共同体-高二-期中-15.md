# 题目 15

某农业基地引进了智能水果分拣机，需要根据水果的 3 个特征（大小、颜色饱和度、表面缺陷斑点数量）将其自动分类为“特级果”、“一级果”或“二级果”。分类算法如下：计算待测水果与样本库中每个水果的“特征距离”，距离可用欧氏距离公式表示。例如，待测水果“T001”的特征数据如图 b 所示，其与样本库中“A001”的距离为 $\sqrt{(80-85)^2+(90-95)^2+(1-0)^2}$。用该方法计算出“T001”与样本库中所有水果的距离，选取前 k 个最近距离的水果，统计出现频次最多的水果等级（若频次相等，取更高等级），即为该待测水果的等级。

（2）定义如下 `fmin(result, flag)` 函数，参数 result 列表存储距离，flag 列表存储标记。若 `result=[43,33,18,25,65]`，`flag=[False,False,True,True,False]`，则函数的返回值为 ______。



```python
def fmin(result, flag):
    f = 10000    # 假定 result 列表元素值不超过 10000
    pos = -1
    for i in range(len(result)):
        if f > result[i] and flag[i] == False:
            f = result[i]
            pos = i
    return pos
```

## 答案

（1）A。

（2）1。

（3）① `x[j]-data[i][j]`（或相反数）；② `dic[data[p][4]] += 1`；③ `k -= 1`。

## 解析

前 5 个最近邻中，特级果与一级果频次并列，按规则取更高的特级果。fmin 跳过已标记元素，在剩余项中选出距离最小者的下标。平方距离不受相减方向影响；每选出一个邻居就累加其等级频次并将剩余名额减一。
