# 题目 11

11.有如下 Python 函数 `mydel`，功能是在非空列表 `lst` 中找第一个数据 `x` 并删除，划线处的正确代码为（ ）

```python
def mydel(lst, x):
    for i in range(len(lst)):
        if lst[i] == x:
            break
    else:
        return "找不到想删除的数据"
    for j in range(①):
        lst[j] = lst[j+1]
    lst.pop()
```

- A. `i, len(lst)-1`
- B. `i, len(lst)-2`
- C. `len(lst)-1, i, -1`
- D. `len(lst)-2, i-1, -1`

---

## 答案

**正确答案：** A

---

## 解析

找到下标 i 后，需把 i 后面的元素依次向前覆盖，j 应从 i 遍历到 `len(lst)-2`，故范围为 `range(i, len(lst)-1)`；最后 `pop()` 删除重复的末尾元素。
