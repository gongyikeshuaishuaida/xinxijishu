# 题目 12

已知`a,b`均是规模为`n`的降序数组，现要从两数组共`2n`个元素中选出最大的`n`个元素，并仍按降序存入数组`a`，部分Python代码如下：

```python
i = j = 0
while j <= len(b)-1 and i <= len(a)-1:
    if a[i] >= b[j]:
        ______(1)______
    else:
        for k in range(______(2)______):
            a[k] = a[k-1]
        ______(3)______
        j = j+1
```



则划线处（1）（2）（3）的正确代码是：

①`i=i+1`　②`j=j+1`　③`len(a)-1,i,-1`　④`len(a)-1,i-1,-1`　⑤`a[i]=b[j]`　⑥`a[k]=b[j]`（   ）

- A. ①③⑤
- B. ①③⑥
- C. ②④⑤
- D. ②④⑥

---

## 答案

**正确答案：** A

---

## 解析

若`a[i]>=b[j]`，保留当前a元素并推进i；否则从末端到i+1逆序右移，循环参数为`len(a)-1,i,-1`，再把`b[j]`写入`a[i]`。之后推进j。
