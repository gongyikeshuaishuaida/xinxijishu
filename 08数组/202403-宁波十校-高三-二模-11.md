# 题目 11

用数组 a 和 b 存储两个降序序列，用数组 c 存储合并后的降序序列。例如 `a = [19,16,12,8,5]`、`b = [20,15,14,10,6]` 时，`c = [20,19,16,15,14,12,10,8,6,5]`。实现该功能的程序段如下，划线处可选代码为：① `c.append(a[i])`；② `c[i] = a[i]`；③ `tot,p-1,-1`；④ `tot,p,-1`；⑤ `tot-1,p-1,-1`。则（1）（2）处的代码依次为（   ）

```python
c = [-1] * (len(a) + len(b))
p = 0
tot = len(a)
for i in range(len(a)):
    ______①/②______
for i in range(len(b)):
    while b[i] < c[p]:
        p += 1
    if c[p] == -1:
        c[p] = b[i]
        tot += 1
    else:
        for j in range(______③/④/⑤______):
            c[j + 1] = c[j]
        c[p] = b[i]
        tot += 1
```

- A. ①③
- B. ①④
- C. ②⑤
- D. ②③

## 答案

**正确答案：** C

## 解析

数组 c 预先分配了固定长度，第一轮必须把 a 中元素写入对应位置，不能使用 append；插入 b 中元素时要把从末端到插入位置的元素整体后移，范围为 `range(tot-1, p-1, -1)`，所以选择 ②⑤，即 C。
