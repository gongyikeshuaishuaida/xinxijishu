# 题目 15

“云游良渚”平台招募6名线下参观志愿者，编号为 $0 \sim 5$ ，设置5个服务岗位，编号 $0 \sim 4$ 。每名志愿者填报两个不同意向岗位。岗位分配分三轮执行，规则如下：

第一轮：按志愿者编号依次处理。若志愿者填报的第一志愿岗位尚未分配人员，则将该志愿者分配至该岗位；否则本轮分配失败。

第二轮：针对第一轮分配失败的志愿者，仍按其编号升序依次处理。若该志愿者的第二志愿岗位仍有空闲，则将其分配至该岗位；否则本轮分配失败。

第三轮：第二轮结束后，若还有未分配志愿者且存在空缺岗位，将待分配志愿者以及空缺岗位分别按编号升序排序，并依次进行配对补录，直到岗位全部占满。

三轮结束后仍未分配成功的志愿者，分配失败。

（1）若 6 名志愿者提交的第一志愿依次为 3、1、4、1、3、0，第二志愿依次为 1、2、3、4、0、1，则第一轮分配失败的志愿者是 ______ 号；三轮结束后仍未分配到岗位的志愿者是 ______ 号。

（2）自定义函数 `alloc(w1,w2)` 的功能：按上述三轮规则完成岗位分配，返回分配失败的志愿者编号列表。请在划线处填入合适的代码。



```python
def alloc(w1, w2):
    # w1[i]、w2[i]依次为志愿者i的第一志愿、第二志愿岗位编号
    occ = [-1] * 5    # occ[j]存放岗位j分配的志愿者编号，-1表示该岗位空缺
    res = [-1] * 6    # res[i]存放志愿者i分配的岗位编号，-1表示未分配
    for i in range(6):    # 第一轮志愿分配
        p = w1[i]
        if occ[p] == -1:
            ______①______
            res[i] = p
    for i in range(6):    # 第二轮志愿分配
        if ______②______:
            p = w2[i]
            if occ[p] == -1:
                occ[p] = i
                res[i] = p
    free = []
    for j in range(5):
        if occ[j] == -1:
            free.append(j)    # 把空缺岗位的编号加入列表free
    k = 0
    for i in range(6):    # 第三轮志愿分配
        if res[i] == -1 and k < len(free):
            ______③______
            res[i] = free[k]
            k = k + 1
    # 输出各岗位分配结果，代码略
    fs = []
    for i in range(6):
        if res[i] == -1:
            fs.append(i)    # 把未分配志愿者的编号加入列表fs
    return fs
```



（3）主程序部分如下，请在划线处填入合适的代码。



```python
zy1 = [3,1,4,1,3,0]    # 依次存放6名志愿者的第一志愿
zy2 = [1,2,3,4,0,1]    # 依次存放6名志愿者的第二志愿
fs = ______①______
print("分配失败的志愿者编号为：", fs)
```

---

## 答案

（1）3、4；4。

（2）① `occ[p] = i`；② `res[i] == -1`；③ `occ[free[k]] = i`。

（3）① `alloc(zy1, zy2)`。

---

## 解析

第一轮 0、1、2、5 依次占据岗位 3、1、4、0，3、4 失败；其第二志愿也已满。第三轮只剩岗位 2，按编号优先补录志愿者 3，所以最后失败的是 4。occ 按岗位记录人，res 按人记录岗位，两者需同步更新。
