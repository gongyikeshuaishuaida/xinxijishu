# 题目 13

世界卫生组织认为成年人正常血压标准为：收缩压在 [90,140] 且舒张压在 [60,90]。现有连续若干天的血压值，编程计算正常血压持续的最长天数并输出起止日期；若有多段最长天数，输出最后一段的起止日期。

（1）某段时间测量的血压值如下图，则正常血压持续的最长天数为 ______ 天。

![[attachments/202403浙江四校_13_血压数据.jpg]]

（2）数组 `a` 中保存每天的收缩压和舒张压，`a[2*i]` 和 `a[2*i+1]` 分别表示第 `i` 天的两项数据，数组 `b` 保存日期。请填空：

```python
n = len(a)
t, ans, end = 0, 0, 0
for i in range(n // 2):
    if 90 <= a[2*i] <= 140 and 60 <= a[2*i+1] <= 90:
        t += 1
        if ______①______:
            ans = t
            end = i
    else:
        ______②______
print("正常血压持续的最长天数为：", ans)
beg = ______③______
print("起止日期：", b[beg], "--", b[end])
```

## 答案

**正确答案：** （1）3；（2）① `t >= ans`；② `t = 0`；③ `end - ans + 1`。

## 解析

图中 9 月 2 日至 9 月 4 日连续三天正常，最长长度为 3。遍历时遇到正常值就累加当前段长度；用 `t >= ans` 更新可保证相同长度时保留最后一段。遇到异常值将当前段清零；最长段起点为结束下标减去长度再加 1。
