# 题目 15

学校创客社团开展智能小车竞速活动，小车在铺有网格的赛道上按编程指令移动。每条移动指令用 4 位二进制码表示：前 2 位表示移动方向（00→东，01→南，10→西，11→北），后 2 位表示移动距离（距离值为后两位二进制码转换成的十进制数，可取 0～3 格）。小车从原点(0,0)出发，按收到指令的顺序依次移动，每执行完一条指令就更新一次当前位置。程序运行结束后统一输出移动轨迹（如“南 1、西 2、东 3”）、最终位置，以及离开原点后是否再次经过原点。方向编码表：

![[attachments/202611温州十校高二_15_图1.png]]

请回答下列问题:

(1) 若控制器发送的指令串为“011110010010”，最终小车所在的位置为 ____（坐标表示），移动过程中是否再次经过原点为 ____。

(2) 定义如下 `b2d(code)` 函数，参数 `code` 为两位数字字符组成的字符串，函数返回转换后的十进制整数，请在程序划线处填上合适的代码。

```python
def b2d(code):
    n = 0
    for i in range(len(code)):
        n = ______
    return n
```

下列填入上述程序划线处的代码中，可行的有______（多选）。

（注：全部选对的得2分，选对但不全的得1分，不选或有选错的得0分。）

- A. `n + 2 * int(code[i])`

- B. `n * 2 + int(code[i])`

- C. `n + int(code[i]) * 2 ** (1-i)`

- D. `n + int(code[i]) * 2 ** (2-i)`

(3) 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
s = input("请输入指令串：")
x = y = 0
flag = False
left = False
res = ""
dic = {"00": "东", "01": "南", "10": "西", "11": "北"}
i = 0
while i + 4 <= len(s):
    d = b2d(s[i:i+2])
    v = b2d(s[i+2:i+4])
    res += ______①______ + str(v) + "、"
    if d % 2 == 0:
        dx = 1 - d
        dy = 0
    else:
        dx = 0
        dy = ______②______
    x += dx * v
    y += dy * v
    if x != 0 or y != 0:
        left = True
    if left and ______③______:
        flag = True
    i = i + 4
print(res[:-1], x, y, flag)
```

---

## 答案

**正确答案：** (1) (1,-3)，否；(2) B、C；(3) ① `dic[s[i:i+2]]`；② `d - 2`；③ `x == 0 and y == 0`。

---

## 解析

指令0111、1001、0010依次为南3、西1、东2，到达(1,-3)。二进制可逐位乘2累加，也可按位权相加。奇数方向码1、3分别对应南、北，dy应为-1、1，故d-2。left记录是否离开过原点，之后位置回到(0,0)才置flag。

原程序只在每条指令结束后检查原点；若“经过原点”包括指令中途跨越原点，代码不能覆盖这种情况。例如东1再西2会途经原点，但两次终点均非原点。题面和参考填空保留，适用范围据此说明。
