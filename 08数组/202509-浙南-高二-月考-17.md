# 题目 17

一面墙由 `n` 列砖组成，已知每列砖的数量为 `nums[i]`（相邻两列砖之间无缝隙），每块砖的长宽高均为 1，现需在这面墙中找到一块面积最大的矩形用于涂鸦。例如，`n = 6`，每列砖的数量依次为 3、2、1、5、6、2，如第 17 题图所示，该墙最大面积的矩形为 10。

![[attachments/202509浙南高二_17_图.jpg]]

（1）若该面墙有 5 列砖，每列砖的数量为 4、3、5、2、3，那么最大的矩形面积是 ______。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
def area(nums):
    maxa = 0
    ①
    for i in range(n):
        left = i
        while nums[left - 1] <= nums[i]:
            left -= 1
        right = i
        while right < n - 1 and nums[right + 1] >= nums[i]:
            right += 1
        ②
        cur = nums[i] * lenght
        if maxa < cur:
            maxa = cur
    return maxa

# 获取每列砖的数量，存于列表 nums 中，代码略
③
print("最大的矩形面积是：", s)
```

（3）加框处的代码有误，请改正。

---

## 答案

**正确答案：** （1）10；（2）① `n = len(nums)`；② `lenght = right - left + 1`；③ `s = area(nums)`；（3）`while left > 0 and nums[left - 1] >= nums[i]:`

---

## 解析

（1）对于 4、3、5、2、3 五列，取高度 2 的整段矩形可得面积 `2×5=10`；其余候选区间的面积均不超过 10，所以最大面积为 10。

（2）循环需要先取得列表长度 `n`，因此 ① 为 `n = len(nums)`。以第 `i` 列为最低高度时，向左右扩展后覆盖的列数为 `right - left + 1`，所以 ② 使用题目中的变量名 `lenght` 赋值。读入 `nums` 后调用函数并保存返回值，③ 为 `s = area(nums)`。

（3）向左扩展时必须先保证 `left > 0`，并且左侧相邻柱子的高度应大于等于当前柱高，才能继续包含该列。因此加框处应改为 `while left > 0 and nums[left - 1] >= nums[i]:`。
