# 题目 12

有如下程序段：

```python
from random import randint
i, n = 0, 4
a = [0, 0, 0, 0, 0]
while i <= n:
    x = randint(1, 9)
    if x % 2 == 1:
        a[i] = x
    else:
        a[n] = x
        n = n - 1
    i = i + 1
print(a)
```

运行后，输出 `a` 的值可能是（   ）

- A. `[7,1,3,9,10]`
- B. `[3,4,1,8,8]`
- C. `[0,7,0,6,8]`
- D. `[3,7,5,5,0]`

---

## 答案

**正确答案：** C

---

## 解析

随机数范围只有 1～9，排除 A。奇数从左侧当前 `i` 位置写入，偶数从右侧当前 `n` 位置写入；两端指针交错后中间可能保留 0。C 可由先写右端偶数、再写左侧奇数等过程产生。
