# 题目 13

仓库中连续货位放置红、白、蓝三色货物，编号为 0～`n-1`。现要把货物按红、白、蓝顺序分类，使同色货物相邻。

（1）若白色 1 个、红色 3 个、蓝色 2 个，分类后第 4 个货物的颜色为______（红/白/蓝）。

（2）补全程序：

```python
# 读取货物颜色信息存储到列表 a 中，0、1、2 分别表示红、白、蓝
n = len(a)
______①______
i = p0 = 0
while i <= p2:
    while i <= p2 and ______②______:
        a[i], a[p2] = a[p2], a[i]
        p2 -= 1
    if a[i] == 0:
        a[i], a[p0] = a[p0], a[i]
        ______③______
    i += 1
print("分类结果为：", a)
```

---

## 答案

**正确答案：** （1）白；（2）① `p2=n-1`；② `a[i]==2`；③ `p0+=1`

---

## 解析

三个红色占据前 3 个位置，第 4 个位置是白色。程序用 `p0` 指向下一个红色位置、`p2` 指向下一个蓝色位置，扫描时先把蓝色交换到右端，再把红色交换到左端。
