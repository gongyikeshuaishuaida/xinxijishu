# 题目 15

某加密字符串由 0～255 的整数和大小写字母构成，以非数字字符结尾。解密依次进行“提取整数、值变换、位置变换、行列变换”。方阵转换示例如下：

![[attachments/202410江浙皖_15_方阵转换示意图.jpg]]

（1）`data="asd123hts35pyg253klm89tre247ytu"`，提取整数后`num_lst`的第一个元素为`[______①______, ______②______]`。

（2）位置变换函数如下：

```python
def pos_trans(data, c):
    n = len(data)
    m = len(c)
    num = [0] * n
    for i in range(n // m):
        for j in range(m):
            num[i * m + j] = data[i * m + c[j] - 1]
    for i in range((n // m) * m, n):
        num[i] = data[i]
    return num
```

若`data=[126,44,11,109,16,10,220,178,23]`、`c=[3,1,2]`，返回列表最后一个元素为 ______③______。

## 答案

**正确答案：** ① 123；② 3；③ 178；④ `flag`（或`flag == True`）；⑤ `(data[i][1] + data[i][0]) % 256`；⑥ `pa = start + (i + 1) // m`

---

## 解析

整数 123 从下标 3 开始。位置变换每 3 个元素按第 3、1、2 个重排，最后一组 `[220,178,23]` 变为 `[23,220,178]`。提取首位数字时用 `flag` 记录起点；值变换按题意把整数与起始位置相加后模 256；按列读取方阵时，每完成一列应把 `pa` 移到下一列首元素。
