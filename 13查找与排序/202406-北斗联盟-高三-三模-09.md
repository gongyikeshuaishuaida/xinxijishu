# 题目 09

9.有如下 Python 程序段，若 `n=8`、`key=23`，数组 `a[0]` 至 `a[n-1]` 依次存放 `13，17，20，23，23，24，39，43`。

```python
i=0; j=n-1; c=0
while i<=j:
    m=(i+j)//2
    c+=1
    if a[m]<=key:
        i=m+1
    else:
        j=m-1
```

执行该程序段后，下列说法正确的是（ ）

- A.`i` 的值为 3
- B.`j` 的值为 4
- C.`m` 的值为 5
- D.`c` 的值为 2

---

## 答案

**正确答案：** B

---

## 解析

二分查找依次取 `m=3、5、4`，对应更新 `i=4、j=4、i=5`，循环结束时 `j=4`、`c=3`，所以 B 正确。
