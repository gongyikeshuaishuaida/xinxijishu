# 题目 15

15.“红五月文艺”比赛有“合唱”和“趣味操”两个项目，每个班级先进行合唱再进行趣味操，两个场地各同一时间只允许一个班级。为缩短总时长，先按每班两个项目的较短时长升序排列：较短项目为合唱（或两项相等）时从前往后加入，较短项目为趣味操时从后往前加入。

（2）`sy(m)` 中，`m[i][2]=0` 表示较短项目为合唱，`m[i][2]=1` 表示较短项目为趣味操。`top+=1` 与 `top-=1` 应分别放在下列程序的哪些位置？

```python
def sy(m):
    r = []
    top = 0
    st = [0] * len(m)
    for i in range(len(m)):
        if m[i][2] == 0:
            r.append(m[i][0])
        elif m[i][2] == 1:
            ______①______
            st[top] = m[i][0]
            ______②______
    while top != 0:
        ______③______
        r.append(st[top])
        ______④______
    return r
```

- A. ①③
- B. ①④
- C. ②③
- D. ②④

（3）补全 `times(data)`：

```python
def times(data):
    n=len(data)
    m=[]
    for i in range(n):
        if ①:
            m.append([i,data[i][1],1])
        else:
            m.append([i,data[i][0],0])
    ②
    while ed!=0:
        last=0
        for j in range(ed):
            if m[j][1]>m[j+1][1]:
                m[j],m[j+1]=m[j+1],m[j]
            last=j
        ed=last
    r=sy(m)

    tot=0
    for i in range(1,n+1):
        t[i]=③
```

---

## 答案

**正确答案：** （1）231；（2）BC；（3）①`data[i][0]>data[i][1]`；②`ed=n-1`（或 `ed=len(data)-1`、`ed=len(m)-1`）；③`t[i-1]+data[r[i-1]][0]`

---

## 解析

图 e 中各班较短时长分别为 3、2、4，排序后按 Johnson 规则得到顺序 2、3、1。`sy` 遇到趣味操时压入栈，遍历结束后再从栈顶弹出：既可采用“先增加 `top`、后存入；先取出、后减少 `top`”的 B 方案，也可采用“先存入、后增加 `top`；先减少 `top`、后取出”的 C 方案，因此选 BC。构造 `m` 时比较两个项目时长确定较短项目；先将冒泡排序边界 `ed` 设为 `n-1`，再按最终顺序计算第二场地开始/结束时间，`t[i]` 为前一班完成第一项目后的可开始时间 `t[i-1]+data[r[i-1]][0]`。
