# 题目 11

有如下 Python 程序段：

```python
from random import randint
a = [3, 1, 4, 12, 6, 5, 9, 7]
s = randint(0, 1) * 2 - 1  # randint(0, 1)随机生成0或1
i = 0
while i < len(a):
    if i == 0 or (a[i] - a[i - 1]) * s >= 0:
        i += 1
    else:
        a[i], a[i - 1] = a[i - 1], a[i]
        i -= 1
```

执行该程序段后，`a` 的值可能为（   ）

- A. `[3, 4, 12, 6, 5, 9, 7, 1]`

- B. `[1, 3, 4, 6, 5, 9, 7, 12]`

- C. `[12, 9, 7, 6, 5, 4, 3, 1]`

- D. `[1, 3, 4, 5, 6, 9, 12, 7]`

---

## 答案

**正确答案：** C

---

## 解析

s随机为1或-1。相邻元素不符合对应次序时交换并回退，最终得到升序或降序序列；选项中只有C是完整降序。
