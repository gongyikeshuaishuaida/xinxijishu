# 题目 12

有如下 Python 程序段：

```python
import random

a = [10, 20, 28, 36, 36, 54, 68, 92, 98]
f = [0] * len(a)
key = 2 * random.randint(10, 45) + 1
i = 0
j = len(a) - 1
n = 0
while i <= j:
    m = (i + j) // 2
    f[m] = 1
    if key > a[m]:
        i = m + 1
        n = n + 1
    else:
        j = m - 1
        n = n - 1
```

执行该程序段后，下列说法正确的是（   ）
- A. 变量 `i` 的值可能为 4
- B. 变量 `n` 的值范围为 [-3, 3]
- C. 数组 `f` 中至少有 3 个元素值为 1
- D. 数组 `f` 的值可能为 `[0, 0, 0, 0, 1, 0, 1, 1, 1]`

---

## 答案

**正确答案：** C

---

## 解析

key 始终为21到91之间的奇数，而数组元素均为偶数，因此不会命中。对长度9的有序表执行二分查找时至少访问3个中点，所以 f 中至少有3个元素被置1。
