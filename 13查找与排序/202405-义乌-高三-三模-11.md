# 题目 11

根据列表 `s` 中元素的大小关系，使用冒泡排序升序排列各元素的索引，并将排序后的索引保存在 `y` 中。程序如下：

```python
def sort_indices(s):
    n = len(s)
    y = [i for i in range(n)]
    for i in range(______①______):
        for j in range(______②______):
            if ______③______:
                y[j], y[j+1] = y[j+1], y[j]
    return y
```

三处代码依次是（ ）

- A.`n`；`n-i`；`s[y[j]] >= s[y[j+1]]`
- B.`n`；`n-i`；`y[j] >= y[j+1]`
- C.`n-1`；`n-i-1`；`s[y[j]] >= s[y[j+1]]`
- D.`n-1`；`n-i-1`；`y[j] >= y[j+1]`

---

## 答案

**正确答案：** C

---

## 解析

冒泡排序需要进行 `n-1` 轮，第 `i` 轮比较到下标 `n-i-2`，因此内层为 `range(n-i-1)`；排序的是索引对应的元素值，比较应使用 `s[y[j]]` 与 `s[y[j+1]]`，故选 C。
