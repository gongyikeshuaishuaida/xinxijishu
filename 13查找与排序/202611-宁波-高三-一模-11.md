# 题目 11

有如下 Python 程序段：

```python
k, c = 7, 5
i, j = 0, len(a) - 1
while i <= j:
    m = (i + j) // 2
    if abs(a[m] - c) < abs(k - c):
        i = m + 1
    elif abs(a[m] - c) > abs(k - c):
        j = m - 1
    else:
        if a[m] < k:
            i = m + 1
        else:
            j = m - 1
print(i)
```

运行程序后，输出 `i` 的值为 4，则数组 `a` 可能是（   ）

- A. `[6, 4, 5, 5, 6, 8, 3]`
- B. `[5, 4, 6, 7, 7]`
- C. `[6, 4, 5, 5, 3, 6, 6]`
- D. `[5, 4, 6, 3, 8]`

---

## 答案

**正确答案：** D

---

## 解析

D 的 `m` 依次为 2、3、4。遇到 6 时令 `i = 3`，遇到与 5 相距 2 且小于 7 的 3 时令 `i = 4`，遇到 8 时令 `j = 3` 并结束。A、B、C 实际分别输出 5、3、7。
