# 题目 12

有如下 Python 程序段：

```python
# 读取数组 a 的值，代码略
i = 0
for j in range(len(a) - 1):
    if a[j] < a[-1]:
        a[i], a[j] = a[j], a[i]
        i += 1
a[i], a[-1] = a[-1], a[i]
```

执行该程序段后，数组 a 的值为 `[3, 1, 2, 5, 4, 6, 7, 8]`，则该数组的初始值中 `a[-1]` 不可能是（   ）

- A. 5
- B. 6
- C. 7
- D. 8

---

## 答案

**正确答案：** A

---

## 解析

程序以 `a[-1]` 为基准，把小于基准的元素移到左侧，再将基准放到分界位置。若基准为 5，最终基准右侧必须全大于等于 5，但给定结果中右侧出现 4，不可能；其他基准值可以构造得到，故选 A。
