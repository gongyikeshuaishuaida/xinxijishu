# 题目 10

程序根据列表 `a` 中元素的大小关系，按降序排列各元素的索引并返回索引列表。例如 `a=[3,4,2,5,1]` 时，得到 `b=[3,1,0,2,4]`。

```python
# 读取 n 个数据依次存储到列表 a 中
b = [i for i in range(n)]
end = 0
while end < n - 1:
    last = n - 1
    ______方框______
    end = last
```

方框中应填入的代码为（   ）

### A

```python
for j in range(1, end + 2):
    if a[b[j]] > a[b[j - 1]]:
        b[j], b[j - 1] = b[j - 1], b[j]
        last = j - 1
```

### B

```python
for j in range(n - 1, end, -1):
    if a[b[j]] > a[b[j - 1]]:
        b[j], b[j - 1] = b[j - 1], b[j]
        last = j
```

### C

```python
for j in range(1, end + 2):
    if b[j] > b[j - 1]:
        b[j], b[j - 1] = b[j - 1], b[j]
        last = j - 1
```

### D

```python
for j in range(n - 1, end, -1):
    if b[j] > b[j - 1]:
        b[j], b[j - 1] = b[j - 1], b[j]
        last = j
```


---

## 答案

**正确答案：** B

---

## 解析

排序比较的是 `a[b[j]]` 与 `a[b[j-1]]`，不是索引值本身；从右向左扫描未排序区间，发生逆序时交换两个索引，并把最后交换位置记录为 `last=j`。因此选择 B。
