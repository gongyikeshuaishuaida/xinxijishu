# 题目 8

有以下 Python 程序段：

```python
s = [5, 9, 8, 6, 7, 1, 4, 2]
n = len(s)
for i in range(1, n // 2):
    for j in range(______①______):
        if s[j] < s[j - 1]:
            s[j], s[j - 1] = s[j - 1], s[j]
```

执行程序段后，数据部分有序，结果 `s` 的值为 `[5,9,1,6,7,8,4,2]`，则划线处的代码是

- A. `n-3, i+1, -1`
- B. `i+1, n-i-1`
- C. `n-1, i-1, -1`
- D. `2, n-i+1`

## 答案

**参考答案：** A

## 解析

填入 A 后，内层循环为 `range(n-3,i+1,-1)`，每轮从后向前进行相邻比较。对 `i=1,2,3` 执行后，数组恰好变为 `[5,9,1,6,7,8,4,2]`。
