# 题目 10

有如下 Python 程序段：

```python
import random as rd
a = [7, 9, 5, 8, 6, 4]
k = 2 * rd.randint(0, 2) + 1
for i in range(k, len(a)):
    for j in range(len(a) - 1, i, -1):
        if a[j] < a[j - 1]:
            a[j - 1], a[j] = a[j], a[j - 1]
```

该程序段执行后，`a` 中各元素值不可能的是

- A. `[7, 4, 5, 6, 8, 9]`
- B. `[7, 9, 4, 5, 6, 8]`
- C. `[7, 9, 5, 4, 6, 8]`
- D. `[7, 9, 5, 8, 6, 4]`

## 答案

**参考答案：** B

## 解析

`k` 只能取 1、3、5。内层循环从后向前进行相邻交换，分别模拟不同起始位置的部分冒泡排序。逐一分析三种 `k` 的结果，B 项的排列无法由该程序得到。
