# 题目 12

某二分查找算法的 Python 程序段如下：

~~~python
n = len(a)
L = 0
R = (n - 1) // 2       # 语句①
while L <= R:
    m = (L + R) // 2    # 语句②
    if key == a[m]: break
    if key < a[m]:
        R = m - 1
    else:
        L = m + 1
if L <= R or R >= 0 and a[n - R - 1] == key:
    print("YES")
else:
    print("NO")
~~~

执行该程序段后，下列说法正确的是（   ）

- A. 若列表 a 有 8 个元素，则语句②最多被执行 4 次
- B. 若 a 为 [1, 5, 8, 7, 3]，key 为 7，输出结果为“NO”
- C. 若要实现 key 的查找，a 中元素应按升序排列
- D. 将语句①修改为“R = n - 1”，可能会影响程序输出的结果

---

## 答案

**正确答案：** D

## 解析

程序先在前半段进行二分查找，再通过 a[n-R-1] 检查后半段的对应位置，算法利用的是特定的分段有序关系，不要求整个列表单纯按升序排列。B 中执行后 R=1，检查 a[3]=7，输出应为 YES；A 的次数上界判断不正确。若把 R 改为 n-1，会改变二分查找范围和后续下标关系，可能影响输出，因此 D 正确。
