# 题目 11

有如下Python程序段：

```python
a = [2] * n + [3] * k   # n、k 均为正整数
i, j, cnt = 0, len(a)-1, 0
while i <= j:
    m = (i + j) // 2    # ①
    if a[m] < key :     # ②
        i = m + 1
    else:
        j = m - 1
    cnt += 1
print(i)
```

关于上述程序段，下列说法正确的是（   ）

- A. 若`key`的值为3，程序的输出结果取决于列表`a`中元素3的个数
- B. 若将①处语句修改为`m=(i+j+1)//2`，会影响程序的输出结果
- C. 若将②处语句的加框部分修改为`a[m]<=key`，会影响程序的输出结果
- D. 若列表`a`中有1000个元素，则程序运行后`cnt`的值可能超过10

---

## 答案

**正确答案：** C

---

## 解析

原程序求第一个不小于key的下标。key=3时输出n，取决于元素2的个数；改变中点取整方向不改变查找边界；把比较改为不大于时，求第一个大于key的下标，例如key=3时从n变为n+k。1000个元素的二分循环最多10次。原卷②处加框部分为`a[m] < key`。
