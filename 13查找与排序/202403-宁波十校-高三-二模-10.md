# 题目 10

有如下 Python 程序段：

```python
import random
def binary(L, R, key):
    m = (L + R) // 2
    if L > R:
        return L
    if key <= a[m]:
        return binary(m + 1, R, key)
    else:
        return binary(L, m - 1, key)

a = [9, 8, 7, 7, 7, 5, 5, 3]
x = random.randint(1, 4) * 2 + 1
print(binary(0, 7, x))
```

执行该程序段后，输出结果不可能是（   ）

- A. 2
- B. 5
- C. 7
- D. 8

## 答案

**正确答案：** A

## 解析

`x` 只可能取 3、5、7、9。按程序在降序数组中递归查找插入位置，返回值可得到 5、7、8 等位置，但不会得到 2，因此不可能的是 A。
