# 题目 11

11.某二分查找算法的 Python 程序段如下：

```python
import random
key=random.randint(2,4)*2
a=[2,5,6,8,13,15,20,22]
ans=0; i=0; j=len(a)-1
while i<=j:
    m=(i+j)//2
    ans+=m
    if key==a[m]:
        break
    elif key>a[m]:
        i=m+1
    else:
        j=m-1
```

执行该程序段后，`ans` 的值不可能是（ ）

- A.3
- B.4
- C.5
- D.6

---

## 答案

**正确答案：** C

---

## 解析

`key` 只能取 4、6、8。取 4 时访问下标 3、1、0，`ans=4`；取 6 时访问 3、1、2，`ans=6`；取 8 时第一次访问下标 3，`ans=3`。因此 5 不可能出现，选 C。
