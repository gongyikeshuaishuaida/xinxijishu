# 题目 10

小杨编写了一个 Python 程序，部分代码如下：

~~~python
# 输入数据，存储到列表 d 中，代码略
n = len(d)
for i in range(1, n):
    for j in range(i, n):
        if d[j] < d[j - 1]:
            d[j], d[j - 1] = d[j - 1], d[j]
~~~

执行该程序段，输入下列数据，列表 d 中元素未按升序排列的是（   ）

- A. 1, 2, 4, 3, 5
- B. 4, 1, 2, 3, 5
- C. 5, 2, 1, 4, 3
- D. 5, 1, 2, 3, 4

---

## 答案

**正确答案：** C

## 解析

该程序每一轮从下标 i 开始比较，不能保证前面已经形成的部分继续有序。选项 C 执行第一轮后得到 2,1,4,3,5，第二轮后得到 2,1,3,4,5，仍有 2>1，未按升序排列。其余选项执行后均能得到升序序列。
