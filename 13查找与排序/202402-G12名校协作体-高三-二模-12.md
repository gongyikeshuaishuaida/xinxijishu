# 题目 12

有如下 Python 程序段：

```python
a = [15, 20, 32, 32, 54, 66, 94, 96]
f = [0] * len(a)
key = 2 * random.randint(10, 47) + 1
i = 0; j = len(a) - 1; s = 0; n = 0
while i <= j:
    m = (i + j + 1) // 2
    f[m] = 1
    if key <= a[m]:
        j = m - 1; n = n - 1
    else:
        i = m + 1; n = n + 1
    s = sum(f)
```

执行该程序段后，下列说法正确的是（   ）

- A. 变量 `i` 的值可能为 3
- B. 变量 `n` 的值可能为 3
- C. 变量 `s` 的值一定为 3
- D. 变量 `f` 的值可能为 `[1, 0, 1, 0, 1, 0, 0, 0]`

---

## 答案

**正确答案：** C

---

## 解析

`key` 是 21～95 的奇数。二分查找每次访问一个新位置，数组长度为 8，因此循环恰好访问 3 个位置，`s=sum(f)` 恒为 3；枚举所有可能的 key 可知 `i` 不会为 3、`n` 只会为 -1 或 1，选项 D 的访问位置组合也不会出现。
