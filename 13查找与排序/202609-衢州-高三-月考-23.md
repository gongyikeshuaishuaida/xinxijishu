# 题目 23

有如下Python程序段：

```python
key=int(input("key="))
q=[0]*len(a)
L=R=len(a)//2
i,j=0,len(a)-1
while i<=j:
    m=(i+j)//2
    if a[m]>key:
        j=m-1;L-=1;q[L]=m
    else:
        i=m+1;R+=1;q[R]=m
print(q[L:R+1])
```

已知数组`a=[20,21,22,22,22,27,27,27,30,31]`，执行该程序段后，输入`key`值，则输出的结果不可能是（   ）

- A. `[0,1,4,0]`
- B. `[1,4,0,0]`
- C. `[7,0,4,5]`
- D. `[9,0,4,7,8]`

---

## 答案

**正确答案：** C

---

## 解析

中间位置初始0始终保留。比较结果为“大于key”时从中间向左逆序记录下标，否则向右记录。`key=19`可得到A，`key=20`可得到B，`key=30`可得到D。要使4记录在右侧需 `key>=22`；此时下一次比较下标7。若7记录在左侧，后续下标5的数据同为27，也应记录在左侧，不可能出现C将7放左侧、5放右侧的组合。
