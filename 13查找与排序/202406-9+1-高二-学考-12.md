# 题目 12

12.某次技术练习的成绩放在 `score.csv` 文件中，第一列为姓名，第二列为信息技术成绩，第三列为通用技术成绩。编写 Python 程序从文件中读取数据，计算技术总分，然后选出总分最高的前十名（第十名若有同分一起输出）。

![[attachments/202406-9+1-高二-学考-12_横排1_2.png]]

（1）下列代码实现读取数据、计算总分、存入 `zflst` 列表中的功能，请填空：

```python
zflst=[]
for stu in data:
    zf=______①______
    zflst.append(zf)
```

（2）下列代码利用逐个比较求最大值的方式从 `zflst` 中挑选出总分最高的前十名，并用 `flag` 标记已选数据，请填空：

```python
print("姓名 总分")
n=______②______
flag=[False]*n
for i in range(10):
    max=0
    for j in range(n):
        if flag[j]==False:
            if ______③______:
                max=zflst[j]
                k=j
    print(data[k][0], " ",zflst[k])
    flag[k]=True
i=0
while i<n:
    if flag[i] or zflst[i]==max:  # 改错
        print(data[i][0], " ",zflst[i])
        flag[i]=True
    i+=1
```

（3）改正加框处代码。

---

## 答案

**正确答案：** （1）`float(stu[1])+float(stu[2])`。
（2）② `len(zflst)`（或 `len(data)`）；③ `zflst[j]>max`（或 `zflst[j]>=max`）。
（3）`if not flag[i] and zflst[i]==max:`（或 `flag[i]==False and zflst[i]==max`）。

---

## 解析

每个学生的两门成绩是字符串，先转为浮点数再相加。`n` 是学生数，因此可取 `len(zflst)`。每轮只在未选数据中更新最大值；最后查找第十名同分者时必须排除已经输出过的元素，所以条件应为未标记且分数等于第十名分数。
