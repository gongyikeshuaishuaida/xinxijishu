# 题目 11

有如下程序段：

~~~python
a=["-","p","y","-","t","h","o","n","-"]
p=0
for i in range(len(a)):
    if not ("a" <= a[i] <= "z"):
        j=i; pt=a[i]
        while j>p:
            a[j]=a[j-1]
            j=j-1
        p=j; a[j]=pt
print(a[4])
~~~

则运行该程序段后，输出的值为（   ）

- A. "-"
- B. "p"
- C. "y"
- D. "t"

---

## 答案

**正确答案：** C

## 解析

程序依次把不在小写字母范围内的字符移到已处理区域的末尾。列表中的三个连字符依次被移到下标 0、1、2 处，处理结束时列表为 “-、-、-、p、y、t、h、o、n”，所以 a[4] 为 y，选 C。
