# 题目 12

有如下 Python 程序段：

```python
left = 0; right = len(d)-1; t = 1
for k in range(3):    # 原卷加框的是 3
    for i in range(left,right,t):
        if d[i] * t > d[i+t] * t:
            d[i], d[i+t] = d[i+t], d[i]
    right = right - t
    left, right, t = right, left, -t
```

若 d 为 [9,13,8,7,2,4,3,5]，执行该程序段后，下列说法错误的是（   ）

- A. d[0],d[1],d[2]的值依次为2,8,7
- B. d[5],d[6],d[7]的值依次为3,9,13
- C. t的值为-1
- D. 将加框处改为7，可实现d中元素升序

---

## 答案

**正确答案：** B

---

## 解析

正反各向交替冒泡，前三趟后右侧已经放定的元素可直接跟踪，B 给出的顺序与结果不符。
