# 题目 11

有如下 Python 程序段：

```python
d = [3, 9, 2, 0, 2, 4]
s = [0, 1, 2, 3, 4, 5]
n = len(d)
for i in range(n - 1):
    for j in range(n - 1, i, -1):
        if d[s[j]] < d[s[j - 1]]:
            s[j], s[j - 1] = s[j - 1], s[j]
print(s)
```

执行该程序段后，输出的结果是（   ）

- A.`[3, 4, 2, 0, 5, 1]`
- B.`[3, 2, 4, 0, 5, 1]`
- C.`[1, 5, 0, 4, 2, 3]`
- D.`[1, 5, 0, 2, 4, 3]`

---

## 答案

**正确答案：** B

---

## 解析

程序排序的是索引列表 `s`，比较关键字为 `d[s[j]]`。按关键字升序排列后，0 的索引为 3，2 的索引依次为 2、4，随后是 3 的索引 0、4 的索引 5 和 9 的索引 1，结果为 `[3,2,4,0,5,1]`，故选 B。
