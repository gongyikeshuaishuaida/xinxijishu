# 题目 11

某二分查找算法的 Python 程序段如下：

```python
key = int(input())
n = 0
i, j = 0, len(d) - 1
while i <= j:
    m = (i + j) // 2
    if key < d[m]:
        j = m - 1
    else:
        i = m + 1
        n += 1
print(n)
```

若 `d` 为 `[8, 12, 15, 18, 25, 28, 34, 39, 48, 65]`，运行程序后，输出结果和其他三项不同的 `key` 值是（   ）

- A. 18
- B. 34
- C. 40
- D. 63

---

## 答案

**正确答案：** C

---

## 解析

程序在 `key >= d[m]` 时才把 n 加 1。`key` 为 18、34、63 时各执行 3 次右移分支，而 `key` 为 40 时只执行 2 次，所以不同的是 40。
