# 题目 11

有如下两个 Python 函数：

```python
def search1(a, key):
    i, j = 0, len(a) - 1
    while i <= j:
        m = (i + j) // 2
        if a[m] < key:
            i = m + 1    # ①
        else:
            j = m - 1
    return i

def search2(a, key):
    i = 0
    while i < len(a):
        if a[i] >= key:
            return i
        i += 1
    return i    # ②
```

对于相同的升序数组 a 和 key，正确的是（   ）

- A. 函数 `search1` 和函数 `search2` 的返回值可能不同

- B. 将函数 `search2` 中②处语句删除，函数功能不变

- C. 将函数 `search1` 中①处语句修改为 `i=i+1`，函数返回值不变

- D. 函数 `search1` 的循环次数一定比函数 `search2` 的少

---

## 答案

**正确答案：** C

---

## 解析

两函数均返回第一个不小于 key 的位置，找不到时返回 len(a)。把 i=m+1 改成 i=i+1 仍逐步缩小正确边界，只是可能增加循环次数。删除末尾 return 会在未找到时返回 None。
