# 题目 10

某二分查找程序如下：

```python
flag = False
c = 0
i, j = 0, len(d) - 1
while i <= j and not flag:
    m = (i + j) // 2
    c += 1
    if d[m] == key:
        flag = True
    elif key < d[m]:
        j = m - 1
    else:
        i = m + 1
```

当 `d=[8,12,16,18,23,28,33,37,48,55]` 时，运行后 `c=4` 且 `flag=True`，符合的查找键 `key` 有几个？

- A. 1
- B. 2
- C. 3
- D. 4

---

## 答案

**正确答案：** C

---

## 解析

按该中点取法构造查找判定树，位于第 4 次比较才命中的元素共有 3 个。
