# 题目 11

有如下 Python 程序段：

```python
n = 8
cnt1 = cnt2 = 0
flag = True
last = 0
d = [1, 2, 4, 6, 7, 9, 5, 8]
while last <= n - 2 and flag:
    flag = False
    for j in range(n - 1, last, -1):
        cnt1 += 1
        if d[j] < d[j - 1]:
            d[j - 1], d[j] = d[j], d[j - 1]
            cnt2 += 1
            flag = True
            pos = j
    last = pos
```

运行后，`cnt1` 和 `cnt2` 的值分别为（   ）

- A. 28、4
- B. 10、4
- C. 28、24
- D. 13、24

---

## 答案

**正确答案：** B

---

## 解析

`cnt1` 记录比较次数，`cnt2` 记录交换次数。带最后交换位置优化的冒泡过程共比较 10 次、交换 4 次。
