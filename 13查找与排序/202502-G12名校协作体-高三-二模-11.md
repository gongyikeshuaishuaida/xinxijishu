# 题目 11

某二分查找算法的 Python 程序段如下：

```python
i, j, n = 0, len(a) - 1, 0
while i <= j:
    m = (i + j) // 2       # ①
    if key > a[m]:
        i = m + 1
        n += 1
    else:
        j = m - 1
        n -= 1
```

当 `a=[0,1,2,3,4,5,6,7]` 时，运行程序查找 `key` 得到的 `n` 值，与把①处语句改为 `m=(i+j+1)//2` 后得到的 `n` 值相等，则 `key` 可能是

- A. 0
- B. 1
- C. 2
- D. 3

## 答案

**参考答案：** C

## 解析

分别用向下取整和向上取整的中点模拟查找过程，比较每次更新 `n` 的加减结果，`key=2` 时两种取中点方式得到的 `n` 值相同，因此选择 C。
