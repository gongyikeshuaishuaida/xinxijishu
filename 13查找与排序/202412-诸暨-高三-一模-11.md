# 题目 11

某二分查找算法的 Python 程序段如下：

```python
from random import randint
key,cnt=randint(5,9)*2+1,0
i,j=0,len(d)-1
while i<=j:
    cnt+=1
    m=(i+j)//2
    if key==d[m]:
        break
    elif key<d[m]:
        j=m-1
    else:
        i=m+1
```

当 `d` 为 `[8,10,12,14,16,17,18,19]` 时，变量 `cnt` 的值不可能是（   ）

- A. 1
- B. 2
- C. 3
- D. 4

## 答案

**正确答案：** A

## 解析

`key` 的取值为 11、13、15、17、19。第一次比较的中间元素为 14，不可能直接命中这些 `key`；因此 `cnt` 不可能为 1。`key=17` 时可在第二次命中，`key=11、13、15` 需要 3 次比较，`key=19` 需要 4 次比较，所以可能值为 2、3、4。
