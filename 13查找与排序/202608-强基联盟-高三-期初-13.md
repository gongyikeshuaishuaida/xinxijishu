# 题目 13

某电商仓库有 `n` 个待发包裹（编号从 1 到 `n`），需要在 `d` 天内全部配送至指定区域，要求按照包裹编号从小到大进行运送，求运送包裹的车辆的最低载重量。现有 6 个包裹，依次编号为 1-6，其重量如下表所示。

![[attachments/202608强基联盟高三_13_包裹重量表.jpg]]

例如要求在 3 天内完成，则车辆最低载重量为 15，其中：第一天运送编号 1、2、3（重量 9、1、5），第二天运送编号 4（重量 13），第三天运送编号 5、6（重量 9、4）。

请回答下列问题：

（1）若以上包裹要求在 4 天内全部配送完，则车辆的最低载重量为 ______。

（2）实现上述功能的程序如下，完成划线部分填空。

```python
def days(n):  # 求载重量为 n 时所需的天数
    c = 1; temp = 0
    for i in range(t):
        temp = temp + weight[i]
        if temp > n:
            __________  # ①
            c = c + 1
    return c

# 将各包裹重量按编号顺序存入列表 weight，代码略。
t = len(weight)
maxv = 0; sumv = 0
for i in range(t):
    if weight[i] > maxv:
        maxv = weight[i]
    __________  # ②

d = int(input("请输入天数："))
L = maxv; R = sumv
while L <= R:
    m = (L + R) // 2
    if __________:  # ③
        R = m - 1
    else:
        L = m + 1
print("车辆最低载重量为：", L)
```

---

## 答案

**正确答案：** （1）13；（2）① `temp = weight[i]`；② `sumv += weight[i]`；③ `days(m) <= d`

---

## 解析

4 天配送时可按 `1、2`，`3`，`4`，`5、6` 分组，各组重量依次为 10、5、13、13；且车辆载重低于 13 不可能配送编号 4，因此最低载重量为 13。若当前包裹加入后超过载重，应从当前包裹重新开始新的一天，故 ① 将 `temp` 重置为 `weight[i]`。② 统计所有包裹总重量，作为二分上界。③ 当 `days(m) <= d` 时，载重 `m` 已能在规定天数内完成，尝试减小载重，移动右边界。
