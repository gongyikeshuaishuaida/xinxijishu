# 题目 11

有如下 Python 程序段：

```python
i, j = 0, n - 1
while i <= j:
    m = (i + j) // 2
    if a[m] < b[m]:
        i = m + 1
    else:
        j = m - 1
```

数组 `a` 和 `b` 长度均为 `n`（n>2），其中 `a` 为升序序列，`b` 为降序序列，且 `a[0]` 等于 `b[n-1]`，`a[n-1]` 等于 `b[0]`。执行上述程序段后，对于任意0～n-1之间的整数 `k`，下列说法正确的是（   ）

- A. 若 `k<i`，则 `a[k]<b[k]` 成立

- B. 若 `k==i`，则 `a[k]==b[k]` 成立

- C. 若 `k>j`，则 `a[k]>b[k]` 成立

- D. 若 `k>=m`，则 `a[k]>=b[k]` 成立

---

## 答案

**正确答案：** A

---

## 解析

条件 `a[m] < b[m]` 随下标增大只可能由真变假，程序找第一个不满足该条件的位置 i。因此所有 `k<i` 均满足 `a[k]<b[k]`；右侧可能相等，不能保证严格大于。
