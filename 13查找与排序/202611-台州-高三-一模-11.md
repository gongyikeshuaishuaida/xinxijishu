# 题目 11

有如下 Python 程序段：

```python
low = max(a); high = sum(a)
while low < high:
    mid = (low + high) // 2
    cnt = 1; s = a[0]
    for i in range(1,len(a)):
        if s + a[i] > mid:
            cnt += 1; s = a[i]
        else:
            s += a[i]
    if cnt <= k:
        high = mid
    else:
        low = mid + 1
```

若 a 为 [3,2,4,2,9,1,5]，k 为 3，执行该程序段后，low 的值为（   ）

- A. 9
- B. 10
- C. 11
- D. 13

---

## 答案

**正确答案：** C

---

## 解析

以 mid 为各段和上限，贪心判断能否分为不超过 3 段。上限 10 不可行，上限 11 可行。
