# 题目 10

某对分查找算法的 Python 程序段如下：

```python
d = [7, 12, 18, 25, 39, 58, 61, 72, 86]
key = int(input())
i, j, n = 0, 8, 0
f = [0] * 9
while i <= j:
    m = (i + j) // 2
    n += 1
    if d[m] == key:
        break                 # 表示退出循环
    if key < d[m]:
        j = m - 1
        f[m] = -1
    else:
        i = m + 1
        f[m] = 1
print(n, sum(f))
```

执行上述程序段后，下列说法正确的是（   ）

- A. 若输入的 `key` 为 58，则 `sum(f)` 的值为 1
- B. 若 `n` 的值为 4，则 `key` 可能的值是 `[40,45]`
- C. `sum(f)` 的最大值可能为 3
- D. `f[0]` 到 `f[8]` 各元素值可能的是 `0,0,0,0,1,0,1,-1,0`

## 答案

**正确答案：** D

## 解析

每次比较后，若目标值小于中间元素，记录 `-1` 并缩小右边界；若目标值大于中间元素，记录 `1` 并增大左边界；命中时不再写入新的方向标记。逐项检查可知，D 给出的标记序列可以由一次合法的查找过程得到，其余选项的查找次数或 `sum(f)` 结论不成立。
