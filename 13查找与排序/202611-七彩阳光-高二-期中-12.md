# 题目 12

有如下 Python 程序段：

```python
import random
a = [0] * 6
b = [1] * 6
a[0] = random.randint(10, 99)
i = 1
while i < 6:
    a[i] = random.randint(10, 99)
    if a[i] != a[i-1]:
        i += 1
for i in range(6):
    for j in range(6):
        if a[i] > a[j]:
            b[i] += 1
print(b)
```

该程序运行后，输出的结果不可能的是（   ）

- A. `[5,4,1,3,5,2]`

- B. `[2,4,1,2,5,2]`

- C. `[3,6,3,1,5,2]`

- D. `[4,6,1,3,5,2]`

---

## 答案

**正确答案：** B

---

## 解析

排名为“比它小的元素个数加 1”。B 中三个排名为 2 的元素相等，加上唯一最小元素后，下一档排名至少为 5，不能出现 4。
