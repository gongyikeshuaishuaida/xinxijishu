# 题目 10

数组元素 `a[0]`～`a[n-1]` 已按降序排列，现要将 `a[pos]`（`0 ≤ pos ≤ n-1`）的值加 5，并保持数组的有序性不变。实现该功能的部分程序段如下，方框中应填入的正确代码为

```python
t = a[pos] + 5
L, R = 0, pos - 1
while L <= R:
    m = (L + R) // 2
    if t < a[m]:
        L = m + 1
    else:
        R = m - 1
for i in range(______①______):
    a[i] = a[i - 1]
a[L] = t
```

- A. `pos, R, -1`
- B. `pos, L, -1`
- C. `R, pos`
- D. `L, pos`

---

## 答案

**正确答案：** B

## 解析

二分查找结束后，`L` 是新值 `t` 在降序数组中的插入位置。需要从原位置 `pos` 开始向后移动元素，直到 `L+1`，所以循环范围应为 `range(pos, L, -1)`，对应 B。
