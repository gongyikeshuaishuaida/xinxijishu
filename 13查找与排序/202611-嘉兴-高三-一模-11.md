# 题目 11

在升序列表中插入两个值，Python 程序段如下：

```python
data = [1, 8, 46, 69]
small = 6
big = 88
i = len(data) - 1
data += [0, 0]  # 在列表末尾追加两个元素
m = 0
while i >= 0 and data[i] > small:
    if data[i] > big:
        data[i+2] = data[i]
    else:
        data[i+1] = data[i]
        m += 1
    i -= 1
data[i+1] = small
data[i+m+2] = big
print(m)
```

程序运行结束后，输出的值为（   ）

- A. 0

- B. 1

- C. 2

- D. 3

---

## 答案

**正确答案：** D

---

## 解析

原列表中大于small=6且不大于big=88的元素有8、46、69，各进入else使m加1，共3次。
