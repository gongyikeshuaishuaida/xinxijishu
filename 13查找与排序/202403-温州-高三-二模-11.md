# 题目 11

定义如下函数：

```python
def search(lst, i, j, key):
    if i > j:
        return -1
    m = (i + j) // 2
    if lst[m] > key:
        return search(lst, i, m - 1, key)
    elif lst[m] < key:
        return search(lst, m + 1, j, key)
    else:
        return m
```

若列表 `lst` 为 [12, 31, 47, 50, 55, 55, 71, 76]，执行 `search(lst, 0, 7, 51)`，该函数被调用的次数为（   ）

- A. 1
- B. 2
- C. 3
- D. 4

## 答案

**正确答案：** D

## 解析

递归调用依次检查下标 3、5、4，最后在区间 [4,3] 进入结束条件，因此共调用 4 次。
