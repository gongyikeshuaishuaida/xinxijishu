# 题目 09

9.数组L长度为n，要实现L[a]至L[b]升序排列（0≤a<b≤n-1），其余位置不变：

```python
for i in range(0,b-a):
    for j in range(b-1,a-1,-1):
        if L[j] < L[j-1]:
            L[j],L[j-1] = L[j-1],L[j]
```

加框处代码有误，可修改为：

A.`range(a,b-1)`  B.`range(b,a-i,-1)`  C.`range(b,a+i,-1)`  D.`range(a-i+1,b)`

---

## 答案

**正确答案：** C

---

## 解析

外层第i趟冒泡时，内层下界应逐步右移到 `a+i`，因此用 `range(b,a+i,-1)`，选C。
