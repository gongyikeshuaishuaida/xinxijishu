# 题目 10

某二分查找算法的 Python 程序段如下：

```python
i, j = 0, len(a) - 1
while i <= j:
    m = (i + j) // 2
    if ______①______:
        i = m + 1
    else:
        j = m - 1
print([i, j])
```

列表 `a=[23,21,21,19,19,15,13,7]`，`key` 的值为 21，若该程序段执行后输出的值为 `[1,0]`，则方框处应填入的语句为

- A. `a[m] > key`
- B. `a[m] >= key`
- C. `a[m] <= key`
- D. `a[m] < key`

## 答案

**参考答案：** A

## 解析

数组按降序排列。第一次中点为 3，`a[3]=19`，应令 `j=2`；随后中点为 1，`a[1]=21`，为了继续向左查找边界，条件 `a[m]>key` 为假并令 `j=0`；再比较 `a[0]=23` 后令 `i=1`，得到 `[1,0]`。
