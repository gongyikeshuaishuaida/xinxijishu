# 题目 12

有如下 Python 程序段：

```python
def search(key, L, R):
    if L > R:
        return "该数不存在"
    else:
        m = (L + R) // 2       # ①
        if a[m] == key:
            return m
        elif a[m] > key:
            return search(key, L, m - 1)
        else:
            return search(key, m + 1, R)

a = [2, 3, 8, 12, 19, 23, 25, 30, 34, 50]
key = int(input())
print(search(key, 0, len(a) - 1))
```

下列说法不正确的是

- A. 若输出“该数不存在”，则 `search` 函数被调用的次数最多为 4 次
- B. 若 `search` 函数被调用两次，则 `key` 的值可能是 3 或 30
- C. 将①处的代码改成 `m = (L + R + 1) // 2`，程序运行的结果不会改变
- D. 数组 `a` 中的元素为降序，则不能用此程序进行查找

## 答案

**参考答案：** A

## 解析

长度为 10 的数组进行二分查找时，查找失败时的调用次数可能超过 4 次，因此 A 的表述不正确。上取中点不会改变成功查找的结果；该程序的比较方向要求数组升序，降序时不能直接使用。
