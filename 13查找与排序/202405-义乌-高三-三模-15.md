# 题目 15

大型活动中，从 1 到 10000 的演员经筛选后保留 `n` 人，先按序号升序排列，再按尽可能大的 `m×m` 方阵分割区间，每个方阵使用一个颜色字母编码。示例 `n=21` 时分成 16、4、1 三个方阵，颜色依次为 A、B、C。

示例方阵图：

![[attachments/202405-义乌-高三-三模-15_横排1_2.png]]

（1）按示例增加一个序号为 40 的演员，则其编码为 ______①______。

（2）补全区间分割函数：

```python
def cut():
    size = []
    x = int(n ** 0.5) + 1
    for m in range(x, 0, -1):
        while n >= m * m:
            ______②______
            size += [m]
q = len(size)
id = [0] * q
val = [0] * q
id[0] = 0
val[0] = a[0]
for i in range(1, q):
    id[i] = ______③______
    val[i] = a[id[i]]
```

（3）二分查找 `val`，若 `search(key)` 返回 `-1`，则输入的 `key` 可以为 ______④______（填写一个整数）。

（4）输出方阵内行号和列号的语句为：

```python
print(i // size[pos] + 1, ______⑤______)
```

---

## 答案

**正确答案：** （1）D40；（2）②`n-=m*m`；③`id[i-1]+size[i-1]*size[i-1]`；（3）④`1`；（4）⑤`i%size[pos]+1`

---

## 解析

每次取当前剩余人数能容纳的最大平方块，扣除 `m*m` 人数并记录边长；第 i 个方阵起始下标等于前一方阵起始下标加前一方阵人数。示例中 40 位于新增的第二个 1×1 方阵，颜色为 D。`val[0]` 是最小演员序号，二分查找返回 -1 表示 key 小于该值，可取 1；方阵列号用下标对边长取模再加 1。
