# 题目 12

有以下 Python 程序段：

~~~python
# 输入 nums 代码略
stack=[0]*10
top=-1
res=[-1]*len(nums)
for i in range(0,len(nums)):
    while top!=-1 and nums[stack[top]]<nums[i]:
        res[stack[top]]=nums[i]
        top-=1
    top+=1
    stack[top]=i
print(res)
~~~

执行该程序段后，得到的输出结果为 [5,25,25,-1,-1,-1]，则 nums 数据可能是（   ）

- A. [4,5,25,25,24,23]
- B. [4,5,2,25,23,24]
- C. [4,5,2,25,24,23]
- D. [5,5,25,25,24,23]

## 答案

**正确答案：** C

## 解析

该程序使用栈保存尚未找到右侧更大元素的下标。选项 C 中，4 的下一个更大值是5，5和2的下一个更大值是25，而25、24、23右侧均没有更大值，输出正好为 [5,25,25,-1,-1,-1]。其余选项至少有一个位置的下一个更大值不同。
