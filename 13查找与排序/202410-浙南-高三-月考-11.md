# 题目 11

有如下 Python 程序段：

```python
# 随机产生包含10个整型元素的升序序列，依次存入列表a，代码略
i, j = 0, len(a) - 1
key = int(input())
b = []
while i <= j:
    m = (i + j) // 2
    b.append(a[m])
    if a[m] > key:
        j = m - 1
    else:
        i = m + 1
print(b)
```

运行该程序段后，`b` 的结果不可能是（   ）

- A. `[18,6,2]`
- B. `[20,9,13,18]`
- C. `[14,21,22]`
- D. `[23,30,25,22]`

---

## 答案

**正确答案：** D

---

## 解析

列表 `a` 为升序，`b` 记录二分查找依次访问的中间元素。访问30后若向左查找，下一中间值25；继续向左时下一值必须小于25，但序列D给出22且其相对区间与前述中点路径不相容，因此D不可能。
