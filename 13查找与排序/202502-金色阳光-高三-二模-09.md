# 题目 9

某排序算法的 Python 程序段如下：

```python
a = [98, 66, 16, 78, 25, 69, 55, 78]
n = len(a)
c = 0
for i in range(n - 1):
    k = i
    for j in range(i + 1, n):
        if a[j] > a[k]:
            k = j
    if k != i:
        a[k], a[i] = a[i], a[k]
    c += 1
```

下列说法正确的是

- A. 程序段执行后，`a` 中的元素为 `[16,25,55,66,69,78,78,98]`
- B. 将代码 `if a[j]>a[k]:` 修改为 `if a[j]>=a[k]:`，不会影响程序的运行结果
- C. 若某一轮中没有数据交换，则说明 `a` 数组已经有序
- D. 程序段执行后，`c` 的值为 5

## 答案

**参考答案：** B

## 解析

该程序每轮选择剩余部分的最大值，最终按降序排列；`c` 在外层循环的每一轮都加 1，共为 7。将 `>` 改为 `>=` 只会在相等元素间改变选中的下标，不改变最终元素值和程序结果，因此 B 正确。
