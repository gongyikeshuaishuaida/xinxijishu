# 题目 10

如下 Python 程序段：

```python
# 导入模块并随机产生 8 个整型元素的非降序的奇数序列
# 依次存入列表 a（a[0]~a[7]），代码略
key = random.randint(1, 20)
i = 0
j = 7
s = 0
while i <= j:
    m = (i + j + 1) // 2
    if a[m] == key:
        break
    if a[m] > key:
        j = m - 1
    else:
        i = m + 1
    s += 1
```

执行上述程序段后，下列说法不正确的是（   ）

- A. `a[j]` 可能小于 `a[i] + 2`
- B. `a[i]` 可能等于 `key`
- C. `i` 一定等于 `j + 1`
- D. `s` 的值一定小于等于 4

## 答案

**正确答案：** C

## 解析

若查找过程中 `a[m] == key`，程序会直接 `break`，此时不保证 `i=j+1`。未命中时区间才会不断缩小并越过；8 个元素的二分查找比较次数不超过 4。
