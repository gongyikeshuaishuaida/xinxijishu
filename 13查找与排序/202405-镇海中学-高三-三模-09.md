# 题目 09

运行下列程序，输出结果不可能的是（ ）

```python
from random import randint
from math import sqrt

a = []
for i in range(6):
    a.append(randint(5, 10) * 2)
for i in range(6):
    for j in range(len(a) - 1, i, -1):
        if a[j] > a[j - 1] and sqrt(a[j]) != int(sqrt(a[j])):
            a[j], a[j - 1] = a[j - 1], a[j]
print(a)
```

- A.`[20,12,12,10,16,10]`
- B.`[20,18,16,14,10,14]`
- C.`[18,16,14,12,12,10]`
- D.`[16,14,12,10,10,10]`

---

## 答案

**正确答案：** B

---

## 解析

数组元素均为 10、12、14、16、18、20 中的偶数。循环只会把非完全平方数（除 16 外）中较大的元素向前交换，完全平方数 16 不会主动参与交换。选项 B 中 20、18、16、14、10、14 末尾出现了被交换关系无法产生的逆序结构，程序不可能输出 B。
