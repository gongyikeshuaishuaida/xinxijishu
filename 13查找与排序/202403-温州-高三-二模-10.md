# 题目 10

列表 `a` 中 `a[0]` 至 `a[4]` 的值依次为 9、2、5、1、3，分别执行下列两段程序，数据交换次数分别是（   ）

```python
for i in range(1, len(a) - 1):
    for j in range(1, len(a) - i):
        if a[j - 1] > a[j]:
            a[j], a[j - 1] = a[j - 1], a[j]

for i in range(len(a) - 1, 1, -1):
    for j in range(len(a) - 1, len(a) - i, -1):
        if a[j - 1] > a[j]:
            a[j], a[j - 1] = a[j - 1], a[j]
```

- A. 1 和 3
- B. 5 和 5
- C. 5 和 3
- D. 7 和 7

## 答案

**正确答案：** C

## 解析

第一段从左向右比较相邻元素，完成排序所需交换 5 次；第二段从右向左比较，交换 3 次。因此选 C。
