# 题目 12

某对分查找算法的部分程序如下：

```python
def search(a, key):
    i = 0
    j = len(a) - 1
    s = ""
    while i <= j:
        m = (i + j) // 2
        if a[m] == key:
            return s
        elif key < a[m]:
            s += "L"
            j = m - 1
        else:
            s += "R"
            i = m + 1
    return s

key = int(input("请输入待查数据："))
result = search(a, key)
print(result)
```

按非降序排序的整型数组 `a` 的值依次为 `10,25,30,41,47,50,61,x,70,87`。如果输入 `key` 的值为 67，执行程序后显示结果为 `RRL`，则 `x` 的可能值个数为（   ）

- A. 5
- B. 6
- C. 8
- D. 9

---

## 答案

**正确答案：** B

---

## 解析

第一次比较下标 4 的 47，向右；第二次比较下标 7 的 `x`，仍向右，故 `x<67`；第三次比较下标 8 的 70，向左。数组非降序且前一项为 61，所以 `x` 可取 61～66，共 6 个整数。
