# 题目 11

有如下 Python 程序段：

~~~python
a=[100,90,15,40,72,65,32,81,6]
b=[8,2,6,3,5,4,7,1,0]
i=0
j=len(a)-1
c=0
key=72
while i<=j:
    m=(i+j)//2
    if a[b[m]]==key:
        break
    elif a[b[m]]<key:
        i=m+1
    else:
        j=m-1
    c+=1
~~~

程序执行结束后变量 c 的值为（   ）

- A. 4
- B. 3
- C. 2
- D. 1

## 答案

**正确答案：** C

## 解析

通过索引数组 b 访问 a 后，实际参与二分查找的有序序列为 [6,15,32,40,65,72,81,90,100]。第一次比较中间值 65，小于 72，c 加 1；第二次比较 81，大于 72，c 再加 1；第三次比较得到 72，执行 break，c 不再增加，所以 c=2。
