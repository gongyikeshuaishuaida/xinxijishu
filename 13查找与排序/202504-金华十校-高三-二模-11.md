# 题目 11

有如下 Python 程序：

```python
import random
i,j = 0, len(a) - 1
key = random.randint(1, 47)
while i <= j:
    mid = (i+j)//2       # 语句①
    if a[mid] <= key:    # 语句②
        i = mid + 1
    else:
        j = mid - 1
print(j)
```

当 `a` 为 `[5, 12, 19, 26, 33, 33, 48, 50]`，运行程序，下列说法正确的是（   ）

- A. 语句①执行的次数可能为 4
- B. 语句①改为“`mid = (i + j + 1) // 2`”，程序结果不会改变
- C. 语句②改为“`a[mid] < key`”，程序结果不会改变
- D. 若生成的 `key` 是 33，则输出结果是 4

---

## 答案

**正确答案：** B

---

## 解析

程序是在有序数组中查找最后一个不大于 `key` 的位置。将中点改为上取整中点仍能保持同样的区间收缩方向和最终结果；原数组长度为 8 时循环次数不可能达到 4，改变比较条件会改变重复值的处理方式，`key=33` 时输出为 5 而不是 4。
