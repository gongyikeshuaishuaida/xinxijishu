# 题目 11

某二分查找算法的 Python 程序段如下：

```python
n = int(input())
c = 0
d = [1, 2, 3, 4, 5, 6]
for k in range(0, len(d), n):
    i = 0
    j = len(d) - 1
    key = d[k]
    while i <= j:
        m = (i + j) // 2
        c += 1
        if key == d[m]:
            break
        elif key < d[m]:
            j = m - 1
        else:
            i = m + 1
print(c)
```

执行程序段后，输入以下不同的 `n` 值，输出结果与其它三个不同的是（   ）

- A. 2
- B. 3
- C. 4
- D. 5

---

## 答案

**正确答案：** C

---

## 解析

分别统计每个 `n` 对应的查找次数总和：`n=2` 时为 5，`n=3` 时为 5，`n=4` 时为 4，`n=5` 时为 5。只有输入 4 时输出不同。
