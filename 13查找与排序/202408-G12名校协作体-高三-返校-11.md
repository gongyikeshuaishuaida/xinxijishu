# 题目 11

有如下 Python 程序段：

```python
a = [13, 23, 34, 44, 55, 67, 78, 80, 85, 90]
i = 0
j = 9
s = [-1] * 4
top = -1
n = 0
key = int(input())
while i <= j:
    m = (i + j) // 2
    if a[m] >= key:
        j = m - 1
        n += 1
        top += 1
        s[top] = m
    else:
        i = m + 1
        n -= 1
        if top != -1:
            top -= 1
```

下列有关该程序段的说法，正确的是（   ）
- A. `i` 的值不一定等于 `j + 1`
- B. `n` 的值最小为 -3，最大为 4
- C. 输入任意 `key` 的值，`top` 的最大值为 3
- D. 若输入 `key` 的值为 67，则 `s` 的值为 `[7, 5, -1, -1]`

---

## 答案

**正确答案：** D

---

## 解析

输入 key=67 时，中点下标依次为4、7、5。下标7和5满足 a[m]>=key，依次压入 s，循环结束后 s=[7,5,-1,-1]，所以 D 正确。
