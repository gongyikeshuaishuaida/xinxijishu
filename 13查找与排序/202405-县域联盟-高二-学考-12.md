# 题目 12

12.书画大赛邀请8位评委，选手总分为8个评分之和去掉1个最高分和1个最低分。`scores.txt` 每行包含4位选手编号和8个评分。

![[attachments/202405县域高二_12_评分文件.jpg]]

（1）主程序按总分从高到低输出：

```python
data = caltotal('scores.txt')
flag = [True] * len(data)
for i in range(len(data)):
    pos = findmax(data, flag)
    flag[pos] = ______
    print(data[pos][0], data[pos][1])
```

（2）`caltotal` 读文件并计算总分：

```python
def caltotal(filename):
    f = open(filename); line = f.readline(); data = []
    while line:
        xs = ______
        sp = line[5:].split(',')
        s = tot(sp)
        data.append([xs, s])
        line = f.readline()
    return data
```

（3）`tot(sp)` 中遍历全部评分：`for i in range(______):`。

（4）`findmax(data,flag)` 中的 if 条件从未使用数据中找最大分，应选：

- A.`maxnum<data[i][1]`
- B.`maxnum<data[i][1] and flag`
- C.`maxnum<data[i][1] and flag[i]`
- D.`maxnum<data[i][1] and not flag[i]`

---

## 答案

**正确答案：** （1）`False`；（2）`line[:4]`；（3）`len(sp)`（或 `0,len(sp)`）；（4）C

---

## 解析

每次选出最高分后把对应 `flag[pos]` 置为 False，避免重复使用。编号是每行前4个字符；评分列表长度为 `len(sp)`。找最大值时必须同时满足分数更大且 `flag[i]` 为 True，因此选 C。
