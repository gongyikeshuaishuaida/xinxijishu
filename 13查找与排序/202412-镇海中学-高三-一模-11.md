# 题目 11

有如下 Python 程序段：

```python
d = [9, 3, 1, 8, 4, 2]
s = [0, 1, 2, 3, 4, 5]
n = len(d)
for i in range(1, n):
    key = s[i]
    j = i - 1
    while j >= 0 and d[s[j]] > d[key]:
        s[j + 1] = s[j]
        j -= 1
    s[j + 1] = key
    print(s)
```

执行该程序过程中，第 4 次（从 1 开始计数）输出的内容为（   ）

- A. `[2,5,1,4,3,0]`
- B. `[2,1,3,0,4,5]`
- C. `[2,1,4,3,0,5]`
- D. `[2,1,0,3,4,5]`

---

## 答案

**正确答案：** C

---

## 解析

程序不改变 `d`，而是对下标列表 `s` 按 `d[s[i]]` 的值执行插入排序。第 4 轮结束后，`d` 的前 5 个元素按值排列为 1、3、4、8、9，对应原下标为 2、1、4、3、0，未参与该轮排序的下标 5 保持在末尾，故输出 `[2,1,4,3,0,5]`。
