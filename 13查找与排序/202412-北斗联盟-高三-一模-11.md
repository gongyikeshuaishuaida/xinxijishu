# 题目 11

实现查询功能的 Python 程序段如下，输出结果如第 11 题图所示。

```python
# 将文件 cj.csv 有序数据存入数组 a 中，并输出，代码略
Key=int(input('输入需要查找的分数：'))
i=1;j=len(a)-1
while i<=j:
    ______①______
    if ______②______:
        j=m-1
    else:
        i=m+1
while ______③______:
    print(a[i])
    i=i+1
```

![[attachments/202412北斗联盟_11_查询输出表.png]]

请在 ①②③ 处选择正确代码（   ）

- A. ① `m=(i+j+1)//2`　② `a[m][2]<key`　③ `a[i][2]==key`
- B. ① `m=(i+j)//2`　② `a[m][2]<=key`　③ `a[j][2]==key`
- C. ① `m=(i+j+1)//2`　② `a[m][2]<=key`　③ `a[m][2]==key`
- D. ① `m=(i+j)//2`　② `a[m][2]<=key`　③ `a[i][2]==key`

## 答案

**正确答案：** D

## 解析

表中“总分”按降序排列。二分查找取中点 `m=(i+j)//2`；当 `a[m][2]` 小于或等于目标分数时，应把右边界移到 `m-1`，否则把左边界移到 `m+1`。查找到目标分数的第一个位置后，连续输出时应检查当前下标 `i` 的总分是否仍等于 `key`，所以选择 D。
