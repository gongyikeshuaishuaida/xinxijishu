# 题目 11

定义如下函数，返回 `key` 在列表 `data` 中的下标，若 `key` 不存在，则返回 `-1`。

```python
def search_key(data, key):
    i, j = 0, len(data) - 1
    while i <= j:
        m = (i + j) // 2
        for pos in [m, m + 2]:
            if i <= pos <= j and data[pos] == key:
                return pos
        if data[m] < key:
            i = m + 1
        else:
            j = m - 1
    return -1
```

若调用函数查找 `key = 22` 时返回结果为 `-1`，则 `data` 可能是（   ）

- A. `[35,30,25,22,20,15,10]`
- B. `[10,15,20,22,25,30,35]`
- C. `[35,22,30,25,20,15,10]`
- D. `[10,22,15,20,25,30,35]`

---

## 答案

**正确答案：** D

---

## 解析

程序按升序二分逻辑更新区间。D并非有序，22会被错误排除且未落在每轮检查的`m`或`m+2`位置，因而可能返回-1。
