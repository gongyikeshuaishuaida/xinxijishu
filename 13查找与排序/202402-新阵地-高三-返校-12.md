# 题目 12

有如下 Python 程序段：

```python
a = [12, 30, 32, 37, 37, 37, 49, 49, 60, 70]
i = 0; j = 9; key = 37; c = 0
while i <= j:
    m = (i + j) // 2
    if key < a[m]:
        j = m - 1
    else:
        i = m + 1
        c += 1
```

该程序段运行结束后，下列说法不正确的是（  ）

A．i 的值一定为 j+1

B．i 的值是 6

C．j 的值是 2

D．c 的值为 4

## 答案

**正确答案：** C

## 解析

运行过程的中间值为 `m=4`、`7`、`5`、`6`，结束时 `i=6`、`j=5`、`c=4`。因此 `i=j+1`、`i=6`、`c=4` 均正确，`j` 并不是 2。
