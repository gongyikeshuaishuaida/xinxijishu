# 题目 15

设计一个简单的快递算法。有`n`位骑手为一个大型超市提供同城配送服务，每送完一单后骑手需回超市取货。骑手先送优先级高的订单；若优先级相同，则先送距离近的订单。忽略路况及取货、卸货时间，可将距离转换成单程配送时间，优先级数字越小表示优先级越高。

![[attachments/202404宁波_15_订单表.jpg]]

（1）若订单如图所示，并有2位骑手甲和乙，订单总是先派给空闲的骑手；若两人都空闲，则先给甲。订单“C”的顾客需要等待 ______①______ 分钟。

（2）定义`sort_bag(a)`函数，将列表`a`中的订单按优先级和配送时间排序。程序加框处代码有错，请改正，并补充划线处。

```python
def sort_bag(a):
    n = len(a)
    for i in range(n - 1):
        for j in range(i, n - i):  # 加框处
            if a[j][0] > a[j+1][0]:
                a[j], a[j+1] = a[j+1], a[j]
            elif ______③______:
                a[j], a[j+1] = a[j+1], a[j]
    return a
```

加框处应改为 ______②______。

（3）以下代码模拟派送过程，并计算顾客的平均等待时长和订单完成总时间，请补全程序。

```python
if ______④______:
    rider[j] = rider[j] + data[i][1] * 2
    waittime = waittime + ______⑤______
```


---

## 答案

**正确答案：** ① 18；② `range(i, n - i - 1)`；③ `a[j][0] == a[j + 1][0] and a[j][1] > a[j + 1][1]`；④ `rider[j] <= nowtime`；⑤ `nowtime + data[i][1]`

---

## 解析

优先级 1 的 E、G 先分配给两位骑手，随后 D、F 由先空闲的骑手处理，C 在时刻 12 分配并在 18 分钟送达；排序内层循环上界应为 `n-i-1`，同优先级时比较配送时间；模拟时空闲条件为 `rider[j]<=nowtime`，顾客等待时间为 `nowtime+data[i][1]`。
