# 题目 11

有如下 Python 程序段：

```python
import random
def bs(key, i, j):
    m = (i + j) // 2
    v.append(a[m])
    if a[m] == key or i > j:
        return len(v)
    elif a[m] > key:
        return bs(key, i, m - 1)
    else:
        return bs(key, m + 1, j)

a = [2, 4, 7, 11, 13, 16, 20, 25];  v = []
key = random.randint(1,9) * 2 + 1
print(bs(key, 0, len(a) - 1))
```

执行该程序段后，输出的结果不可能是（   ）

- A. 1
- B. 2
- C. 3
- D. 4

## 答案

**正确答案：** B

## 解析

`key` 的取值为 3、5、7、9、11、13、15、17、19。第一次访问中间位置 3 的元素 11；当 `key=11` 时输出 1，其他取值需要继续递归，可能得到 3 或 4 次比较。输出 2 的情况不会出现，因此选择 B。
