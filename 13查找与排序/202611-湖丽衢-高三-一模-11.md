# 题目 11

有如下 Python 程序段：

```python
def find_free(d):
    i,j=0,len(d)-1
    while i<=j:
        m=(i+j)//2
        if d[m]==0:
            return m
        if m>i and d[m-1]==0:
            j=m-1
        elif m<j and d[m+1]==0:
            i=m+1
        else:
            i=m+3
    return -1
```

执行语句 `v=find_free(d)` 后，v 的值为 -1，则 d 可能是（   ）

- A. `[0,0,1,1,1,1,1]`
- B. `[0,0,0,1,1,1,1]`
- C. `[0,0,0,0,0,1,1]`
- D. `[0,0,0,0,0,0,1]`

---

## 答案

**正确答案：** A

---

## 解析

A 首次取中点 3，两侧相邻值均为 1，之后左界移到 6，最终越过右界。其余在下标 2 或 3 命中 0。
