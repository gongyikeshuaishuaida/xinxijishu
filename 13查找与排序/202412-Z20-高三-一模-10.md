# 题目 10

有如下 Python 程序段：

```python
a=[9,7,2,5,2,8]
for i in range(len(a)-1):
    for j in range(len(a)-1,i,-1):
        if a[j] > a[j-1]:    # 语句①
            a[j],a[j-1] = a[j-1],a[j]
```

执行上述程序段后，下列说法正确的是（   ）

- A. 语句①的执行次数为 30
- B. 若问题规模为 n，则该程序段的时间复杂度为 O(log₂n)
- C. 将代码中的“j-1”改为“j+1”，可以实现数组 a 升序排序
- D. 将加框处的语句修改为“range(1,len(a)-i)”，程序执行的结果无变化

## 答案

**正确答案：** D

## 解析

原程序各轮比较次数之和为 5+4+3+2+1=15，不是 30；双重循环的时间复杂度为 O(n²)；把 `j-1` 改为 `j+1` 会改变访问方向并可能越界，不能直接实现升序排序。将内层循环改为从 1 到 `len(a)-i-1`，对本组数据执行后的结果仍为 `[9,8,7,5,2,2]`，因此 D 正确。
