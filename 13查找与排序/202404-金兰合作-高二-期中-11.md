# 题目 11

11.有如下 Python 程序段：

```python
n = int(input())
a = [0] * 10
i = 2
j = 0
while n > i:
    if n % i == 0:
        n //= i
        a[j] = i
        j += 1
    else:
        i += 1
a[j] = n
for i in range(10):
    if a[i] > 0:
        print(a[i], end=" ")
```

输入 `126`，输出结果是（ ）

- A. `23371`
- B. `2337126`
- C. `2337`
- D. `237126`

---

## 答案

**正确答案：** C

---

## 解析

程序不断提取最小因子，`126=2×3×3×7`，依次输出 `2 3 3 7`，故选 C。
