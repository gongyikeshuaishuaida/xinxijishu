# 题目 11

`a` 为非递减顺序排列的整数列表（非空）。函数 `f(a)` 的功能是：利用二分查找确定候选元素，再从中找出并返回与列表所有元素的平均值最接近的元素；若有两个不同元素与平均值的距离相同，则返回较小的元素。

```python
def f(a):
    n = len(a); s = sum(a)  # sum(lst)：返回列表lst元素之和
    lo, hi = 0, n - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if ______①______:
            i = mid
            hi = mid - 1
        else:
            lo = mid + 1
    cands = []
    if i - 1 >= 0: cands.append(a[i - 1])
    if i < n: cands.append(a[i])
    best = cands[0]
    for x in cands[1:]:
        if ______②______:
            best = x
    return best
```

可选择的代码如下：① `n * a[mid] >= s`　② `n * a[mid] > s`　③ `abs(n * x - s) < abs(n * best - s)`　④ `abs(n * x - s) > abs(n * best - s)`

则划线处依次填入的代码是（   ）

- A. ①③

- B. ②③

- C. ①④

- D. ②④

---

## 答案

**正确答案：** A

---

## 解析

用 `n*a[mid] >= s` 找第一个不小于平均值的元素，与其前驱构成候选。候选按从小到大遍历，只在距离严格变小时替换，可在距离相同时保留较小者。
