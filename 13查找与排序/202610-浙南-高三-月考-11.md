# 题目 11

有如下Python程序段：

```python
for i in range(1, n):
    for j in range(____________):
        if d[j] > d[j + 1]:
            d[j], d[j + 1] = d[j + 1], d[j]
```

划线处可选的表达式有：

① `0, n - i`；② `i, n - 1`；③ `n - 2, i - 2, -1`；④ `n - i - 1, -1, -1`；⑤ `0, n - 2`；⑥ `n - 2, -1, -1`。

其中能实现对数组`d`中的元素升序排列的有（   ）

- A. 1个
- B. 3个
- C. 4个
- D. 6个

---

## 答案

**正确答案：** B

---

## 解析

可行的是①、③、⑥，共3个。①从左向右比较，每轮将当前最大值放到未排序部分右端；③从右向左比较，每轮将当前最小值放到未排序部分左端；⑥每轮从右向左完整扫描，经过 `n-1` 轮也能排好。②会一直漏掉下标0；⑤会一直漏掉最后一对相邻元素；④虽从右向左扫描，却错误地逐轮缩小右边界。例如初始 `[3,2,1]`，④最终仍为 `[1,3,2]`。
