# 题目 11

11.班里有 `n` 位同学，学号 0 至 `n-1`，其中一人未交作业。已交作业的 `n-1` 个学号升序存于 `a`，二分查找代码如下：

```python
L, R = 0, n-2
while L <= R:
    m = (L + R) // 2
    if a[m] == m:
        ①
    else:
        ②
print(③)
```

- A. ① `R=m-1`；② `L=m+1`；③ `L`
- B. ① `R=m-1`；② `L=m+1`；③ `R`
- C. ① `L=m+1`；② `R=m-1`；③ `L`
- D. ① `L=m+1`；② `R=m-1`；③ `R`

---

## 答案

**正确答案：** C

---

## 解析

若 `a[m]==m`，缺失学号在右侧，令 `L=m+1`；否则缺失号在左侧，令 `R=m-1`；循环结束时 `L` 即缺失学号，故选 C。
