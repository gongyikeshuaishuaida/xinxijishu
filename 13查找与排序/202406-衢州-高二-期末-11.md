# 题目 11

11. 有如下 Python 程序段：

~~~python
from random import randint
a=[0]*5
for i in range(5):
    a[i]=randint(-4,4)*2+1
for i in range(1,5):
    k=a[i]
    j=i-1
    while j>=0 and a[j]<k:
        a[j+1]=a[j]
        j-=1
    a[j+1]=k
~~~

执行后列表 a 的值可能是（ ）

- A. [-9, 5, 3, 1, 1]
- B. [7, 5, 1, 1, -5]
- C. [7, 3, 0, -5, -1]
- D. [-3, -1, 1, 3, 9]

---

## 答案

**正确答案：** B

---

## 解析

程序是按降序进行插入排序，随机生成的数一定为奇数，B 满足降序且全部为奇数；A 不是降序，C 含偶数 0，D 为升序，故选 B。
