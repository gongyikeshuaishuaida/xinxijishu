# 题目 11

11. 某二分查找算法的 Python 程序段如下：

~~~python
key,cnt = 5,0
i,j = 0,len(d)-1
while i <= j:
    cnt += 1
    m = (i+j)//2
    if key == d[m]:
        break
    elif key < d[m]:
        j = m-1
    else:
        i = m+1
~~~

当 d 为 [2,4,5,6,7,8,9] 时，在 d 中插入一个元素 x，维持 d 为一个非降序序列，在元素 x 插入前后分别运行程序段，若变量 cnt 的值相同，则增加的元素 x 可能是（   ）

- A. 2
- B. 3
- C. 4
- D. 6

---

## 答案

**正确答案：** D

---

## 解析

逐项按非降序插入并模拟二分查找。插入 6 后，查找键值 5 的比较路径长度保持不变，cnt 与原序列相同；其余选项会改变查找区间的中点路径，故选 D。
