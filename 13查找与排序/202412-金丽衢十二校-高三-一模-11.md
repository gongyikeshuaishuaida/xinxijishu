# 题目 11

如下 Python 程序段实现对数组元素 `a[0]` 到 `a[5]` 升序排序：

```python
a = [27, 34, 53, 54, 55, 42]
n = len(a)
start = 0
while start != n - 1:       # 语句①
    last = n - 1
    for j in range(n - 1, start, -1):
        if a[j] < a[j - 1]:  # 语句②
            a[j], a[j - 1] = a[j - 1], a[j]  # 语句③
            last = j
    start = last
print(a)
```

下列关于运行该程序段后的说法不正确的是（   ）

- A. 加框处代码第一次执行结束后 `start` 的值为 3
- B. 语句①可以修改为 `while start < n - 1:`
- C. 语句②执行了 6 次
- D. 语句③执行了 3 次

## 答案

**正确答案：** C

## 解析

第一次从后向前比较 5 次，将 42 依次移到下标 3，交换 3 次，所以第一次循环结束时 `start=3`。第二次循环的 `j` 取 5、4，还要比较 2 次但不交换，因此语句②总共执行 `5+2=7` 次；语句③只执行 3 次。将循环条件改为 `start<n-1` 与当前条件等价，所以不正确的是 C。
