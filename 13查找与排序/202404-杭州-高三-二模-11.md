# 题目 11

有如下 Python 程序段：

```python
# 随机产生5个整数，存储在列表a中
for i in range(1,5):
    k = a[i]
    j = i-1
    while j >= 0 and abs(a[j]-2) > abs(k-2):
        a[j+1] = a[j]
        j -= 1
    a[j+1] = k
```

执行该程序段后，列表 `a` 的值可能是（   ）

- A. [-5, -2, 4, 0, 1]
- B. [3, -1, 0, 2, -3]
- C. [1, 2, 3, 4, 5]
- D. [0, 4, 0, -2, -4]

## 答案

**正确答案：** D

## 解析

程序按元素与 2 的绝对差从小到大进行插入排序。D 中绝对差依次为 2、2、2、4、6，满足非递减；其他选项的绝对差序列均不满足。
