# 题目 10

有如下 Python 程序段：

```python
k = random.randint(2, 4)
for i in range(1, k):
    for j in range(i, 0, -1):
        if a[j] < a[j - 1]:
            a[j], a[j - 1] = a[j - 1], a[j]
```

若 `a=[14,11,2,1,20,16]`，运行该程序段后，`a` 的结果不可能是（   ）

- A. `[11,14,2,1,20,16]`
- B. `[2,11,14,1,20,16]`
- C. `[1,2,11,14,20,16]`
- D. `[1,2,11,14,16,20]`

---

## 答案

**正确答案：** D

---

## 解析

`k` 只可能为2、3、4，循环只对前 `k` 个元素执行插入排序，后两个元素20、16不会被交换，因此不可能得到把16排到20之前的 D。
