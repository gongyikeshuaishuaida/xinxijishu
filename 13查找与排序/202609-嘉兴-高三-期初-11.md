# 题目 11

对数组a执行排序算法：每一轮处理当前未排序区间，采用双向遍历方式。先从左向右扫描，将区间内最大值逐步移动至区间右端；再从右向左扫描，将区间内最小值逐步移动至区间左端。重复上述过程，直至整个数组按升序排列。实现该功能的部分Python程序段如下：

```python
m1 = 0; m2 = len(a) - 1
while m1 < m2:
    for i in range(m1, m2):
        if ______①______:
            a[i], a[i + 1] = a[i + 1], a[i]
    m2 -= 1
    for i in range(m2, ______②______, -1):
        if a[i] < a[i - 1]:
            a[i], a[i - 1] = a[i - 1], a[i]
    m1 += 1
```

则划线处①②应填入的代码是（   ）

- A. ①`a[i] > a[i + 1]`　②`m1`
- B. ①`a[i] > a[i + 1]`　②`m1+1`
- C. ①`a[i] < a[i + 1]`　②`m1`
- D. ①`a[i] < a[i + 1]`　②`m1+1`

---

## 答案

**正确答案：** A

---

## 解析

正向扫描要把最大值移到区间右端，相邻两数逆序（前大后小）时才交换，故①为`a[i] > a[i + 1]`，排除C、D。反向扫描要将最小值移到区间左端，i最小时应比较`a[m1+1]`与`a[m1]`，即range的终点（取不到）为m1，②为`m1`；若填`m1+1`，则i最小只到m1+2，`a[m1]`不参与比较，最小值无法到达左端。故选A。
