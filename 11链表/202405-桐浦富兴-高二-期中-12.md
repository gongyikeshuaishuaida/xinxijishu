# 题目 12

12.有如下 Python 代码，函数 `Linkinsert` 的功能是在升序链表 `lst` 中按序插入数据 `data`：

```python
def Linkinsert(lst, data, head):
    p = head
    lst.append([data, -1])
    if data <= lst[head][0]:
        lst[-1][1] = head
        head = len(lst)-1
    else:
        q = lst[p][1]
        while ① and data > lst[q][0]:
            p = q
            q = lst[p][1]
        ②
        lst[-1][1] = q
    return head
```

- A.① `q!=-1`；② `lst[p][1]=len(lst)-1`
- B.① `q!=-1`；② `lst[p][1]=len(lst)`
- C.① `p!=-1`；② `lst[q][1]=len(lst)-1`
- D.① `p!=-1`；② `lst[q][1]=len(lst)`

---

## 答案

**正确答案：** A

---

## 解析

q 是待比较的后继指针，必须先判断 `q!=-1` 才能访问 `lst[q]`。循环结束后，新节点应接到 q 前面，并令前驱 p 指向新节点下标 `len(lst)-1`，故选 A。
