# 题目 12

有如下Python程序：

```python
lnk = [[1, 1], [2, 2], [3, 3], [4, 4], [5, -1]]
head = 0
for i in range(len(a)):
    p = head
    while p != -1 and a[i][0] != lnk[p][0]:
        q = p; p = lnk[p][1]
    if ______(1)______:
        if p == head:
            head = ______(2)______
        else:
            lnk[q][1] = lnk[p][1]
    else:
        if lnk[p][1] != -1:
            lnk[p][1] = ______(3)______
```

若`a`为`[[1, 1], [2, 0], [2, 1]]`，运行程序段后，`lnk`为`[[1, 1], [2, 3], [3, 3], [4, 4], [5, -1]]`，`head`为3。

程序段中(1)～(3)处可选语句为：

① `a[i][1] == 0`；② `a[i][1] == 1`；③ `q`；④ `lnk[q][1]`；⑤ `lnk[p][1]`；⑥ `lnk[lnk[p][1]][1]`。

则(1)～(3)处语句序号依次为（   ）

- A. ①④⑥
- B. ①⑤⑥
- C. ②③④
- D. ②⑤⑥

---

## 答案

**正确答案：** D

---

## 解析

标志为1时删除当前节点，删除头节点应令 `head = lnk[p][1]`；标志为0时删除当前节点的后继，应令 `lnk[p][1] = lnk[lnk[p][1]][1]`。执行 `[1,1]` 后 `head=1`；执行 `[2,0]` 后，下标1节点跳过下标2节点，后继改为3；执行 `[2,1]` 后删除当前头节点，下一个头节点为下标3。最终数组与题干一致，三处依次为②⑤⑥。
