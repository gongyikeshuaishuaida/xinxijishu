# 题目 15

15.有 n 个碗按碗口直径从小到大叠放，自上而下编号 `0~n-1`，容量为 `w[i]`，溢出的水流入下面的碗。程序用数组节点 `[水量, 前驱, 后继]` 维护碗的双向链表。

![[attachments/202405-五校联盟-高三-三模-15_横排1_2.png]]

（1）容量 `[5,10]` 时，执行 `[1,0,4]、[2,0]、[1,1,5]、[1,0,4]、[2,0]、[2,1]` 后，编号1碗中的水量为 ______。

（2）从代码看，使用的数据结构是（填字母）：A.单向链表 / B.双向链表 / C.循环链表 / D.数组。

（3）初始化节点的加框代码时间复杂度为 ______（大 O）。

（4）删除节点函数中空格应填：

```python
def delete(pos):
    global a, head
    if pos == head:
        head = a[pos][2]
    else:
        ①
        a[a[pos][2]][1] = a[pos][1]
```

（5）向第 p 个碗加水时，补全：

```python
if p >= u:
    ②
    a[p][0] += water
    x -= water
    if ③:
        delete(p)
    p = a[p][2]
```

---

## 答案

**正确答案：** （1）8；（2）B；（3）`O(n)`；（4）①`a[a[pos][1]][2]=a[pos][2]`；（5）②`water=min(x,w[p]-a[p][0])`；③`a[p][0]==w[p]`

---

## 解析

每次加水先填当前碗，超过容量的部分继续流向后继节点；删除已满碗时同时修改前驱和后继指针，因此是双向链表。初始化 n 个节点需线性时间。题设操作中先给1号碗5单位，再由0号碗溢出3单位，最终1号碗为8。
