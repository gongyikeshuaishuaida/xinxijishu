# 题目 11

有如下 Python 程序段，链表 `lst` 中每个元素由数据和指针两个数据项组成，数据可能重复且呈升序排列。若链表初始状态如图，执行完程序段后链表 `lst` 更新为（   ）

~~~python
# 链表 lst 中每个元素由数据和指针两个数据项组成
p1 = head
p2 = lst[p1][1]
while p2 != -1:
    if lst[p1][0] == lst[p2][0]:
        p2 = lst[p2][1]
        lst[p1][1] = p2
    else:
        p1 = p2
        p2 = lst[p2][1]
~~~

![[attachments/202406温州十校_11_链表图.jpg]]

- A. `1→2→3→4→-1`
- B. `4→3→3→2→1→1→-1`
- C. `4→3→2→1→-1`
- D. `1→1→2→3→3→4→-1`

---

## 答案

**正确答案：** A

---

## 解析

程序比较相邻节点数据，遇到重复值就跳过后一个节点并修改前驱指针，因此初始的 `1→1→2→3→3→4` 会去重为 `1→2→3→4`，选 A。
