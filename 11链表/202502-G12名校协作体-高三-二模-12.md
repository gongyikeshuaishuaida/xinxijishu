# 题目 12

有如下 Python 程序段，使用列表模拟升序链表 `link`，删除链表中的重复数据，仅保留下不重复的数据：

```python
link = [[2,1], [2,2], [2,3], [5,4], [6,-1]]
pre = head = 0
cur = link[pre][1]
while cur != -1:
    if link[pre][0] != link[cur][0]:
        ______①______
    else:
        ______②______
    ______③______
```

可选语句为：

- ① `cur=link[cur][1]`
- ② `pre=cur`
- ③ `link[pre][1]=link[cur][1]`

则（1）、（2）、（3）处正确的语句顺序是

- A. ③②①
- B. ③①②
- C. ②①③
- D. ②③①

## 答案

**参考答案：** D（②③①）

## 解析

当前节点数据与前一节点不同时，移动 `pre` 指针（②）；相同时把前一节点的后继直接改为当前节点的后继（③），跳过重复节点；最后沿原链表继续移动 `cur`（①）。
