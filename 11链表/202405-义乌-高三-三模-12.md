# 题目 12

链表 `a` 的节点由数据域和指针域构成，原链表按数据域升序排列，现要调整为奇数在前升序、偶数在后升序。程序和调整前后示意图如下：

![[attachments/202405义乌高三_12_链表结构图.jpg]]

```python
a = [[8,1],[9,-1],[6,0],[1,5],[5,2],[2,4]]
p = t = head = 3
while a[t][1] != -1:
    k = a[t][1]
    if a[k][0] % 2 == 1:
        # 此处填入四条语句
        ______①______
        ______②______
        ______③______
        ______④______
    else:
        t = a[t][1]
```

四条语句的选项为：

- A.`a[t][1]=a[p][1]`；`a[p][1]=t`；`p=t`；`t=k`
- B.`a[t][1]=a[k][1]`；`a[k][1]=a[p][1]`；`a[p][1]=k`；`p=a[p][1]`
- C.`a[p][1]=t`；`a[t][1]=a[p][1]`；`p=a[p][1]`；`t=k`
- D.`t=a[t][1]`；`a[k][1]=a[p][1]`；`a[p][1]=k`；`p=k`

---

## 答案

**正确答案：** B

---

## 解析

当后继节点 `k` 的数据为奇数时，应先把 `k` 从当前扫描链中摘出：令 `a[t][1]=a[k][1]`；再把它接到当前奇数链尾 `p` 后面，并令 `p` 指向新奇数尾。选项 B 的四条语句能得到 `1→5→9→2→6→8` 的目标链表。
