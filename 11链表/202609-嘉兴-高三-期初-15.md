# 题目 15

某文具中转仓接收批量到货文具，所有文具规格相同，每件分配唯一正整数货号，文具到货先后顺序与货号大小无关。收到调拨需求时，执行如下操作：

①读取货号数据data，根据调拨需求reqs，用满足调拨时间的数据生成以区间起始货号升序排列的链表lst。

②根据调拨指定的目标货号进行区间检索。

③若未找到符合条件的区间，则取消本次调拨。

④若检索到该货号在区间内，且区间长度不小于调拨数量x，则调出从该区间起始货号开始的x件连续文具；否则取消本次调拨。

请回答下列问题:

（1）若按照如下表所示的到货数据，根据上述规则生成链表存储。若执行调拨需求`[14:30，3，519]`，目标货号所在区间在完成调拨后剩余文具的起止货号是（   ）

- A. 无剩余，区间删除
- B. `[522,522]`
- C. `[519,522]`
- D. `[519,521]`

## 答案

（1）A；（2）①`target > arr[mid][1]`；②4；（3）①`search(start_arr, reqs[i][2])`；②`seg_len >= need`（或 `end - start + 1 >= need`）；③`lst[prep][2] = lst[p][2]`

---

## 解析

（1）到货时间不迟于14:30的货号为512～515、517、519～521，合并成区间[512,515]、[517,517]、[519,521]。目标货号519位于[519,521]，区间长度3不小于调拨数量3，调出从519开始的3件后区间为空，故无剩余、区间删除，选A。

（2）①target未落入当前区间时，若大于该区间的结束货号则应在右侧继续查找，填`target > arr[mid][1]`；②长度为10的数组做二分查找，查找失败时循环体最多执行4次（每次区间约减半，10→4→2→1→0）。

（3）①pos是目标货号在有序区间数组start_arr中的下标，应调用`search(start_arr, reqs[i][2])`检索；②只有区间长度不小于调拨数量时才能调出，填`seg_len >= need`（即`end - start + 1 >= need`）；③区间被取空（起始货号越过结束货号）时删除该链表节点，将前驱节点的后继指针指向被删节点的后继，填`lst[prep][2] = lst[p][2]`。
