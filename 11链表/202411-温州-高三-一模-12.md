# 题目 12

使用列表 `a` 和 `d` 模拟 2 个链表结构（节点数均大于 0），头指针分别为 `ha` 和 `hd`，每个节点包含数据区域和指针区域，如下图所示。两个链表各节点均已按数据区域中数值升序排列，且 `a[ha][0] < d[hd][0]`。现要将 `d` 合并到 `a` 中形成降序链表结构。实现上述功能的 Python 程序段如下，方框中应填入的正确代码为（   ）

![[attachments/202411温州高三_12_链表结构图.png]]

~~~python
p = ha = 1
q = hd = 2
hnew = ha
p = a[p][1]
a[hnew][1] = -1
while p != -1 and q != -1:
    if a[p][0] < d[q][0]:
        ______①______
    else:
        a.append([d[q][0], hnew])
        hnew = len(a) - 1
        q = d[q][1]
~~~

- A.

~~~python
pnext = a[p][1]
a[p][1] = hnew
hnew = p
p = pnext
~~~

- B.

~~~python
a[p][1] = a[hnew][1]
a[hnew][1] = p
p = a[p][1]
~~~

- C.

~~~python
a[p][1] = hnew
hnew = p
p = a[p][1]
~~~

- D.

~~~python
pnext = a[p][1]
hnew = p
a[p][1] = hnew
p = pnext
~~~

---

## 答案

**正确答案：** A

## 解析

原链表按数据升序排列，目标链表要按降序排列，因此从 `a` 中取出当前节点时，需要用头插法接到新链表头部。修改 `a[p][1]` 前先保存后继节点 `pnext`，再令当前节点指向 `hnew`、更新头指针并让 `p` 后移，A 完整实现了这四步。
