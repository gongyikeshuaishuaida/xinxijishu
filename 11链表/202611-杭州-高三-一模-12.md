# 题目 12

有如下 Python 程序段，使用列表 `data` 模拟链表结构，每个节点包含数据区域和指针区域：

```python
import random
data = [[6, 5], [18, -1], [2, 0], [3, 4], [10, 1], [5, 6], [12, 3]]
head = 2
p = random.randint(0, len(data)-1)  # 随机生成一个[0, len(data)-1]范围内的整数
t = q = p
while data[q][1] != -1:
    r = data[q][1]
    if data[r][0] % data[p][0] == 0:
        if q == t:
            t = q = r
        else:
            data[q][1] = data[r][1]
            data[r][1] = data[t][1]
            data[t][1] = r
            t = r
    else:
        q = r
```

执行该程序段后，链表最后一个节点的数据不可能为（   ）

- A. 3

- B. 5

- C. 10

- D. 18

---

## 答案

**正确答案：** B

---

## 解析

原链表数据顺序为2、6、5、12、3、10、18。程序将 p 后面能被 p 数据整除的节点依次移动到 p 后的连续区域。枚举 p 的7种取值，最终尾节点数据只可能为3、10、18，不可能为5。
