# 题目 12

某音乐播放器用链表 `d`（元素格式为 `[歌曲编号, 后继偏移量]`）存储播放列表（播放列表首元素的前驱、末元素的后继均为-1），以下程序模拟从最后一首歌开始，连续执行 `k` 次“上一首”后，输出当前播放的歌曲编号。

```python
d = [[1, -2], [2, 4], [3, -1], [4, 3], [5, -3]]
head = 1; k = 3
pre, cur = -1, head
while cur != -1:
    tmp = pre
    pre = cur
    cur = tmp + d[cur][1]
______①______
for i in range(k):
    tmp = pre
    pre = cur
    ______②______
print(d[cur][0])
```

代码中划线处可选的表达式有：

① `pre = cur`　② `pre, cur = cur, pre`

③ `cur = pre - d[cur][1]`　④ `cur = tmp - d[cur][1]`

则划线处的表达式序号依次为（   ）

- A. ①③

- B. ①④

- C. ②④

- D. ②③

---

## 答案

**正确答案：** C

---

## 解析

第一段遍历结束时pre是尾节点，cur为-1。先交换二者，使cur指向尾节点、pre表示其后继。反向移动时根据“后继下标=前驱下标+偏移量”，得到前驱 `tmp-d[cur][1]`。
