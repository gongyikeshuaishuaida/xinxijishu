# 题目 11

使用二维数组 arr 模拟链表结构，每个节点数据依次为数据域和指针域，head 为链表头指针，链表已按数据域升序排序。现要删除链表中所有重复的节点，部分代码如下：

```python
def delete_duplicates(head):
    if head == -1:
        return -1
    dummy = len(arr)
    arr.append([-1, head])
    prev = dummy
    cur = head
    while cur != -1:
        if arr[cur][1] != -1 and arr[cur][0] == __________:  #①
            val = arr[cur][0]
            while cur != -1 and __________:  #②
                cur = arr[cur][1]
                __________ = cur  #③
        else:
            prev = cur
            cur = arr[cur][1]
    arr[prev][1] = -1
    return arr[dummy][1]
```

划线①②③处可填入的代码为（   ）

- A. ① `arr[arr[cur][1]][0]`；② `arr[cur][0] == val`；③ `arr[prev][1]`
- B. ① `arr[arr[cur][1]][0]`；② `arr[cur][0] == val`；③ `prev`
- C. ① `arr[cur][1][0]`；② `arr[pre][0] == val`；③ `arr[prev][1]`
- D. ① `arr[arr[cur][1]][0]`；② `arr[pre][0] == val`；③ `prev`

---

## 答案

**正确答案：** A

---

## 解析

链表已按数据域升序。①应比较当前节点与其后继节点的数据域，填 `arr[arr[cur][1]][0]`；发现重复后用 val 保存重复值，②判断当前节点数据是否仍等于 val；③应修改前驱节点的指针域 `arr[prev][1]`，三者组合为 A。
