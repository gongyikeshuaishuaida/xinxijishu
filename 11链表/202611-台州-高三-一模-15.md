# 题目 15

某果园管理员小江将采摘的 n 个苹果进行等级处理，根据每个苹果的重量、果径、着色率等特征数据将苹果划分为 k 个品质等级。分级步骤如下：

① 选取前 k 个苹果的特征数据作为各等级苹果划分的参考数据；

② 逐个取苹果与 k 个等级参考数据进行对比后，该苹果划分至与参考数据最相近的所属等级；

③ 计算各个等级内现有苹果特征数据的平均值，并将其更新为该等级的参考数据；

④ 重复步骤②、③，直至各个等级的参考数据不再变化，最终完成苹果的品质分级。

（1）不同特征的单位和数值范围不同，例如重量（280 g）、果径（87 mm）、着色率（17%）。直接比较时，数值大的特征会占主导，数值小的特征容易被掩盖。因此，小江将每个特征数据统一转换成 0～1 之间的数值，代码如下。

```python
def scale(d):
    fmin=[-1]*3
    fmax=[-1]*3
    for j in range(3):
        for i in range(len(d)):
            if fmin[j]==-1 or d[i][j]<fmin[j]:
                fmin[j]=d[i][j]
            if fmax[j]==-1 or d[i][j]>fmax[j]:
                fmax[j]=d[i][j]
        for i in range(len(d)):
            d[i][j]=(d[i][j]-fmin[j])/(fmax[j]-fmin[j])
    return d
```

若 `d=[[365,89,0.17],[283,82,0.15],[383,92,0.19],[330,90,0.17]]`，执行语句 `d=scale(d)` 后，`d[0][0]` 的值为 ______。

（3）函数 `dist(x,y)` 用于计算苹果 x 与参考数据 y 的距离，但加框处代码未做开平方根处理，该操作 ______ 影响苹果等级划分结果（选填：会/不会）。

---

## 答案

（1）0.82。

（2）① `dis=dist(d[i],cents[0])`，② `next[i]=head[idx]`，③ `flag=check(cents,tmp,k)`。

（3）不会。

---

## 解析

归一化的第一项为 (365-283)/(383-283)=0.82。找最近等级时，以 0 号等级的距离作为比较基准；头插时先把新结点指向旧表头，再更新头指针。新旧中心差值在阈值内即停止迭代。距离平方与距离在非负范围内排序一致。
