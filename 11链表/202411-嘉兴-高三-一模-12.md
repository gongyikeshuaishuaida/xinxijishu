# 题目 12

对非空链表进行反转操作。链表存储在列表 d 中，如下图所示，每个节点由数据区域和指针区域组成，h 为头指针。

![[attachments/202411嘉兴高三_12_链表表格.png]]

实现上述功能的 Python 自定义函数如下，方框中应填入的正确代码为（   ）：

~~~python
def revlst(d,h):
    p = d[h][1]
    d[h][1] = -1
    while p != -1:
        ______
    return d,h
~~~

- A.
  ~~~python
  r = d[p][1]
  d[p][1] = h
  h = p
  p = r
  ~~~
- B.
  ~~~python
  r = d[p][1]
  p = r
  h = p
  d[p][1] = h
  ~~~
- C.
  ~~~python
  r = d[p][1]
  d[p][1] = h
  p = r
  h = p
  ~~~
- D.
  ~~~python
  p = d[p][1]
  h = p
  r = d[p][1]
  p = r
  ~~~

---

## 答案

**正确答案：** A

---

## 解析

先保存当前节点的后继 r，再把当前节点的指针改为指向已反转链表的头 h，然后将 h 更新为当前节点，最后令 p 指向原后继。四条语句的顺序必须保持为 A。
