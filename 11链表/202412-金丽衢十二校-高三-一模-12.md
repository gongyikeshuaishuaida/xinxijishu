# 题目 12

列表 `a[1]` 到 `a[n]` 中存储了一个 1 到 `n` 的排列 `p`（即 1 到 `n` 中每个数在 `p` 中出现了恰好一次）。令 `right[i]` 为 `i` 号位置之后第一个比 `a[i]` 值更小的位置；如果不存在这样的位置，则 `right[i]=n+1`。例如，若 `a=["",5,4,1,3,2]`，则 `right[1]` 到 `right[5]` 分别为 `2,3,6,5,6`。实现该功能的程序如下：

```python
a = ["", 5, 4, 1, 3, 2]
n = len(a)
b = [-1] * (n + 1)
left = [-1] * (n + 1)
right = [-1] * (n + 1)
for i in range(1, n):
    b[______①______] = i
for i in range(1, n):
    left[i] = i - 1
    right[i] = i + 1
for i in range(n - 1, 0, -1):
    left[______②______] = left[b[i]]
    right[______③______] = right[b[i]]
for i in range(1, n):
    print(right[i], end=' ')
```

上述程序中划线处可选语句为：① `a[i]`；② `i`；③ `right[a[i]]`；④ `left[a[i]]`；⑤ `right[b[i]]`；⑥ `left[b[i]]`。则（1）、（2）、（3）处语句依次是（   ）

- A. ①③④
- B. ②③④
- C. ①⑤⑥
- D. ②⑤⑥

## 答案

**正确答案：** C

## 解析

首先用 `b[a[i]]=i` 建立“数值到位置”的反向索引。处理值 `i` 时，要从当前双向链表中删除位置 `b[i]`，因此应令其右邻居的左指针指向 `left[b[i]]`，并令其左邻居的右指针指向 `right[b[i]]`：

```python
b[a[i]] = i
left[right[b[i]]] = left[b[i]]
right[left[b[i]]] = right[b[i]]
```

所以三个空依次选择 ①、⑤、⑥，即 C。
