# 题目 12

使用列表`a`模拟链表结构，每个节点包含[数据域，指针域]。对链表进行分区整理：使所有数据值小于`x`的节点位于数据值大于等于`x`的节点之前，且小于`x`的节点保持原有相对顺序。如链表`a = [[3,1],[1,2],[4,3],[2,4],[5,-1]]`，`head = 0`。取`x = 3`，分区整理得到1→2→3→4→5。实现该功能的程序段如下，方框处应填入的语句是

```python
def part(head,x,a):
    dy = len(a)
    a.append([-1,head])
    t = prv = dy
    cur = head
    while cur != -1:
        nxt = a[cur][1]
        if a[cur][0] < x:
            # 方框处
        else:
            prv = cur
        cur = nxt
    return a[dy][1]  # 返回头指针
```

## 答案

**正确答案：** D（原卷参考答案；存在下述边界缺陷）

---

## 解析

D先用`a[prv][1]=nxt`摘下当前节点，再把它插入t之后，最后在if之外更新`t=a[t][1]`。对原题示例可得到1→2→3→4→5。B先改t的后继再读取它，会令当前节点指向自身；C未正确摘链；A条件和游标更新均不正确。

但D未在`t==prv`时同步更新prv：例如原链1→2→4，x=3，处理首节点后t指向1而prv仍是虚拟头；处理2时错误改动头指针，最终只返回4，丢失前两节点。应在`t==prv`时执行`prv=cur`，否则正常摘链插入，再统一`t=cur`。因此D是参考答案的预期选项，不能认为其程序对所有链表都正确。
