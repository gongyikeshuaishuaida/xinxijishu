# 题目 15

某学校设置一间答疑室，现要开发一个答疑室预约系统，学生可在晚自修前提交预约申请，在晚自修期间根据系统分配的答疑时间进行答疑。答疑室预约系统中，共开放 `r` 个可预约时间段，每个时间段最多容纳 `c` 名学生，学生预约申请信息包含：学生学号、预约时间段（`0～r-1`）、所需答疑时长（1 或 2 个连续时段）；若预约时间段人数未满，成功预约；若预约时间段人数已满，进入等待分配队列；若学生预约 2 个连续时段，需两个时段人数均未满才可成功预约，否则进入等待分配队列；第一轮分配完后，在满足学生所需答疑时长的要求下，从等待分配队列中按先进先出原则、按时间段从早到晚分配到未满的时间段中。若 `r=3`，`c=2`，学生申请和分配情况如第 15 题图所示。

（3）答疑室预约功能的 Python 程序如下，请在划线处填入合适的代码。

```python
def proc(data, r, c):
    n = len(data); a = [0] * r
    h = t = -1
    for i in range(n):
        data[i].append(i + 1)
    data[n - 1][-1] = -1
    for i in range(n):
        k, m = data[i][1], data[i][2]

            a[k] += 1
            a[k + m - 1] += m - 1  # 更新各时间段人数

            ______①______

                h = i
            else:
                data[t][-1] = i
            t = i

        p = q = h
        while a[i] < c and q != -1:

                a[i + data[q][2] - 1] += data[q][2] - 1  # 更新各时间段人数

                    h = data[h][-1]

sort(result)
print(result)
```

---

## 答案

(1) 2

(2) `result[j+1]=result[j]`

(3) ①`data[pre][-1]=data[i][-1]`；②`i<r-1 and a[i+1]<c`；③`pre=q`

---

## 解析

新增申请第一轮等待，第二轮可分到时段2。插入排序需右移较大学号记录；队列删除与遍历时要正确维护前驱和后继，双时段申请还需检查下一时段容量。


原题程序问题：第一轮结束后，等待队列的尾节点 `t` 未明确断开原链表的后继。若最后一名等待学生后面还有第一轮成功的学生，第二轮可能再次处理这些已成功分配的节点，甚至形成循环。题干与三个填空按原卷和参考答案保留。

可复现反例：`r=5`、`c=1`，申请依次为 `["stu1",0,1,-1]`、`["stu2",0,1,-1]`、`["stu3",4,1,-1]`。正确分配应为 `[0,1,4]`，按原代码及参考填空得到 `[0,3,2]`。课堂演示时，可在第一轮结束、`for i in range(r)` 之前补充：

```python
if h != -1:
    data[t][-1] = -1
```

补充后已通过 1000 组随机申请与独立分配实现的对照；该语句属于修正建议，不属于原题填空。
