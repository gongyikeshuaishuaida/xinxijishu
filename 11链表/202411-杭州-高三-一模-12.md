# 题目 12

使用列表 `d` 模拟链表结构（节点数大于 2，且不存在连续为 0 的节点），每个节点包含数据区域和指针区域，`h` 为头指针。链表的开头和末尾的节点数据区域的值均为 0，如图所示。现要把相邻两个数值为 0 的节点之间所有节点合并为一个节点，该节点值为所有合并节点值之和，并将值为 0 的节点移除，结果如图所示。实现该功能的部分程序段如下。

![[attachments/202411杭州_12_图1.png]]

```python
k = h
p = d[k][1]
while k != -1 and p != -1:
    ______①______
    p = d[k][1]
```

方框中应填入的正确代码如下图所示。

![[attachments/202411杭州_12_图2.png]]

## 解析

当 `p` 指向的节点数据不为 0 时，应把 `p` 节点的数据累加到 `k` 节点，并让 `k` 的后继指向 `p` 的后继；当 `p` 指向的数据为 0 时，说明前一段已经合并完成，应将 `k` 移到其后继节点。选项 B 正好分别完成这两种情况，随后统一用 `p=d[k][1]` 更新待检查节点。
