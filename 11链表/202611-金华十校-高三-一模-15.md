# 题目 15

某工厂流水线依次下线一批产品,形成一个队列,产品型号用大写字母 A\~Z 表示,每件产品占用相同的装载位。连续下线的同型号产品构成一个"段",因此相邻段的型号必定不同。现用若干载重量为 cap 件的卡车把这批产品全部运走,规则如下:

①每辆卡车只运一种型号的产品,型号类型 t 由当前队列第一个产品型号决定;

②从队首到队尾依次考察每个段:若该段型号为 t 且件数不超过车上剩余容量,则整段装走并从剩余容量中扣除该段件数;否则跳过该段,继续考察下一个段;

③走完整条流水线后,若车未装满且仍有 t 型段未运走,则从第一个未运走的 t 型段中取若干件把车装满(该段剩余件数留在流水线上原位置;若恰好取完,则该段删除);

④本车运走的段全部删除后,重新检查整条流水线,将相邻的同型号段合并为一个段(件数相加);

⑤重复①\~④,直至产品全部运完。

(1)若本批产品按下线顺序记录为 AAABAABAA, 且 cap = 4, 则第 1 辆卡车运走后的记录变为 BABAA, 第 2 辆卡车运走后的记录变为 ______。

(2) 定义 `create(s)` 函数。根据字符串 `s` 建立段链表（`seg[i] = [型号, 件数, 前驱, 后继]`，其中 `seg[0]` 为哨兵结点，不表示实际的段，`seg[0][3]` 指向段首）：

```python
def create(s):
    seg = [[None, 0, -1, -1]]
    tail = 0
    for ch in s:
        if tail != 0 and seg[tail][0] == ch:
            seg[tail][1] += 1
        else:
            seg.append([ch, 1, tail, -1])
            seg[tail][3] = len(seg) - 1
            tail = len(seg) - 1
    return seg
```

## 答案

**正确答案：** (1) AAA；(2) `['A', 4, 2, 4]`；(3) `dele(q)`；(4) ① `seg[p][1] <= rem`；② `seg[unf][1] -= rem`。

---

## 解析

第一辆车后为BABAA；第二辆车装走两个B段，剩余AAA。建表后第3段是4个A，其前驱2、后继4。合并时累加q的件数后删除q，保留p以继续检查后继。运输时能整段装下就删除，否则记下首个未装同型号段；最后从该段扣除剩余容量。

原卷主程序有 `unf = p.`，末尾句点导致Python语法错误，应为 `unf = p`；`ans += 1.` 则按浮点数累加。题面均按原卷保留，核验运输逻辑时使用修正后的 `unf = p`。
