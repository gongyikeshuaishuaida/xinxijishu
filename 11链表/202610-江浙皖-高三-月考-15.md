# 题目 15

某厂房有`m`台钻床，编号为1～`m`，每台钻床配有尺寸为1～`n`的`n`个可安装的钻头（保证钻头可以满足所有订单需求），初始所有钻床均未加装钻头（以下称为未启用，否则称为已启用）。该厂房接到了`k`个订单，每个订单编号用该订单需要加工的孔的尺寸`item`表示。现在需要将这`k`个订单依次分配给`m`台钻床，分配方式如下：

①若所有钻床均未启用，则订单分配给1号钻床；

②若已有钻床启用，当前订单的`item`大于所有已启用钻床的钻头尺寸，且仍有未启用的钻床，则订单分配给未启用钻床中编号最小的（钻床的钻头尺寸取最近一次处理的订单需要的尺寸）；

③否则订单分配给所有已启用钻床中钻头尺寸与`item`相差（差的绝对值）最小钻床，若存在多个钻床符合条件，则分配给编号最小的钻床。

注意：不考虑订单处理的时间，且钻床一旦启用就不能恢复为未启用状态。

例如：当`m=3`，订单依次为`[2,5,3,7,6,8]`，各订单的分配结果与各钻床当前钻头尺寸如第15题图a所示：

(1) 当`m=3`，订单依次为`[2,5,7,4,7,6,8,6]`时，3台钻床要处理的订单数量分别为______。（数字间用逗号隔开）

(2) 自定义函数`alloc`实现将`order_list`中的订单分配给`m`台钻床。

```python
def alloc(m, order_list):
    siz = [-1] * m; cnt = -1
    order = [[] for i in range(m)]  # order中存放m台钻床的订单
    for item in order_list:
        if cnt == -1 or item > siz[cnt] and cnt <= m-1:
            cnt += 1
            order[cnt].append(item)  # 在order[cnt]的末尾添加元素item
            siz[cnt] = item
        else:
            L = 0; R = cnt
            ans = 0
            while L <= R:
                mid = (L+R)//2
                if siz[mid] <= item:
                    ans = mid
                    L = mid+1
                else:
                    R = mid-1
            if ans == m-1 or item-siz[ans] <= siz[ans+1]-item:
                order[ans].append(item); siz[ans] = item
            else:
                order[ans+1].append(item); siz[ans+1] = item
    return order
```

原卷加框处为`if cnt == -1 or item > siz[cnt] and cnt <= m-1:`，划线处为`ans = mid`。

①程序中加框处代码有错，请改正。

②运行下列哪一组数据划线处的语句执行次数最多______。（单选，填字母）。

- A. `m=6, order_list=[1,2,3,4,5,6,4,2]`
- B. `m=6, order_list=[1,2,3,4,5,6,6,2]`
- C. `m=6, order_list=[1,2,3,4,5,6,1,4]`
- D. `m=6, order_list=[1,2,3,4,5,6,3,6]`

(3) 加装一个钻头或卸下一个钻头均称为1次操作。钻床上已有钻头时，可以在原钻头基础上直接加装尺寸更大的钻头，钻床的钻头尺寸更新为新加装上的钻头尺寸。根据订单情况，求每台钻床所需要的最小操作次数。

## 答案

(1) 1，3，4。

(2) ①`cnt == -1 or item > siz[cnt] and cnt < m-1`；②B。

(3) ①`head = x[0]`；②`head != -1 and x[i] < drill[head][0]`；③`drill[x[i]][1] = head`。

---

## 解析

(1) 分配到钻床编号的顺序为1、2、3、2、3、3、3、2，订单列表分别为`[2]`、`[5,4,6]`、`[7,7,6,8]`，数量为1、3、4。

(2) `cnt`是最后一台启用钻床的0起算下标，只有`cnt < m-1`时才可启用新钻床。二分查找求不大于当前尺寸的最右下标；划线`ans=mid`只在该条件成立时执行。A、B、C、D的执行次数分别为4、5、3、4，故B最多。

(3) 用尺寸作为节点下标，`head`为当前最外层钻头。初装第一个钻头计1次。若当前钻头过大，就沿后继卸下它，每卸下一层计1次；遇到相同尺寸可直接使用，否则把新尺寸节点的后继指向剩余钻头栈顶，再装上新钻头并计1次。链表实现了钻头层叠的栈式维护。
