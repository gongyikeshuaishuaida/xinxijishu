# 题目 15

某校进行体育之星评比，现有引体向上、俯卧撑、仰卧起坐、跳绳四个项目。学生自愿参加其中一项评比，成绩前 `num` 名（包含 `num`，同名次均可）同学为该项目的体育之星。保证每个项目都有超过 `num` 人参加。编写程序完成上述功能并输出结果。

（1）定义如下函数 `insert(a,i,k)`，函数的功能是实现数据的有序插入。

```python
def insert(a,i,k):
    if queinfo[k][1] == -1:
        queinfo[k][1] = i
    elif a[i][3] >= a[queinfo[k][0]][3]:
        a[i][4] = queinfo[k][0]
        queinfo[k][0] = i
    elif ______②______:
        a[queinfo[k][1]][4] = i
        queinfo[k][1] = i
    else:
        q = queinfo[k][0]; p = a[q][4]
        while p!=-1 and a[p][3]>a[i][3]:
            q = p; p = a[p][4]
        a[i][4] = p; a[q][4] = i
```

①若函数中加框语句改成 “`p!=-1 and a[p][3]<a[i][3]`” 对整个程序的结果会不会影响 `______①______`（单选，填：会/不会）。

②在划线处填写合适的代码：`elif` 处应填 `______②______`。

（2）实现功能的 Python 程序如下，请在程序中划线处填入合适的代码。

```python
# 读取数据存入列表 data 中，代码略
'''

queinfo=[[-1,-1] for i in range(4)] ; rs=[0]*4
```

（3）`data` 数据为 `[["101 班","周**","跳绳",100,-1],["103 班","叶*","跳绳",50,-1],["107 班","幸**","跳绳",105,-1],["111 班","陈**","跳绳",100,-1],["113 班","郑*","跳绳",171,-1]]`，若 `num` 值为 3，则需要输出跳绳项目的体育之星，`insert(a,i,k)` 函数调用 `______⑤______` 次。

## 答案

**正确答案：**

- （1）① 会；② `a[i][3]<=a[queinfo[k][1]][3]`（或 `a[i][3]<a[queinfo[k][1]][3]`）
- （2）① `k=programe[data[i][2]]`；② `queinfo[programe[i]][0]`
- （3）5 次

## 解析

`queinfo[k][0]` 和 `queinfo[k][1]` 分别记录某项目有序链表的头、尾。新数据成绩不低于头节点时插入表头；若新数据成绩不高于尾节点，则把它接到尾部，条件可写为 `a[i][3]<=a[queinfo[k][1]][3]`；否则沿指针域寻找插入位置。将加框条件改成按相反方向比较，会改变等分或中间成绩数据的插入位置和后续指针关系，因此会影响程序结果。

遍历 `data` 时先用项目名称通过字典得到项目编号 `k`；输出时循环变量 `i` 是项目名称，需再次通过 `programe[i]` 找到对应链表头，即 `q=queinfo[programe[i]][0]`。给出的 5 条数据都属于跳绳项目，按程序都会进入 `insert`，所以调用 5 次。
