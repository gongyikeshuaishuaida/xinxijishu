# 题目 15

某快递员每天需要完成 `n` 个取件任务，每个任务 `i` 包含两项数据：取件耗时 `t_i`（分钟数），以及客户要求的取件截止时间 `d_i`，其中 `d_i` 以当前 00:00 开始的分钟数表示，取件任务必须在 `d_i` 时刻之前完成。快递员同一时间只能处理一个任务。

为了在有限时间内完成尽可能多的任务，快递员采用如下策略：按截止时间从早到晚依次考虑每个任务，能按时完成的则加入取件计划，不能按时完成的则尝试替换计划中耗时最长的任务。

请回答下列问题。

（1）若快递员某天收到的取件任务如第 15 题图所示，则最多能按时完成 ______ 个任务。

![[attachments/202608精诚联盟_15_图1.jpg]]

（2）定义 `preproc()` 函数完成排序和预处理工作，`jobs` 为任务列表，每个元素表示一个任务，包含两个数据项，依次是耗时和截止时间。耗时和截止时间都相同的两个任务认为是重复任务，重复仅保留一个。函数返回排序去重后的有效任务数量。

```python
def preproc(jobs):
    n = len(jobs)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if jobs[j][1] > jobs[j + 1][1]:
                jobs[j], jobs[j + 1] = jobs[j + 1], jobs[j]
            elif jobs[j][1] == jobs[j + 1][1] and jobs[j][0] > jobs[j + 1][0]:
                jobs[j], jobs[j + 1] = jobs[j + 1], jobs[j]
    i = j = 0
    while j < n:
        if jobs[i] != jobs[j]:
            i += 1
            jobs[i] = jobs[j]
        j += 1
    return ______
```

① 函数中两个嵌套的 `for` 循环完成的功能是 ______③______（单选）。

- A. 按截止时间从小到大排序，截止时间相同的按耗时从小到大排序
- B. 按截止时间从大到小排序，截止时间相同的按耗时从大到小排序
- C. 按截止时间从小到大排序，截止时间相同的按耗时从大到小排序
- D. 按截止时间从大到小排序，截止时间相同的按耗时从小到大排序

② 为了返回去重后的任务数量，划线处语句应该填写 ______④______。

（3）实现优化调度任务的处理函数 `proc()` 如下。参数 `orders` 表示原始任务数据，已选任务用 `lst` 链表保存，`lst[0]` 为头节点（不存储有效数据），其余每个节点包含两个数据项，依次是任务耗时和后续节点指针。请在划线处填入合适的代码。

```python
def proc(orders):
    n = preproc(orders)
    lst = [[-1, -1]]  # 初始化为仅包含头节点的链表
    cur = cnt = 0
    for i in range(n):
        t, d = orders[i][0], orders[i][1]
        if ______①______:
            new_idx = len(lst)
            lst.append([t, -1])
            lst[new_idx][1] = lst[0][1]
            lst[0][1] = new_idx
            cur += t
            cnt += 1
        else:
            max_val = max_idx = -1
            pre_max = pre = 0
            p = lst[0][1]
            while p != -1:
                if ______②______:
                    max_val = lst[p][0]
                    max_idx = p
                    pre_max = pre
                pre = p
                p = lst[p][1]
            if max_val > t:
                ______③______
                new_idx = len(lst)
                lst.append([t, -1])
                lst[new_idx][1] = lst[0][1]
                lst[0][1] = new_idx
                cur = cur - max_val + t
    return cnt
```

---

## 答案

**正确答案：** （1）4；（2）①A；② `i + 1`；（3）① `cur + t <= d`；② `lst[p][0] > max_val`；③ `lst[pre_max][1] = lst[max_idx][1]`

---

## 解析

先按截止时间升序、同截止时间按耗时升序排列并去重。处理任务 0、1、2 后累计耗时为 13，任务 3 不能直接加入但可用耗时 5 替换已选的耗时 7 任务，随后任务 4 也可完成，最终 4 个。去重后的有效元素下标到 i，因此数量为 i+1；链表遍历用最大耗时比较，替换时让最大节点的前驱直接指向其后继。
