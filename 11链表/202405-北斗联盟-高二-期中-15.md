# 题目 15

15.树上有 `n` 个苹果，小明身高160 cm、板凳高40 cm，摘苹果和搬板凳各消耗1个能量点。将高度不超过160 cm的苹果存入 `apple_a`，高度大于160且不超过200 cm的存入 `apple_b`，两组按重量降序排列；若消耗2点能量摘到的最重苹果重量大于消耗1点能量可摘到的最重两个苹果重量之和，则先摘 `apple_b` 中的苹果，否则摘 `apple_a` 中的苹果。

（1）若 `apple = [[200,102],[205,200],[160,400],[150,300],[130,190],[175,104],[188,350]]`，`ey=6`，摘到的总重量最大为多少克？

（2）定义 `link(d)` 将列表创建成链表：

```python
def link(d):
    for i in range(len(d)):
        d[i].append(-1)
    for i in range(1, len(d)):
        ______①______
    return d
```

（3）主程序中，补充 `linkdel` 和比较代码：

```python
def linkdel(d, head, dlen):
    apple_end.append(d[head])
    ______②______
    dlen = dlen - 1
    return head, dlen

while ey > 0:
    if alen > 1 and blen > 0:
        if ______③______ and ey >= 2:
            ...
```

（4）程序中“`elif [blen > 0 or alen == 0]:`”有误，请修正。

---

## 答案

**正确答案：** （1）1240；（2）`d[i-1][2]=i`；（3）① `head=d[head][2]`（或 `head+=1`）；② `apple_b[head_b][1] > apple_a[head_a][1] + apple_a[apple_a[head_a][2]][1]`；（4）`blen>0 and alen==0`

---

## 解析

链表第三列保存下一个节点下标，删除头结点后应沿指针移动到下一个节点。比较两种摘取方案时，消耗2点能量的最高重量要与消耗1点能量的前两个重量和比较；最后一个条件必须是布尔表达式而不是带方括号的列表。
