# 题目 15

某学校举办社团节，在一条直路的同侧依次有 n 个社团展位。从入口到第 1 个展位需花费 `dis[0]` 单位时间，从第 i 个展位到第 i+1 个展位需花费 `dis[i]` 单位时间。每个展位举行若干活动，每参加一个活动需 5 单位时间；第 i 个展位第 k 次活动获得 `a[i-1]-(k-1)*b[i-1]` 个积分。小明从入口出发，用 m 单位时间选择活动并回到入口，求规定时间内最多积分的方案。

示例数据和运行界面如下。

![[attachments/202402-G12名校协作体-高三-二模-15_横排1_2.png]]

当可用时间为 28 时，参加前 1、2、3 个展位的方案分别可得 18、40、36 分，最大为 40。

（1）若可用时间为 32，按上表数据可得最多积分为 ______①______。

（2）定义如下 `insert(head, r)` 函数，功能是在首节点下标为 `head` 的链表中插入下标为 `r` 的节点，返回新的链首节点下标。`data[i][0]` 存储当前积分，`data[i][1]` 存储每次活动后的下降积分，`data[i][2]` 存储后继下标。

```python
def insert(head, r):
    p = q = head
    while q != -1 and data[r][0] < data[q][0]:
        p = q
        q = data[q][2]
    if q == head:
        data[r][2] = head
        head = r
    else:
        data[p][2] = r
        data[r][2] = q
    return head
```

若函数加框处代码误写为 `data[r][0] < data[q][0]`，会导致某些情况下无法得到符合函数功能的结果。调用函数，下列数据中能测试出这一问题的是 ______②______（单选，填字母）。

- A. `data=[[6,6,-1],[10,3,3],[2,11,-1],[7,5,2]]; head=1; r=0`
- B. `data=[[6,6,-1],[10,3,3],[2,11,-1],[7,5,0]]; head=1; r=2`
- C. `data=[[6,6,2],[10,3,0],[2,11,-1],[7,5,-1]]; head=1; r=3`
- D. `data=[[6,6,2],[10,3,-1],[2,11,-1],[7,5,0]]; head=3; r=1`

（3）实现上述功能的 Python 程序如下，请在划线处填入合适的代码。

```python
# 展位数存入变量 n，可用时间存入变量 m；
# 各展位首次参加活动可获得的积分存入 a 列表；
# 各展位每参加一次活动要下降的积分存入 b 列表；
# 相邻展位之间步行花费时间存入 dis 列表，dis[0] 为入口到第1个展位的时间，dis[i]（i>0）为第 i 个展位到第 i+1 个展位的时间；
# 代码略

for i in range(1, n):
    dis[i] = ______③______
data = []
for i in range(n):
    data.append([a[i], b[i], -1])
ans = 0

for i in range(n):
    head = -1

        data[j][0] = a[j]
        head = insert(head, j)
    t = (m - 2 * dis[i]) // 5
    if t <= 0:
        break
    total = 0
    count = [0] * n
    while ______④______:
        p = head
        head = data[head][2]
        total += data[p][0]
        count[p] += 1
        data[p][0] = ______⑤______
        if data[p][0] > 0:
            head = insert(head, p)
        t -= 1
    if total > ans:
        # 更新 ans 和 best，代码略
        pass
```

## 答案

**正确答案：** ① 51；② B；③ `dis[i-1] + dis[i]`；④ `t > 0 and head != -1`；⑤ `data[p][0] - data[p][1]`

---

## 解析

可用时间为 32 时，走到前三个展位并返回的步行时间为 2×(1+3+4)=16，剩余 16 个单位时间可参加 3 次活动。三次最高积分为 20、16、15，共 51 分。
错误条件在 `q` 已经变为 -1 后仍访问 `data[q]`，选项 B 会让链表遍历到尾部并暴露该问题；其他选项不会触发这一边界。
把 `dis` 原本的相邻路程改为从入口到第 i 个展位的累计路程，所以 `dis[i]=dis[i-1]+dis[i]`。活动循环必须同时满足还有活动次数且链表非空；每参加一次活动，当前节点积分下降 `data[p][1]`，再按新积分重新插入链表。
