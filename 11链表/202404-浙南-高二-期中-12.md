# 题目 12

12.单向链表 `data` 中的节点由[数据区域，指针区域]构成，其中数据有重复。原始数据为：

`data=[[3,1],[3,2],[1,3],[5,4],[1,5],[3,6],[2,7],[3,8],[8,9],[2,-1]]`

去重后输出：`[3,2],[1,3],[5,6],[2,8],[8,-1]`。程序如下，请选择合适代码组合：

```python
head = 0
cur = head
while ______①______:
    p = cur
    q = data[cur][1]
    while q != -1:
        if data[q][0] == data[cur][0]:
            ______②______
        else:
            p = q
        ______③______
    cur = data[cur][1]
```

① `data[cur][1] != -1`　② `cur != -1`　③ `data[p][1] = data[q][1]`　④ `data[q][1] = data[p][1]`　⑤ `q = data[q][1]`　⑥ `p = data[p][1]`

A.①③⑤　B.②④⑥　C.①④⑤　D.②③⑥

---

## 答案

**正确答案：** A

---

## 解析

外层只需处理仍有后继节点的当前结点，条件为 `data[cur][1] != -1`；发现重复数据时用前驱 `p` 跳过当前结点，即 `data[p][1]=data[q][1]`；未发现重复时沿链表后移 `q=data[q][1]`，所以选 A。
