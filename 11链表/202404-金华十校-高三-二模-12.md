# 题目 12

12.列表 `a` 存储了两个升序链表的节点，每个节点包含数据区域和指针区域，头指针分别为 `ha`、`hb`，且 `a[ha][0] < a[hb][0]`，如图所示。现要将其合并为一个升序链表，头指针为 `h`，结果如图所示。

![[attachments/202404-金华十校-高三-二模-12_横排1_2.png]]

实现功能的程序段如下，方框中应填入的正确代码为（ ）：

```python
q = h = ha
p = a[ha][1]
k = hb
while p != -1 and k != -1:
    if a[p][0] <= a[k][0]:
        q = p
        p = a[q][1]
    else:
        ______①______
if k != -1:
    a[q][1] = k
```

- A.

  ```python
  a[p][1] = k
  p = k
  k = a[p][1]
  a[p][1] = q
  ```

- B.

  ```python
  a[q][1] = k
  q = k
  k = a[q][1]
  a[q][1] = p
  ```

- C.

  ```python
  a[q][1] = k
  k = a[q][1]
  q = k
  a[q][1] = p
  ```

- D.

  ```python
  a[p][1] = k
  k = a[p][1]
  p = k
  a[p][1] = q
  ```

---

## 答案

**正确答案：** B

---

## 解析

合并时若 `a[p][0] <= a[k][0]`，把 p 节点接到结果链表后继续移动 p；否则应把 k 节点接到当前尾部，保存 k 的后继到 k，再令该节点后继指向 p。选项 B 正确。
