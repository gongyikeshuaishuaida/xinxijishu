# 题目 12

使用列表 `a` 模拟链表结构（节点数 `n>0` 且有偶数个节点），每个节点包含数据区域和指针区域，`head` 为头指针。现要将链表两两交换其中相邻的节点，交换前后如图所示。

![[attachments/202502金色阳光_12_链表交换图.png]]

实现上述功能的部分 Python 程序段如下：

```python
a = [["A", 1], ["B", 2], ["C", 3], ["D", 4], ["E", 5], ["F", -1]]
head = 0
a.append(["-1", head])
t = len(a) - 1
p = head
q = a[p][1]
while p != -1:
    if p == head:
        head = q
        a[t][1] = q
    a[p][1] = a[q][1]
    ______①______
```

方框处可选的语句为：

- ① `t=p`
- ② `a[q][1]=p`
- ③ `p=a[p][1]`
- ④ `q=a[a[p][1]][1]`

则方框处语句依次为

- A. ③①②④
- B. ②①③④
- C. ②①④③
- D. ③④①②

## 答案

**参考答案：** C（方框处语句依次为 ②①④③）

## 解析

交换一对相邻节点时，先把后一个节点的后继改为前一个节点（②），再记录当前节点为下一轮的前驱（①），随后根据新的链表指针更新下一对节点的位置（④、③）。因此顺序为 ②①④③，即选项 C。图示中的交换前后链表已完整保留。
