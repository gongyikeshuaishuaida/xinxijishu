# 题目 15

酒店房间按连续编号登记连续空房段，如 1_2 表示从 1 号开始连续 2 间空房。退房或入住时需要维护这些记录。

![[attachments/202406浙南_15_空房登记运行截图.jpg]]

当前记录为 2_3、6_2、9_4。若旅客退掉 8 号房间，登记记录将变为 ______①______。

（2）对空房间数据按起始编号升序排序：

    def sort(d):
        i = 0; n = len(d)
        for i in range(1, n):
            for j in range(1, n-i+1):
                if ______②______:
                    d[j], d[j-1] = d[j-1], d[j]
        return d

（3）退房主程序中补全：

    q = p = head
    while ______③______:
        q = p
        p = room[p][2]
    if room[q][0] + room[q][1] == num:
        if room[p][0] == num + 1:
            ______④______
            room[q][2] = room[p][2]
        else:
            room[q][1] += 1
    elif num + 1 == room[p][0]:
        room[p][0] = num
        room[p][1] += 1
    else:
        room.append([num, 1, p])
        if p == head:
            head = len(room) - 1
        else:
            ______⑤______

---

## 答案

**正确答案：** （1）2_3、6_7；（2）② d[j-1][0] > d[j][0]；（3）③ p != -1 and room[p][0] < num；④ room[q][1] += room[p][1] + 1；⑤ room[q][2] = len(room) - 1。

---

## 解析

退掉 8 号房后，6_2 与 9_4 两段上下相邻，合并为 6_7。冒泡排序中若前一项起始编号更大则交换。遍历链表时先找到 num 所在位置；上下两段都相邻时合并长度，并在中间插入新区间时更新前驱节点的 next 指针。
