# 题目 15

现有 n 台检测机器（编号 0～n-1），处理当天提交的多项检测任务，每项任务包含编号、开始时间、持续时长。初始时，各台机器均处于空闲状态。各任务按开始时间从小到大顺序提交（如第 15 题图所示），然后进行逐项分配，规则如下：

①每次分配时优先选择最早结束任务的机器，若多台机器符合要求，则优先选择编号最小的。

②若选中的机器当前未空闲，任务将被延时，直到该机器空闲后立即执行，任务检测时长不变。

请回答下列问题：

![[attachments/202611杭州周边高二_15_图1.png]]

(1) 若 n = 2 各项任务如第 15 题图所示, 哪些任务需要被延时检测: ▲ (填编号用, 分隔)

（2）定义如下函数 change，实现将列表 task 中编号 bh 的任务开始时间提早 t 分钟后，调整该任务次序，使得所有任务依旧按开始时间升序排列，若任务的开始时间相同，则保持原有次序。请修正加框处的代码 ______。

```python
def change(task,bh,t):
    for i in range(len(task)):
        if task[i][0]==bh:
            break
    task[i][1]-=t
    new=task[i]
    while i>0 and task[i-1]<new:    # 原卷加框
        task[i]=task[i-1]
        i-=1
    task[i]=new
    return task
```

（3）根据上述任务分配规则，编写如下 Python 程序输出延时检测任务个数。请在划线处填入合适的代码。

```python
def proc(task,n):
    devices=[]
    for i in range(n):
        devices.append([-1,i+1])
    devices[n-1][1]=-1
    head=0
    ______①______
    for t in task:
        start,time=t[1],t[2]
        id=head
        if devices[id][0]<=start:
            devices[id][0]=start+time

            ______②______

                p=devices[p][1]
            else:
                break
        ______③______
        if pre==-1:
            head=id
        else:
            devices[pre][1]=id
    return cnt

"""
将机器数存入n；将任务按开始时间从小到大存入列表task，每个元素包含任务编号、开始时间、持续时长，例如 task=[["A",1,4],["B",2,5],……]，代码略。
输入需要调整的任务编号和提早时长，调用函数change实现任务次序调整，代码略。
"""
num=proc(task,n)
print("需要延时检测的任务个数为：",num)
```

## 答案

（1）C、E。

（2）`while i>0 and task[i-1][1]>new[1]:`。

（3）① `cnt=0`，② `devices[id][0]+=time`，③ `devices[id][1]=p`。

---

## 解析

处理 C 时两台机器分别要到 5、7 才空闲，C 从 4 延至 5；处理 E 时两台机器分别要到 8、13 才空闲，E 从 7 延至 8。更新任务开始时间后，只把开始更晚的前项右移，同一时刻的任务不调换顺序。分配后将原链首重新插入，按结束时刻和机器编号保持排序。
