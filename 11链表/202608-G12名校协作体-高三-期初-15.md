# 题目 15

小明家墙上出现了一个矩形坑洞，他找来了一些矩形木板，希望使用最少数量的木板完全覆盖这个坑洞。要求：所有使用的木板的两边都必须与坑洞边界平行，任一木板的四个角都必须严格位于坑洞边界之外，不能恰好位于边界上。例如，如果坑洞的大小为 `weight=6`、`height=4`，有 3 块可用木板，其边长分别为 `[[8,2],[8,3],[5,3]]`，那么选用 1、2 号木板和 2、3 号木板都可以修补这个坑洞，如第 15 题图 a、第 15 题图 b 所示（虚线方框代表坑洞）。最优方案中所有被选中的木板一定满足：要么能够完全横跨坑洞的左右边界，通过垂直方向上的拼接覆盖坑洞；要么能完全横跨坑洞上下边界，通过水平方向上的拼接覆盖坑洞。

第15题图a、第15题图b

（1）如果坑洞的大小为 `weight=7`、`height=5`，有 5 块木板，边长分别为 `[[8,2],[3,2],[6,4],[9,3],[2,8]]`，则完全覆盖坑洞至少需要 ______ 块木板。

（2）定义 `insertboard(head, id)` 函数，功能是将木板列表 boards 中索引为 id 的木板插入到头指针为 head 的链表当中，其中 `boards[id][0]`、`boards[id][1]` 分别表示索引为 id 的木板的两边边长。插入时需保证链表中所有木板按照 `boards[id][1]` 的值降序排序。请在划线处填入合适的代码。

（3）`check(h, w)` 函数实现求解假设选取的木板都能够横跨长度为 w 的边对应的坑洞边界，将所有木板沿着长度为 h 的边进行拼接，所需的最少木板数量，如无法实现则返回 -1。该函数与主程序的部分代码如下。

```python
def insertboard(head, id):
    if head == -1 or boards[id][1] >= boards[head][1]:
        boards[id][2] = head
        head = id
    else:
        cur = head
        while cur != -1:
            if boards[cur][2] == -1 or boards[id][1] >= boards[boards[cur][2]][1]:
                __________  # 插入位置代码
                boards[cur][2] = id
                break
            cur = boards[cur][2]
    return head

def check(h, w):
    n = len(boards); head = -1
    for i in range(n):

            boards[i][0], boards[i][1] = boards[i][1], boards[i][0]
        if __________ > w:  # (a)
            head = insertboard(head, i)
        elif __________ > w:  # (b)
            boards[i][0], boards[i][1] = boards[i][1], boards[i][0]
            head = insertboard(head, i)

    cnt, sum = 0, 0
    cur = head
    while __________:  #①
        cnt += 1
        sum += boards[cur][1]
        cur = boards[cur][2]
        if sum < h:
            cnt = -1
    return cnt

answ = check(height, weight)
ansh = check(weight, height)
if answ!=-1 and ansh!=-1:
    ans=min(answ, ansh)
else:
```

I. 请在划线处填写合适的代码。
II. 为实现函数功能，方框 (a) 和 (b) 可填写的代码为：

- A. (a) `boards[i][0]`；(b) `boards[i][1]`
- B. (a) `boards[i][1]`；(b) `boards[i][0]`
- C. A 或 B 均正确

---

## 答案

**正确答案：** （1）2；（2）`boards[id][2] = boards[cur][2]`；（3）I. `cur != -1 and sum < h`；② `ans=max(answ, ansh)`；II. A

---

## 解析

先把木板两边规范为短边在 `boards[i][0]`、长边在 `boards[i][1]`，分别计算竖向拼接和横向拼接两种方案。给定 5 块木板时，宽度 7 的横跨条件与高度 5 的拼接长度组合至少需要 2 块。链表插入时先保存后继指针，再将当前节点指向新节点。遍历链表应在仍有节点且累计长度不足 `h` 时继续；两种方向都可行时取较小值，否则取可行的一种或 -1。方框 (a)、(b) 用 A 或 B 均可，因为两种写法分别对应先交换与不交换的两种方向检查。
