# 题目 15

操作系统需要为应用程序分配和释放内存。大小为 1024B 的内存用 0/1 列表表示空闲和占用；将连续空闲块组织成节点 `[空闲块起点, 空闲块长度, 下一个空闲块位置]`。

![[attachments/202404五校_15_内存占用图.jpg]]
![[attachments/202404五校_15_空闲块链表图.jpg]]

（1）根据内存占用图，执行释放指令`[4,4]`后（连续空闲块合并），空闲块数量变为 ______①______ 个。

（2）根据 allot 创建空闲块链表：

```python
def linkList(allot):
    link = [[-1,-1,-1]]
    head = tail = 0
    n = len(allot)
    i = 0
    while i < n:
        if allot[i] == 0:
            j = i + 1
            while j < n and allot[j] == 0:
                j = j + 1
            link.append([i, j-i, -1])
            link[tail][2] = ______②______
            tail = len(link) - 1
            i = j + 1
        else:
            i += 1
    return head, link
```

① 填空；② 若将加框处修改为`i = j`，是否影响程序执行结果？______③______（选填：是/否）。

（3）模拟内存操作的程序中，填空：

```python
head, link = linkList(allot)
for i in range(len(order)):
    if order[i][0] == "+":
        p = head
        q = link[head][2]
        while ______④______:
            p = q
            q = link[q][2]
        if q == -1:
            print("内存不足！")
        else:
            if link[q][1] == order[i][1]:
                ______⑤______
            else:
                link[q][0] += order[i][1]
                link[q][1] -= order[i][1]
    else:
        p = head
        q = link[head][2]
        while q != -1 and link[q][0] < order[i][0]:
            p = q
            q = link[q][2]
        if link[p][0] + link[p][1] == order[i][0]:
            link[p][1] += order[i][1]
        else:
            link.append([order[i][0], order[i][1], q])
            link[p][2] = len(link) - 1
            p = link[p][2]
        if q != -1 and ______⑥______:
            link[p][1] += link[q][1]
            link[p][2] = link[q][2]
```

## 答案

**正确答案：** ① 2；② `len(link) - 1`；③ 否；④ `q != -1 and link[q][1] < order[i][1]`；⑤ `link[p][2] = link[q][2]`；⑥ `link[p][0] + link[p][1] == link[q][0]`

## 解析

释放 `[4,4]` 后，原有相邻空闲块合并，剩下 `[2,9]` 与 `[13,1011]` 两个空闲块。链表尾指针连接新节点位置 `len(link)-1`；`i=j` 与 `i=j+1` 在下一格为占用状态的给定数据上结果相同。分配时沿链表寻找容量足够的第一个空闲块，刚好用尽则把节点从链表中删除；释放时按地址插入并分别检查前后相邻块是否合并。
