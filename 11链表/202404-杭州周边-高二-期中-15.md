# 题目 15

15.幼儿园小朋友排成两队，若两队后部合并为一队，需要按规则拆分为人数相等的两队。

题图 a、b、c 如下：

![[attachments/202404杭州周边_15_队伍图a.jpg]]

![[attachments/202404杭州周边_15_队伍图b.jpg]]

![[attachments/202404杭州周边_15_队伍图c.jpg]]

（1）图 c 的队伍经过调整后，B 队首的队伍序列是 `BCDF`。

（2）链表长度函数：

```python
def link_len(h):
    p = h
    c = 0
    while p != -1:
        c += 1
        ______①______
    return c
```

（3）调整程序中，①②③分别填入：

```python
if (______①______):
    pb = link[pb][1]

if na >= n:
    ______②______
    link[q][1] = -1

while na < n:
    link[pa][1] = p
    link[pb][1] = link[p][1]
    pa = link[pa][1]
    pb = link[pb][1]
    ______③______
    na += 1
```


---

## 答案

**正确答案：** （1）BCDF；（2）`p = link[p][1]`；（3）① `c < 0`；② `link[pb][1] = link[q][1]`；③ `p = link[pb][1]`（或 `p = link[link[p][1]][1]`）

---

## 解析

链表长度遍历时需沿后继指针移动，②把交叉节点后继接到较短队伍的后继，③更新待处理节点指针；按两队长度差的符号决定是否移动 `pb`，所以答案分别为 `c<0`、`link[pb][1]=link[q][1]` 和 `p=link[pb][1]`。
