# 题目 12

有如下 Python 程序段：

```python
def poem(lst, q, flag):
    st = ""
    for i in range(7):
        st += lst[q][0]
        q = lst[q][flag]
    print(st)

hw = [["冬", -1, 1], ["梅", 0, 2], ["枝", 1, 3], ["几", 2, 4],
      ["点", 3, 5], ["雪", 4, 6], ["花", 5, 7], ["开", 6, 8],
      ["春", 7, 9], ["信", 8, 10], ["来", 9, 0]]
p = head = 0
flag = 1
step = 3
for i in range(2):
    flag = -flag
    p = hw[head][flag]
    poem(hw, p, flag)  # ①
    for j in range(step):
        p = hw[p][flag]
    poem(hw, p, flag)  # ②
```

关于上述程序段的说法，不正确的是（   ）

- A. 语句①第一次执行时，输出“梅枝几点雪花开”
- B. 语句②第二次执行时，输出“开花雪点几枝梅”
- C. 若将加框处语句改为 `flag += (-1) ** i`，不会影响程序运行结果
- D. 若将 `hw` 中的 `["梅", 0, 2]` 修改为 `["梅", 0, 3]`，输出结果将不含文字“枝”
 
## 答案

**正确答案：** D

## 解析

程序通过每个节点的两个指针字段沿链表方向遍历并打印 7 个字符。修改“梅”节点的后继会改变遍历路径，D 的绝对说法不正确；其余描述符合程序执行结果。
