# 题目 15

某快递中转站配置了 1 条自动分拣线，用于处理每天到达的多批次快递。每批次快递包含编号、到达时间、所需分拣时长（分钟）、类型（分为 1、0 两类，其中 1 类为紧急件，0 类表示普通件）。已知快递站的营业时间为 `[start,end]`。快递分拣规则如下：

① 当快递到达时间相同时，优先处理紧急件，再处理普通件；

② 若某批次快递预计完成时间超过快递站营业结束时间，则进行人工分拣并优先分拣先到达的紧急件。

（1）若 `start` 的值为“08:30”，各快递批次如第 15 题图所示，则编号为 “S02” 的快递的开始检测时间是 ______。

![[attachments/202608A9协作体_15_图1.jpg]]

（2）定义如下 `psort()` 函数，参数 `data` 的每个元素由编号、到达时间、所需分拣时长、类型 4 个数据项构成。函数功能是按快递到达时间升序排列，时间相同时按快递类型降序。请在划线处填入合适代码。

```python
def psort(data):
    n = len(data)
    for i in range(n):
        data[i].append(-1)
    for i in range(0, n - 1):
        for j in range(0, n - i - 1):
            if data[j][1] > data[j + 1][1] or ______①______:
                data[j], data[j + 1] = data[j + 1], data[j]
```

（3）实现程序功能的代码如下，请在划线处填入合适代码。

## 答案

**正确答案：** （1）09:15；（2）① `data[j][1] == data[j + 1][1] and data[j][3] < data[j + 1][3]`；（3）② `curtime = start`；③ `p != -1 and data[i][3] <= data[p][3]`；④ `data[q][4] = i`

---

## 解析

先按到达时间升序、同一时间类型降序排列：S01 先处理，08:55 完成；同为 08:40 的紧急件 S03 接着处理，09:15 完成，因此普通件 S02 从 09:15 开始。人工分拣链表按类型降序插入，遍历条件保证紧急件在前；处理正常件前将 curtime 初始化为营业开始时间。
