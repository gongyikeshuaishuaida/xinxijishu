# 题目 12

12.给定链表 `a`，以表头元素为基准数，将小于基准的节点移动到它的左侧并保持相对顺序，大于等于基准的节点保持不动。程序如下，方框中应填入的正确代码是（ ）

![[attachments/202405-精诚联盟-高三-三模-12_横排1_2.png]]

```python
pivot = a[head][0]
p, r = head, -1
while a[p][1] != -1:
    q = a[p][1]
    if a[q][0] < pivot:
        a[p][1] = a[q][1]
        ______
        r = q
    else:
        p = a[p][1]
```

- A. `if r==-1: a[q][1]=p; head=q; else: a[r][1]=a[q][1]; a[q][1]=r`
- B. `if r==-1: a[q][1]=q; head=q; else: a[r][1]=a[p][1]; a[q][1]=r`
- C. `if r==-1: a[p][1]=q; head=q; else: a[q][1]=a[r][1]; a[r][1]=q`
- D. `if r==-1: a[q][1]=head; head=q; else: a[q][1]=a[r][1]; a[r][1]=q`

---

## 答案

**正确答案：** D

---

## 解析

当 r=-1 时，左侧链表为空，新节点 q 应插到头部并指向原头结点；当 r 已有节点时，q 应插入左侧链表尾部 r 之后，令 `a[q][1]=a[r][1]`、`a[r][1]=q`，从而保持小于基准节点的相对顺序，故选 D。
