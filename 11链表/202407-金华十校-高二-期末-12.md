# 题目 12

使用列表 lnk 模拟链表结构，head 为头指针，每个节点包括性别、身高和后续指针。原链表按先男生再女生升序排列，现要修改链接关系，使链表按先女生再男生升序排列。已知：

```python
lnk = [["男", 178, 1], ["男", 180, 2], ["男", 185, 3],
       ["女", 160, 4], ["女", 172, 5], ["女", 174, -1]]
head = 0
t = head
pre = cur = lnk[head][2]
while lnk[cur][2] != -1:
    if lnk[cur][0] == "男":
        pre = cur
    cur = lnk[cur][2]
```

![[attachments/202407金华十校_12_代码选项图.jpg]]

## 答案

**正确答案：** C

---

## 解析

遍历结束时 cur 指向女生链尾、pre 指向男生链尾。要让女生成为新头结点，应令 head=cur，并把男生链尾 lnk[pre][2] 置为 -1；若未到链尾，还要继续移动 cur，因此 C 的处理完整。
