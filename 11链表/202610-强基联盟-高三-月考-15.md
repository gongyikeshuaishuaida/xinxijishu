# 题目 15

某校园广播站维护一份点播歌单，每首歌曲用一个正整数编号表示。系统按操作日志记录中的序号顺序编辑歌单，支持插入、删除和撤销三种操作，格式如下：

插入操作(`I k x`)：在当前歌单第`k`首歌曲之后插入编号为`x`的歌曲（`k`为0表示插入到歌单最前面）；

删除操作(`D k`)：删除当前歌单第`k`首歌曲；

撤销操作(`U`)：撤销最近一次**尚未被撤销**的插入或删除操作，使歌单恢复到该操作执行前的状态（若被撤销的操作为插入，则移除该次插入的歌曲；若被撤销的操作为删除，则将该次删除的歌曲还原至原位置）。若当前没有可撤销的操作，则该条撤销操作不执行任何动作。

日志中所有的插入、删除操作均保证在执行时位置`k`合法。编写模拟歌单编辑过程的Python程序，其中用到的部分列表方法如第15题图a所示。

(2) 定义如下`pair(ops)`函数，参数`ops`为操作日志列表，`ops[i][0]`为操作类型（`'I'`、`'D'`或`'U'`）。若下标为`i`的日志是一条有效的撤销操作，函数将它所撤销的插入或删除操作的下标存入`res[i]`。函数返回`res`。

```python
def pair(ops):
    stk = []
    res = [-1] * len(ops)
    for i in range(len(ops)):
        if ops[i][0] != 'U':
            stk.append(i)
        elif len(stk) > 0:
            res[i] = stk.pop()
    return res
```

①若`ops`中9条操作的类型依次为I，I，U，U，I，D，U，U，U，则`res[7]`的值为______①______。

②若`ops`的长度为100，则返回的`res`中值为-1的元素个数最少是______②______个。

(3) 实现歌单编辑功能的部分Python程序如下，请在划线处填入合适的代码。

ops=[['I',0,501],['I',1,503],['D',2],['U']]

## 答案

(1) 501、502、503、505。

(2) ①4；②50。

(3) ①`stk.append([1, pre, len(lst)-1])`；②`lst[pre][1] = lst[p][1]`；③`lst[r[1]][1] = r[2]`。

---

## 解析

(1) 前3次插入得到`[501,502,503]`；删除第2首后为`[501,503]`；插入504后为`[501,504,503]`；两次撤销依次撤销插入504和删除502，恢复`[501,502,503]`；最后在第3首后插入505。

(2) 非U操作的下标入栈，U从栈顶取最近未撤销操作。第7条（下标6）撤销下标5，第8条（下标7）撤销下标4，所以`res[7]=4`。每个有效U必须匹配一个非U操作，100条最多50对，最多50项非-1，因此最少50项为-1。

(3) 插入后保存类型1、前驱及新节点下标，供撤销时绕过新节点。删除时让前驱直接指向被删节点的后继，同时保存类型2、前驱和被删节点；撤销删除时把前驱重新指向被删节点即可。节点没有物理删除，原后继仍保留。栈的后进先出规则保证撤销顺序正确。
