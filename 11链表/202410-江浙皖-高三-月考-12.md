# 题目 12

使用列表 `data` 模拟链表，每个节点包含学生编号、性别和指针。现要将链表整理为女生在前、男生在后，并保持男女生各自原有相对顺序：

![[attachments/202410江浙皖_12_男女生链表图.jpg]]

```python
head = 0
p = t1 = t2 = head
p = data[p][2]
data[head][2] = -1
while p != -1:
    t = data[p][2]
    if data[p][1] == "男":
        if data[t2][1] == "女":
            data[t1][2] = p
        else:
            data[t2][2] = p
        t2 = p
        data[p][2] = -1
    else:
        ______方框______
        t1 = p
    p = t
```

方框中应填入（   ）。

- A.

  ```python
  if data[t1][1] == "女":
      data[p][2] = data[t1][2]
      data[t1][2] = p
  else:
      data[p][2] = t1
      head = p
  ```

- B.

  ```python
  if data[t2][1] == "女":
      data[p][2] = data[t2][2]
      data[t2][2] = p
  else:
      data[p][2] = t2
      head = p
  ```

- C.

  ```python
  if data[t1][1] == "女":
      data[p][2] = data[t1][2]
      data[t1][2] = data[p][2]
  else:
      data[p][2] = t1
      head = p
  ```

- D.

  ```python
  if data[t2][1] == "女":
      data[t2][2] = data[p][2]
      data[t2][2] = data[p][2]
  else:
      data[p][2] = t2
      head = p
  ```

---

## 答案

**正确答案：** A

---

## 解析

`t1` 始终指向最后一个女生节点。遇到女生时，若此前已有女生，就把新节点插在 `t1` 后且接回原来的男生链；若头部尚为男生，则把新女生移到链首。这样保持两组内部相对顺序。
