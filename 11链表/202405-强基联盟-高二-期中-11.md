# 题目 11

11.单链表中 b 为 a 的后继，现将节点 b 与其后继节点 c 交换，其余不变。若指针域为 `next[a]`、`next[b]`，语句为：

① `next[next[a]] = b`
② `next[a] = next[b]`
③ `next[b] = next[next[b]]`

正确的执行顺序是（ ）

![[attachments/202405强基_11_链表交换图.jpg]]

- A.①③②
- B.③①②
- C.②①③
- D.②③①

---

## 答案

**正确答案：** D

---

## 解析

先令 a 指向 b 的后继 c（②），再令 b 指向 c 的后继（③），最后把 c 接到 b 后（①），因此顺序为②③①。
