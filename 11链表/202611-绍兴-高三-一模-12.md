# 题目 12

列表 `d` 的全部元素构成一个链表，元素形式为 `[a,b]`，`a`、`b` 分别为节点的数据域和指针域，尾节点的 `b` 值为-1。函数 `findh(d)` 用于找回头指针，若列表 `d` 如第12题图所示，函数返回4。

![[attachments/202611绍兴高三_12_图1.png]]

```python
def findh(d):
    n = len(d)
    pre = [-1] * n
    h = -1
    for k in range(n):
        if d[k][1] == -1:
            h = k
        else:
            pre[d[k][1]] = k
    # 此处为原卷方框
    ______①______
    return h
```

方框中应填入的代码为（   ）

- A. ```python
while pre[h] != -1:
    h = pre[h]
```


- B. ```python
for k in range(n):
    h = pre[h]
```


- C. ```python
while d[h][1] != -1:
    h = pre[h]
```


- D. ```python
while pre[h] != -1:
    h = d[h][1]
```

---

## 答案

**正确答案：** A

---

## 解析

先找到尾节点h，并用pre记录每个节点的前驱。沿 `pre[h]` 向前走，直到前驱为-1，即找到头节点。
