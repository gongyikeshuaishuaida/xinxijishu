# 题目 12

使用列表 `d` 模拟链表结构，头指针为 `head`，每个节点包含数据区域（0～9 的整数）和指针区域。链表的节点按逆序存储一个非负整数，例如链表 `3->2->1` 表示数值 123。现需要将该数值加 `c`（`0<=c<=9`），并将结果以同样的链表结构存储，头指针仍为 `head`。

实现该功能的程序段如下，方框中应填入的正确代码为（   ）

```python
c = int(input())
head = 0
p = head
prev = -1
while p != -1:
    d[p][0] += c
    c = d[p][0] // 10
    d[p][0] %= 10
    prev = p
    p = d[p][1]
if c > 0:
    ______
```

- A.


```python
d.append([c, prev])
d[prev][1] = len(d) - 1
```

- B.


```python
d.append([c, head])
head = len(d) - 1
```

- C.


```python
d.append([c, p])
d[prev][1] = len(d) - 1
```

- D.


```python
d.append([c, -1])
head = len(d) - 1
```

---

## 答案

**正确答案：** C

---

## 解析

遍历结束时`p=-1`，新最高位应追加为尾节点`[c,-1]`，并让原尾节点`prev`指向它；C正好满足。
