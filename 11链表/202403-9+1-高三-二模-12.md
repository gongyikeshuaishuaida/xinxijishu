# 题目 12

使用列表 `a` 模拟链表结构（节点数大于 0），每个节点包含数据区域和指针区域，`head` 为头指针。链表中各节点已按数据区域中的数值由小到大排列。现要计算链表中的中位数，正确代码为（  ）

```python
fast = slow = head
while fast != -1 and ______①______:
    p = slow
    slow = a[slow][1]
    fast = a[a[fast][1]][1]
if ______②______:
    mid = (a[p][0] + a[slow][0]) / 2
else:
    mid = a[slow][0]
print("中位数是:", mid)
```

A．① `slow != -1`；② `fast != -1`

B．① `a[slow][1] != -1`；② `fast == -1`

C．① `a[fast][1] != -1`；② `fast != -1`

D．① `a[fast][1] != -1`；② `fast == -1`

## 答案

**正确答案：** D

## 解析

快指针每次前进两步，循环条件必须保证 `fast` 的下一节点存在，即 `a[fast][1] != -1`。循环结束时 `fast == -1` 表示节点数为偶数，需要将 `p` 和 `slow` 两个中间节点取平均，因此选 D。
