# 题目 12

阅读以下伪代码，为实现对 `a` 数组的排序，`flw` 的最终值应为 `[2, 3, 4, 6, 7, -1, 0, 5]`。

```text
a ← [3, 1, 4, 1, 5, 9, 2, 6]
flw ← [1, 2, 3, 4, 5, 6, 7, 8, -1]
初始化 head ← 0
外层循环 i 从 0, 1, 2, ……, n-2:
    prev ← -1; cur ← head
    内层循环 当 flw[cur] ≠ -1 时:
        nxt ← flw[cur]
        判断：a[cur] > a[nxt]?
            是：
                q ← flw[nxt]
                判断：prev = -1?
                    是：执行 ______(1)______
                    否：执行 ______(2)______
                flw[nxt] ← cur
                flw[cur] ← q
                执行 ______(3)______
            否：
                prev ← cur
                cur ← nxt
    结束内层循环
结束外层循环
```

伪代码中（1）～（3）处可选的表达式有：

① `head ← nxt`　② `cur ← nxt`　③ `flw[prev] ← nxt`  
④ `flw[cur] ← nxt`　⑤ `prev ← cur`　⑥ `prev ← nxt`

则（1）～（3）处的表达式序号依次为（   ）

- A. ①④⑤
- B. ②③⑤
- C. ②④⑥
- D. ①③⑥

---

## 答案

**正确答案：** D

---

## 解析

相邻节点交换后，`nxt` 排在 `cur` 前。若 `cur` 原来是头节点，则令 `head ← nxt`，否则令 `flw[prev] ← nxt`。交换完成后 `cur` 保持不变，继续与新后继比较，其前驱更新为 `nxt`。

原卷初始 `flw` 多写了一个 8，沿后继到下标 8 时会超出 8 元素数组 `a` 的范围。按 8 个节点的题意将初始 `flw` 理解为 `[1, 2, 3, 4, 5, 6, 7, -1]`，代入 D 可得到题给的最终结果。
