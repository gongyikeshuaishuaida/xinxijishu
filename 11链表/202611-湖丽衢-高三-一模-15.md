# 题目 15

某外卖平台有 m 架无人机（编号 0～m-1），无人机满电续航里程为 50 千米，仅能配送往返距离不大于 50 千米的订单。无人机初始为满电状态，不满电且空闲时自动充电，充电时每分钟增加的续航里程为 0.5 千米。现有 n 个订单，每个订单包含 4 个数据：订单编号、下单时刻、配送往返距离、配送时长。平台收到订单时开始调度无人机，调度规则为：先计算出每架无人机（包含空闲的、正在配送的）能开始配送订单的时刻，然后选择开始配送时刻最早的无人机，若存在多架满足要求，则选择编号最小的无人机。例如 n 为 4，m为 2，各订单数据如第 15 题图 a所示，调度结果如第 15题图b所示。

（1）根据调度规则，第 15 题图 a 所示的所有订单完成配送后的时刻为 ▲ 。

（2）定义如下函数 add_seq(head,tail,nxt,k,i)，功能是将订单 i 添加到无人机 k配送的订单序列中，head、tail、nxt列表的元素初始值都为-1。

```python
def add_seq(head,tail,nxt,k,i):
    if head[k] == -1:
        head[k] = i
    else:
        nxt[tail[k]] = i
    tail[k] = i
```

## 答案

（1）145。

（2）4。

（3）① `fly[j][3] <= s`，② `s += (orders[i][2]-fly[j][0])/0.5`，③ `end=fly[k][3]`。

---

## 解析

取所有完成时刻中的最大值 145。0 号无人机的订单链按插入顺序为 0→2→4。若上单完成时间不晚于下单时刻，先补计这段空闲充电；预计续航不足时，用缺口除以每分钟续航增量得到等待时间。原程序②只推迟 s，未同步累计这段额外充电增加的续航，逐单模拟时需同时考虑该状态。
