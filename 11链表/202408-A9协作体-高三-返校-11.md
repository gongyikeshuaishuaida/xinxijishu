# 题目 11

使用列表 `data` 模拟链表结构，每个节点包含数据区域和指针区域。如下图所示，`ha` 和 `hb` 分别为两个链表的头指针，现要找出并返回两个链表相交的起始节点，并输出该节点的数据域值。

![[attachments/202408A9协作体_11_链表结构图.jpg]]

实现该功能的程序如下：

```python
d = []
qa, qb = ha, hb
while qa != -1:
    ______①______
    qa = data[qa][1]
while qb != -1:
    if ______②______:
        print(data[qb][0])
        break
    qb = data[qb][1]
else:
    print("两个链表不相交")
```

上述程序段中可选语句为：

![[attachments/202408A9协作体_11_代码语句表.jpg]]

则（1）、（2）处语句依次为（   ）
- A. ①③
- B. ②④
- C. ①④
- D. ②③

---

## 答案

**正确答案：** D

---

## 解析

判断链表相交必须比较节点下标而不是数据域，因为不同节点可以存相同数据。第一遍将 qa 节点下标加入 d，应选②；第二遍判断 qb 是否在 d 中，应选③，所以选D。
