# 题目 12

使用列表 `d` 模拟链表结构（节点数大于 1），每个节点包含数据区域和指针区域，`h` 为头指针，如图 a 所示。现要对该链表节点进行去重操作，只保留最后一次出现的节点，结果如图 b 所示。程序段如下，方框中应填入的正确代码为（   ）。

![[attachments/202403-强基联盟-高三-二模-12_横排1_2.png]]

```python
lst = [0] * 10
p = h
while p != -1:
    lst[d[p][0]] += 1
    p = d[p][1]
q, p = h, h
while d[p][1] != -1:
    # 此处填空
    pass
```

- A.

  ```python
  if lst[d[p][0]] >= 2:
      if p == h:
          h = d[h][1]
      else:
          d[q][1] = d[p][1]
      lst[d[p][0]] -= 1
  else:
      q = p
  ```

- B.

  ```python
  if lst[d[p][0]] < 2:
      q = p
  elif p == h:
      lst[d[p][0]] -= 1
      h = d[h][1]
  else:
      lst[d[p][0]] -= 1
      d[q][1] = d[p][1]
  ```

- C.

  ```python
  if lst[d[p][0]] >= 2:
      if p == h:
          h = d[h][1]
      else:
          d[d[p][1]][1] = q
      lst[d[p][0]] -= 1
  else:
      q = d[q][1]
  ```

- D.

  ```python
  if lst[d[p][0]] < 2:
      q = d[p][1]
  else:
      if p != h:
          d[q][1] = p
      else:
          h = d[h][1]
      lst[d[p][0]] -= 1
  ```

## 答案

**正确答案：** B

## 解析

第一次遍历统计每个数据值出现次数。第二次遍历时，计数小于 2 的节点保留并令 q=p；计数大于等于 2 的节点删除：若它是头节点就更新 h，否则由前驱 q 跳过当前节点，然后将该数据的计数减一。该逻辑正是选项 B。
