# 题目 15

某物流中转站有 `n` 个货架（编号 0～n-1），每个货架存放有若干包裹。每个包裹有唯一编号和到达时间（时间用整数分钟表示，数值越小表示到达越早）。中转站按以下规则出库，重复执行直到所有货架为空：

① 选择当前包裹数量最多的货架；若包裹数量相同，则选择货架编号最小的货架；

② 从该货架中取出到达时间最早的包裹进行出库；

③ 该货架的包裹数量相应减 1，若数量减为 0，则移除该货架，返回步骤①。

初始每个货架的包裹数量存储在列表 `areas` 中，每个元素格式为 `[货架编号, 包裹数量]`。所有包裹信息存储在列表 `boxes` 中，每个元素格式为 `[货架编号, 到达时间, 包裹编号]`，且 `boxes` 已按到达时间升序排列（若到达时间相同，则按包裹编号升序）。

请回答下列问题：

（1）模拟出库。现在货架数据 `areas` 的值为 `[[0, 2], [1, 3], [2, 3], [3, 1]]`，包裹信息 `boxes` 的值为 `[[1, 5, 'A'], [0, 8, 'B'], [0, 12, 'C'], [3, 15, 'D'], [1, 18, 'E'], [2, 22, 'F'], [2, 25, 'G'], [1, 30, 'H'], [2, 35, 'I']]`。根据题意，模拟中转站的出库，则第一个出库的包裹编号是 ______①______，最后一个出库的包裹编号是 ______②______。

（2）查找第一个要处理的包裹。定义如下函数 `findb(boxes, shelf)`，其功能是在 `boxes` 列表中查找在指定货架 `shelf` 中到达时间最早的包裹，返回该包裹在 `boxes` 中的下标；若该货架没有包裹，则返回 -1。

```python
def findb(boxes, shelf):
    idx = -1
    for i in range(len(boxes)):    # 与 idx = -1 齐平
        if boxes[i][0] == shelf:
            if idx == -1 or boxes[i][1] < boxes[idx][1]:
                idx = i
    return idx
```

请回答①和②两个问题。

① 若某货架的所有包裹到达时间均相同，则该函数返回的是该货架中第一个包裹的下标，这一说法是否正确？______▲______（单选，填字母：A. 正确 / B. 错误）。

② 若加框处条件改为 `boxes[i][1] < boxes[idx][1]`，程序功能是否会受到影响？______▲______（单选，填字母：A. 是 / B. 否）

## 答案

（1）① A，② D。  
（2）① A，② A。  
（3）① `shelf = areas[head][0]`。  
② `boxes = boxes[:first] + boxes[first+1:]`，也可用 `boxes.pop(first)` 或 `boxes[first][0] = -1`。  
③ `head = insertp(areas, areas[head][2], head)`。

---

## 解析

（1）开始时货架 1、2 都有 3 件包裹，先取编号较小的货架 1，其最早到达的包裹是 A。按规则逐次模拟，出库顺序为 A、F、B、E、G、C、H、I、D。

（2）首次匹配时 `idx == -1` 为真，直接记录下标。后续只有到达时间严格更早才更新，因此同到达时间时保留第一件。去掉 `idx == -1` 后首次匹配将与 `boxes[-1]` 比较，若目标包裹就是末项或与末项时间相同，首次匹配就可能无法记录。

（3）链表按剩余包裹数量降序、货架编号升序维护。头节点给出当前货架。包裹出库后应移除该条记录或用非法货架编号标记。若货架仍有包裹，把原头节点按更新后的数量插回以其后继为头的链表。`insertp` 的第二个参数是待插入链表的头，第三个参数是待插入节点。参考答案将 `boxes.pop(first)` 中的 `first` 误写成 `fisrt`，这里按题面变量名填写。
