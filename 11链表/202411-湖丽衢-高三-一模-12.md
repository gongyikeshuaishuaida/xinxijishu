# 题目 12

12. 使用列表 d 模拟链表结构（节点数大于 0），每个节点包含数据区域和指针区域，h 为头指针（头节点数据为奇数），如图 a 所示。现需修改该链表各节点的链接关系，使链表各节点数据区域中的数值按奇数在前，偶数在后排列，结果如图 b 所示。实现该功能的程序段如下，方框中应填入的正确代码为：

![[attachments/202411湖丽衢_12_链表图a至b.png]]

~~~python
p = h
q = d[h][1]
r, tmp = -1, -1
while q != -1:
    if d[q][0]%2 == 0:
        ______①______
    else:
        d[p][1] = q
        p = q
    q = d[q][1]
if d[p][1] == -1 and r != -1:
    d[r][1] = -1
d[p][1] = tmp
~~~

备选代码如下：

- A.

  ~~~python
  if r == -1:
      tmp = q
  else:
      d[r][1] = q
  r = q
  ~~~

- B.

  ~~~python
  if r == -1:
      tmp = q
  else:
      d[r][1] = q
      r = q
  ~~~

- C.

  ~~~python
  if r == -1:
      tmp = q
      r = q
      d[r][1] = q
  r = q
  ~~~

- D.

  ~~~python
  if r != -1:
      d[r][1] = q
  else:
      tmp = q
  r = q
  ~~~

---

## 答案

**正确答案：** A

---

## 解析

偶数节点需要从原链表中摘下并接到偶数链表的尾部。第一次遇到偶数时令 tmp=q 记录偶数链表头指针，之后把前一个偶数节点的指针改为 q，每次都令 r=q 更新尾指针，因此应选 A；循环外再把奇数链表尾部接到 tmp。
