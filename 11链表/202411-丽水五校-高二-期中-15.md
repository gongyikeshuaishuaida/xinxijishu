# 题目 15

15. 某音乐播放软件中，播放列表中包括歌曲名称和其热度，并按照热度降序排列。用户可以进行以下操作：

一．删除歌曲：用户选中歌曲将其从播放列表中删除。

二．添加歌曲：用户输入歌曲名称和热度将其添加到播放列表中，需维持热度降序排列。

该软件使用链表 `lst` 存储播放列表，每个节点包括歌曲名称、热度和指针区域，`head` 存储链表头节点位置，请回答下列问题。

（1）若 `lst=[["晴天",123,2],["小美满",138,0],["苹果香",104,-1]]`，`head=1`，现需删除歌曲《晴天》，应修改（   ）的值（单选，填字母）

- A. `lst[0]`
- B. `lst[1]`
- C. `lst[2]`
- D. `head`

（2）实现删除歌曲功能的 `remove_song` 函数如下，请在划线处填入合适代码。

```python
def remove_song(lst,head,song):
    if lst[head][0]==song:
        ______①______
    else:
        p=head;q=lst[p][2]
        while lst[q][0]!=song:
            p=q
            q=lst[q][2]
        ______②______
    return head,lst
```

（3）实现添加歌曲功能的 `add_song` 函数如下，请在划线处填入合适代码。

```python
def add_song(lst,head,song,fever):
    if len(lst)==0:
        lst.append([song,fever,-1])
        head=0
    else:
        if ______①______:
            lst.append([song,fever,head])
            head=len(lst)-1
        else:
            p=head;q=lst[p][2]
            while q!=-1 and fever<lst[q][1]:
                p=q
                q=lst[q][2]
            lst.append(______②______)
            lst[p][2]=len(lst)-1
    return head,lst
```

---

## 答案

**参考答案：**

- （1）B
- （2）① `head=lst[head][2]`；② `lst[p][2]=lst[q][2]`
- （3）① `fever>lst[head][1]`（或 `fever>=lst[head][1]`）；② `[song,fever,q]`（或 `[song,fever,lst[p][2]]`）

---

## 解析

（1）当前链表顺序为下标 1 的“小美满”指向下标 0 的“晴天”，下标 0 再指向下标 2。删除下标 0 的节点时，应让前驱下标 1 直接指向下标 2，所以修改 `lst[1]` 的指针区域。

（2）如果删除的是头节点，头指针改为原头节点的后继；删除其他节点时，前驱 `p` 的指针改为待删节点 `q` 的后继，从链表链接中跳过 `q`。

（3）新歌曲热度高于当前头节点时插入表头；否则沿链表寻找第一个热度不低于新歌曲的节点位置，在 `p` 和 `q` 之间插入 `[song,fever,q]`，并把 `p` 的指针改为新节点下标，以保持热度降序。
