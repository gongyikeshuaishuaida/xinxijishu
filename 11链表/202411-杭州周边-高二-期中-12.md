# 题目 12

12. 节点数均大于0的2个链表 `a` 与 `b`，每个节点包含数据区域和指针区域，`ha` 和 `hb` 分别为链表 `a` 和 `b` 的头指针，链表中各节点已按数据区域中数值大小升序排列，且 `a[ha][0]<b[hb][0]`。现将链表 `b` 中的数据合并到链表 `a` 中，仍保持升序排列，实现该功能的程序段如下：

```python
ha = hb = 0
q = ha
while hb != -1:
    ______①______
    if p == -1 or a[p][0] > b[hb][0]:
        a.append([b[hb][0], p])
        a[q][1] = len(a) - 1
        ______②______
    ______③______
```

上述程序中方框处可选语句为：

- ① `q = a[q][1]`
- ② `p = a[q][1]`
- ③ `hb = b[hb][1]`

则（1）、（2）、（3）处语句依次是（   ）

- A. ③①②
- B. ①③②
- C. ②③①
- D. ②①③

---

## 答案

**正确答案：** C

---

## 解析

在当前 `q` 节点之后寻找插入位置，首先令 `p=a[q][1]`，所以（1）为②。若插入了 `b[hb]`，应让 `hb` 移到 `b` 的后继，故（2）为③；完成当前节点处理后，`q` 沿 `a` 链表后移，故（3）为①。顺序为②③①，即 C。
