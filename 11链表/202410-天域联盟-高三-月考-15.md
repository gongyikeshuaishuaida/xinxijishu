# 题目 15

某省举行大型考试，需要输入分数区间的最低分和最高分，统计区间人数，并按成绩降序输出学校名称、准考证号和成绩。考试数据与学校信息分别如下：

![[attachments/202410天域联盟_15_考试与学校数据表.jpg]]

（1）680～698分有2185人，690～698分有708人，则680～689分有 ______①______ 人。

（2）定义学校代码查询函数：

```python
def search(school, key):
    i, j = 0, len(school) - 1
    while i <= j:
        m = (i + j) // 2
        if school[m][0] > key:
            j = m - 1
        else:
            i = m + 1
    return school[j][1]
```

给定学校代码列表：`0101,0103,0501,0803,0804,0909`。

①查找`key="0909"`需要比较 ______②______ 次。  
②若把`return school[j][1]`改为`return school[m][1]`，下列哪组数据能测出问题？______③______（单选，填字母：A.`0101` / B.`0103` / C.`0803` / D.`0909`）。

（3）补全程序：


---

## 答案

**正确答案：** ① 1477；② 3；③ A；④ `data[i][3] = head[k]`；⑤ `p = head[i]`；⑥ `sum[low] - sum[high + 1]`

---

## 解析

人数相减得 `2185-708=1477`。查询 0909 时中点依次落在 0501、0804、0909，共 3 次。查 0101 时最后一次循环的 `m` 不等于最终 `j`，可暴露错误返回值。各分数用链表头数组串起考生；后缀和 `sum[x]` 表示不低于 x 的人数，因此闭区间人数为 `sum[low]-sum[high+1]`。
