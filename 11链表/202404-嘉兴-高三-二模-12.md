# 题目 12

12.使用列表 `d` 模拟链表结构（节点数大于 0），每个节点包含数据区域和指针区域，`head` 为头指针。现要删除链表中数据值在 `[begin,end]` 范围的节点，实现该功能的部分程序段如下，方框中应填入的正确代码为：

```python
d = [[4, 5], [10, 2], [12, 4], [1, 0], [16, -1], [7, 1]]
head = 3
q = head
p = head
while p != -1:
    if d[p][0] < begin or d[p][0] > end:
        q = p
        p = d[p][1]
    else:
        ______①______
```

## 解析

删除当前节点时，若当前节点不是头结点，应令前驱 `q` 跳过当前节点；若当前节点就是头结点，则更新 `head`；两种情况最后都要把 `p` 移到原后继。因此选项 A 的指针更新顺序和分支条件完整正确。
