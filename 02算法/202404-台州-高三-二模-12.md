# 题目 12

有如下 Python 程序段：

```python
s1 = input()
n = len(s1)
s1 = s1 + s1
i, j = 0, 1
while i < n and j < n:
    k = 0
    while k < n and s1[i+k] == s1[j+k]:
        k += 1
    if s1[i+k] > s1[j+k]:
        i = i + k + 1
    else:
        j = j + k + 1
    if i == j:
        j += 1
    k = min(i, j)
```

执行程序后，下列说法正确的是（   ）

- A. 变量 i 与变量 j 的和可能大于 3*n
- B. 程序执行过程中变量 i 一定小于变量 j
- C. 该算法时间复杂度为 O(n²)
- D. 若输入 s1 为“abaada”，执行后 k 为 5

## 答案

**正确答案：** D

## 解析

这是寻找字符串最小循环表示的线性算法。i、j 的增量保证总步数是 O(n)，i 不必始终小于 j；对“abaada”模拟后最小表示起点为 5，最终 k=min(i,j)=5。
