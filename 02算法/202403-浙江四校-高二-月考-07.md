# 题目 07

某算法流程图如图所示，其对应的 Python 程序是（   ）

![[attachments/202403浙江四校_07_流程图.jpg]]

- A.

  ```python
  s = 0
  for i in range(1, 101):
      if i % 5 == 0:
          s = s + i
      else:
          i = i + 2
  print(s)
  ```

- B.

  ```python
  s = 0
  i = 1
  while i <= 100:
      if i % 5 == 0:
          s = s + i
      else:
          i = i + 2
  print(s)
  ```

- C.

  ```python
  s = 0
  for i in range(1, 101):
      if i % 5 == 0:
          s = s + i
      i = i + 2
  print(s)
  ```

- D.

  ```python
  s = 0
  i = 1
  while i <= 100:
      if i % 5 == 0:
          s = s + i
      i = i + 2
  print(s)
  ```

## 答案

**正确答案：** D

## 解析

流程图从 `i=1` 开始循环到 100：遇到 5 的倍数累加并进入下一轮，否则将 `i` 增加 2。只有 D 的 `while` 结构和分支更新方式与流程图一致。
