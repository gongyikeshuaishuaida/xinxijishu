# 题目 08

某电影院对“快速入场通道”设置如下规则：若为会员（`v` 为真），不限身高；非会员要求身高在 120 厘米及以上。下列分支语句中的代码描述不正确的是（   ）

```python
# A
if v:
    ok = True
else:
    ok = h >= 120

# B
ok = h >= 120
if v:
    ok = True

# C
ok = False
if h >= 120:
    ok = True
if v:
    ok = True

# D
if h >= 120:
    ok = True
elif not v:
    ok = False
```

- A. 代码 A
- B. 代码 B
- C. 代码 C
- D. 代码 D

---

## 答案

**正确答案：** D

---

## 解析

代码 A、B、C 都能让会员直接通过，并让身高不足 120 厘米的非会员不能通过。代码 D 在 `h < 120` 且 `v` 为真时两个分支都不执行，变量 `ok` 没有被正确赋值，因此描述不正确的是 D。
