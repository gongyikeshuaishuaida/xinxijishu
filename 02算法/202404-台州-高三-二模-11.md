# 题目 11

用 last 将数组划分为两部分，使小于 key 的整数位于 last 左侧。程序中先随机选取 key 并与 a[0] 交换：

```python
k = randint(0, n-1)
key = a[k]
a[0], a[k] = a[k], a[0]
（1）______
for i in range(1, n):
    if a[i] < key:
        （2）______
        （3）______
a[0], a[last] = a[last], a[0]
```

可选语句：
① last = -1
② last = 0
③ a[last], a[i] = a[i], a[last]
④ last += 1
⑤ a[last] = a[i]

- A. ①③④
- B. ①④⑤
- C. ②④③
- D. ②⑤③

## 答案

**正确答案：** C（②④③）

## 解析

key 被放在 a[0]，last 从 0 开始。扫描到小于 key 的元素时先将 last 加 1，再与 a[last] 交换，循环结束再把 key 与 a[last] 交换，故填 ②、④、③。
