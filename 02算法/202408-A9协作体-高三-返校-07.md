# 题目 07

某同学根据流程图编写了如下 Python 程序段：

![[attachments/202408A9协作体_07_成绩判断流程图.jpg]]

```python
n = int(input())
if n < 60:
    s = "D"
if n < 75:
    s = "C"
elif n < 90:
    s = "B"
else:
    s = "A" 
```

用下列输入数据测试程序段与流程图，两者得到的 `s` 值不同的是（   ）
- A. 100
- B. 75
- C. 60
- D. 50

---

## 答案

**正确答案：** D

---

## 解析

流程图采用互斥分支，输入50时结果为D；程序中的第二个 if 独立执行，50先令 s='D'，随后又因 n<75 改为C，因此两者不同。其余三个输入结果一致。
