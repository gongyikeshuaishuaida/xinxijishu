# 题目 15

15.某学校有 `n` 个社团组织招新（社团编号为 `1-n`），每个社团最多可招收 `m` 人。学生在线提交申请信息，提交内容为社团编号和对该社团的喜好程度（1-5 分），学生可同时提交报名多个社团，但只能被 1 个社团录取。后台自动记录学生的报名序号和全部报名信息。

报名信息和录取结果如下：

![[attachments/202404-金华十校-高三-二模-15_横排1_2.png]]

（1）若每个社团最多招收3人，1、2、3号社团抽签序号仍为1、3、2，对图中数据重新执行招录操作，则3号社团录取的学生为 ______①______。

（2）定义`px(clubs)`函数，参数`clubs`存储社团编号及抽签序号。若将加框处语句改为`for i in range(n-1)`，执行`a = px(clubs)`，正确选项为 ______②______（单选，填字母）：

```python
def px(clubs):
    n = len(clubs)
    ans = []
    for i in range(n-1):
        for j in range(n-1, i, -1):
            if clubs[j][1] < clubs[j-1][1]:
                clubs[j], clubs[j-1] = clubs[j-1], clubs[j]
        ans.append(clubs[i][0])
    return ans
```

- A. `[5,3,1,4,2,6]`
- B. `[5,3,1,4,2]`
- C. `[5,3,1,4,6,2]`
- D. `[5,3,1,4,6]`

（3）实现社团招录功能的 Python 代码如下，请在程序中划线处填入合适的代码。


## 答案

**正确答案：** ① 2、5；② B；③ `item[1][x + 1]`；④ `x = f[i][fs]`；⑤ `flag[j] == False and t > 0`

---

## 解析

（1）按社团抽签顺序 1、3、2 和每社团最多 3 人重新招录，3 号社团最终录取报名序号 2、5 的学生。

（2）`px` 的冒泡排序每轮把当前最小抽签序号移到前部；把外层循环改为 `range(n-1)` 后只追加前 5 个社团编号，得到选项 B。

（3）报名信息每两个数据为社团编号和喜好程度，因此 ①取 `item[1][x+1]`；按抽签社团和喜好分读取报名序号，②为 `x=f[i][fs]`；录取时必须保证学生尚未录取且社团仍有名额，③为 `flag[j] == False and t > 0`。
