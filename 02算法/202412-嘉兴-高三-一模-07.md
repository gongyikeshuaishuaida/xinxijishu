# 题目 07

某系统规定密码输入错误5次后账号锁定，验证算法流程图如下图所示。程序片段如下：

~~~python
if c<5:
    print('第',c,'次输入错误！')
    pwd = input('请重新输入密码:')
else:
    print(c,'次输入错误，账号已锁定')
    f = True
~~~

![[attachments/202412嘉兴_07_密码验证流程图.png]]

7. 测试程序时发现少了计数代码 c+=1，该代码应添加的位置是（   ）

- A. “else:”的上一行
- B. “else:”的下一行
- C. “if c<5:”的上一行
- D. “if c<5:”的下一行

---

## 答案

**正确答案：** A

---

## 解析

只有密码错误且账号尚未锁定时才需要继续计数。计数语句应放在错误处理分支进入 if c<5 判断之前，即放在 else: 的上一行，使每次错误输入都先将 c 加1，再判断是否达到5次。
