# 题目 15

10 个区域由 8 个传感器覆盖，每个传感器的覆盖能力用 10 位二进制数表示。需要选择最少传感器覆盖所有区域，传感器覆盖表如下。

![[attachments/202406温州十校_15_传感器覆盖表.jpg]]

（1）选择传感器 s1、s2、s3、s5 时，综合覆盖能力为 ______①______（填 10 位二进制数）。

（2）函数 `f(a,b)` 计算两个传感器的综合覆盖能力，参数为二进制字符串，请改正函数中错误的条件：

~~~python
def f(a, b):
    s = ""
    for i in range(len(a)):
        if ______②______:
            s += "1"
        else:
            s += "0"
    return s
~~~

（3）选择最少传感器实现全覆盖的程序中，请填空：

~~~python
for i in range(1, 256):
    g = "0000000000"; tmp = ""
    ______③______
    for j in range(8):
        c = i % 2
        if c == 1:
            cnt += 1
            g = f(g, ______④______)
            top += 1
            st[top] = "s" + str(8 - j)
        i //= 2
    if g == "1111111111" and cmin > cnt:
        cmin = cnt
        while top != -1:
            tmp += st[top] + ","
            ______⑤______
        ans = tmp[:-1]
~~~

---

## 答案

**正确答案：** ①`1111111111`；②`a[i] == "1" or b[i] == "1"`；③`cnt = 0`；④`k[7-j]`；⑤`top -= 1`

---

## 解析

综合覆盖取各传感器覆盖位的逻辑或，s1、s2、s3、s5 的或结果为全 1。枚举传感器组合时 `cnt` 记录本组合选中的数量；循环从最低位开始，`j=0` 对应 s8，所以应取 `k[7-j]`；记录完一个传感器后用 `top -= 1` 弹出栈顶。
