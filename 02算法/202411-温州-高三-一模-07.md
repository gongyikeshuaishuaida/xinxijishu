# 题目 07

将十进制数 a 转换为二进制并循环右移 b 位的部分流程图如下，如 a 为 18、b 为 3 时，输出结果为“01010”。虚线框中的内容是（   ）

![[attachments/202411温州高三_07_循环右移主流程图.png]]

![[attachments/202411温州高三_07_循环右移选项.png]]

---

## 答案

**正确答案：** C

## 解析

18 的二进制为 10010，循环右移 3 位后为 01010。流程从低位开始逐位取余，前 b 位应逆序拼接到 s1 的前端，剩余位逆序拼接到 s2 的前端，因此虚线框中应先判断 b>0，在满足时执行 (s1\leftarrow c+s1)，再令 b 减 1；选项 C 的流程满足这一逻辑。
