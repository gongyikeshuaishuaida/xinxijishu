# 题目 15

15.小明采集了 `n` 种原料，每种原料的分析依次经过放射试验和加热试验。实验室各只有一台相应仪器，同一时间最多只能进行一个放射试验和一个加热试验。为尽早完成试验，将放射试验时间短的尽量排前面，加热试验时间短的尽量排后面。

示例原料的试验时间、安排顺序和最早结束时间如下图。

![[attachments/202406北斗联盟_15_试验时间表与安排.jpg]]

（1）自定义函数 `order(task,n)` 安排合理的试验顺序：

```python
def order(task,n):
    f=[False]*n
    st=-1; ed=n
    for i in range(n):
        min=30000
        for j in range(n):
            if f[j]==False:
                for k in range(1,3):
                    if task[j][k]<min:
                        min=task[j][k]
                        bestj=j
                        bestk=k
        if bestk==1:
            st+=1; odr[st]=bestj
        else:
            ed-=1; odr[ed]=bestj
```

若 `task=[['A',5,2],['B',4,2],['C',1,8]]`、`n=3`：

①调用函数后，`st` 和 `ed` 的值分别为 `______①______`、`______②______`。

②将虚线框处代码改为 `for j in range(n-1,-1,-1)`，是否会影响原料试验的安排顺序？`______③______`（A.会 / B.不会）。

③上述程序中划线处应填入的正确代码是 `______④______`。

请在划线处填入合适的代码。

---

## 答案

**正确答案：** （1）① 0；② 1；③ A；④ `f[bestj]=True`。
（2）⑤ `tm[i]=tm[i-1]+task[odr[i]][1]`；⑥ `tot+=task[j][2]`（或等价写法）。

---

## 解析

这是 Johnson 两台设备流水调度：选出当前最短工时，若在放射试验机上则从前端排入，否则从后端排入。示例中 `st=0、ed=1`；改变遍历方向会改变相同最短工时的选取顺序。`f[bestj]` 标记已安排原料。`tm` 记录每种原料结束放射试验的时间，加热试验开始时间取当前加热设备时间与 `tm[i]` 的较大值。
