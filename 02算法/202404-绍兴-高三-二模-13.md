# 题目 13

13.现代诗的连排格式为各句以“/”分开，按右起竖式打印。

![[attachments/202404绍兴高三_13_竖式诗句图.jpg]]

（1）对“ABC/CBDA”按右起竖式打印，第三行为 ______①______。

（2）程序中划线处：

```python
s=[]; t=""
poem += "/"
for c in poem:
    if c != "/":
        ______②______
    else:
        s.append(t)
        t=""
maxlen=0
______③______
for i in range(maxlen):
    t=""
    for j in range(n):
        if ______④______:
            t=s[j][i]+t
        else:
            t=" "+t
    print(t)
```

---

## 答案

**正确答案：** ① DC；② `t = t + c`；③ `n = len(s)`；④ `len(s[j]) - 1 >= i`（或`len(s[j]) > i`）

---

## 解析

按右起竖式对齐后，ABC和CBDA的第三行形成DC。遍历字符时把非分隔符追加到当前句；分隔后统计句子数；按列打印时只有当第j句长度覆盖第i列才取字符，否则补空格。
