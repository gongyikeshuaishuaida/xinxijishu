# 题目 08

某算法的部分流程图如下所示。执行这部分流程后，输出 `s` 的值为 64，则①处应填入（   ）

![[attachments/202403精诚联盟_08_流程图.jpg]]

- A. `i // 4 == 2`
- B. `i ** 0.5 == int(i ** 0.5)`
- C. `i % 2 == 1`
- D. `i % 2 == 0`

## 答案

**正确答案：** D

## 解析

`s` 初值为 1，`i` 从 0 到 10。若在偶数 `i` 时执行 `s=s*2`，共执行 6 次，最终为 `2^6=64`，所以判断条件是 `i % 2 == 0`。
