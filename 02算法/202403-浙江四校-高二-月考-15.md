# 题目 15

某地区中考录取采用“平行志愿”的投档录取方式：按考生总分从高到低投档；每位考生依次尝试三个志愿学校，学校有剩余招生名额时录取，否则尝试下一个志愿；所有学校完成计划招生数后停止投档。程序从文件读取考号、总分及三个志愿学校代码（1—5），输出各校计划招生数、实际招生数、录取分数线和最低录取名次。

第15题图 b 为输出结果表：

（1）若 A 校计划招生 520 人，B 校计划招生 480 人，C 校计划招生 540 人，某同学考分名次为 490 名，三个志愿依次为 B 校、A 校、C 校，且已知同名次人数最多有 30 人，则该同学不可能被哪所学校录取（填字母）：______。

（2）程序读取所有考生后已按总分降序存入 `stuInfo`，其中 `stuInfo[0]` 存储考号、总分、三个志愿。请在划线处填空：

```python
stuCnt = len(stuInfo)
schCnt = 5
zsCnt = [620, 680, 460, 480, 520]
zsCnt2 = [0] * schCnt
stuMc = [0] * stuCnt
minScore = [0] * schCnt
minMc = [0] * schCnt
f = [False] * schCnt
finished = 0
i = 0
preScore = -1

while ______①______ and finished < schCnt:
    if stuInfo[i][1] == preScore:
        stuMc[i] = stuMc[i-1]
    else:
        ______②______
    preScore = stuInfo[i][1]
    for j in range(2, 5):
        school = stuInfo[i][j] - 1
        if zsCnt2[school] < zsCnt[school]:
            ______③______
            minScore[school] = stuInfo[i][1]
            minMc[school] = stuMc[i]
            break
        else:
            if ______④______:
                f[school] = True
                finished += 1
    i += 1
```

## 答案

**正确答案：** （1）C；（2）① `i < stuCnt`；② `stuMc[i] = i + 1`；③ `zsCnt2[school] += 1`；④ `f[school] == False`（或 `not f[school]`）。

## 解析

同分考生共享名次。该考生若第一志愿 B 未录取，按其名次和 A 校计划数会在第二志愿 A 校录取，因此不会继续尝试第三志愿 C，故不可能被 C 校录取。程序循环条件防止访问越界；不同分数段的名次为当前下标加 1，同分沿用上一名次。每当某校录满且尚未标记，就把 `f` 置为真并累加 `finished`，各校计划数与实际数分别维护。
