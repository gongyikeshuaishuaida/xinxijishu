# 题目 13

小涵想借助一篇文章来背 `n` 个单词。已知该文章由 `m` 个单词构成，为了提高效率，她想在文章中找到一段连续的、最短的段落，使得该段落包含她想要背的单词是最多的。

例如：小涵要背的 `n` 个单词为 `a=['hot','dog','milk','meat']`，文章中的 `m` 个单词为 `b=['hot','dog','dog','milk','hot','milk','dog']`。示例输出如下：

![[attachments/202412Z20_13_输出界面.jpg]]

段落①②③都包含了最多个小涵要背的单词，①的长度大于②，故选②；②和③的长度相同，故选最先出现的②。

请回答下列问题：

（1）假设小涵要背的 `n` 个单词为 `a=['hot','dog','milk','meat']`，文章中的 `m` 个单词为 `b=['pie','hot','jam','dog','milk','hot','dog']`，则包含最多单词的最短段落在第 ______①______ ～ ______②______ 位置。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 小涵要背的 n 个单词存放在列表 a 中，文章的 m 个单词存放在列表 b 中，代码略
n = len(a); m = len(b)
cnt = length = L = st = 0
s = {}
for i in range(n):
    s[a[i]] = 0    # s 记录要背的单词及其出现的次数，次数的初值为 0
for i in range(m):
    x = b[i]
    if x in s:
        s[x] += 1
        if s[x] == 1:
            cnt = ______③______
            length = i-L+1
            while L <= i:    # 调整当前最短段落的左边界 L，以查找符合要求的段落
                y = b[L]
                if y not in s:
                    L += 1
                    continue
                if ______④______:
                    s[y] = 1
                    L += 1
                    continue
                break
            if length > i-L+1:
                length = i-L+1
                ______⑤______
print("包含最多单词的最短段落在第", st+1, "~", st+length, "位置")
print("共包含了她想要背的单词中的", cnt, "个")
```

## 答案

**参考答案：**

- （1）① 4；② 6
- （2）③ `cnt+1`；④ `s[y]>1`；⑤ `st=L`

## 解析

给定文章中，位置 4～6 的连续片段为 `dog、milk、hot`，覆盖 3 个不同的目标单词，长度为 3，且是满足最大覆盖数的最短片段。字典 `s` 记录目标单词的出现次数；首次出现目标单词时令 `cnt` 加 1。左端点移动时，只有当 `s[y]>1` 才能安全删除当前单词并继续缩短窗口。若新窗口更短，则记录 `st=L`。
