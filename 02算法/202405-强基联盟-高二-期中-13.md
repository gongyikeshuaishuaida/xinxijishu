# 题目 13

13.给定 n 个非负整数表示柱状图各柱高度，柱宽均为1，求可勾勒出的最大矩形面积。例如 `h=[2,1,5,6,2,3]` 的最大面积为10。

![[attachments/202405-强基联盟-高二-期中-13_横排1_2.png]]

（1）若柱高依次为 `2、4、5、6、3、5`，最大矩形面积为 ______。

（2）补全程序：

```python
def maxArea(h):
    max_area=0
    for i in range(len(h)):
        left=i
        while ______①______:
            left-=1
        right=i
        while right < len(h)-1 and h[right+1] >= h[i]:
            ______②______
        area=(right-left+1)*h[i]
        if area>max_area:
            ______③______
    return max_area
```

---

## 答案

**正确答案：** （1）15；（2）① `left>0 and h[left-1]>=h[i]`；② `right-=1`；③ `max_area=area`

---

## 解析

以每个柱子为最低高度向左右扩展，得到高度5、宽3的矩形面积15为最大值。向左扩展条件是相邻柱高不小于当前高度，向右循环每次递减 right；面积更大时更新最大值。
