# 题目 07

7.算法如下：

~~~text
输入两个正整数 m 和 n
r ← m 除以 n 的余数
while r ≠ 0:
    m ← n，n ← r，r ← m 除以 n 的余数
输出 n
~~~

若输入 m、n 分别为 24、16，输出 n 的值为（ ）

- A.2
- B.4
- C.6
- D.8

---

## 答案

**正确答案：** D

---

## 解析

这是辗转相除法：24 除以 16 余 8，16 除以 8 余 0，最终输出 n=8。
