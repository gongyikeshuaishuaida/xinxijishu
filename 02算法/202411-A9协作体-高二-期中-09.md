# 题目 09

9. 某 Python 算法的代码如下：

```python
list1 = [1, 3, 5, 7, 9]
sum = 0
for i in list1:
    sum += i
print(sum)
```

和以上代码输出结果相同的流程图如下图所示，则填空部分代码为（   ）

![[attachments/202411A9协作体_09_流程图.png]]

- A. ① `sum←0, i←0`　② `i>1?`　③ `sum←sum+i, i←i+2`
- B. ① `sum←0, i←1`　② `i>1?`　③ `sum←sum+i, i←i+2`
- C. ① `sum←0, i←1`　② `i<10?`　③ `sum←sum+list1[i], i←i+1`
- D. ① `sum←0, i←0`　② `i<5?`　③ `sum←sum+list1[i], i←i+1`

---

## 答案

**正确答案：** D

---

## 解析

列表 `list1` 的下标范围是 `0`～`4`。流程图需要先初始化 `sum=0`、`i=0`，当 `i<5` 时累加 `list1[i]`，再将 `i` 加 1，循环结束后输出 `sum`，所以应选 D。
