# 题目 15

某字符串按字符出现次数越多编码长度越短、出现次数越少编码长度越长的规则进行编码。每个字符初始为一个对象，反复选择次数最小和次小的对象（次数相同则选择最前面的对象），分别更新编码值为 0 和 1，合成为新对象，直到合成为一个对象。若字符串由若干个相同字符组成，编码为“0”。

![[attachments/202403温州_15_哈夫曼编码图.jpg]]

（1）根据编码规则，字符串“success”中字符“c”的编码为 ______。

（2）定义 `min_index(lst, head)` 函数，参数 `lst` 的节点包含对象、次数、编码值和指针四项。函数返回两个最小次数节点及其前驱，表示出现次数最小的节点位置变量名为 ______。

```python
def min_index(lst, head):
    preml = None
    ml = pre_p = prem2 = head
    m2 = p = lst[head][3]
    while p != -1:
        if lst[ml][1] > lst[p][1]:
            m2 = ml
            prem2 = preml
            ml = p
            preml = pre_p
        elif lst[m2][1] > lst[p][1]:
            m2 = p
            prem2 = pre_p
        pre_p = p
        p = lst[p][3]
    return preml, ml, prem2, m2
```

## 答案

**正确答案：** （1）`10`；（2）`ml`；（3）① `p = lst[p][3]`；② `lst[ml][1] + lst[m2][1]`；③ `prem2 == ml`。

## 解析

按最小次数优先合并构造哈夫曼树，字符 c 在图中得到编码 10。`ml` 是当前最小次数节点，`m2` 是次小节点；沿链表指针推进得到编码前缀。新节点次数为两节点次数之和，删除第一个节点后，若第二个节点的前驱正是第一个节点（`prem2 == ml`），需改用原前驱再删除第二个节点。
