# 题目 15

乐乐参加商场打折活动。每个商品有原价和优惠价，乐乐有 p 次机会以优惠价购买商品，希望在总金额不超过 m 元的前提下尽可能多购买商品。商品价格表和程序运行结果如下：

![[attachments/202407金华十校_15_商品价格表.jpg]]

（1）若有 2 次优惠价购买机会，购买全部 4 件商品至少需要的金额 m 为 ______。
（2）函数 get_sort(data, k) 返回按第 k 列升序排列后的商品编号列表，请补全：

```python
def get_sort(data, k):
    n = len(data)
    b = [i for i in range(n)]
    for i in range(n):
        for j in range(n - i - 1):
            if ______:
                b[j], b[j + 1] = b[j + 1], b[j]
    return b
```

（3）程序运行结果如图所示，请补全划线代码：

![[attachments/202407金华十校_15_程序运行截图.jpg]]

```python
org = get_sort(data, 0)
pre = get_sort(data, 1)
r = [0] * p
f = [False] * n
ans = []
i = j = cnt = 0
while ______①______:
    while f[org[i]]:
        i += 1
    while f[pre[j]]:
        j += 1
    if ______②______:    # 用优惠价购买商品更划算
        d = pre[j]
        cost = data[d][1] + r[0]
        r[0] = data[d][0] - data[d][1]
        k = 0
        while k < p - 1 and r[k] > r[k + 1]:
            r[k], r[k + 1] = r[k + 1], r[k]
            k += 1
    else:
        d = org[i]
        cost = data[d][0]
        if m < cost:
            break
        m -= cost
        ______③______
        ans.append(d)
        cnt += 1
```

---

## 答案

**正确答案：** （1）11；（2）data[b[j]][k] > data[b[j + 1]][k]；（3）① cnt < n；② data[org[i]][0] > data[pre[j]][1] + r[0]；③ f[d] = True。

---

## 解析

两次优惠应优先用于折扣最大的商品 2 和商品 3，原价总和 19 减去折扣 5、3 得 11。冒泡排序在前一项大于后一项时交换。购物循环最多处理 n 件商品；当优惠价加当前最小折扣低于原价时使用优惠，否则按原价购买，并把已购商品标记为 True。
