# 题目 13

某活动招募志愿者，将所有报名学生按照身高排成一排，然后从中选出连续的若干个人，使得选出的人中男女人数相等。

（1）若9位报名学生依次排队后的性别序列为 `[0,1,0,0,0,1,1,0,0]`（0代表女生，1代表男生），最长的一段男女人数相等的子序列长度为 ______①______。

S0、S1分别为到当前学生女生、男生的总人数，统计结果如下：

![[attachments/202410新阵地_13_前缀人数统计表.jpg]]

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
def solve(n, a):
    qzh = [0] * (n + 1)
    for i in range(1, n + 1):
        if a[i - 1] == 0:
            qzh[i] = qzh[i - 1] - 1
        else:
            qzh[i] = ______①______
    for Lth in range(______②______, 1, -2):  # 枚举子序列长度，长度为偶数
        for i in range(n - Lth + 1):          # 枚举子序列起点
            if ______③______:
                return Lth
    return -1  # 如果没有找到符合条件的子序列，则返回-1

# 读取输入人数 n，排队后的性别序列为 a，代码略
ans = solve(n, a)
# 输出结果，代码略
```

---

## 答案

**正确答案：** （1）6；（2）① `qzh[i-1]+1`；② `n-n%2`；③ `qzh[Lth+i]-qzh[i]==0`

---

## 解析

把女生记为 -1、男生记为 +1，`qzh` 记录前缀和。某连续段男女人数相等，当且仅当该段和为0，即两端前缀和相同。候选长度必须为偶数，所以从不超过 `n` 的最大偶数 `n-n%2` 开始递减枚举。
