# 题目 07

某算法的流程图如下，依次输入 1、1、0、1、2，则输出 `s` 的值是（  ）。

![[attachments/202402浙南_07_流程图.jpg]]

A．0

B．7

C．13

D．26

## 答案

**正确答案：** C

## 解析

输入 1、1、0、1 时均满足 `a<=1`，按 `s=s*2+a` 依次得到 1、3、6、13；下一次输入 2 满足 `a>1`，输出 13。
