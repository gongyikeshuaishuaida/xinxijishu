# 题目 11

哥德巴赫猜想：任意一个大于等于 4 的偶数，都可以用两个素数之和表示。素数是一个大于等于 2 的整数，并且只能被 1 和本身整除，而不能被其他整数整除的数。验证程序如下，横线处的选项正确的是（   ）

~~~python
def prime(num):
    for i in range(①):
        if num%i==0:
            ②
    return True

a=int(input('请输入一个大于等于4的偶数：'))
for i in range(2,a):
    j=a-i
    if ③:
        print('YES')
        print(str(a)+' ='+str(i)+' +'+str(j))
        break
~~~

- A. ① `2,num`；② `return False`；③ `prime(i) and prime(j)`
- B. ① `2,num`；② `return True`；③ `prime(i) and prime(j)`
- C. ① `2,num+1`；② `break`；③ `not prime(i) and not prime(j)`
- D. ① `2,num+1`；② `return False`；③ `not prime(i) and not prime(j)`

## 答案

**正确答案：** A

## 解析

判断 `num` 是否为素数时，应枚举 `2` 到 `num-1` 的除数，即 `range(2,num)`；发现可以整除就应返回 `False`，循环结束仍未找到因数才返回 `True`。对 `i` 和 `j=a-i`，二者都为素数时才输出，所以第三空为 `prime(i) and prime(j)`。
