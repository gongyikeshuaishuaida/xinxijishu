# 题目 15

影片平台根据样本影片的搞笑、拥抱、打斗镜头数据，使用距离公式和近邻投票确定新影片类型。样本数据与《美人鱼》的特征如下：

![[attachments/202401湖州_15_图1.jpg]]

![[attachments/202401湖州_15_图2.jpg]]

距离最近的前5部影片为：唐人街探案19.62、罗马假日22.56、新步步惊心22.83、泰坦尼克号23.45、我的特工爷爷24.92。

（1）该影片属于（单选，填字母：A.喜剧片 / B.动作片 / C.爱情片）。

（2）`mvmin(result,flag)`函数从未标记的距离中找最小值。若 `result=[43,33,18,25,65]`，`flag=[False,False,True,True,False]`，函数返回值为 ______①______。

```python
def mvmin(result,flag):
    mv=10000
    for i in range(len(result)):
        if mv>result[i] and flag[i]==False:
            mv=result[i]
            pos=i
    return pos
```

## 答案

**正确答案：** （1）C；（2）1；（3）② `data[i][j]-x[j]`（或相反数）；③ `flag[p]=True`；（4）可调整`k`值、按距离大小加权投票或调整距离算法等。

---

## 解析

（1）前5部影片中，爱情片有罗马假日、新步步惊心和泰坦尼克号3部，喜剧片1部、动作片1部，因此多数投票得到爱情片C。

（2）被标记的下标2、3不能再选，未标记距离中最小的是33，对应下标1。

（3）每个特征的差值为 `data[i][j]-x[j]`，平方后累加得到欧氏距离；选出最近样本后要用 `flag[p]=True` 标记，避免下一轮重复选择。

（4）可把投票改为按距离倒数加权，或增大/调整`k`并设置同票时的距离优先规则，从而打破并列。
