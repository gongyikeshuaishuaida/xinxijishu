# 题目 13

某算法如下：对任意一个正整数 n，若 n 为偶数，下一步将其除以2；若 n 为奇数，下一步将其乘以3再加1，不断重复，经过有限次运算后得到1。编写程序验证这一算法。

（1）当 n=10 时，数据的变化过程是：10→______①______→1。

（2）实现上述算法的 Python 程序段如下，请在划线处填入合适的代码。

~~~python
n=int(input("请输入一个整数："))
if n>0:
    print("变化过程为：", n, end="")
    while n!=1:
        if ______②______:
            n=n//2
        else:
            ______③______
        print("→", n, end="")
else:
    print("输入错误，请重新输入")
~~~

（3）该程序段采用的算法是（单选，填字母：A.解析算法/B.枚举算法）。

---

## 答案

**正确答案：** ① 5→16→8→4→2；② n%2==0；③ n=n*3+1；（3）A

---

## 解析

10为偶数，依次得到5、16、8、4、2，下一步得到1。程序用 n%2==0 判断奇偶，偶数执行整除2，奇数执行 3*n+1。它按照明确的规则逐步求出结果，属于解析算法，而不是逐一尝试所有可能值的枚举算法。
