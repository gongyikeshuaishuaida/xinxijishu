# 题目 15

独桥搬箱。有 k 名工人，要将 n 个箱子从旧仓库（河右岸）搬到新仓库（河左岸），只能通过一座桥通行。按照如下规则过桥：

①每次只能有一个人过桥，且右边等待的人先过桥；

②若一边有多人等待过桥，则过桥总用时短的人先过桥（过桥总用时=空手过桥用时+搬箱过桥用时）；

③若过桥总用时相同，则工人编号小的先过桥。

使用 time 记录了每位工人空手过桥、到旧仓库取箱子返回桥边、搬箱过桥、放箱子到新仓库返回桥边的用时。开始时，工人们都在桥的左边等待。计算最后一个搬运箱子的工人到达河左岸的时间。

例如 n=3，k=2，time=[[1,4,1,3],[5,5,5,5]]，则最后一个搬运箱子的工人在第17分钟到达河左岸。过程如第15题图所示。

（1）题干示例中，若将 n 改为4，则最后一个搬运箱子的工人到达河左岸的时间是 ______①______。

（2）定义如下 insertQue(quetype,i) 函数，实现了工人 i 在桥左边或右边排队，其中 quetype 表示4个状态：0表示处于空手过桥状态，1表示处于到旧仓库取箱子返回桥边的状态，2表示处于搬箱过桥状态，3表示处于放箱子到新仓库返回桥边的状态。

~~~python
def insertQue(quetype,i):
    que[i]=-1
    if head[quetype]==-1:
        head[quetype]=i
    else:
        p=head[quetype]
        while p!=-1:
            if quetype in [0,2]:
                if time[p][0]+time[p][2]>time[i][0]+time[i][2]:
                    break
                if time[p][0]+time[p][2]==time[i][0]+time[i][2] and p>i:
                    break
            else:
                if finishtime[p]>=finishtime[i]:
                    break
            q=p
            p=que[p]
        if p==head[quetype]:
            que[i]=p
            head[quetype]=i
        else:
            que[q]=i
            que[i]=p
~~~

## 答案

**参考答案：**

- （1）① 26
- （2）② [2,-1,-1,-1]；③ [-1,0,1]
- （3）④ fn=n；⑤ head[2]=que[w]（或 head[2]=que[head[2]]）；⑥ curtime=min(finishtime[wh],finishtime[wh2])（或使用 head[1]、head[3]）

## 解析

将 n 改为4后按“右侧等待者优先、同侧按过桥总时间再按编号”逐事件模拟，最后一个搬箱工人在第26分钟到达左岸。insertQue 使用链式队列按空手过桥时间与搬箱过桥时间之和排序，工人2的总过桥时间为4，小于工人1的15和工人0的15，所以插入队首，链为 2→1→0，得到 head=[2,-1,-1,-1]、que=[-1,0,1]。主程序中 fn 记录剩余箱子数，初始化为 n；工人 w 离开右侧过桥队列后，需令 head[2] 指向其后继；两侧都有人在返回途中时，下一事件时间取两人的完成时间较小值。
