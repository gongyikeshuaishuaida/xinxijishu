# 题目 15

有 `n` 个小雪球，每次将任意两个雪球滚到一起，消耗的体力等于两个雪球重量之和，目标是使总耗费最少。

（1）现有 6 个小雪球，重量依次为 `1,3,5,7,2,6`，则滚成一个大雪球所耗费的总体力为 ______。

（2）定义 `sort(lst)` 函数对雪球重量升序排序。调用函数，若 `lst=[4,8,3,9,2,7]`，则加框处的交换语句执行次数为 ______。

```python
def sort(lst):
    for i in range(1, n):
        for j in range(0, n-i):
            if lst[j] > lst[j+1]:
                lst[j], lst[j+1] = lst[j+1], lst[j]
    return lst
```

（3）主程序如下，请在划线处填入合适的代码。

```python
# 读入所有雪球的重量，并存入列表 a 中，代码略
n = len(a)
sort(a)
w = 0; headA = 0
headB = -1; tailB = 0
while headA < n or ______①______:
    t = 0
    for i in range(______②______):
        if headA < n:
            if headB < tailB:
                if a[headA] < a[headB]:
                    t += a[headA]
                    headA += 1
                else:
                    t += a[headB]
                    headB += 1
            else:
                t += a[headA]
                headA += 1
        else:
            t += a[headB]
            headB += 1
    w += t
    ______③______
    tailB += 1
print("耗费的总体力为:", w)
```

## 答案

**正确答案：** （1）57；（2）8；（3）① `headB+1<tailB`（或 `headB<n-2`）；② 2；③ `a[tailB]=t`。

## 解析

按最小合并策略依次合并 `1+2=3`、`3+3=6`、`5+6=11`、`6+7=13`、`11+13=24`，总耗费为 `3+6+11+13+24=57`。冒泡排序中满足交换条件的次数为 8。主程序把原数组和新生成的合并结果视为两个有序队列，每轮取出最小的两个数合并，并把新重量写入 B 队列尾部。
