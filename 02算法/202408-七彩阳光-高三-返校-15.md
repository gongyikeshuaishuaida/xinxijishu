# 题目 15

两个车间的产品用0和1交替组成原始序列，连续相同字符为一个块。每组取出每个块最左侧产品，取完后相邻同车间块合并。

（1）产品序列“001100010011”时，第二组抽取的产品序号是 ______①______。

（2）主程序对原始产品序列进行处理，输出每次分组的结果，请补全程序。

~~~python
s=s+"."
sel=[False]*len(s)
q,k,begin=[],0,0
for i in range(1,len(s)):
    if ______②______:
        q.append([begin,i-1,s[i-1]])
        begin=i
i=0
cnt=len(s)-1
while cnt>0:
    print("第"+str(i+1)+"组：",end="")
    q2=selection(q,0,len(q))
    i+=1
    print("")
    q=mergence(q2,0,len(q2))
~~~

（3）`selection`函数实现产品抽取，请补全程序。

~~~python
def selection(q,head,tail):
    global cnt
    q2=[]
    while head<tail:
        F=q[head]
        head+=1
        while ______③______:
            F[0]+=1
        print(F[0]+1,end=" ")
        cnt-=1
        sel[F[0]]=True
        if F[0]==F[1]:
            continue
        ______④______
        q2.append(F)
    return q2
~~~

（4）`mergence`函数实现产品抽取后剩余产品的调整，请补全程序。

```python
def mergence(q2,head2,tail2):
    q=[]
    while head2<tail2:
        X=q2[head2]
        head2+=1
        while head2<tail2:
            Y=q2[head2]
            if X[2]==Y[2]:
                ______⑤______
                head2+=1
            else:
                break
        q.append(X)
    return q
```

---

## 答案

**正确答案：** ① 2、4、6、12；② s[i]!=s[i-1]；③ sel[F[0]]==True；④ F[0]+=1；⑤ X[1]=Y[1]。

---

## 解析

序列“001100010011”第一组取出1、3、5、8、9、11，剩余块合并后第二组取2、4、6、12。分块时字符发生变化就结束前一块；selection遇到已标记元素要继续向后找，并在输出后把块首加1；mergence把相同字符的相邻块的结束位置更新为后一块结束位置。
