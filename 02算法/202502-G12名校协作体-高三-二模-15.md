# 题目 15

有 `n` 种原材料，这些材料将被用在 `k` 条不同的流水线进行产品加工，每个流水线所需的材料各不相同。每个流水线的材料需求用一串 `n` 位、由 0、1 和 -1 三种值组成的数表示：1 表示当前流水线必须使用该材料；0 表示该材料可加可不加；-1 表示当前流水线不需要该材料。例如 `0110-1-1` 表示当前流水线必需第 2、3 种材料，不需要第 5、6 种材料，第 1、4 种材料可有可无。

通过编程计算能否找到一个用最少原材料种类且满足所有流水线需求的最佳生产方案。两条流水线需求及最佳方案如图所示。

![[attachments/202502G12名校协作体_15_流水线材料需求表.jpg]]

（1）现在有 3 种原材料，4 条流水线分别给出的需求为 `1，0，1`；`1，-1，0`；`0，0，1`；`1，-1，1`。能满足所有流水线的原材料生产方案为 ______（用原材料编号顺序、01 组成的串表示生产方案）。

（2）定义 `chan(s,n,k)` 函数，将 01 字符串 `s` 转换成包含 `k` 个数据元素、每个数据元素包含 `n` 个数据项的数据存储形式。

```python
def chan(s, n, k):
    a = [[] for i in range(k)]
    p = 0
    i = 0
    while p < len(s):
        if s[p] != "-":
            a[i].append(int(s[p]))
            p += 1
        else:
            a[i].append(int(s[p:p + 2]))
            p += 2
        if len(a[i]) == n:
            i += 1
    return a
```

若字符串 `s` 的值为 `"110-10101-1-1-11"`，调用 `chan(s,6,2)` 函数，则语句 `i+=1` 的执行次数为 ______。

（3）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 读取原材料种类 n、流水线数量 k 及 k 条流水线的材料需求，代码略
# s 的格式形如 "1011-100011-11"
b = [0] * (n + 1)
a = chan(s, n, k)
p = True
while ______①______:
    j = n
    while b[j] == 1:
        j -= 1
    b[j] = 1
    for i in range(j + 1, n + 1):
        ______②______
    p = False
    for i in range(len(a)):
        for j in range(len(a[i])):
            if a[i][j] == 1 and b[j + 1] == 0 or ______③______:
                p = True
    if p == True:
        print("无最佳原材料生产方案！")
    else:
        for i in range(1, n + 1):
            if b[i] == 1:
                print("原材料", i, "必须生产")
            else:
                print("原材料", i, "无需生产")
```

## 答案

**参考答案：**

- （1）`101`
- （2）2
- （3）① `p==True and b[0]==0`；② `b[i]=0`；③ `a[i][j]==-1 and b[j+1]==1`

## 解析

四条流水线的必需材料并集为第 1、3 种材料，因此最少方案为 `101`。字符串中两个数据元素各包含 6 个数据项，所以 `i+=1` 执行 2 次。程序从高位材料开始枚举组合，先清除被回溯位置之后的选择；若某流水线要求某材料不生产却发现该材料已选，或要求某材料生产却未选，则当前方案不满足约束。
