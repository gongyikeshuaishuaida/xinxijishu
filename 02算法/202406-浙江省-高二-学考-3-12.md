# 题目 12

随机生成一个长度为 n、仅由大写字母 A、B、C 组成的字符串。若存在连续三个或更多的相同字符，则将该连续段删除，并重复处理。

例如字符串 ACCBBBBCBC 可先删除 BBB，再删除 CCC，最终得到 ABC。

（1）若字符串为 ABBBAACCB，按规则消除后字符串为 ______①______。

（2）请在下列程序划线处填入代码：

    import random

    def left(s, x):
        while x-1 >= 0 and s[x] == s[x-1]:
            x = x-1
        return x

    def right(s, x):
        while x+1 <= len(s)-1 and s[x] == s[x+1]:
            ______②______
        return x

    def strs(n):
        s = ""
        for i in range(n):
            m = ______③______
            s = s + chr(ord("A") + m)
        return s

    K = int(input("请输入字符串的长度："))
    s = ______④______
    i = 0
    while i < len(s):
        L = left(s, i)
        R = right(s, i)
        if R-L+1 >= 3:
            s = s[:L] + s[R+1:]
            i = L
        else:
            i = i+1
    print("最后的字符串为：", s)

---

## 答案

**正确答案：** （1）CCB；（2）x=x+1；（3）random.randint(0,2)；（4）strs(K)；条件判断可写 R-L+1>=3（或等价表达）。

---

## 解析

left 和 right 分别向连续字符段的左右边界扩展。right 每次发现右侧相同字符就将下标加 1。随机生成 A、B、C 时取 0、1、2 的随机整数；主程序调用 strs(K)。ABBBAACCB 先删去 BBB 得到 AAACCB，再删去 AAA，最终为 CCB。
