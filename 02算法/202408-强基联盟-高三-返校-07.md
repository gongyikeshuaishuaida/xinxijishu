# 题目 07

导航软件按车速判断拥堵并显示颜色，流程图如下。

![[attachments/202408强基联盟_07_流程图.jpg]]

以下代码与流程图功能一致的是（   ）

- A.

  ```python
  if x < 50:
      if x <= 20:
          print("红")
      else:
          print("黄")
  else:
      print("绿")
  ```

- B.

  ```python
  s = "红"
  if x >= 50:
      s = "绿"
  else:
      s = "黄"
  print(s)
  ```

- C.

  ```python
  s = "绿"
  if x < 20:
      s = "红"
  elif x >= 20:
      s = "黄"
  print(s)
  ```

- D.

  ```python
  s = "黄"
  if x < 20:
      s = "红"
  elif x >= 50:
      s = "绿"
  print(s)
  ```

---

## 答案

**正确答案：** D

---

## 解析

流程图的分段条件为 x<20 红色、20≤x<50 黄色、x≥50 绿色。D完整对应三个互斥区间，其他选项边界或分支结构不正确。
