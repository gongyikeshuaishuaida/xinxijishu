# 题目 07

某算法的流程图如第7题图所示，若数组`a`的初始值为`[4, 3, 7, 2, 6, 9, 5]`，执行该算法流程后，输出的结果为（   ）

![[attachments/202610浙南_07_图1.png]]

- A. `[9, 7, 6, 5, 4, 3, 2]`
- B. `[5, 7, 6, 9, 4, 2, 3]`
- C. `[4, 7, 6, 9, 5, 2, 3]`
- D. `[2, 3, 4, 7, 6, 9, 5]`

---

## 答案

**正确答案：** B

---

## 解析

以 `a[0]=4` 为比较基准，`i`初值为1。`j`依次扫描其余元素，遇到大于4的元素时与 `a[i]` 交换，再令 `i`加1。扫描结束得到 `[4, 7, 6, 9, 5, 2, 3]`，此时 `i=5`。最后交换 `a[0]` 与 `a[i-1]`，输出 `[5, 7, 6, 9, 4, 2, 3]`。
