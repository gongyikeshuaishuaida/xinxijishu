# 题目 13

编号为 0~8 的开关组成一个 3 行 3 列的开关阵列，如第 13 题图所示。每个开关状态为“开”（1）或“关”（0），每操作某个开关 1 次，将导致自身和所有相邻的开关改变状态。例如，操作开关 4 将导致开关 1、3、4、5、7 改变状态。

![[attachments/202411绍兴_13_开关阵列.png]]

指定一组操作对象序列 P，序列元素 Pi 为开关编号。对 P 中开关依次各执行 1 次操作后，求开关阵列的状态，并判断其中某个开关 S 的状态是否改变。请回答：

（1）若 P 为 [0,2,5,6,7]，执行操作后，开关阵列中状态发生变化的开关编号是 ______①______（填数字）。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

~~~python
while True:
    # 操作对象序列、开关阵列状态数据存入 P、d，d[0]~d[8] 表示开关 0~8 的状态，代码略
    t = int(input("请输入开关 S 的编号："))
    ______①______
    q = [0] * 9
    for x in P:
        q[x] += 1
        if ______②______:    # 左
            q[x-1] += 1
        if x-3 >= 0:          # 上
            q[x-3] += 1
        if x % 3 < 2:         # 右
            q[x+1] += 1
        if x+3 <= 8:          # 下
            q[x+3] += 1
    for i in range(9):
        d[i] = ______③______
    if pre == d[t]:
        print("开关 S 的状态未改变")
    else:
        print("开关 S 的状态改变")
~~~

---

## 答案

**正确答案：** （1）0；（2）① pre = d[t]；② x % 3 - 1 >= 0；③ abs(d[i] - q[i] % 2)

## 解析

对 P 中每个开关操作一次时，q[i] 统计开关 i 被自身或相邻操作影响的次数。q[i] 的奇偶性决定 d[i] 是否翻转，因此新状态可写为 abs(d[i] - q[i] % 2)。编号 x 存在左邻居的条件是 x%3-1≥0。记录操作前的 d[t] 后，再与更新后的 d[t] 比较即可。

对于 P=[0,2,5,6,7]，按相邻关系统计后只有编号 0 的状态发生变化。
