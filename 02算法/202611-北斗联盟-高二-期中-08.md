# 题目 08

某同学根据第 8 题图所示流程图编写的 Python 程序段如下：

```python
x = int(input("请输入一个整数："))
if x < 30:
    y = -1
if x < 60:
    y = 0
else:
    y = 1
```

用下列输入数据测试该程序段与流程图，两者得到的 y 值不同的是（   ）

![[attachments/202611北斗联盟高二_08_图1.png]]

- A. 20

- B. 45

- C. 60

- D. 75

---

## 答案

**正确答案：** A

---

## 解析

流程图对 x<30 时赋值 -1，程序的第二个 if 却会把该值覆盖为 0，所以输入 20 时不同。
