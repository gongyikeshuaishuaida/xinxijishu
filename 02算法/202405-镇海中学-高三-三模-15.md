# 题目 15

给定 `m` 个区间和一个数组，要求按各区间的取值范围把数组依次分隔成 `m+1` 段。若第 `p` 段末尾连续元素同时属于第 `p+1` 个区间，则这些元素为第 `p` 段的重叠块。

![[attachments/202405镇海高三_15_区间分段示意图.jpg]]

（1）给定两个区间 `[10,50]`、`[30,80]`，数组为 `12,44,34,45,66,50,45,70`，第 1 段“重叠块”中元素个数为 ______①______ 个。

（2）完善程序：

```python
def IsIn(k, p, m):
    # judge if k in interval p
    if p > m:
        return False
    else:
        if ______①______:
            return True
        else:
            return False

a = [10,20,33,58,46,55,62,69,78,66,57,18,19,16,36,26,5,9]
b = [0,5,10,25,30,70,50,80,5,15,10,20]
ans = []
n = len(a); m = len(b) // 2
i = 0; p = 1
cnt1 = 0; cnt2 = 0
while ______②______:
    if IsIn(a[i], p, m):
        if IsIn(a[i], p + 1, m):
            cnt2 += 1
        else:
            ______③______
        cnt2 = 0
        i += 1
    else:
        ans.append(cnt1); ans.append(cnt2)
        cnt1 = 0; cnt2 = 0; p = p + 1
if i < n:
    ans.append(______④______)
else:
    ans.append(cnt1); ans.append(cnt2)
for p in range(1, m + 1):
    print('第', p, '段:', ans[p * 2 - 2], ans[p * 2 - 1])
print('剩余段:', ans[-1])
```

---

## 答案

**正确答案：** （1）3；（2）① `b[2*(p-1)]<=k<=b[2*p-1]`；② `i<n and p<=m`；③ `cnt1=cnt1+cnt2+1`；④ `n-i`

---

## 解析

第 1 段中的元素 12、44、34、45 均属于 `[10,50]`，其中末尾的 44、34、45 也属于第 2 区间 `[30,80]`，所以重叠块长度为 3。程序中用 `b[2*(p-1)]` 与 `b[2*p-1]` 判断元素是否在第 p 个区间；只要数组和区间都未处理完就继续循环。当前元素属于本段但不属于下一段时，之前累计的重叠块转为本段非重叠块，并将当前元素计入，所以 `cnt1=cnt1+cnt2+1`；区间处理完后的剩余元素数为 `n-i`。
