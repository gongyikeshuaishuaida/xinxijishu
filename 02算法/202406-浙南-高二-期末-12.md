# 题目 12

有如下 Python 程序段：

    from random import randint
    def find(x, y, key):
        m = (x + y + 1) // 2
        if a[m] == key:
            return m
        elif a[m] > key:
            y = m - 1
        else:
            x = m + 1
        if x > y:
            return -1
        return find(x, y, key)

    a = [1, 3, 6, 10, 11, 12, 17, 21]
    x = randint(1, 9) * 2 + 1
    print(find(0, len(a)-1, x))

上述程序执行完后，函数 find 被调用的次数不可能的是

- A. 1 次
- B. 2 次
- C. 3 次
- D. 4 次

---

## 答案

**正确答案：** D

---

## 解析

x 的取值为 3、5、7、9、11、13、15、17、19。二分查找在数组长度为 8 时最多需要 3 次调用，不能达到 4 次，因此 D 不可能。
