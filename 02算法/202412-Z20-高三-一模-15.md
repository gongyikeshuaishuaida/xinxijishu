# 题目 15

小乐收集了近一年来学校贴吧的数据，准备将这些帖子按其收到的总点赞数从高到低进行排名，并统计哪些帖子是曾经的“热帖”。在任意连续的 `d` 天内（0～`d-1` 视为连续 `d` 天）总共收到不少于 `k` 个赞就称为“热帖”。最后输出这些“热帖”近一年来的总点赞数及其排名。请回答下列问题。

（1）贴吧的点赞数据经预处理后存入列表 `a`，存储的格式为：`a=[[t,id,c],……]`，每个元素表示第 `t` 天编号为 `id` 的帖子收到 `c` 个赞。如果将“7 天内收到不少于 3 个赞”判定为“热帖”，则当
`a=[[0,0,2],[0,1,1],[0,2,1],[5,1,1],[7,1,2],[7,2,2],[10,3,2],[20,3,1]]` 时，统计得到的“热帖”编号为 ______①______。

（2）定义如下 `pm(q)` 函数，参数 `q` 的每个元素由 4 个数据项组成，函数的功能是根据第 3 个数据项的值进行排名，值最大的为第 1 名，若值相同，则排名也相同，第 4 个数据项用于存放名次。

例如：若 `q=[[0,8,15,1],[1,6,20,1],[4,7,30,1],[6,9,20,1]]`，程序运行后得到 `q=[[0,8,15,4],[1,6,20,2],[4,7,30,1],[6,9,20,2]]`。

（3）实现上述所有功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
"""
读取 maxn 条帖子的 data，每条帖子有若干个点赞数据
读取 n 个点赞数据，存储在列表 a 的 a[0] 至 a[n-1]，并根据 a[i][0] 的值进行升序排序
读取判定为“热帖”的连续时间长度 d 和点赞数 k
代码略
"""
f = [False] * maxn
q = [[-1,-1,0,1] for i in range(maxn)]
for i in range(n):
    a[i].append(-1)
    id = a[i][1]
    ______③______
    if f[id]:
        continue
    if q[id][0] == -1:
        q[id][0] = i
    if q[id][1] != -1:
        a[q[id][1]][3] = i
    q[id][1] = i
    while q[id][0] != -1 and ______④______:
        q[id][0] = a[q[id][0]][3]
    cur = q[id][0]
    num = a[cur][2]
    while cur != -1:
        cur = a[cur][3]
        num += a[cur][2]
    if num >= k:
        f[id] = True    # 标记为“热帖”
pm(q)    # 对所有帖子的总点赞数进行排名
for i in range(maxn):    # 输出“热帖”近一年来的总点赞数及其排名
    if f[i]:
        print("热帖编号为",i,"总点赞数为",q[i][2],"排名为",q[i][3])
```

（4）加框处的代码有误，应修改为 ______⑤______。

## 答案

**参考答案：**

- （1）① 1
- （2）② `q[i][3] += 1`
- （3）③ `q[id][2] += a[i][2]`；④ `a[i][0]-a[q[id][0]][0]+1>d`
- （4）⑤ `while cur != q[id][1]:`（或等价地使用 `while a[cur][3] != -1:`）

## 解析

帖子 1 在第 1～7 天内累计收到 1+1+2=4 个赞，属于热帖；其余编号在任意连续 7 天内都达不到 3 个赞。排名函数统计比当前帖子总赞数更大的帖子数并加 1，因此填 `q[i][3] += 1`。处理每条点赞记录时先累加到对应帖子的总数，再用首尾时间差维护 7 天窗口。遍历链表统计总赞数时，原程序在 `cur` 已变为 `-1` 后仍访问 `a[cur][2]`，应在到达该帖子的最后一条记录时停止。
