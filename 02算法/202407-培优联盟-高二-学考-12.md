# 题目 12

寻找关联次数最多的商品。销售记录按交易清单号升序排列，同一交易清单号的商品表示同时购买。数据表与程序运行效果如下：

![[attachments/202407-培优联盟-高二-学考-12_横排1_2.png]]

（1）若 a=[81001, 81001, 81002, 81003, 81003, 81003]，b=[“茶叶蛋”, “烤肠”, “电池7号”, “烤肠”, “康师傅红烧牛肉面”, “茶叶蛋”]，则“茶叶蛋”和“烤肠”的关联次数为 ______。

（2）函数 add(x,y) 将两种商品的关联次数加 1，关联信息存入列表 c。删除加框处代码后，统计到的关联次数将（增多/减少/不变）：

```python
c = []

def add(x, y):
    flag = False
    for i in range(len(c)):
        if c[i][0] == x and c[i][1] == y or c[i][0] == y and c[i][1] == x:
            c[i][2] += 1
            flag = True
    if flag == False:
        c.append([x, y, 1])
```

（3）相同交易清单号的记录连续，函数 work(start,end) 处理区间内的商品。请修正加框代码：

```python
def work(start, end):
    for i in range(start, end + 1):
        for j in range(________③________, end + 1):
            add(b[i], b[j])
```

（4）调用 work 处理列表 a、b，请补全：

```python
i = 0
for j in range(1, len(a)):
    if ________④________:
        work(i, j - 1)
        i = j
work(i, j)
```

（5）求关联次数最大值，请补全：

```python
p = 0
for i in range(1, len(c)):
    if ________⑤________:
        p = i
print("关联度最高的两件商品为：", c[p][0], c[p][1], "关联次数：", c[p][2])
```

---

## 答案

**正确答案：** （1）2；（2）减少；（3）i+1；（4）a[j] != a[j-1]（或 a[i] != a[j]）；（5）c[i][2] > c[p][2]。

---

## 解析

同一交易清单号中每一对不同商品只计一次，因此内层循环应从 i+1 开始。删除无序配对判断会漏掉商品顺序相反的关联，次数减少。遇到交易清单号变化时处理上一段，最后比较每条关联信息的次数并更新最大值索引。
