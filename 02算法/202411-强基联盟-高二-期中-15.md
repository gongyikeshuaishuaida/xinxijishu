# 题目 15

列表的连续子序列是指从列表中选取连续的若干个元素（至少一个元素）组成的新列表。例如，对于列表 a=[1,2,3]，其子序列有 [1]、[1,2]、[1,2,3]、[2]、[2,3]、[3]。现要查找列表 a 中和最大的连续子序列，并输出该子序列。实现该功能的程序段如下，方框中应填入的正确代码为（   ）。

~~~python
a=[1,-2,3,4,-5,6,-1]
# 初始化 maxs 为负无穷大，代码略
start=end=0
for i in range(len(a)):
    ans=0
    j=i
    while j<len(a):
        ______①______
        j+=1
print("最大子序列为：",a[start:end+1])
print("最大子序列的和为：",maxs)
~~~

原题四列代码选项如下：

![[attachments/202411强基联盟_15_代码选项.png]]

- A.

  ~~~python
  ans+=a[j]
  if maxs<ans:
      maxs=ans
      start=i
      end=j
  ~~~

- B.

  ~~~python
  start=i
  if maxs<ans:
      maxs=ans
      end=j
      ans+=a[j]
  ~~~

- C.

  ~~~python
  if maxs<ans:
      maxs=ans
      start=i
      end=j+1
      ans+=a[j]
  ~~~

- D.

  ~~~python
  start=i
  ans+=a[j]
  if maxs<=ans:
      maxs=ans
      end=j
  ~~~

---

## 答案

**正确答案：** A

## 解析

每次循环应先把 a[j] 加入当前连续子序列，再将当前和与 maxs 比较；若更大，就同时记录起点 i 和终点 j。A 的顺序和下标均正确。程序最终找到的最大连续子序列为 [3,4,-5,6]，其和为 8。
