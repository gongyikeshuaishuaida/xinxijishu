# 题目 15

某大型农场自动灌溉系统同时为多个农作物区域提供水分。每个任务包含开始时间、结束时间和需要灌溉的单位时间量，任务可在开始到结束时间内分段完成。为减少系统开启时间，先按结束时间升序排列，再按“优先安排重叠时段、剩余时间安排在最靠后时段”的规则处理.

![[attachments/202404杭州_15_灌溉时段图.png]]

（1）若灌溉任务为 `[[2,4,1],[4,7,1],[3,7,3],[6,9,2]]`，系统总计需开启 ______ 个单位时间段。

（2）按结束时间升序排列的函数中，冒泡内层循环的空白处应填（单选，A. `i+1,n` / B. `n-1,i,-1`）。

（3）实现安排灌溉任务的部分程序如下，请填空：

```python
def arrange(task):
    n = len(task)
    st = [[0,0] for i in range(n)]
    top = -1
    ______①______
    task = sort_task(task)
    for item in task:
        start, end, dur = item[0], item[1], item[2]
        k = 0
        while k <= top and start > st[k][1]:
            k += 1
        if k <= top:
            for i in range(k+1, top+1):
                ______②______
            if start < st[k][0]:
                dur = dur - (st[k][1] - st[k][0])
            else:
                dur = dur - (st[k][1] - start)
        if dur > 0:
            res += dur
            tl = end
            while ______③______:
                dur = dur - (tl - st[top][1])
                tl = st[top][0]
                top -= 1
            top += 1
            st[top] = [tl-dur, end]
    return res
```

（4）若把查找重叠区间的线性循环改为二分查找，给定 `st=[[2,3],[4,6],[8,9],[11,12],[13,15]]`、`start=12`、`top=4`，修改后循环执行次数与原代码相比（单选）：

- A. 增加
- B. 减少
- C. 不变

## 答案

**正确答案：**

- （1）4
- （2）B（`n-1,i,-1`）
- （3）① `res = 0`；② `dur -= st[i][1]-st[i][0]`；③ `top != -1 and tl - st[top][1] <= dur`（`< dur` 亦可）
- （4）B

## 解析

任务按结束时间排序后，先扣除与已安排区间重叠的时段，再从当前任务结束时间向前选择最靠后的空档。①初始化总开启时长；②移动到更靠后的已安排区间时扣除该区间长度；③只要栈非空且当前区间向前覆盖的时长不超过剩余时长，就继续合并。二分查找在有序区间上定位重叠位置，比较次数少于从头线性扫描。
