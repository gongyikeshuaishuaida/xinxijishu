# 题目 07

某算法的部分流程图如下，执行该流程图后，下列说法不正确的是（   ）

![[attachments/202412北斗联盟_07_算法流程图.png]]

- A. `s` 的值为 4
- B. `i` 的值为 22
- C. 若循环条件“`i<=20?`”改成“`i<=22?`”不影响程序的输出结果
- D. 当第 3 次执行循环条件“`i<=20?`”时，`i` 的值为 7

## 答案

**正确答案：** C

## 解析

初始 `s=1，i=1`。每轮循环后 `i` 增加 3，循环时 `i` 依次为 1、4、7、10、13、16、19；其中 `i=4` 和 `i=16` 时满足 `i%4==0`，使 `s` 连续乘 2，最终输出 `s=4，i=22`。若条件改为 `i<=22`，还会多执行 `i=22` 这一轮，输出的 `i` 会变为 25，因此 C 不正确。
