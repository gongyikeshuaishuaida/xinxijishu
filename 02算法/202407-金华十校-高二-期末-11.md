# 题目 11

若 xh = [0,1,2,3,4,6,7,8]，运行如下程序段后，输出结果为（ ）

```python
def search(i, j):
    m = (i + j) // 2
    if i > j:
        return j
    else:
        if m == xh[m]:
            return search(m + 1, j)
        else:
            return search(i, m - 1)

print(search(0, 7))
```

- A. 4
- B. 5
- C. 6
- D. 7

---

## 答案

**正确答案：** A

---

## 解析

递归查找第一个满足 xh[m] 不等于 m 的位置。中点 3、4 均满足，m=5 时 xh[5]=6 不满足，递归到区间 [4,4] 后继续到 [5,4]，最终返回 4。
