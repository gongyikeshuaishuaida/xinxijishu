# 题目 15

小明开发了一款股票交易复盘软件，软件可以跟踪一段时期内某支股票的价格走势，并计算最佳买入和卖出时间来获得最大收益（1股收益=卖出价格-买入价格）。小明可同时拥有多股该股票，但每天最多只能进行一次操作（即买入1股、卖出1股或什么都不做）。

软件跟踪获取某支股票最近9天的价格分别为10、5、4、7、9、12、6、2、10，则可以在第2、3、8天买入，在第5、6、9天卖出，此时可获取的最大收益为20。

![[attachments/202408强基联盟_15_价格走势.jpg]]

计算最大收益的算法设计如下：

1. 将跟踪获取的股票价格存入数组 `a` 中；
2. 设计“买卖计划队列” `q`，`h` 指针指向当前最小买入价格，初始值为0；
3. 遍历股价数组 `a`，若当天股价大于队列中的最小买入价格，则买入该最小价格，并把当天股价插入有序队列、标记为卖出；若之后遇到更高股价，则取消此前卖出标记并把更高股价标记为卖出；
4. 若当天股价小于等于队列中的最小买入价格，则把当天股价直接插入有序队列。

（1）若天数为7天，每天股票价格为2、5、4、3、8、8、6，则能获得的最大收益为 ______①______。

（2）定义函数 `q_sort(h,t)`，功能为对买卖计划队列中的股价数据进行升序排序。方框处代码有误，请在代码块后更正。

```python
def q_sort(h, t):
    tmp = q[t]
    i = t - 1
    while i >= h and q[i][0] > q[t][0]:
        q[i + 1] = q[i]
        i -= 1
    q[i + 1] = tmp
```

方框处应更正为 ______②______。

（3）定义函数 `pq_push(x,f)`，功能为维护买卖计划队列，请完成划线处代码填空。

```python
def pq_push(x, f):
    global t
    q[t][0] = x
    q[t][1] = f
    t += 1
    q_sort(______③______)
```

（4）实现上述算法的程序代码如下，请完成划线处代码填空。

```python
# 输入天数 n 及每天的股价数据 a，代码略
h = t = 0
pq_push(a[0], 0)
ans = 0
for i in range(1, n):
    if a[i] > q[h][0]:
        ______④______
        if q[h][1] == 0:
            h += 1
        else:
            q[h][1] = 0
        pq_push(a[i], 1)
    else:
        ______⑤______
print(ans)
```

---

## 答案

**正确答案：** ①13；② q[i][0]>tmp[0]；③ h,t-1；④ ans+=a[i]-q[h][0]；⑤ pq_push(a[i],0)。

---

## 解析

按价格序列可实现收益 6+5+2=13。插入排序中 tmp 保存待插入元素，比较应始终与 tmp[0] 比较；t 指向下一个空位，排序范围末端为 t-1。出现更高价格时先累加当前最低买入价对应的收益，出现更低价格时把新价格以买入标记加入队列。
