# 题目 12

无序链表中，将所有小于 x 的节点通过头插逐个移到链表前面。链表数据和整理后的指针如图所示。

![[attachments/202408-强基联盟-高三-返校-12_横排1_2.png]]

对应的程序主体如下，方框处为待填代码：

```python
a = [[1, 1], [4, 2], [2, 3], [3, 4], [5, 5], [2, -1]]
p = head = 0
x = int(input())
frt = -1
while p != -1:
    if a[p][0] < x and p != head:
        pp = p  # 提取出要移动的元素
        ______①______
    else:
        frt = p
        p = a[p][1]
```

程序方框处应填入的代码为（   ）。选项中的每一项均为按执行顺序排列的完整代码。

- A.
  ```python
  a[pp][1] = head
  head = pp
  a[frt][1] = a[p][1]
  p = a[p][1]
  ```
- B.
  ```python
  a[frt][1] = a[p][1]
  p = a[p][1]
  a[pp][1] = head
  head = pp
  ```
- C.
  ```python
  a[frt][1] = a[p][1]
  a[p][1] = head
  p = a[p][1]
  head = pp
  ```
- D.
  ```python
  a[pp][1] = head
  head = pp
  a[p][1] = a[frt][1]
  p = a[p][1]
  ```

---

## 答案

**正确答案：** B

---

## 解析

当前节点 pp 被移到链表头部前，先让前驱 frt 跳过该节点，保存原后继；再令 pp 的后继指向旧 head，并把 head 更新为 pp。B同时完成前驱断链和头插，其他选项会丢失节点或更新错误。
