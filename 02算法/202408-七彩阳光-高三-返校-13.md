# 题目 13

玩具机器人每秒采集一次坐标，若连续前进100次则产品合格。当前位置坐标和大于前一位置坐标和才算前进。

（1）坐标依次为 (0,0),(1,0),(0,2),(0,3),(1,2),(3,1) 时，连续前进次数最多为 ______①______。

（2）程序中的三个空为：

~~~python
prex=prey=-1; n=t=maxn=0
while True:
    # 接收坐标 x,y
    t+=1
    if ______②______:
        n+=1
    else:
        n=1
    if ______③______:
        maxn=n
    if t>=120:
        if ______④______:
            # 合格
            pass
        else:
            # 不合格
            pass
        n=t=maxn=0; prex=prey=-1
    else:
        prex=x; prey=y
~~~

---

## 答案

**正确答案：** ① 3；② x+y>prex+prey；③ n>maxn；④ maxn>=100（或 maxn==100）。

---

## 解析

相邻坐标和依次为0、1、2、3、3、4，只有前三次比较连续增大，最多连续前进3次。n记录当前连续次数，maxn用打擂法保存最大值；达到120秒时只要某一段连续次数达到100即可判定合格，所以判断 maxn>=100。
