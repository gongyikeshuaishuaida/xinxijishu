# 题目 13

某路边有一排照明装饰灯，编号依次为 1~n。现发现有多个装饰灯不亮，受维修成本的限制，只对其中的一部分进行维修，维修后保证有 k 个编号连续的装饰灯能够正常照明。编写程序，根据已损坏的装饰灯编号，输出最少需要维修的装饰灯数量。请回答下列问题：

（1）若路边有 10 个照明装饰灯（编号 1~10），其中编号为 1、4、8、10 的装饰灯不亮，维修后需保证有 6 个编号连续的装饰灯能正常照明，则最少需要维修的装饰灯数量是 ______①______。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

~~~python
# 输入照明装饰灯的总数 n、编号连续的正常照明装饰灯数量 k，代码略
# 读取不亮的装饰灯编号，存入 d，代码略
v = [0] * (n + 1)
c = [0] * (n + 1)
ans = n
for i in ______②______:
    v[d[i]] = 1
for i in range(1, n + 1):
    c[i] = c[i-1] + v[i]
i = 1
while i <= n - k + 1:
    last = ______③______
    num = c[last] - c[i - 1]
    if ______④______:
        ans = num
    i = i + 1
print(ans)
~~~

---

## 答案

**正确答案：** （1）1；（2）② range(len(d))；③ i + k - 1；④ num < ans

## 解析

长度为 6 的连续区间中，编号 2~7 只包含编号 4 的坏灯，维修这一盏即可，因此最少为 1。程序用 v 标记坏灯，用 c 计算前缀和；区间 [i, i+k-1] 中的坏灯数为 c[i+k-1]-c[i-1]，遍历所有窗口取最小值。读取列表 d 的下标范围应为 range(len(d))。
