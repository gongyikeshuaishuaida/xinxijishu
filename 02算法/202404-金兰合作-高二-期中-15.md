# 题目 15

马拦过河卒。棋盘上A点有一个过河卒，需要走到目标B点；卒每次只能向下或向右移动一步。在棋盘上C点有一个对方的马，该马所在的点和所有跳跃一步可达的点均为卒的禁区。编写程序计算马在C点时，卒从A点到B点的方案数。

![[attachments/202404金兰合作_15_棋盘图.jpg]]

图a中起点A坐标为`(0,0)`，目的地B坐标为`(5,6)`，马的坐标为`(3,3)`，解得路径数量为3，图b和图c是其中两条可能的路径。

（1）若将图a中的目的地B坐标改为`(6,6)`，起始点和马的坐标均不变，则路径数为 ______①______ 条。

（2）设计自定义函数 `control(row,col,crow,ccol)`，用于判断点`(row,col)`是否为马的控制点。已知马所在坐标为`(crow,ccol)`，请在划线处填写适当的代码。

```python
def control(row, col, crow, ccol):
    # dir存储各控制点相对于马的坐标
    dir = [[0, 0], [2, 1], [1, 2], [-1, 2], [-2, 1],
           [-2, -1], [-1, -2], [1, -2], [2, -1]]
    for i in range(9):
        if ______②______:
            return True
    return False
```

（3）假设棋盘大小为30×30，`arr[0][0]=1`。程序从键盘输入目标点B的位置`(n,m)`和马的位置`(x,y)`，通过遍历网格统计可行路径数量。请补全程序。

```python
n, m, x, y = map(int, input("请输入目的地和马的坐标(以空格隔开):").split())
arr = [[0] * 30 for i in range(30)]
arr[0][0] = 1

for i in range(1, m + 1):  # 遍历第一行元素
    if control(0, i, x, y):
        ______③______
    arr[0][i] = 1
for i in range(1, n + 1):
    if control(i, 0, x, y):
        break
    ______④______
for i in range(1, n + 1):
    for j in range(1, m + 1):
        if not control(i, j, x, y):
            arr[i][j] = ______⑤______
print(f"从(0,0)点到({n},{m})点的可行路径共有{arr[n][m]}条")
```


---

## 答案

**正确答案：** ① 6；② `dir[i][0] + crow == row and dir[i][1] + ccol == col`；③ `break`；④ `arr[i][0] = 1`；⑤ `arr[i - 1][j] + arr[i][j - 1]`

---

## 解析

改变目标后用递推或枚举得到 6 条路径；控制点判定是方向向量平移后的坐标相等；初始化边界遇到禁区应立即 `break`，未遇到禁区的第一列置 1，普通格的路径数为上格与左格之和。
