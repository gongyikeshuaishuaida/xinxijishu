# 题目 07

某算法的流程图如第 7 题图所示，若输入 `k` 为 2，则输出的 `a` 不可能为（   ）

![[attachments/202611宁波高三_07_图1.png]]

- A. `[9, 7, 4, 7, 3]`
- B. `[3, 7, 1, 5, 5]`
- C. `[3, 5, 0, 3, 5]`
- D. `[3, 7, 5, 4, 5]`

---

## 答案

**正确答案：** A

---

## 解析

`c` 记录已扫描的偶数个数，遇到奇数时写入 `a[j-c]`，因此全部奇数依原顺序紧凑地写到数组前部，后缀保留原位置上的值。A 至少含有三个不同的奇数，前 3 项却出现偶数 4，无法得到。B、C、D 分别可由 `[3, 7, 2, 1, 5]`、`[2, 4, 0, 3, 5]`、`[3, 7, 2, 4, 5]` 得到。
