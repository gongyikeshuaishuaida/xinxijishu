# 题目 13

13.某仓库记录每天出入库情况，正数表示入库、负数表示出库，查询总量等于 k 的连续时间段。某星期数据为 `10,-10,5,6,7,8,-5`，k=18 时有第1～5天、第3～5天两个时间段。

（1）若将 k 改为 21，则有多少个时间段满足要求？

（2）补全程序：

```python
pos = {0: [-1]}; count = 0
①
for i in range(len(a)):
    cur += a[i]
    ②
    if pre in pos:
        for j in pos[pre]:
            print('时间段:', j+2, '~', i+1)
            ③
    if cur not in pos:
        pos[cur] = [i]
    else:
        pos[cur].append(i)
print('一共有', count, '个时间段')
```

---

## 答案

**正确答案：** （1）3；（2）①`cur=0`；②`pre=cur-k`；③`count+=1`

---

## 解析

用前缀和记录每个和出现的位置。k=21 时前缀和序列为 `0,10,0,5,11,18,26,21`，差为 21 的位置对有三组，分别对应第1～7天、第3～7天和第4～6天。每次累加后令 `pre=cur-k`，查找已有位置并计数。
