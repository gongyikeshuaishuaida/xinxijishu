# 题目 17

商场商品按价格升序排列，并将连续相同价格分段压缩：每段用“当前价格相对前一段的增值、该段个数”表示，段之间用逗号连接。压缩示意图如下：

![[attachments/202401金华十校_17_图1.jpg]]

（1）价格数据 `2,2,2,5,5,7,7,7,7` 的压缩结果为 ______①______。

（2）补全解压程序。

```python
s=input()
a=[0]*1000
f=False; tmp=0; k=1
for i in range(len(s)):
    if "0"<=s[i]<="9":
        tmp=______②______
    else:
        if f==False:
            a[k]=a[k-1]+tmp
            k+=1
        else:
            for j in range(tmp-1):
                ______③______
                k+=1
        f=______④______
        tmp=0
print(a[1:k])
```

（3）统计有 `m` 元资金时购买两个商品的方案数，补全 `else` 分支。

```python
if a[i]+a[j]>m:
    j-=1
else:
    ______⑤______
    i+=1
```

（4）若解压后价格为 `[0,22,22,24,55,76,77]`，输入 `m=100` 后输出11，则`else`分支执行 ______⑥______ 次。

---

## 答案

**正确答案：** （1）`2,3,3,2,2,4`；（2）② `tmp=tmp*10+int(s[i])`；③ `a[k]=a[k-1]`；④ `f=not f`；（3）⑤ `ans += j-i`；（4）⑥ 3

---

## 解析

（1）三段价格分别为2（3个）、5（2个）、7（4个），增值依次为2、3、2，故压缩序列为`2,3,3,2,2,4`。

（2）连续读取数字字符时用十进制累加构造当前数；解压同一段的剩余商品价格都等于前一个价格；读完一组数字后切换“增值/个数”状态，故用`f=not f`。

（3）当最小价与最大价之和不超过资金时，固定当前最小价可与从`i+1`到`j`的所有商品组成方案，共`j-i`种，然后将`i`右移。

（4）按双指针过程逐步比较首尾价格，满足预算的三次比较进入`else`分支，因此执行3次。
