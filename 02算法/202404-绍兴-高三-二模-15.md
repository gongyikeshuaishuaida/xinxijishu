# 题目 15

某餐厅的订单数据由线上、线下多条订单合并而成。每条订单含下单时间、菜品列表两个数据项，下单时间精确到“时：分”，菜品列表由互不重复的大写字母构成，按字母升序排列如“ABC”，每个字母代表一种菜品，合并后的订单数据如下图所示。

订单示例：`[['10:00','ABC'],['10:03','AB'],['10:06','BC'],['10:07','AC'],['10:08','A'],['10:09','AC'],['10:11','AB'],['10:12','AB']]`。

由于厨师一锅能烹饪5份同种菜品，程序按下单时间先后逐条处理：当某种菜品中首份菜品的下单时间超过10分钟，或累计份数达到5份时，该种菜品及累计份数进入烹饪提示队列，入队后重新开始统计。当多种菜品符合某个入队条件时，按各菜品中首份菜品下单时间的先后顺序入队。所有订单处理完毕，剩余未入队的菜品直接进入队列。

（1）若仅将上述订单数据中的`['10:00','ABC']`修改为`['10:00','BC']`，则A菜品第1次烹饪的数量为 ______①______ 份。

（2）定义`merged_list(lst1,lst2)`函数，参数`lst1`和`lst2`的每个元素由下单时间和菜品列表组成，且均已按下单时间升序排列。函数将`lst2`中的元素合并到`lst1`中，使`lst1`按下单时间保持升序排列并返回。程序中①、②、③三处语句有一处需要修改，请选择 ______②______（单选，填序号）处，并将其修改为 ______③______。

```python
def merged_list(lst1, lst2):
    m = len(lst1) - 1
    n = len(lst2) - 1
    tail = m + n + 1          # ①
    for i in range(n + 1):    # ②
        lst1.append(["", ""])
    while n >= 0:
        if lst1[m][0] > lst2[n][0]:  # ③
            lst1[tail] = lst1[m]
            m -= 1
        else:
            lst1[tail] = lst2[n]
            n -= 1
        tail -= 1
    return lst1
```

## 答案

**正确答案：** ① 5；② ③；③ `if m >= 0 and lst1[m][0] > lst2[n][0]`；④ `dishes_str = orders[i][1]`；⑤ `len(qu) > 0 and pret - dc[qu[0]][1] > 10`；⑥ `pdish = qu.pop(k)`

---

## 解析

首项改为BC后，A从10:03开始累计，到10:08达到5份并首次入队。合并列表逆向比较时m可能减到-1，必须先判断m>=0；处理订单先取出菜品字符串，超过10分钟的队首菜品出队，达到5份的菜品用`qu.pop(k)`出队。
