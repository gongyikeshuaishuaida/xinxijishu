# 题目 13

13.有 `n` 名同学参加春游，公用经费为 `total`，个人现金存于 `cash`；自行车按租金从高到低存于 `bike`。每位同学优先用自己的现金，不足部分用公用经费补足。

（1）当 `n=5,total=80,cash=[21,15,10,8,5]`，`info=[[60,1],[50,2],[35,2],[25,3]]` 时，是否都能租到自行车：A.是 / B.否。

（2）程序中划线处：

```python
bike = []
for i in range(len(info)):
    for j in range(info[i][1]):
        bike.append(info[i][0])
m = len(bike)
i = ______①______
j = 0
while i < m and total >= 0:
    if bike[i] > cash[j]:
        ______②______
    i += 1
    j += 1
```

（3）将加框处改为 `i == m`，是否影响判断准确性？A.影响 / B.不影响。

---

## 答案

**正确答案：** （1）B；（2）① `m-n`；② `total -= bike[i] - cash[j]`；（3）A

---

## 解析

按租金从高到低匹配时，先跳过多出的自行车数量，①为 `m-n`；租金高于个人现金时从公费中补足差额，②为 `total-=bike[i]-cash[j]`；循环结束只需判断公费是否非负，改为 `i==m` 不影响最终判断，故（1）B、（3）A。
