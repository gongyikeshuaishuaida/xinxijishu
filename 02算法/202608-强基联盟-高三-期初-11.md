# 题目 11

有如下程序段：

```python
import random
s = input("请输入一串数字：")
k = random.randint(1, len(s) - 1)
for i in range(k):
    f = False
    for j in range(len(s) - 1):
        if s[j] > s[j + 1]:
            f = True
            break
    if f:
        s = s[:j] + s[j + 1:]
    else:
        s = s[:len(s) - 1]
```

执行该程序段后，输入“1853”，则变量 `s` 的值可能是（   ）

- A. `"3"`
- B. `"13"`
- C. `"183"`
- D. `"15"`

---

## 答案

**正确答案：** B

---

## 解析

`k` 在 1 到 3 之间随机取值。每一轮若存在逆序对，就删除第一个逆序对的前一个字符；若不存在逆序对，就删除最后一个字符。输入 `1853` 时，第一轮可删除 `8` 得到 `153`，第二轮可删除 `5` 得到 `13`，继续一轮还会删除 `3` 得到 `1`。选项中只有 `"13"` 是可能结果，因此选 B。
