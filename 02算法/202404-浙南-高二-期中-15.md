# 题目 15

15.某加工厂中每个材料依次经过“裁切→打磨→组合”三个步骤，裁切和组合由两位师傅完成，打磨由机器完成。程序用列表保存材料和师傅状态，并按规则模拟加工过程。

函数使用的方法如下：

![[attachments/202404浙南_15_函数与方法表.jpg]]

材料数据为：`["材料1",13,10,16]`、`["材料2",11,9,11]`、`["材料3",12,11,14]`、`["材料4",9,6,13]`、`["材料5",12,11,11]`、`["材料6",13,10,11]`、`["材料7",13,7,11]`。

（1）给“材料3”进行裁切的师傅是（A.张师傅 / B.李师傅）。

（2）请补全程序：

```python
def cut(master, index, mat):
    start_time[index] = ______①______
    q_dic[masters[index][0]].append([mat[0], start_time[index] + mat[2], mat[3]])
    masters[index][1] = 1

i = 0; n = len(mats) - 1
while ______②______:
    for index in range(len(masters)):
        if ______③______:  # 当前师傅尚未完成当前材料的加工
            continue
        que = q_dic[masters[index][0]]
        if i > n and judge(masters[index][0]):
            ...
        elif masters[index][1] == 1 and que[0][1] <= start_time[index]:
            pol(masters[index][0], index)
        elif i > n:
            continue
        else:
            mat = ______④______
            cut(masters[index][0], index, mat)
            i += 1
```

---

## 答案

**正确答案：** （1）B；（2）① `start_time[index]+mat[1]`；② `i<=n or judge_all()`；③ `cur_time<start_time[index]`；④ `mats[i]`

---

## 解析

裁切任务按材料顺序分配给先空闲的师傅，材料3由李师傅接手。裁切结束时间为当前开始时间加裁切耗时；只要仍有未裁切材料或组合队列尚有任务就继续循环。若师傅当前结束时间还未到则跳过；新材料取 `mats[i]`。
