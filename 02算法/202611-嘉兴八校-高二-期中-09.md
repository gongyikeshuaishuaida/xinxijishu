# 题目 09

某算法的部分流程图如图所示，执行该流程时，输入 n 的值为 15，则输出的 f 和 i 分别是（   ）

![[attachments/202611嘉兴八校高二_09_图1.png]]

- A. True 3
- B. False 3
- C. True 4
- D. False 4

---

## 答案

**正确答案：** D

---

## 解析

从 i=2 起试除，i=3 时能整除 15，于是 f 置 False。i 随后增到 4，结束循环。
