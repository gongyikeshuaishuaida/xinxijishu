# 题目 14

14. 俄罗斯套娃素数是指这样的素数：去掉最后一位，剩下的部分仍然是个素数；再去掉剩下部分的最后一位，剩下的部分仍然是个素数；不断这样做下去，得到的数始终是素数。例如，`2393` 就是一个俄罗斯套娃素数，因为不但 `2393` 本身是素数，不断去掉最后一位将会依次得到 `239`、`23`、`2`，它们也都是素数。编写一个 Python 程序，找到四位数中的俄罗斯套娃素数。

（1）整数 `1374` ______①______（是/不是）俄罗斯套娃素数。

（2）函数 `sushu` 功能：判断一个数是不是素数，是返回 `True`，不是返回 `False`。

```python
def sushu(n):
    for i in range(______①______):
        if n % i == 0:
            return False
    return True
```

程序划线处应填入的代码为 ______（多选，填字母）。

- A. `2,n`
- B. `1,n+1`
- C. `2,n//2`
- D. `2,int(n**0.5)+1`

（3）主程序如下，请在程序划线处填入合适的代码。

```python
______①______
for i in range(1000, 10000):
    p = i
    while sushu(p) and p > 0:
        ______②______
    if p == 0:
        s += str(______③______) + ","
print("四位数中的俄罗斯套娃数有：", s[:-1])
```

---

## 答案

**参考答案：**

- （1）不是
- （2）A、D
- （3）① `s=""`；② `p=p//10`；③ `i`

---

## 解析

`1374` 本身是偶数，不是素数，因此不是俄罗斯套娃素数。判断素数时从 2 开始试除，试除到 `n-1`（A）或到 `sqrt(n)` 以内并包含上界（D）都可以；B 从 1 开始会直接判定合数，C 的范围在部分边界情况下不能完整覆盖试除过程。主程序先初始化结果字符串，反复整除 10 去掉末位；只有当前数始终为素数并最终变为 0 时，才把原四位数 `i` 加入结果。
