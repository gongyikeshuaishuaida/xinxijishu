# 题目 13

随机生成 `n` 个 `[1,100]` 范围内的整数，并以环状形式存储在列表中，找出最长的连续升序子序列；若有多个最长子序列，则输出最先出现的那个。程序运行界面如下。

![[attachments/2024039+1_13_运行界面.png]]

（1）若 `n=10`，依次生成整数 `14,15,18,11,15,16,18,9,11,13`，则最长的连续升序子序列长度为 ______。

（2）实现上述功能的 Python 程序段如下，请在划线处填入合适的代码。

```python
# 输入 n，生成 n 个 [1,100] 范围内的整数并存储在列表 a 中，代码略
i = 1
while i <= n - 1:
    if ______①______:
        break
    i += 1
if i == n:
    k = n - 1; maxs = n
else:
    maxs = 1; cnt = 1; p1 = i
    ______②______
    while p1 != i - 1:
        if a[p1] < a[p2]:
            cnt += 1
            if cnt > maxs:
                maxs = cnt
                ______③______
        else:
            cnt = 1
        p1 = p2
        p2 = (p2 + 1) % n
print("最长连续升序子序列长度为:", maxs)
ans = ""
for i in range(maxs):
    ans = str(a[k]) + " " + ans
    k = (k - 1) % n
print("最长连续升序子序列为:", ans)
```

## 答案

**正确答案：** （1）6；（2）① `a[i] <= a[i-1]`；② `p2 = (p1 + 1) % n`（或 `p2 = (i + 1) % n`）；③ `k = p2`。

## 解析

给定序列的最长环状升序段为 `9,11,13,14,15,18`，长度 6。程序先找到一个不再上升的位置作为起点；②初始化环状扫描的下一个位置；发现更长序列时将末位置 `p2` 保存为回溯输出的起点。
