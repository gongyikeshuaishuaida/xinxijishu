# 题目 14

14.某中学新高一共安排12个班，成绩1—12名按1—12班分配，13—24名按12—1班逆序分配，循环进行。

（1）成绩排第188名的同学分到哪个班？

（2）`find` 在未分配名单中寻找成绩最高者，返回序号：

```python
def find(st,f):
    k=-1
    for i in range(len(st)):
        if f[i]==False:
            if ______:
                k=i
    return k
```

- A.`st[i][2]>st[k][2]`
- B.`k!=-1 or (st[i]>st[k])`
- C.`k==-1 and (st[i][2]>st[k][2])`
- D.`k==-1 or (st[i][2]>st[k][2])`

（3）补全分班程序：

```python
head=[0]*12; p=[0]*12
flag=[False]*len(stu)
for i in range(len(stu)):
    k=find(stu,flag)
    if ______①______:
        head[i]=p[i]=k
    else:
        if i//12%2==0:
            t=i%12
        else:
            t=______②______
        stu[p[t]][3]=k
        p[i%12]=k
        flag[k]=True
for i in range(12):
    p=______③______
    while p!=-1:
        print(stu[p])
        p=stu[p][3]
```

---

## 答案

**正确答案：** （1）5班；（2）D；（3）① `i<12`；② `11-i%12`；③ `head[i]`

---

## 解析

每24人为一轮，第188名在第8轮余20人，逆序分配到第5班。寻找最高分时，尚未找到候选者（k=-1）或当前成绩更高都应更新 k。前12人分别作为12个班表头，逆序轮次的班号为 `11-i%12`，输出从 `head[i]` 开始的链表。
