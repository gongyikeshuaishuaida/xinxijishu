# 题目 09

数组 `a` 的 `a[0]` 表示序列长度，其他元素由 0 和 1 组成。程序要找出连续区间中“1 的个数减去 0 的个数”的最大值：

```python
n = a[0] + 1
s = [0] * n
ans = -1
for i in range(1, n):
    s[i] = s[i-1] + a[i]
for i in range(1, n):
    for j in range(i, n):
        p = s[j] - s[i-1]
        q = ______①______
        if p - q > ans:
            ans = p - q
print(ans)
```

方框中应填入的代码为（ ）

- A.`n-p`
- B.`n-i-p`
- C.`j-i-p`
- D.`j-i+1-p`

---

## 答案

**正确答案：** D

---

## 解析

区间 `[i,j]` 的长度为 `j-i+1`，其中 1 的个数为 `p`，0 的个数为区间长度减去 `p`，所以 `q=j-i+1-p`，故选 D。
