# 题目 13

Excel表中单元格用“列标+行号”表示，区域用“左上单元格:右下单元格”表示，多个区域以逗号分隔。程序从 `excel.txt` 读取区域指令，统计 `A1:Z99` 中各单元格被选取的次数，找出次数最多的单元格。

指令示例和区域示意图如下：

![[attachments/202401-慈溪-高二-期末-13_横排1_2.png]]

（1）根据图中指令，单元格 `C5` 的选取次数为 ______①______。

（2）`find_area`函数依次切割一行中的多个区域。以下三行数据能得到正确返回值的是（   ）

- A. `A7,,A5,`
- B. `A3:A5,A7:B8`
- C. `C3:D7,A56,`

（3）`find_cells`列举区域中的所有单元格并统计数量，请补全代码。

```python
def find_cells(ss):
    k=0
    for i in range(len(ss)):
        if ss[i]==":":
            k=______②______
            break
    if k==0:
        cell[ss]+=1
    else:
        x1=ss[0]; x2=int(ss[1:k])
        y1=ss[k+1]; y2=int(ss[k+2:])
        for i in range(ord(x1),ord(y1)+1):
            for j in range(x2,y2+1):
                z=______③______
                cell[z]+=1
```

（4）`find_max`找出被选次数最多的单元格，请补全条件。

```python
def find_max(cell):
    fmax=0; result=""
    for s in cell:
        if cell[s]>fmax:
            result=s+","; fmax=cell[s]
        elif ______④______:
            result+=s+","
    return result
```

---

## 答案

**正确答案：** （1）3；（2）B；（3）② `k=i`；③ `chr(i)+str(j)`；（4）`cell[s]==fmax`

---

## 解析

（1）按图中三个区域逐格统计，`C5`被选取3次。

（2）A和C末尾有逗号，切割后会产生空字符串或遗漏最后区域；B的两个区域格式完整，能得到正确返回值。

（3）扫描到冒号时记录其下标 `i`，再用列标的ASCII码遍历起止列，用 `chr(i)+str(j)` 拼出每个单元格名称。

（4）当当前单元格的次数与当前最大值相等时，也应追加到结果，以保留并列最多的单元格，因此条件为 `cell[s]==fmax`。
