# 题目 07

某算法的部分流程如图所示。执行这部分流程，若输入的 x 依次为 2、3、5、0，则输出 n 的值是（   ）

![[attachments/202411宁波_07_流程图.png]]

- A. 0
- B. 1
- C. 2
- D. 3

---

## 答案

**正确答案：** B

---

## 解析

初始 a、b、c、n 均为 0。依次输入 2、3、5 时，三次更新后分别得到 (a,b,c)=(2,0,0)、(3,2,0)、(5,3,2)，只有输入 5 时满足 a=b+c，n 加 1；输入 0 后结束，故 n=1。
