# 题目 15

丑数是只包含质因数 2、3、5 的正整数，三位不重复丑数是三位正整数且各位数字不重复的丑数。程序运行结果如图所示。

![[attachments/202407衢温5加1_15_丑数运行结果图.jpg]]

（1）下列选项中可以填入加框处的代码是 ______（多选，填字母）：
- A. `[2, 3, 5]`
- B. `range(2, 6)`
- C. `range(2, 8)`

（2）Python 程序代码如下，请在划线处填入合适的代码：

```python
def check(n):
    # 判断正整数 n 是否只包含 2、3、5 三个质因子，是返回真，否则返回假。
    for i in ______①______:
        while n % i == 0:
            n = n // i
    if ______②______:
        return True
    else:
        return False


ans = 0
a = []
for i in range(100, 1000):
    f = [0] * 10
    temp = i
    while temp != 0:
        f[temp % 10] = 1
        temp //= 10
    if sum(f) == 3:
        if ______③______:
            ans += 1
            a.append(i)
print("三位不重复丑数有", a)
print("共有", ans, "个")
```

---

## 答案

**正确答案：** （1）A、B；（2）① [2, 3, 5]（或 range(2, 6)）；② n == 1；③ check(i)

---

## 解析

检查函数将 n 中的 2、3、5 因子全部除尽，最后只有 n==1 才说明没有其他质因子，因此 [2,3,5] 和 range(2,6) 都可用；range(2,8) 会把质因数 7 也除掉，误判含 7 的数。主程序用 sum(f)==3 判断三位数字互不重复，再调用 check(i) 判断是否为丑数。
