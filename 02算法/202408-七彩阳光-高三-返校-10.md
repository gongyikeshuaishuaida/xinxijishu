# 题目 10

某二分查找算法的Python程序段如下：

```python
i, j, x = 0, len(a) - 1, 0
while i <= j:
    m = (i + j) // 2
    x += 1
    if a[m] == key:
        break
    elif a[m] < key:
        i = m + 1
    else:
        j = m - 1
```

当`a`的元素分别为`[5,16,22,28,35,43,52,67,78,89]`和`[5,16,22,28,35,43,52,67,78]`时，查找同一`key`产生的`x`值相同，则`key`的值可能是（   ）

- A. 52
- B. 39
- C. 58
- D. 70

---

## 答案

**正确答案：** B

---

## 解析

逐次比较中点即可统计比较次数。key=39时，第一数组的访问路径为35、16、28，第二数组的访问路径为35、16、28，均为3次；其余选项在两个长度不同的数组中访问层数不同，因此选B。
