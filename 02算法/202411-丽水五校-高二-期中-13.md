# 题目 13

13. 用火柴棒拼数字公式，数字0到9的拼法如第13题图a所示，加号与等号各自需要2根火柴棒，若现在有 `n` 根火柴棒（1≤n≤24），可以拼出多少个形如 `A+B=C` 的等式？如果 `A≠B`，则 `A+B=C` 与 `B+A=C` 视为不同的等式，`n` 根火柴棒必须用尽，程序运行结果如第13题图b所示。

![[attachments/202411-丽水五校-高二-期中-13_横排1_2.png]]

```python
f=[6,2,5,5,4,5,6,3,7,6]     #存储各数字所需火柴棒数量
def stick(n):    #统计整数n所需要的火柴棒数量
    if n<10:
        return f[n]
    num=0
    while ______①______:
        k=n%10
        num+=f[k]
        n=n//10
    return ______②______
n=int(input("请输入1-24内的整数："))
cnt=0
for i in range(1112):
    for j in range(1112):
        if stick(i)+stick(j)+stick(i+j)+4==n:
            ______③______
            print(i,"+",j,"=",i+j)
print("共有",cnt,"个等式")
```

（1）该程序所用的算法是（单选，填字母：A.解析算法/B.枚举算法）

（2）为实现上述功能，请在划线处填入合适的代码。

---

## 答案

**参考答案：**

- （1）B
- ① `n!=0`（或 `n>0`）
- ② `num`
- ③ `cnt+=1`

---

## 解析

程序用两层循环逐一尝试 `i`、`j`，再检查 `i+j` 的火柴棒数和加号、等号共 4 根是否正好等于 `n`，因此采用枚举算法。`stick` 函数从个位开始取出每一位，累加对应的火柴棒数量；不断整除 10，直到原数处理完，最后返回累计值。满足条件时计数器 `cnt` 加 1，然后输出等式。
