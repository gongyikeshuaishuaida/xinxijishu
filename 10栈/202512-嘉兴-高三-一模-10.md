# 题目 10

**10．** 有如下 Python 程序段：

```python
chs = input("请输入字符串：")
s = []
res = ""
for ch in chs:
    if s != [] and s[-1] == ch:
        s.pop()
    else:
        s.append(ch)
for i in range(len(s)):
    res += s[i]
print(res)
```

程序运行时，若输出为 `car`，则可能的输入是（   ）

- A. `cbbare33e`
- B. `cbeare33b`
- C. `caeer33rb`
- D. `caar33reb`

---

## 答案

**正确答案：** A

---

## 解析

A 的处理过程：c 入栈；两个 b 抵消；a、r、e 入栈；两个 3 抵消；末尾 e 与新暴露的栈顶 e 抵消，最后得到 car。

四个选项实际结果为：A→`car`，B→`cbeareb`，C→`cab`，D→`ceb`。例如 C 中先消去 ee，再消去 33，两个 r 又成为相邻有效字符并抵消，所以不能保留一个 r。

该程序要求“当前字符等于栈顶”才成对消除；标准括号匹配要求开闭符号类型配对，二者条件不同。
