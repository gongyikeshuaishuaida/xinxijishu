# 题目 15

某社区共有 `n` 位居民，每位居民有唯一编号 1～`n`。工作人员发现居民之间存在 `k` 个亲属关系，每个关系用列表 `[a, b]`（`a < b`）表示居民 `a` 和 `b` 属于同一家庭。编写程序求不同家庭总数及最大家庭人数。请回答下列问题：

（1）若社区有 10 位居民，亲属关系为 `[3, 7]`、`[9, 10]`、`[5, 6]`、`[2, 3]`、`[4, 5]`、`[1, 4]`，则总共组成 ______ 个不同家庭。

（2）定义如下 `merge(lst1, lst2)` 函数，将已按第一个数据项升序排列的 `lst2` 合并到 `lst1`：

```python
def merge(lst1, lst2):
    x = len(lst1) - 1
    y = len(lst2) - 1
    tail = x + y + 1
    for i in range(y + 1):
        lst1.append([0, 0])
    while y >= 0:
        if x >= 0 and lst1[x][0] > lst2[y][0]:
            lst1[tail] = lst1[x]
            x -= 1
        else:
            lst1[tail] = lst2[y]
            y -= 1
        tail -= 1
    return lst1
```

若 `lst1 = [[1, 2], [3, 4], [10, 11], [12, 13], [17, 18]]`，`lst2 = [[5, 6], [9, 10], [14, 15], [15, 16], [19, 20]]`，调用函数后，语句 `lst1[tail] = lst1[x]` 的执行次数为 ______。

---

## 答案

**正确答案：** （1）4；（2）3；（3）① len(q) > 0（或 len(q) != 0）；② s[a[i][0]].append(a[i][1])；③ total += 1

---

## 解析

亲属关系形成4个连通家庭。merge 从尾部归并时 lst1 元素被复制3次。check 使用列表末尾 append/pop 作为栈遍历一个家庭；每发现一个尚未访问的居民就完成一次家庭遍历并令 total 加1。
