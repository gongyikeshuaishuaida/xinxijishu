# 题目 11

有如下Python程序：

```python
a = [2, 0, 2, 1, 1, 0]
st = [0] * len(a)
top = -1
for i in range(len(a)):
    while top != -1 and a[i] < a[st[top]]:
        top -= 1
    top += 1
    st[top] = i
res = [0] * 3
for j in st:
    res[a[j]] += 1
print(res)
```



运行该程序后，输出的`res`为（   ）

- A. `[2, 0, 0]`
- B. `[0, 0, 2]`
- C. `[2, 1, 3]`
- D. `[2, 0, 4]`

---

## 答案

**正确答案：** C

---

## 解析

栈顶只维护有效区间，弹栈不会清除列表中原有下标。最终`top=1`，有效栈为下标1、5，但完整`st`仍为`[1,5,4,0,0,0]`。`for j in st`遍历全部6项，对应值为0、0、1、2、2、2，所以`res=[2,1,3]`。
