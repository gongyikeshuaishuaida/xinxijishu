# 题目 12

12.有如下 Python 程序段：

```python
a=[1,2,3,4,5,6]; b=[0,1,1,0,0,1]
top=-1; sum=0; st=[0]*len(a)
for i in range(len(a)):
    if b[i]==1 or top==-1:
        top+=1
        st[top]=a[i]
    elif a[i]%2==0:
        top-=1
    else:
        st[top]-=a[i]
    sum += st[top]
```

程序运行后变量 `sum` 的值是（ ）

- A.5
- B.7
- C.9
- D.11

---

## 答案

**正确答案：** D

---

## 解析

按 `b` 控制入栈，遇偶数出栈，遇奇数把当前栈顶再减去该奇数，并在每轮累加栈顶。逐步得到 `1+2+3+2-3+6=11`，故选 D。
