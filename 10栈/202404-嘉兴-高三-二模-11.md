# 题目 11

11.有如下程序段：

```python
s = ["A", "B", "C", "D"]
m = [1, 3, 0, 2]
st = [""] * 4
top = -1
j = 0
for i in range(len(s)):
    top += 1
    st[top] = s[i]
    while top != -1 and ord(st[top]) - ord("A") == m[j]:
        top -= 1
        j += 1
print(st[:top + 1])
```

执行该程序段后，输出内容是（ ）

- A. `[]`
- B. `['A']`
- C. `['A', 'C']`
- D. `['A', 'C', 'E']`

---

## 答案

**正确答案：** C

---

## 解析

按程序逐步模拟：压入 A 后不弹出；压入 B 时满足 `B-A=1`，弹出 B；压入 C 后不弹出；压入 D 时满足 `D-A=3`，弹出 D。栈中剩下 A、C，输出 `[A, C]`，选 C。
