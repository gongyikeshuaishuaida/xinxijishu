# 题目 12

有如下 Python 程序：

```python
s1 = "aabbcabba"
s2 = "ab"
st = ""
for ch in s1:
    st += ch
    if len(st) >= len(s2) and st[len(st)-len(s2):] == s2:
        st = st[:len(st)-len(s2)]
print(st)
```

执行该程序段后，输出结果为（   ）

- A. `"abcb"`

- B. `"abcba"`

- C. `"c"`

- D. `"cba"`

---

## 答案

**正确答案：** D

---

## 解析

逐字符追加到st，若末尾为ab就删除。删除产生的新相邻关系可在后续追加时继续消除，最终剩下cba。
