# 题目 08

栈 s1 和 s2 从栈底到栈顶的元素依次为 A、B、C 和 D、E、F，约定两种操作：①将栈 s1 中栈顶元素出栈后入至栈 s2；②将栈 s2 中栈顶元素出栈并输出。经过若干次操作后，栈 s1、s2 均为空且第四个输出的元素为 C，则在元素 C 前输出的序列个数为（   ）

- A. 1
- B. 2
- C. 3
- D. 4

---

## 答案

**正确答案：** D

---

## 解析

C 位于 s1 栈顶，转移到 s2 后，D、E、F 中尚未输出的元素都在 C 下方，无法赶在 C 前输出；只有后来从 s1 转入的 B、A 能压到 C 上面。

因此按“C 转移前已经输出多少个原 s2 元素”分类：

| C 转移前输出数 | 已输出前缀 | C 前还需输出 | 前三个输出 |
|---|---|---|---|
| 3 | F、E、D | 无 | F、E、D |
| 2 | F、E | B | F、E、B |
| 1 | F | B、A 或 A、B | F、B、A；F、A、B |
| 0 | 空 | 需要 3 个，但只有 B、A 两个可用 | 不可行 |

共 4 种。B、A 的两种次序分别通过“转 B 后立刻出 B”与“连续转 B、A 后逆序出栈”实现。
