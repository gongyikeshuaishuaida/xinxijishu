# 题目 14

14.给定只包括三种括号 `{}`、`[]`、`()` 的数学计算式，设计程序判断括号是否匹配。请完成代码：

```python
def check(expr):
    bracket = "{[()]}"
    op = {"}": "{", "]": "[", ")": "("}
    st = [""] * 100
    top = -1
    for ch in expr:
        if ch in bracket:
            if ch in bracket[:3]:
                top += 1
                ______①______
            elif top == -1 or ______②______:
                return False
            else:
                ______③______
    ______④______
```

程序对 `[a/(b-c)+d]*e` 输出“括号匹配”，对 `[a/(b-c)+d*e` 输出“括号不匹配”。

---

## 答案

**正确答案：** ① `st[top]=ch`；② `op[ch]!=st[top]`；③ `top-=1`；④ `return top<0`（或 `return top==-1`）

---

## 解析

左括号入栈；遇到右括号时，栈空或栈顶左括号与其不匹配就返回假，否则弹栈。遍历结束后栈为空才表示所有括号均匹配。
