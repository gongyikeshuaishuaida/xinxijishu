# 题目 12

12. 某 Python 程序把 `a=[1,2,3,4,5]` 依次压栈，并按输入数组 `b` 尝试出栈：

```python
stack = [0] * 10
top = -1
i = 0
for num in a:
    top += 1
    stack[top] = num
    while top != -1 and stack[top] == b[i]:
        top -= 1
        i += 1
if top == -1:
    print("True")
else:
    print("False")
```

执行程序后输出 `True`，则 `b` 的值不可能是（ ）

- A. `[3, 2, 1, 5, 4]`
- B. `[4, 3, 1, 2, 5]`
- C. `[1, 3, 2, 5, 4]`
- D. `[1, 2, 3, 4, 5]`

---

## 答案

**正确答案：** B

---

## 解析

栈的后进先出规则要求 4、3 出栈后才能处理 1；选项 B 在 4、3 出栈后不能直接得到 1，因而不是合法出栈序列，故选 B。
