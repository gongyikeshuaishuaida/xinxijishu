# 题目 09

对栈进行操作时，若进栈的元素顺序是"A" "B" "C" "D"，则出栈的顺序不可能的是（   ）

- A. A B C D

- B. D C B A

- C. D C A B

- D. C D B A

---

## 答案

**正确答案：** C

---

## 解析

要先出 D、C，必须先将四个元素全部入栈，此后栈顶为 B，不能先出 A。
