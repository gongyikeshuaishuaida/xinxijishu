# 题目 11

11.有如下 Python 程序段，运行后其输出结果不可能是（ ）

```python
import random
stack = ["", "", "", "", ""]
s, i, top = "ABCDE", 0, -1
while i < len(s):
    if random.randint(0, 10) % 2 == 0:
        top += 1
        stack[top] = s[i]
        i += 1
    elif top >= 0:
        print(stack[top], end='')
        top -= 1
while top >= 0:
    print(stack[top], end='')
    top -= 1
```

- A.`ABCDE`
- B.`EDCBA`
- C.`DCEAB`
- D.`BEDCA`

---

## 答案

**正确答案：** C

---

## 解析

不管随机结果如何，i 只在入栈后加 1，因此入栈顺序始终是 A、B、C、D、E。若输出前缀为 D、C，则栈内剩下 A、B；接着压入并输出 E 后，栈顶仍为 B，不能先输出 A。所以 DCEAB 不可能。

ABCDE 可边入边出；EDCBA 可全部入栈后倒序输出；BEDCA 可先压 A、B 并出 B，再压 C、D、E，依次出 E、D、C、A。

注意：D 第一个出栈时，E 不必已经入栈，证明不能把尚未处理的 E 画进栈里。
