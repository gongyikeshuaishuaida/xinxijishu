# 题目 12

有如下 Python 程序段：

```python
stk = [5, 2, 6, 3, 7]
lst = [""] * 10
top = len(stk) - 1
q, s = 0, 0
while top > -1:
    s += stk[top]
    if s % a == 0:
        break
    else:
        lst[q] = stk[top]
        q += 1
    top -= 1
for i in range(q):
    top += 1
    stk[top] = lst[i]
```

若 `a` 为 [2,4] 区间的随机整数，执行该程序段后，`stk` 的值不可能是（   ）

- A. [5, 2, 6, 7, 3]
- B. [5, 2, 6, 3, 7]
- C. [5, 2, 7, 6, 3]
- D. [5, 2, 7, 3, 6]

## 答案

**正确答案：** C

## 解析

程序从栈顶 7、3、6、2、5 依次累加，遇到累计和被随机 `a` 整除时停止，再把已经弹出的元素按记录顺序压回栈顶。逐项模拟可知 C 的排列无法由 `a∈{2,3,4}` 的停止位置产生。
