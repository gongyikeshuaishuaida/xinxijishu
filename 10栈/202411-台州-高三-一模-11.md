# 题目 11

某括号序列中，若左括号出现的顺序及个数与右括号保持一致，则称该序列中的括号是匹配的。例如序列“())(”中的括号是不匹配的，可将其中第 3、第 4 个括号修改为“()”使其重新匹配。现给出一个长度为偶数的不匹配序列，为使其重新匹配，统计最少需要修改的括号数。实现上述功能的 Python 程序段如下：

~~~python
s = input()
# 输入括号序列，序列中仅包含“(”和“)”两种字符
top = -1; ans = 0
for i in range(len(s)):
    if s[i] == "(":
        top += 1
    else:
        if ______①______:
            top += 1
            ans += 1
        else:
            ______②______
            ans += ______③______
~~~

上述程序段中方框处可选代码为：

① top != -1  
② top == -1  
③ top += 1  
④ top -= 1  
⑤ top // 2  
⑥ (top + 1) // 2

则（1）（2）（3）处代码依次为（   ）

- A. ①③⑥
- B. ①④⑤
- C. ②④⑤
- D. ②④⑥

---

## 答案

**正确答案：** D

## 解析

变量 top 表示未匹配左括号数量减 1。遇到右括号时，若 top==-1，说明没有可匹配的左括号，应把当前右括号修改为左括号，执行 top+=1 并令 ans 加 1；否则匹配一个左括号，执行 top-=1。扫描结束后剩余未匹配左括号数为 top+1，长度为偶数时需要将其中一半改为右括号，即加上 (top+1)//2。因此依次选择 ②、④、⑥，选 D。
