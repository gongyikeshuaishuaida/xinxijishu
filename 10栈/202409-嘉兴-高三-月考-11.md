# 题目 11

有如下 Python 程序段：

```python
s = "01357987"
k = 3
stack = [s[0]]
for char in s[1:]:
    while stack[-1] > char and k > 0:
        stack.pop()  # 删除 stack 列表的最后一个元素
        k -= 1
    stack.append(char)  # 在 stack 列表的结尾插入元素 char
while k > 0:
    stack.pop()
    k -= 1
while stack[0] == "0":
    stack.pop(0)  # 删除 stack 列表的第一个元素
```

执行该程序段后，`stack` 的值是（   ）

- A. `['1','3','5','7']`
- B. `['7','9','8','7']`
- C. `['0','7','9','8','7']`
- D. `['0','1','3','5','7']`

---

## 答案

**正确答案：** A

---

## 解析

扫描字符串时，只要栈顶大于当前字符且仍可删除，就弹出栈顶；共删除 3 个字符。最后再删除开头的 `0`，得到 `['1','3','5','7']`。
