# 题目 07

小李录制并保存了 `a1.wav` 和 `a2.wav` 两段音频，再分别另存为 `a1.mp3` 和 `a2.mp3`，参数如下图。下列说法正确的是（   ）

![[attachments/202405Z20_07_音频参数表.jpg]]

- A.`a1.wav` 与 `a2.wav` 的存储容量一样大
- B.`a1.wav` 与 `a1.mp3` 的存储容量一样大
- C.`a1.wav` 比 `a2.wav` 保真度高
- D.`a2.wav` 与 `a2.mp3` 的保真度一样

---

## 答案

**正确答案：** C

---

## 解析

a1.wav 的采样频率和量化位数均高于 a2.wav，因此单位时间采样数据更多、保真度更高。MP3 是压缩格式，存储容量和保真度都可能与 WAV 不同，故只有 C 正确。
