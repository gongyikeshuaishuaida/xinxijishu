# 题目 16

图像数字化要经过采样、量化、编码等环节，图像的量化是指要使用多大范围的数值来表示图像采样之后每个像素的颜色信息，一般用二进制数来表示，其长度也称为颜色的位深度。如256色图像的位深度为8位。图像存储容量计算公式为：存储容量=总像素×颜色位深度。

已知某BMP图像的每个像素的颜色均不同，可根据其宽度和高度计算最小存储容量（四舍五入保留1位小数），运行结果如下图所示。

w = int(input("请输入图像宽度："))
h = int(input("请输入图像高度："))
d = len(d2b(w * h-1))    # 计算最小位深度
c = ______③______       # 注意将存储容量单位转换成KB
print("该BMP图像的最小存储容量为", ______④______, "KB")
~~~

（1）请将程序代码补充完整。

（2）若该BMP图像的宽、高分别为128、64，则其位深度至少为 ______⑤______。

---

## 答案

（1）① n%2　② n//2　③ w*h*d/8/1024　④ round(c,1)

（2）⑤ 13

---

## 解析

十进制整数转二进制时，每轮取 n 除以2的余数并将 n 整除2。图像像素数为 w*h，每个像素占 d 位，先除以8换算为字节，再除以1024换算为KB。128×64=8192=2^13，因此最少需要13位表示不同颜色。
