# 题目 13

“奇校验”是一种检验数据在传输过程中是否出错的方法。例如要传输一个 ASCII 字符“A”，先得到“A”的内码值 65D，再转成二进制形式的内码值 1000001B，如下图所示，该二进制内码值就是图中的“数据位”内容。由于该“数据位”里共有 2 个“1”，于是在“数据位”前加上一个字符“1”作为“校验位”。如果“数据位”里已经是奇数个“1”，则将字符“0”作为“校验位”加在“数据位”前。

![[attachments/202411温州十校_13_奇校验示意图.png]]

小明编写了一个输入 ASCII 码字符、生成该字符对应的奇校验码的 Python 程序：

~~~python
ch=input('请输入一个ASCII码字符：')
ans=0
s=''
x=ord(ch)
while x>=0:
    ans=______②______
    s=str(x%2)+s
    ______③______
if ans%2==1:
    ______④______
else:
    s='1'+s
print('生成的奇校验码为：',s)
~~~

（1）已知“3”的 ASCII 码值为 33H，则它的奇校验码是“1100001” ______①______。（单选：填字母）

- A. 正确
- B. 错误

（2）请在划线处填入合适的代码。

（3）加框处代码有错，请改正：`while x>=0` 应改为 ______⑤______。

## 答案

**正确答案：** （1）B；（2）② `ans+x%2`；③ `x=x//2`（或 `x//=2`）；④ `s='0'+s`；（3）⑤ `while x>0`（`while x!=0` 也可）。

## 解析

程序每轮取出 `x` 的最低位并累加到 `ans`，再用整除 2 去掉最低位。数据位中“1”的个数为奇数时，校验位应为 0；否则应为 1。`33H` 对应的 7 位数据位为 `0110011`，题干给出的“1100001”并非其奇校验码，所以（1）选 B。若条件写成 `x>=0`，当 `x` 变为 0 后仍会继续循环，必须改为 `x>0` 或 `x!=0`。
