# 题目 13

13.运动场馆公告牌上的数字提示语采用 UTF-8 编码，编码规则如图所示：

![[attachments/202406-湖州-高二-期末-13_横排1_2.png]]

（1）若提示语为 1100100110001011，按规则得到的十六进制数是 ______①______ H。

（2）请在程序划线处填入合适的代码：

~~~python
def check_bt(bstr):
    if bstr[______②______]=="0":
        return 1
    elif bstr[:3]=="110":
        return 2
    elif bstr[:4]=="1110":
        return 3
    elif bstr[:5]=="11110":
        return 4

s=input("请输入数字提示语：").replace(" ","")
bzw={1:[1],2:[3,2],3:[4,2,2],4:[5,2,2,2]}
______③______
i=0
while i<n:
    k=check_bt(s[i:i+8])
    ss=""
    for j in range(k):
        ss+=s[i+j*8+______④______:i+(j+1)*8]
    i=i+k*8
~~~

（3）代码把去掉标志位后的二进制字符串转换为十六进制并输出对应 Unicode 字符。

---

## 答案

**正确答案：** ①24B；②0（或 0:1、:1）；③n=len(s)；④bzw[k][j]

---

## 解析

两字节 UTF-8 串 1100100110001011 去掉首字节的 110 和第二字节的 10 后得到 01001011，即十六进制 24B。判断首字节时从下标 0 开始；输入字符串长度用于循环；每个字节要跳过的标志位个数由 bzw[k][j] 给出。
