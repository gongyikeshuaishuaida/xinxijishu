# 题目 14

某中学在校园的校门、走廊、操场等区域安装了高清摄像头，建成“平安校园”视频监控系统。该系统的摄像头拍摄的图像采用 24 位 RGB 真彩色编码，其中 R、G、B 三个颜色分量各占 8 位。采集到的画面经一定的压缩后传输到服务器统一存储。

请回答下列问题:

(1) 下列关于图像数字化与图像编码的说法，正确的是 ______ (多选)

(注:全部选对的得2分，选对但不全的得1分，不选或有选错的得0分)。

- A. 数字化时提高采样频率，图像会更清晰

- B. RGB 模式的图像最多可表示 256 种颜色

- C. 拍摄的画面，任意放大不会失真

- D. 将图像文件 .bmp 压缩为 .jpg，其占用的存储空间会减小


(2) 小明编写了如下 Python 程序，用于计算一幅未经压缩图像所需的存储容量并换算为MB。

```python
w = int(input())  # 图像宽度（像素）
h = int(input())  # 图像高度（像素）
b = int(input())  # 每个像素占用的位数
size = ______
mb = size / 1024 / 1024
print("存储容量约为：", round(mb, 1), "MB")  # round函数用于对数据进行四舍五入
```

①请将程序补充完整。

②程序体现的算法为______②______（单选，填字母：A. 解析算法/B. 枚举算法）。

③该系统中某摄像头抓拍到一幅未经压缩的BMP彩色图像，分辨率为1280×960。根据上面的参数输入，则程序输出的结果是______③______。

(3) 该摄像头以25帧/秒的帧率连续拍摄视频，每帧图像经压缩后平均占用约256KB。若连续录制1分钟，经压缩后所需的存储容量约为______MB。

(4) 该市计划扩大“平安校园”建设规模：在全市100所中学各建设1套视频监控系统，每套系统安装5台摄像机。若使用二进制串对这些设备进行编码，二进制码的前几位表示学校编号，其余位表示摄像机编号，则所需的二进制位数最少是______。

---

## 答案

**正确答案：** (1) A、D；(2) ① `w * h * b / 8`（或整除8）；②A；③ `存储容量约为： 3.5 MB`；(3) 375；(4) 10。

---

## 解析

图像未经压缩容量=像素数×每像素位数÷8。1280×960×24÷8÷1024²≈3.5MB。视频容量25×60×256÷1024=375MB。100所学校需7位，5台摄像机需3位，共10位。
