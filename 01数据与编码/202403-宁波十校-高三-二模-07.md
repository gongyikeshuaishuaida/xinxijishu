# 题目 07

某段未经压缩的音频，采样频率是 44.1 kHz，量化位数为 8 b，下列说法正确的是（   ）

- A. 声音数字化需要经过采样和量化两个过程
- B. 该音频数字化时，量化值取值范围为 1～256
- C. 用手机播放音频的过程实现了信号的数模转换
- D. 该音频数字化时，每分钟的采样样本数为 44100 个

## 答案

**正确答案：** C

## 解析

播放数字音频时需要把数字信号转换为模拟信号，即数模转换。8 位量化值通常为 0～255；44.1 kHz 是每秒采样次数而不是每分钟；声音数字化还包括编码等环节，A 表述不严谨。
