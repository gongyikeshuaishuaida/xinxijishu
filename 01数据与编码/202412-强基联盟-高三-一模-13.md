# 题目 13

行程编码是一种利用空间冗余度压缩图像的方法。它的主要算法是在数据图像的编码中寻找连续的重复数值，并用出现次数和颜色编号标记这些连续的值。行程编码能有效减少二值图像的存储空间。

例如，若某图像共有四个像素，位深度为 4，各像素的像素值如示例图所示：

![[attachments/202412强基联盟_13_像素示例.jpg]]

该图像的二值图像颜色编码为：1100 0000 0101 1111，利用行程编码算法可以压缩为：2 1 7 0 1 1 1 0 5 1。

另外，第 13 题图 a 为“熊猫.bmp”图像：

![[attachments/202412强基联盟_13_熊猫图.jpg]]

（1）对于某二值图像的颜色编码：0000 0000 0111 1111 1000，利用行程编码算法可以压缩为 ______①______（各数之间用空格隔开）。

（2）编写 Python 程序，利用行程编码算法对第 13 题图 a“熊猫.bmp”图像进行压缩（图像像素：100*100，位深度：8 位）。实现该功能的部分 Python 程序如下，请在划线处填入合适的代码。im 的存储格式为 100 行、100 列的像素值数组（第 13 题图 b 的文字示意略）。

~~~python
from PIL import Image
import numpy as np

# 打开“熊猫.bmp”图像，将图像每个像素的值（十进制）存入 im 中
im=np.array(Image.open("熊猫.bmp").convert("L"))

def dtob(x):
    t=""
    for i in range(8):
        t=str(x%2)+t
        x//=2
    return t

s=""
for i in im:
    for j in i:
        ______①______
n=len(s)
i=1; k=1; xcode=""
while i<=n-1:
    if ______②______:
        k+=1
    else:
        xcode=xcode+" "+str(k)+" "+s[i-1]
        ______③______
    i+=1
xcode=xcode+" "+str(k)+" "+s[i-1]
print(xcode)
~~~

## 答案

**参考答案：**

- （1）9 0 8 1 3 0
- （2）① s+=dtob(j)；② s[i]==s[i-1]（写成 int(s[i])==int(s[i-1]) 亦可）；③ k=1

## 解析

颜色编码 00000000011111111000 中连续的 0、1、0 分别有 9、8、3 个，行程编码按“次数、颜色编号”输出，所以结果为 9 0 8 1 3 0。程序先把每个像素转换为 8 位二进制字符串并依次追加到 s；从 i=1 开始比较相邻字符，若相同就累加行程长度，否则输出上一段并把 k 重置为 1。
