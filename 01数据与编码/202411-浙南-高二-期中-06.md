# 题目 06

使用 UltraEdit 软件观察字符串“11月6日，期中考！”的内码，原题界面如下：

![[attachments/202411浙南_06_UltraEdit内码界面.png]]

下列说法正确的是（   ）

- A. 字符“！”的内码是“A3”
- B. 图中共有 3 个 ASCII 码字符
- C. 汉字“考”的内码二进制表示为“10111111 10111100”
- D. 字符“6”的内码是“36”，所以字符“10”的内码是“3A”

## 答案

**正确答案：** C

## 解析

界面显示“考”的 UTF-8 字节为 `BF BC`，分别转换为二进制即 `10111111 10111100`。字符“！”对应两个字节 `A3 A1`，ASCII 字符数量也不止 3 个，且字符“10”是两个字符，不能按一个十六进制码表示。
