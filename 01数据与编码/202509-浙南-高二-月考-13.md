# 题目 13

编写 Python 程序，将输入的十进制整数转换为十六进制字符串。例如：输入 42 时输出 `"2A"`，代码如下：

```python
n = int(input("请输入十进制数:"))
s = ""
while n != 0:
    r = n % 16
    if r > 9:
        __________  # (1)
    else:
        __________  # (2)
    n = n // 16

print("转换成十六进制数是:", s)
```

为实现上述功能，划线处可供选择的代码有：

- ① `s = str(r) + s`
- ② `s = s + str(r)`
- ③ `s = chr(r + 55) + s`
- ④ `s = s + ord(r + 55)`

依次可填入的顺序为（   ）

- A. ③①
- B. ④②
- C. ①④
- D. ②③

---

## 答案

**正确答案：** A

---

## 解析

余数大于 9 时，要把 10—15 转换为字符 A—F，并且由于除法得到的余数顺序是低位到高位，所以新字符应加到字符串左侧，填 ③。余数不超过 9 时同样要加到左侧，填 ①。因此顺序为 ③、①，选 A。
