# 题目 10

有如下 Python 程序段：

```python
n = 5
a = [""] * n
y = float(input())
i = 0
while i < n:
    y = y * 2
    if y >= 1:
        a[i] = "1"
        y = y - 1
    else:
        a[i] = "0"
    i = i + 1
print("0.", end="")
for i in range(n):
    print(a[i], end="")
```

若输入的值为 `0.375`，运行以上程序段后，输出的结果是（   ）

- A. `0.01100`
- B. `0.00110`
- C. `0.10100`
- D. `0.00101`

---

## 答案

**正确答案：** A

---

## 解析

小数部分连续乘2取整数：`0.375×2=0.75` 得0，`0.75×2=1.5` 得1，余下依次得到1、0、0，因此输出 `0.01100`。
