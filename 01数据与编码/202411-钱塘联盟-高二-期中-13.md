# 题目 13

某种编码以 4 位二进制码为一组，每组前两位表示方向，后两位表示距离。编写一个 Python 程序，将编码翻译成方向和距离，距离值为每组编码后两位二进制码转换为十进制数的值。运行过程如下：

~~~text
输入二进制编码（位数为4的整数倍）：00000101
东 0
南 1
~~~

（1）实现该问题的程序如下，请在划线处填入合适的代码。

~~~python
s = input('输入二进制编码（位数为4的整数倍）：')
d = {"00": "东", "01": "南", "10": "西", "11": "北"}
i = 0
while i < len(s):
    c = ______①______
    b1 = s[i+2]
    b2 = s[i+3]
    ______②______
    print(d[c], v)
    ______③______
~~~

（2）若输入的内容为 1111，则输出的内容是 ______④______。

---

## 答案

（1）① s[i:i+2]　② v=int(b1)*2+int(b2)　③ i=i+4

（2）④ 北 3

---

## 解析

每轮从当前位置取前两位作为方向编码，再将后两位按二进制转换为十进制距离，最后把下标向后移动 4 位。输入 1111 时方向码为 11，对应“北”，距离码 11 对应 3。
