# 题目 09

数组a有21个互不相等的整型元素，按升序排列。若采用二分查找算法在a中查找key，且3次参与比较的元素依次是`a[10]`、`a[15]`、`a[13]`，则key不可能是（   ）

- A. `a[11]`
- B. `a[12]`
- C. `a[14]`
- D. `a[16]`

---

## 答案

**正确答案：** D

---

## 解析

第一次比较`a[10]`后仍继续向右查找，说明`a[10] < key`；第二次比较`a[15]`后，第三次比较的是位于`a[15]`左侧的`a[13]`，说明比较`a[15]`后查找范围回到其左侧，即`key < a[15]`。因此`a[10] < key < a[15]`，key只可能是`a[11]`～`a[14]`，`a[16]`大于`a[15]`，不可能是key。
