# 题目 11

有如下Python程序段：

```python
# 随机产生10个互不相等的整数存入列表a，代码略
m, r = 0, 0
for i in range(len(a)):
    if a[i] < a[m]:
        r = i
    else:
        m = i
```

执行该程序段后，r的值为6，则下列表达式中，值一定为True的表达式共有（   ）个。

① `a[0] < a[6]`        ② `a[6] < a[5]`        ③ `a[6] < a[7]`

- A. 0
- B. 1
- C. 2
- D. 3

---

## 答案

**正确答案：** B

---

## 解析

循环中m记录最近一次满足“`a[i] ≥ a[m]`”的下标，r记录最近一次满足“`a[i] < a[m]`”的下标。r的值为6，说明i=6时`a[6] < a[m]`成立且m未更新；此后i=7、8、9均未使r更新，说明`a[7] ≥ a[m]`，结合`a[6] < a[m]`可得`a[6] < a[7]`，③一定为True。①、②均可举出r=6的反例，如a=[10,9,8,7,6,5,4,12,13,14]时`a[0] > a[6]`，a=[10,5,6,7,8,3,4,11,12,13]时`a[6] > a[5]`，均不一定成立。故一定为True的表达式共1个，选B。
