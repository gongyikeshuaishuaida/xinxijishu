# 题目 10

有如下Python程序段：

```python
i = len(s) - 1
while i >= 0 and c == "*":
    if "0" <= s[i] <= "9":
        c = s[i]
    else:
        i -= 1
```

若c和s的初始值分别为"*"和"172D6AF"，执行该程序段后，c的值为（   ）

- A. "*"
- B. "1"
- C. "2"
- D. "6"

---

## 答案

**正确答案：** D

---

## 解析

程序从字符串末尾开始向前扫描，只要当前字符不是数字字符就继续前移，一旦遇到数字字符就把它存入c，此时c不再等于"*"，循环结束。"172D6AF"从右向左依次为F、A、6，首次遇到的数字字符是"6"，故c的值为"6"。
