# 题目 15

某活动的n个工作组（编号0～n-1）通过在线平台招募志愿者。活动涉及t项技能（编号0～t-1），每个工作组对每项技能提出了需求数量。每位志愿者具备若干项技能，至多加入1个工作组，可兼顾该工作组相应的多项技能需求。现有m位候选人（编号0～m-1），招募流程如下：

①工作组按技能需求总数降序排序；

②排在首位的工作组录用一位满足其所需技能项数最多的候选人；

③根据录用情况更新工作组技能需求，并保持所有工作组按技能需求总数降序排列；

④当工作组的技能需求总数为0，或无候选人满足需求时，该工作组招募结束；

⑤重复②～④，直至所有工作组招募结束。

（1）若有两个工作组招募，工作组对各技能的需求数与所有候选人的技能情况分别如第15题图a和图b所示。0号工作组技能需求总数为6，录用2号候选人后更新为3，接下来1号工作组录用的第1位候选人编号为________。

![[attachments/202606-高考-高三-真题-15_横排1_2.png]]

（2）定义如下两个函数，参数lst均为列表，每个元素由“工作组编号”和“技能需求总数”两个数据项构成。fsort(lst)函数的功能是根据每个工作组的“技能需求总数”对lst进行降序排序。

```python
def move(lst, idx):
    if 0 <= idx < len(lst) - 1:
        q = lst[idx]
        k = idx
        while k < len(lst) - 1 and lst[k+1][1] >= q[1]:
            lst[k] = lst[k+1]
            k += 1
        lst[k] = q

def fsort(lst):
    n = len(lst)
    for i in range(n-1):
        move(lst, n-i)
```

①若`lst=[[0,5],[1,6],[4,8],[2,7],[3,4]]`，调用`move(lst,1)`后，`lst[2][0]`的值为________。

②程序中加框处的表达式`n-i`有错，应将其修改为________________。

（3）根据上述招募流程，编写如下Python程序输出各候选人的录用结果，请在划线处填入合适的代码。

```python
def proc(reqs, cands):
    """
    根据reqs列表计算生成rsum列表，rsum[i][0]为工作组编号，
    rsum[i][1]为工作组技能需求总数；将rsum按技能需求总数
    降序排序。代码略
    """
    sel = [-1] * len(cands)  # sel[i]为-1表示i号候选人未被录用
    while len(rsum) > 0:
        num = rsum[0][0]
        maxcnt = 0
        ______①______
        for i in range(len(cands)):
            if sel[i] == -1:
                cnt = 0
                for j in ______②______:
                    if reqs[num][j] != 0:
                        cnt += 1
                if cnt > maxcnt:
                    maxcnt = cnt
                    bestc = i
        if bestc == -1:
            rsum.pop(0)      # 删除rsum中下标为0的元素
        else:
            sel[bestc] = num
            for i in cands[bestc]:
                if reqs[num][i] != 0:
                    reqs[num][i] -= 1
            ______③______
            if rsum[0][1] == 0:
                rsum.pop(0)
            else:
                move(rsum, 0)
    return sel

"""
读取各工作组的技能需求数据存入reqs列表，reqs[i][j]表示
i号工作组对j号技能的需求数；读取所有候选人的技能存入
cands列表，cands[i]为i号候选人的技能编号列表。代码略
"""
sel = proc(reqs, cands)
# 根据sel列表输出录用结果，代码略
```

---

## 答案

（1）3；（2）①2；②`n-i-2`；（3）①`bestc = -1`；②`cands[i]`；③`rsum[0][1] -= maxcnt`（或 `rsum[0][1] = sum(reqs[num])`）

---

## 解析

（1）0号工作组录用2号候选人后技能需求总数更新为3，1号工作组需求总数为4，按降序排在首位。其需求技能为1号、2号技能，候选人3具备1、2两项技能，是满足其所需技能项数最多的候选人，故1号工作组录用的第1位候选人编号为3。

（2）①调用`move(lst,1)`时，q=[1,6]依次与后方的8、7比较并后移，最终lst=[[0,5],[4,8],[2,7],[1,6],[3,4]]，`lst[2][0]`的值为2。②fsort每轮处理的位置应从n-2递减到0，加框处应为`n-i-2`。

（3）①每轮挑选候选人前应先将bestc初始化为`bestc = -1`，便于判断本轮是否找到候选人；②cnt统计候选人i具备的工作组num所需技能项数，应遍历该候选人的技能列表，填`cands[i]`；③录用bestc后，工作组num的各项需求数被扣减，其技能需求总数相应减少maxcnt，填`rsum[0][1] -= maxcnt`（或直接重新计算`rsum[0][1] = sum(reqs[num])`）。
