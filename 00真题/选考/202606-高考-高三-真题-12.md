# 题目 12

执行如下程序段，输出的数据依次为6、9、8。若将加框处语句删除，则输出的数据依次为-12、6、-7、9、8、-6。

![[attachments/202606高考_12_图1.png]]

```python
def proc(head, d):
    # 算法的流程图如第12题图所示，代码略
    # 将head和d初始化为给定值，代码略
    # head是整型变量，列表d每个元素包含两个整型数据项

head = proc(head, d)
p = head
while p != -1:
    print(d[p][0])
    p = d[p][1]
```

流程图中（1）～（3）处可选的表达式有：

① `q ← d[p][1]`         ② `q ← p`

③ `head ← d[p][1]`      ④ `d[q][1] ← d[p][1]`

则（1）～（3）处的表达式序号依次为（     ）

- A. ④②③
- B. ④③①
- C. ③④①
- D. ③④②

---

## 答案

**正确答案：** D

---

## 解析

列表d的每个元素包含数据项和后继指针，程序的功能是删除链表中数据为负数的节点：删除加框处语句（流程图中删除负数节点的分支）后，负数节点不再被删除，所有数据依次输出。流程图中，当`d[p][0]<0`且`q=-1`时，被删节点是头节点，应执行（1）`head ← d[p][1]`修改头指针；当`q≠-1`时，被删节点在链表中部，应执行（2）`d[q][1] ← d[p][1]`让前驱节点跳过当前节点；当`d[p][0]≥0`时节点保留，应执行（3）`q ← p`记录当前节点。故（1）～（3）依次为③④②，选D。
