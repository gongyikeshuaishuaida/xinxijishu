# 题目 14

在葡萄园监控系统中，为防止网络传输不稳定导致的数据丢失，智能终端采用了缓冲机制：每隔60分钟获取一次传感器数据存入缓冲区，然后将缓冲区中的数据按获取顺序逐一上传，上传成功的数据从缓冲区中删除；若上传失败，则随机延时1至10分钟后重试，但重试过程不得影响数据获取的时间间隔。

（1）若智能终端在某天8:00、9:00、10:00、11:00获取的传感器数据依次为D1、D2、D3、D4，8:30～11:30网络断开，其他时段数据传输正常，则智能终端在11:00以后上传成功的第2个数据是________。

（2）实现上述功能的部分Python程序如下，请在划线处填入合适的代码。

注：本程序中sleep的参数单位为毫秒；忽略数据获取、上传及其他处理的耗时。

```python
# 导入相关库，代码略
def trans(data):
    # 将data上传至服务器，上传成功返回1，否则返回0，代码略
buf = []
while True:
    # 获取传感器数据，存入变量data中，代码略
    buf.append(data)                  # 将传感器数据存入缓冲区
    stime = 60
    while stime > 0 and ______①______:
        data = buf[0]
        state = trans(data)
        if ______②______:
            buf.pop(0)                # 删除上传成功的数据
        else:
            delay = randint(1, 10)    # 随机生成1到10之间的整数
            if delay > stime:
                delay = stime
            sleep(delay * 60 * 1000)  # 延时delay分钟
            ______③______
    sleep(stime * 60 * 1000)
```

---

## 答案

（1）D3；（2）①`len(buf) > 0`（或 `buf`）；②`state == 1`；③`stime -= delay`

---

## 解析

（1）8:00获取D1后立即上传成功并移出缓冲区；9:00、10:00获取的D2、D3入缓冲区，因断网上传失败进入重试；11:30网络恢复后按获取顺序先后上传成功D2、D3，故11:00以后上传成功的第2个数据是D3。

（2）①内层循环在缓冲区中仍有数据且剩余时间大于0时继续上传，故填`len(buf) > 0`（或直接写`buf`）；②上传成功时trans返回1，即`state == 1`时删除队头数据；③每次失败延时delay分钟后，剩余时间应减少delay分钟，填`stime -= delay`，保证整点获取数据的时间间隔不受影响。
