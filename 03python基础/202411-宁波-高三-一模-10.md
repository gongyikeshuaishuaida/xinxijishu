# 题目 10

有如下 Python 代码段：

~~~python
from random import randint

def fun(a, x):
    r = 0
    for i in range(len(a)):
        if a[i] % x != 0:
            a[r] = a[i]
            r += 1
    return a[:r]

a = [3, 5, 16, 9, 8, 5]
t = randint(3, 5)
a = fun(a, t)
~~~

则运行程序后，a 的值不可能是（   ）

- A. [5, 16, 8, 5]
- B. [3, 5, 9, 5]
- C. [3, 5, 16, 9]
- D. [3, 16, 9, 8]

---

## 答案

**正确答案：** C

---

## 解析

函数保留不能被 t 整除的元素。t=3 时得到 A，t=4 时得到 B，t=5 时得到 D；C 不是 t 取 3、4、5 中任意一个时的结果。
