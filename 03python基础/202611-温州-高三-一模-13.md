# 题目 13

某自习室采用智能灯控系统，采集人体存在传感器数据，若为 1 表示有人，则读取光线传感器数据（光线强度范围为 0～1023，包含 0 和 1023）存入变量 light；若为 0 表示无人，则将 -1 存入变量 light。灯的控制逻辑为：

①若当前灯状态为亮，无人或读取到的光线强度大于 300，则关灯。

②若当前灯状态为灭，连续 2 次有人且光线强度不高于 100，则开灯。

请回答下列问题。

（1）若灯初始状态为灭，某段时间内 light 的值依次为“41,39,145,-1,41,40”，则该时段内开灯次数为 ______ 次。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。



```python
sta = False    # 当前灯状态为灭
flag = False
while True:
    # 采集传感器数据，为变量 light 赋值，代码略
    if sta and (light == -1 or light > 300):
        ______①______
        # 关灯，代码略
    elif not sta:
        if ______②______:
            if flag:
                sta = True
                # 开灯，代码略
            ______③______
        else:
            flag = False
    # 延时 1 秒
```

---

## 答案

（1）2。

（2）① `sta = False`；② `0 <= light <= 100`；③ `flag = not flag`。

---

## 解析

41、39 形成首次连续两次满足条件，开灯后直到 -1 才关灯；41、40 再次触发开灯。flag 记录前一次是否满足开灯条件，开灯时翻转使其复位。
