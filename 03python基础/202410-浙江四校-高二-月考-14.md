# 题目 14

某字符串中存在重复字符，程序运行结果如下：

![[attachments/202410浙江四校_14_字符串去重运行图.jpg]]

（1）补全字符串去重程序：

```python
def pr(x):
    sp = ""
    for i in range(x):
        sp = sp + s[i]
    return sp

num = input("请输入字符串：")
print("原始字符串：", num)
s = list(num)
i = 1
j = len(s)
while ______①______:
    if s[i] in s[:i]:
        s = s[:i] + s[i + 1:j]
        j = j - 1
        ______②______
    i = i + 1
print("去重后字符串：", ______③______)
```

（2）把加框处删除语句改为 `s[i]=s[j-1]` 后，输入仍为 `isixiao`，输出结果为______。

---

## 答案

**正确答案：** （1）① `i<j`；② `i=i-1`；③ `pr(j)`（或 `pr(i)`、`pr(len(s))`）；（2）`isoxa`

---

## 解析

发现重复字符后删除当前位置，列表缩短且当前位置换成了下一个字符，所以要让 `i` 退 1，抵消循环末尾的自增以便重新检查。若改成用末尾字符覆盖当前位置，则各次覆盖后得到 `isoxa`。
