# 题目 11

有如下 Python 程序：

```python
import random
def f(s):
    i, j = 0, len(s) - 1
    k = random.randint(1, 3)
    ans = ""
    flag = True
    while i <= j:
        if flag or s[i] <= s[j]:
            ans += s[i]
            i += 1
        else:
            ans += s[k]
            j -= 1
        flag = not flag
    return ans
print(f("avocado"))
```

执行语句 `print(f("avocado"))` 后，下列输出结果不可能的是

- A. `aavaoac`
- B. `avvvovc`
- C. `aovoooc`
- D. `acvcocc`

---

## 答案

**正确答案：** A

## 解析

随机数 `k` 只能取 1、2、3。分别枚举三种取值并按 `flag` 交替模拟，可能得到 B、C、D 三个输出；A 不在可能结果中，因此 A 不可能。
