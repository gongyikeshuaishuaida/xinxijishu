# 题目 11

有如下 Python 程序段，用于判断列表 `data` 中元素是否升序，是则输出 `"YES"`，不是则输出 `"NO"`。当 `data=[1,2,3,4,5]` 时，运行代码时系统报错“list index out of range”（列表索引越界），引发该报错的语句是（   ）

```python
# 输入列表 data 的值，代码略
i = 1    # ①
s = "YES"
while i < len(data):
    if data[i] > data[i + 1]:    # ②
        s = "NO"    # ③
        break
    i += 1    # ④
print(s)
```

- A. ①
- B. ②
- C. ③
- D. ④

---

## 答案

**正确答案：** B

---

## 解析

当 `i=4` 时，循环条件 `i < len(data)` 仍然成立，执行语句②会访问 `data[5]`，而长度为 5 的列表最大下标是 4，因此发生索引越界。应把循环条件改为只让 `i` 遍历到倒数第二个元素，报错语句为②，选 B。
