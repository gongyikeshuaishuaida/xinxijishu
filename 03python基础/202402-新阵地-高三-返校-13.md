# 题目 13

有一个数字集合，所有数按从小到大的顺序排成规律的数列，即 `a1=3`、`a2=5`、`a3=6`、`a4=9`、……，按照左小右大、上小下大的原则写成三角表。

![[attachments/202402新阵地_13_图a_数列三角表.jpg]]

程序运行界面如下：

![[attachments/202402新阵地_13_图b_运行界面.jpg]]

（1）根据图 a 中的数据规律，可以推出 `a(13)=______`。

（2）部分 Python 程序如下，请在划线处填入合适的代码。

```python
num = int(input("请输入数列的项数："))
n = num
i, sum = 1, 0
while n > i:
    for j in range(i):
        ______①______
    ______②______
    i += 1
if n != 0:
    for j in range(n):
        sum += 2 ** i + 2 ** j
    ______③______
print("a(" + str(num) + ")=", b)
print("集合前" + str(num) + "项和为:", sum)
```

## 答案

**正确答案：** （1）36；（2）① `sum += 2 ** i + 2 ** j`；② `n = n - i`；③ `b = 2 ** i + 2 ** (n - 1)`（或 `b = 2 ** i + 2 ** j`）。

## 解析

第 `i` 行的元素可表示为 `2 ** i + 2 ** j`（`j` 从 0 到 `i-1`）。循环先完整累加已经确定的行，并将剩余项数减去该行长度；最后一行中第 `n` 个元素就是 `b`。第 13 项位于第 5 行第 3 列，故为 `2**5+2**2=36`。
