# 题目 10

10.有如下 Python 程序段：

```python
s = "a5bc23d26t"
t = 0
res = ""
for i in range(len(s)):
    if "0" <= s[i] <= "9":
        t = t * 10 + int(s[i])
    else:
        t = (t + i) % len(s)
        res = s[t] + res
```

程序运行后，变量 `res` 的值是（ ）

- A. `"3ta2a"`
- B. `"3dbct"`
- C. `"a6d2t"`
- D. `"3tb2a"`

---

## 答案

**正确答案：** A

---

## 解析

只有遇到非数字字符时才执行 `t=(t+i)%len(s)` 并把 `s[t]` 加到结果前端；数字字符只更新 `t`。逐位执行后得到 `res="3ta2a"`，选 A。
