# 题目 15

15.将四字成语进行分类。例如“心心相印”属于 AABC 类型，“喜气洋洋”属于 ABCC 类型。编写程序从文本文件中读取所有四字成语，分类并输出。

![[attachments/202406杭州_15_成语分类输出.jpg]]

（1）若收集了 3 个成语“百花齐放”“同心同德”“一心一意”，共出现 `______①______` 种类型。

（2）定义函数 `ctype(s)` 返回四字成语类型：

```python
def ctype(s):
    ret="A"
    k=65
    for i in range(1,4):
        for j in range(i):
            if s[i]==s[j]:
                ret+=ret[j]
                break
        if s[i]!=s[j]:
            k+=1
            ret+=chr(k)
    return(ret)
```

②调用 `ctype(s)`，若 `s` 为“熙熙攘攘”，函数结束时 `k` 的值是 `______②______`。

③若将加框处代码 `ret[j]` 误写为 `chr(k)`，下列哪组数据能测试出问题（ ）

- A.`s="炯炯有神"`
- B.`s="人才济济"`
- C.`s="同心同德"`
- D.`s="博学多才"`

（3）实现分类输出的部分程序如下，请填空：

```python
file=open("成语.txt","r")
word=[["",-1] for i in range(100)]
______③______
n=0
ct=[""]*10
head=[-1]*10; tail=[-1]*10
for line in file:
    word[i][0]=line.strip("\n")
    ctmp=ctype(word[i][0])
    j=0
    while ______④______:
        j+=1
    if j!=n:
        p=tail[j]; word[p][1]=i; tail[j]=i
    else:
        ct[n]=ctmp; head[n]=i; tail[n]=i
        n+=1
    i+=1
file.close()
for i in range(n):
    print(ct[i],end=" ")
    ______⑤______
    while q!=-1:
        print(word[q][0],end=" ")
        q=word[q][1]
    print()
```

请在划线处填入合适的代码。

---

## 答案

**正确答案：** （1）① 2。
（2）② 66；③ C。
（3）③ `i=0`；④ `j<n and ctmp!=ct[j]`；⑤ `q=head[i]`。

---

## 解析

“百花齐放”是 ABCD，“同心同德”和“一心一意”都是 ABAC，因此共有 2 种。处理“熙熙攘攘”时只出现 A、B 两个新类别，`k=66`；“同心同德”中的第三个字重复第一个字，错误使用 `chr(k)` 才会暴露。分类链表初始化从 `i=0` 开始，循环查找已有类型，输出每类前先令 `q=head[i]`。
