# 题目 09

在 Python 中，以下哪个选项能正确实现查找列表中是否存在特定元素8并输出其索引？

```python
lst = [3, 4, 8, 1]
target = 8
for i in ______①______:
    if ______②______:
        print(i)
```

- A. ① `range(len(lst))`；② `lst[i] == target`
- B. ① `lst`；② `lst[i] == target`
- C. ① `lst`；② `i == target`
- D. ① `range(len(lst))`；② `i == target`

---

## 答案

**正确答案：** A

---

## 解析

要输出索引，循环变量应遍历下标范围 `range(len(lst))`，再用 `lst[i]` 与目标值比较。
