# 题目 14

有如下 Python 程序段：

~~~python
list = "2134524567"
c = 1
max = 0
for i in range(len(list)-1):
    if list[i] < list[i+1]:
        c = c+1
    else:
        max = c
        c = 1
print(max)
~~~

14. 执行该程序段后，变量 max 的值是（   ）

- A. 3
- B. 4
- C. 5
- D. 6

---

## 答案

**正确答案：** B

---

## 解析

程序统计连续递增段，但只在遇到下降时把当前 c 赋给 max，循环结束后没有再更新一次。前一段 1、3、4、5 的连续递增长度为4，遇到5后面的2时 max被赋为4；最后的递增段不会改变 max，因此结果为4。
