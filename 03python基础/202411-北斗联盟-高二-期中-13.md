# 题目 13

有如下 Python 程序段：

```python
a=[2,1,6,1,6,5,3,6,4,3,6,4,5,5,3]
dic={}
for i in a:
    if i not in dic:
        dic[i]=1
    else:
        dic[i]+=1
```

执行该程序段后，`dic[3]` 的值为（   ）

- A. 1
- B. 2
- C. 3
- D. 4

---

## 答案

**正确答案：** C

---

## 解析

列表 `a` 中数字 3 出现 3 次，字典统计后 `dic[3]=3`，因此选择 C。
