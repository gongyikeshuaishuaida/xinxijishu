# 题目 14

14.座位预约信息用数字和字母 `p`、`e` 编码：数字表示连续座位数，`p` 表示这些座位可预约，`e` 表示已被预约。例如 `3p7e1p5e11p` 表示 3 个可预约座位、7 个已预约座位、1 个可预约座位、5 个已预约座位和 11 个可预约座位。

![[attachments/202406杭州周边_14_座位预约输出.jpg]]

（1）若预约连续座位数为 5，输出的起始座位号为 ______①______。

（2）补充解析字符串的函数：

```python
def input_data(data):
    list1=[]
    t=0
    for ch in data:
        if "0"<=ch<="9":
            ______②______
        else:
            status=1
            if ______③______:
                status=0
            for i in range(t):
                list1.append(status)
            t=0
    return list1
```

（3）在座位数组 `seat` 中查找长度为 `n` 的连续空闲段：

```python
while i<=len(seat)-n:
    if ______④______:
        ans.append(i+1)
        c=c+1
    i=i+1
```

---

## 答案

**正确答案：** ①`[4,5,6,12]`；②`t=t*10+int(ch)`；③`ch=="e"`；④`list2==seat[i:i+n]`

---

## 解析

读取数字时按十进制累加，遇到 `p` 保持状态 1，遇到 `e` 改为状态 0，再把状态重复 `t` 次。样例数据中长度为 5 的连续空闲段起始位置为 4、5、6、12。滑动窗口 `seat[i:i+n]` 与全空闲列表 `list2` 相等时记录座位号。
