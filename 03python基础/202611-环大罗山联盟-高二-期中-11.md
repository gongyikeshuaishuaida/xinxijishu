# 题目 11

有如下 Python 程序段：

```python
a = [6, 4, 2, 8, 5, 3, 9, 17]
b = []
for i in range(len(a)):
    f = False
    for j in range(len(b)):
        if a[i] > b[j][-1]:  # b[j][-1]用于取二维列表b中索引j的子列表的最后一个元素
            b[j].append(a[i])  # append函数用于在列表末尾追加一个元素
            f = True
            break
    if f == False:
        b.append([a[i]])
```

用 Python 程序对列表 `a` 元素进行分组，程序运行后 `b[2]` 的值为（   ）

- A. `[2,3]`

- B. `[4,5]`

- C. `[6,8,9,17]`

- D. `[2,5,9]`

---

## 答案

**正确答案：** A

---

## 解析

每个元素放入第一个末元素更小的子列表，若无则新建。最终分组为[6,8,9,17]、[4,5]、[2,3]，故b[2]为[2,3]。
