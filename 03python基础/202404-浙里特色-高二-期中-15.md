# 题目 15

15.小明学习凯撒密码加密后，在基础上引入密钥字符串。规则为：字母、数字分别按密钥中的数字向左移位，密钥循环使用，其他字符不变。例如明文 `hello2024`、置换密钥 `526` 的密文为 `ccfgm6508`。

![[attachments/202404浙里特色_15_加密示例表.jpg]]

（1）若输入明文为 `123Abc`、置换密码为 `2024`，输出的密文为：______。

（2）加密算法如下，请在划线①②③处填入合适代码。

```python
def jiami(encode, key):
    q = []
    result = ""
    for x in key:
        q.append(int(x))
    head = 0
    for ch in encode:
        if "a" <= ch <= "z":
            ch = chr((ord(ch) - ord("a") - q[head]) % 26 + 97)
        elif "A" <= ch <= "Z":
            ch = chr((ord(ch) - ord("A") - q[head]) % 26 + 65)
        elif "0" <= ch <= "9":
            ch = ______①______
        head = ______②______
        result += ch
    return result

mw = input("请输入明文：")
key = input("请输入置换密钥：")
ss = ______③______
print("密文为：" + ss)
```

---

## 答案

**正确答案：** （1）`921Wzc`；（2）① `chr((ord(ch)-48-q[head])%10+48)`（或 `str((int(ch)-q[head])%10)`）；② `(head+1)%len(q)`（或 `(head+1)%len(key)`）；③ `jiami(mw,key)`

---

## 解析

数字字符的 ASCII 码从 48 开始，减去密钥后按 10 取模再转回字符；字母同理按 26 循环。每处理一个字母或数字，密钥下标循环加一；非字母数字字符虽不变，也按程序继续消耗一个密钥位。代入 `123Abc` 和 `2024` 得 `9、2、1、W、z、c`，即 `921Wzc`。
