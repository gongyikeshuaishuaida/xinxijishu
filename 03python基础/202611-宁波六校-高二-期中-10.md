# 题目 10

有如下 Python 程序段：

```python
def factor(x):
    cnt = 0; i = 2
    while x > 1:
        if x % i == 0:
            x = x // i
            cnt += 1
        else:
            i += 1
    return cnt
print(factor(n))
```

以下为 n 的不同取值，输出结果不同的一项是（   ）

- A. 60
- B. 210
- C. 16
- D. 48

---

## 答案

**正确答案：** D

---

## 解析

60、210、16 都有四个质因子（按重数计），48 有五个。
