# 题目 09

甲、乙程序段输出结果相同，则乙程序段划线处的正确代码是

甲程序段：

```python
s = 0; k = 1
for i in range(1, 100, 2):
    s = s + k / i
    k = -k
print(s)
```

乙程序段：

```python
s = 1; k = 1
i = 1
while ______①______:
    ______②______
    k = -k
    ______③______
print(s)
```

（   ）

- A. ① `i<99`；② `i=i+2`；③ `s=s+k/i`

- B. ① `i<99`；② `s=s+k/i`；③ `i=i+2`

- C. ① `i<=99`；② `i=i+2`；③ `s=s+k/i`

- D. ① `i<=99`；② `s=s+k/i`；③ `i=i+2`

---

## 答案

**正确答案：** A

---

## 解析

s 初值已计入第一项 1，因此先把 i 从 1 增至 3，再反转 k，加入 -1/3；最后应包含 99，不应再加入 101。
