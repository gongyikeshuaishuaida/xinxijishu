# 题目 13

在生物学中，碱基互补配对计算互补链规则有：DNA链或RNA链C与G相互配对，DNA链A与T相互配对，RNA链A与U相互配对，再相应处理，即是互补链。例如：DNA链“AGTCG”的互补链为“CGACT”。小明用Python设计程序，实现碱基互补配对计算互补链。

(1) RNA链“AUUGUC”的互补链是______。

(2) 完善`cpl`函数中的程序填空，实现相应功能。

```python
def cpl(sequ,type):
    ______①______
    dicDNA = {"A":"T","T":"A","G":"C","C":"G"}
    dicRNA = {"A":"U","U":"A","G":"C","C":"G"}
    for nt in ______②______:
        if type == "DNA":
            ans = dicDNA[nt]+ans
        elif type == "RNA":
            ans = dicRNA[nt]+ans
    return ans
# data中数据，如data = [["ACGTAG","DNA"],["GCUAGG","RNA"]]代码略
for seq in data:
    sequ,type = seq[0],seq[1]
    comp = ______③______
    print(type,"链",sequ,"的互补链是：",comp)
```

---

## 答案

(1) `GACAAU`。

(2) ① `ans = ""`；② `sequ`；③ `cpl(sequ,type)`。

---

## 解析

初始化空字符串，逐个读取原链字符，用对应字典查互补字符。每次把新字符拼在ans前面，得到反向互补链。AUUGUC逐字符互补为UAACAG，反向后为GACAAU。调用cpl时传入链内容和类型。
