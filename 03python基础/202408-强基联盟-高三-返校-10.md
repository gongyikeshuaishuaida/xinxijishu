# 题目 10

有如下程序段：

```python
# 随机生成5个正整数并存入列表s中，代码略
def sort_indices(s):
    n = len(s)
    y = [i for i in range(n)]  # 生成序列0～n-1
    for i in range(n - 1):
        for j in range(n - i - 1):
            if s[y[j]] >= s[y[j + 1]]:
                y[j], y[j + 1] = y[j + 1], y[j]
    return y
```

执行上述程序后，若返回结果为`[2,1,0,4,3]`，列表`s`中各元素值可能的是（   ）

- A. [3,2,1,5,4]
- B. [4,2,1,5,3]
- C. [5,2,1,3,4]
- D. [3,2,5,1,4]

---

## 答案

**正确答案：** A

---

## 解析

返回索引顺序表示 s[2]<s[1]<s[0]<s[4]<s[3]。A为1<2<3<4<5，正好对应索引2、1、0、4、3；其余选项不满足该顺序。
