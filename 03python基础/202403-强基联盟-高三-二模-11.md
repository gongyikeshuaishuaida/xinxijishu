# 题目 11

有如下 Python 程序：

```python
import random
s1 = "abcde"
s2 = "12345"
res = ""
i, j = 0, len(s2) - 1
while i <= len(s1)-1 and j >= 0:
    k = random.randint(0, 1)
    if k == 0:
        res += s1[i+k]
        i += 1
    else:
        res += s2[j-k]
        j -= 1
print(res)
```

执行程序后，变量 res 不可能的是（   ）

- A. ab4c321d5
- B. 4a32b1cde
- C. 5abc321
- D. ab4cd3e

## 答案

**正确答案：** C

## 解析

程序每次从 s1 的当前字符或从 s2 的尾部字符取一个字符，两个序列各自保持相对顺序。循环结束时，只有一种序列先耗尽；选项 C 的字符顺序与程序的取数规则不相容，不能产生。
