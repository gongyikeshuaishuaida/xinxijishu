# 题目 09

有如下 Python 程序段：

```python
d = {1: "p", 2: "y", 3: "t", 4: "h", 5: "o", 6: "n"}
num = [2, 6, 5, 3]
result = ""
for i in num:
    result = d[i] + result
```

执行后，`result` 的值为（   ）

- A. `ynot`
- B. `noty`
- C. `tony`
- D. `nyto`

---

## 答案

**正确答案：** C

---

## 解析

每次把字典查到的字符添加到已有字符串左侧，依次形成 `y`、`ny`、`ony`、`tony`。
