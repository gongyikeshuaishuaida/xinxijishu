# 题目 15

阅读下列材料，回答第 15 题：

某实验室搭建了室内环境监测系统，每日监测数据记录在字符串 `record` 中，其中“0”表示异常、“1”表示正常。

实现查找最长连续正常天数的 Python 程序如下：

```python
record = "011100110101011111000111111111"
mlen = 0
__________  # ①
for i in range(len(record)):
    if __________:  # ②
        cnt += 1
        if cnt > mlen:
            mlen = cnt
    else:
        cnt = 0
print("连续正常最多的天数是", mlen, "天")
```

上述程序段中划线处可选填代码有：

- ① `cnt = 0`
- ② `cnt = 1`
- ③ `record[i] == "0"`
- ④ `record[i] == "1"`

则（1）（2）处语句依次为（   ）

- A. ①③
- B. ②④
- C. ②③
- D. ①④

---

## 答案

**正确答案：** D

---

## 解析

计数变量 `cnt` 在扫描开始前必须初始化为 0，填 ①；正常数据用字符 `"1"` 表示，判断条件应为 `record[i] == "1"`，填 ④。遇到“0”时程序进入 `else` 把当前连续计数清零，因此顺序为 ①④，选 D。
