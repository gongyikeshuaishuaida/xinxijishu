# 题目 13

使用 Python 求两个单词的最长连续公共子串。如果有多个同样长的公共子串，则输出第一串中的第一个。运行示例如下：

（1）输入 `thought` 和 `thigh`，输出的最长连续公共子串为______。

（2）补全程序：

## 答案

**正确答案：** （1）`th`；（2）① `c+=1`；② `c-1`；③ `maxstr=s1[i:i+maxlen]`

---

## 解析

从两个起点字符相同的位置开始向右逐个比较，`c` 记录已经匹配的长度；退出时最后一次不匹配不计入，因此返回 `c-1`，主程序再加上起始字符。发现更长结果时，用切片保存对应子串。
