# 题目 15

15.某歌手投票系统从 `tp.txt` 读取“选手编号-投票人编号”记录，并统计每位歌手的有效票数。

![[attachments/202406-杭州周边-高一-期末-15_横排1_2.png]]

（1）投票人 414 已经投给歌手 2 和歌手 7，若他还投给歌手 8，对歌手 8 的票数 ______①______（有/无）影响。

（2）补充读取函数：

```python
def read_f():
    a=[]
    f=open("tp.txt","r")
    line=f.readline()
    while line:
        s=line.strip("\n").split("-")
        a.append(s)
        line=f.readline()
    ______②______
```

（3）同一投票人再次投票时，撤销其上一张有效票：

```python
flag=[-1]*1000
for i in lst:
    v_num=int(i[1])
    if flag[v_num]==-1:
        flag[v_num]=i[0]
        xs[int(i[0])][1]+=1
    elif flag[v_num]!=0:
        ______③______
        flag[v_num]=0
```

统计最高票数时，若要在首次找到最高票时记录下标，应将条件中的 `<` 改为 `>`，并补充：

```python
if s_pos==-1 or xs[i][1]>maxnum:
    maxnum=xs[i][1]
    ______④______
```

---

## 答案

**正确答案：** ①无；②`return a`；③`xs[flag[v_num]][1]-=1`；④`s_pos=i`；条件应为 `s_pos==-1 or xs[i][1]>maxnum`

---

## 解析

投票人 414 的重复投票会使其前一张有效票失效，歌手 8 不会因此增加有效票，所以第①空为“无”。读取文件后返回记录列表；发现重复投票时要把原歌手票数减 1 并将该投票人标记为无效。最高票统计应使用大于号，更新最大值时保存当前下标。
