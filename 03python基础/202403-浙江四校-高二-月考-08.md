# 题目 08

用 Python 语句描述城市主干道中机动车平均行驶速度：“不低于 30 为畅通，小于 20 为堵塞，其余为拥挤”。设 `v` 为机动车平均行驶速度（km/h），下列选项正确的是（   ）

![[attachments/202403浙江四校_08_条件选项.jpg]]

- A. 条件分支把 `20 <= v < 30` 也输出为堵塞
- B. 条件分支把 `v < 20` 输出为堵塞、`v > 20` 输出为拥挤，并把其余输出为畅通
- C. 条件分支的范围判断互相矛盾
- D. 先判断 `v >= 20`，再在其中判断 `v < 30` 输出拥挤，否则输出畅通；`v < 20` 输出堵塞

## 答案

**正确答案：** D

## 解析

速度小于 20 应输出“堵塞”；20≤v<30 输出“拥挤”；v≥30 输出“畅通”。D 的嵌套判断完整覆盖三段且边界正确。
