# 题目 12

12. 有如下 Python 程序，程序执行，输入 `s` 之后输出的结果正确的是（   ）

```python
lst = ["8", "5", "9", "14", "10", "8", "11", "9", "10"]
s = input("请输入 s 的值:")
j = 0
for i in range(8):
    if lst[i] <= s:
        lst[j] = lst[i]
        j = j + 1
print(lst[:j])
```

- A. `s='10'`　输出：`['10']`
- B. `s='9'`　输出：`['8', '5', '9', '8', '9']`
- C. `s='5'`　输出：`['5']`
- D. `s='14'`　输出：`['14', '10', '11', '10']`

---

## 答案

**正确答案：** A

---

## 解析

程序只遍历列表下标 0～7，并按字符串字典序筛选出不大于 `s` 的元素。输入 `s='10'` 时，前 8 个元素中只有 `'10'` 满足条件，输出 `['10']`，所以 A 正确。其他选项的字符串比较结果或遍历范围均不符合程序实际执行过程。
