# 题目 09

小明计算出正确 BMI 值后，编写代码根据 BMI 值判断体重是否标准，选项中正确的是（   ）

- A.

  ~~~python
  s="偏瘦"
  if BMI>25:
      s="超重"
  elif BMI<=25:
      s="标准"
  ~~~

- B.

  ~~~python
  s="标准"
  if BMI>25:
      s="超重"
  elif BMI<18.5:
      s="偏瘦"
  ~~~

- C.

  ~~~python
  if 18.5<=BMI<=25:
      s="标准"
  if BMI>25:
      s="超重"
  else:
      s="偏瘦"
  ~~~

- D.

  ~~~python
  if BMI>25:
      s="超重"
  if 18.5<=BMI<=25:
      s="标准"
  else:
      s="偏瘦"
  ~~~

## 答案

**正确答案：** B

## 解析

BMI 大于 25 时为超重，小于 18.5 时为偏瘦，介于 18.5 和 25（含边界）之间为标准。B 先处理超重，再用 `elif` 处理偏瘦，初始值“标准”正好覆盖剩余区间。A 会把偏瘦也判为标准，C、D 的 `else` 分别只与第二个 `if` 配对，逻辑不完整。
