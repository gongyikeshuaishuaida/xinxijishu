# 题目 10

有如下程序段：

```python
s = "a123b456"
t = ""
f = True
for i in s:
    if "0" <= i <= "9" and f:
        t += i
        f = False
    else:
        f = True
print(t)
```

运行程序，输出结果是（   ）

- A. 123456
- B. 1346
- C. 123
- D. 14

## 答案

**正确答案：** B

## 解析

`f` 初值为真，每遇到一个数字且 `f` 为真就追加该数字，随后把 `f` 置为假；遇到非数字或连续数字的第二个字符时恢复为真。因此提取 1、3、4、6，输出 1346。
