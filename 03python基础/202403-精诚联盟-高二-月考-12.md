# 题目 12

通过键盘输入一些单词，程序输出这些单词的最长公共前缀。例如，当输入“flower, flow, flight”时，将输出“fl”。实现上述功能的程序段如下，方框中应填入的代码段可行的是（   ）

程序如下，请在方框处填入合适的代码：

```python
def commonPrefix(strs):
    length = len(strs[0])
    count = len(strs)
    prefix = ""
    for i in range(______①______):
        cur = strs[0][i]
        for j in range(1, count):
            if ______②______:
                return prefix
        prefix += cur
    return prefix

strs = input().split(',')
print(commonPrefix(strs))
```

- A. ① `0, length`；② `i >= len(strs[j]) or strs[j][i] != cur`
- B. ① `0, length`；② `i >= len(strs[j]) and strs[j][i] != cur`
- C. ① `1, length`；② `i >= len(strs[j]) or strs[j][i] == cur`
- D. ① `1, length`；② `i >= len(strs[j]) and strs[j][i] != cur`

## 答案

**正确答案：** A

## 解析

索引应从 0 遍历到首个单词长度，且只要任一单词长度不足或当前位置字符不同，就应立即返回当前前缀，因此两个判断条件之间使用“或”。
