# 题目 12

有如下 Python 程序段：

```python
# 获取 s 的初始值，代码略
k = 5
i = 0
j = 1
t = len(s) - k
while j < len(s):
    if s[i] < s[j] and t > 0:
        t -= 1
    else:
        i += 1
    s[i] = s[j]
    j += 1
print(s[:k])
```

执行该程序段后，s 的值为 `[9,8,5,7,4]`，则 s 的初始值不可能是（   ）

- A. `[2,9,6,8,5,7,3,4]`

- B. `[2,9,6,8,5,7,4]`

- C. `[9,8,2,3,4,5,7,4]`

- D. `[2,3,9,6,8,5,7,4]`

---

## 答案

**正确答案：** A

---

## 解析

依次执行四组数据，输出分别为 [9,8,7,3,4]、[9,8,5,7,4]、[9,8,5,7,4]、[9,8,5,7,4]，因此选 A。原题“s 的值”按末尾 print(s[:k]) 的输出理解，完整列表 s 的长度不会变为 5。
