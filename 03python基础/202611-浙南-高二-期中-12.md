# 题目 12

有如下 Python 程序段：

```python
import random
lst = [0] * 6
for k in range(6):
    num = random.randint(1, 10)
    if k % 2 == num % 2:
        lst[k] = num
    elif k % 2 == 1:
        lst[k] = lst[k-1] + num
```

执行该程序段后，lst 列表的值不可能为（   ）

- A. `[8,5,4,7,4,9]`

- B. `[0,7,0,4,4,3]`

- C. `[2,6,4,11,10,9]`

- D. `[8,16,2,4,4,7]`

---

## 答案

**正确答案：** C

---

## 解析

偶数下标只能是 0 或 1～10 内的偶数；奇数下标若直接取数为奇数，否则等于前一元素加 2～10 的偶数。C 中最后一项 9 无法接在 10 后产生。
