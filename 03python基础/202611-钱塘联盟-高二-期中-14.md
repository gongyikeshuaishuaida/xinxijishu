# 题目 14

校园自动售货机的商品编号为 1～20。售货机每日会生成一条销售记录，记录由若干商品编号构成，相邻编号以逗号分隔，整条记录以逗号结尾。例如销售记录字符串"3,7,11,"，代表商品 3、商品 7、商品 11 各售出 1 件。

小明编写 Python 程序用于统计售货机销售数据：输入一条销售记录字符串，统计各商品的销售次数，找出销售量最高的商品编号；若有多个商品的销售次数同为最大值，则选取其中编号最大的商品，如第 14 题图所示。请回答下列问题。

![[attachments/202611钱塘联盟高二_14_图1.png]]

（1）若某天的销售记录为 "11,6,11,6,11,13,6,13,13,11,6,13,"，则销量最高的商品编号为

（2）实现上述功能的 Python 程序如下，请在划线处填入合适代码：

```python
s = input("请输入销售记录：")    # 如 "3,7,11,"
a = [0] * 21
num = 0
for ch in s:
    if ch == ",":
        ______①______
        num = 0
    else:
        num = ______②______
mx = 0
for i in range(1,21):
    if ______③______:
        mx = i
print("销售次数最多的商品编号是", mx)
```

---

## 答案

（1）13。

（2）① `a[num]+=1`，② `num*10+int(ch)`，③ `a[i]>=a[mx]`。

---

## 解析

每遇逗号就结束一个编号并增加对应计数。第二问的记录中 6、11、13 均出现 4 次，取编号最大的 13。
