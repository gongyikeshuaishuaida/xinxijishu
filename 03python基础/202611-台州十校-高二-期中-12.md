# 题目 12

执行下面 Python 程序，程序输出结果是（   ）

```python
s = 0, i = 1
while i <= 8:
    i = i + 2
    if i % 3 != 0:
        s = s + i
print(s)
```

- A. 12

- B. 16

- C. 20

- D. 24

---

## 答案

**正确答案：** A（按初始化意图修正后）

---

## 解析

原卷初始化行是 `s = 0, i = 1`，在Python中存在语法错误，原样不能运行；参考答案按 `s = 0; i = 1` 理解。修正后i依次为3、5、7、9，只累加5和7，输出12，选A。
