# 题目 14

影片推荐度由5位专业评审和5位大众评审评分，专业评审均分占60%，大众评审均分占40%，加权和取整后按下表确定星级；评委数据文件格式如下：

![[attachments/202401-湖州-高二-期末-14_横排1_2.png]]

（1）若专业评审均分为5，大众评审均分为6，则影片等级为 ______①______ 颗星。

（2）补全程序。

```python
f=open("dc.txt",encoding="utf-8")
line=f.readline()
pro,pub=0,0
while line:
    x=______②______
    t=int(line[3:])
    if x=="A":
        pro+=t
    elif x=="B":
        ______③______
    line=f.readline()
score=int(pro/5*0.6+pub/5*0.4)
grade=______④______
print("推荐度为:","★"*grade)
```

（3）若文件中无异常数据，写出与加框处代码功能相同的一条语句。

---

## 答案

**正确答案：** （1）3；（2）② `x=line[0]`；③ `pub+=t`；④ `(score+1)//2`；（3）`else`

---

## 解析

（1）加权推荐度为 `5×0.6+6×0.4=5.4`，取整得5分；5—6分对应3颗星。

（2）每行前三个字符中的首字符表示评审类型，故取 `line[0]`；大众评审分数累加到 `pub`；1—2分为1星、3—4分为2星、5—6分为3星……，可用 `(score+1)//2` 计算星级。

（3）当输入既不是A也不是B时，文件中无异常数据意味着只需处理B分支后继续读下一行；与加框处等价的语句为 `else`。
