# 题目 13

小明编写 Python 程序，实现不同进制的加法运算。加数可以是二进制数（B）、十进制数（D）、十六进制数（H）。如输入算式“1101B+2AH=”，则输出结果为“和为：55”。

（1）输入算式“1011B+3DH=”，则输出结果为 ______①______。

（2）Python代码如下，请在划线处填入合适代码，完善功能。

~~~python
s=input("请输入算式;")
def convert(ch):
    result=0
    dic={"B":2,"D":10,"H":16}
    jz=______①______
    for i in range(len(ch)-1):
        if "A"<=ch[i]<="F":
            result=result*jz+______②______
        else:
            result=result*jz+int(ch[i])
    return result

temp=""
sum=0
for i in range(len(s)):
    if s[i]=="+" or s[i]=="=":
        sum=sum+convert(temp)
        ______③______
    else:
        temp=temp+s[i]
print("和为:",sum)
~~~

---

## 答案

（1）① 和为：72

（2）① dic[ch[-1]]　② ord(ch[i])-55　③ temp=""

---

## 解析

1011B=11，3DH=61，两数之和为72。转换函数的进制由加数末尾字母确定；十六进制字母 A—F 转为10—15时使用 ord(ch[i])-55；每次遇到加号或等号完成一项转换后要清空 temp。
