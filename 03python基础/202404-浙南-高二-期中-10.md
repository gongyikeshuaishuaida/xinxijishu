# 题目 10

10.有如下 Python 程序：

```python
import random
a = [0] * 6
i = 0
while i < 6:
    a[i] = random.randint(1, 10)
    if a[i] in a[0:i]:
        i -= 1
    i += 1
for i in range(6):
    if i % 2 == 0 and a[i] > a[i + 1]:
        a[i], a[i + 1] = a[i + 1], a[i]
    else:
        a[i] += a[i] % 2
print(a)
```

执行程序后，数组 `a` 中不可能的结果为（ ）

A.`[4, 6, 4, 8, 7, 10]`　B.`[3, 11, 6, 8, 1, 4]`　C.`[1, 4, 4, 8, 6, 8]`　D.`[4, 8, 2, 4, 6, 8]`

---

## 答案

**正确答案：** B

---

## 解析

随机数由 `randint(1,10)` 产生，任何元素都不可能为11；因此 B 不可能。前面的重复检测和后续交换、奇偶调整可以产生其他三个结果。
