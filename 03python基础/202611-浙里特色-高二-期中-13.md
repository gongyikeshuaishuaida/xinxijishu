# 题目 13

快递站点给包裹分配 8 位二进制编码，最高位是奇校验位，用于检验传输是否出错。编码规则：包裹编号是范围 1～127 的正整数，先写出包裹编号的 7 位二进制，在最前面添加奇校验位，保证整个 8 位二进制里“1”的总个数为奇数。

- 低 7 位中 1 的个数为奇数：校验位填 0。
- 低 7 位中 1 的个数为偶数：校验位填 1。

例如：编号 5 的低 7 位二进制是 0000101，添加上校验位后完整的 8 位编码为 10000101.

（1）发送方编码

请计算编号 10 的 8 位二进制编码：______。

（2）接收方解码

接收方在收到 8 位二进制串后进行校验：若其中“1”的总个数不是奇数，返回“无效包裹”；若校验无误，则将低 7 位转回十进制编号。补全解码函数 decode 划线处代码。

```python
def decode(s):
    st = s[1:]    # st取出低7位二进制串
    res = cnt = 0
    for x in st:
        res = ______①______    # 二进制字符串转十进制
        if x == "1":
            cnt += 1
    if ______②______:
        return "无效包裹"
    else:
        return res
```

（3）主程序批量分割解码接收方收到的二进制串由多个包裹的 8 位编码拼接而成，按每 8 位一组解码。

示例：输入 0000101110001100，分割成“00001011”、“10001100”，解码后得到包裹编号列表[11，12]，在以下主程序的划线处填入合适代码。

```python
packnum = []
receive = input("请输入收到的二进制串：")
for i in range(0,len(receive),8):
    packnum.append(______)
print("包裹编号序列：",packnum)
```

---

## 答案

（1）10001010。

（2）① `res*2+int(x)`，② `(cnt+int(s[0]))%2==0`。

（3）`decode(receive[i:i+8])`。

---

## 解析

10 的低 7 位为 0001010，已有两个 1，所以最高位填 1。按位累积时左移一位相当于乘 2，最后应把校验位也计入 1 的个数。每 8 个字符切出一个编码。
