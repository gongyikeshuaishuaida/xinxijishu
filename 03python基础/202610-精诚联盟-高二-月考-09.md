# 题目 09

有如下程序段，目的是为了使输出的`z`值有0,1,2三种情况，但该程序段中存在问题，输入下列哪个选项的数据能测试出其中的问题

```python
n = int(input())
if n <= 20:
    z = 0
if n <= 50:
    z = 1
else:
    z = 2
print(z)
```

（   ）

- A. 20
- B. 40
- C. 50
- D. 60

---

## 答案

**正确答案：** A

---

## 解析

输入20时第一个if使z=0，第二个if又使z=1，暴露覆盖赋值错误。要实现互斥分段，应将第二个if改成elif。其他三个输入分别输出1、1、2，不能发现该问题。
