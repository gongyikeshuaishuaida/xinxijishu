# 题目 05

一段信息被采集到计算机中，形成的文件图标如下图所示。下列关于这个文件的说法正确的是（   ）

![[attachments/202411温州新力量_05_音频文件图标.png]]

- A. 原信息在采集后经过数模转换，存储在计算机中
- B. 采样指的是将原来离散的信号转换为连续的信号
- C. 打开并播放该文件的内容，会经历信息解码的过程
- D. 与该文件媒体类型相同的文件格式还有 wav、mp4 等

## 答案

**正确答案：** C

## 解析

`record.mp3` 是音频文件，播放压缩音频时需要进行解码。模拟信息采集到计算机通常经历模数转换；采样是将连续信号离散化；MP4 主要是多媒体封装格式，不能据此与 MP3 视为相同的音频格式，因此 C 正确。
