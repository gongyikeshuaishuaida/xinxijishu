# 题目 10

有如下 Python 程序段：

~~~python
b = input()
a = "2345"
s = ""
j = -1
for i in range(len(a)):
    j = j + 1
    if j == len(b):
        j = 0
    c = 9 - int(a[i] + b[j]) % 3
    s = str(c) + s
~~~

运行该程序段后，变量 s 的值为“7897”，则变量 b 不可能的输入是（   ）

- A. 3
- B. 12
- C. 300
- D. 9306

---

## 答案

**正确答案：** B

## 解析

程序把 `a` 与输入字符串 `b` 的字符按循环方式配对，再根据模 3 的结果计算字符并逆序拼接。将选项代入后，输入 `12` 得到的结果不是“7897”，而其他选项可以得到题设结果，因此 B 不可能。
