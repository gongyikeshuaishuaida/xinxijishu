# 题目 11

某 Python 程序段如下：

```python
book = {"title": "Python 入门", "author": "Wang", "sales": [120, 350, 210]}
print(book["title"][:6]+str(book["sales"][1]))
```

程序运行后，输出的结果是（   ）

- A. Python 入门350
- B. Python350
- C. Python120
- D. Python210

---

## 答案

**正确答案：** B

---

## 解析

标题切片取前 6 个字符 Python，列表下标 1 取 350，转成字符串后连接。
