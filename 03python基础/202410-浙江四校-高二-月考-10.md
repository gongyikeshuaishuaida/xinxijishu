# 题目 10

有如下 Python 程序段：

```python
s = "5A9C3B0E7D"
ans = ""
i = 0
while s[i] != "0":
    t = int(s[i])
    ans = ans + s[t]
    i = t - 1
```

运行后，变量 `ans` 的值是（   ）

- A. `BCDEA`
- B. `BCD`
- C. `ABCD`
- D. `BCDE`

---

## 答案

**正确答案：** D

---

## 解析

索引依次为 0、4、2、8、6，对应数字 5、3、9、7、0；前四次分别取 `s[5]、s[3]、s[9]、s[7]`，得到 `BCDE`，遇到 0 后结束。
