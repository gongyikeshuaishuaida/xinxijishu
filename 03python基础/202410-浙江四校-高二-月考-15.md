# 题目 15

“数据山峰”是序列中一段先上升后下降的连续区域。例如字符串 `5136432783` 中有 `136432` 和 `783` 两座山峰。补全输出所有数据山峰的程序：

```python
s = input("请输入数字序列：")
i = 0
j = 1
f = 0
while j < len(s):
    if f == 0 and s[j - 1] < s[j]:
        f = 1
        ______①______
    elif f == 1 and s[j - 1] > s[j]:
        f = 2
    elif f == 2 and s[j - 1] <= s[j]:
        print(s[i:j])
        f = 0
    elif s[j - 1] == s[j] or f == 0 and s[j - 1] > s[j]:
        f = 0
    ______②______
if ______③______:
    print(s[i:j])
```

（2）变量 `f=2` 表示当前数字序列______。

（3）输入 `51366432783` 时，输出的数据山峰为______（多个山峰用逗号间隔）。

---

## 答案

**正确答案：** （1）① `i=j-1`；② `j+=1`；③ `f==2`；（2）从上升状态进入下降状态；（3）`2783`

---

## 解析

发现首次上升时记录山峰起点 `j-1`；每轮把 `j` 后移。状态 2 表示已经由上升转为下降。输入序列中的重复 6 会中断前一候选区域，最后只有 `2783` 构成完整山峰。
