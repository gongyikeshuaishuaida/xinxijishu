# 题目 10

某网约车计费方法：起步价 8 元（3 公里及以内），超出 3 公里但不超出 10 公里的部分按 2 元/公里计费，超出 10 公里的部分按 3 元/公里计费。下列程序段，输入行驶里程 s 后不能正确计算出费用 pay 的是（   ）

- A.

  ~~~python
  if s<=3:
      pay=8
  if s<=10:
      pay=8+(s-3)*2
  else:
      pay=22+(s-10)*3
  ~~~

- B.

  ~~~python
  if s<=3:
      pay=8
  if 3<s<=10:
      pay=8+(s-3)*2
  if s>10:
      pay=22+(s-10)*3
  ~~~

- C.

  ~~~python
  pay=8
  if s>3:
      if s>10:
          pay=22+(s-10)*3
      else:
          pay=8+(s-3)*2
  ~~~

- D.

  ~~~python
  pay=8
  if s>10:
      pay=22+(s-10)*3
  elif s>3:
      pay=8+(s-3)*2
  ~~~

---

## 答案

**正确答案：** A

---

## 解析

A 中两个 if 相互独立。当 s<=3 时，第二个 if 仍成立，会把 pay 改为 8+(s-3)*2，导致费用错误。B、C、D 均能覆盖 3 公里以内、3 到 10 公里以及超过 10 公里的情况。
