# 题目 09

有如下 Python 程序段：

~~~python
s=input()
st=""
for i in s:
    if "0"<=i<="9":
        st=st+i
    elif "a"<=i<="z":
        st=i+st
~~~

执行该程序段，输入 "01yaYUn"，则 st 的值是（   ）

- A. "nUYay10"
- B. "nUYay01"
- C. "nay01YU"
- D. "nay01"

---

## 答案

**正确答案：** D

---

## 解析

数字按原顺序追加，所以先得到 "01"；小写字母按遍历顺序插入字符串首部：y 得到 "y01"，a 得到 "ay01"，n 得到 "nay01"。大写字母 Y、U 不满足任一条件，最终为 "nay01"，选D。
