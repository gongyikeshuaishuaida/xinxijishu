# 题目 10

有如下 Python 程序段：

```python
s = "abaabcaab"
st = s[0]
i = 1
while i < len(s):
    if len(st) == 0 or s[i] != st[-1]:
        st = s[i] + st
    else:
        st = st[0:len(st)-1]
    i += 1
```

执行该段代码后，`st` 的值为（  ）

A．`bca`

B．`acb`

C．`bac`

D．`cab`

## 答案

**正确答案：** C

## 解析

逐字符模拟：遇到与栈顶不同的字符就前置，遇到相同字符就删除栈顶，处理完 `abaabcaab` 后得到 `st="bac"`。
