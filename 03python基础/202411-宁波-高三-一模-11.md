# 题目 11

若字符串 a 的值为 “takeiteasy”，执行如下程序段后，变量 res 的值是（   ）

~~~python
res = [''] * 5
head = 0
tail = 0
a = 'takeiteasy'
for i in range(len(a)):
    if tail - head == 0 or a[i] > res[tail - 1]:
        res[tail] = a[i]
        tail += 1
    elif tail - head == 1:
        res[head] = a[i]
    elif tail - head > 1 and a[i] > res[tail - 2]:
        res[tail - 1] = a[i]
~~~

- A. ['t', 'y', '', '', '']
- B. ['a', 'e', 's', 'y', '']
- C. ['a', 'e', 'i', 's', 'y']
- D. ['a', 's', 'y', '', '']

---

## 答案

**正确答案：** C

---

## 解析

按程序逐字符模拟，head 和 tail 维护当前有效区间，较小字符会替换前端或倒数第二个位置，最终有效的五个字符依次为 a、e、i、s、y。
