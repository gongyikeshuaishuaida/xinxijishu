# 题目 16

为响应“双碳”目标，鼓励市民优先选择共享单车出行，某平台推出“绿行能量折扣券”福利活动。平台按日统计每位用户的骑行累计实付金额，并在当日消费结算后根据该金额赠送不同数量的“8 折骑行折扣券”。折扣券自领取后的下一日起 7 天内有效，超时自动失效。

发券、用券规则如下：

- 金额 ≥ 6.0 元（类型 0）：赠送 2 张全场 8 折券；
- 3.0 元 ≤ 金额 < 6.0 元（类型 1）：赠送 1 张全场 8 折券；
- 金额 < 3.0 元（类型 2）：不赠送；
- 下单时，卡包内若存在有效 8 折券，系统自动使用；有多张有效券时，优先使用最早领取的有效优惠券；优惠券一经使用立即失效。

## 答案

**正确答案：** （1）23；（2）① `date // 10000`；② 否；（3）① `cou.append(mon(a[0]))`；② `i += 1`；③ `money += data[k][1] * 0.8`

---

## 解析

第 3 笔消费后的实付金额为 12.2 元。第 4 笔 8.5 元使用 8 折券后支付 6.8 元；到第 5 笔消费时，先前获得的优惠券均已过期，因此第 5 笔按原价支付 4 元，累计为 23 元。日期整数的年份取 `date // 10000`；`date % 100 // 10` 不能得到月份，所以两者功能不同。类型 0 要赠送两张同日到期的券，已有一张追加一张；过期券通过 `i += 1` 跳过；有有效券时支付金额乘 0.8 并让指针前移。
