# 题目 08

管理员设定夏季阅览室的适宜温度 `t` 为18到23摄氏度（包含18和23）。用变量 `sta` 表示当前室温状态，0表示适宜，-1表示偏低，1表示偏高，下列选项符合设置要求的是（   ）

- A. ```python
if t < 18:
    sta = -1
    if t > 23:
        sta = 1
else:
    sta = 0
```


- B. ```python
sta = 0
if t > 23:
    sta = 1
elif t < 18:
    sta = -1
```


- C. ```python
if t >= 18:
    sta = 0
elif t > 23:
    sta = 1
else:
    sta = -1
```


- D. ```python
if t < 18:
    sta = -1
if t <= 23:
    sta = 0
if t > 23:
    sta = 1
```

---

## 答案

**正确答案：** B

---

## 解析

先默认适宜，再对高于23或低于18分别改写状态。A和C不能把高温设为1；D会把低温状态覆盖成0。
