# 题目 10

有如下 Python 程序段：

```python
import random
s = ""
p = [0, 1, 2, 3]
random.shuffle(p)  # 将序列 p 中所有元素随机排序
for i in p:
    s += chr(65 + i)
```

运行该程序段后，变量 `s` 的值可能的是（  ）

A．`"acbd"`

B．`"aabc"`

C．`"ABCB"`

D．`"ADBC"`

## 答案

**正确答案：** D

## 解析

`chr(65+i)` 将 0、1、2、3 分别转换为大写字母 A、B、C、D，随机排列后每个字母恰好出现一次；只有 D 符合。
