# 题目 15

某校开设了9门选修课，学生从中选择3门课程，课程名称用数字1～9表示（1～9依次为排球、篮球、足球、羽毛球、乒乓球、网球、健身操、游泳、太极），最终每个学生只安排2门课程学习。为了统计每门课程的选课人数及同选最多的两门课程，程序从文本文件读取选课信息。

“同选”是指学生在3门课的选择中最喜欢一起选的两门课，例如A同学选了124、B同学选了134，则同选的两门课为14。

![[attachments/202404台州六校_15_运行结果图.jpg]]

（1）图15-1中同选次数最多的课程编号是 ______①______。

（2）请在划线处填空：

```python
course = ["排球", "篮球", "足球", "羽毛球", "乒乓球", "网球", "健身操", "游泳", "太极"]
xk = []
f = [0] * 9
d = [0] * 81

def relation(c):
    for i in range(1, 10):
        for j in range(______②______):
            if str(i) in c and str(j) in c:
                d[10 * i + j] += 1
    return d

file = open("xk.txt", "r")
for line in file:
    k = line.split()
    xk.append(k)
for x in xk:
    relation(x)
    for y in x:
        ______③______
for i in range(9):
    print(course[i], "选课人数：", f[i], "人")
print("同选最多的两门课程是：")
for k in range(81):
    if d[k] == max(d):
        print(course[k // 10 - 1], ______④______)
```

---

## 答案

**正确答案：** ① 6和7；② `i + 1, 10`；③ `f[int(y - 1)] += 1`；④ `course[k % 10 - 1]`

---

## 解析

同选次数最多的是编号6和7。内层循环只需从当前课程编号之后遍历到9，避免重复统计；每读到一个课程编号就给对应的 `f` 元素加1，`k//10` 和 `k%10` 分别取出同选的两个课程编号。
