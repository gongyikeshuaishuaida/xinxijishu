# 题目 11

有如下 Python 程序段：

~~~python
s=2; i=10
if i%2==0 or i%5==0:
    s=s+1
if i%3==1:
    s=s+2
else:
    s=s+1
print(s)
~~~

其输出结果为（   ）

- A. 2
- B. 3
- C. 4
- D. 5

## 答案

**正确答案：** D

## 解析

`i=10` 同时满足 `i%2==0`，第一次判断后 `s` 由 2 变为 3；`10%3==1`，第二个判断成立，再加 2，最终 `s=5`。
