# 题目 12

某网络平台要求密码长度为 8—14 个字符，必须包含字母、数字和特殊符号 !@#$%&?。保存时：英文字符的 ASCII 码转为十六进制并头尾互换；数字字符循环后移 2 位（如 3→1、2→0、1→9），其他字符不变。

（1）定义 judge(x) 判断密码设置是否正确，请补全：

    def judge(x):
        p = "!@#$%&?"
        c1 = c2 = c3 = 0
        for i in range(len(x)):
            if "a" <= x[i] <= "z" or "A" <= x[i] <= "Z":
                c1 = 1
            elif "0" <= x[i] <= "9":
                c2 = 1
            elif x[i] in p:
                c3 = 1
        if ______①______:
            return True
        else:
            return False

（2）定义 dh(d)，将 ASCII 码值转换成十六进制并头尾互换，请补全：

    def dh(d):
        hs = "0123456789ABCDEF"
        h1 = hs[d//16]
        h2 = hs[d%16]
        return ______②______

（3）主程序如下，请补全：

    m = input("请输入密码：")
    mw = ""
    if ______③______:
        print("密码不符合要求")
    else:
        for i in range(len(m)):
            s = ""
            if "a" <= m[i] <= "z" or "A" <= m[i] <= "Z":
                s = dh(ord(m[i]))
            elif "0" <= m[i] <= "9":
                s = ______④______
            else:
                s = m[i]
            mw += s
        print("密码的密文是：", mw)

---

## 答案

**正确答案：** （1）c1+c2+c3==3（或 c1==1 and c2==1 and c3==1）；（2）h2+h1；（3）judge(m)==False（或 not judge(m)）；（4）str((int(m[i])-2)%10）。

---

## 解析

密码必须同时含有字母、数字和规定的特殊符号，因此三个标志量都为 1 即通过。十六进制的高位和低位分别为 h1、h2，头尾互换后为 h2+h1。主程序在判断不通过时提示错误；数字字符按循环规律减 2 位，可写为 str((int(m[i])-2)%10)。
