# 题目 12

有如下 Python 程序段：

~~~python
from random import randint
s='0123456'
k=randint(1,3)
n=k
while n>0:
    k=(k+3)%len(s)
    s=s[:k]+s[k+1:]
    n=n-1
print(s)
~~~

执行该程序段后，输出的结果不可能是（   ）

- A. `012356`
- B. `01346`
- C. `02356`
- D. `0245`

## 答案

**正确答案：** C

## 解析

初始 `k` 只能为 1、2、3。分别跟踪删除位置，可得到 A、B、D 三种结果；当初始 `k=2` 时得到 `01346`，不会得到 `02356`，因此 C 不可能。
