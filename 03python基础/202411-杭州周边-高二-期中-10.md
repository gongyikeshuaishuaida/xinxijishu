# 题目 10

10. 有如下 Python 程序段：

```python
s = "zangh8769"
res = ""
for ch in s:
    if '0' <= ch <= '9':
        k = int(ch) % 5
        res = s[k] + res
```

执行该程序段后，变量 `res` 的值是（   ）

- A. `gnah`
- B. `gzan`
- C. `nazg`
- D. `hang`

---

## 答案

**正确答案：** D

---

## 解析

字符串中的数字依次为 8、7、6、9，对应下标 `3、2、1、4`。取出的字符依次为 `g、n、a、h`，每次放到 `res` 的左侧，最终得到 `hang`。
