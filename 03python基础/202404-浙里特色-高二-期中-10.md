# 题目 10

10.有如下 Python 程序段：

```python
s = input("请输入待处理字符串：")
st = ""
for i in range(len(s)):
    ch = s[i]
    if "0" <= ch <= "9":
        ch = str((int(ch) + 3) % 10)
        st = st + ch
    else:
        if "A" <= ch <= "Z":
            ch = ch.lower()
        st = st + ch
print(st)
```

输入字符串 `Happy2024!`，输出的结果为（ ）

A.`7535happy!`　B.`4202Happy!`　C.`!7535yppah`　D.`happy5357!`

---

## 答案

**正确答案：** D

---

## 解析

字母 `Happy` 转为小写 `happy`；数字分别加 3 后按 10 取模，`2024` 变为 `5357`；感叹号保持不变，因此输出 `happy5357!`。
