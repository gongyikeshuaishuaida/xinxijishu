# 题目 11

有如下 Python 程序段：

```python
a = [2,2,3,-8,4,-2,5,9]
s, ans, n = 0, 0, 0
for i in range(0, len(a)):
    s = s + a[i]
    if s >= 0:
        n += 1
    else:
        s = 0
        n = 0
    if s > ans:
        ans = s
print(ans, n)
```

执行该程序段后，输出的结果是（   ）

- A. 14 2

- B. 14 4

- C. 15 8

- D. 16 4

---

## 答案

**正确答案：** D

---

## 解析

当前累计和一旦小于 0 就清零并重新计数；末段 4、-2、5、9 和为 16，长度为 4，输出 16 4。
