# 题目 12

有如下 Python 程序段：

```python
if x>188:
    y=x*0.5
else:
    y=x*0.8
```

下列选项中，与上述程序段功能相同的是（   ）

- A.

  ```python
  if x>188:
      y=x*0.5
  y=x*0.8
  ```

- B.

  ```python
  if x<188:
      y=x*0.8
  else:
      x=x*0.5
  ```

- C.

  ```python
  y=x*0.8
  if x>188:
      y=x*0.5
  ```

- D.

  ```python
  if x>188:
      y=x*0.5
  if x<188:
      y=x*0.8
  ```

---

## 答案

**正确答案：** C

---

## 解析

先将 `y` 设为 `x*0.8`，再在 `x>188` 时改为 `x*0.5`，与原程序在两种分支下的结果一致。D 在 `x=188` 时不会给 `y` 赋值，B 还错误地修改了 `x`，A 会在条件成立时被后一句覆盖。
