# 题目 15

有 `n` 个小组（编号 1 至 `n`），每个小组有 `m` 个成员，每个成员都有一个 0 到 20 之间的整数得分。若小组成员中得分最高的前 `k` 人得分都不低于 `s1`，且得分最低的前 `k` 人得分都不超过 `s2`，则该小组的平衡值为 `s1-s2`。

（1）若取 `k=2`，小组成员得分依次为“5，2，7，11，8，6，5，1”，此时第一小组的平衡值是 ______。

（2）请在划线处填入合适的代码。

```python
n = 6; m = 8; k = 3
a = [0] * (n * m)
ans = [0] * n
# 读取 n 个小组每个成员的得分，按组别从小到大依次存入数组 a，代码略

def balance(w):  # 计算第 w 小组的平衡值

        c[t] += 1
    s1 = 20; t = k
    while t > 0:
        if c[s1] > 0:

            t -= 1

            ______③______

maxg = -1

for i in range(p + 1):
    print("平衡值最大的小组编号为：" + str(ans[i]) + ", 平衡值为:" + str(maxg))
```

## 答案

**正确答案：** （1）6；（2）① `t = a[i]`；② `c[s1] -= 1`；③ `s1 -= 1`；④ `g = balance(i)`。

## 解析

当 `k=2` 时，最高两项为 11、8，最低两项为 1、2，平衡值为 `8-2=6`。程序先将每个小组的分数按分值计数；从 20 向下寻找前 `k` 个最高分，遇到一个就减少计数，否则继续降低分值；主循环调用 `balance(i)` 并维护最大值及并列小组编号。
