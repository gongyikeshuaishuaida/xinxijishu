# 题目 11

已知字符串 s 由数字字符 1、3、5、7、9 各一个组成（即 s 是 1、3、5、7、9 的一个排列）。对字符串 s 执行如下变换：

```python
from random import randint
s="13579"
res=""
i,j=0,len(s)-1
while i<=j:
    if randint(0,1)==1:
        res+=s[i]; i+=1
    else:
        res+=s[j]; j-=1
```

变量 res 的值不可能是（   ）

- A. "13597"
- B. "19753"
- C. "19573"
- D. "97531"

---

## 答案

**正确答案：** C

---

## 解析

先从左侧取 1，再从右侧取 9，剩余序列是 3、5、7。5 位于内部，无法作为第三个字符取出。
