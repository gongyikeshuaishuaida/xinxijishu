# 题目 08

台风风速为32.7~41.4米/秒时为“台风”，41.5~50.9米/秒时为“强台风”，51.0米/秒或以上时为“超强台风”。现输入风速 x（x≥32.7，且只含1位小数），下列 Python 代码段不能正确划分这3个台风风力等级的是（   ）

- A.
  ~~~python
  x=float(input(":"))
  if x<=41.4:
      dj="台风"
  elif x<=50.9:
      dj="强台风"
  else:
      dj="超强台风"
  print(dj)
  ~~~
- B.
  ~~~python
  x=float(input(":"))
  if x<=41.4:
      dj="台风"
  if 41.5<=x<=50.9:
      dj="强台风"
  else:
      dj="超强台风"
  print(dj)
  ~~~
- C.
  ~~~python
  x=float(input(":"))
  dj="台风"
  if x>50.9:
      dj="超强台风"
  elif x>=41.5:
      dj="强台风"
  print(dj)
  ~~~
- D.
  ~~~python
  x=float(input(":"))
  dj="强台风"
  if x<=41.4:
      dj="台风"
  if x>51.0:
      dj="超强台风"
  print(dj)
  ~~~

---

## 答案

**参考答案页标注：** B

**题面程序复核：** B、D 均存在边界问题

---

## 解析

B中两个 if 相互独立。当 x≤41.4时，第二个 if 条件为假，else会把前面设置的“台风”覆盖为“超强台风”，因此不能正确分类。D也存在边界问题：题目允许输入 x=51.0，但 D 使用 x>51.0，x=51.0 时会保留默认的“强台风”，没有输出“超强台风”。因此卷内答案给出的B与题面单选要求不一致，本笔记保留官方标注并显式记录B、D的程序复核冲突。
