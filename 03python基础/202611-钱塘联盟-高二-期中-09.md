# 题目 09

有如下 Python 程序段：

```python
s = "a7s9k45"
total = 0
for i in range(len(s)):
    if i % 2 == 1:
        if "0" <= s[i] <= "9":
            total += int(s[i])
print(total)
```

执行该程序段之后，输出的结果是（   ）

- A. 20
- B. 16
- C. 25
- D. 7

---

## 答案

**正确答案：** A

---

## 解析

奇数下标为 1、3、5，分别取数字 7、9、4，和为 20。
