# 题目 14

气象部门台风预警信号由弱到强共设置4个等级：蓝色、黄色、橙色、红色（第14题图1）。预警系统读取实测持续风力 `v`（级数），按照算法自动判定预警等级，具体规则如下所示。现用 Python 编写程序实现该判定逻辑，请阅读代码，补全①、②、③三处空缺。

![[attachments/202611-台州十校-高二-期中-14_横排1_2.png]]

```python
def warn(v):
    if v < 6:
        r = "不发布台风预警"
    elif v < 8:
        r = "蓝色预警"
    elif v < 10:
        r = "黄色预警"
    elif ______①______:
        r = "橙色预警"
    else:
        r = "红色预警"
    ______②______
s = int(input("输入持续风力等级："))
res = ______③______
print(res)
```

---

## 答案

**正确答案：** ① `v < 12`（或 `v >= 10 and v < 12`）；② `return r`；③ `warn(s)`。

---

## 解析

前面分支已排除v<10，因此橙色分支只需判断v<12。函数返回判断结果r，主程序将输入s作为实参调用warn。
