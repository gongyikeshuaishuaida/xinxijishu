# 题目 11

11. 有如下 Python 程序段：

```python
import random
i = 0; n = 5; a = [0] * n
while i < n:
    m = random.randint(1, 10)
    if m % 2 == 1:
        a[i] = m
    else:
        a[n - 1] = m
        n = n - 1
    i = i + 1
```

执行该程序段后，列表 `a` 中各元素的值不可能是（   ）

- A. `[1, 1, 0, 7, 8]`
- B. `[0, 5, 0, 8, 4]`
- C. `[0, 3, 5, 4, 6]`
- D. `[1, 3, 0, 4, 3]`

---

## 答案

**正确答案：** D

---

## 解析

奇数写入当前 `i` 指向的位置，偶数写入当前有效区间的末端并使 `n` 减 1。每次循环 `i` 都加 1，因此一旦发生偶数写入，后续有效区间会缩短；按这个过程检查四个结果，D 所示状态无法由同一执行过程得到，其他三项均可构造出相应的随机数序列。
