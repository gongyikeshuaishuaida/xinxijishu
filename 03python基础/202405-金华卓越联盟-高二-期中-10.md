# 题目 10

10.有如下 Python 程序段：

```python
s = "Secret"; t = [1, 0, 2]
r = [""] * len(s)
for i in range(len(s)):
    m = t[i % len(t)]
    if i < len(t):
        r[m] = s[i]
    else:
        r[m + len(t)] = s[i]
print("".join(r))
```

运行后输出结果是（ ）

- A.`Secret`
- B.`eScert`
- C.`retSec`
- D.`ceSter`

---

## 答案

**正确答案：** B

---

## 解析

按 `t=[1,0,2]` 将前3个字符放入下标1、0、2，后3个字符放入下标4、3、5，最终列表为 `[e,S,c,e,r,t]`，输出 `eScert`。
