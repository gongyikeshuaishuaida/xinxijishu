# 题目 08

用 Python 语句描述：60 分以上（包含）为合格，85 分以上（包含）为优秀，60 分以下（不包含）为不合格。设 `n` 为分数，则下列选项中正确的是（   ）

![[attachments/202411浙东北_08_条件判断选项.png]]

- A、B、C、D 代码选项见上图

## 答案

**正确答案：** C

## 解析

应先判断 `n<60` 的不合格情况，再在剩余分数中判断 `n<85` 的合格情况，否则为优秀。四个完整代码选项已保留在原题图中，符合这一嵌套判断逻辑的是 C。
