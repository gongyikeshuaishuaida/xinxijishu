# 题目 13

为支持公益事业，彩票中心设立彩票项目。每张彩票有 7 个不重复号码（1—33），中奖号码也由 7 个不重复号码构成；按与中奖号码相同的个数分为特等奖至六等奖。

（1）若中奖号码为 23、31、1、14、19、17、18，彩票为 11、8、9、32、1、16、7，中奖结果为 ______。

（2）程序如下，请填空：

```python
import random
flag = [0] * 34
data = [0] * 7
i = 0
while i < 7:
    t = random.randint(1, 33)
    if not flag[t]:
        ______①______
        i = i + 1
        flag[t] = 1
print("中奖号码:", data)

# 读取彩票记录，得到 sale=[[12,8,9,23,1,16,7], ...]
num = [0] * 8
for i in range(len(sale)):
    cnt = 0
    for j in range(7):
        if sale[i][j] in data:
            cnt += 1
    num[______②______] += 1
print("彩票开奖结果：")
for i in range(7):
    s = "特等奖一等奖二等奖三等奖四等奖五等奖六等奖"
    print(s[______③______], "产生:", num[i], "个")
```

（3）上述加框处代码能否修改为 `num=[0]*7`？（选填：是/否）

## 答案

**正确答案：**

- （1）六等奖
- （2）① `data[i] = t`；② `7-cnt`；③ `i*3:i*3+3`
- （3）否

## 解析

彩票与中奖号码只有 1 个相同号码，因此是六等奖。`cnt` 的取值为 0—7，奖项数组用 `num[7-cnt]` 映射为 0—7 共 8 个计数槽，不能改成长度 7；奖项名称字符串每 3 个字符对应一个奖项，使用 `s[i*3:i*3+3]` 切片。
