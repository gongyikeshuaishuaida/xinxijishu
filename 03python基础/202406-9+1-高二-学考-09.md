# 题目 09

9.有如下 Python 程序段：

```python
s=input("请输入字符串：")
t=s[0];max=0;ans=""
for i in range(1,len(s)):
    if s[i]>s[i-1]:
        t+=s[i]
        if len(t)>max:
            max=len(t)
            ans=t
    else:
        t=s[i]
print(ans)
```

执行该程序段，输入 `"123ABCD6789abcde"`（不包括引号），输出的结果是（ ）

- A. `123ABCD`
- B. `6789`
- C. `Abcde`
- D. `6789abcde`

---

## 答案

**正确答案：** D

---

## 解析

程序寻找按字符编码递增的最长连续子串。`D` 与后面的字符 `6` 比较时不满足递增，序列从 `6` 重新开始，随后 `6789abcde` 持续递增并成为最长结果。
