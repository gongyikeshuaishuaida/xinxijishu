# 题目 13

13. 为激发学生对创新和实践的兴趣，某校举办了一场创业大赛。其中一个项目是开发一个能够将小写数字金额（小于10万的整数）转换为中文大写数字的程序，编写一个 Python 程序实现上述功能。例如，输入“1234”，则输出“壹仟贰佰叁拾肆圆整”。运行结果如第13题图所示。

![[attachments/202411杭州周边_13_运行结果.png]]

（1）实现上述功能的 Python 程序如下，请在划线处填入合适的代码。

```python
ch = "零壹贰叁肆伍陆柒捌玖"
unit = ['', '拾', '佰', '仟', '万']
num = input("请输入小写数字金额: ")
ch_num = ""
flag = False
i = 0
while ______①______:
    d = int(num[i])
    if d == 0:
        ______②______
    else:
        if flag:
            ch_num += "零"
            flag = False
        ch_num += ______③______
    i += 1
print(ch_num + "圆整")
```

（2）将加框处的代码删除，运行程序并输入 `1023`，输出结果是（   ）。

---

## 答案

**参考答案：**

- （1）① `i<len(num)`（或 `i<=len(num)-1`）；② `flag = True`；③ `ch[d] + unit[len(num)-1-i]`
- （2）`壹仟零贰拾零叁圆整`

---

## 解析

程序从高位到低位遍历金额字符串，位下标 `i` 还未达到长度时继续循环。遇到 0 时设置 `flag`，表示后面出现非零数字时需要补一个“零”；非零数字用 `ch[d]` 转换，并按剩余位数选择单位。输入 1023 时，若删除框出的 `flag=False`，标志不会被清除，连续的非零位会重复补“零”，所以得到“壹仟零贰拾零叁圆整”。
