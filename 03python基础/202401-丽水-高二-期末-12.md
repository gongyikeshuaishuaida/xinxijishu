# 题目 12

某 Python 程序段实现输入三个数并按从大到小的顺序依次输出。方框中应填入的正确代码为（   ）

![[attachments/202401丽水_12_图1_选项.jpg]]

- A. if a<b 交换 a,b；if a<c 交换 a,c；elif b<c 交换 b,c
- B. if a<b 交换 a,b；if b<c 交换 b,c；if a<b 交换 a,b
- C. if a<b 交换 a,b；elif b<c 交换 b,c；if a<c 交换 a,c
- D. if a<b 交换 a,b；if b<c 交换 b,c；else 交换 a,c

---

## 答案

**正确答案：** B

---

## 解析

B先保证 a≥b，再通过比较 b 与 c 把较大的数移到中间位置，最后再次比较 a 与 b，从而保证 a≥b≥c。其他选项在某些输入排列下会遗漏比较或错误使用 else。
