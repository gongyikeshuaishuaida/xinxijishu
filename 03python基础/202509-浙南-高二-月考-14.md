# 题目 14

有如下 Python 程序段：

```python
import random
lst = ["a", "b", "c", "d"]
res = ""
i = 0
while i < len(lst):
    n = random.randint(0, 5)
    if n < 4:
        res = lst[i] + res
    i += 1
print(res)
```

执行该程序段后，输出结果不可能是（   ）

- A. `"a"`
- B. `"cb"`
- C. `"dcba"`
- D. `"dcbca"`

---

## 答案

**正确答案：** D

---

## 解析

循环只会依次访问 `lst` 中的 a、b、c、d 各一次，每个字符至多被加入结果一次，且加入时放在结果左侧，所以结果长度最多为 4，不可能出现长度为 5 且重复 `c` 的 `"dcbca"`。其余三个结果都可以通过选择不同的随机数得到。
