# 题目 12

12. 有如下 Python 程序段：

```python
import random
s = [0, 0, 0, 0, 0, 0]
for i in range(2):
    a = random.randint(2, 3)
    k = a
    for j in range(3):
        k = (k + a) % len(s)
        s[k] = s[k] + 1
```

执行该程序段，变量 `s` 的值不可能是（   ）

- A. `[2, 0, 2, 0, 2, 0]`
- B. `[4, 0, 0, 2, 0, 0]`
- C. `[3, 0, 1, 1, 1, 0]`
- D. `[3, 1, 1, 1, 0, 0]`

---

## 答案

**正确答案：** D

---

## 解析

当 `a=2` 时，一轮会依次给下标 `4、0、2` 加 1；当 `a=3` 时，一轮会依次给下标 `0、3、0` 加 1。两轮取值的组合可以得到 A、B、C 的结果，但下标 1 从未被访问，因此 D 不可能出现。
