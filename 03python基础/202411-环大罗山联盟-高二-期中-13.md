# 题目 13

13. 有如下 Python 程序段：

~~~python
s="水果75fRU2IT!"
ans=res=""
for x in s:
    if "a"<=x<="z":
        ans=ans+chr(ord(x)-32)
    elif "A"<=x<="Z":
        ans=ans+chr(ord(x)+32)
    elif "0"<=x<="9":
        res=x+res
t=ans+res
print(t)
~~~

程序执行后，输出的结果是（   ）

- A. 75fRU2IT
- B. Fruit752
- C. Fruit257
- D. 752Fruit

---

## 答案

**正确答案：** C

---

## 解析

小写字母 f 转为大写 F，大写字母 RU IT 转为小写 ruit，得到 Fruit。数字依次为 7、5、2，并使用 res=x+res 头插，得到 257，因此最终输出 Fruit257。
