# 题目 10

定义如下函数：

~~~python
def f(s):
    if len(s) <= 2:
        return s
    else:
        return s[0] + s[-1] + f(s[1:-1])
~~~

执行 print(f("123456")) 后，输出结果为（   ）

- A. 342561
- B. 162534
- C. 162543
- D. 342516

---

## 答案

**正确答案：** B

---

## 解析

递归展开为 f("123456")="16"+f("2345")，再得到"16"+"25"+f("34")，最后加上"34"，结果为162534。
