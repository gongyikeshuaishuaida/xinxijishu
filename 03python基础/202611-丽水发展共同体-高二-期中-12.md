# 题目 12

有如下 Python 程序段：

```python
import random
a = [0] * 6
a[0] = random.randint(1, 9)
i = 1
while i < 6:
    step = random.randint(0, 2)
    a[i] = a[i-1] + step
    if a[i] % 2 == i % 2:
        a[i] += 1
    i += 1
print(a)
```

执行该程序后，输出 a 的值可能是（   ）

- A. `[2,8,11,14,15,18]`

- B. `[6,6,7,10,11,14]`

- C. `[6,7,8,9,10,11]`

- D. `[7,7,9,10,11,14]`

---

## 答案

**正确答案：** B

---

## 解析

除首元素外，程序最终使元素奇偶性与下标相反，且相邻增量只能为 0～3。只有 B 同时符合这些限制。
