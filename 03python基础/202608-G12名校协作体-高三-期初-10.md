# 题目 10

有 Python 程序如下：

```python
s="Aaa24A2566a"; f=[0]*len(s); ss=""
for i in range(len(s)):
    k=i
    if f[k]==0:
        for j in range(i+1, len(s)):
            if s[k]==s[j]:
                f[k]=1; f[j]=2; k=j
        if k==i and f[k]!=1:
            ss+=s[k]
print(ss)
```

程序运行后，输出的结果是（   ）

- A. 4A256a
- B. Aa2456
- C. a4A256a
- D. Aa4256a

---

## 答案

**正确答案：** A

---

## 解析

程序逐个检查字符的重复情况，只把没有在后续位置找到相同字符的字符追加到 ss。重复的 A、a、2、5、6 被标记，保留下来的字符按程序处理结果为 4A256a，选 A。
