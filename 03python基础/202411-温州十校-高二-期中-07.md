# 题目 07

已知字符串 `s="abcABC123"`，结果为 `False` 的是（   ）

- A. `chr(ord(s[0])+2)=='c'`
- B. `s[-1]>s[-3:]`
- C. `s[-1]==int(s[-1])`
- D. `len(s)//4==2`

## 答案

**正确答案：** C

## 解析

`s[-1]` 是字符串 `'3'`，而 `int(s[-1])` 是整数 `3`，二者类型不同，使用 `==` 比较时结果为 `False`。A、B、D 的结果均为 `True`。
