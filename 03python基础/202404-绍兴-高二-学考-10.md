# 题目 10

10.程序统计输入字符串中的元音字母A、E、I、O、U：

```python
d={}
text=input()
text=text.upper()
for c in text:
    if c in "AEIOU":
        if c in d:
            d[c]+=1
        else:
            d[c]=1
print(d["A"])
```

输入 `How are you? Fine,Thankyou. And you?`，输出结果是

A.0  B.1  C.2  D.3

---

## 答案

**正确答案：** D

---

## 解析

转为大写后，字符串中A分别出现在`are`、`Thankyou`和`And`中，共3次。
