# 题目 13

某冶金车间炉温常年高于 255℃，为防止炉温数值被他人直接窃取，车间工作人员设计了一套简易加密方式用来传输炉温数据。加密流程如下：

① 传感器采集十进制炉温 `m`（>255℃）；

② 以 2、3 为前两项，按斐波那契递推规则生成长度为 `k` 的数列 `lst`（第 3 项起，每项等于前两项之和）；

③ 将炉温转换为二进制串，按位取反得到反码字符串；反码串总长度等于数列 `lst` 的所有元素值之和（若长度不足，高位补 1）；

④ 以 `lst` 中的数值为长度，依次切割反码字符串，每段二进制转为十进制后对 26 取余，余数按下表映射为大写字母 A～Z；

![[attachments/202611宁波高三_13_图1.png]]

## 答案

（1）CGT

（2）① `lst[i-1] + lst[i-2]`，也可用 `lst[-1] + lst[-2]` 或 `lst[len(lst)-1] + lst[len(lst)-2]`。  
② `str(1 - bit) + s`，也可用 `str((bit + 1) % 2) + s`、`str(1 - m % 2) + s` 或 `str((m % 2 + 1) % 2) + s`。  
③ `val = btod(seg) % 26`，也可用 `val = btod(s[pos:pos+num]) % 26`。

## 解析

（1）段长为 2、3、5，总长 10。将 300 写成 10 位二进制 `0100101100` 后按位取反，切为 `10 110 10011`，十进制值为 2、6、19，对应 CGT。

（2）新段长等于前两项之和。程序从低位到高位取出二进制位，取反后插到字符串左侧。每段转换为十进制并对 26 取余，再用余数作为字母表下标。若炉温的二进制位数超过总段长，题给代码只处理低位，原题未另行规定这一情形。
