# 题目 11

有如下 Python 程序段：

```python
nums = [1,3,5,2,4,6,7,1,2]
max_cnt = 1; cnt = 1
for i in range(1, len(nums)):
    if nums[i] > nums[i-1]:
        cnt += 1
        if cnt > max_cnt:
            max_cnt = cnt
    else:
        cnt = 1
print(max_cnt)
```

程序运行后，输出结果是（   ）

- A. 4
- B. 3
- C. 2
- D. 1

---

## 答案

**正确答案：** A

---

## 解析

2、4、6、7 连续严格递增，长度为 4，其他段更短。
