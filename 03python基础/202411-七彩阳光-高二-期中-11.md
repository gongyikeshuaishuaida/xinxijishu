# 题目 11

11. 有如下 Python 程序段：

```python
s = "1223159"
i = 1
while i < len(s):
    for j in range(0, i):
        if s[j] == s[i]:
            s = s[0:j] + s[i+1:]
            i = j
            break
    else:
        i = i + 1
```

执行该程序段，变量 `s` 的值为（   ）

- A. `'12359'`
- B. `'59'`
- C. `'13159'`
- D. `'159'`

---

## 答案

**正确答案：** B

---

## 解析

程序从左到右检查当前字符是否在前面出现过。第一次在 `"1223159"` 中删除重复的 `2`，得到 `"13159"`；随后重新检查，删除重复的 `1`，得到 `"59"`。之后字符串中没有重复字符，最终结果为 `'59'`。
