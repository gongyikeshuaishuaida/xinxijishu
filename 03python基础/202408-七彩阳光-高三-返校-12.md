# 题目 12

差集`a-b`是指属于`a`但不属于`b`的元素构成的集合，现用链表模拟差集运算。链表每个节点包含数据区域和指针区域，集合中元素递增存放且允许重复。程序通过`p`遍历链表`a`、`q`遍历链表`b`，`tp`保存待保留链表的尾指针。方框中应填入的正确代码为（   ）。

![[attachments/202408七彩阳光_12_链表图.jpg]]

```python
p = ha = 0
q = hb = 0
tp = 0
while ha != -1 and p != -1 and q != -1:
    if a[ha][0] == b[q][0]:
        ha = a[ha][1]
        p = ha
    else:
        if a[p][0] > b[q][0]:
            q = b[q][1]
        # 方框处
# 从ha指针处输出链表a的数据，代码略
```

- A.

  ```python
  elif a[p][0] < b[q][0]:
      tp = p
      p = a[p][1]
  else:
      a[tp][1] = a[p][1]
      p = a[p][1]
  ```

- B.

  ```python
  elif a[p][0] < b[q][0]:
      p = tp
      tp = a[tp][1]
  else:
      a[p][1] = a[tp][1]
      tp = a[tp][1]
  ```

- C.

  ```python
  elif a[p][0] < b[q][0]:
      p = a[p][1]
      tp = p
  else:
      a[tp][1] = a[p][1]
      tp = p
  ```

- D.

  ```python
  elif a[p][0] < b[q][0]:
      tp = p
      p = a[p][1]
  else:
      a[tp][1] = a[p][1]
      p = a[p][1]
  ```

---

## 答案

**正确答案：** D

---

## 解析

当 a[p][0] 小于 b[q][0] 时，该节点不在b中，应保留，先令 tp=p 再令 p 指向下一个节点。相等时该节点应从a链表中删除，令前一节点 tp 的后继跳过当前节点，再移动p。D同时保持了tp为保留链表尾指针并正确删除节点。
