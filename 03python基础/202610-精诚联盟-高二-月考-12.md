# 题目 12

函数`jm(password)`用来对加密字符进行解密，代码如下：

```python
def jm(password):
    key = {"b":"d","d":"a","a":"c","c":"b"}
    i = 0
    while i < len(password)-1:
        if i >= 0 and key[password[i]] == password[i+1]:
            password = password[:i]+password[i+1:]
            i -= 1
        else:
            i += 1
    return password
```

运行`jm("bdacbdac")`，函数的返回值为（   ）

- A. `"bdacbdac"`
- B. `"bc"`
- C. `"c"`
- D. `"bdac"`

---

## 答案

**正确答案：** C

---

## 解析

匹配到映射相邻字符时删除左字符并回退检查。该串沿b→d→a→c→b→d→a→c的映射连续匹配，逐次删除前面的字符，最终只剩c。i=-1时通过短路判断避免负下标参与匹配。
