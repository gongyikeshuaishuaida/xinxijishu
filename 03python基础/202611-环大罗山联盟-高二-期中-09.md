# 题目 09

下列 Python 程序代码不能实现变量 `k` 在数值1和0之间切换的是（   ）

- A. `k=1-k`

- B. `k=(1+k)%2`

- C. `dic1={1:"0",0:"1"};k=dic1[k]`

- D. `k=1//(k+1)`

---

## 答案

**正确答案：** C

---

## 解析

C把数值1、0映射为字符串"0"、"1"，不符合数值切换；另外三种式子均在数值0和1之间切换。
