# 题目 14

将数字1～9分成3组，分别组成3个三位数，且使这3个三位数的数值构成1:2:3的比例，例如：192、384、576就是符合要求的一组三位数。

(1) 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
def check(num1, num2, num3):
    cnt = [0] * 10
    lst = [num1, num2, num3]
    for x in lst:
        while ______①______:
            d = x % 10
            cnt[d] += 1
            ______②______
    for d in range(1, 10):
        if ______③______:
            return False
    return True
for num1 in range(100, 1000):  # 原卷加框处为100, 1000
    num2 = num1 * 2
    num3 = num1 * 3
    if check(num1, num2, num3):
        print(num1, num2, num3)
```

(2) 若将加框处参数改为123,330，程序运行结果______（A.有影响/B.没有影响，填写A或B）。

---

## 答案

**正确答案：** (1) ① `x > 0`（或 `x != 0`）；② `x = x // 10`；③ `cnt[d] != 1`；(2) B。

---

## 解析

逐位取个位、删除个位，统计1～9的出现次数，要求每个恰出现一次。原范围实际得到的num1为192、219、273、327；这四个都在[123,330)内，因此缩小范围不改变输出。
