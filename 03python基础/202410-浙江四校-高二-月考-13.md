# 题目 13

对任意正整数 `n`，若为偶数就除以 2，若为奇数就乘 3 再加 1，不断重复直到得到 1。

（1）当 `n=10` 时，数据变化过程为 `10→______→1`。

（2）补全程序：

```python
n = int(input("请输入一个整数："))
if n > 0:
    print("变化过程为：", n, end="")
    while ______①______:
        if ______②______:
            n = n // 2
        else:
            ______③______
        print("→", n, end="")
else:
    print("输入错误，请重新输入")
```

（3）该程序采用的算法是（   ）（单选：A.解析算法 / B.枚举算法）。

---

## 答案

**正确答案：** （1）`5→16→8→4→2`；（2）① `n!=1`；② `n%2==0`；③ `n=n*3+1`；（3）A

---

## 解析

程序按奇偶性直接套用明确的数学规则，直到 `n` 变成 1，属于解析算法。
