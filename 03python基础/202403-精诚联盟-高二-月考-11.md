# 题目 11

有如下程序段：

```python
from random import randint
i, n = 0, 4
a = [0, 0, 0, 0, 0]
while i <= n:
    x = randint(1, 9)
    if x % 2 == 1:
        a[i] = x
    else:
        a[n] = x
        n = n - 1
    i = i + 1
print(a)
```

运行程序后，输出 `a` 的值可能是（   ）

- A. 713910
- B. 34188
- C. 07068
- D. 37550

## 答案

**正确答案：** C

## 解析

奇数从左侧位置 `i` 写入，偶数从右侧有效位置 `n` 写入并使 `n` 左移。逐项检查各选项，C（可写为 `[0, 7, 0, 6, 8]`）符合这种随机执行结果。
