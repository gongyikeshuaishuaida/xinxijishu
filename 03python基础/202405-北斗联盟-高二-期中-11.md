# 题目 11

11.有如下 Python 程序段：

```python
from random import randint
a = [1] * 8
p = randint(1, 7)
a[0] = p
for i in range(1, len(a)):
    a[i] = a[i - 1] + randint(1, 5) * 2
for i in range(len(a) - 1, p, -1):
    a[i] = a[i - 1]
    a[i - 1] = p
print(a)
```

执行程序后，输出的结果可能是（ ）

- A.`[4,10,18,4,20,22,24,26]`
- B.`[6,14,22,32,40,44,6,46]`
- C.`[1,1,7,11,19,31,33,41]`
- D.`[2,5,2,7,17,19,21,29]`

---

## 答案

**正确答案：** B

---

## 解析

数组前半段先由正的偶数增量构成严格递增序列，再把 `p` 插入到下标 `p` 位置并整体后移。逐项检查可知 B 符合程序产生的结构，其他选项不满足初始递增关系或插入位置约束。
