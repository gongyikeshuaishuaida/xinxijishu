# 题目 10

有如下 Python 程序：

~~~python
g = int(input('请输出分数:'))
if g >= 85:
    print('A')
elif g >= 70:
    print('B')
elif g < 60:
    print('D')
else:
    print('C')
~~~

10. 程序最后输出 C，输入的范围为（   ）

- A. g >= 60
- B. 60 <= g < 85
- C. 60 <= g < 70
- D. g < 70

---

## 答案

**正确答案：** C

---

## 解析

程序先排除 g>=85 和 70<=g<85 的情况；若 g<60 会进入第三个分支输出D。因此输出C的范围是 60<=g<70。
