# 题目 12

字典 dic 中存储了部分地市的考点数量，现编写以下 Python 程序：

~~~python
dic={"杭州":73,"金华":102,"宁波":67,"台州":90,"衢州":84}
count=9999
city=""
for name in dic:
    if dic[name]<count:
        count=dic[name]
        city=name
print(city)
~~~

执行该程序段后，输出的结果是（   ）

- A. 杭州
- B. 金华
- C. 宁波
- D. 衢州

---

## 答案

**正确答案：** C

## 解析

程序遍历字典中的考点数量并持续更新最小值。各地市数量的最小值是宁波的 67，因此最终输出宁波，选 C。
