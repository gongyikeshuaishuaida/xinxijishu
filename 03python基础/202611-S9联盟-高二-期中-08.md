# 题目 08

阅读下列材料，回答第 08 题。

某高中引入了智能运动会系统，系统根据收集到的报名信息和赛程自动安排分组等相关设置。系统利用摄像头实现比赛项目自动签到，输入比赛成绩后，服务器（计算机）自动统计名次和相应积分，并积分统计到相应班级中同时利用广播播报或大屏投屏比赛结果。

将某个运动员报名信息转换为 `lst=[1,1,0,0,0,0,1,0,0,0]`，下列程序段不能够判断该运动员同时报名了“100M”和“200M”项目的是（   ）

- A.

    ```python
    if lst[0] == 1 and lst[1] == 1:
        s = "同时报名了"
    else:
        s = "没有同时报名"
    ```

- B.

    ```python
    s = "同时报名了"
    if lst[0] != 1 and lst[1] != 1:
        s = "没有同时报名"
    ```

- C.

    ```python
    if lst[0] == 1:
        if lst[1] == 1:
            s = "同时报名了"
        else:
            s = "没有同时报名"
    else:
        s = "没有同时报名"
    ```

- D.

    ```python
    if lst[0] != 1:
        s = "没有同时报名"
    elif lst[1] != 1:
        s = "没有同时报名"
    else:
        s = "同时报名了"
    ```

---

## 答案

**正确答案：** B

---

## 解析

B 在只有一个项目报名时仍保留“同时报名了”，不能完成一般性的判定；例如前两位为 [1,0] 时出错。题中给出的 [1,1,...] 单个输入不能暴露这一问题。
