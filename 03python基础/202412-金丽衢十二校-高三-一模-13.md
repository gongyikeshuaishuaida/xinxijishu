# 题目 13

有一个农田作物生长环境监测系统。该系统的智能终端通过传感器获取数据，并通过 IOT 模块以无线方式将数据上传到 Web 服务器。服务器实时对数据进行处理，判断出异常时，通过智能终端控制执行器发出预警信号并打开环境调控设备。用户可通过浏览器查询实时和历史数据。请回答下列问题。

（1）下列环节中不属于信息系统搭建的是 ______①______（单选，填字母）。

- A. 软件开发
- B. 硬件搭建
- C. 系统测试

- C. 不同传感器采集的数据可以通过同一智能终端传输至 Web 服务器
- D. 该系统采集到的数据可以存储在数据库中

## 答案

**参考答案：**

- （1）A
- （2）BCD
- （3）环境调控设备故障，或智能终端与环境调控设备之间的连接/控制线路故障等
- （4）① `input?id=s1&h=50`（`input?h=50&id=s1` 亦可）；② `last == -1 or abs(sensorvalue - last) > x`

## 解析

软件开发、硬件搭建和系统测试都属于信息系统建设环节，但本题给出的 A 项不是搭建环节。IOT 模块负责向服务器上传数据，损坏后无法获得实时数据；多个传感器可以共用一个智能终端，采集数据也可以存储在数据库中。预警能发出而设备不能打开，可能是执行器、环境调控设备或通信连接出现故障。路由为 `/input`，参数名分别为 `id` 和 `h`，所以 URL 应包含对应路径和查询参数；`last=-1` 表示没有历史数据，或者变化量超过 `x` 时，才满足写库条件。
