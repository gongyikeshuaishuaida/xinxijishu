# 题目 10

有如下pyhon程序段：

```python
s = "301-413-132"
isum,t = 0,0
for i in s:
    if "0" <= i <= "4":
        t = t*5+int(i)
    else:
        isum += t
        t = 0
print(isum)
```

运行该程序段，输出结果是（   ）

- A. 76
- B. 108
- C. 184
- D. 226

---

## 答案

**正确答案：** C

---

## 解析

t按五进制累积每段数。遇到两个连字符时分别加上301₅=76和413₅=108，得到184。末段132₅虽被计算为42，但循环结束后没有执行isum+=t，故不计入输出。
