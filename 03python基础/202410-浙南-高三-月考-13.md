# 题目 13

2024年巴黎奥运会乒乓球混双比赛采取七局四胜制，一方获胜四局即停止。每局采用11分制，即一方达到11分且领先至少2分时结束。

（1）根据比分规则，若一局比赛比分为 `10:13`，是否合理？ ______①______（选填：合理/不合理）

程序某次执行结果如下：

![[attachments/202410浙南_13_比赛输出图.jpg]]

（2）实现上述功能的 Python 程序如下，请在划线处填入合适代码。

```python
import random
m = 4
count = 1
wa = wb = 0
while ______①______:
    a = b = 0  # 表示比赛双方此局的分数
    while a < 11 and b < 11 or abs(a - b) < 2:
        t = random.randint(0, 1)  # 产生随机得分0或1
        a += t
        ______②______
    print("第", count, "局：", a, ":", b)
    if a > b:
        wa += 1
    else:
        wb += 1
    ______③______
print("胜负情况：", wa, ":", wb)
```

---

## 答案

**正确答案：** （1）不合理；（2）① `wa<m and wb<m`；② `b+=1-t`；③ `count+=1`（或 `count=wa+wb`）

---

## 解析

10:13 的领先差为3；按逐分比赛规则，达到12:10时比赛已结束，不会继续到10:13。比赛在任一方胜4局时结束；每次随机得分中一方加 `t`、另一方加 `1-t`；每局后更新局号。
