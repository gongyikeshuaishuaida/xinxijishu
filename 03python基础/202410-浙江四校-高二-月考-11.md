# 题目 11

原卷给出如下程序段：

```python
s = "a123b456"
f = True
for i in s:
    if "0" <= i <= "9" and f == True:
        t = t + i
        f = False
    else:
        f = True
print(t)
```

运行程序，输出结果是（   ）

- A. `123456`
- B. `1346`
- C. `123`
- D. `14`

---

## 答案

**正确答案：** B

---

## 解析

原卷代码直接使用了变量 `t`，未显示初始化语句；按参考答案隐含 `t=` 计算。标志 `f` 使连续数字中每隔一个字符被记录，因此两段数字分别取 1、3 和 4、6，得到 `1346`。
