# 题目 12

有如下 Python 程序段：

```python
import random
s1="ABC"; s2="1234"; res=""
i,j=0,len(s2)-1
while i<len(s1) and j>=0:
    k=random.randint(0,1)    # 产生[0,1]范围内的随机整数
    if k==0:
        res+=s1[i]
        i+=1
    else:
        res+=s2[j]
        j-=1
print(res)
```

执行程序后，变量 res 不可能的是（   ）

- A. A4B3C2
- B. A4321B
- C. 4A3B2C
- D. 432ABC

---

## 答案

**正确答案：** A 或 B

---

## 解析

参考答案接受 A 或 B。A 中最后一个 C 已使 i 达到长度，循环无法再追加 2；B 中数字 1 已使 j 变为 -1，无法再追加 B。
