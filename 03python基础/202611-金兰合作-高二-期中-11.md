# 题目 11

有如下 Python 程序段：

```python
data = [5, 4, 3, 8, 7, 6, 9]
i = 0
while i < len(data) - 1:
    if data[i] > data[i+1]:
        k = i
        while k < len(data) - 1 and data[k] > data[k+1]:
            k += 1
        data = data[:i+1] + data[k+1:]
    i += 1
print(data)
```

执行该程序段后，输出的结果是（   ）

- A. `[5,8,9]`
- B. `[5,3,8,6,9]`
- C. `[5,4,3,8,9]`
- D. `[5,8,7,9]`

---

## 答案

**正确答案：** A

---

## 解析

每段连续下降的区间只保留其首元素，结果是 [5,8,9]。
