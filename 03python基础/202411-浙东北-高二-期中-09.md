# 题目 09

有如下 Python 程序段：

~~~python
i=1;t=0
while i<=10:
    if i%3==0:
        i+=2
    t+=1; i+=1
print(i,t)
~~~

执行该程序段后，变量 `i` 和 `t` 的值分别为（   ）

- A. 11，7
- B. 12，5
- C. 11，10
- D. 12，6

## 答案

**正确答案：** B

## 解析

逐轮跟踪可得：`i` 依次经过 1、2、3、5、6、8、9、11、12，循环执行 5 次。遇到 3、6、9 时先额外加 2，再统一加 1，最终 `i=12,t=5`。
