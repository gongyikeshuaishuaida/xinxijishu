# 题目 10

哥德巴赫猜想验证程序中，方框处应填入能实现程序功能的代码（   ）

```python
import math
def isprime(x):
    for i in range(2, int(math.sqrt(x)) + 1):
        if ______①______:        # 发现因子
            return False
    return True

n = int(input("请输入一个大于2的偶数:"))
for p in range(2, n - 1):
    q = n - p
    if ______②______:             # 找到两个质数
        print(n, "=", p, "+", q)
        break
```

- A. ① `x % i != 0`；② `isprime(p) and isprime(q)`
- B. ① `x % i != 0`；② `isprime(p) or isprime(q)`
- C. ① `x % i == 0`；② `isprime(p) and isprime(q)`
- D. ① `x % i == 0`；② `isprime(p) or isprime(q)`

---

## 答案

**正确答案：** C

---

## 解析

若 `x % i == 0` 说明找到除1和自身外的因子，`x` 不是质数；哥德巴赫表达式要求 `p`、`q` 同时为质数，所以使用 and。
