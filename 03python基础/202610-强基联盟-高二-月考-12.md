# 题目 12

有如下Python程序段：

```python
import random
a=[4,7,1,6,8,2,9,5]
tot=0; c=0; m=-1
n=random.randint(2,4)
for i in range(len(a)):
    tot+=a[i]
    c+=1
    if c>=n:
        if tot>m:
            m=tot
        tot-=a[i-n+1]
print(m)
```

执行该程序段后，输出结果不可能是（   ）

- A. 14
- B. 19
- C. 25
- D. 30

---

## 答案

**正确答案：** D

---

## 解析

n只可能为2、3、4。每次累计一个元素，形成长度n的窗口后更新最大和，再移除窗口最左元素。三个窗口长度分别输出14、19、25，故30不可能。
