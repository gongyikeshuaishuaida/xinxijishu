# 题目 11

有如下 Python 程序段：

```python
s = "3a78bb2ccc9dddeee"
i = 0
max_len = 0
start = 0
while i < len(s) - 1:
    j = i
    while j + 1 < len(s) and s[j + 1] == s[j]:
        j += 1
    if j - i + 1 > max_len:
        max_len = j - i + 1
        start = i
    i = j + 1
print(s[start: start + max_len])
```

执行该程序段后，输出结果为（   ）

- A. bb
- B. ccc
- C. ddd
- D. eee

---

## 答案

**正确答案：** B

---

## 解析

ccc、ddd、eee 都长 3。只有严格更长才更新，因此保留先遇到的 ccc。
