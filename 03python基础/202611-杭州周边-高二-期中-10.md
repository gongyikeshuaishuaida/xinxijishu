# 题目 10

有如下 Python 程序段：

```python
i=0
j=len(s)-1
ans=""
while i<=j:
    if "a"<=s[i]<="z":
        ans=ans+s[i]
    else:
        ans=s[i]+ans
        j-=1
    i+=1
```

若 s 为“a1b2c3”，运行该程序段后，ans 的值为（   ）

- A. "123abc"
- B. "12ab"
- C. "21ab"
- D. "1ab"

---

## 答案

**正确答案：** C

---

## 解析

依次得到 a、1a、1ab、21ab；第二次读到数字后右边界减小，循环到此结束。
