# 题目 12

有如下 Python 程序段：

```python
def fun(a):
    n = len(a); i = 0
    while i < n // 2:
        a[i] = a[i] + a[n - 1 - i]
        i += 1
    return a

a = [1, 2, 3, 4, 5, 6]
print(fun(a))
```

执行该程序段后，输出的结果是（   ）

- A. `[7, 7, 7, 4, 5, 6]`
- B. `[7, 8, 9, 4, 5, 6]`
- C. `[7, 7, 7, 7, 7, 7]`
- D. `[7, 8, 9, 10, 11, 12]`

---

## 答案

**正确答案：** A

---

## 解析

循环只处理前半部分的三个下标。`i=0` 时 `a[0]=1+6=7`，`i=1` 时 `a[1]=2+5=7`，`i=2` 时 `a[2]=3+4=7`，后半部分保持原值 4、5、6，所以结果为 `[7, 7, 7, 4, 5, 6]`，选 A。
