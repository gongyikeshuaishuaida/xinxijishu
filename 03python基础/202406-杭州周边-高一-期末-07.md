# 题目 07

7.下列 Python 表达式的值为 True 的是（ ）

- A.`"12"*2>"2"`
- B.`"a" in ["apple"]`
- C.`len(range(12))==12`
- D.`3**2-7%5<int(6.8)`

---

## 答案

**正确答案：** C

---

## 解析

`range(12)` 生成 0 到 11 共 12 个整数，因此其长度等于 12。A 是字符串重复后的字典序比较，B 判断的是完整列表元素，D 左边为 7 而右边为 6，均不成立。
