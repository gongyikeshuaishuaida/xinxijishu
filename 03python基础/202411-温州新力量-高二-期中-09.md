# 题目 09

有如下 Python 程序段：

~~~python
import random
def lsk(a, b):
    while a > 0:
        a = a // 10
        b = b % 10
    c = a + b
    return c

x = random.randint(10, 99)
y = random.randint(10, 99)
result = lsk(x, y)
print(result)
~~~

运行以上程序，不可能出现的结果是（   ）

- A. 0
- B. 1
- C. 9
- D. 10

## 答案

**正确答案：** D

## 解析

循环结束时 `a` 一定为 0；`b=b%10` 后保留 `y` 的个位数，因此 `result` 只能是 0～9 之间的整数，不可能为 10。
