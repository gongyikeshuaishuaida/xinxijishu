# 题目 11

有下列 Python 程序段：

```python
s1 = "pytorch"
s2 = "python"
s = ""
i = 0
j = 0
while i < len(s1) and j < len(s2):
    if s1[i] > s2[j]:
        s = s + s1[i]
    else:
        j += 1
    i += 1
```

执行以上程序段后，`s` 中的值是（　　）

- A. `"or"`
- B. `"ch"`
- C. `"on"`
- D. `"to"`

---

## 答案

A

---

## 解析

前 3 次比较的字符分别相同，均令 `j` 增加。随后 `s1[3]='o'`、`s1[4]='r'` 均大于当前的 `s2[3]='h'`，依次加入 `s`；之后循环没有再加入字符，最终 `s="or"`。
