# 题目 11

有如下 Python 程序段：

```python
k = 2
sum, j, c = 0, 0, 0
flag = False
s = "a36/b12c/27/e59/"
for ch in s:
    if "0" <= ch <= "9":
        c = c * 10 + int(ch)
        j += 1
    elif "a" <= ch <= "z":
        flag = True
    else:
        if j == k and flag:
            sum += c
        flag = False
        j = 0
        c = 0
```

执行该程序段后，sum 的值为（   ）

- A. 124

- B. 107

- C. 75

- D. 48

---

## 答案

**正确答案：** B

---

## 解析

按斜杠分段，只累加带字母且有两位数字的段，36+12+59=107；纯数字段 27 被排除。
