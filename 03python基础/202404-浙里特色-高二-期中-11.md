# 题目 11

11.有如下 Python 程序：

```python
s, n = 0, 9
while True:
    s += n
    if s > 15:
        break
    n = 3
print(n, s)
```

程序运行后，输出的结果是（ ）

A.`0 18`　B.`3 18`　C.`6 15`　D.`6 18`

---

## 答案

**正确答案：** B

---

## 解析

第一次累加得到 `9`，随后 `n` 变为 `3`；继续累加得到 `12、15、18`，在 `s=18` 时跳出循环，`n` 仍为 `3`，故输出 `3 18`。
