# 题目 14

某高校 2026年“三位一体”综合评价招生规定，考生须同时满足以下两个条件方可获得综合素质测试资格：

①基础门槛：所有 10 门学考科目成绩均不能为 D 等；

②分数要求：学考折算分须达到 80 分及以上（折算规则：A=10 分，B=8 分，C=4 分，D=0 分）。

现编写程序判断某考生的学考成绩是否具备测试资格。实现上述功能的Python程序如下，请在划线处填入合适的代码：



```python
grade = input("请输入考生的10门学考等第：")    # 形如 "ABCAABCBAA"
st = {"A":10, "B":8, "C":4, "D":0}
total = 0
______①______
for i in range(len(grade)):
    if grade[i] == "D":
        flag = False
    total += ______②______
if flag == True and ______③______:
    print("具备测试资格！")
else:
    print("不具备测试资格！")
```



（1）若输入考生的学考等第为“AABBBBCCCC”，则程序输出的结果为 ______（单选，填字母）。



- A. 具备测试资格！



- B. 不具备测试资格！

（2）请在划线处填入合适的代码。

---

## 答案

（1）B。

（2）① `flag = True`；② `st[grade[i]]`；③ `total >= 80`。

---

## 解析

AABBBBCCCC 的折算分为 2×10+4×8+4×4=68，低于 80。flag 初始为 True，任何一门 D 都将其改为 False；最后同时检查无 D 与总分达标。
