# 题目 11

有如下 Python 程序段：

```python
c = 1; t = 1; s = 0
ans = 0
for i in range(1, len(a)):
    if a[i] > a[i-1]:
        t = t + 1
    else:
        t = 1; s = i
    if t > c:
        c = t; ans = s
print(c, ans)
```

若列表 `a=[3,5,8,6,12,4,6,7,9]`，运行该程序段后，输出的结果是（   ）

- A. 3 0

- B. 3 1

- C. 4 4

- D. 4 5

---

## 答案

**正确答案：** D

---

## 解析

最后一段 4、6、7、9 最长，长度为 4，起始下标为 5。
