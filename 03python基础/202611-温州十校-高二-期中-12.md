# 题目 12

有如下 Python 程序段：

```python
s = input("请输入一个字符串：")
t = ""
for i in range(len(s)):
    if i % 2 == 0:
        t = t + s[i]
    else:
        t = s[i] + t
t = t[2:len(t)] + t[0:2]
print(t)
```

执行该程序段后，输出的结果为bacefd，则输入的字符串 `s` 可能是（   ）

- A. abcdef

- B. ecfadb

- C. bacefd

- D. fdbace

---

## 答案

**正确答案：** A

---

## 解析

输入abcdef时，偶数下标字符向右追加、奇数下标字符向左追加，得到fdbace；再将前2字符移至末尾，得到bacefd。
