# 题目 13

一个数，求它所有数位的立方和，得到的新数再次求所有数位的立方和，如此重复，若最终结果为 1，则称该数为"幸运数"。如：对于正整数 778，重复过程如下：

（1）7³＋7³＋8³＝343＋343＋512＝1198

（2）1³＋1³＋9³＋8³＝1＋1＋729＋512＝1243

（3）1³＋2³＋4³＋3³＝1＋8＋64＋27＝100

（4）1³＋0³＋0³＝1

最终结果为 1，所以 778是一个幸运数。

请回答下列问题：

（1）根据上述规则，数字 211 ______（选填：是/不是）幸运数。

（2）编写 Python 程序，实现判断输入的正整数是否为幸运数，请在划线处填入合适的代码。

```python
def cube_sum(n):
    ______①______
    while n > 0:

        t = r ** 3
        temp = temp + t
        n //= 10
    return temp
num = int(input("请输入一个正整数："))
n = num
res = []

    res.append(n)    # append 函数的功能是在列表最后追加一个新元素
    n = ______③______
    if n in res:

if n == 1:
    print(num, "是幸运数！")
else:
    print(num, "不是幸运数！")
```

---

## 答案

（1）是。

（2）① `temp=0`，② `r=n%10`，③ `cube_sum(n)`。

---

## 解析

211 的各位立方和依次为 10、1。函数每次用取余取得末位、整除 10 去掉末位。主程序记录已出现的值，遇到重复值退出并检查它是否为 1。
