# 题目 09

有如下Python程序段：

```python
s1 = "AB"; s2 = "AACBD"
i = 0; s3 = ""
for j in range(len(s2)):
    if i >= len(s1):
        break
    if s1[i] == s2[j]:
        i += 1
    else:
        s3 += s2[j]
print(s3)
```

运行该程序段后，变量s3的值是（   ）

- A. "ACD"
- B. "CD"
- C. "AC"
- D. "AACBD"

---

## 答案

**正确答案：** C

---

## 解析

程序在s2中按顺序匹配s1的字符：匹配成功则i后移，匹配失败则把s2中的字符追加到s3。j=0时s2[0]="A"与s1[0]="A"匹配，i=1；j=1时"A"与"B"不匹配，s3="A"；j=2时"C"不匹配，s3="AC"；j=3时"B"与"B"匹配，i=2；j=4时i≥2满足break条件退出循环。故s3的值为"AC"。
