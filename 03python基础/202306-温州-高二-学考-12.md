# 题目 12

为实现天数倒计时，小陈用共阴极LED七段数码管显示数字。数码管引脚、字符字形码和数字“3”的显示效果如下：

（1）若显示数字“25”，则十六进制字形码为 ______①______。

（2）`days`函数计算日期到元年元旦的总天数。闰年为4的倍数且不是100的倍数，或为400的倍数；闰年有366天，平年有365天。请补全代码。

```python
def days(y, m, d):
    mdays = [0, 31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334]
    ans = y * 365 + y // 4 - y // 100 + y // 400
    ans = ans + mdays[m - 1] + d
    if (y % 4 == 0 and y % 100 != 0 or y % 400 == 0) and m >= 3:
        ______②______
    return ans
```

（3）`single`函数根据十六进制字形码求单个数码管的引脚电平值，请补全代码。

```python
def single(num):
    code = {0: "3F", 1: "06", 2: "5B", 3: "4F", 4: "66", 5: "6D", 6: "7D", 7: "07", 8: "7F", 9: "6F"}
    b = ""
    for i in range(1, -1, -1):
        if "0" <= code[num][i] <= "9":
            c = int(code[num][i])
        else:
            c = ______③______
        for i in range(4):
            b = str(c % 2) + b
            c //= 2
    return b[1:]
```

（4）倒计时主程序中，循环输出 `total` 的各位数字，请补全条件。

```python
while True:
    total = days(2023, 9, 23) - days(y, m, d)
    ans = ""
    if total == 0:
        break
    while ______④______:
        num = total % 10
        ans = single(num) + ans
        total = total // 10
    print(ans)
```

---

## 答案

**正确答案：** （1）`5B 6D`（或`5BH 6DH`）；（2）`ans += 1`；（3）`ord(code[num][i]) - 55`；（4）`total > 0`

---

## 解析

（1）根据字形码表，数字2对应`5B(H)`，数字5对应`6D(H)`，因此显示“25”时依次输出`5B 6D`。

（2）前面的公式把每个年份按365天并加上常规闰年数计算，若当前年份是闰年且月份已到3月，还需要把2月多出的一天补入总天数，所以填 `ans += 1`。

（3）字符`0`—`9`可直接转为整数，字符`A`—`F`对应十进制10—15。大写十六进制字符的编码值比数字字符`0`大55，因此用 `ord(code[num][i]) - 55` 转换。

（4）只要 `total` 仍为正数，就继续取个位并用整除10去掉已处理的个位，条件为 `total > 0`。
