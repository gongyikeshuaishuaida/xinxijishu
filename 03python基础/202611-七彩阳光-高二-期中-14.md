# 题目 14

某地图书馆管理系统针对每本在馆图书进行每日状态检测，每本图书的检测数据格式记为[x, y]，其中 x、y 分别为该图书的“可借状态”和“破损状态”值，0表示不具备该状态，1 表示具备该状态。如[0,1]表示该图书不可外借、处于破损状态。

现要编写程序，每天进行一次采集并检测图书状态是否存在如下异常：

第一类：可借状态与破损状态一致。即该图书同时标记为可借和破损，或同时标记为不可借和无破损；

第二类：状态超时。即该图书保持不可借且破损状态的时长超过上限值（如 7 天）。

检测到异常就发送对应警示信息。

请回答下列问题：

（1）若检测到某本图书同时标记为“可借和破损”，则采集到的数据是 ______（单选，填字母）。



- A. `[0,0]`



- B. `[0,1]`



- C. `[1,0]`



- D. `[1,1]`

（2）以下 Python 程序用于持续监测单本图书每日状态，请在划线处填入合适的代码。



```python
limit = 7    # 设置图书不可借且破损状态超时上限值（单位：天）
pre = [-1, -1]
broken = 0
while True:
    # 接收图书一次采集到的状态数据，存入 d，代码略
    if ______①______:
        if d[0] == 1:
            # 发送“状态异常：图书可借且破损”信息，代码略
        else:
            # 发送“状态异常：图书不可借且无破损”信息，代码略
    if d == [0, 1]:
        if pre == [0, 1]:
            broken += 1
        else:
            ______②______
        if ______③______:
            # 发送“状态异常：图书不可借且破损状态超时”信息，代码略
    else:
        broken = 0
    ______④______
    # 延时 1 天，代码略
```

---

## 答案

（1）D。

（2）① `d[0] == d[1]`；② `broken = 1`；③ `broken > limit`；④ `pre = d`。

---

## 解析

可借与破损状态一致时触发第一类异常。连续处于不可借且破损状态时累计天数，刚进入该状态记为第 1 天，超过上限才报警；每轮保存本轮状态供下一轮比较。
