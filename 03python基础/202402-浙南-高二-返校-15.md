# 题目 15

学校团委收集了某届学生在校三年期间的社团数据，每位学生每年选择一个社团，用于统计各社团间的关联次数。

![[attachments/202402-浙南-高二-返校-15_横排1_2.png]]

（1）根据关联次数排行榜，以下部分社团开设时段安排最合理的是 ______①______（单选，填字母）。

A．高一辩论社和法学社、高二书画社和诗词社、高三动漫社和摄影社

B．高一辩论社和书画社、高二诗词社和汉学社、高三飞羽社和魔方社

C．高一辩论社和摄影社、高二诗词社和飞羽社、高三书画社和魔方社

（2）定义 `proc` 函数，参数 `x` 表示某位学生三年所选的社团信息，函数将各社团名称依次存入列表 `lst`。

```python
def proc(x):
    x = x + "/"
    i = j = 0; lst = []
    n = len(x)
    while j < n:
        if x[j] == "/":
            lst.append(x[i:j])
            ______②______
            j += 1
    return lst
```

①请在划线处填入合适的代码。

②调用`proc(x)`，若`x`为`"魔方社/飞羽社/动漫社"`，则划线处语句的执行次数是 ______③______。

（3）定义如下 `freq` 函数，功能是统计列表 `x` 中各个不同社团间的关联次数。程序中加框处代码有错，请改正。

```python
def freq(x):

            m = st[x[i]]
            n = st[x[j]]

```


## 答案

**正确答案：** ① C；② `i = j + 1`；③ 3；④ `i + 1, len(x)`；⑤ `cur = proc(i[2])`

## 解析

关联次数高的社团应尽量错开时段，按图中排行比较三组选项可知 C 最合理。`proc` 每遇到一个斜杠就把当前名称加入列表，并将下一段起点移到斜杠后一位；三个社团名称对应三次执行。统计不同社团对时，内层循环必须从 `i+1` 开始，避免重复统计同一对及统计自身；主程序对每条学生记录的第三项社团字符串调用 `proc`。
