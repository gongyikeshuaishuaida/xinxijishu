# 题目 11

阅读下列材料，回答第 11 题。

某 Excel 文件记录了不同时间某农业大棚内的温度，导出某一天的部分数据如图所示，现需根据数据智能调控环境温度。

![[attachments/202509浙南高二_10_11_图.jpg]]

列表 `records` 中存储了大棚当日采集的 6 次温度数据，现编写以下 Python 程序：

```python
records = [
    "2025-03-07 06:00", 22.5,
    "2025-03-07 06:20", 25.3,
    "2025-03-07 07:00", 29.1,
    "2025-03-07 07:20", 31.2,
    "2025-03-07 08:20", 30.7,
    "2025-03-07 09:00", 23.5
]
c = 0; mt = 0
for i in range(0, len(records), 2):
    if records[i + 1] > 28:
        c += 1
    if records[i + 1] > mt:
        mt = records[i + 1]
```

执行该程序段后，`c` 和 `mt` 的值分别为（   ）

- A. `3，31.2`
- B. `3，22.5`
- C. `2，29.1`
- D. `2，31.2`

---

## 答案

**正确答案：** A

---

## 解析

循环每次跨过一个时间和一个温度，实际检查的温度依次为 22.5、25.3、29.1、31.2、30.7、23.5。其中超过 28℃ 的有 29.1、31.2、30.7，共 3 次；最大温度为 31.2℃，所以选 A。
