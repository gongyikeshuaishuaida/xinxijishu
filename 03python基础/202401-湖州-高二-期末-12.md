# 题目 12

有如下Python程序段：

```python
def half_s(s):
    n=len(s); result=""
    i,j=0,n-1
    while i<n//2 and j>=n//2:
        if s[i]>s[j]:
            result+=s[i]; i+=1
        elif s[i]<s[j]:
            result+=s[j]; j-=1
        else:
            i+=1; j-=1
    return result
```

执行 `v=half_s("welcome")`，变量 `v` 的值是（   ）

- A. `"come"`
- B. `"wmol"`
- C. `"www"`
- D. `"emo"`

---

## 答案

**正确答案：** B

---

## 解析

从两端向中间比较：`w>e`取w，`e<m`取m，`l<o`取o，`l>c`取l，得到字符串 `wmol`，故选B。
