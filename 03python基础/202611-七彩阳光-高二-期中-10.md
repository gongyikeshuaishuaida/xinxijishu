# 题目 10

有如下 Python 程序段：

```python
s = "Happy!2026"
ans = ""
for i in range(len(s)):
    ch = s[i]
    if "A" <= ch <= "Z":
        ch = chr(ord(ch) + 32)
    if "0" <= ch <= "9":
        ans = ans + str((int(ch) + i) % 10)
    else:
        ans = ch + ans
print(ans)
```

该程序运行后，输出的结果是（   ）

- A. !yppa8705

- B. !yppah8705

- C. happy!5078

- D. appy!5078

---

## 答案

**正确答案：** B

---

## 解析

非数字字符加到 ans 左边，数字按原下标加偏移后接到右边，结果为 !yppah8705。
