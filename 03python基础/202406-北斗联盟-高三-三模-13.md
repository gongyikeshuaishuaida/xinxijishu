# 题目 13

13.提取数字字符串中以逗号分隔的数字并转换为整数存入数组，再将数组中的元素分类：第一类为“小于 30”，第二类为“30～60”，第三类为“大于 60”。例如输入数字字符串 `"34, 23, 45, 99, 24, 56, 9,87，"`，输出结果为 `[23, 9, 24] [34, 45, 56] [87, 99]`。

```python
for i in range(len(s)):
    if s[i]!=",":
        ch+=s[i]
    if s[i]=="," or i==len(s)-1:
        a.append(int(ch))
        ______①______
i=0; j=len(a)-1; k=0
while k<=j:
    if ______②______:
        a[i],a[k]=a[k],a[i]
        i+=1
    elif a[k]>60:
        a[k],a[j]=a[j],a[k]
        j-=1
        ______③______
    k+=1
print(a[:i], a[i:j+1], a[j+1:])
```

（1）在划线处填入合适的代码。

（2）若两组输入的数据分别为 `"12,78,65,7,45,2,55,"`、`"12,78,65,7,45,2,55"`，则两组输出的结果（ ）。

- A.一致
- B.不一致

---

## 答案

**正确答案：** （1）① `ch=" "`；② `a[k]<30`；③ `k-=1`（或 `k=k-1`）。
（2）A

---

## 解析

每次遇到逗号或处理到字符串末尾，都要把当前数字转为整数并清空 `ch`。小于 30 的数交换到左侧，大于 60 的数交换到右侧；右侧交换后当前 `k` 位置仍需重新判断，所以 `k` 要减 1。带不带末尾逗号都会在最后一个数字处完成一次追加，输出一致。
