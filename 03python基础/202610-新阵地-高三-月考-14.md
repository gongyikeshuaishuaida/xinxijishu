# 题目 14

某高校设计的智慧供餐系统中有`n`台自动供餐设备（编号0~n-1），单台容量20份，初始各存10份。每到达1个批次的餐品需求时，系统按规则分配设备：从当前有足够剩余餐食（剩余份数≥需求份数）的设备中选择历史利用率最高的设备（历史利用率=该设备已累计供应份数÷单台容量）；若多台设备历史利用率同为最高，则选择编号最小的进行供餐；若没有设备满足需求，则暂时等候。系统会定时自动补充餐食，确保设备可持续工作。请回答下列问题：

（1）若系统中有3台设备，某时刻每台设备的剩余餐食份数和历史累计供应份数如第14题图所示。该时刻有一个需求批次需要供应4份餐食，那么被选中的设备编号为______。

![[attachments/202610新阵地高三_14_图1.png]]

（2）实现上述功能的部分Python程序如下，请在划线处填入合适的代码。

```python
def choose_device(need):
    max_rate = -1; id = -1
    for i in range(n):
        if ______①______:
            rate = items[i][1] / v
            if rate > max_rate:
                max_rate = rate; id = i
            elif rate == max_rate and i < id:
                id = i
    return id

"""
读取设备数量、每台设备容量依次存入变量n、v；读取每台设备的餐食情况存入列表items，

"""
reqs = []; ctime = 0
while True:

        if id != -1:
            items[id][0] -= reqs[0]

            reqs.pop(0)  # 移除reqs中的第一个元素
```

（3）若将上述代码中加框处语句删除，______（填字母：A．会/B．不会）影响程序的运行结果。

原卷加框处：

```python
elif rate == max_rate and i < id:
    id = i
```

---

## 答案

（1）0。

（2）①`items[i][0] >= need`；②`items[id][1] += reqs[0]`。

（3）B（不会）。

---

## 解析

（1）先筛选剩余份数足够的设备，再比较历史累计供应量与相同容量的比值；最高利用率相同时选择最小编号，因此选0。

（2）①确保设备剩余餐食满足本批次需求；②在移除队首请求之前，将供应份数累计到所选设备的历史供应量。reqs按先入先出处理，成功供应后删除队首。

（3）循环按编号从小到大遍历，第一次遇到最高利用率的设备已是其中编号最小者。后续利用率相等的设备编号更大，i<id不成立，因此这两行不会改变结果，删除后也不影响。
