# 题目 14

学生刷校园一卡通核验身份，访问图书馆智能书架系统。传感器每隔1秒读取一次当前被借阅书籍的book_id，根据检测结果发送相关信息给管理端，规则为：若检测到book_id等于-1，表示书籍未被取走，则发送“空状态”（send = -1）；若连续3次检测到book_id不等于-1，则发送该书籍的book_id。

（1）学生使用校园卡进行身份识别时用到的是______①______（单选，填字母：A.射频识别技术 / B.人体红外技术 / C.人脸识别技术 / D.蓝牙技术），其中该校园卡属于______②______（单选，填字母：A.有源标签 / B.无源标签）。

（2）实现上述功能的部分Python程序如下，请在划线处填入合适的代码。

```python
book_id = -1 ; send = -1 ; last = -1
cnt = 0 ; k = 3
while True:
    # 读取传感器数据 book_id，代码略
    if book_id == -1:
        send = -1
        print("发送",send)
        cnt, last = 0, -1
    else:
        if book_id != last:
            ______①______
        else:
            cnt += 1
        if ______②______:
            send = book_id
            print("发送",send)
            cnt = 0
        ______③______
```

---

## 答案

（1）①A；②B；（2）①`cnt = 1`；②`cnt == k`（或 `cnt >= 3`）；③`last = book_id`

---

## 解析

（1）校园一卡通通过读卡器以射频识别技术完成身份识别，故①选A；校园卡内部没有电源，靠近读卡器时靠感应获得能量工作，属于无源标签，②选B。

（2）①检测到与上次不同的book_id时，连续计数重新开始，填`cnt = 1`；②连续检测次数达到k（3次）即发送该书籍的book_id，填`cnt == k`（或`cnt >= 3`）；③每轮处理完非空状态后，都要把last更新为当前book_id，作为下一秒判断“是否同一本书”的依据，填`last = book_id`。
