# 题目 09

有如下 Python 代码段：

```python
s = input()
s1 = ""
for ch in s:
    if "a" <= ch <= "z":
        s1 = ch+s1
    else:
        s1 = s1+ch
print(s1)
```

若输入字符串为“82k9x3”，程序输出结果是（   ）

- A. xk8293
- B. 82k9x2
- C. 3x9k28
- D. 8293xk

---

## 答案

**正确答案：** A

---

## 解析

字母从左侧插入，其他字符从右侧追加。先插入 k 再插入 x，结果为 xk8293。
