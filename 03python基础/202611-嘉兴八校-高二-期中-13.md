# 题目 13

有如下程序段：

```python
sum = 0
for i in range(len(s)):
    if s[i] % 3 != 0:
        sum += s[i]
print(sum)
```

若 `s=[7,15,13,9,33,65,48,45,41,34]`，输出的结果是（   ）

- A. 300
- B. 310
- C. 160
- D. 150

---

## 答案

**正确答案：** C

---

## 解析

筛出 7、13、65、41、34，相加得 160。
