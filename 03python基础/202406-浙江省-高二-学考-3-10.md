# 题目 10

某 Python 程序如下：

    p = "A!@#$%&?B"
    c = "cra2edu"
    t = ""
    for i in range(len(c)//2+1):
        if i%2 == 0:
            t = t + c[len(c)-i-1]
        elif c[i] >= "0" and c[i] <= "9":
            t = t + p[int(c[i])]
        else:
            t = c[i] + t
    print(t)

程序运行后，输出结果是

- A. rue@
- B. cda!
- C. ure@
- D. arc!

---

## 答案

**正确答案：** A

---

## 解析

逐次跟踪 i=0、1、2、3：先取末尾 u，再在左侧加入 r，随后加入 e，最后将数字 2 映射为 p[2]=@，得到 rue@。
