# 题目 11

11. 有如下 Python 程序段：

```python
s = "绿水青山就是金山银山"
lst = ["A", "B", "C", "D"]
ans = ""

for i in range(len(s)):
    if s[i] == "山":
        ans = ans + lst[i % len(lst)]
    elif i % 2 == 1:
        ans = lst[i % len(lst)] + ans

print(ans)
```

执行该程序段后，输出的结果是（   ）

- A. `BDBDB`
- B. `BDDBB`
- C. `BBBDB`
- D. `BBDDB`

---

## 答案

**正确答案：** D

---

## 解析

按程序逐个处理字符串下标：下标为 1、5 的非“山”字符会把 `B` 插入到字符串左侧；下标为 3、7、9 的“山”分别在右侧追加 `D`、`D`、`B`。因此最终 `ans` 为 `BBDDB`，选 D。
