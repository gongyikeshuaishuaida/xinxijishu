# 题目 15

15. 校运会将至，各班级需要去超市预订 A、B、C 三种物品。某超市 A、B、C 三种物品的价格分别为 50 元/个、30 元/个、2 元/个。因学校规模和班级人数原因，各班级 A 种和 B 种物品需求量为 1—9 个，而 C 种物品需求量为 10—99 个。每两个班级的订单信息共同组成一个订单码，该订单码以第一个班级编号 `bj1` 和字符 `-` 开头，后面由物品种类及其数量组成，两个班级的信息编号以逗号分隔。

例如，订单码 `"bj1-A8B5C50,bj2-A3B6C90"` 表示班级 bj1 所订 A、B、C 产品数量分别为 8 个、5 个、50 个，班级 bj2 所订 A、B、C 产品数量分别为 3 个、6 个、90 个。请回答下列问题：

（1）若某订单码为 `"bj1-A2B1C17,bj2-A8B9C22"`，则该订单的两个班级的总花销为 ______①______ 元。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
def fi(s, b, e):
    expense = 0
    i = b
    while i <= e:
        if s[i] == "A":
            expense += int(s[i + 1]) * 50
            i += 2
        elif s[i] == "B":
            expense += int(s[i + 1]) * 30
            i += 2
        elif s[i] == "C":
            expense += ______②______
            i += 3
    return expense

s = input("请输入订单码：")
flag = False
i = 0
while i < len(s):
    if s[i] == "-" and ______③______:
        p = i
        flag = True
    elif s[i] == "-":
        q = i
    elif s[i] == ",":
        e = i
        total = ______④______
        ______⑤______
    i += 1
total += fi(s, q + 1, len(s) - 1)
print(total)
```

---

## 答案

**参考答案：**

- （1）`878`
- （2）② `int(s[i+1:i+3])*2`；③ `not flag`；④ `fi(s,p+1,e-1)`；⑤ `i+=1`

---

## 解析

第一个班级的花销为 `2×50+1×30+17×2=164` 元，第二个班级的花销为 `8×50+9×30+22×2=714` 元，总花销为 `878` 元。解析 C 类物品时数量占两个字符，因此取 `s[i+1:i+3]` 转为整数后乘 2。第一个短横线出现时 `flag` 为假，应记录其位置 `p` 并置位；逗号处先计算第一个班级区间 `p+1` 到 `e-1` 的花销，再令循环下标加 1，避免重复处理逗号位置。
