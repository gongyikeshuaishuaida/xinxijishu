# 题目 15

某物流公司受委托对客户下单的大件货品进行打包发货。货品 A、B、C 每件打包时间均为半小时，12:00 开始每隔 1 小时接受一次订单。货品按甲、乙、丙的顺序分配给各师傅处理，每位师傅一次打包一件货品；同一时间下单时，优先级越高（数字越小）的货品先全部打包完成。

### （1）

若某天订单如下表，甲的打包顺序为 3A5B1C，乙的打包报酬为多少元？

![[attachments/202403-强基联盟-高三-二模-15_横排1_2.png]]

### （2）

定义 `convert(data)` 函数，将订单转换成货品名称序列。例如订单 `2B1A1C` 转换成 `ABBC`。请填空。

```python
def convert(data):
    num, q = 0, ""
    qsort = ["", "", ""]
    for i in range(len(data)):
        if data[i] >= "0" and data[i] < "9":
            num = ______①______
        else:
            for j in range(num):
                q += data[i]
            qsort[ord(data[i]) - ord("A")] = q
            num, q = 0, ""
    s = qsort[0] + qsort[1] + qsort[2]
    return s
```

### （3）

主程序如下，请在划线处填空。

```python
goods = [30, 20, 10]
m = (18-12) * 2
b = [""] * m
a = [["12:00", "2B7A"], ["14:00", "7B"], ["15:00", "6B3C"]]

for i in range(len(a)):
    que = convert(______①______)
    x = (int(a[i][0][0:2]) - 12) * 2
    while len(b[x]) == 3:
        x += 1
    while len(que) > 0:
        t = 3 - len(b[x])
        if len(que) < t:
            t = len(que)
        b[x] = ______②______
        if t == len(que):
            que = ""
        else:
            que = que[t:]
        x += 1

s1, salary = "", 0
for i in range(m):
    if b[i] != "":
        s1 += b[i][0]
        salary += ______③______
```

## 答案

**正确答案：** （1）180；（2）① `num*10+int(data[i])`；（3）① `a[i][1]`；② `b[x]+que[0:t]`；③ `goods[ord(b[i][0])-ord("A")]`。

## 解析

`convert` 先把订单中的数量和货品字母转换为按优先级排列的字符序列。主程序以半小时为时间结点，每个时间点最多同时处理三件货品；`b` 记录每个时间点的三位打包序列，并把新订单接续在相应时间点。三位货品的单件报酬分别为 30、20、10 元，按表中订单分配后乙的报酬为 180 元；报酬累加时用货品字母索引 `goods`。
