# 题目 06

某校的智慧朗读系统按照以下规则实现音量提示功能：`30 ≤ v ≤ 80` 时记录“音量正常”，`v > 80` 时提示“音量过高”，`v < 30` 时提示“音量过低”。

第 05 题的规则流程图如下，作为本题的公共材料保留：

![[attachments/202609强基联盟高二_05_流程图.jpg]]

根据上述音量提示规则，下列 Python 程序段无法实现该功能的是（   ）

```python
# A
if v < 30:
    s = "音量过低"
elif v <= 80:
    s = "音量正常"
else:
    s = "音量过高"

# B
if v > 80:
    s = "音量过高"
if v >= 30:
    s = "音量正常"
if v < 30:
    s = "音量过低"

# C
if v > 80:
    s = "音量过高"
else:
    if v >= 30:
        s = "音量正常"
    else:
        s = "音量过低"

# D
if v > 80:
    s = "音量过高"
elif v >= 30:
    s = "音量正常"
else:
    s = "音量过低"
```

- A. 代码 A
- B. 代码 B
- C. 代码 C
- D. 代码 D

---

## 答案

**正确答案：** B

---

## 解析

代码 B 使用三个相互独立的 `if`。当 `v=85` 时，第一段先将 `s` 设为“音量过高”，随后第二个条件 `v >= 30` 成立，又把 `s` 覆盖为“音量正常”，结果错误。A、C、D 的分支能分别覆盖低音量、正常音量和高音量三种情况。
