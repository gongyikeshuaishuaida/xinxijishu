# 题目 13

某快递站点记录包裹的配送方式，用“0”表示上门配送，“1”表示驿站自提。现需从一天的配送记录中，找出最长的一段连续记录，要求这段记录中上门配送和驿站自提的包裹数量恰好相等。请回答下列问题：

（1）若给定记录为 `[0,1,0,1,1,0,0,1,0,1,0]`，则最长符合条件的连续记录长度为 ______。

（2）实现上述功能的 Python 程序如下，请在划线处填入合适的代码。

```python
# 读取包裹的配送方式数据，存入列表 nums，代码略。
______①______
for i in range(n):
    if nums[i] == 0:
        nums[i] = -1
d = {}
cur = ans = 0
for i in range(n):
    cur += nums[i]
    if ______②______:
        ans = i + 1
    if cur not in d:
        d[cur] = i
    else:
        tmp = ______③______
        if tmp > ans:
            ans = tmp
print(ans)
```

---

## 答案

(1) 10

(2) ①`n=len(nums)`；②`cur==0`；③`i-d[cur]`

---

## 解析

把0变为-1后，和为0表示两类数量相等；相同前缀和两次出现之间的区间和为0，用首次位置计算最长长度。
