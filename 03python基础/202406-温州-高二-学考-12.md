# 题目 12

某餐厅编写点餐程序，在查询框中输入字母后到“菜单.txt”中查询中文菜品名。菜单文件和查询过程如下图。

![[attachments/202406-温州-高二-学考-12_横排1_2.png]]

（1）若输入 `sz`，则查询到的菜品数量为 ______①______ 个。

（2）定义 `suoxie` 函数提取拼音首字母，如 `suoxie("gong bao ji ding")` 返回 `"gbjd"`，请填空：

```python
def suoxie(name):
    res = ""
    flag = True
    for i in range(len(name)):
        if name[i] != " " and flag:
            ______②______
            flag = False
        elif name[i] == " ":
            flag = True
    return res
```

（3）将 `menu` 中所有拼音替换为缩写：

```python
def convert(menu):
    for i in range(1, len(menu), 2):
        menu[i] = ______③______
    return menu
```

（4）定义 `search` 函数，输入字母并返回中文菜名：

```python
for i in range(1, len(menu), 2):
    k = 0
    for ch in menu[i]:
        if ch == key[k]:
            k += 1
        if ______④______:
            res += menu[i - 1] + " "
            break
```

---

## 答案

**正确答案：** ①1；②`res += name[i]`；③`suoxie(menu[i])`；④`k == len(key)`

---

## 解析

菜单中“水煮肉片”的拼音首字母缩写为 `szrp`，只有它包含按顺序匹配的 `s`、`z`，因此输入 `sz` 得到 1 个菜品。`suoxie` 在每个单词首字符处追加到 `res`；`convert` 对奇数下标的拼音调用该函数；搜索时累计匹配字符数达到输入长度即可返回该菜名。
