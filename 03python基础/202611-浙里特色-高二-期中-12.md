# 题目 12

有如下 Python 程序段：

```python
from random import randint
a = [0]*6
flag = True
i = 0
while i <= 5:
    x = randint(1,40)
    if flag or x > 20:
        a[i] = x
        flag = not flag
        i += 1
print(a)
```

该程序段运行后，输出的结果不可能是（   ）

- A. `[7,31,15,22,36,25]`
- B. `[12,26,8,19,33,28]`
- C. `[35,24,11,30,17,22]`
- D. `[5,29,21,32,14,23]`

---

## 答案

**正确答案：** B

---

## 解析

下标 0、2、4 不限制大小；下标 1、3、5 的值必须大于 20。B 的下标 3 为 19。
