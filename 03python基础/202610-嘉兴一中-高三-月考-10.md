# 题目 10

有如下 Python 程序段，已知 s 为非空字符串：

```python
n = len(s); m = c = 1
for i in range(n-1):
    if s[i]==s[i+1]:
        c += 1
    else:
        if c>m:
            m=c
        c=1
if c>m:
    m=c
print(m)
```

该程序段的功能是（   ）

- A. 输出字符串中最长连续相同字符子串的长度
- B. 输出字符串中最长重复子串的长度
- C. 输出字符串中最长连续子串的长度
- D. 输出字符串中第一个连续相同字符的长度

---

## 答案

**正确答案：** A

---

## 解析

c 记录当前连续相同字符段长度，m 保存已经遇到的最大长度，循环后还会检查末段。
