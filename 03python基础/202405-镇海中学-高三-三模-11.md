# 题目 11

有如下 Python 程序段：

```python
import random

def select(s, k):
    for i in range(k):
        j = i + 1
        if j < len(s):
            s = s[:j] + s[j + 1:]
        else:
            s = s[:len(s) - 1]
        connect(i, s, k)

def connect(i, s, k):
    list1 = ''
    if i < k - 1:
        list1 = list1 + s + '-'
    else:
        list1 = list1 + s
    print(list1, end='')

s = 'hello'
k = random.randint(1, 4)
select(s, k)
```

执行后，输出结果可能是（ ）

- A.`hllo-`
- B.`hllo-hll-hl`
- C.`hllo-hlo`
- D.`hllo-hlo-hl-`

---

## 答案

**正确答案：** C

---

## 解析

当 `k=2` 时，第一次 `j=1` 删除原字符串下标 1 的 `e`，得到 `hllo-`；第二次 `j=2` 删除当前字符串下标 2 的 `l`，得到 `hlo`，输出拼接为 `hllo-hlo`，因此 C 是可能结果。其他选项的删除次数、连字符位置或字符串长度与程序不符。
