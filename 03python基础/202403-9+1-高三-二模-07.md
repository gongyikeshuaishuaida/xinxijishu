# 题目 07

噪声分贝 `zs` 的规则是：30dB 以下为“安静”，30dB～40dB 为“较安静”，超过 40dB 为“较吵”。下列选项能正确表示这三种情况的是（  ）

- A.

```python
ans = "安静"
if zs >= 30:
    ans = "较安静"
elif zs > 40:
    ans = "较吵"
```

- B.

```python
ans = "较吵"
if zs < 30:
    ans = "安静"
elif zs <= 40:
    ans = "较安静"
```

- C.

```python
if zs <= 40:
    ans = "较安静"
elif zs > 40:
    ans = "较吵"
```

- D.

```python
ans = "较安静"
if not zs < 30:
    ans = "较吵"
else:
    ans = "安静"
```

## 答案

**正确答案：** B

## 解析

B 先将默认状态设为“较吵”，小于 30 时改为“安静”，30～40 时改为“较安静”，超过 40 时保持“较吵”，覆盖了三个互斥区间。
