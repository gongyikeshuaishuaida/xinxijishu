# 题目 13

无人驾驶出租车在行驶过程中通过传感器持续检测车辆偏离车道中心线的横向偏移值，并判断是否发生车道偏离事件。设定偏移阈值为0.3米，判断规则如下：

\- 单次偏移绝对值 >0.3 ，代表车辆当前偏离车道；

\- 为过滤传感器噪声，只有连续2次检测都出现偏离，才算发生1次“车道偏离事件”；

\- 连续偏离一旦被判定为事件后，后续新的连续2次偏离才统计为下一次事件。

现有一组车辆相对于车道中心线的横向偏移数据存入列表 olist 中, 编写 Python 程序统计总共发生车道偏离事件的次数。

（1）实现上述功能的 Python 程序如下，请在划线处填入合适的代码。

```python
olist = [0.1,0.4,0.35,-0.1,0.5,-0.6,0.1]
event = 0
pre = False    # pre 标记上一次检测是否发生偏离
for off in olist:
    if ______①______:
        cur = True
    else:
        cur = False
    if cur and pre:
        ______②______
        pre = False
    elif cur:
        pre = True
    else:
        ______③______
print("车道偏离事件数量：", event)
```

（2）若当前的横向偏移数据为 `[-0.1,0.5,-0.3,0.4,0.35,-0.45,0.2,0.5]`，则统计出来发生的车道偏离事件为 ______ 次。

---

## 答案

（1）① `abs(off)>0.3`，② `event += 1`，③ `pre=False`。

（2）1。

---

## 解析

绝对值恰好为 0.3 时不计偏离。连续两次偏离组成一次事件后将 pre 清零，避免重叠计数。第二问只有 0.4、0.35 配成一对，-0.45 与其后 0.2 不成对。
