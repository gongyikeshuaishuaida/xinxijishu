# 题目 14

有如下程序段：

```python
s = "a12b345c67d890"
cur = maxn = 0
for ch in s:
    if "0" <= ch <= "9":
        cur = cur * 10 + int(ch)
    else:
        if cur > maxn:
            maxn = cur
        cur = 0
print(maxn)
```

执行该程序后，输出的结果是（   ）

- A. 345
- B. 890
- C. 67
- D. 12

---

## 答案

**正确答案：** A

---

## 解析

只有读到非数字字符才比较和清零，最后一段 890 在字符串结尾，打印的最大值仍是 345。
