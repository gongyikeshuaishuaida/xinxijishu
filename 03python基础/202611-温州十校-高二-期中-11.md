# 题目 11

某校运动会报名结束后，7个班级的报名人数存放在列表 `a` 中。小明编写了如下程序：

```python
a = [18, 21, 17, 20, 22, 16, 19]
m = a[0]
s = 0
for x in a:
    if x > m:
        m = x
    s = s + x
ave = s / len(a)
print(m, ave)
```

下列关于该程序，说法正确的是（   ）

- A. 用于统计班级报名人数中的最小值和平均值

- B. 将 `m = a[0]` 改为 `m = 0`，程序输出的第一个结果变为0

- C. 将 `s = s + x` 移入if语句内部，程序输出的平均人数不变

- D. 将 `ave = s / len(a)` 移入for循环语句内部，程序输出的ave结果不变

---

## 答案

**正确答案：** D

---

## 解析

程序求最大值和平均值。把ave计算移入for内，最后一次仍使用完整累计和与固定总人数，因此最终结果不变。把求和移入if会漏掉未刷新最大值的元素。
