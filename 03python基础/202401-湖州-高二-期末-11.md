# 题目 11

有如下Python程序段：

```python
c,m=0,0
for i in range(2,len(a)):
    if a[i-2]+a[i-1]==a[i]:
        c+=1
    if c>m:
        m=c
    else:
        c=0
```

若列表 `a=[2,1,3,4,5,9,14,23]`，执行后变量 `m` 的值是（   ）

- A. 0
- B. 1
- C. 2
- D. 3

---

## 答案

**正确答案：** D

---

## 解析

程序逐项检查相邻两项之和是否等于下一项。序列中`2+1=3`、`1+3=4`、`3+4=7`不等于5，随后`4+5=9`、`5+9=14`、`9+14=23`连续成立，连续计数的最大值为3，故选D。
