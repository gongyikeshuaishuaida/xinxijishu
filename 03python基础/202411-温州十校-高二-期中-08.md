# 题目 08

BMI 指数的计算方法为 `BMI=体重/身高²`。小明编写了如下 Python 程序，哪个选项填入横线处算出的 BMI 值是错误的？

~~~python
import math
sg=float(input('请输入身高(米):'))
tz=float(input('请输入体重(公斤):'))
BMI=______①______
~~~

- A. `tz/sg/sg`
- B. `tz/math.pow(sg,2)`
- C. `tz/sg**2`
- D. `tz/sg*sg`

## 答案

**正确答案：** D

## 解析

除法和乘法具有相同优先级，按从左到右计算。`tz/sg*sg` 实际等于 `tz`，不是 `tz/(sg**2)`；A、B、C 都正确实现了体重除以身高平方。
