# 题目 12

有如下Python程序段:

```python
from random import randint
st = [randint(1, 10) for i in range(10)]
i = 0 ; t = 0
while i < len(st):
    f = st[i] ; g = st[i + 1]
    if f >= t:
        n = i
    t = g
    i += 2
```

执行后n的值为4，则下列表达式的值一定为True的是（   ）

①`st[4] >= st[3]`    ②`st[5] > st[6]`    ③`st[5] < st[7]`

- A. ①②③
- B. ①③
- C. ②③
- D. ①②

---

## 答案

**正确答案：** D

---

## 解析

程序每次处理下标为偶数的位置，n记录最近一次`st[i] >= t`成立的i，且每轮结束时t都更新为`st[i+1]`。n=4说明i=4时`st[4] >= t`成立，而此时t是上一轮（i=2）更新的`st[3]`，故①`st[4] >= st[3]`一定为True；i=6时若`st[6] >= t=st[5]`成立，n将被更新为6，与n=4矛盾，故`st[6] < st[5]`，②一定为True；程序中从未将st[7]与st[5]比较，③不一定成立。故选D。
