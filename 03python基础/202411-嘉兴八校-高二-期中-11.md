# 题目 11

有如下 Python 程序段：

~~~python
s = 0
for i in range(100):
    if i%10 != 0:
        continue
    if s >= 66:
        break
    s += i
~~~

11. 执行程序段后，输出的 i 和 s 分别是（   ）

- A. 100，66
- B. 99，66
- C. 40，100
- D. 50，100

---

## 答案

**正确答案：** D

---

## 解析

只有10的倍数会执行后续语句。i依次为0、10、20、30、40时，s依次变为0、10、30、60、100；下一次遇到i=50时，先判断 s>=66，条件成立而执行 break，因此输出 i=50、s=100。
