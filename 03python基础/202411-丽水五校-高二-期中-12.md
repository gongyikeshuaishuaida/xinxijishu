# 题目 12

12. 已知数组 `a` 中包含若干整数，现要统计其中连续出现最多的数字的出现次数。若有多个数字连续出现次数相同且最多，则输出最先出现的那个数字和出现次数。Python 程序段如下，则方框中的语句应为（   ）

```python
cnt,m,num = 1,1,a[0]
for i in range(1,len(a)):
    if nums[i] == nums[i - 1]:
```

上面条件行中的 `nums` 为试卷原文排版，结合题干和选项按数组 `a` 理解。

- A.

  ```python
  if a[i]==a[i-1]:
      cnt+=1
      if cnt>=m:
          m=cnt
          num=a[i]
  else:
      cnt=1
  ```

- B.

  ```python
  if a[i]==a[i-1]:
      cnt+=1
      if cnt>m:
          m=cnt
          num=a[i]
  else:
      cnt=1
  ```

- C.

  ```python
  if a[i]==a[i+1]:
      cnt+=1
  else:
      if cnt>m:
          m=cnt
          num=a[i]
      cnt=1
  ```

- D.

  ```python
  if a[i]==a[i-1]:
      cnt+=1
  else:
      if cnt>=m:
          m=cnt
          num=a[i-1]
      cnt=1
  ```

---

## 答案

**正确答案：** B

---

## 解析

相等时先把当前连续段长度 `cnt` 加 1；只有当新长度严格大于历史最大值 `m` 时才更新 `num`，才能在并列时保留最先出现的数字。遇到不同数字时将 `cnt` 重置为 1。A 和 D 使用 `>=` 会覆盖并列时的先出现结果，C 的比较对象及更新时机也不正确。
