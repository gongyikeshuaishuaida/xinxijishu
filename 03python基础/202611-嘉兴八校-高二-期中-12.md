# 题目 12

某 Python 程序如下：

```python
s = "school"
ans = ""
n = len(s)
for i in range(n//2, 0, -1):
    if s[i-1] > s[n-i]:
        ans = ans + s[n-i]
    else:
        ans = s[i-1] + ans
print(ans)
```

执行该程序段后，输出的结果是（   ）

- A. "chl"
- B. "hcl"
- C. "clh"
- D. "lch"

---

## 答案

**正确答案：** A

---

## 解析

i 依次为 3、2、1，三次分别得到 h、ch、chl。
