# 题目 12

12.物品柜有 n 个格子，存放时选编号最小的空格子，取出时从编号最大的格子中取出指定物品。

![[attachments/202406-嘉兴-高二-期末-12_横排1_2.png]]

（1）在图示基础上再进行操作 (2,B:2)、(1,C:2)、(1,D:1)，编号为 4 的格子中货物名称为 ______①______。

（2）主程序中，读取操作字符串的代码为 ______②______：

~~~python
s=input("请输入操作：")
while s!="Q":
    xh=______②______
    gname=s[2]
    num=int(s[4:])
~~~

（3）putx() 函数中补充：

~~~python
def putx(gname,num):
    cnt=0
    for i in range(n):
        if lst[i]=="":
            ______③______
            cnt+=1
            if cnt==num:
                break
    if ______④______:
        print("已放满！还有",num-cnt,"个未放。")
~~~

（4）getx() 函数中补充：

~~~python
def getx(gname,num):
    p=n-1
    cnt=num
    while num>0:
        while ______⑤______:
            p-=1
        if p>=0:
            lst[p]=""
            ______⑥______
        else:
            print("货物数量不足！取出",cnt-num,"个。")
            break
~~~

---

## 答案

**正确答案：** ①C；②s[0]；③lst[i]=gname；④cnt<num；⑤p>=0 and lst[p]!=gname；⑥num-=1

---

## 解析

继续操作后，格子 4 的物品为 C。主程序取操作首字符 s[0]；放入时找到空格就写入物品名，若成功数量不足 num 则提示剩余数量；取出时从后往前跳过非目标物品，找到目标后清空并令 num 减 1。
