# 题目 08

水库的水位正常范围为（minL～maxL），现用变量 wL、stage 表示测量水位值和水位状态。变量 stage 值 0、1、2 分别表示水位状态为正常、偏低、偏高。下列 Python 程序段中符合要求的是（   ）

- A.

    ```python
    if wL < minL:
        stage = 1
    if minL <= wL <= maxL:
        stage = 0
    else:
        stage = 2
    ```

- B.

    ```python
    stage = 0
    if wL > maxL:
        stage = 2
    else:
        stage = 1
    ```

- C.

    ```python
    if wL >= minL:
        if wL <= maxL:
            stage = 0
        else:
            stage = 2
    else:
        stage = 1
    ```

- D.

    ```python
    stage = 2
    if wL >= minL:
        if wL <= maxL:
            stage = 0
    else:
        stage = 1
    ```

---

## 答案

**正确答案：** C

---

## 解析

C 按低于下限、区间内、高于上限正确分类；其他写法的 else 归属或初值会造成覆盖、漏判。
