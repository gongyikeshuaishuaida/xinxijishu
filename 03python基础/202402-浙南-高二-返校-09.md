# 题目 09

校门口路段的通行状态是：放学后，30 分钟内“拥堵”，之后“慢行”，50 分钟后“畅通”。设 `t` 为放学后的时长（单位：分钟），`p` 为通行状态，下列代码描述不正确的是（  ）

- A.

```python
p = "畅通"
if t <= 50:
    p = "慢行"
elif t < 30:
    p = "拥堵"
```

- B.

```python
p = "拥堵"
if t >= 30:
    p = "慢行"
if t > 50:
    p = "畅通"
```

- C.

```python
p = "畅通"
if t <= 50:
    if t < 30:
        p = "拥堵"
else:
    p = "慢行"
```

- D.

```python
if t > 50:
    p = "畅通"
elif t >= 30:
    p = "慢行"
else:
    p = "拥堵"
```

## 答案

**正确答案：** A

## 解析

A 先判断 `t<=50`，会把 30 分钟以内的状态也设为“慢行”，后面的 `elif t<30` 不会执行；B、C、D 能按时间区间给出相应状态。
