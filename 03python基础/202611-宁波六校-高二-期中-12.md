# 题目 12

有如下 Python 程序段：

```python
from random import *
num = [1,3,5,7,9,11,13]
k = len(num)
total = 0
cnt = 0
f = -1
while cnt < 4:
    m = randint(0, k-1)    # 生成[0, k-1]的随机整数
    t = randint(0, 1)
    if t % 2 == 1 or f == -1:
        total += num[m]
        num[m] = num[k-1]
        k -= 1
    if t == 0:
        f = -f
        cnt += 1
print(total)
```

以下说法正确的是（   ）

- A. 输出的结果一定是奇数
- B. 输出的结果可能是5
- C. 输出的结果不可能是9
- D. 若输出的值为11，k的值一定为4

---

## 答案

**正确答案：** D

---

## 解析

循环中 t 为 0 才增加 cnt。四次翻转时，f 为 -1 的两次必选，另外可在 t 为 1 时选取。11 只能由三个不同的正奇数相加得到，因此还剩 4 个元素。
