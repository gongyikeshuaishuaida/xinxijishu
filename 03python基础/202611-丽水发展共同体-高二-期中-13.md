# 题目 13

某园区门禁人流监测系统每秒采集门口进出人数，若在 30秒内（共采集 30 次）检测到连续有人进入，且连续人数累加的最大值超过 25 人判定为高峰人流，门禁开启双通道，开门时长 30 秒后自动切换回单通道。例：检测数据 [3,1,0,4,2,0,1]，一共检测 7次，每次人数依次为 3、1、0、4、2、0、1，连续人数累加最大值为 6。请回答下列问题：

（1）若 10 次检测人流数据为 `[4,0,1,5,2,0,2,3,0,6]`，则持续累加数量最大是 ______。

（2）实现上述功能的部分 Python 程序，请在划线处填入合适代码。



```python
while True:
    cur = 0
    maxn = 0
    for i in range(30):
        # 接收监控检测到的人数存入 n，代码略
        if n > 0:
            cur += n
            if ______①______:
                maxn = cur
        else:
            ______②______
        # 延时 1 秒，代码略
    if ______③______:
        # 发送高峰人流，开启双通道，代码略
    else:
        # 普通人流，开启单通道，代码略
    # 等待本轮门禁周期结束，继续下一轮监测
```

---

## 答案

（1）8。

（2）① `cur > maxn`；② `cur = 0`；③ `maxn > 25`。

---

## 解析

用 0 分隔连续进入人流，各段累计值为 4、8、5、6，最大为 8。cur 记录当前连续段的累计人数，检测到 0 时清零；maxn 保存整个监测周期中的最大值，超过 25 才开启双通道。
