# 题目 09

下列 Python 表达式的值为 True 的是（   ）

- A. `len('2+3') < 2`
- B. `ord('a') - ord('A') == 20`
- C. `'a' in {'a': 'apple', 'b': 'banana'}`
- D. `int(max("5", "11", "100")) == 100`

## 答案

**正确答案：** C

## 解析

字典的 `in` 运算判断键，`'a'` 是字典的键，所以 C 为真。`len('2+3')` 为 3，大小写字母编码差为 32，字符串 `max` 按字典序比较也不能得到 D 的等式。
