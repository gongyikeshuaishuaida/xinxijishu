# 题目 14

图书馆智能座位管理系统持续记录学生每日的选座位置（包括：“窗边”、“走廊边”、“中间”）。系统分析学生连续 n(n>2) 天的选座偏好。当 n 天内某位置出现次数不少于 n-1 次，且与当前偏好不同时，系统自动更新偏好为该位置；若没有位置满足次数条件，则保持原偏好。

(1) 设 n = 4 ，某学生当前偏好为“中间”，接下来连续7天的选座记录为：“窗边、窗边、窗边、走廊边、窗边、中间、窗边”。系统从第1天开始，依次以每连续4天为单位进行分析，系统最终偏好将更新为____。

(2) 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
n=4; current="中间"
choices=["窗边","窗边","窗边","走廊边","窗边","中间","窗边"]
for start in range(len(choices)-n+1):
    w=______①______
    for loc in ["窗边","走廊边","中间"]:
        cnt=0
        for i in range(n):
            if w[i]==loc:
                cnt+=1
        if ______②______:
            if loc!=current:
                ______③______
            break
```

---

## 答案

（1）窗边。

（2）① `choices[start:start+n]`，② `cnt>=n-1`，③ `current=loc`。

---

## 解析

前四天有三次窗边，达到阈值 3，更新为窗边。之后的窗口没有让其他位置达到阈值。切片右端 start+n 不含在窗口内。
