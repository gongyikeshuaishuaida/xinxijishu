# 题目 11

用 Python 算法控制结构描述“水库水位：水位超过警戒值2.5m时发出预警；水位高于3.8m时发出紧急警报”，设 `h` 为当前水位（单位：m），下列选项正确的是（   ）

- A. ```python
if h > 2.5:
    print("预警")
elif h > 3.8:
    print("紧急警报")
```


- B. ```python
if h > 3.8:
    print("紧急警报")
else:
    print("预警")
```


- C. ```python
if h > 2.5 and h <= 3.8:
    print("预警")
else:
    print("紧急警报")
```


- D. ```python
if h > 3.8:
    print("紧急警报")
elif h > 2.5:
    print("预警")
```

---

## 答案

**正确答案：** D

---

## 解析

应先判断更高水位，再判断较低警戒水位；h≤2.5不预警。A使紧急分支无法进入，B/C会在安全水位也报警。
