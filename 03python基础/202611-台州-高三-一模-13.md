# 题目 13

在某环境监测系统中，智能终端每 t 秒采集一次温度数据，将连续采集到的 m 个数据上传至服务器。上传数据前需对这 m 个数据进行合理性验证，合理范围为 -10～60℃（包含 -10℃ 和 60℃）。若 m 个数据均在合理范围内，则直接上传；若 m 个数据均超出合理范围，则不上传；若 m 个数据中存在异常，则需对数据进行清洗后再上传（连续异常数据，采用相同处理方法）。m 为 5 时，数据清洗过程如第 13 题图所示。

![[attachments/202611台州高三_13_图1.png]]

请回答下列问题:

(1) 若 m 为 6，某次连续采集的温度数据序列为 “25, 30, -50, 200, 40, 68”，经过清洗后，温度数据序列为____。

(2) 实现上述功能的部分 Python 程序如下, 程序中加框处代码有错, 请改正。

（3）请在划线处填上合适的代码。

```python
s = []
# 获取 m 值，代码略
while True:
    # 获取温度数据保存到变量 x，代码略
    s.append(x)    # 为列表 s 追加一个元素 x
    if len(s) == m:
        b = []    # 将 s 中异常数据段的起止索引位置，以区间形式存入列表 b
        # 如 s=[5,70,-15,68,9,-19,13]，处理后 b=[[1,3],[5,5]]
        for i in range(m):
            if s[i] < -10 or s[i] > 60:
                if len(b)>0 and b[-1][1]+1==i:
                    b[-1][0]=i    # 改错，原卷加框
                else:
                    b.append([i,i])
        if b != [[0,m-1]]:    # m个数据中存在正常数据

                left=x[0]-1; right=x[1]+1
                if left>=0 and right<len(s):
                    t=______①______
                elif left>=0:
                    t=s[left]
                elif right<len(s):
                    t=s[right]
                for i in range(______②______):
                    s[i]=t    # 替换异常数据
            # 将温度数据序列 s 上传到服务器，代码略
        s=[]
    # 延时 t 秒，代码略
```

---

## 答案

（1）25，30，35，35，40，40。

（2）`b[-1][1]=i`。

（3）① `(s[left]+s[right])/2`，② `left+1,right`。

---

## 解析

连续异常 -50、200 的两侧为 30、40，替换成均值 35；末尾的 68 只有左侧正常值 40。扩展异常段时应更新终点。左、右正常值之间的范围在 range 中写为左端加一、右端不含。
