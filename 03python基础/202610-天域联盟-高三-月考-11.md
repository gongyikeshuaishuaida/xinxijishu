# 题目 11

某Python程序段如下，列表`a`中存有10个互不相等的整数。

```python
p,q = 0,0
for i in range(1,len(a)):
    if a[i] < a[q]:
        q = i
    else:
        p = i
```

执行该程序段后`p`的值为3，则下列表达式中一定为`True`的有

① `a[4]<a[3]`　② `a[4]<a[0]`　③ `a[5]<a[4]`　④ `a[0]<a[4]`（   ）

- A. 1个
- B. 2个
- C. 3个
- D. 4个

---

## 答案

**正确答案：** C

---

## 解析

`q`保存当前最小元素下标。p最终为3说明i=4至9都进入if，各项不断刷新最小值。所以a[4]小于此前所有项，a[5]又小于a[4]，①②③均真，④假。
