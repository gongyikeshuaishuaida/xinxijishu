# 题目 12

12.某 Python 程序统计输入字符串中各字符出现次数，再用随机数决定是否输出字符：

```python
n = input("请输入一串字符")
f = [0] * 128
for i in n:
    f[ord(i)] += 1
for i in n:
    if f[ord(i)] == random.randint(0, 1):
        print(i, end="")
```

若输出结果为 `xyz3`，则输入可能是（ ）

- A. `yazabcx3`
- B. `auxYZ33`
- C. `axaybbzc3`
- D. `xyaaxbbz3c`

---

## 答案

**正确答案：** C

---

## 解析

输出中的每个字符需要在输入中只出现 1 次，且随机数可能取到 1；C 中 `x、y、z、3` 均只出现一次，其他字符重复，存在输出 `xyz3` 的可能，故选 C。
