# 题目 13

长桌上盘子和蜡烛排成一列。如果一个盘子的左边和右边都至少有一支蜡烛，那么这个盘子满足“在两支蜡烛之间”。字符串 `s` 只包含字符“*”和“|”，其中“*”表示盘子，“|”表示蜡烛。示例统计如下图所示：

![[attachments/202408A9协作体_13_盘子蜡烛统计图.jpg]]

编写程序，输入变量 `lefti` 和 `righti`，统计子字符串 `s[lefti:righti+1]` 中在两支蜡烛之间的盘子数目。请回答下列问题：

（1）若排列情况为“**|**|***|”，`lefti` 和 `righti` 分别为 5 和 9，该范围中在两支蜡烛之间的盘子数目为 ______。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码：

```python
# 读取桌子上的盘子和蜡烛排列情况存入 s，读取 lefti 和 righti，代码略

______①______
ps = [0] * (n + 1)  # ps[i+1] 存储 s[:i+1] 中盘子的总数
left = [0] * n       # left[i] 存储 i 左侧最近蜡烛位置
right = [0] * n
c, res = -1, 0
for i in range(n):
    ch = s[i]
    if ch == "|":
        c = i
        ps[i + 1] = ps[i]
    else:
        ______②______
    left[i] = c
c = n
for i in range(n - 1, -1, -1):
    if s[i] == "|":
        c = i
    right[i] = c
L, R = right[lefti], left[righti]
if ______③______:
    res = ps[R + 1] - ps[L + 1]
print("桌子上盘子和蜡烛排列情况：", s)
print("子字符串 s[", lefti, ":", righti + 1, "]中在两支蜡烛之间的盘子的数目：", res)
```

---

## 答案

**正确答案：** （1）3；（2）① n = len(s)；② ps[i + 1] = ps[i] + 1；③ L < R

---

## 解析

left 和 right 分别记录每个位置左右最近蜡烛下标，ps 为盘子数量前缀和。查询区间内存在左右蜡烛且 L<R 时，ps[R+1]-ps[L+1] 即两支蜡烛之间的盘子数。
