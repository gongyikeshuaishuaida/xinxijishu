# 题目 14

14.密码强度规则包括数字、符号、长度和字母，安全等级按总得分划分。

![[attachments/202406衢州高一_14_密码评分规则表.jpg]]

（1）密码 A3abc791 的安全等级为 ______①______（强 / 中 / 弱）。

（2）补充程序：

~~~python
def length(pwd):
    if ______②______:
        return 25

def letter(pwd):
    x,y=0,0
    for i in pwd:
        if "a"<=i<="z":
            x=10
        elif ______③______:
            y=10
    return ______④______
~~~


---

## 答案

**正确答案：** ①中；②len(pwd)>=8；③'A'<=i<='Z'；④x+y

---

## 解析

密码含多个数字得 20 分，长度为 8 得 25 分，大小写字母混合得 20 分，无符号得 0 分，总分 65，属于 50≤总分<75 的“中”等级。长度条件为 len(pwd)>=8；大写字母条件为 'A'<=i<='Z'；字母得分为 x+y。
