# 题目 9

有如下两段 Python 程序：

```python
def fact1(n):
    s = 0
    while n != 0:
        s += n % 2
        n = n // 2
    return s

def fact2(n):
    if n == 1:
        return 1
    else:
        return ______①______
```

对于任意正整数 `n`（`n>=2`），两个函数的返回值相等，则方框处的代码是

- A. `n%2+fact2(n//2)`
- B. `str(n%2)+fact2(n//2)`
- C. `fact2(n%2)+str(n//2)`
- D. `n//2+fact2(n%2)`

## 答案

**参考答案：** A

## 解析

`fact1` 统计整数二进制表示中 1 的个数。递归函数每次取 `n%2` 作为最低位，再对 `n//2` 继续统计，故应写成 `n%2+fact2(n//2)`。
