# 题目 13

假设 `maxn` 是一段字符串中出现次数最多的字母的出现次数，`minn` 是该段字符串中出现次数最少的字母的出现次数。如果 `maxn` 与 `minn` 之差恰好是一个完美数，就认为这个字符串是 Lucky string，否则不是。完美数是一个正整数，它的所有真因子（除了其自身以外的因子）之和等于它自己，例如 28 的真因子为 1、2、4、7、14。

实现上述功能的部分 Python 程序如下：

~~~python
sentence=input("请输入一段字符串：")
def process_sentence(s):
    dic={}
    for char in s:

#主程序
num=process_sentence(s)
~~~

（1）根据题意，如果输入“Where there is a will,there is a way.”，该字符串 ______④______（填：是/否）为 Lucky string。

（2）为实现上述功能，请在 ①②③ 划线处填入合适的代码。

（3）程序加框处代码有错误，请改正：`num=process_sentence(s)` 应改为 ______⑤______。

## 答案

**正确答案：** ① `dic[char]+=1`；② `n%i==0`；③ `sum==n`；④ 否；⑤ `num=process_sentence(sentence)`。

## 解析

忽略空格、标点后按大小写区分字母，该字符串中最多出现 6 次的字母为 `e`，最少出现 1 次的字母为大写 `W`、`y` 等，差值为 5，不是完美数，所以答案为“否”。字典中已有字符时计数加 1；枚举 `1` 到 `n-1`，把能整除 `n` 的真因子累加，最后判断因子和是否等于 `n`。主程序应把输入变量 `sentence` 传给函数，不能使用未定义的 `s`。
