# 题目 08

有如下 Python 程序段：

```python
Lst1=["周杰伦","林俊杰","薛之谦","邓紫棋","毛不易"]
Lst2=Lst1[1:]
print("循环单曲",Lst2[1][1]+Lst2[2][2])
```

运行程序后，输出的结果是（   ）

- A. 循环单曲 周俊
- B. 循环单曲 林之
- C. 循环单曲 之棋
- D. 循环单曲 俊谦

---

## 答案

**正确答案：** C

---

## 解析

切片从“林俊杰”开始，下标 1 的第二字与下标 2 的第三字相连得到“之棋”。
