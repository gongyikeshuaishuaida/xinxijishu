# 题目 10

有如下 Python 程序段：

```python
s = input("输入字符串:")
s1 = ""; flag = False
for i in range(1, len(s)):
    if ord(s[i-1]) + 1 == ord(s[i]) and not flag:
        s1 = s1 + s[i-1] + "-"
        flag = True
    elif ord(s[i-1]) + 1 != ord(s[i]):
        s1 = s1 + s[i-1]
        flag = False
    s1 = s1 + s[i]
print(s1)
```

程序运行时，若输入 `234ac5mnoq`，则输出结果是

- A. `2-4a-c5m-q`
- B. `2-4ac5m-oq`
- C. `2-3-4ac5m-n-oq`
- D. `2-3-4a-c5m-n-oq`

---

## 答案

**正确答案：** B

---

## 解析

程序遇到连续递增字符时，在连续段开始处补入连字符，并用 `flag` 避免重复处理。逐项跟踪输入 `234ac5mnoq` 可得输出 `2-4ac5m-oq`，故选 B。
