# 题目 10

有如下 Python 程序段：

```python
def check_bus(speed):
    if speed < 20:
        return "低速"
    if speed > 40:
        return "超速"
    return "正常"
res = check_bus(45)
print(res)
```

执行该程序段后，输出的结果是（   ）

- A. 低速
- B. 正常
- C. 超速
- D. 45

---

## 答案

**正确答案：** C

---

## 解析

45 大于 40，函数在第二个判断处返回“超速”。
