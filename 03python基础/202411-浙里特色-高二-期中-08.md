# 题目 08

下列 Python 表达式中，值为 `True` 的选项是（   ）

- A. `3**2 != 3*2`
- B. `abs(int(5.6)) == len("123456")`
- C. `12345//100%10 == 4`
- D. `ord(max(["a","2","D"]))-97 > 1`

## 答案

**正确答案：** A

## 解析

选项 A 中 `3**2=9`、`3*2=6`，不等式成立。B 为 `5==6`，C 中 `12345//100%10=3`，D 中列表最大字符为小写 `a`，结果为 `0>1`，均不成立。
