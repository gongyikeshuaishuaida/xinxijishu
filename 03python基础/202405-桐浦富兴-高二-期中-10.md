# 题目 10

10.有如下 Python 程序段：

```python
import random
s = 'Python2024'; ans = ''
k = random.choice([-1, 1])
for ch in s:
    key = random.randint(1, 3)
    if 'A' <= ch <= 'Z':
        ans += chr((ord(ch) + k * key - 65) % 26 + 65)
    elif '0' <= ch <= '9':
        ans += chr((ord(ch) + k * key - 48) % 10 + 48)
    else:
        ans += ch
print(ans)
```

执行后，输出结果可能是（ ）

- A.`Python2024`
- B.`Qython3111`
- C.`Oython3935`
- D.`Sython5145`

---

## 答案

**正确答案：** D

---

## 解析

字母和数字都会按同一个方向 k、但各自按随机 key（1～3）移位，非字母数字字符不变。D 中 `P` 向后移 3 位为 `S`，数字也可分别取合法随机移位；其他选项与移位规则不符。
