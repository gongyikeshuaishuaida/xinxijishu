# 题目 11

有如下 Python 程序段：

```python
n = int(input())
c = 0
while n != 1:
    if n % 3 == 0:
        n = n // 3
    else:
        n = n - 1
    c = c + 1
print(c)
```

若输入下列某个整数后，程序输出的结果不是 3，该整数是（   ）

- A. 5

- B. 7

- C. 11

- D. 12

---

## 答案

**正确答案：** C

---

## 解析

5、7、12 都运行 3 次，11 要运行 4 次；每轮能被 3 整除就除以 3，否则减一。
