# 题目 13

某校智慧教室装有两类传感器：人体红外传感器每5分钟返回一次“是否有人”（1有人、0无人），光敏传感器同步返回一次“环境光线是否充足”（1充足、0不足）。当出现“无人且光线充足”的状态时，照明灯应关闭。系统需统计该状态发生的总次数，以及最长连续发生次数。

（1）系统完成 “是否有人”、“光线是否充足” 的采集，所使用的部件属于 ____ （选填字母：A 传感器/B 执行器）。

（2）若某间教室连续 9 次的采集数据如下：`motion=[1,0,0,1,0,0,0,1,0]`；`light=[1,1,0,1,1,1,0,1,1]`，则“无人且光线充足”的状态最长连续发生 ______ 次。

（3）实现统计功能的 Python 程序如下，请在划线处填入合适的代码。



```python
# 将采集的数据分别存放到列表 motion、light，代码略
n = len(motion)
cnt = 0; cur = 0; mx = 0
for i in range(n):
    if ______①______:
        cnt = cnt + 1
        cur = cur + 1
        if ______②______:
            mx = cur
    else:
        ______③______
print("该状态共发生"+str(cnt)+"次，最长连续发生"+str(mx)+"次。")
```

---

## 答案

（1）A。

（2）2。

（3）① `motion[i]==0 and light[i]==1`；② `cur > mx`；③ `cur = 0`。

---

## 解析

传感器采集外部状态，灯等执行器执行控制动作。两项状态同时满足时总次数、当前连续次数均增加；不满足时只清零连续次数，历史最长值保留。给定数据中最长连续段在下标 4、5。
