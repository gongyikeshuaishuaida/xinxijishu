# 题目 14

某校进行学生评教活动，共有 10 个题目，每题有 4 个选项（ABCD），各选项对应分值如图 a 所示。如果学生对某学科老师的评教结果为 AAAABBABAB，则该学科老师的评教分数为 46。

![[attachments/202407衢温5加1_14_评教分值表.jpg]]

若输入评教结果中出现 ABCD 以外的字符，则该生的评教成绩无效。执行程序的效果如图 b 所示。

![[attachments/202407衢温5加1_14_评教运行结果图.jpg]]

（1）若输入的评教结果为 `ABABAACABD`，则评教成绩为 ______。

（2）实现上述功能的 Python 程序如下，请在划线处填入合适的代码：

```python
s = input("请输入学科1老师的评教结果：")
n = 0
score = 0
for ______①______:
    if ch == "A":
        score += 5
    elif ch == "B":
        score += 4
    elif ______②______:
        score += 2
    elif ch == "D":
        score += 1
    else:
        n += 1
if n > 0:
    print("你的评教成绩无效")
else:
    print("评教成绩为：" + ______③______)
```

（3）上述 Python 程序采用的算法是 ______（单选，填字母：A.解析算法；B.枚举算法）。

---

## 答案

**正确答案：** （1）40；（2）① ch in s；② ch == "C"；③ str(score)；（3）A

---

## 解析

A、B、C、D 的分值依次为 5、4、2、1。ABABAACABD 的得分为 5+4+5+4+5+5+2+5+4+1=40。逐字符遍历并按字符分支累加分值，遇到其他字符只记录无效次数；输出时需把整数 score 转成字符串后与提示语拼接，因此这是解析算法。
