# 题目 08

8.变量 `a`、`b` 均为布尔型，下列 Python 表达式与 `not a or b` 等价的是（ ）

- A.`not (a or b)`
- B.`not (a and b)`
- C.`a != True or b != False`
- D.`a == False and b == False`

---

## 答案

**正确答案：** C

---

## 解析

布尔变量中 `a != True` 等价于 `not a`，`b != False` 等价于 `b`，因此 C 与 `not a or b` 等价。
