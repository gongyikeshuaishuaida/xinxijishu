# 题目 12

有如下 Python 程序段：

```python
import random
a = [0] * 6
for i in range(6):
    a[i] = random.randint(1,4) * 2
    if a[i] % 3 == 0:
        a[i] = a[i] + 1
    elif i % 2 == 1:
        a[i] = a[i] - 1
    if i > 2 and a[i] % 2 == 0:
        a[i] = a[i] // 2
print(a)
```

执行该程序段后，下列输出结果不可能的是（   ）

- A. `[2,7,4,3,1,3]`
- B. `[8,3,2,1,7,7]`
- C. `[4,4,7,3,2,7]`
- D. `[4,3,2,1,7,7]`

---

## 答案

**正确答案：** C

---

## 解析

奇数下标若得到 4，会走减 1 分支得到 3；其余初始偶数也无法在下标 1 变成 4。
