# 题目 10

有如下 Python 程序段：

~~~python
s1=input("请输入一个四位正整数：")
s2=""
n=len(s1)
for i in range(n):
    d=int(s1[i])+int(s1[(i+1)%n])
    if d%2==0:
        s2+=chr(d+ord("A")-1)
    else:
        s2+=chr(d+ord("a")-1)
print(s2)
~~~

若输入的字符串 `s1` 的值为 `"1528"`，执行该程序段后，输出结果为（   ）

- A. `GhKj`
- B. `FGjI`
- C. `FgJi`
- D. `iJgF`

## 答案

**正确答案：** C

## 解析

相邻数字和（首尾循环）依次为 6、7、10、9。偶数和使用大写字母，奇数和使用小写字母，得到 `F`、`g`、`J`、`i`，所以输出为 `FgJi`。
