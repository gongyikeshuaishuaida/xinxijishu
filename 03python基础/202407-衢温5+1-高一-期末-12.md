# 题目 12

有如下 Python 程序段：

```python
s1 = input()
s2 = ""
while len(s1) > 1:
    s2 += s1[0]
    s1 = s1[2:] + s1[1]
s2 += s1
print(s2)
```

若输入 “abcde”，执行该程序段后输出的结果是（   ）
- A. dbace
- B. abcde
- C. edcba
- D. acedb

---

## 答案

**正确答案：** D

---

## 解析

输入 abcde 时依次把 a、c、e、d 加入 s2，剩余 s1 为 b，最后得到 acedb。
