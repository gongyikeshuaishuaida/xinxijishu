# 题目 08

8. 某 Python 程序如下：

```python
infomation = {"01":["李切","男",16],"03":["狄辛","女",16],"04":["彭栈","男",17]}
infomation["01"][2] = 17       # ①
infomation["02"] = ["孔紫","女"] # ②
info1 = infomation[1]             # ③
print(infomation["02"])           # ④
```

程序运行后，提示报错信息，报错的语句是（   ）

- A. ①
- B. ②
- C. ③
- D. ④

---

## 答案

**正确答案：** C

---

## 解析

字典的键为字符串 `"01"`、`"03"` 和 `"04"`。①可以修改键 `"01"` 对应列表的第 3 个元素，②可以增加键 `"02"`，④可以读取键 `"02"` 对应的列表；③使用整数键 `1` 读取字典中不存在的键，会触发 `KeyError`。
