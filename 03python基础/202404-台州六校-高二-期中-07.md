# 题目 07

关于 Python 语句功能描述正确的是（   ）

- A. `ord(chr(x)+26)`：若字符变量 `x` 是大写字母即变成小写字母
- B. `str(x)+str(y)`：求两数之和
- C. `"abcd"[2:4]`：运行结果为 `"bcd"`
- D. `2**3*2/2 % 5`：结果为 3

---

## 答案

**正确答案：** D

---

## 解析

D 中先算乘除得到8，再对5取余得到3。A中 `ord` 不能接收字符串拼接结果，B是字符串连接，C的切片结果是 `"cd"`。
