# 题目 07

下列 Python 表达式中，其值最大的是（   ）

- A. abs(int(-4.6))
- B. 5%2//2+3
- C. len(str(10))
- D. 2**5%9

---

## 答案

**正确答案：** D

## 解析

A 的值为 4，B 的值为 3，C 的值为 2，D 的值为 32%9=5，因此 D 最大。
