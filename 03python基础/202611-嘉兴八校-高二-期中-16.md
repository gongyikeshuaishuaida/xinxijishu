# 题目 16

某商城购物节满减规则：每满 500 减 60，每满 200 减 20，优惠可叠加，优先计算高档位。计算顺序：先按原价计算每满 500 的优惠；剩下不足 500 的剩余金额，再计算每满 200 的优惠。如下图小红购买的商品可享受 3 次 “满 500 减 60” 和 1 次 “满 200 减 20” 优惠。

![[attachments/202611嘉兴八校高二_16_图1.png]]

编写 Python 程序实现:

① 计算所有商品原价总和；

② 根据总价计算满减优惠总额;

③ 计算实际支付金额 = 原价总和 - 优惠总额;

④ 输出原价总和、优惠金额、实际支付金额。

（1）将小红购物清单中运动鞋的价格改成 399 后，最终实际支付 ______ 元。

（2）请将程序代码补充完整。

（3）加框处程序代码有误，请改正。

```python
goods = {"智能手表":899, "卫衣":299, "运动鞋":529, "水杯":45}
total = 0    # total 存储商品原价总和
# 遍历字典，累加所有商品价格
for price in goods:
    total = total + ______①______
discount = 0    # discount 存储满减优惠金额
if total >= 500:
    discount = total // 500 * 60
    remain = ______②______    # remain 存储剩余总价
if remain >= 200:
    discount = remain // 200 * 20    # 原卷加框
pay = ______③______    # 实际支付金额
print("原价总和：", total)
print("优惠金额：", discount)
print("实际支付：", pay)
```

---

## 答案

（1）1462。

（2）① `goods[price]`，② `total%500`，③ `total-discount`。

（3）`discount += remain//200*20`。

---

## 解析

修改后的原价为 1642 元，先减 3×60 元，剩余 142 元达不到 200 元门槛。遍历字典得到的是键，需要通过键取价格。加框处要把第二档优惠累加到已有优惠中。另需注意，若将示例推广到总价不足 500 的输入，应先给 remain 赋值，原卷代码在这种输入下会引用未定义的变量。
