# 题目 10

定义如下函数：

```python
def f(num, k):
    code = "0123456789ABCDEF"
    ans = ""
    while num != 0:
        x = num % k
        ans = code[x] + ans
        num //= k
    return ans
```

执行语句 `k=f(18,2)` 后，k 的值为（   ）

- A. `"10001"`

- B. `"01001"`

- C. `"10010"`

- D. `"1001"`

---

## 答案

**正确答案：** C

---

## 解析

不断除以 2 取余并前插，把十进制 18 转为二进制字符串 10010。
