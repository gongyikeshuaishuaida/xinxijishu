# 题目 10

10.用 Python 实现“每满 100 减 30，每满 200 减 70，可以累计，上不封顶”的优惠金额计算，原价为 `s`，优惠金额为 `t`，正确的是（ ）

- A.

  ```python
  t = s // 200 * 70
  if s % 200 >= 100:
      t = t + 30
  ```

- B.

  ```python
  t = s // 100 * 30
  if s // 200 > 0:
      t += s // 200 * 70
  ```

- C.

  ```python
  if s >= 200:
      t = s // 200 * 70
  else:
      t = s // 100 * 30
  ```

- D.

  ```python
  if s >= 100:
      t = s // 100 * 30
  else:
      t = s // 200 * 70
  ```

---

## 答案

**正确答案：** A

---

## 解析

应先按每满 200 元的优惠计算，再对余数是否满 100 元判断是否追加 30 元；A 正好实现“可累计、上不封顶”，故选 A。
