# 题目 09

有如下 Python 程序段：

```python
a = [6, 12, 9, 20, 8, 11, 4]
for j in range(1, len(a)):
    if a[j] < a[j-1]:
        a[j] = a[j] + a[j-1]
        a[j-1] = a[j] - a[j-1]
        a[j] = a[j] - a[j-1]
```

执行该程序段后，列表 a 的值是（   ）

- A. [4, 6, 12, 9, 20, 8, 11]
- B. [4, 6, 8, 12, 9, 20, 11]
- C. [6, 9, 12, 8, 11, 4, 20]
- D. [6, 9, 8, 11, 4, 12, 20]

## 答案

**正确答案：** C

## 解析

程序从左到右只比较相邻元素并在逆序时交换。逐步得到 [6,9,12,8,11,4,20]，因此选择 C。
