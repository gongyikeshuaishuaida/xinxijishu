# 题目 13

有如下 Python 程序段：

~~~python
def s(x):
    if x <= 1:
        y = x
    else:
        y = s(x-1)+s(x-2)
    return y

a = int(input("请输入正整数："))
print(s(a))
~~~

13. 运行程序，输入值为6，则输出结果为（   ）

- A. 8
- B. 9
- C. 13
- D. 14

---

## 答案

**正确答案：** A

---

## 解析

函数满足 s(0)=0、s(1)=1，且 s(x)=s(x-1)+s(x-2)，所以 s(6)=8。
