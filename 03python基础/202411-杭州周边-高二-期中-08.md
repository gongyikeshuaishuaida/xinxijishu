# 题目 08

8. 下列 Python 程序，能正确判断整数 `x` 是奇数还是偶数的是（   ）

- A.

  ```python
  if x % 2 == 0 :
          y = "偶数"
  y = "奇数"
  ```

- B.

  ```python
  if x % 2 == 0 :
          y = "偶数"
  else x % 2 != 0:
          y = "奇数"
  ```

- C.

  ```python
  if x // 2 == 0 :
          y = "偶数"
  if x // 2 != 0:
          y = "奇数"
  ```

- D.

  ```python
  if x / 2 == x // 2 :
          y = "偶数"
  else:
          y = "奇数"
  ```

---

## 答案

**正确答案：** D

---

## 解析

整数除以 2 时，偶数的真除法结果与整除结果相等，奇数的真除法结果带有 `0.5`，与整除结果不等，所以 D 能正确区分两类整数。A 会在偶数情况下被后面的语句覆盖，B 语法错误，C 判断的是商是否为 0 而不是奇偶性。
