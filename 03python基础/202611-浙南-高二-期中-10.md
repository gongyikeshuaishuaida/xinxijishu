# 题目 10

有如下 Python 程序段：

```python
s = "baauay"
ch, i, t = "", 0, 0
while i < len(s) and t <= 2:
    if s[i] == "a":
        t += 1
    else:
        ch += s[i]
    i += 1
```

执行该程序段后，ch 的内容为（   ）

- A. b

- B. bu

- C. buy

- D. buay

---

## 答案

**正确答案：** B

---

## 解析

第三个 a 出现后 t 变为 3，下一轮停止，此前追加的非 a 字符只有 b 和 u。
