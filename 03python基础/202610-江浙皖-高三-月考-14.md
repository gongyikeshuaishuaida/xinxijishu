# 题目 14

图书馆噪声监控系统在接入广播后对提醒规则进行了优化和更新，具体实现方式如下：声音传感器每分钟采集一次声音数据，每3分钟为一个时间单位，统计该时间段内声音最大值存入数组`peak`。`peak`每3分钟更新一次，始终按时间顺序存放着最近30分钟内的数据。

规则如下：

①若连续4个统计单位的数据都≥45，则触发并保持“一级提醒”（灯带闪烁）。

②若一级提醒触发后的4个统计单位内，任一次出现数据≥45，则触发“二级提醒”（语音提醒），并重新计数。

③若一级提醒触发后的4个统计单位内，未出现数据≥45，则关闭一级提醒状态。

(1) 若系统9:00启动，截至9:36时，请问9:30—9:33这个时间单位内的最大值存储在数组`peak`的位置为______（填索引值）。

(2) 实现上述功能的部分Python程序如下，请在划线处填入合适的代码。

```python
peak = [0] * 10
n = cnt = max_val = 0
first = False
check = 0
while True:
    n += 1
    # 声音传感器采集数据存储到变量t中，代码略
    if t > max_val:
        max_val = t
    if ______①______:
        if max_val >= 45:
            cnt += 1
        else:
            cnt = 0
        if ______②______:
            print("一级提醒：灯带闪烁")
            first = True
            max_val = 0
            continue
        if first:
            check += 1
            if max_val >= 45 and check <= 4:
                print("二级提醒：语音播报")
                check = 0
            elif check == 4:
                print("一级提醒超时关闭")
                ______③______
                cnt = 0
                check = 0
        max_val = 0
    # 延时一分钟，代码略
```

---

## 答案

(1) 8。

(2) ①`n % 3 == 0`；②`cnt >= 4 and not first`；③`first = False`。

---

## 解析

(1) 9:36时保留最近30分钟，即9:06—9:36，共10个单位。9:30—9:33是其中第9个，索引8。

(2) 每3分钟结算一次最大值，故①按3取模。连续4次达阈值且尚未开启一级提醒时才触发，②须同时判断计数与状态；触发时`continue`避免把触发单位计入后续4个单位。超时关闭须将`first`恢复False，再清零`cnt`、`check`。原卷这一程序片段未给出更新`peak`的代码，按原样保留。
