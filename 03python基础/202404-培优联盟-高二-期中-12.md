# 题目 12

字符串 `s` 由数字字符组成，且首位不为 `"0"`。现需要在 `s` 中某一位置插入 1 位数字字符，得到新字符串 `st`，使 `st` 的值最大。例如 `s` 为 `"975463"`，插入字符 `"8"` 后，得到最大值 `"9875463"`。

程序段如下，方框中应填入的正确代码是（　　）

```python
# 输入字符串 s，长度为 n；输入字符串 ch，长度为 1，代码略
i = 0
while i < n:
    # 方框处
st = s[0:i] + ch + s[i:n]
```

- A.

  ```python
  if ch >= s[i]:
      i += 1
  else:
      break
  ```

- B.

  ```python
  if ch >= s[i]:
      break
  else:
      i += 1
  ```

- C.

  ```python
  if ch < s[i]:
      break
  else:
      i += 1
  ```

- D.

  ```python
  if ch > s[i]:
      break
  else:
      i += 1
  ```

---

## 答案

D

---

## 解析

为了使新数最大，应从左向右寻找第一个小于 `ch` 的数字，并把 `ch` 插在它前面。因此当 `ch > s[i]` 时退出循环，否则继续右移，D 正确。若所有数字都不小于 `ch`，循环结束后把 `ch` 插到末尾。
