# 题目 11

有如下 Python 程序段：

```python
from random import randint
n = 6
a = [0] * n
for i in range(n):
    x = randint(1, 10)
    if i % 2 == 0:
        a[i] = x * 2
    elif x <= 5:
        a[i] = a[i-1] + x
    else:
        a[i] = x
print(a)
```

执行该程序段后，输出的结果可能是（   ）

- A. `[7,8,20,8,12,8]`

- B. `[14,15,22,9,10,11]`

- C. `[16,7,2,7,16,20]`

- D. `[12,3,6,11,8,13]`

---

## 答案

**正确答案：** C

---

## 解析

偶数下标取 2～20 内的偶数；奇数下标取 6～10 或前项加 1～5。C 满足全部条件；A 首位为奇数，B 含 22，D 第二项 3 无法产生。
