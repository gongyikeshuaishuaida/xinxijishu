# 题目 11

11.有如下Python程序段：

```python
a=[4,3,1,2,3]
m=0
s=0
for i in range(1,len(a)):
    if a[i]<a[m]:
        m=i
    s=s+m
print(s)
```

执行以上程序段后，s中的值是（ ）

A.10  B.9  C.8  D.7

---

## 答案

**正确答案：** D

---

## 解析

`m`依次变为1、2、2、2，累加得到 `1+2+2+2=7`，所以选D。
