# 题目 14

某工厂自动化生产线配备智能质量检测系统，对生产线上的产品进行监测。将采集到的产品尺寸数据存储于列表 `data` 中，以任意连续 `k` 个数据为一组，统计该组中尺寸不在标准范围 `[48,52]` 内的产品个数，若不合格产品数量超过阈值 `m`，则判定生产线异常，立即发出预警提示。

（1）某时段接收到的产品尺寸数据为“45、55、50、48、42、51、41、52”，若 `k=3`，`m=1`，则预警次数为 ______ 次。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 获取 k、m 的值
low = 48
high = 52
cnt = 0
i = 0
for j in range(len(data)):
    if data[j] < low or data[j] > high:
        ______①______
    if j - i + 1 > k:
        if data[i] < low or data[i] > high:
            cnt -= 1
        ______②______
    if ______③______:
        # 发出生产线异常预警
        pass
```

---

## 答案

**正确答案：** （1）2；（2）① `cnt = cnt + 1`；② `i = i + 1`；③ `j - i + 1 == k and cnt > m`

---

## 解析

用滑动窗口维护最近 `k` 个产品中的不合格数量。每读入一个不合格数据就增加 `cnt`；窗口超长时移出 `data[i]` 并相应减少 `cnt`，再将 `i` 右移。窗口恰好为 `k` 个且 `cnt` 大于 `m` 时预警。给定数据中窗口 `[45,55,50]` 和 `[42,51,41]` 超过阈值，共 2 次。
