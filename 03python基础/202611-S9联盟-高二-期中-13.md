# 题目 13

已知：字符“0”的 ASCII 值为 48，“A”的 ASCII 值为 65，“a”的 ASCII 值为 97。

书写下列 Python 程序段运行结果：

（1）



```python
a = int(min(["1234", "54"]))
print(a)
```



（2）



```python
print(240 // 2 ** 3 * 5 % 8)
```



（3）



```python
a = "ABC" + ["abc", "123"][1]
print(a[2:4])
```



（4）



```python
s1 = "abc"
s2 = [12, 2, 3, 3, 5]
p1 = ord(s1[0]) + len(s2)
p2 = ord(s1[2]) // s2[3]
ans = p1 % p2
print(ans)
```

---

## 答案

（1）1234。

（2）6。

（3）C1。

（4）3。

---

## 解析

min 先按字符串顺序比较，得到“1234”再转整数。第二式依次计算 2**3=8、240//8=30、30×5=150、150%8=6。拼接后的字符串为 ABC123，切片 [2:4] 为 C1。最后 p1=102、p2=33，余数为 3。
