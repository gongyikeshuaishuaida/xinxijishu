# 题目 10

有如下 Python 程序段：

```python
s = "aabbccabc"
c = 0
i = 0
while i < len(s) - 1:
    if s[i] == s[i + 1]:
        c = c + 1
        i = i + 2
    else:
        i = i + 1
print(c)
```

执行该程序段后，输出的结果是（   ）

- A. 1

- B. 2

- C. 3

- D. 4

---

## 答案

**正确答案：** C

---

## 解析

检测到aa、bb、cc三组相邻相同字符后各跳过2位，其余abc无相邻相同，输出3。
