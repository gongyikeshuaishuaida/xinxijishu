# 题目 12

有如下 Python 程序段：

```python
import random
n = 8
a = [random.randint(0, 9) for i in range(n)]
for t in range(2):
    i = t + 1
    while i < n - 1:
        if t % 2 == 0:
            if a[i-1] < a[i] and a[i] > a[i+1]:
                i += 2
            else:
                a[i] += random.randint(0, 9)
        else:
            if a[i-1] > a[i] and a[i] < a[i+1]:
                i += 2
            else:
                a[i] -= random.randint(0, 9)
```

运行后，数组 `a` 中的值可能是（   ）

- A. [8, 8, 3, 5, 4, 7, 3, 5]
- B. [5, 11, 10, 18, 8, 9, 0, 2]
- C. [1, 2, 1, 4, 0, 10, -1, 7]
- D. [7, 12, 5, 17, 9, 19, -10, 8]

## 答案

**正确答案：** C

## 解析

程序第一轮只可能对局部极小值位置增加非负随机数，第二轮只可能对不满足局部极小条件的位置减去非负随机数。逐项检查变化方向和相邻关系，只有 C 能由某组初始随机数组经上述两轮操作得到。
