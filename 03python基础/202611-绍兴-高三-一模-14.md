# 题目 14

智能终端每分钟采集 n 台饮水机（编号 0\~n-1）的 TDS 值，对每台饮水机分别按以下规则决定是否上传本次采集值：

① 第 1 次采集值直接上传;

② 此后，本次采集值与最近上传值之差的绝对值达到 d 时，记为一次显著变化；若最近一次上传后已连续 2 次显著变化（含本次），或本次采集前已连续 m 次未上传，则上传。

请回答下列问题:

(1) 设 `d=20, m=3` 。某台饮水机开机后连续 8 次采集值依次为 150、162、178、186、208、202、212、204，则上传的采集值个数为 ____。

(2) 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
# 读取n、d、m的值，代码略
rec = [[] for i in range(n)]  # rec[i]按时间顺序存放i号饮水机的上传值
chg = [0] * n  # chg[i]为i号饮水机最近一次上传后连续显著变化次数
cnt = [0] * n  # cnt[i]为本次采集前i号饮水机连续未上传次数
while True:
    # 采集值存入列表x，x[i]为i号饮水机的值，代码略
    for i in range(n):
        up = 0
        if len(rec[i]) == 0:
            up = 1
        else:
            if abs(x[i] - ______①______) >= d:
                chg[i] = chg[i] + 1
            else:
                chg[i] = 0
            if ______②______:
                up = 1
        if up == 1:
            # 上传饮水机编号i和采集值x[i]，代码略
            rec[i].append(x[i])  # 在列表rec[i]末尾追加元素x[i]
            chg[i] = 0
            cnt[i] = 0
        else:
            ______③______
    # 延时1分钟，代码略
```

---

## 答案

**正确答案：** (1) 3；(2) ① `rec[i][-1]`；② `chg[i] >= 2 or cnt[i] >= m`；③ `cnt[i] += 1`。

---

## 解析

显著变化须与最近一次上传值比较，而非上一采集值；达到连续两次变化或已有m次未上传即上传并清零。给定序列上传值依次为150、186、204，共3次。
