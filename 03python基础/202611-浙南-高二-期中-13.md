# 题目 13

对给定只包含小写字母的字符串进行处理，输出原字符串中所有出现次数最多的字符，按它们在原字符串中出现的先后顺序连成一个新字符串。例如①字符串"addcd"，输出结果为：ddd。②字符串"abbcc"，输出结果为：bbcc。

（1）若字符串 `s="accddeeccadd"`，则处理后的字符串为 ______。

(2)实现上述功能的部分 Python 程序如下：请在划线处填入合适的代码。

#读入字符串 s 的值，代码略。



```python
______①______
num = [0] * 26
for i in s:
    num[ord(i)-97] += 1
ch = [0]    # 存放当前出现次数最多的字符索引列表（初始假设'a'）
for i in range(1, 26):
    if num[i] > num[ch[0]]:
        ______②______
    elif num[i] == num[ch[0]]:
        ch += [i]
for i in s:
    if ______③______ in ch:
        res += i
print("处理后的字符串:", res)
```

---

## 答案

（1）ccddccdd。

（2）① `res = ""`；② `ch = [i]`；③ `ord(i)-97`。

---

## 解析

c、d 都出现 4 次，为最高频字符，保留它们在原串中的先后次序，得到 ccddccdd。遇到更高频次时应重建候选索引列表，频次相同才追加，最后按原串逐字符筛选。
