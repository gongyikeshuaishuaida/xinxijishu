# 题目 13

13. 小明想要编写一个程序，计算输入字符串的密钥平均值 `k`：英文字符按字母表位序代表其数值，数字字符逐个计算，其余字符不计值。例如，输入明文 `Ab%*71` 得到的密钥平均值 `k` 为 `(1+2+7+1)//6=1`。请在下面程序段划线处填入合适的语句。

```python
s = input("输入一个字符串：")
______①______
i = 0
while i < len(s):
    if "0" <= s[i] <= "9":
        ______②______
    elif "a" <= s[i] <= "z":
        sum += ord(s[i]) - ord("a") + 1
    elif "A" <= s[i] <= "Z":
        ______③______
    i += 1
k = sum // len(s)
print("密钥平均值为：", k)
```

---

## 答案

**参考答案：**

- ① `sum=0`
- ② `sum+=int(s[i])`
- ③ `sum+=ord(s[i])-ord("A")`

---

## 解析

累加变量需要先初始化为 0。数字字符应转换为整数后逐个累加；小写字母使用相对于 `"a"` 的位置并加 1；大写字母使用相对于 `"A"` 的位置并加 1，写作 `ord(s[i])-ord("A")`。题目中的分母使用原字符串长度，因此其他字符只是不计入累加值。
