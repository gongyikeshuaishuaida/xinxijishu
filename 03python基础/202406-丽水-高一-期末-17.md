# 题目 17

17.签到兑奖活动中，签到状态用 0/1 表示，连续签到第 1—4 天分别得 1—4 分，第 5 天起每天得 5 分，中途漏签后重新计分。

![[attachments/202406-丽水-高一-期末-17_横排1_2.png]]

（1）签到状态为 110011101，赚取积分为 ______①______；若兑换 20 积分奖品，还需连续签到最少 ______②______ 天。

（2）补充 cal(n)：

~~~python
def cal(n):
    if ______③______:
        return n*(1+n)//2
    else:
        return 15+(n-5)*5
~~~

（3）签到程序中补充：

~~~python
while i<len(s):
    j=i
    while j<len(s) and s[j]=='1':
        j+=1
    jf+=cal(j-i)
    if flag==True:
        last=j-i
    ______④______

else:
    ______⑤______
    lastjf=0
    if flag==True:
        count=last
        lastjf=cal(last)
        lx=jf
        while lx<jp+lastjf:
            count+=1
            lx=jf+______⑥______
~~~



---

## 答案

**正确答案：** ①10；②4；③n<=5（或 n<5、n<6）；④i=j+1；⑤count=0；⑥cal(count)

---

## 解析

签到状态分段为 11、111、1，积分分别为 3、6、1，总计 10。连续签到 4 天新增 2+3+4+5=14 分，达到 20 分。cal 的前五天积分为等差和，超过 5 天后按 15+(n-5)*5；循环处理完一段后令 i=j+1，未达到奖品积分时从 count=0 累计连续天数。
