# 题目 06

6.室内合适温度为 `16～24℃`，用 `tmin～tmax` 表示；温度存放在 `t`，空调调温量 `k` 为1（升温）、-1（降温）、0（温度合适）。以下代码不能正常调控的是（ ）

![[attachments/202404浙南_06_温度判断选项.jpg]]

- A.
```python
if t > tmax:
    k = -1
if t < tmin:
    k = 1
if tmin <= t <= tmax:
    k = 0
```

- B.
```python
if t > tmax:
    k = -1
elif t >= tmin:
    k = 0
else:
    k = 1
```

- C.
```python
if t > tmax:
    k = -1
if t < tmin:
    k = 1
else:
    k = 0
```

- D.
```python
k = 0
if t > tmax:
    k = -1
elif t < tmin:
    k = 1
```

---

## 答案

**正确答案：** C

---

## 解析

C 中第二个 `if` 与 `else` 配对：当 `t>tmax` 时，先设置 `k=-1`，随后因 `t<tmin` 为假又执行 `else` 将 `k` 改为0，降温控制失效。A、B、D 的分支逻辑均能覆盖三种温度状态。
