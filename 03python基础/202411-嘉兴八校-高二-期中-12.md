# 题目 12

有如下 Python 程序段：

~~~python
s = 'jiaxing';ans = ''
n = len(s)
for i in range(n//2, 0, -1):
    if s[i-1] < s[n-i]:
        ans = ans + s[i-1]
    else:
        ans = s[n-i] + ans
print(ans)
~~~

12. 执行该程序段后，输出的结果是（   ）

- A. jia
- B. aig
- C. gai
- D. xin

---

## 答案

**正确答案：** C

---

## 解析

n=7，i依次为3、2、1。三轮分别比较 a 与 i、i 与 n、j 与 g，ans依次为 a、ai、gai，最终输出 gai。
