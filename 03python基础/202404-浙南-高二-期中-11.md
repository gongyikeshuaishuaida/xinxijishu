# 题目 11

11.执行以下 Python 程序，输入 `"985c9q39s211"`，输出结果为（ ）

```python
s = input("请输入字符串：")
n = len(s); ch = ""; max = ""
for i in range(n - 1, -1, -1):
    c = s[i]
    if "0" <= c <= "9":
        ch = c + ch
    else:
        if ch > max:
            max = ch
        ch = ""
print(max)
```

A.`9`　B.`39`　C.`211`　D.`985`

---

## 答案

**正确答案：** D

---

## 解析

从右向左得到连续数字片段 `211`、`39`、`985`。程序以字符串进行比较，`"985"` 大于前两段，最终输出 `985`。原卷第16页参考答案表将第11题标为 A，与程序实际执行结果不一致，本题按源程序核定为 D。
