# 题目 09

有如下 Python 程序段：

~~~python
from random import randint
s = "abcde"
key = "123"
res = ""
for i in range(len(s)):
    k = int(key[i%len(key)])
    if randint(0,1) == 0:    # 随机生成整数0或1
        res += chr((ord(s[i]) - ord("a") + k) % 26 + ord("a"))
    else:
        res += chr((ord(s[i]) - ord("a") - k) % 26 + ord("a"))
~~~

执行该程序段后，变量 res 的值不可能是（   ）

- A. “bdzec”
- B. “bzfzz”
- C. “zzfcg”
- D. “zdzeg”

---

## 答案

**正确答案：** B

## 解析

每一位字符只能按对应密钥数字加法或减法变换。第二位原字符 b、密钥为 2，只可能得到 d 或 z；第四位原字符 d、密钥循环回到 1，只可能得到 e 或 c。选项 B 的第二位 z 虽可得到，但第四位为 z，不可能由 d 加减 1 得到，因此 B 不可能。
