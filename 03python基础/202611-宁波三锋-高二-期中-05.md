# 题目 05

下列 Python 表达式中，值与其他三项不同的是（   ）

- A. `23%5+2**2`
- B. `5*3%8`
- C. `2**6//2-1`
- D. `8-3%2`

---

## 答案

**正确答案：** C

---

## 解析

A、B、D 都为 7，C 为 31。
