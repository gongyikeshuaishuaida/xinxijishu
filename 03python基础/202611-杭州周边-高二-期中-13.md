# 题目 13

某物流中转站负责转运物品, 每个物品有唯一的正整数编号。将现有物品编号划分为若干序列, 连续的编号按升序置于同一序列, 不连续的编号置于不同序列。某次货车要运走一个序列的物品, 要求该序列的长度超过 x , 若存在多个序列, 则选择其中最短的且起始编号最小的, 若不存在这样的序列, 则取消当次货车运输。请回答下列问题:

(1) 若现有物品如第 13 题图所示, 当 x=2 时则货车运走物品的编号分别为: ▲ (用, 分隔)

![[attachments/202611杭州周边高二_13_图1.png]]

（2）实现上述功能的部分Python程序如下，请在划线处填入合适代码。

```python
"""
将车辆现有物品编号从小到大存入列表 hw 中，例如 hw=[101,102,105,……]
并读取 x 的值，代码略。
"""
hw=hw+[0]
s=hw[0]
length=1
bests=-1
bestlen=len(hw)+1
for i in range(______①______):
    if hw[i]-hw[i-1]==1:
        length+=1
    else:
        if ______②______:
            bestlen=length
            bests=s
        s=hw[i]
        length=1
if bests!=-1:
    lst=[]
    p=0
    while p<bestlen:
        lst.append(______③______)
        p+=1
    print("当次货车运走的物品编号为：",lst)
else:
    print("当次货车运输取消")
```

---

## 答案

（1）112，113，114。

（2）① `1, len(hw)`，② `length>x and length<bestlen`，③ `bests+p`。

---

## 解析

连续编号分段后，满足长度超过 2 的有 105～108 与 112～114，后者较短。追加 0 用于触发最后一段的比较，遇到长度相等时不替换，先扫描到的编号更小。
