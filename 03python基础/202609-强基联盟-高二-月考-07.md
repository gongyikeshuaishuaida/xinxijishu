# 题目 07

下列 Python 表达式中，值最小的是（   ）

- A. `7 % 3 ** 3`
- B. `len("warm-up")`
- C. `abs(int(-4.3))`
- D. `ord("c") - ord("a")`

---

## 答案

**正确答案：** D

---

## 解析

A 的值为 `7 % 27 = 7`，B 的值为 7，C 的值为 `abs(-4)=4`，D 的值为 `99-97=2`，所以最小的是 D。
