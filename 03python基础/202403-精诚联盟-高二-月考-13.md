# 题目 13

对某升序数字序列按如下规则进行压缩：对其中的连续递增部分（长度≥2）只保留其起始值和结束值，并用“-”来连接；其余数据不变。例如，升序序列“0、1、2、4、6、7、8”压缩后变为“0-2、4、6-8”。

（1）若某数字序列压缩后的结果为“1-5、7、10-12”，则压缩前该序列为 ______①______。

（2）现编写程序实现解压缩，运行结果如下图所示。请在程序中填入合适的代码。

![[attachments/202403精诚联盟_13_运行界面.jpg]]

```python
s = input('请输入压缩后的结果：')
s = s + ','
i = num = 0
flag = False
rs = ''
while i < len(s):
    if '0' <= s[i] <= '9':
        ______②______
    elif s[i] == '-':
        start = num
        num = 0
        ______③______
    else:
        end = num
        if flag:
            for j in range(start, end + 1):
                rs += str(j) + ','
        else:
            ______④______
        num = 0
        flag = False
    i += 1
print('原序列为：' + rs[:-1])
```

## 答案

**正确答案：** ① 1、2、3、4、5、7、10、11、12；② `num = num * 10 + int(s[i])`；③ `flag = True`；④ `rs += str(end) + ','`（或`rs += str(num) + ','`）

## 解析

读取数字字符时用乘 10 再加当前位，能够正确处理多位数；遇到连字符说明后续存在连续区间，设置 `flag` 并记录起点；遇到逗号时，区间逐项展开，单个数字直接追加到结果字符串。
