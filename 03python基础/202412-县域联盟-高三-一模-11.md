# 题目 11

找出字符串 s 中长度为 k、包含元音字母数最多的子串。例如：当 k=3，s="trouble" 时，结果是 "rou"。实现该功能的部分程序段如下，方框中应填入的正确代码为（   ）。

~~~python
vowels="aeiouAEIOU"
cnt=0
res=s[:k]
for i in range(k):
    if s[i] in vowels:
        cnt+=1
m=cnt
for i in range(k,len(s)):
    ______①______
    if cnt>m:
        m=cnt
        res=s[i-k+1:i+1]
print(res)
~~~

题目中的方框选项如下：

![[attachments/202412县域联盟_11_滑动窗口选项.jpg]]

- A.

~~~python
if s[i] in vowels:
    cnt+=1
if s[i-k+1] in vowels:
    cnt-=1
~~~

- B.

~~~python
if s[i] in vowels:
    cnt+=1
if s[i-k] in vowels:
    cnt-=1
~~~

- C.

~~~python
if s[i] in vowels:
    cnt+=1
if s[i-k] in vowels:
    cnt+=1
~~~

- D.

~~~python
if s[i] not in vowels:
    cnt-=1
if s[i-k+1] in vowels:
    cnt+=1
~~~

## 答案

**正确答案：** B

## 解析

初始 cnt 统计窗口 s[0:k]。窗口向右移动时，新进入窗口的字符是 s[i]，应在它为元音时加1；离开窗口的字符是 s[i-k]，应在它为元音时减1。因此选择 B，且这样可以在线性时间内完成统计。
