# 题目 11

11.用 Python 程序处理字符串：

```python
s="b2-c1-2"
t=0; sum=0
for ch in s:
    if "0" <= ch <= "9":
        t=t*10+int(ch)
    elif "a" <= ch <= "z":
        t=ord(ch)-ord("a")
    else:
        sum += t
        t=0
```

执行后 `sum` 的值是（ ）

- A.12
- B.35
- C.33
- D.21

---

## 答案

**正确答案：** C

---

## 解析

按程序逐字符处理并在非数字、非小写字母处累加：`b` 得1，`2` 后遇 `-` 累加12；`c` 得2，`1` 后遇 `-` 累加21；最后数字2在循环结束后没有进入 `else`，因此总和为33。
