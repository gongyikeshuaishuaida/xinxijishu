# 题目 11

有如下 Python 程序段：

```python
s = input()
sl = " "
for i in range(len(s)):
    c = s[i]
    if "A" <= c <= "Z":
        c = chr((ord(c) - ord("A")) % 10 + ord("0"))
    if "5" <= c <= "9":
        c = chr(ord(c) - ord("5") + ord("a") + 1)
    sl = c + sl
print(sl)
```

若输入的字符为 `ZJ2024sk`，执行上述程序后输出的内容为

- A. `bf2024sk`
- B. `592024sk`
- C. `ks4202fb`
- D. `ks420295`

## 答案

**参考答案：** C

## 解析

大写字母先按字母序号的个位转换为数字字符，再将数字 5～9 转换为 `b`～`f`；随后每次把字符加到 `sl` 的左侧，因此最终字符串是原处理结果的逆序 `ks4202fb`。
