# 题目 11

有如下 Python 程序段：

```python
t = "PrtiTimr"
f = [0] * 26
i = 0
while i < len(t):
    if "A" <= t[i] <= "Z":
        i += 1
        continue
    elif "a" <= t[i] <= "z" and f[ord(t[i]) - ord("a")] == 0:
        f[ord(t[i]) - ord("a")] += 1
    i += 1
for i in range(26):
    if f[i] == 1:
        print(chr(i + ord("a")), end="")
```

执行程序后，输出结果是（   ）

- A. `imrt`
- B. `itmr`
- C. `mt`
- D. `tm`

---

## 答案

**正确答案：** A

---

## 解析

程序忽略大写字母，用数组记录每个小写字母是否出现，再按字母表顺序输出。小写字母集合为 `i、m、r、t`，故输出 `imrt`。
