# 题目 11

有如下 Python 程序段：

~~~python
sc="ab018/20c2/d101e"
s,c=0,0
flag=False
for ch in sc:
    if "0"<=ch<="9":
        c=c*10+int(ch)
    elif "a"<=ch<="z":
        flag=True
    else:
        if flag:
            s+=c
        flag=False
    c=0
print(s)
~~~

执行该程序段后，输出结果为（   ）

- A. 220
- B. 101
- C. 119
- D. 321

## 答案

**正确答案：** A

## 解析

遇到 `/` 时，只有此前出现过小写字母才把当前数字累加。第一段 `ab018/` 累加 18，第二段 `20c2/` 累加 202，合计 220；末尾 `d101e` 后没有分隔符，程序不会再次累加，因此选 A。
