# 题目 09

有如下 Python 程序段：

```python
s = "a@bcde#fh"
ans = ""
flag = True
for i in s:
    if "a" <= i <= "z" and flag:
        ans += i
    flag = not flag
print(ans)
```

该程序运行后，输出的结果是（   ）

- A. abdh

- B. abdfh

- C. acdeh

- D. abcdefh

---

## 答案

**正确答案：** A

---

## 解析

flag 每轮都翻转，只有处于 True 且读到小写字母才追加，依次得到 a、b、d、h。
