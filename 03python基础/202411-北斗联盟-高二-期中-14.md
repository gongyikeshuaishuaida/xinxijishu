# 题目 14

有如下 Python 程序段：

```python
import random
a=[0]*6
i=0
while i<6:
    a[i]=random.randint(1,10)
    if a[i]%2==i%2:
        continue
    elif i%2==1:
        a[i]=a[i]-a[i-1]
    i+=1
```

程序运行后，列表 `a` 的值可能是（   ）

- A. `[2,3,4,1,6,-5]`
- B. `[7,3,9,-1,9,-3]`
- C. `[5,9,3,3,5,1]`
- D. `[1,5,7,-2,3,5]`

---

## 答案

**正确答案：** B

---

## 解析

当随机数与下标同奇偶时执行 `continue`，当前下标不会增加，直到得到相反奇偶的数；奇数下标还要减去前一项。逐项检查可知 B 的各项满足这些约束，其他选项至少有一项不符合，因此 B 可能出现。
