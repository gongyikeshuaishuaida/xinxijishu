# 题目 13

高速公路某路段设有多处区间测速点，每处测速点对应一个监控区间`[start, end]`（单位：千米）。同一个行驶方向上，多个测速区间可能相互重叠，交管部门需要对这些区间进行合并，得到一组互不重叠的区间集合。例如区间`[[3, 4], [1, 2], [4, 6]]`，合并得到的结果为`[[1, 2], [3, 6]]`。请设计算法，合并所有重叠区间，输出得到的区间集合。要求合并后的区间集合完整覆盖原始所有区间范围，无遗漏、无冗余区间，并按区间起始值`start`升序排列。

(1) 某路段上的测速区间为`[[5, 12], [1, 4], [8, 15], [20, 25], [18, 22], [25, 35]]`，按上述规则合并后，得到的区间集合为______（写出完整的二维数组形式）。

(2) 实现上述功能的部分Python程序如下，请在划线处填入合适的代码。

```python
#读取各测速区间的数据存储于 intervals 列表中，代码略
mx = max(p[1] for p in intervals)    #找出所有区间的最大右端点
diff = [0] * (mx * 2 + 2)
for i in intervals:
    diff[i[0] * 2] += 1; diff[i[1] * 2 + 1] -= 1
______①______
sum_d = 0    #当前扫描位置的覆盖区间数
start = -1    #当前合并区间的起点，-1 表示尚未进入覆盖区间
for i in range(len(diff)):
    sum_d += diff[i]
    if ______②______:
        if start < 0:
            start = i
    elif start >= 0:
        ans.append(______③______)
        start = -1
print(ans)    #输出结果
```

---

## 答案

(1) `[[1, 4], [5, 15], [18, 35]]`。

(2) ① `ans = []`；② `sum_d > 0`；③ `[start // 2, i // 2]` 或 `[start // 2, (i - 1) // 2]`。

---

## 解析

先合并 `[5,12]` 与 `[8,15]` 得 `[5,15]`；`[18,22]`、`[20,25]`、`[25,35]` 依次重叠或共享端点，合并为 `[18,35]`，另保留 `[1,4]`。

程序把端点放大2倍，在 `2×左端点` 处加1、`2×右端点+1` 处减1；`sum_d` 是差分数组的前缀和，表示当前位置的覆盖次数。`sum_d > 0` 时处于覆盖区间，首次进入时记起点；覆盖次数归零时记录合并区间并重置起点。归零位置 `i` 是奇数 `2×右端点+1`，故 `i//2` 与 `(i-1)//2` 相同，都还原右端点。端点放大能区分 `[1,4]` 和 `[5,15]` 之间的空隙，同时使共享端点的区间自然合并。
