# 题目 09

“云游良渚”线下文创商店推出满减优惠：单笔消费金额满 200 元减 40 元、满 100 元减 15 元，两项优惠不叠加。根据上述优惠规则，下列 Python 程序段中，能正确实现该功能的是（注：pay 表示消费金额，res 表示应付金额）（   ）

- A.

    ```python
    if pay >= 100:
        if pay >= 200:
            res = pay - 40
        res = pay - 15
    else:
        res = pay
    ```

- B.

    ```python
    if pay >= 100:
        res = pay - 15
    elif pay >= 200:
        res = pay - 40
    else:
        res = pay
    ```

- C.

    ```python
    res = pay
    if pay >= 200:
        res = pay - 40
    if pay >= 100:
        res = pay - 15
    ```

- D.

    ```python
    res = pay
    if pay >= 100:
        if pay >= 200:
            res = pay - 40
        else:
            res = pay - 15
    ```

---

## 答案

**正确答案：** D

---

## 解析

D 先令 res=pay，再按是否满 100、是否满 200 选择唯一优惠；其余程序存在覆盖或分支顺序错误。
