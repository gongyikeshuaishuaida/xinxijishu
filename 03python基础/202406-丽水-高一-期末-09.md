# 题目 09

9.下列 Python 表达式的值最大的是（ ）

- A.int("21345"[2:3])
- B.len("app")
- C.int(3.6)
- D.12%3**2+1

---

## 答案

**正确答案：** D

---

## 解析

A、B、C 的值都为 3；D 按幂、取模、加法顺序计算为 12%9+1=4，最大的是 D。
