# 题目 11

有如下 Python 程序段：

```python
import random
a=[0]*6; b=[0]*6; c=[0]*6
for i in range(6):
    a[i]=random.randint(0,5)    # 随机生成0~5的整数
for i in range(6):
    b[a[i]]=b[a[i]]+1
c[0]=b[0]
for i in range(1,6):
    c[i]=c[i-1]+b[i]
```

执行该程序段后，下列表达式中，值一定为 True 的表达式个数为

① `b[2]>=b[4]`　② `c[4]>=b[4]`　③ `c[5]==6`（   ）

- A. 3
- B. 2
- C. 1
- D. 0

---

## 答案

**正确答案：** B

---

## 解析

c[i] 是不超过 i 的出现次数。c[4]>=b[4]、c[5]==6 恒成立；b[2] 可以大于 b[4]。
