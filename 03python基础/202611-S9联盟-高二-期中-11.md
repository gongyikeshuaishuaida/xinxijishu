# 题目 11

有如下 Python 程序段：

```python
s = 1; i = 10
if i % 2 == 0 or i % 5 == 0:
    s = s + 1
if i % 3 == 1:
    s = s * 2
else:
    s = s + 1
print(s)
```

其输出结果为（   ）

- A. 4

- B. 5

- C. 11

- D. 22

---

## 答案

**正确答案：** A

---

## 解析

i=10 满足首个条件，s 从 1 变为 2；10%3=1，随后 s 变为 4。
