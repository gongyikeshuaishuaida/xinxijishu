# 题目 13

13. 某公司举办抽奖活动，设有一、二、三等奖。每张奖券印有 3 个互不相同的数字，每次在兑奖前公布中奖号码，兑奖时不考虑中奖数字的先后顺序，兑奖规则如下表所示。编程统计奖券获得的总奖金。

![[attachments/202411湖丽衢_13_兑奖规则表.png]]

（1）某次中奖号码为 3,1,8，则号码为 1,6,3 的奖券可以获得奖金 ______①______ 元。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

~~~python
# 输入中奖号码，依次存储到列表元素 win[0] 至 win[2] 中，代码略
rew = [0, 100, 200, 500]
______②______
n = int(input("输入奖券数量："))
for i in ______③______:
    cnt = 0
    # 输入奖券的号码，依次存储到列表元素 tic[0] 至 tic[2] 中，代码略。
    for j in range(3):
        if tic[j] in win:
            cnt += 1
    mon = ______④______
print("总奖金金额为：", mon)
~~~

---

## 答案

**参考答案：**

- （1）______①______：200
- （2）______②______：mon=0
- （2）______③______：range(n) 或 range(1,n+1) 或其他相同作用答案
- （2）______④______：mon+rew[cnt]

---

## 解析

号码 1、3 与中奖号码 3、1、8 匹配，共 2 个数字，奖金为 200 元。程序需先将总奖金 mon 初始化为 0，再循环处理每张奖券，按匹配个数 cnt 从 rew 中取奖金并累加。
