# 题目 15

在数据压缩前，对数据进行预处理可以在一定程度上提高压缩效率。以下模拟对长度为 `n` 的字符串 `data`（由小写字母组成）进行预处理，步骤如下：

1. 将“`$`”字符添加到字符串 `data` 末尾得到新字符串。
2. 将新字符串循环右移 1 位，重复 `n` 次后，共得到 `n+1` 个循环字符串。
3. 将步骤 2 得到的所有字符串进行升序排序（“`$`”的 ASCII 码比英文字母都小）。
4. 取排序后每个字符串的最后一个字符拼接，得到字符串 `datas`。

如字符串 `data="abcbc"`，经过变换后得到 `datas="c$cabb"`，变换过程如图所示。

（1）若 `data` 为“abb”，则经变换后得到的 `datas` 为：______①______。

（2）定义 `trans(ndata)` 函数，实现的功能是返回字符串 `ndata` 通过变换算法得到的 `datas`。

```python
def trans(ndata):
    m = len(ndata)
    result = [""] * m
    for i in range(m):
        tmp = ndata[i+1:] + ndata[:i+1]
        result[i] = tmp
        j = i
        while j > 0 and result[j-1] > tmp:
            result[j], result[j-1] = result[j-1], result[j]
            j -= 1
    # 将 result 中的字符串按顺序取出最后一个字符拼接得到 datas，代码略
    return datas
```

---

## 答案

**正确答案：** ① `b$ba`；② 5；③ `c = ndata[x]`；④ `ndata[lis[i]-1]`；⑤ C（`lis[j]+1, lis[j-1]+1`）

---

## 解析

对 `abb$` 的 4 个循环字符串排序后，依次取末字符可得 `b$ba`。插入排序过程中，交换语句在各轮插入时共执行 5 次。优化算法按起始字符把循环字符串的起始下标放入桶中，因此 `c` 应取 `ndata[x]`，再根据字符计算桶编号。桶中的下标表示循环字符串的起始位置，输出该循环字符串的最后一个字符时使用 `ndata[lis[i]-1]`。比较同一桶中两个循环字符串时，题目中的下标需要加 1，且前一个与后一个的位置分别对应 `lis[j]+1` 和 `lis[j-1]+1`，所以选 C。
