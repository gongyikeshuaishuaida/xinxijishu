# 题目 13

某小区在垃圾集中投放点安装了6台智能饮料瓶回收机（编号0～5），每台回收机内置一个储瓶箱，用于暂存居民投交的空瓶。系统每隔1小时采集一次各储瓶箱的装载率，并按以下规则调度：

①装载率超过90（不含90本身）且处于工作状态的回收机暂停回收服务；

②暂停服务的回收机，其储瓶箱需要清运，同时对机器做维护。清运维护期间（装载率尚未归0时）不参与任何调度；待装载率归0（清运维护完成）后，回收机立即恢复工作；

③若本轮所有工作状态回收机的装载率都不超过90，则暂停其中装载率最高的回收机；若多台回收机装载率同为最高，则暂停编号最小的那台。

用 `s[i]` 记录 `i` 号回收机的状态：`s[i]` 为1表示工作中，为0表示暂停（清运中）。系统启动时，0～4号回收机工作，5号回收机暂停。

(1) 系统启动后第一次采集到0～5号回收机的装载率依次为 `[0,0,0,0,0,0]`，求第一轮调度结束被暂停的回收机编号______。（填写0～5的阿拉伯数字）

(2) 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
n = 6
a = [0] * n  # a[i]存放i号回收机的装载率
s = [1, 1, 1, 1, 1, 0]  # s[i]为1表示回收机工作中，为0暂停（清运维护中）
while True:
    # 延时1小时，采集各回收机装载率存入a，代码略
    for i in range(n):
        if s[i] == 0 and a[i] == 0:
            ______①______
    t = -1
    cnt = 0
    for i in range(n):
        if s[i] == 0:
            continue
        if ______②______:
            s[i] = 0
            cnt += 1
        elif t == -1 or a[i] > a[t]:
            t = i
    if ______③______:
        s[t] = 0
```

---

## 答案

**正确答案：** (1) 0；(2) ① `s[i] = 1`；② `a[i] > 90`；③ `cnt == 0 and t != -1`。

---

## 解析

先恢复清运完成的机器，再遍历工作机。超过90的机器暂停并计数；若没有这种机器且候选存在，则暂停装载率最高者。严格大于才更新t，保证并列时编号最小。全零时5号先恢复，随后0号被选中暂停。
