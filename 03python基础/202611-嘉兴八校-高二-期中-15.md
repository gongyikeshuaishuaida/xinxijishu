# 题目 15

有如下程序段：

```python
from random import randint
a = [0] * 6
for i in range(6):
    if i % 2 == 0:
        a[i] = randint(1, 10)
    else:
        a[i] = randint(2, 8) * 2 - 1
print(a)
```

执行该程序段后，a 的值可能是（   ）

- A. `[4, 7, 11, 5, 8, 7]`
- B. `[7, 1, 3, 7, 5, 15]`
- C. `[10, 3, 3, 9, 2, 7]`
- D. `[9, 7, 2, 10, 1, 9]`

---

## 答案

**正确答案：** C

---

## 解析

偶数下标取 1～10，奇数下标取 3～15 的奇数，只有 C 同时满足。
