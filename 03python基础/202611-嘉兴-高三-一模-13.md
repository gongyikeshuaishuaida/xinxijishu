# 题目 13

传感器应每分钟采集 1 次数据，数据元素格式为 `[相对时刻，读数]`，相对时刻的值为距离 0 点的分钟数。现要对数据进行整理，规则如下：

① 补缺失数据：相邻两条数据时间差大于 1 分钟时，中间缺失的每个时间点读数，用前后读两个读数与缺失数据形成的等差数列填充。

② 修正信号跳变: 若某读数同时比前、后读数的差异不小于 20, 用前后读数的算术平均值替换该读数。

(1) 实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
data = [[0, 20], [1, 22], [4, 28], [5, 90], [6, 32]]
filled = []
for i in range(len(data) - 1):
    t1, v1 = data[i][0], data[i][1]
    t2, v2 = data[i + 1][0], data[i + 1][1]
    filled.append([t1, v1])
    if ______①______:
        m = (v2 - v1)/(t2 - t1)  # 等差数列公差
        for k in range(1, t2 - t1):
            filled.append([t1 + k, ______②______])  # 原卷加框处
filled.append(data[-1])
print(filled)
result = []
for x in filled:
    result.append([x[0], x[1]])
for i in range(1, len(filled) - 1):
    v0 = filled[i - 1][1]
    v1 = filled[i][1]
    v2 = filled[i + 1][1]
    if v1 - max(v0, v2) >= 20 or v1 - min(v0, v2) <= -20:
        ______③______
print(result)
```

(2) 以代码中的数据运行程序，加框处代码的执行次数为______次。

---

## 答案

**正确答案：** (1) ① `t2 - t1 > 1`；② `v1 + m * k`；③ `result[i][1] = (v0 + v2) / 2`；(2) 2。

---

## 解析

相邻时刻差大于1才有缺失点，按等差数列插值。跳变判断始终读取filled，修正写入result，避免前一处修正影响后一处判断。1至4分钟之间缺少2、3分钟，补值语句执行2次。
