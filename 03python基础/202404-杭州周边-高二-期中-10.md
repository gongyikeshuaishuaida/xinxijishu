# 题目 10

10. 某 Python 程序段如下：

```python
s = "420play+2qQ"
res = ""
for i in range(len(s)):
    if "0" <= s[i] <= "9":
        res = s[i] + res
    if i % 3 == 0 and "a" <= s[i] <= "z":
        res = res + chr(ord(s[i]) - 32)
print(res)
```

执行该程序段后，输出的结果是（ ）

- A. `4202PYQ`
- B. `2024A`
- C. `PYQ4202`
- D. `2024PYQ`

---

## 答案

**正确答案：** D

---

## 解析

数字字符从左侧依次插到结果首部形成 `2024`；下标 3、6、9 的小写字母转换为大写并追加，得到 `2024PYQ`，故选 D。
