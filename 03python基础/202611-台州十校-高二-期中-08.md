# 题目 08

在 Python 中，字符比较依据 ASCII 码值。执行下面表达式：`"apple" > "App"`，关于该表达式运算结果正确的是（   ）

- A. True

- B. true

- C. False

- D. false

---

## 答案

**正确答案：** A

---

## 解析

字符串按字符编码逐位比较。首字符a的ASCII码大于A，因此表达式为True；Python布尔值首字母须大写。
