# 题目 10

有如下 Python 程序段：

```python
s = input()
k = 3
cnt = j = c = 0
for x in s:
    if '0' <= x <= '9':
        c = c * 10 + int(x)
        j += 1
    else:
        if j >= k:
            cnt += c
        j = c = 0
print(cnt)
```

若输入 “ab30cd201e2024fg002h” 后运行程序段，输出结果为（ ）
- A. 2024
- B. 2227
- C. 2225
- D. 2257

---

## 答案

**正确答案：** B

---

## 解析

程序把连续数字串转换为整数，仅当数字串长度不少于 3 时累加。输入中的 30 长度为 2 不计入，201、2024、002 分别贡献 201、2024、2，总和为 2227。
