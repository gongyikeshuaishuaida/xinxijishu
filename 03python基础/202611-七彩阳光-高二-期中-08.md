# 题目 08

图书馆按照读者的年度积分 s 进行会员等级划分，积分在 t1 到 t2 之间（包含 t1 和 t2）为银牌会员，积分超过 t2 为金牌会员，其余情况为普通会员。下列 Python 程序段中，不能实现该规则的是（   ）

- A.

    ```python
    if s > t2:
        level = "金牌会员"
    elif s >= t1:
        level = "银牌会员"
    else:
        level = "普通会员"
    ```

- B.

    ```python
    level = "普通会员"
    if s <= t2:
        if s >= t1:
            level = "银牌会员"
        if s > t2:
            level = "金牌会员"
    ```

- C.

    ```python
    if s <= t2:
        if s >= t1:
            level = "银牌会员"
        else:
            level = "普通会员"
    else:
        level = "金牌会员"
    ```

- D.

    ```python
    level = "金牌会员"
    if s <= t2:
        level = "银牌会员"
        if s < t1:
            level = "普通会员"
    ```

---

## 答案

**正确答案：** B

---

## 解析

B 中两次 if 是嵌套关系，s>t2 时无法进入内层第二个 if，不能设为金牌；其余程序覆盖三个区间。
