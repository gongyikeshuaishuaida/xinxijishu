# 题目 09

中学生（男）的跳远标准如下，设 s 为学生的跳远距离，level 为学生的最终等第，则下列 Python 程序段中，无法正确输出该生跳远体测成绩的是（   ）。

![[attachments/202411台州山海协作体_09_跳远标准.png]]

- A.

  ~~~python
  level="不及格"
  if s>=1.85:
      level="及格"
  if s>=2.25:
      level="良好"
  if s>=2.4:
      level="优秀"
  ~~~

- B.

  ~~~python
  level="不及格"
  if s>=1.85:
      level="及格"
  elif s>=2.25:
      level="良好"
  elif s>=2.4:
      level="优秀"
  ~~~

- C.

  ~~~python
  if s<2.25:
      if s>=1.85:
          level="及格"
      else:
          level="不及格"
  else:
      level="优秀"
      if s<2.4:
          level="良好"
  ~~~

- D.

  ~~~python
  if s>=2.4:
      level="优秀"
  elif s>=2.25:
      level="良好"
  elif s>=1.85:
      level="及格"
  else:
      level="不及格"
  ~~~

---

## 答案

**正确答案：** B

## 解析

B 先判断 s>=1.85，凡是达到及格线的成绩都会进入第一个分支，后面的 elif 不会再判断，因此 s>=2.25 或 s>=2.4 时不能输出良好或优秀。A、C、D 的分支逻辑能够覆盖四个区间。
