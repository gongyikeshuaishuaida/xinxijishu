# 题目 08

将分数转换为对应等级的规则为：90 分及以上评定为 A 等，60 分至 89 分评定为 B 等，60 分以下评定为 C 等。下列 Python 语句不能实现该功能的是（   ）

- A.

    ```python
    if score >= 90:
        grade = "A"
    elif score >= 60:
        grade = "B"
    else:
        grade = "C"
    ```

- B.

    ```python
    if score >= 90:
        grade = "A"
    if score >= 60 and score < 90:
        grade = "B"
    else:
        grade = "C"
    ```

- C.

    ```python
    if score >= 60:
        grade = "B"
    else:
        grade = "C"
    if score >= 90:
        grade = "A"
    ```

- D.

    ```python
    if score >= 90:
        grade = "A"
    if score >= 60 and score < 90:
        grade = "B"
    if score < 60:
        grade = "C"
    ```

---

## 答案

**正确答案：** B

---

## 解析

B 的 else 只归属于第二个 if，score=95 时先赋 A，随后会被 else 覆盖为 C。
