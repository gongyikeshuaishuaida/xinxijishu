# 题目 12

某英文字符加密方法以单个字符为单位：先对字母和数字循环移位，再将移位后的 ASCII 码与密钥分别转成 7 位二进制数并逐位异或，最后转回字符。

（1）对明文字符做移位处理属于简单加密算法中的 ______①______（单选，填字母：A. 换位密码法 / B. 替代加密法）。

（2）主程序从文件读取明文 `pText` 和密钥列表 `keys`。例如 `keys=[[2,30],[3,40],[4,50]]`，每个字符循环使用一组密钥。请补全：

```python
cText = ""
for i in range(len(pText)):
    p = ______②______
    ch_new = chShift(pText[i], keys[p][0])
    ch_new = XorEncrypt(ch_new, keys[p][1])
    cText += ch_new
print("加密后的密文为:" + cText)
```

（3）请补全字符移位函数中对其他字符的处理：

```python
def chShift(ch, k):

        newch = chr((ord(ch)-ord("A")+k)%26+ord("A"))
    elif "0" <= ch <= "9":
        newch = str((int(ch)+k)%10)
    else:

    return newch
```

（4）请补全 `toBit(x)`：

```python
def toBit(x):
    a = [0] * 7; i = 6
    while x > 0:
        a[i] = x % 2
        x = x // 2

```

（5）请补全逐位异或函数：

```python
def XorEncrypt(ch, key):

    b = toBit(key)
    new_asc = 0
```

---

## 答案

**正确答案：** （1）B；（2）`i % len(keys)`；（3）`newch = ch`；（4）`i -= 1`；（5）`(a[i] + b[i]) % 2`（或 `abs(a[i] - b[i])` 等等价写法）。

---

## 解析

移位会改变字符的替代结果，属于替代加密法。密钥下标按字符位置对密钥组数取模。非字母、数字字符保持不变；二进制数组从低位向高位填充时每次循环都要将下标减 1；异或可用 `(a[i] + b[i]) % 2` 实现。
