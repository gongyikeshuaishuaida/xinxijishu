# 题目 15

接上题，业主远程查看留言需要通过登录物业APP，在登录时需要输入卡号和密码。为确保信息安全，密码需加密存储。某字符加密算法的思路如下：

1）只针对英文字符和数字进行加密，其余字符保持不变；

2）将原文中的大写字母转换成小写字母；

3）根据 2）所得结果，若是英文字符，则逐个前移 2 位（例如“a”→“y”，“c”→“a”）；若是数字，则逐个后移 2 位（例如“3”→“5”，“9”→“1”）。

请回答下列问题：

（1）若加密后的密码是“az@1502”，则原始密码可能是 ______。

（2）用计算机解决问题的过程一般包括四步：①设计算法；②调试运行程序；③编写程序；④抽象与建模，这四个步骤的正确顺序是 ______；

（3）编写如下Python程序段，实现对单个字符x的加密，请在划线处填入合适的代码。



```python
if "A" <= x <= "Z":
    x = chr(ord(x) + 32)
if "a" <= x <= "z":
    ans = ______①______
elif "0" <= x <= "9":
    ans = str((int(x) + 2) % 10)
else:
    ans = x
```



（4）用户登录物业APP需要进行验证，如图所示流程图用于登录时密码验证。密码有三次输入机会，若连续三次输错密码，则结束输入并提示“机会已用完”，若三次以内（包含三次）输入正确的密码，则结束输入并提示“密码正确”。流程图①②处代码可以实现该功能的是 ______（单选，填字母）

![[attachments/202611S9联盟高二_15_图1.png]]

- A. ① `x == pw or n == 3`；② `n == 3`

- B. ① `x == pw and n == 3`；② `n == 3`

- C. ① `x == pw or n == 3`；② `x != pw`

- D. ① `x == pw and n == 3`；② `x != pw`

---

## 答案

（1）例如 `cb@9380`（字母 c、b 可分别使用大写或小写）。

（2）④①③②。

（3）① `chr((ord(x)-97-2)%26+97)`。

（4）C。

---

## 解析

逆向将密文字母后移 2 位，数字前移 2 位，可得 c、b、9、3、8、0。字符转换通过取模实现首尾循环。密码正确或输入满三次时退出循环，退出后再判断密码是否错误；如果第三次输入正确，仍须提示密码正确，不能只按输入次数判失败。
