# 题目 09

有如下 Python 程序段：

```python
s = "Science"
t = ""
for i in range(0, len(s), 2):
    t += s[i]
print(t)
```

执行该程序段后，输出的结果是（   ）

- A. `Sinee`
- B. `Science`
- C. `Sine`
- D. `See`

---

## 答案

**正确答案：** C

---

## 解析

`range(0, len(s), 2)` 依次取下标 0、2、4、6，对应字符 `S、i、n、e`，所以输出 `Sine`，选 C。
