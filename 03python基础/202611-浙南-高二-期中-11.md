# 题目 11

下列自定义函数的功能为判断一个正整数是否存在连续重复的数字；若存在重复返回 True，否则返回 False；例如正整数 112 存在重复，正整数 121 不重复。Python 程序代码如下：

```python
def rep(n):
    a = n % 10
    flag = False
    while n > 0 and not flag:
        ______
        ______
        if a == b:
            flag = True
        ______
    return flag
```

下划线处由以下语句组成：① `a=b`；② `n//=10`；③ `b=n%10`。下列选项中，代码顺序正确的是（   ）

- A. ①②③

- B. ①③②

- C. ②①③

- D. ②③①

---

## 答案

**正确答案：** D

---

## 解析

先去掉已比较的末位，再读新的末位，与旧末位比较后更新旧值，顺序为②③①。
