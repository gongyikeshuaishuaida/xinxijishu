# 题目 22

有如下Python程序段，执行该程序段后，输出的结果可能是（   ）

```python
import random
a=[0]*6;i=0
while i<6:
    a[i]=random.randint(1,10)
    if a[i]==i*2:
        a[i]=0
        i+=1
    elif a[i]%2==i%2:
        a[i]=a[i]-1
        i+=1
print(a)
```

- A. `[3,2,5,4,9,10]`
- B. `[3,4,9,0,3,6]`
- C. `[1,2,7,4,8,5]`
- D. `[0,8,1,6,0,0]`

---

## 答案

**正确答案：** B

---

## 解析

只有满足两个分支之一才推进下标。B可以由每个下标首次随机到 `[4,5,10,6,4,7]` 实现：正常分支各减1，下标3随机到6等于 `2*i`，变为0。A最后的10不可能产生；C在下标4出现偶数8、下标5出现奇数5不符合输出约束；D的下标0为0不可能，因为随机范围不含0，且通常分支只能产生正奇数。
