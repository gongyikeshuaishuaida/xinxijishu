# 题目 10

有如下 Python 程序段：

```python
def fun(x):
    x += 3
    return x

x = 3
print(fun(x), x)
```

执行该程序段后，输出的结果是（   ）

- A. 3 3
- B. 6 3
- C. 6 6
- D. 报错

## 答案

**正确答案：** B

## 解析

调用 `fun(3)` 时，形参 `x` 在函数内部变为 6 并返回；函数外的整数变量 `x` 仍为 3，所以输出 `6 3`。
