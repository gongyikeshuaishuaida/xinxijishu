# 题目 13

某中学社团有 7 位成员，编号 0～6。系统每周采集成员周末打卡积分，a[i] 代表 i 号成员打卡积分（0 代表本周未打卡）。

统计打卡规则：

① 打卡积分大于 88，标记为优秀成员；

② 如果没有成员达到优秀标准，选取打卡积分最高的成员进行鼓励；多个人积分同为最高，选取编号最大的成员；

③ 本周未打卡（a[i]==0）成员不进行鼓励；

④ 一轮统计结束，等待下一周采集数据。

请回答下列问题：

(1) 某次采集 0～6 号成员打卡积分依次：73，82，77，82，0，71，79，未打卡成员编号为 4，本次需要鼓励的成员编号是 。

（2）实现统计功能的部分 Python 程序如下，请补全划线代码。

```python
n = 7
a = [0] * n    # a[i]存储 i 号成员打卡积分，0 代表未打卡
while True:
    # 读取一周打卡数据存入a，代码略
    t = 0
    cnt = 0
    for i in range(n):
        if ______①______:
            # 将 i 号标记为优秀，代码略
            cnt += 1
        # 更新最大值，同分选取编号最大
        if ______②______:
            t = i
    if ______③______:
        # 鼓励 t 号成员，代码略
```

---

## 答案

（1）3。

（2）① `a[i]>88`，② `a[i]>=a[t]`，③ `cnt==0 and a[t]!=0`。

---

## 解析

没有积分超过 88。最高分 82 出现在编号 1 和 3，按规则选 3。从小到大扫描时用大于等于更新，同分就保留后遇到的较大编号。
