# 题目 10

有如下 Python 程序段：

```python
res = ""
i, k = 0, 2
while i < len(s):
    if "0" <= s[i] <= "9":
        res = s[i] + res
        i += 2
    else:
        res += chr((ord(s[i]) - ord("a") + k) % 26 - 32 + ord("a"))
        i += 1
print(res)
```

对于任意的字符串 `s`，运行程序后，下列说法不正确的有（   ）

① 该程序可能进入死循环  
② `res` 中只可能出现数字字符与大写字母  
③ 将 `k` 改成 28，程序功能不变  
④ 数字字符不可能出现在 `res` 的最后一位

- A. ①②
- B. ③④
- C. ①④
- D. ②③④

---

## 答案

**正确答案：** C

---

## 解析

`i` 每轮增加 1 或 2，循环一定结束，①错误。数字分支保留数字，另一分支的字符编码在 65 到 90 之间，②正确。28 与 2 相差 26，取模结果相同，③正确。输入 `s = "5"` 时输出 `"5"`，④错误。
