# 题目 10

定义如下函数：

~~~python
def f(n):
    if n==1:
        return str(n)
    else:
        return str(n%2)+f(n//2)
~~~

执行语句 k=f(20) 后，k 的值为（   ）

- A. "00101"
- B. "10101"
- C. "10100"
- D. "01001"

---

## 答案

**正确答案：** A

---

## 解析

递归每次先把当前数除以2的余数放在结果前面。计算过程为 f(20)="0"+f(10)，f(10)="0"+f(5)，f(5)="1"+f(2)，f(2)="0"+f(1)，f(1)="1"，拼接得到 "00101"，选A。
