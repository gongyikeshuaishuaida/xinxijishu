# 题目 12

有如下 Python 程序段：

```python
# 随机产生 10 个互不相等的整数存入列表 a，代码略
m, r = 0, 0
for i in range(1, len(a)):
    if a[i] > a[m]:
        m = i
    else:
        r = i
```

执行该程序段后，r 的值为 6，则下列表达式中，值一定为 True 的是（   ）

- A. `a[6]>a[5]`

- B. `a[7]>a[6]`

- C. `a[4]>a[6]`

- D. `a[6]>a[9]`

---

## 答案

**正确答案：** B

---

## 解析

r=6 表示下标 7、8、9 都未进入 else，均刷新此前最大值，所以 a[7] 大于 a[6]。
