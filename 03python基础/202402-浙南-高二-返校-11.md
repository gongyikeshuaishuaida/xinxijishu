# 题目 11

有如下 Python 程序段：

```python
s = "5A9C3B0E7D"
ans = ""; i = 0
while s[i] != "0":
    t = int(s[i])
    ans += s[t]
    i = t - 1
print(ans)
```

运行该程序段后，变量 `ans` 的值是（  ）

A．`"BCDEA"`

B．`"BCD"`

C．`"ABCD"`

D．`"BCDE"`

## 答案

**正确答案：** D

## 解析

按索引跳转依次访问 `s[5]='B'`、`s[3]='C'`、`s[9]='D'`、`s[7]='E'`，随后 `s[6]='0'` 结束循环，因此 `ans` 为 `BCDE`。
