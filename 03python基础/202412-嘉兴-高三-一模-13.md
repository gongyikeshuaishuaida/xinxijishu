# 题目 13

编写 Python 程序求生日幸运数。算法如下：遍历身份证号，提取其中最大连续非0数字（遇到0，当前连续结束；“X”作10处理）的和作为生日幸运数，如下图中连续数字“21982”各位数字的和（2+1+9+8+2=22）最大，输出22作为生日幸运数。

![[attachments/202412嘉兴_13_生日幸运数运行界面.png]]

程序运行界面如上图所示。

13. （1）输入身份证号 33040220060102123X，输出的生日幸运数为 ______①______。

（2）程序如下，请在划线处填入合适的代码。

~~~python
s=input('请输入您的身份证号：')
max=0;sum=0
for i in s:
    if ______①______:
        if sum>max:
            max=sum
        ______②______
    else:
        if i=='x' or i=='X':
            sum+=10
        else:
            ______③______
if sum>max:
    max=sum
print('您的生日幸运数为：',max)
~~~

---

## 答案

（1）18

（2）① i=='0'（或 i<'1'、int(i)==0 等价写法）　② sum=0　③ sum += int(i)

---

## 解析

遇到字符0时，一段连续非0数字结束，先用 sum 更新 max，再将 sum 清零。遇到数字字符时，将其转换成整数累加；字符X按10累加。输入 33040220060102123X 的最后一段 2123X 的和为 2+1+2+3+10=18，且不小于其他连续段，因此结果为18；程序末尾还需比较最后一段。
