# 题目 11

有如下 Python 程序段：

```python
import random
n = 6
a = [0] * n
i = 0
while i < n:
    k = random.randint(1, 10)
    if k % 2 == 0:
        i = i - 1
    elif k % 3 == 0:
        a[n - 1] = k
        n = n - 1
    else:
        a[i] = k
        i = i + 1
```

执行该程序段后，列表 `a` 中的各元素可能的是（   ）

- A. `[0, 0, 3, 3, 6, 9]`
- B. `[1, 1, 0, 3, 7, 9]`
- C. `[5, 0, 0, 5, 7, 3]`
- D. `[0, 0, 5, 3, 3, 9]`

## 答案

**正确答案：** D

## 解析

程序用 `n` 控制有效长度，遇到 3 的倍数就从末端写入并缩短有效区间，偶数会使 `i` 回退。逐项检查可构造出 D 的结果；其他选项与偶数回退、末端写入和有效区间变化规律不符。
