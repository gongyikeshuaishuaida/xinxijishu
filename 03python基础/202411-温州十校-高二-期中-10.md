# 题目 10

根据下表的命令提示，以下 Python 程序代码运行后，画出的图形是（   ）

~~~python
import turtle

t=turtle.Pen() #画笔初始方向为正右方
t.right(90)

lengh=20
for i in range(6):
    t.forward(lengh)
    t.left(90)
    lengh=lengh+20
turtle.done()
~~~

![[attachments/202411温州十校_10_turtle图形选项.png]]

- A、B、C、D 图形选项见上图

## 答案

**正确答案：** D

## 解析

画笔初始向右，先右转 90° 向下，然后每画一条边左转 90°，边长依次为 20、40、60、80、100、120。将起始方向、转向和递增边长逐段对应到图中，得到 D。
