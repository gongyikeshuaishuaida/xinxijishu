# 题目 12

已知字符串 `s` 中存储了某校高二年级学生某学科的学考成绩（成绩以等级制表示，包含 A、B、C、D、E 五个等级），如 `s='AADDEACDBBB'`。编写 Python 程序，统计各等级人数，并按照 A 至 E 的顺序输出各等级人数占总人数的比例（以百分比形式表示）。

```python
s = input()
b = {}
for x in s:
    if x in b:
        __________  # (1)
    else:
        __________  # (2)
total = len(s)
for i in "ABCDE":
    __________  # (3)
    print(f"{i}等级占比：{p*100:.2f}%")
```

上述程序段中划线处可选代码为：

- ① `p = s[i] / total`
- ② `p = b[i] / total`
- ③ `b[x] = 1`
- ④ `b[x] += 1`

则（1）（2）（3）处语句依次为（   ）

- A. ④③①
- B. ④③②
- C. ③④②
- D. ③④①

---

## 答案

**正确答案：** B

---

## 解析

遍历字符串时，若等级已经在字典中，应把该等级计数加 1，填 ④；第一次遇到某等级时建立键值并置为 1，填 ③。统计完成后应使用字典中的等级人数 `b[i]` 除以总人数，填 ②。因此顺序为 ④、③、②，选 B。
