# 题目 11

某 Python 程序代码如下：

```python
s = "H2a3pp4y"
r = ""
for ch in s:
    if "0" <= ch <= "9":
        r = ch + r
    elif "A" <= ch <= "Z":
        r = r + chr(ord(ch)-ord("A")+ord("a"))
    elif "a" <= ch <= "z":
        r = r + chr(ord(ch)-ord("a")+ord("A"))
print(r)
```

运行该程序，输出的结果是（   ）

- A. h2A3PP4Y

- B. hAPPY234

- C. 432hAPPY

- D. 234hAPPY

---

## 答案

**正确答案：** C

---

## 解析

数字每次前插，最终数字部分为 432；字母原顺序保留但大小写互换，得到 hAPPY。
