# 题目 20

信息传递过程中通常会对敏感信息进行加密，设计实现加密功能的Python程序段如下：

```python
s = input("明文：")
p=""
key = 3
for ch in s:
    if "0"<=ch and ch<="9":
        p += str((int(ch)+key)%10)
    else:
        p = ch+p
print(p)
```

执行该段程序，输入kz872，则输出结果是（   ）

- A. kz105
- B. 105zk
- C. zk105
- D. 105kz

---

## 答案

**正确答案：** C

---

## 解析

非数字字符插到字符串开头，所以k、z处理后得到zk。数字加3后模10，再追加到末尾：8→1、7→0、2→5，最终为zk105。
