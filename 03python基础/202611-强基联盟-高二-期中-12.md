# 题目 12

有如下 Python 程序段：

```python
s = "A3dx7Bx2b79"
a = [2,1,0,3]
ans = ""
i = j = 0
for ch in s:
    if "0" <= ch <= "9":
        ans += str((int(ch)+a[i])%10)
        i = (i+1)%4
    elif "A" <= ch <= "Z":
        ans += chr((ord(ch)-ord("A")+a[j])%26+ord("A"))
        j = (j+1)%4
    else:
        ans += chr((ord(ch)-ord("a")+a[j])%26+ord("a"))
        j = (j+1)%4
```

执行该程序段后，变量 i、`ans[3]` 的值为（   ）

- A. 1 x

- B. 0 x

- C. 0 y

- D. 1 y

---

## 答案

**正确答案：** A

---

## 解析

数字字符共 5 个，所以 i 最终为 1。ans[3] 对应字母 x，使用偏移 a[2]=0，仍为 x。
