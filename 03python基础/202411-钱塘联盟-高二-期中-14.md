# 题目 14

一个数，求它的所有数位的平方和，得到的新数再次求其所有数位的平方和，如此重复，最终结果为 1，则称该数为快乐数。如：正整数 129，求得其每个位置上的数字的平方和，重复过程如下：1**2 + 2**2 + 9**2 = 86；8**2 + 6**2 = 100；1**2 + 0**2 = 1。所以 129 是一个快乐数。

（1）根据以上规则，数字 13 ______①______（选填：是/否）快乐数。

（2）编写程序如下，请在划线处填入合适的代码。

~~~python
def sqrare_sum(n):
    temp = 0
    while n > 0:
        ______②______
        temp = temp + t
        n //= 10
    return temp

num = int(input('请输入一个正整数：'))
n = num
res = []
while ______③______:
    res.append(n)    # 将 n 的值添加到列表 res 的尾部
    n = ______④______
    if n in res:
        break
if n == 1:
    print(num, '是快乐数！')
else:
    print(num, '不是快乐数！')
~~~

---

## 答案

（1）① 是

（2）② t=(n%10)**2　③ n!=1　④ sqrare_sum(n)

---

## 解析

13 的数位平方和为 1**2+3**2=10，再计算 1**2+0**2=1，所以 13 是快乐数。函数每次取 n 的个位平方加入累加值，再用整除 10 去掉个位；循环在 n 不为 1 时继续，下一轮 n 由 sqrare_sum(n) 更新。
