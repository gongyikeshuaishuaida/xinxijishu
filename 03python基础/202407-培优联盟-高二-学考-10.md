# 题目 10

编写 Python 程序：输入英文文本至字符串 s，已知 s 中每个句子都以句号结束，将每个句子的第一个单词首字母大写，其余字母修改为小写。请补全：

```python
s = input()
flag = True
res = ""
for i in range(len(s)):
    if ______①______:
        if "a" <= s[i] <= "z":
            res += chr(ord(s[i]) - ord("a") + ord("A"))
        else:
            res += s[i]
        flag = False
    else:
        if "A" <= s[i] <= "Z":
            res += chr(ord(s[i]) + ord("a") - ord("A"))
        else:
            res += s[i]
        if ______②______:
            flag = True
print(res)
```

- A. ① flag == True；② s[i] == "."
- B. ① flag == True；② s[i] != "."
- C. ① flag == False；② s[i] == "."
- D. ① flag == False；② s[i] != '.'

---

## 答案

**正确答案：** A

---

## 解析

flag=True 表示位于句子第一个单词的首字母位置；处理完字符后，遇到句号才把 flag 重新置 True，所以 ①为 flag == True，②为 s[i] == "."。
