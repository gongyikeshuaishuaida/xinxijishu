# 题目 08

人体最适宜的环境温度在18℃到25℃之间（包括18℃和25℃），设 `t` 为环境温度，人体感受存储在变量 `r` 中。下列选项正确的是（   ）

- A.

  ```python
  r = "温度过低"
  if t >= 18:
      r = "温度适宜"
  elif t > 25:
      r = "温度过高"
  ```

- B.

  ```python
  r = "温度过低"
  if t >= 18:
      r = "温度适宜"
  if t > 25:
      r = "温度过高"
  ```

- C.

  ```python
  r = "温度适宜"
  if t >= 25:
      r = "温度过高"
  elif t < 18:
      r = "温度过低"
  ```

- D.

  ```python
  r = "温度过高"
  if t <= 25 and t >= 18:
      r = "温度适宜"
  else:
      r = "温度过低"
  ```

---

## 答案

**正确答案：** B

---

## 解析

温度低于18℃应为“温度过低”，18℃到25℃应为“温度适宜”，高于25℃应为“温度过高”。B先判断 `t>=18`，再独立判断 `t>25`，能覆盖三个区间；A的 `elif t>25`不可能执行，C漏掉了低温区间，D把高温初值和低温分支关系写反，因此选择B。
