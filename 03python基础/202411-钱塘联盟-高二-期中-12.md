# 题目 12

有如下 Python 程序段：

~~~python
import random
s=''
i=0
while i<5:
    k = random.randint(1,10)
    # 函数 randint(a,b) 产生 [a,b] 范围内的整数
    c=chr(96+k)
    if i % 2 == k % 2:
        s=s+c
        i=i+1
print(s)
~~~

若该段程序执行以后，s 的值可能的是（   ）

- A. 'abcde'
- B. 'abcdi'
- C. 'hahah'
- D. 'efghi'

---

## 答案

**正确答案：** C

---

## 解析

只有当 i 与 k 的奇偶性相同时才会追加字符并使 i 加 1。选项 C 中 h、a、h、a、h 分别可以由偶数、奇数、偶数、奇数、偶数的 k 产生，因此可能出现；其他选项的字符奇偶性序列不能满足相应 i 的要求。
