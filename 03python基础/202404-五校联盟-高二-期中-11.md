# 题目 11

有如下 Python 程序段：

```python
s = "Li20An24K04ao"
i = 0
while i < len(s):
    if "A" <= s[i] <= "Z":
        s = s[:i] + s[i+1:]
    elif "0" <= s[i] <= "9":
        s = s[:i] + str((int(s[i]) + 8) % 10) + s[i+1:]
    else:
        s = s[:i] + chr((ord(s[i]) - 95) % 26 + 97) + s[i+1:]
    i = i + 1
```

执行上述程序后，s 的值为（   ）

- A. `k08p0202co`
- B. `i08n0202cq`
- C. `i08p0202cq`
- D. `h28w22g82o`

## 答案

**正确答案：** B

## 解析

按程序逐位处理，大写字母删除，数字加 8 后对 10 取模，小写字母按给定公式替换，程序运行结果为 `i08n0202cq`。
