# 题目 08

系统背景：小李家大棚葡萄园安装了智能滴灌系统。智能终端通过湿度传感器采集土壤湿度数据并上传到 Web 服务器，服务器将数据保存到数据库；当湿度低于或超过阈值时，智能终端控制灌水器自动调节。系统通过光猫接入互联网，小李用浏览器输入账号和密码登录，连续 3 次密码错误会锁定账号。

8.实现“若连续 3 次输入的密码不正确，系统自动锁定账号”功能，变量 `pwd` 存输入的密码，变量 `key` 存正确的密码，变量 `n` 存输入密码的次数。部分 Python 代码如下，加框处代码正确的是（ ）

```python
# 输入密码存变量 pwd，代码略
f = True
n = 0
while ______:
    n += 1
    if n > 3:
        f = False

# 输入密码存变量 pwd，代码略
if f == False:
    print('锁定账号')
```

- A. `pwd != key`
- B. `f == True and pwd != key`
- C. `pwd == key`
- D. `f == True and pwd == key`

---

## 答案

**正确答案：** B

---

## 解析

循环应在账号尚未锁定且本次密码错误时继续，因此条件为 `f == True and pwd != key`。密码正确或已锁定时退出循环，连续错误达到 3 次后再输出锁定提示。
