# 题目 15

15.程序统计字符串中的数字字符：

~~~python
def js(s):
    c=0
    for i in range(len(s)):
        if "0"<=s[i]<="9":
            c+=1
    return c
~~~

若输出 yes，变量 s 的值是（ ）

- A.2024xxjs
- B.Actionism
- C.20240623
- D.SHA-1

---

## 答案

**正确答案：** C

---

## 解析

只有 C 的每个字符都是数字，因此 c 等于字符串长度，输出 yes。
