# 题目 14

男装尺码划分与身高（165cm～185cm）的对照如下表所示：

![[attachments/202610强基联盟高二_14_图1.png]]

某男装网店根据客户填写的身高、体重计算体质指数BMI，为客户推荐尺码（不在165cm～185cm范围内无尺码推荐）。BMI的计算公式为：`体重(kg)/[身高(m)]²`，若`BMI<24`，则推荐表中身高对应的尺码，否则加大一码推荐（若超过XXL尺码，则无尺码推荐）。

（1）若某客户的身高为172cm，体重80kg，则该网店给出的推荐尺码为______。

（2）实现计算推荐尺码的Python程序如下，请在划线处填入合适的代码。

```python
def size(h,w):       # 参数h表示身高(cm)，参数w表示体重(kg)
    if h<165 or h>185:
        return "抱歉，没有您的尺码！"
    if h<170:
        base="M"
    elif ______①______:
        base="L"
    elif h<180:
        base="XL"
    else:
        base="XXL"
    h=h/100
    bmi=w/h*h
    up={"M":"L","L":"XL","XL":"XXL","XXL":"抱歉，没有您的尺码！"}
    if bmi>=24:
        ______②______
    else:
        final=base
    return final
h=int(input("输入身高(cm)："))
w=int(input("输入体重(kg)："))
print("推荐尺码：",______③______)
```

（3）加框处代码有误，请修改。

原卷加框处为`bmi=w/h*h`。

---

## 答案

（1）XL。

（2）①`h<175`；②`final=up[base]`；③`size(h,w)`。

（3）`bmi=w/(h*h)`（或`bmi=w/h**2`）。

---

## 解析

（1）按身高先确定基础尺码，再按BMI判断是否加大一码。172cm的基础尺码为L，80/(1.72×1.72)约为27.04，不小于24，因此推荐XL。

（2）①接在h<170分支之后，只需判断h<175；②利用字典up将基础尺码映射为大一码的结果；③调用函数size，传入h和w。

（3）除法和乘法同级，从左到右计算。原式w/h*h近似等于w，未除以身高的平方；必须用括号或平方运算符。题干保留错式，答案按题目要求修正。

参考答案解析将函数调用的体重实参写成m，是解释文字笔误；题面及答案代码实际使用w。
