# 题目 09

有如下 Python 程序段：

```python
a = [10,18,18,20,19,20,13]
s = 0
for i in range(0, len(a)-1):
    if a[i] > a[i+1]:
        s += a[i+1]
print(s)
```

该程序段执行后，输出结果是（   ）

- A. 19

- B. 32

- C. 50

- D. 58

---

## 答案

**正确答案：** B

---

## 解析

只在前一项大于后一项时累加后一项，20>19 和 20>13 两处累加，得到 32。
