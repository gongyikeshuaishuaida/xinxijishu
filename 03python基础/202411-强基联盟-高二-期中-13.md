# 题目 13

有如下 Python 程序段：

~~~python
n=5
k=t=0
for i in range(1,n+1):
    t=i**k
    if t>100:
        break
    k+=1
~~~

执行该程序段后，t 和 k 的值为（   ）

- A. 64，4
- B. 64，5
- C. 625，4
- D. 625，5

---

## 答案

**正确答案：** C

## 解析

各次循环开始时的 k 依次为 0、1、2、3、4。当 i=5 时计算 t=5^4=625，满足 t>100，直接跳出循环，k 仍为 4。因此选 C。
