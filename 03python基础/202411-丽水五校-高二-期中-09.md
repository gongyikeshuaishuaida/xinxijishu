# 题目 09

9. 中学生一分钟仰卧起坐体测标准为：小于25个为不合格，大于45个为优秀，25至45个为良好。已知 `v` 为一分钟内的仰卧起坐个数，则下列 Python 程序段中，不能实现该功能的是（   ）

- A.

  ```python
  if v<25:
      print("不合格")
  elif v<=45:
      print("良好")
  else:
      print("优秀")
  ```

- B.

  ```python
  if v>45:
      print("优秀")
  elif v>=25:
      print("良好")
  else:
      print("不合格")
  ```

- C.

  ```python
  if v>45:
      print("优秀")
  if v<25:
      print("不合格")
  else:
      print("良好")
  ```

- D.

  ```python
  if v>=25:
      if v<=45:
          print("良好")
      else:
          print("优秀")
  else:
      print("不合格")
  ```

---

## 答案

**正确答案：** C

---

## 解析

A、B、D 都把三个区间互斥地覆盖。C 使用了两个独立的 `if`：当 `v>45` 时先输出“优秀”，随后第二个 `if` 的条件为假，又会进入 `else` 输出“良好”，因此不能保证只输出一个正确结果。
