# 题目 10

有如下Python程序段：

```python
s = "python"
k, i = 2, 0
while len(s) != 0:
    i = (i + k - 1) % len(s)
    print(s[i], end = "")
    s = s[:i] + s[i + 1:]
    k += 1
```

程序运行后，输出的结果为（   ）

- A. yohpnt
- B. yhntpo
- C. tpynho
- D. python

---

## 答案

**正确答案：** A

---

## 解析

每轮在当前字符串上重新计算下标，并删除输出的字符。六轮的 `(k, i, 输出字符, 删除后字符串)` 依次为 `(2,1,y,pthon)`、`(3,3,o,pthn)`、`(4,2,h,ptn)`、`(5,0,p,tn)`、`(6,1,n,t)`、`(7,0,t,空串)`，连续输出 `yohpnt`。
