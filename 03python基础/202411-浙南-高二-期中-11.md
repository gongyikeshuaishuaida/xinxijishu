# 题目 11

有如下 Python 程序段：

~~~python
k=1;m=0;n=4
w="aadmabebdabcdz"
for i in range(len(w)-1):
    if w[i]<=w[i+1]:
        k=k+1
    else:
        if k>=n:
            m+=1
        k=0
~~~

运行该程序段后，`m` 的值是（   ）

- A. 1
- B. 2
- C. 3
- D. 4

## 答案

**正确答案：** A

## 解析

程序在相邻字符不递增时检查当前连续段长度，达到 4 才累加 `m`。字符串中只有一段满足条件，因此 `m=1`。
