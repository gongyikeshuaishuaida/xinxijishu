# 题目 13

有`n`个集装箱要装上一艘载重量为`c`的轮船，其中集装箱`i`的重量为`w[i]`。现编写Python程序找出一种最优装载方案，将轮船尽可能装满，即在装载体积不受限制的情况下，将尽可能重的集装箱装上轮船。程序运行结果如图第13题图所示：

![[attachments/202610天域联盟_13_图1.png]]

程序代码如下：

```python
w = [6,3,5,6,6]  # 集装箱重量列表
c = 20
bestw = 0  # 初始化最优装载重量
bestc = []  # 存储最优解的集装箱索引
______①______
for i in range(2**n):  # 使用进制枚举所有物品的组合情况，共2**n种组合
    total = 0; curr = []
    for j in range(n):
        if i//2**j%2 == 1:  # 当i的第j位二进制为1，表示w[j]重量的集装箱装上船
            ______②______
            curr.append(j)
    if total <= c:
        if total > bestw:
            bestw = total
            bestc = [curr]  # 更新最优集装箱索引组合
        elif ______③______:
            bestc.append(curr)
print("最优装载重量：",bestw)
print("集装箱索引：",bestc)
```

(1) 如果轮船载重`c`改为21，最优装载重量的物品索引为______。

(2) 请在划线处填写合适的代码以完成上述功能。

---

## 答案

(1) `[0,1,3,4]`。

(2) ① `n=len(w)`；② `total+=w[j]`；③ `total==bestw`。

---

## 解析

枚举整数0～2ⁿ−1，每一位表示对应集装箱是否选中；`i//2**j%2`读取第j位。累加选中重量后，在载重限制内更新最优值，或追加同样最优的方案。载重21时选择重量6、3、6、6，合计21，对应索引0、1、3、4。
