# 题目 09

计算字符串中最多连续相同字符个数的程序如下：

```python
s = input("请输入字符串：")
k = 1
maxlen = 0
for i in range(1, len(s)):
    if s[i] == s[i - 1]:
        k = k + 1
    else:
        if k > maxlen:
            maxlen = k
        k = 1
print("最多连续相同字符个数为：", maxlen)
```

用以下数据测试，能测出程序错误的是（   ）

- A. `AAABBCCD`
- B. `AABBBCDD`
- C. `AABCCCDD`
- D. `ABBCCDDD`

---

## 答案

**正确答案：** D

---

## 解析

程序只在字符发生变化时更新 `maxlen`，循环结束后没有再比较末尾一段。D 的最长连续段 `DDD` 位于字符串末尾，因此会暴露错误。
