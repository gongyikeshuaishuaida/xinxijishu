# 题目 14

如果一个正整数是素数且含有数字 9，那么该数被称为“和9有关的素数”。程序通过键盘输入 `n`，寻找 10～`n` 中符合条件的数，运行界面如下：

![[attachments/202411浙里特色_14_运行界面.png]]

（1）该程序段采用的算法是 ______①______。（单选：A.解析算法；B.枚举算法）

（2）编写 `prime` 函数，判断变量 `t` 是否是素数。如果是素数返回 `True`，否则返回 `False`，请在划线处填入合适代码。

~~~python
def prime(t):
    p=True
    for i in range(2,t):
        if t%i==0:
            ______②______
            break
    return p
~~~

（3）编写 `pd` 函数，判断变量 `x` 是否是“和9有关的素数”。

~~~python
def pd(x):
    if prime(x) and ______③______:
        return True
    else:
        return False
~~~

（4）解决上述问题的主程序如下，请在划线处填入合适代码。

~~~python
n=int(input("请输入n的值："))
print("符合条件的数：")
for i in range(10,n+1):
    if ______④______:
        print(i,end=" ")
~~~

## 答案

- ① `B`
- ② `p=False`
- ③ `"9" in str(x)`
- ④ `pd(i)`（或 `pd(i)==True`）

## 解析

程序逐个检查 10 到 `n` 的整数，属于枚举算法。素数判断中一旦发现因数即可将 `p` 设为 `False`；“和9有关”还要求十进制表示中包含字符 `9`；主程序对每个候选数调用 `pd`。
