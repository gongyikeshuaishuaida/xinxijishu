# 题目 07

阅读下列材料，回答第 07 题。

某高中引入了智能运动会系统，系统根据收集到的报名信息和赛程自动安排分组等相关设置。系统利用摄像头实现比赛项目自动签到，输入比赛成绩后，服务器（计算机）自动统计名次和相应积分，并积分统计到相应班级中同时利用广播播报或大屏投屏比赛结果。

该校运动会项目设置依次有“100M、200M、400M、800M、1500M、跳高、跳远、铅球、三级跳远、4×100M 接力”，报名了该项目设置为“1”，没报名设置为“0”。已知运动员的项目信息为 st（例如 `st="0110000001"`），下列表达式不能判断报名了“4×100M”项目的是（   ）

- A. `st[-1] == "1"`

- B. `st[9] == "1"`

- C. `not st[9] != "0"`

- D. `int(st[10])-1 != 0`

---

## 答案

**正确答案：** D

---

## 解析

参考答案为 D，st[10] 会越界。原卷 C 为 not st[9] != "0"，等价于 st[9] == "0"，也不能正确判断报名接力；因此按原卷表达式，C、D 均有问题，单选题存在歧义。这里保留原选项并说明差异。
