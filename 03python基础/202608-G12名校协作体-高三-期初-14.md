# 题目 14

某校举行田径赛事活动，3 组（每组共 8 人）选手已完成预赛，现计划根据预赛的成绩挑选 8 名选手参加决赛。成绩位列所在小组前 2 名的选手直接入选，剩余名额按成绩由高到低依次挑选，选手的成绩各不相同。

现给定所有选手的预赛成绩数据表（已按成绩由高到低排列），每位选手的数据包含小组编号（0~2）、选手编号、成绩。编写程序，挑选出 8 名选手，并按照成绩排名确定决赛道次，如第 14 题图 a 所示。

![[attachments/202608G12名校协作体_14_图a.jpg]]

第14题图a

![[attachments/202608G12名校协作体_14_图b.jpg]]

第14题图b

请回答下列问题：

（1）对于第 14 题图 b 所示数据，决赛道次第 1 道的选手编号为 ______。

（2）实现根据选手成绩挑选决赛选手，并分配决赛道次功能的 Python 程序如下，请在划线处填入合适的代码。读取选手成绩数据表存入 data 列表，每个元素包含小组编号、选手编号、成绩 3 个数据项，代码略。

```python
count=[0,0,0]
b=[["",-1] for i in range(8)]
__________  #①
num=0
i=0
while num<8 and i<len(data):
    if count[data[i][0]]<2 or m>0:
        if __________:  #②
            b[3-num//2]=[data[i][1], data[i][2]]
        else:
            b[4+num//2]=[data[i][1], data[i][2]]
        num+=1
        __________  #③
        if count[data[i][0]]>2:
            m-=1
    i+=1
for j in range(8):
    print("决赛第",j+1,"道的选手编号：",b[j][0],"，成绩：",b[j][1])
```

---

## 答案

**正确答案：** （1）0015；（2）① `m=2`；② `num%2==0`；③ `count[data[i][0]]+=1`

---

## 解析

本题先直接录取各组前两名，共 6 人，因此初始超出所在组前两名的补录名额 `m=2`。按总成绩顺序，前两名补录到 `b` 的后半部分，其余直接入选者交替放入两侧道次；`num` 为偶数时写入 `3-num//2`，每录取一人都应增加对应小组的计数。
