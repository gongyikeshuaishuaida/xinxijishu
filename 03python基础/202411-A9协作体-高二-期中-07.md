# 题目 07

7. 下列 Python 表达式中，值为 `True` 的是（   ）

- A. `"pt" in "python"`
- B. `"123" > "python"`
- C. `121%2==1%3`
- D. `5//2>5/2`

---

## 答案

**正确答案：** C

---

## 解析

`"pt"` 不是字符串 `"python"` 的连续子串，A 为 `False`；字符串比较中 `"123"` 小于 `"python"`，B 为 `False`；C 两边均为 `1`，结果为 `True`；`5//2=2` 而 `5/2=2.5`，D 为 `False`。
