# 题目 12

有如下 Python 程序段：

~~~python
a=[1,2,3,-7,4,-2,6,8]
s,ans=a[0],a[0]
p=0
for i in range(1,len(a)):
    if s+a[i]>=0 and s+a[i]>a[i]:
        s+=a[i]
    else:
        s=a[i]
    if s>=ans:
        ans=s
        p=i
print(ans,p)
~~~

该程序段运行后，`ans` 和 `p` 的值为（   ）

- A. `14 7`
- B. `15 6`
- C. `16 7`
- D. `17 6`

## 答案

**正确答案：** C

## 解析

程序维护以当前位置结尾的最大连续子段和，并在达到更大值时记录下标。到下标 3 时，`s+a[3]` 不满足条件，程序将 `s` 重置为 `-7`；随后从下标 4 开始累计，得到 `4-2+6+8=16`，最终 `ans=16,p=7`，选 C。
