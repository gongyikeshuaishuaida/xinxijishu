# 题目 11

有如下 Python 程序段：

```python
sum = 0
j = 0
c = 0
s = "ab300cde2022fg002h"
for ch in s:
    if ch >= "0" and ch <= "9":
        c = c * 10 + int(ch)
        j = j + 1
    else:
        if j % 2 == 1:
            sum = sum + c
        else:
            sum = sum - c
        c = 0
```

执行该程序段后，`sum` 的值为（   ）

- A. -1720
- B. 1720
- C. 2320
- D. -2320

## 答案

**正确答案：** C

## 解析

连续数字段依次为 300、2022、002。`j` 记录已经读入的数字个数：遇到非数字时，奇数个数字段加上该数，偶数个数字段减去该数。因此 `sum=300+2022-2=2320`。
