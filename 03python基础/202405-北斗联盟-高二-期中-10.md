# 题目 10

10.某加密程序的代码如下：

```python
s = input("请输入明文：")
q = "1896720354"
mw = ""
for i in range(len(s)):
    if "0" <= s[i] <= "9":
        mw += q[int(s[i])]
    elif "a" <= s[i] <= "z":
        mw += chr((ord(s[i]) - ord("a") + i % 2) % 26 + ord("a"))
    else:
        mw = s[i] + mw
print(mw)
```

运行程序，若输入 `s` 的值为 `"Win98@qq.com"`，则输出结果是（ ）

- A.`.@Wjn45qrdon`
- B.`Wjn53@qr.don`
- C.`Wjn32@qr.don`
- D.`.@Wkp45sseqo`

---

## 答案

**正确答案：** A

---

## 解析

数字按字符串 `q` 的映射转换，小写字母按位置奇偶进行移位，其他字符插入结果串首部。逐字符处理 `Win98@qq.com` 得到 `.@Wjn45qrdon`，故选 A。
