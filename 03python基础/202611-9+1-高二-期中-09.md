# 题目 09

有如下 Python 程序段：

```python
d = {"a":[1,2], "b":[3,4]}
x = len(d["a"] + d["b"])
y = d["a"][1] + d["b"][0]
z = 3 in d
print(x, y, z)
```

运行该程序段后，输出结果是（   ）

- A. 4 5 True

- B. 2 5 False

- C. 4 5 False

- D. 2 3 True

---

## 答案

**正确答案：** C

---

## 解析

列表相加是拼接，长度为 4；第二式为 2+3=5；字典 in 判断键，键中没有整数 3。
