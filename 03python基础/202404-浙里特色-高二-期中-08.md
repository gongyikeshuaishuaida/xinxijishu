# 题目 08

8.有如下 Python 程序段：

```python
def fac(n):
    res = 0
    for i in range(n):
        res += 2 ** i
    return res
```

执行语句 `print(fac(5))`，输出的结果为（ ）

A.`30`　B.`31`　C.`62`　D.`63`

---

## 答案

**正确答案：** B

---

## 解析

`range(5)` 取 `0` 至 `4`，累加 `1+2+4+8+16=31`，所以输出 `31`。
