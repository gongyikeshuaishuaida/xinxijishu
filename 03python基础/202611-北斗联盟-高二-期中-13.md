# 题目 13

某图书馆的借阅系统会根据读者当月归还图书的状态进行积分结算与评级。每本图书基础分值

为 2 分，图书状态分为“完好”、“轻微破损”及”严重损坏”三类，计分规则如下：

① 若图书为“完好”状态，得 2 分；

② 若图书为“轻微破损”状态，得 1 分；

③ 若图书为“严重损坏”状态，当月积分直接清零,当月其它归还图书不再计算得分。

![[attachments/202611北斗联盟高二_13_图1.png]]

（1）若当月借阅图书的状态记录为 `["完好","轻微破损","完好","严重损坏","轻微破损"]`，则最终积分为 ______ 分，评级为 ______。

（2）实现上述功能的 Python 程序如下,在相应的划线处填写对应的语句。



```python
def cal(status_list):
    score = 0
    for state in status_list:
        if state == "严重损坏":
            score = 0
            ______①______    # 单选，填字母：A. continue B. break
        else:
            if state == "完好":
                score += 2
            else:
                ______②______
    return score

# 将输入的状态如“完好,轻微破损,完好,严重损坏,轻微破损”转换成列表

else:
    print("需改进")
```

---

## 答案

（1）0；需改进。

（2）① B；② `score += 1`；③ `cal(record)`。

---

## 解析

一旦出现严重损坏，当月积分清零并立即停止后续计分，需用 break。轻微破损加 1 分；函数用列表 record 作为实参计算总分。
