# 题目 07

三类商品的销量分别为 `a,b,c`（单位：亿元）。现对销量进行降序排序，Python 部分代码如下：

```python
if a < b:
    a, b = b, a
elif b < c:
    b, c = c, b
if a < c:
    a, c = c, a
print("销量依次为:", a, b, c)
```

任意输入3个数给 `a,b,c`，以下能检测出错误的测试数据为（   ）

- A. `2,3,1`
- B. `3,2,1`
- C. `3,1,2`
- D. `1,3,2`

---

## 答案

**正确答案：** D

---

## 解析

输入 `1,3,2` 时，第一条分支交换得到 `a=3,b=1,c=2`；因为使用了 `elif`，不会再比较并交换 `b,c`，最终输出 `3,1,2`，不是降序。
