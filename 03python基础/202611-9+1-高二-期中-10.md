# 题目 10

有如下 Python 程序段：

```python
n = int(input())
c = 0; i = 2
while i < n:
    if n % i == 0:
        c += 1
    i += 1
print(c)
```

运行该程序段后，若输入的值为 16，则输出的结果是（   ）

- A. 2

- B. 3

- C. 4

- D. 5

---

## 答案

**正确答案：** B

---

## 解析

只检查 2～15，能整除 16 的是 2、4、8，共 3 个。
