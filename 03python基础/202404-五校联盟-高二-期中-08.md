# 题目 08

下列表达式的结果为 True 的是（   ）

- A. `2024 % 1000 // 5 == 24`
- B. `abs(int(-1.7) * 2) % 8 == 4`
- C. `int(str(1010 + 90)[1:4]) // 25 == 4`
- D. `(2 ** 2 > 2 * 2) and (not(3 ** 3 == 3 * 3))`

## 答案

**正确答案：** C

## 解析

1010+90=1100，取字符串下标 1 到 3 得到“100”，100 整除 25 等于 4，因此 C 为 True；A、B、D 分别计算为 False。
