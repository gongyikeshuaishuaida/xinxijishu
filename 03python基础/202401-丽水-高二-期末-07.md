# 题目 07

下列 Python 表达式中，值为 True 的是（   ）

- A. len([1, "apple"]) == 6
- B. 3 + 5 % 3**2 == 8
- C. "bird" in "birthday"
- D. abs(int(-4.6)) > 9//2

---

## 答案

**正确答案：** B

---

## 解析

A中列表长度为2；B按优先级先算幂和取模，3+5%9=8，结果为真；C中字符串 bird 不是 birthday 的连续子串；D中 abs(int(-4.6))=4，而9//2=4，严格大于不成立。
