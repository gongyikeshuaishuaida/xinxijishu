# 题目 12

有如下 Python 程序段：

```python
def f(x, list):
    rank = 1
    for i in list:
        if i > x:
            rank += 1
    return rank

score = [100, 95, 98, 98, 94, 89, 80]
for i in score:
    print(f(i, score), end="")
```

运行该程序段后，输出的结果是（  ）

A．0311456

B．1423567

C．0312456

D．1422567

## 答案

**正确答案：** D

## 解析

函数返回“比当前分数高的分数个数+1”。依次计算 100、95、98、98、94、89、80 的名次，得到 `1422567`。
