# 题目 10

智能饮水站根据监测到的水温 w 自动切换工作模式。正常水温范围 [40,80]，mode 存储水温的低温、常温、过热三种模式，其值分别为 0,1,2。下列 Python 代码选项正确的是（   ）

- A.

    ```python
    if w >= 40:
        mode = 1
    elif w > 80:
        mode = 2
    else:
        mode = 0
    ```
- B.

    ```python
    mode = 1
    if w < 40:
        mode = 0
    else:
        mode = 2
    ```
- C.

    ```python
    if w < 40:
        mode = 0
    if w > 80:
        mode = 2
    else:
        mode = 1
    ```
- D.

    ```python
    if w < 40:
        mode = 0
    elif w <= 80:
        mode = 1
    else:
        mode = 2
    ```

---

## 答案

**正确答案：** D

---

## 解析

D 依次判断低于 40、至多 80、超过 80，分别对应 0、1、2。
