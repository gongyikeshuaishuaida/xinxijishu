# 题目 10

有如下 Python 函数：

```python
k = 1
ch = s[0]
for i in range(1, len(s)):
    if ch == s[i]:
        k += 1
    else:
        if k == 0:
            ch = s[i]
            k = 1
        else:
            k -= 1
```

变量 `s` 分别取下列值并运行后，变量 `ch` 的值不为 "a" 的是（   ）

- A. `"aaasd"`
- B. `"asdsa"`
- C. `"asads"`
- D. `"ssdaa"`

---

## 答案

**正确答案：** C

---

## 解析

程序用 `k` 记录当前候选字符的相对次数：遇到相同字符加 1，遇到不同字符且 `k>0` 时减 1，减到 0 后再更换候选字符。逐项执行可得 A、B、D 的最终候选字符为 `a`，C 的最终候选字符不是 `a`。
