# 题目 06

下列 Python 表达式的值为 False 的是（   ）

- A. `2**4 >= 4**2`
- B. `3 in ["3", "6"]`
- C. `len(str(1) + "3") < 13`
- D. `3 * 4 // 5 % 2 + 4 == 4`

## 答案

**正确答案：** B

## 解析

`3` 是整数，而列表中的元素是字符串“3”和“6”，整数 3 不在其中，B 的值为 False。其余表达式的值均为 True。
