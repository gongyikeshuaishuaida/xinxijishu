# 题目 10

10.某 Python 程序如下，运行后变量 `s` 的结果是（ ）

```python
p = "Abc_123"
s = ""
for ch in p:
    if "a" <= ch <= "z":
        s += chr((ord(ch) - ord("a") + 1) % 26 + ord("a"))
    elif "0" <= ch <= "9":
        s += str(9 - int(ch))
    else:
        s += ch
print(s)
```

- A. `Acd_123`
- B. `Bbc_123`
- C. `Bbc_876`
- D. `Acd_876`

---

## 答案

**正确答案：** D

---

## 解析

大写字母 A 和下划线保持不变，小写字母 b、c 分别后移一位为 c、d，数字 1、2、3 按 `9-int(ch)` 转换为 8、7、6，因此结果为 `Acd_876`。
