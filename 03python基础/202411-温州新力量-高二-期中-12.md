# 题目 12

彩虹商场在双十一期间开展以下促销活动：

- 活动 1：消费者在商场内任意消费可享受 9 折优惠；
- 活动 2：在活动 1 的基础上，实付满 300 元（含）以上额外立减 50 元；实付不满 300 元但满 100 元（含）以上，额外立减 10 元。

（1）若小华在该商场的原始消费金额为 500 元，那么实付金额为 ______①______ 元。

（2）实现上述功能的 Python 程序如下，请在划线处填入合适的代码。

~~~python
d1=0.9
#设置活动1折扣
m=float(input("输入原始消费金额:"))
m=m*d1
if m>=300:
    d2=50
    ______②______
    d2=10 #设置活动2立减金
else:
    d2=0
______③______
print("实际应付的金额为:",p)
~~~

（3）下列选项中，不能实现上述加框处代码功能的选项是 ______④______（多选题，全部选对得 2 分，选对但不全得 1 分，选错不得分）。

- A.

  ~~~python
  if m>=300:
      d2=50
  if m>=100:
      d2=10
  if m<100:
      d2=0
  ~~~

- B.

  ~~~python
  if m>=300:
      d2=50
  if m>=100:
      d2=10
  else:
      d2=0
  ~~~

- C.

  ~~~python
  d2=0
  if m>=300:
      d2=50
  elif m>=100:
      d2=10
  ~~~

- D.

  ~~~python
  d2=0
  if m>=300:
      d2=50
  else:
      d2=10
  ~~~

## 答案

**正确答案：** ① 400；② `elif m>=100`；③ `p=m-d2`；④ ABD。

## 解析

原始金额 500 元先打九折，得到 `450` 元，再满 300 元减 50 元，实付 400 元。第二档应使用 `elif m>=100`，这样只有未达到 300 元但达到 100 元的金额减 10 元，其他情况减 0 元。支付金额为折后金额减去立减金，即 `p=m-d2`。A、B 会在金额达到 300 元时被后续判断覆盖，D 会把低于 100 元的情况也减去 10 元，均不能正确实现功能；C 可以。
