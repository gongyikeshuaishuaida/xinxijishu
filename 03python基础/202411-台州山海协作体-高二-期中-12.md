# 题目 12

有如下 Python 程序段：

~~~python
from random import randint
a=[0]*6
flag=True
i=0
while i<6:
    x=randint(10,100)
    if not flag or x<50:
        a[i]=x
        flag=not flag
        i+=1
~~~

执行该程序段后，在下列选项中，列表 a 的值可能的是（   ）

- A. [34, 73, 8, 98, 10, 65]
- B. [89, 53, 18, 35, 20, 58]
- C. [12, 86, 29, 45, 16, 61]
- D. [38, 28, 11, 94, 63, 77]

---

## 答案

**正确答案：** C

## 解析

flag 初始为 True 时，只有 x<50 才能填入当前位置；填入后 flag 变为 False，下一次任意 10—100 的随机数都能填入，再切换回 True。因此下标 0、2、4 的值必须小于 50，所有值都必须在 10—100 之间。只有 C 满足这一条件。原题题干称“VB程序段”，但所给代码为 Python，题目按代码实际语义处理。
