# 题目 12

字符串 `s` 仅包含小写字母且已升序排列，现对字符串进行压缩，例如“aabbccdee”压缩为“2a2b2c1d2e”。实现该功能的程序段如下，方框中应填入的正确代码为

```python
ans = ""; n = len(s)
```

![[attachments/202402七彩阳光_12_代码选项.jpg]]

```python
print(ans)
```

---

## 答案

**正确答案：** B

---

## 解析

选项 B 在遇到字符变化时先把上一段连续字符的次数和字符加入结果，再重新计数；循环结束后还要补上最后一段，才能得到形如 `2a2b2c1d2e` 的压缩结果。
