# 题目 13

列表 `nums` 有 `n`（`n > 2`）个整型元素，现要查找出缺失的第 1 个正整数并输出。若 1～`n` 中没有缺失某个正整数，则输出 `n + 1`。例如 `nums = [3, 2, -1, 0]`，则缺失的第 1 个正整数为 1；`nums = [1, 2, 3, 4, 5, 6]`，则缺失的第 1 个正整数为 7。实现该功能的部分程序如下：

```python
def findz(nums):
    n = len(nums)
    for i in range(n):
        if 1 <= nums[i] <= n:
            p = nums[i] - 1
            if ______③______:
                nums[p], nums[i] = nums[i], nums[p]
    for i in range(n):
        if ______④______:
            return i + 1
    return ______⑤______

# 列表 nums 中存储了 n 个整型元素，代码略
# 调用函数 findz，并输出结果，代码略
```

（1）若`nums = [-5, 4, 3, -1, 0, 1]`，则缺失的第1个正整数为 ______①______。

（2）方框中应填入的代码为 ______②______（单选，填字母）。
- A. `nums[p] > 0`
- B. `nums[p] != nums[i]`
- C. `nums[p] > nums[i]`

（3）请在程序划线处填入合适的代码。

---

## 答案

**正确答案：** ① 2；② B；③ `nums[p] != nums[i]`；④ `nums[i] != i + 1`；⑤ `n + 1`

---

## 解析

通过交换把值 x 放到下标 x-1 的位置。方框条件用于避免目标位置已有相同值时重复交换；第二次遍历中，第一个 nums[i] 不等于 i+1 的位置对应缺失正整数 i+1，若全部匹配则缺失 n+1。
