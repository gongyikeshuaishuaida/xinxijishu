# 题目 10

有如下 Python 程序段：

```python
s = input()
res = ""
for ch in s:
    if "a" <= ch <= "z":
        res = chr(ord(ch) - 32) + res
    elif "A" <= ch <= "Z":
        res = chr(ord(ch) + 32) + res
    else:
        res = res + ch
print(res)
```

若输入的 `s` 为 `"aB3dE!f"`，执行该程序段后，输出的结果为（   ）

- A. `FeDbA3!`
- B. `Ab3De!F`
- C. `F!eD3bA`
- D. `FeDb3A!`

---

## 答案

**正确答案：** A

---

## 解析

字母先转换大小写再插入结果字符串首端，数字和感叹号追加到末端。逐字符处理 `aB3dE!f` 得到 `FeDbA3!`，故选 A。
