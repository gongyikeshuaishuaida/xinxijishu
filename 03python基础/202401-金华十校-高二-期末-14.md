# 题目 14

有如下Python程序，输出结果可能是（   ）

```python
from random import randint
b=[1,0,0,0,0]
i=1
while i<5:
    b[i]=randint(0,15)
    if b[i]%3!=0:
        b[i]+=b[i-1]
    elif i%2==1:
        i-=1
    i+=1
print(b)
```

- A. `[1,12,19,35,40]`
- B. `[1,16,18,22,25]`
- C. `[1,0,3,6,9]`
- D. `[1,9,0,5,3]`

---

## 答案

**正确答案：** D

---

## 解析

每个新生成的随机数若不是3的倍数，就加上前一项；若是3的倍数且下标为奇数，会先将`i`减1再在循环末尾加1，相当于重新处理当前下标。D中的各项可以由该过程生成，其他序列违反对应的累加或下标规则。
