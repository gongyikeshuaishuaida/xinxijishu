# 题目 12

12.有如下 Python 程序段：

```python
from random import randint
a = [0] * 6
i = 0
while i < 6:
    b = randint(1, 20)
    if i % 2 == 0 and b % 2 == 0:
        a[i] = b
        i = i + 1
    elif i % 2 == 1:
        a[i] = b
        i = i + 1
print(a)
```

执行程序段后，显示的内容不可能是（ ）

A.`[4, 3, 6, 19, 16, 16]`
B.`[20, 20, 20, 20, 20, 20]`
C.`[4, 8, 11, 14, 8, 9]`
D.`[12, 2, 20, 19, 16, 1]`

---

## 答案

**正确答案：** C

---

## 解析

偶数下标 `0、2、4` 只有在随机数为偶数时才会写入，因此这些位置必为偶数。选项 C 的下标 2 为奇数 `11`，不可能出现；其余选项满足条件。
