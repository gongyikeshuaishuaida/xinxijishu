# 题目 10

有如下 Python 程序段：

```python
s = "20270228"
i = j = ans = 0
while i < len(s) - 1:
    if s[i] < s[i + 1]:
        ans += int(s[j:i + 1])
        j = i + 1
    i += 1
print(ans)
```

执行该程序段后，输出 `ans` 的值为（   ）

- A. 20
- B. 23
- C. 92
- D. 114

---

## 答案

**正确答案：** D

---

## 解析

相邻字符出现升序时，程序把从 j 到 i 的数字片段转换为整数并累加。依次得到 20、2、70、22，合计 `ans=114`。
