# 题目 14

服务器根据食堂每分钟采集到的人数，统计并发送预警信息，规则如下：

① 若人数 ≥ 500 人，则标记为“待处理”，处于“待处理”时，若连续 3 分钟人数上升，则发送“预警”信息，发送信息后，系统将重新计时。

② 人数 ≤ 400 时，清除“待处理”标记。若清除“待处理”标记 30 分钟内人数又增到 500 人及以上，则直接发送“二次预警”信息。

请回答下列问题。

（1）若系统 11:00 启动，11:00—11:09 的人数依次为 `[480, 505, 510, 520, 525, 460, 380, 410, 450, 510]`，则系统发送“预警”和“二次预警”的总次数是 ______ 次。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适代码。

```python
pending = False    # 标记是否处于“待处理”状态
last_clear = -1
rise_count = 0
while True:
    # 获取当前时刻 t、当前时刻的人数 num、上一分钟的人数 prev，代码略
    if num >= 500:
        if not pending:
            if ______①______:
                # 发送“二次预警”信息，代码略
            pending = True
            rise_count = 1
        else:
            if num > prev:
                ______②______
            else:
                rise_count = 1
            if rise_count >= 3:
                # 发送“预警”信息，代码略
                rise_count = 0
                pending = False
                last_clear = t
    elif pending and num <= 400:
        ______③______
        last_clear = t
        rise_count = 0
    prev = num
    # 延时一分钟，代码略
```

---

## 答案

**正确答案：** （1）2；（2）① `last_clear != -1 and t - last_clear <= 30`；② `rise_count += 1`；③ `pending = False`

---

## 解析

11:03 人数连续上升达到 3 分钟，发送一次“预警”并清零状态；11:06 降至 400 以下清除待处理标记，11:09 在 30 分钟内再次达到 500，发送一次“二次预警”，共 2 次。代码中先判断曾清除且间隔不超过 30 分钟，再累加连续上升次数，人数回落到 400 以下时清除 pending。
