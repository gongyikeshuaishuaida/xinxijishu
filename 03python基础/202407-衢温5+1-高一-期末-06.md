# 题目 06

下列 Python 表达式的值为 False 的是（   ）
- A. `2**3 == 8`
- B. `int("23") == 23`
- C. `ord("b") - ord("a") == 1`
- D. `2 in [1, "2", 3]`

---

## 答案

**正确答案：** D

---

## 解析

A、B、C 的表达式值分别为 True；列表中是字符串“2”而不是整数 2，因此 2 in [1, "2", 3] 为 False。
