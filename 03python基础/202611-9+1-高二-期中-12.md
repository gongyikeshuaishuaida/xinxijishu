# 题目 12

有如下 Python 程序段：

```python
import random
s = "SOFTWARE"
k = random.randint(2, 4)    # random.randint(a,b)：随机生成一个[a,b]范围内的整数
i = 0
while len(s) > 1:
    i = (i+k-1) % len(s)
    s = s[:i] + s[i+1:]
print(s)
```

运行该程序段后，输出的结果不可能是（   ）

- A. A

- B. R

- C. S

- D. T

---

## 答案

**正确答案：** D

---

## 解析

固定 k 分别为 2、3、4 时，最后留下的字符分别是 S、R、A，T 不可能。
