# 题目 10

某校图书馆管理系统统计学生本学年借阅图书册数，并按下表规则评定读者等级。实现上述功能的 Python 程序段如下：

```python
n=int(input("输入本学年借阅册数："))
if n<=15:
    level="普通读者"
elif n<=30:
    level="活跃读者"
else:
    level="资深读者"
print(level)
```

若要测试程序段中所有分支的代码是否正确，下列测试数据中最恰当的是（   ）

![[attachments/202611宁波三锋高二_10_图1.png]]

- A. 14、15、16
- B. 15、30、31
- C. 10、20、30
- D. 20、30、40

---

## 答案

**正确答案：** B

---

## 解析

15、30 是分支边界，31 首次进入第三个分支，这组覆盖三种结果并测试两处上界。
