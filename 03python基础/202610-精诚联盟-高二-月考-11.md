# 题目 11

有如下pyhon程序段：

```python
a = [3,5,9,6,7,2,1]
b = [1,9,3,4,8,6,7]
flag = True
ans = []
for i in range(6,-1,-1):
    if flag and a[i] < b[i]:
        ans.append(b[i]-a[i])
        flag = False
    elif a[i] > b[i]:
        ans.append(a[i]-b[i])
print(ans)
```

执行该程序段后，输出结果为（   ）

- A. `[2,4,6,2,1,4,6]`
- B. `[6,2,6,2]`
- C. `[2,4,6,2]`
- D. `[6,4,1,6,4,2]`

---

## 答案

**正确答案：** B

---

## 解析

i=6时第一次满足if，加入6并将flag置False；此后仅a[i]>b[i]时加入差值，i=3、2、0依次加入2、6、2，结果[6,2,6,2]。
