# 题目 12

有如下 Python 代码段：

~~~python
from random import randint
lst=[0]*6
for i in range(6):
    lst[i]=randint(2,8)*2+1
for i in range(5):
    if i%2==0 and lst[i]>lst[i+1]:
        lst[i],lst[i+1]=lst[i+1],lst[i]
    else:
        lst[i]+=1
~~~

12. 执行该代码段后，lst中可能的值是（   ）

- A. [7,13,9,6,13,6]
- B. [10,10,6,18,11,14]
- C. [5,10,12,6,12,8]
- D. [5,12,6,16,5,17]

---

## 答案

**正确答案：** D

---

## 解析

初始生成的每个 lst 元素均为9、11、13、15、17中的奇数。偶数下标处若满足条件则交换，否则对应元素加1；奇数下标处始终执行 else 加1。逐项检查可知D符合该程序的取值和交换关系，其他选项至少有一个元素不可能出现。
