# 题目 03

动物园门票规则为：6 周岁（含）以下免费；6 周岁（不含）至 18 周岁（含）、60 周岁（含）以上 10 元/人；其他 20 元/人。设 y 为游客年龄，s 为实际门票价格，下列选项正确的是

![[attachments/202406浙江省2_03_门票价格代码选项图.jpg]]

- A.
    if y <= 6:
        s = 0
    if y <= 18 or y >= 60:
        s = 10
    else:
        s = 20

- B.
    s = 0
    if y >= 6:
        if y <= 18 and y >= 60:
            s = 10
        else:
            s = 20

- C.
    s = 20
    if y <= 6:
        s = 0
    else:
        s = 10

- D.
    if y <= 6:
        s = 0
    elif y <= 18 or y >= 60:
        s = 10
    else:
        s = 20

---

## 答案

**正确答案：** D

---

## 解析

D 使用 if-elif-else 结构，先判断免费年龄，再判断半价年龄，最后给出全价，三个区间互斥且覆盖所有年龄。
