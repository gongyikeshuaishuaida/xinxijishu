# 题目 12

有如下 Python 程序段：

```python
import random
a = [0] * 6
i = 0
while i < 6:
    a[i] = random.randint(1, 10)
    if a[i] % 2 == i % 2:
        i -= 1
    elif i % 2 == 1:
        a[i] += a[i - 1] // 2
    i += 1
print(a)
```

执行程序后，输出 `a` 的值不可能是（   ）

- A. `[9,12,9,14,5,12]`
- B. `[1,2,1,4,3,9]`
- C. `[7,8,5,6,5,10]`
- D. `[9,8,5,4,7,9]`

---

## 答案

**正确答案：** C

---

## 解析

最终偶数下标处只能留下奇数。奇数下标处先生成偶数，再加前一项的一半。C 中下标 1 的 8 减去前一项 `7//2=3` 后为 5，不是生成范围内要求的偶数，因此不可能。
