# 题目 10

有如下 Python 程序段：

```python
a = [0] * 10
c = 0
n = int(input())
while n > 0:
    a[n % 10] += 1
    if a[n % 10] == 1:
        c += 1
    n //= 10
print(c)
```

运行该程序后，输出结果为 5，则键盘输入内容为（   ）

- A. 975357
- B. 876985
- C. 808890
- D. 4326479

---

## 答案

**正确答案：** B

---

## 解析

876985中不同数字为8、7、6、9、5，共5种。
