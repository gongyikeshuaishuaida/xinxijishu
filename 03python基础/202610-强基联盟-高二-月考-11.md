# 题目 11

有如下Python程序段：

```python
def p(n):
    res=[]
    for num in range(1,n+1):
        i=1
        while i*i<=num:
            if i*i==num:
                res.append(num)    # 在列表res末尾添加元素num
                break
            i+=1
    return res
print(p(20))
```

执行该程序段后，输出的结果是（   ）

- A. `[1, 4, 9, 16]`
- B. `[4, 9, 16]`
- C. `[1, 2, 3, 4]`
- D. `[2, 3, 4]`

---

## 答案

**正确答案：** A

---

## 解析

程序逐个检查1到20的整数，从i=1开始尝试平方；若i*i=num，就将num加入res并退出内层循环。因此收集1到20中的完全平方数1、4、9、16。
