# 题目 11

11. 有下列 Python 程序段：

```python
dic={};s="1232p321p";i=0
while s[i]!="p":
    if s[i] in dic:
        dic[s[i]]+=1
    else:
        dic[s[i]]=1
    i+=1
```

程序运行后，`dic["1"]` 的值是（   ）

- A. 0
- B. 1
- C. 2
- D. 3

---

## 答案

**正确答案：** B

---

## 解析

循环在遇到第一个 `p` 前只处理字符串 `"1232"`。字符 `"1"` 第一次出现时建立键值并赋为 1，后续没有再次出现，因此 `dic["1"]` 为 1。
