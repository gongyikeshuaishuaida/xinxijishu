# 题目 10

有如下程序段：

```python
# 字符串s初始化长度为n（n>5）的任意字符串，代码略。
left, right = 0, n-1
res = 0
while left < right:
    if s[left] != s[right]:
        res = left
        left += 1
    else:
        res = right
        right -= 1
```

执行该程序段后，`res` 的值为3，则下列表达式中，值一定为 `True` 的表达式个数为（   ）

① `left > right`　② `s[0] != s[n-1]`　③ `left <= 4`

- A. 0

- B. 1

- C. 2

- D. 3

---

## 答案

**正确答案：** B

---

## 解析

每轮只让left加1或right减1，结束时必有left==right，故①错误。最后一次记录res=3时，若记录left则最终left=4，若记录right则最终left=2，因此③一定成立。②并非必真，故只有1项。
