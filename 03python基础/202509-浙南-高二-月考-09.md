# 题目 09

下列 Python 表达式的值，与其他三项不同的是（   ）

- A. `369 % 100 // 10 == 6`
- B. `"7" + "4" > "10"`
- C. `not "56" in [5, 6]`
- D. `int(5.9) == len("Python")`

---

## 答案

**正确答案：** D

---

## 解析

A 中 `369 % 100 // 10` 等于 6，结果为真；B 比较字符串 `"74"` 与 `"10"`，按字典序结果为真；C 中字符串 `"56"` 不在整数列表 `[5, 6]` 中，取反后为真。D 中 `int(5.9)=5`，而 `len("Python")=6`，结果为假，因此 D 与其他三项不同。
