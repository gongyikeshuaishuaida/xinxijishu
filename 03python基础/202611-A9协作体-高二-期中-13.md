# 题目 13

“云游良渚”平台每隔 1 小时统计一次在馆人数，并根据客流情况发布客流等级码以引导游客分流。等级码生成与发布规则如下：

①在馆人数不超过 3000 人时，等级码为 0；超过 3000 人且不超过 8000 人时，等级码为 1；超过 8000 人时，等级码为 2。

②当同一个等级码连续出现 k 次时，发布该等级码一次，发布后连续出现的次数清零并重新开始统计。

（1）若某日连续 10 次统计的在馆人数依次为 2500、2800、2100、6000、7000、9500、9800、8600、1500、2400，k=3，则这 10 次统计中共发布等级码 ______ 次。

（2）实现上述功能的 Python 程序如下，请在划线处填入合适的代码。



```python
# 列表 nums 存放每小时的在馆人数，如[2500,2800,2100,6000,...]
# 同一个等级码连续出现 k 次即发布一次
pre = -1    # pre 存放前一个等级码
cnt = 0
pub = []    # pub 依次存放已发布的等级码
for n in nums:
    code = 2
    if n <= 3000:
        ______①______
    elif n <= 8000:
        code = 1
    if code == pre:
        cnt += 1
    else:
        cnt = 1
    if ______②______:
        print("发布客流等级码", code)
        pub.append(code)    # 把本次发布的等级码依次存入列表pub
        cnt = 0
    pre = ______③______
```

---

## 答案

（1）2。

（2）① `code = 0`；② `cnt == k`；③ `code`。

---

## 解析

等级码依次为 0、0、0、1、1、2、2、2、0、0，前一段 0 和一段 2 各触发一次发布。同码则累计，不同码从 1 开始；发布后清零，但仍需保存当前等级供下一次比较。
