# 题目 10

执行下列 Python 程序段后，变量 c 的值是

```python
c = 0
for i in range(1, 101):
    if i % 3 == 0 and i % 5 != 0:
        c += 1
```

（   ）

- A. 27

- B. 33

- C. 6

- D. 39

---

## 答案

**正确答案：** A

---

## 解析

1～100 中 3 的倍数有 33 个，其中同时为 5 的倍数有 6 个，故计数为 27。
