# 题目 12

有如下 Python 程序段：

```python
def to_bin(x, w):
    # 将十进制数x转成w位二进制，返回列表。例：to_bin(3,3)，返回[0, 1, 1]。代码略
best = 0
n = len(s)
for m in range(2 ** n):
    b = to_bin(m, n)
    t = ""
    for i in range(n):
        if b[i] == 1:
            t = t + s[i]
    if t == t[::-1] and len(t) > best:
        best = len(t)
print(n - best)
```

![[attachments/202611金华十校高三_12_图1.png]]

若 `s` 为 `"abcad"`，则执行该程序段后，输出的结果为（   ）

- A. 1

- B. 2

- C. 3

- D. 4

---

## 答案

**正确答案：** B

---

## 解析

m的二进制位决定是否保留相应字符，程序枚举所有子序列，求最长回文子序列长度。abcad的最长回文子序列为aba或aca，长度3，故输出5-3=2。
