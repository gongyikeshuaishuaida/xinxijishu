# 题目 12

数组元素 `a[0]` 至 `a[n-1]` 为不重复的正整数，程序要找出长度最长的升序子序列。程序中两个空的合适代码及运行结果选择为（   ）：

```python
a = [2, 11, 4, 13, 5, 7]
n = len(a); ans = []
d = [[1, -1] for i in range(n)]
# d[i][0] 记录 i 位置结尾的最长升序子序列长度
# d[i][1] 记录 i 结尾的最长升序子序列前一数据的索引位置
for i in range(1, n):
    for j in range(i):
        if a[j] < a[i] and ______①______:
            ______②______
            d[i][1] = j
maxlen = 0; k = -1
for i in range(n):
    if d[i][0] > maxlen:
        maxlen = d[i][0]
        k = i
while k != -1:
    ans.append(a[k])
    k = d[k][1]
print(ans[::-1])
```

- A.① `d[i][0]<d[j][0]`；② `d[i][0]=d[i][0]+1`
- B.① `d[i][0]<d[j][0]`；② `d[i][0]=d[j][0]+1`
- C.① `d[j][0]>=d[i][0]`；② `d[i][0]=d[i][0]+1`
- D.① `d[j][0]>=d[i][0]`；② `d[i][0]=d[j][0]+1`

---

## 答案

**正确答案：** D

---

## 解析

若 `a[j]<a[i]` 且以 j 结尾的子序列更长或等长，应把 i 接在该子序列后面，长度更新为 `d[j][0]+1`，前驱记录为 j。对应选项 D。
