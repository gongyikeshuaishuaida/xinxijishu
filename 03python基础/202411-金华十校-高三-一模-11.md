# 题目 11

有如下 Python 程序：

~~~python
def re(arr):
    i = 0
    for j in range(1, len(arr)):
        if arr[j] != arr[i]:
            i += 1
            arr[i] = arr[j]
    return i + 1

print(arr[:re(arr)])
~~~

有哪一组 arr 经上述程序处理，输出结果仍然存在重复元素（   ）

- A. [8,9,9,9,8,8]
- B. [3,3,3,5,5,7]
- C. [8,8,3,3,3,1]
- D. [2,2,8,8,6,6]

---

## 答案

**正确答案：** A

---

## 解析

函数删除连续重复元素，只保留每一段的第一个元素。A处理后为[8,9,8]，虽然连续重复已删除，但非连续的两个8仍然重复；B、C、D处理后分别为[3,5,7]、[8,3,1]、[2,8,6]。
