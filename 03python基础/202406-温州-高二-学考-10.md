# 题目 10

某 Python 程序如下，运行后 `flag` 的结果为 `True`，则 `s1` 和 `s2` 的内容不可能为（   ）

```python
i = 0
flag = True
d = {}
while i < len(s1) and flag:
    ch1, ch2 = s1[i], s2[i]
    if ch1 not in d:
        d[ch1] = ch2
    elif d[ch1] != ch2:
        flag = False
    i += 1
```

- A.`冷言冷语`　`一心一意`
- B.`大名鼎鼎`　`落落大方`
- C.`滥竽充数`　`浑水摸鱼`
- D.`寻寻觅觅`　`冷冷清清`

---

## 答案

**正确答案：** B

---

## 解析

程序要求同一 `s1` 字符每次出现时都对应同一个 `s2` 字符。B 中 `鼎` 在 `s1` 的第 3、4 位分别对应“大”和“方”，同一字符映射不一致，`flag` 会变为 False；其余选项均不存在这种冲突。
