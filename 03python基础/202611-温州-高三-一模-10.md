# 题目 10

有如下 Python 程序段：

```python
# 随机产生 5 个整数存入列表 a，代码略
s, k = 0, -1
for i in range(5):
    s += a[i]
    if s < 0:
        k = i
```

执行该程序段后，k 的值为 3，则值一定为 True 的所有表达式为：

① `a[4]>0`

② `a[3]<0`

③ `a[0]+a[1]+a[2]>0`（   ）

- A. ①

- B. ①②

- C. ②③

- D. ①③

---

## 答案

**正确答案：** A

---

## 解析

k=3 表示前三次循环之后的第 4 个前缀和仍小于 0，最后一个前缀和不小于 0，所以 a[4] 必须大于 0；②③都可用反例否定。
