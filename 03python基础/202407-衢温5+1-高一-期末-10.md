# 题目 10

有如下 Python 程序段：

```python
def fib(x, y):
    return x + y

a, b = 1, 1
for i in range(4):
    a, b = b, fib(a, b)
print(a, b)
```

执行该程序段后，运行的结果为（   ）
- A. 3 5
- B. 5 8
- C. 8 13
- D. 8 16

---

## 答案

**正确答案：** B

---

## 解析

初始 (a,b)=(1,1)，循环四次后依次为 (1,2)、(2,3)、(3,5)、(5,8)，所以输出 5 8。
