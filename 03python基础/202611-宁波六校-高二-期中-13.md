# 题目 13

校园开展运动打卡活动，data 列表保存每位同学一周运动天数。规则如下：一周运动 3 天及以上为达标同学；统计达标总人数 count，同时统计达标同学中运动天数等于 7（满勤）的人数，并记录达标同学中的最低运动天数。请回答下列问题：

（1）若 `data=[2,5,3,7,1,6,4,3]`，则达标同学的总人数为 ______。

(2) 补全程序中的三处划线

```python
data = [2,5,3,7,1,6,4,3]; full = 0; min_d = 8
______①______
for i in range(len(data)):
    if data[i] >= 3:
        count += 1
        if ______②______:
            full += 1
        if ______③______:
            min_d = data[i]
print("达标人数:", count, "满勤人数:", full, "达标同学最低运动天数:", min_d)
```

---

## 答案

（1）6。

（2）① `count=0`，② `data[i]==7`，③ `data[i]<min_d`。

---

## 解析

只剔除不足 3 天的两项 2、1。计数从 0 开始；仅在达标分支内检查满勤和更新最小值。
