# 题目 08

已知 Python 程序段如下：

```python
from random import randint
n=12;a=['']*n
for i in range(n//2):
    x=chr(65+randint(0,i))
    while x in a:
        x=chr(65+randint(0,i))
    a[randint(0,i)*2]=x
```

使用得到的数组 `a`，构建的二叉树可能的是（   ）

![[attachments/202412北斗联盟_08_二叉树选项A-D.png]]

## 答案

**正确答案：** D

## 解析

程序每次只把新字符写入下标 `0、2、4、6、8、10` 中的一个位置，奇数下标位置保持为空；同时第 `i` 轮产生的字符只能来自 `A` 到第 `i` 个字母，并通过 `while` 保证已写入的字符不重复。按完全二叉树的数组下标关系检查四个选项，只有 D 的非空节点位置和字符生成范围同时满足条件。
