# 题目 10

有如下 Python 程序：

```python
dic = {'c': ['', 'e'], 'b': ['d', ''], 'm': ['b', 'c'], 'd': ['', 'f'], 'e': ['', ''], 'f': ['', '']}
def find(dic, x):
    if x not in dic.keys():  # 字典dic的键中没有x就返回True，否则返回False
        return "None"
    for k in dic.keys():  # 用k遍历字典dic中的键
        if x in dic[k]:
            return find(dic, k)
    return x
ans = find(dic, 'f')
```

执行上述程序后，变量 `ans` 的值是（   ）

- A. `'b'`

- B. `'m'`

- C. `'d'`

- D. `'c'`

---

## 答案

**正确答案：** B

---

## 解析

字典保存各节点的左右孩子。函数不断查找当前节点的父节点，直到找不到父节点，返回根m。f→d→b→m。
