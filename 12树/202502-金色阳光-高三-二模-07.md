# 题目 7

某二叉树的前序遍历序列是 `ABCDE`，后序遍历序列是 `EDCBA`，则该二叉树的中序遍历序列可能是

- A. `DCEBA`
- B. `ECDBA`
- C. `ABCDE`
- D. `CBADE`

## 答案

**参考答案：** C

## 解析

前序为 `ABCDE`、后序为 `EDCBA` 时，可以构造只有右孩子的链式二叉树。此时中序遍历同样为 `ABCDE`，因此 C 项是可能的序列。
