# 题目 11

有如下 Python 程序段：

```python
def search(x):
    ans = ""
    if a[2*x] != "":
        ans = ans + search(2*x)
    if a[2*x+1] != "":
        ans = ans + search(2*x+1)
    ans = ans + a[x]
    return ans

a = ["" for i in range(32)]
a[1] = "A"; a[2] = "B"; a[3] = "C"; a[4] = "D"; a[7] = "E"; a[9] = "F"
print(search(1))
```

运行该程序段后，输出的结果是（   ）

- A. FDBECA
- B. ACEBDF
- C. ABCDEF
- D. FEDCBA

---

## 答案

**正确答案：** A

---

## 解析

函数先递归访问左孩子，再访问右孩子，最后访问当前节点，是后序遍历。按完全二叉树下标关系，1 的左子树为 2、4、9，输出 F、D、B；右子树为 3、7，输出 E、C；最后输出根 A，结果为 FDBECA。
