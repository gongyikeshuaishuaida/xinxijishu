# 题目 09

定义如下函数：

```python
def f(n, k):
    if n == k or k == 0:
        return 1
    else:
        return f(n-1, k) + f(n-1, k-1)
```

执行 `ans=f(5,3)` 后，`ans` 的值为（  ）

A．2

B．8

C．10

D．20

## 答案

**正确答案：** C

## 解析

该递归函数计算组合数 `C(n,k)`，因此 `f(5,3)=C(5,3)=10`。
