# 题目 10

定义如下 Python 函数：

```python
def f(m, n):
    if m <= n:
        return m
    else:
        return f(m-1, n+2) + 1
```

执行语句 `k = f(12, 5)` 后，`k` 的值为（   ）

- A. 9
- B. 10
- C. 11
- D. 12

---

## 答案

**正确答案：** D

---

## 解析

递归调用过程为 `f(12,5)=f(11,7)+1`，`f(11,7)=f(10,9)+1`，`f(10,9)=f(9,11)+1`。当 `m=9`、`n=11` 时返回 9，因此最终结果为 `9+1+1+1=12`。
