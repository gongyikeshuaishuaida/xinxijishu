# 题目 11

对于任意字符串 s，甲、乙程序段输出结果相同，请在乙程序段划线处填入合适的代码。

```python
def f1(s):  # 甲程序段
    if len(s)==0:
        return 0
    elif s[0]==s[-1]:
        return 1+f1(s[1:-1])
    else:
        return f1(s[1:-1])
print(f1(s))

def f2(s):  # 乙程序段
    n=len(s)
    c=0
    for i in range(__________):
        if s[i]==s[n-i-1]:
            c+=1
    print(c)
```

- A. `n`
- B. `n//2`
- C. `n//2+1`
- D. `(n+1)//2`

---

## 答案

**正确答案：** D

---

## 解析

甲程序从字符串两端向中间递归比较，每层至多统计一对字符；奇数长度时还要统计中间字符。比较次数为 (n+1)//2，因此乙程序的 range 应填 `(n+1)//2`。
