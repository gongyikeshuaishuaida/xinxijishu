# 题目 10

定义如下函数：

```python
def judge(s):
    if len(s) <= 1:
        return s
    m = len(s) // 2
    lmx = judge(s[:m])
    rmx = judge(s[m:])
    if rmx > lmx:
        lmx = rmx
    return lmx
```



执行语句`print(judge("project"))`后，输出的字符是（   ）

- A. c
- B. j
- C. p
- D. t

---

## 答案

**正确答案：** D

---

## 解析

函数递归求左右子串中较大的字符，再比较两侧结果；`project`的最大字符为`t`，故D。原卷左右切片分别为`s[:m]`与`s[m:]`，MinerU初稿将右侧切片误识别为`s[:m]`，已对照原卷修正。实跑输出`t`，与答案总表及逐题解析一致。
