# 题目 10

10.定义如下函数：

```python
def fac(n):
    if n == 1:
        return 1
    else:
        return 1 / n + fac(n - 1)
```

执行语句 `f=fac(5)`，`f` 的值与调用函数 `ite(5)` 返回结果相同的是（ ）。

![[attachments/202404嘉兴_10_递归迭代选项.jpg]]

---

## 答案

**正确答案：** C

---

## 解析

递归函数 `fac(5)` 计算的是 `1/1+1/2+1/3+1/4+1/5`。只有选项 C 的循环范围为 `range(1,n+1)`，并且每次先计算 `t=1/i` 再累加到 `s`，与递归结果一致。
