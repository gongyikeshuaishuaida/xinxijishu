# 题目 09

定义如下函数：

```python
def f(x):
    if x == 1:
        return 1
    else:
        return (f(x - 1) + 1) * 2
```

执行语句 `k = f(5)` 后，`k` 的值为（   ）

- A. 46
- B. 22
- C. 10
- D. 4

## 答案

**正确答案：** A

## 解析

递推得到 `f(1)=1`、`f(2)=4`、`f(3)=10`、`f(4)=22`、`f(5)=46`，所以 `k=46`。
