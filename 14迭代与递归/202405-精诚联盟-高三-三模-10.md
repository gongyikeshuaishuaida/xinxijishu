# 题目 10

10.定义函数：

```python
def f(s, i):
    n = len(s)
    if i >= n // 2:
        return n % 2
    if s[i] == s[n-i-1]:
        return 2 + f(s, i+1)
    else:
        return 0
```

调用 `f("racecar", 0)` 的返回值是（ ）

- A.3
- B.4
- C.7
- D.1

---

## 答案

**正确答案：** C

---

## 解析

字符串 `racecar` 是长度7的回文串，递归比较三对字符后到达中间位置，返回 `1`，回溯累加 `2+2+2+1=7`，故选 C。
