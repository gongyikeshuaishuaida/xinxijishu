# 题目 14

重排字符串：已知一个由大写字母组成的字符串`s`和一个整数`k`，重排后使字符串中相同字母之间的距离至少为`k`（`k`表示两个字母在字符串中索引之差的绝对值）。如果可以重排，则输出其中一种排列方式；否则输出“不能重排”。

（1）若字符串`s`和整数`k`分别为`"AABBC"`和3，则重排后的字符串为 ______①______。

（2）定义函数`find(a)`，参数`a`列表的每个元素表示字母出现的次数。函数查找数量最多的未排字母并返回其索引。加框处应填入的正确代码为 ______②______（单选，填字母）。

```python
def find(a):
    m = 0
    # 加框处代码
    return m
```

（3）实现上述功能的部分Python程序如下，请在划线处填入合适的代码。

```python
# 字符串保存在变量s中，整数保存在变量k中，代码略
# 统计字符串s中各类字符的出现次数，存入列表cnt，代码略
res = [""] * len(s)  # 保存重排后的字母
left = [0] * 26      # 未重排字母可以摆放的最前面位置
flag = True
i = 0
while i < len(s) and flag:
    id = find(cnt)
    ______③______
    while pos < len(s) and res[pos] != "":
        pos += 1
    if pos < len(s):
        res[pos] = chr(ord("A") + id)
        cnt[id] -= 1
        left[id] = pos + k
        ______④______
    else:
        flag = False
# 若flag为True则输出重排后的字符串，否则输出“不能重排”，代码略
```


---

## 答案

**正确答案：** ① `ABCAB`或`BACBA`；② A；③ `pos = left[id]`；④ `i = i + 1`

---

## 解析

最多次数的未排字母应比较 `a[i] > a[m]` 并令 `m=i`，故（2）A；每次放置该字母都从它允许的最早位置开始搜索，①为 `pos=left[id]`，成功放置后总数计数器加一，②为 `i=i+1`。
