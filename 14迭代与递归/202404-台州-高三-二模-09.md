# 题目 09

定义函数：

```python
def climb(n):
    if n == 0:
        return 1
    if n <= 2:
        return n
    return climb(n-1) + climb(n-2) + climb(n-3)
```

执行 `m = climb(6)` 后，函数 climb 被调用的次数与变量 m 的值依次为（   ）

- A. 7、13
- B. 25、24
- C. 24、46
- D. 46、44

## 答案

**正确答案：** B

## 解析

递推值为 F(0)=1、F(1)=1、F(2)=2、F(3)=4、F(4)=7、F(5)=13、F(6)=24。递归调用树的结点总数为 25，因此选择 B。
