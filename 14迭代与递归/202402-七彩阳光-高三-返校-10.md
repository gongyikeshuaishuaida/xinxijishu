# 题目 10

定义如下函数：

```python
def p(x, y):
    if x % y == 0:
        print(y)
    else:
        p(y, x % y)
        print(y)
```

执行语句 `p(64, 18)` 后，依次输出的结果为（   ）

- A. 18、10、8、2
- B. 2、8、10、18
- C. 4、10、18
- D. 18、10、4

---

## 答案

**正确答案：** B

---

## 解析

递归调用依次为 `p(64,18)`、`p(18,10)`、`p(10,8)`、`p(8,2)`。到达 `p(8,2)` 时先输出 2，再逐层返回输出 8、10、18。
