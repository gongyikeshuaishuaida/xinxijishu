# 题目 10

10.定义如下两个函数：

```python
def fn1(n, num1, num2):
    if n == 1:
        return num1
    return fn1(n-1, num2, num1+num2)

def fn2(n):
    if n == 1 or n == 2:
        return 1
    return fn2(n-1) + fn2(n-2)
```

下列说法正确的是（ ）

- A.两种算法的时间复杂度相同
- B.`fn1(n,1,1)` 与 `fn2(n)` 的功能相同
- C.执行 `fn2(8)` 时，`fn2(5)` 被调用了 2 次
- D.`fn1` 函数的调用次数取决于 `num1` 和 `num2` 的值

---

## 答案

**正确答案：** B

---

## 解析

`fn1(n,1,1)` 迭代产生斐波那契数列，与递归函数 `fn2(n)` 功能相同。fn1 每次只递归一次，时间复杂度为线性；fn2 有重复调用，复杂度更高，调用次数由 n 决定而非数值参数。
