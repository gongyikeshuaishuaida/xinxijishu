# 题目 10

定义如下函数：

```python
def f(a, b):
    if a == b:
        return b
    if a > b:
        return f(a - b, b)
    else:
        return f(a, b - a)
```

执行语句`k = f(24,14)`后，k的值为（   ）

- A. 2
- B. 4
- C. 6
- D. 14

---

## 答案

**正确答案：** A

---

## 解析

该递归用“较大数减去较小数”的方式不断缩小两数，直至相等时返回，等价于辗转相减法求最大公约数：f(24,14)→f(10,14)→f(10,4)→f(6,4)→f(2,4)→f(2,2)→返回2，故k的值为2。
