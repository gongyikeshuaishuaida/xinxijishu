# 题目 10

10.有如下程序段：

```python
from random import randint
def f(i,j):
    if i>=j:
        return 0
    t=randint(1,2)
    return f(i+t,j)+1
```

执行 `k=f(0,5)` 后，k的值不可能为：

A.3  B.4  C.5  D.6

---

## 答案

**正确答案：** D

---

## 解析

每次步长为1或2，从0走到5至少3步、最多5步，不可能需要6步。
