# 题目 10

定义如下函数：

```python
def ack(m, n):
    if m == 0:
        return n + 1
    elif n == 0:
        return ack(m - 1, 1)
    else:
        return ack(m - 1, ack(m, n - 1))
```



调用`ack(1, 2)`时，函数的返回值和调用次数分别为`a, b`，请问`a`和`b`的值分别为（   ）

- A. 4，5
- B. 4，6
- C. 5，5
- D. 5，6

---

## 答案

**正确答案：** B

---

## 解析

调用依次涉及`ack(1,2)`、`ack(1,1)`、`ack(1,0)`、`ack(0,1)`、`ack(0,2)`、`ack(0,3)`，包含首次调用共6次，返回4。
