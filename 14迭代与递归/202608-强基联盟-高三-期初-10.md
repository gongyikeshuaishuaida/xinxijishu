# 题目 10

定义如下函数：

```python
def p(x, y):
    if x == 0 or x == 1:
        print(x, end=",")
    else:
        p(x // y, y)
        print(x % y, end=",")
```

执行语句 `p(38, 3)` 后，依次输出的结果为（   ）

- A. `2, 0, 1, 1,`
- B. `1, 1, 0, 2,`
- C. `2, 0, 1,`
- D. `2,`

---

## 答案

**正确答案：** B

---

## 解析

递归调用依次把 38、12、4 除以 3 取整，最后到达基例 1，回溯时依次输出余数。输出顺序为 `1, 1, 0, 2,`，所以选 B。
