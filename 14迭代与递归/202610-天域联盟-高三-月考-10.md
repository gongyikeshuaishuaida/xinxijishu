# 题目 10

有如下程序段：

```python
def dx(h,t):
    if h == t:
        return ""
    if h % 3 == 0:
        a[t] = a[h]
        return dx((h + 1) % 6, (t + 1) % 6)
    else:
        return a[h] + dx((h + 1) % 6, t)
a = ["1","2","3","4","5","6"]
print(dx(0,5))
```

执行后显示结果是（   ）

- A. 12453
- B. 124536
- C. 23514
- D. 235614

---

## 答案

**正确答案：** C

---

## 解析

下标0的数据1被移到下标5；随后连接2、3。到下标3时将4移到下标0，再连接5、1、4，直到头尾相等，结果为23514。取模使下标在0～5之间循环。
