# 题目 10

定义如下 Python 函数：

```python
def f(m,n):
    if m>=n:
        return m
    else:
        return f(m+m%2+1,n-1)+1
```

执行语句 `k=f(6,12)` 后，`k` 的值为（   ）

- A. 11
- B. 12
- C. 13
- D. 14

## 答案

**正确答案：** D

## 解析

递归调用过程为 `f(6,12) → f(7,11)+1 → f(9,10)+2 → f(11,9)+3`。最后一次调用满足 `m>=n`，返回 11，再加上前面 3 次调用累加的 1，结果为 14，选择 D。
