# 题目 10

10.递归函数 `reverse(s)` 的功能是输出字符串反序，例如输入 `hello` 输出 `olleh`：

```python
def reverse(s):
    if len(s) <= 1:
        return s
    return ______
```

- A.`s[-1] + reverse(s[1:])`
- B.`reverse(s[1:]) + s[-1]`
- C.`s[-1] + reverse(s[:-1])`
- D.`reverse(s[:-1]) + s[-1]`

---

## 答案

**正确答案：** C

---

## 解析

每次取出最后一个字符放在前面，再递归处理去掉最后一个字符的前缀，即 `s[-1] + reverse(s[:-1])`，选 C。
