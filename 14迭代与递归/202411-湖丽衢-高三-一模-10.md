# 题目 10

10. 定义如下函数：

~~~python
def f(x,y,flag):
    if flag == False:
        return x*y//f(x,y,not flag)
    if x == y:
        return x
    elif x < y:
        return f(x,y-x,flag)
    else:
        return f(x-y,y,flag)
~~~

执行语句 w = f(6,9,False) 后，w 的值为（   ）

- A. 18
- B. 9
- C. 6
- D. 3

---

## 答案

**正确答案：** A

---

## 解析

当 flag=False 时，函数返回 6*9 除以 f(6,9,True)。真分支用连续相减求最大公约数，f(6,9,True)=f(6,3,True)=3，所以 w=54//3=18。
