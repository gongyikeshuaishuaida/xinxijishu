# 题目 19

有如下Python程序段：

```python
def f(x):
    if x<=2:
        return 2
    return f(x-1)*f(x-3)
print(f(5))
```

关于该程序段，下列说法不正确的是（   ）

- A. 自定义函数采用了递归算法
- B. 自定义函数的时间复杂度是`O(n)`
- C. 执行该段程序时，自定义函数被调用6次
- D. 执行该段程序后，输出的结果是16

---

## 答案

**正确答案：** B、C（按总调用次数计，本题存在单选设问歧义）

---

## 解析

程序输出16。一般输入n的调用量满足 `T(n)=T(n-1)+T(n-3)+O(1)`，呈指数增长，B不正确。`f(5)`的调用顺序为 `f(5), f(4), f(3), f(2), f(0), f(1), f(2)`，总计7次，故按“函数被调用”的通常总次数理解，C也不正确；若出题者只统计函数体内发起的递归调用，则为6次，可能预期只选B。保留原题文字，不能在没有官方解释时把C静默改成7次。
