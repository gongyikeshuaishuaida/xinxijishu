# 题目 10

10.定义函数：

```python
def f(x, y):
    if y == 0 or x == y:
        return 1       # ①
    else:
        return f(x-1, y-1) + f(x-1, y)
```

执行 `k=f(3,2)`，以下说法正确的是（ ）

- A. `k` 的值为 3
- B. 该算法的时间复杂度为 `O(n)`
- C. `f(2,1)` 被调用了 2 次
- D. ①处代码只执行了 1 次

---

## 答案

**正确答案：** A

---

## 解析

`f(3,2)=f(2,1)+f(2,2)=2+1=3`；递归树规模不是线性，`f(2,1)`只在左支调用一次，基线代码执行多次，因此选 A。
