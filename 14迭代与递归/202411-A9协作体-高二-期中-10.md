# 题目 10

10. 有如下 Python 代码：

```python
from random import randint

def gcd(x, y):
    while y > 0:
        t = x
        x = y
        y = t % y
    return x

print(gcd(randint(2, 10), randint(4, 8)))
```

程序运行后所有可能的输出结果中，最大值为（   ）

- A. `10`
- B. `8`
- C. `4`
- D. `2`

---

## 答案

**正确答案：** B

---

## 解析

函数使用辗转相除法求两个随机整数的最大公约数。第二个随机数的最大值为 8，因此最大公约数不可能超过 8；当两个随机数都取 8 时，最大公约数为 8，所以最大值为 8。
