# 题目 10

10.定义函数：

~~~python
def fun(x,y):
    if x<0:
        return y
    else:
        return fun(x-2*y-1,y-1)
~~~

执行语句 s=fun(13,3) 后，s 的值为（ ）

- A.0
- B.1
- C.2
- D.3

---

## 答案

**正确答案：** A

---

## 解析

递归调用的参数依次为 (13,3)、(6,2)、(1,1)、(-2,0)。最后一次满足 x<0，返回 y=0，所以 s=0。
