# 题目 09

定义如下函数：

```python
def jc(n):
    if n==1:    # ①
        return n
    return n*jc(n-1)    # ②
```

执行语句 `x=jc(5)`，下列说法正确的是（   ）

- A. 若实参 a 为正整数，则函数 jc(a) 的调用次数为 a
- B. 程序执行完毕，①处代码共执行 1 次
- C. 程序执行完毕，②处代码共执行 5 次
- D. 如果①处代码改成 n<2，程序将无法正常执行

---

## 答案

**正确答案：** A

---

## 解析

从正整数 a 递归到 1，共调用 a 次。jc(5) 检查终止条件 5 次，递推表达式执行 4 次。
