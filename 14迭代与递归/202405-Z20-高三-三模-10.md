# 题目 10

定义如下函数：

```python
def peach(day):
    if day == 7:
        num = 1
    else:
        num = (peach(day + 1) + 1) * 2
    return num

print(peach(1))
```

执行该程序段后，输出的结果是（   ）

- A.14
- B.94
- C.190
- D.382

---

## 答案

**正确答案：** C

---

## 解析

从第 7 天反向计算：`day=7` 时为 1，前一天依次得到 4、10、22、46、94、190，因此 `peach(1)=190`，故选 C。
