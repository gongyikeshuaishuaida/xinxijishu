# 题目 10

定义如下函数：

```python
def f(n,k):
    if k == n:
        return 1
    elif k == 0 or k > n:
        return 0
    else:
        return k * f(n-1,k) + f(n-1,k-1)
```

执行语句`s=f(4,2)`后，`s`的值为（   ）

- A. 3
- B. 5
- C. 7
- D. 9

---

## 答案

**正确答案：** C

---

## 解析

由边界条件，f(2,2)=1，f(2,1)=1，故f(3,2)=2×1+1=3，f(3,1)=1。于是f(4,2)=2×f(3,2)+f(3,1)=2×3+1=7。
