# 题目 09

9. 某 Python 程序段如下：

```python
def fun(x, y):
    while x < y:
        a[x], a[y] = a[y], a[x]
        x += 1
        y -= 1

a = [1, 2, 3, 4, 5]
k = 3
fun(0, k-1)
fun(k, len(a)-1)
fun(0, len(a)-1)
```

执行该程序段后，列表 `a` 的值是（ ）

- A. `[1, 2, 3, 4, 5]`
- B. `[4, 5, 1, 2, 3]`
- C. `[5, 4, 3, 2, 1]`
- D. `[3, 4, 5, 1, 2]`

---

## 答案

**正确答案：** B

---

## 解析

前两次调用分别反转前 3 个元素和后 2 个元素，得到 `[3,2,1,5,4]`；最后一次整体反转得到 `[4,5,1,2,3]`，故选 B。
