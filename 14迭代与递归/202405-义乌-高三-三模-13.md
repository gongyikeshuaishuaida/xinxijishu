# 题目 13

计算一个正整数各位数字的平方和，再对这个和的各位数字求平方和，循环直到出现重复数。例如 `16→37→58→89→145→42→20→4→16`，统计不重复数的个数。

（1）若输入 `n=38`，得到的不重复数个数是 ______①______ 个。

（2）完善程序：

```python
def sqrsum(x):
    if 0 < x < 10:
        return x ** 2
    return sqrsum(x // 10) + ______②______

d = []
k = int(input())
c = 0
while ______③______:
    d.append(k)
    ______④______
    c += 1
print(c)
```

（其中 ① 为计数空，②—④ 依次为程序中的三个代码空。）

![[attachments/202405义乌高三_13_代码填空图.jpg]]

---

## 答案

**正确答案：** （1）10；（2）②`(x%10)**2`；③`k not in d`；④`k=sqrsum(k)`

---

## 解析

平方和递归时，低位数字为 `x%10`，其平方要加到高位递归结果中。循环每次先判断当前数是否已在列表 `d` 中，未出现才追加并把 `k` 更新为各位平方和；从 38 开始依次得到 38、73、58、89、145、42、20、4、16、37，共 10 个不重复数，下一次出现 58 时停止。
