# 题目 10

定义如下函数：

```python
def g(n):
    if n == 0:
        return 0
    elif n % 2 == 0:
        return 1 + g(n // 2)
    else:
        return g(n - 1)

m = g(14)
```

执行语句 `m = g(14)` 后，`m` 的值为（   ）
- A. 3
- B. 4
- C. 5
- D. 6

---

## 答案

**正确答案：** A

---

## 解析

偶数分支把 n 除以2并加1，奇数分支先减1。递归过程为 14→7→6→3→2→1→0，其中偶数14、6、2各贡献1，因此 m=3。
