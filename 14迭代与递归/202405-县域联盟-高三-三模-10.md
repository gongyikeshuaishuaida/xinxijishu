# 题目 10

10.定义如下函数：

```python
def f(n):
    if n<=1:
        return 1
    elif n%2==0:
        return f(n-3)+1
    return f(n-1)*2
```

执行语句 `s=f(6)` 后，`s` 的值为（ ）

- A.3
- B.4
- C.5
- D.6

---

## 答案

**正确答案：** C

---

## 解析

`f(2)=f(-1)+1=2`，`f(3)=f(2)*2=4`，`f(6)=f(3)+1=5`，故选 C。
