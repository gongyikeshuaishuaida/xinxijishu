# 题目 11

11.有如下 Python 程序段：

```python
def f(n):
    if n <= 1:
        return 1
    else:
        return f(n-1) + f(n-2)

print(f(3))
```

程序输出结果为3，函数 `f` 被调用的次数是（ ）

- A.5
- B.4
- C.3
- D.2

---

## 答案

**正确答案：** A

---

## 解析

`f(3)` 调用 `f(2)` 和 `f(1)`，`f(2)` 又调用 `f(1)` 和 `f(0)`，加上最初的 `f(3)` 共5次调用。
