# 题目 10

有如下 Python 程序段：

```python
def ring(s, k):
    if s == "":
        return ""
    i = k % len(s)
    return s[i] + ring(s[:i] + s[i+1:], k)
```

则运行语句 `print(ring("abcde", 3))` 后，输出的结果为（   ）

- A. deacb

- B. dabce

- C. bcaed

- D. becda

---

## 答案

**正确答案：** A

---

## 解析

每次取当前字符串下标 `3%长度` 的字符并删除该字符，依次取d、e、a、c、b，输出deacb。
