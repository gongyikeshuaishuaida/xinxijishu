# 题目 11

有如下 Python 程序段：

```python
def f(s):
    if len(s) == 0:
        return 0
    elif s[0] == s[-1]:
        return 1 + f(s[1:-1])
    else:
        return f(s[1:-1])

s = "AABAA"
print(f(s))
```

运行后，下列说法正确的是（   ）

- A. 程序输出结果是 3
- B. 最后一次调用 `f` 时 `s` 的值是 `"B"`
- C. 函数 `f` 被调用了 3 次
- D. 若把 `s` 改为 `"AABBAA"`，输出结果为 4

---

## 答案

**正确答案：** A

---

## 解析

每次比较字符串首尾字符后去掉首尾继续递归。`AABAA→ABA→B→空串`，前三层首尾都相同，结果为 3；最后一次调用的参数是空串，共调用 4 次。
