# 题目 11

有如下 Python 程序：

```python
def f(n, k):
    if k == 0 or n == k:
        return 1
    else:
        return f(n - 1, k) + f(n - 1, k - 1)

print(f(4, 3))
```

执行该程序段后，函数 `f` 被调用的次数是（   ）

- A. 5
- B. 6
- C. 7
- D. 8

---

## 答案

**正确答案：** C

---

## 解析

调用树为 f(4,3)→f(3,3) 与 f(3,2)；其中 f(3,3) 立即返回，f(3,2) 再调用 f(2,2) 与 f(2,1)，f(2,1) 又调用两个基例，共 7 次调用。
