# 题目 06

下列关于网络系统的说法，不正确的是（ ）
- A. 网络系统由计算机系统、数据通信系统、网络软件和网络协议组成
- B. 计算机网络按覆盖范围分为局域网、城域网、广域网
- C. HTTP 协议用于管理被传送内容的完整性
- D. 网络系统最基本的功能是数据通信

---

## 答案

**正确答案：** C

---

## 解析

HTTP 主要规定客户端与服务器之间的超文本传输规则，不负责保证被传送内容的完整性；其余说法符合网络系统基础知识。
