# 题目 11

班级植物区环境监测系统每隔30分钟监测土壤温湿度，当土壤日平均湿度低于临界值时自动浇水。系统结构和数据、图表如下：

![[attachments/202307浙江省_11_图1.jpg]]

![[attachments/202307-浙江省-高二-学考-11_横排2_3.png]]

（1）图中①处的设备名称是 ______①______（单选，填字母：A.路由器 / B.交换机 / C.智能终端）。

（2）服务器IP地址为 `192.168.1.10`，端口号为 `8000`，查看传感器数据的页面地址为：

`http://______②______`

（3）从“时间”中提取日期并绘制日平均湿度，补全代码。

```python
import pandas as pd
import matplotlib.pyplot as plt
df=pd.read_excel("day.xlsx")
data=[]
for t in df["时间"]:
    data.append(______③______)
df["日期"]=data
df1=df.groupby("日期", as_index=False).mean()
```

（4）根据图表，系统运行期间对植物生长土壤的湿度控制 ______⑤______（达到 / 未达到）预期目标。

---

## 答案

**正确答案：** （1）C；（2）`192.168.1.10:8000/view`；（3）③ `t[0:5]`（或`t[:5]`）；④ `df1["湿度"]`；（4）达到

---

## 解析

（1）智能终端同时连接传感器和执行器，负责采集数据并发出控制指令，因此①为智能终端C。

（2）由系统图可知查看数据的路由是 `/view`，将服务器IP和端口拼接得到 `http://192.168.1.10:8000/view`。

（3）时间字符串前5位表示日期，故可用 `t[0:5]` 提取；分组求平均后，纵轴应取湿度列 `df1["湿度"]`。

（4）图中湿度低于目标范围时出现浇水后回升，运行期间日平均湿度保持在目标范围内，达到预期目标。
