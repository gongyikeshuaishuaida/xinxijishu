# 题目 13

13.小林为“无人值守超市”设计信息系统，完成客户身份识别、自动结算和库存跟踪。

（1）下列技术中未使用生物特征识别认证技术的是（A.人脸识别 / B.动态短信口令认证 / C.指纹识别）。

（2）顾客经过警示区时检测是否误带未支付商品，最适合的方案是：

A.摄像头捕捉商品图像并识别支付情况
B.热敏传感器探测商品及支付情况
C.在商品上粘贴无源电子标签，使用 RFID 识别商品及支付情况

（3）关于系统搭建，正确的是（多选）：

A.概要设计主要包括模块结构设计、系统物理配置和数据库管理系统选择三大部分
B.数据库需要连接在智能终端上存储传感器数据
C.服务器端程序为 IoT 模块设置连接无线网络的 SSID、账号和密码
D.客户端以 `/input?id=9&val=17.9` 提交数据时，服务器可用 GET 方式接收

（4）可识别区域与采集画面均为边平行矩形，交叠面积用于判断站位：

```python
left = max(mx1, px1); right = min(mx2, px2)
bottom = max(my1, py1); top = min(my2, py2)
if right <= left or top <= bottom:
    s = 0
else:
    s = ______①______
if s < smin:
    if ______②______:
        # 提示用户向左上角移动
        ...
```

![[attachments/202405精诚联盟高三_13_坐标示意图.jpg]]

（5）请从数据安全、网络安全等角度给出两个增强措施。

---

## 答案

**正确答案：** （1）B；（2）C；（3）AD；（4）① `(right-left)*(top-bottom)`；② `my1>py1 and mx2<px2`；（5）如对身份证、人脸、指纹等敏感数据加密存储与传输；设置访问控制和分级权限；配置防火墙、杀毒软件并定期漏洞检测等（任两项）

---

## 解析

动态短信口令属于口令认证而非生物特征认证；RFID 可根据商品标签准确识别商品。概要设计可包括模块、物理配置和数据库管理系统选择，GET 可接收 URL 查询参数。矩形交叠面积为宽乘高；右下角越出可识别区域且位于右下方时，应提示向左上方移动。安全措施应覆盖加密、访问控制、防火墙或漏洞检测等方面。
