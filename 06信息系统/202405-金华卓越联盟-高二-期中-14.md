# 题目 14

14.小华搭建室内绿植养护管家系统：实时监测土壤湿度，低于阈值时打开水泵浇水；用户可通过浏览器查看实时监测结果和历史数据。系统结构如下：

![[attachments/202405金华卓越_14_绿植系统图.jpg]]

（1）属于执行器的设备是（A.水泵 / B.土壤湿度传感器 / C.智能终端 / D.服务器）。

（2）关于系统搭建与应用，正确的是（多选）：

- A.选择 SQLite 数据库进行数据管理，属于搭建信息系统的详细设计
- B.该系统网络应用软件的实现架构是 B/S 架构
- C.若 IoT 模块与智能终端连接故障，用户将无法查看历史湿度数据
- D.对服务器进行定期检查和维护，保证使用的稳定性

（3）每隔1分钟从两个传感器获取湿度值，若均值低于阈值则开启水泵，工作一段时间后关闭，否则水泵不工作，并上传数据：

```python
while True:
    # 获取 hum1、hum2 的代码略
    open = False
    if ______①______:
        open = True
        # 打开水泵并工作一段时间后关闭，代码略
    # 上传 hum1、hum2、open 等数据
    sleep(1000*60)
```

传感器编号、湿度值、水泵开关状态、上传时间等信息至少需要设计 ______②______ 个字段。

（4）浏览器查询到植物缺水，但水泵没有启动，可能原因有（多选）：A.传感器故障；B.传感器与智能终端连接异常；C.水泵故障；D.水泵与智能终端连接异常；E.智能终端故障。

---

## 答案

**正确答案：** （1）A；（2）BD；（3）① `(hum1+hum2)/2<h`；②4；（4）CD

---

## 解析

水泵是执行器，浏览器访问系统体现 B/S 架构，服务器维护有助于稳定运行；历史数据已在服务器保存，IoT 与终端暂时断开不必然导致历史数据无法查看。均值低于阈值时才置 `open=True`，四类上传信息至少对应4个字段。已有缺水数据说明传感器和终端已得到并上传状态，故更可能是水泵本体或终端到水泵的连接故障。
