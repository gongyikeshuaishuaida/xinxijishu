# 题目 06

阅读下列材料，回答第06题：

在某校园的一卡通系统中，学生凭校园卡完成图书借阅、食堂用餐和超市消费，并通过电子班牌完成签到与签退。教师与家长可通过计算机或手机终端的浏览器，查询学生在校园内的相关动态。

下列关于该系统中网络技术的说法，不正确的是（   ）

- A. 查询学生信息的 URL（网址）中包含服务器地址信息
- B. 路由器开启 DHCP 服务后，终端设备可以获取动态地址
- C. 移动终端访问系统服务器时，两者必须在同一局域网内
- D. 终端设备接入路由器，通常情况下两者的 IP 地址属于同一网段

## 答案

**正确答案：** C

## 解析

服务器可通过公网或其他网络提供访问，移动终端不必与服务器处于同一局域网；URL包含服务器地址，DHCP可动态分配地址，同一局域网内终端与路由器通常处于同一网段。
