# 题目 13

小华搭建了一个教室照明灯控制系统。智能终端连接物联网模块、光线传感器、人体红外传感器和室内照明灯等设备。智能终端从服务器获取阈值等参数后自动控制照明灯，并把采集到的数据传输到服务器。用户可通过手机 APP 或浏览器查看历史数据和照明灯状态。系统架构如下：

![[attachments/202409嘉兴_13_照明控制系统架构图.jpg]]

（1）采集教室光线数据采用的技术是（   ）（单选：A.人工智能 / B.传感 / C.射频识别）。

（2）图中①处的设备为（   ）（单选：A.路由器 / B.交换机 / C.防火墙 / D.IoT 模块）。

（3）下列说法正确的是（   ）（多选）。

- A. 该系统采用了 B/S 架构
- B. 用户远程控制照明灯开关，需通过服务器实现
- C. 用户手机可以通过 IoT 模块以无线方式连接服务器
- D. 浏览器获取照明灯控制系统的数据来源于智能终端

（4）智能终端每隔 1 分钟获取 1 次亮度值，若连续两次数据的变化量超过 `val`，则向服务器上传一次数据；如果教室有人且亮度值低于阈值 `k`，则照明灯开启，否则关闭。补全程序：

```python
last = -1
val = 5  # 设定变化量
sw = False  # 标记照明灯状态
while True:
    light = pin0.read_analog()
    # 从红外线传感器获取数据判断教室是否有人，结果存于 flag 中，代码略
    if ______①______:
        # 将 light 光线亮度数据传输到服务器，代码略
        last = light
    if flag and light < k:
        pin8.write_digital(1)
        ______②______
    else:
        pin8.write_digital(0)
        sw = False
    sleep(1000 * 60)
```

---

## 答案

**正确答案：** （1）B；（2）D；（3）A、B；（4）① `abs(light-last)>val`；② `sw=True`

---

## 解析

光线传感器体现传感技术，智能终端与服务器间需要 IoT 模块。浏览器访问体现 B/S 架构，远程控制需经服务器转发。连续两次亮度变化量取绝对值比较；灯打开后同步把状态变量设为 `True`。
