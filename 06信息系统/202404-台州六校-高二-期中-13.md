# 题目 13

小明设计“室内光照强度实时监测系统”：光敏传感器采集光照强度，数据经智能终端处理后与阈值比较，小于阈值时打开补光灯，大于等于阈值时在智能终端屏幕显示笑脸。系统结构如下。

![[attachments/202404台州六校_13_光照系统结构图.jpg]]

（1）图中①②分别表示的设备名称是：① ______①______，② ______②______（填字母：A.防火墙 B.智能终端 C.数据库 D.传感器）；该系统开发模式采用 ______③______ 架构。

（2）代码如下，补光灯连接在智能终端上的引脚为 ______④______。

```python
maxrv = 300
while True:
    light = pin0.read_analog()
    if light >= maxrv:
        display.show(Image.HAPPY)
    else:
        pin8.write_digital(1)
        sleep(2000)
```

（3）服务器代码如下：

```python
from flask import Flask, render_template
app = Flask(__name__)
@app.route("______⑤______")
def hello():
    return render_template('index.html')
@app.route("/input", methods=['POST', 'GET'])
def add_data():
    pass
```

访问 `http://192.168.1.1:5000/` 可渲染 `index.html`；横线处为 ______⑤______，服务器通过 ______⑥______ 方法获取传感器数据。

---

## 答案

**正确答案：** ① B；② C；③ B/S；④ pin8（或 p8）；⑤ `/`；⑥ GET

---

## 解析

传感器数据先由智能终端处理，终端连接补光灯并把数据上传服务器，数据库存储数据；浏览器通过根路由 `/` 请求页面，上传数据的路由允许 GET/POST，本题按参考答案取 GET。
