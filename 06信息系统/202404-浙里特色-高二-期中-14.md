# 题目 14

14.小明搭建某智慧教室信息系统，使教室通过互联网获取光线亮度信息，并根据阈值自动控制照明灯。系统架构如下图。

![[attachments/202404浙里特色_14_智慧教室架构图.jpg]]

（1）图中①②③处表示的硬件设备名称分别是 ______①______（单选，填字母）。

A.传感器、执行器、Web 服务器　B.传感器、执行器、路由器　C.执行器、传感器、路由器　D.执行器、传感器、Web 服务器

（2）选择合适的数据库管理系统属于 ______②______（单选，填字母）。

A.需求分析　B.可行性分析　C.概要设计　D.详细设计

（3）通过手机浏览器登录Web服务器查看数据，网络应用软件的实现架构是 ______③______（填字母：A.C/S；B.B/S）。

（4）为避免重复记录，智能终端代码中的划线处应填：

```python
while True:
    light = pin0.read_analog()
    last = -1
    if ______④______:
        erron, resp = Obloq.get('input?id=1&val=' + str(light), 10000)
```

从代码可以看出，连接传感器的引脚是 ______⑤______，连接执行器的引脚是 ______⑥______。

---

## 答案

**正确答案：** ① D；② C；③ B；④ `last != light`；⑤ `pin0`；⑥ `pin8`

---

## 解析

光线传感器是输入设备，照明灯执行器是输出设备，服务器负责网络服务；选择数据库管理系统属于概要设计，手机浏览器访问服务器采用 B/S 架构。只有当前后光照数据不同才上传，因此判断为 `last!=light`；代码中的 `pin0` 读取传感器，`pin8` 控制执行器。
