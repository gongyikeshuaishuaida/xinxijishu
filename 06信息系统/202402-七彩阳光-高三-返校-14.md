# 题目 14

某蔬菜大棚需要搭建自动化温湿度调节系统。系统通过温湿度传感器采集数据，由智能终端经 IoT 模块发送到 Web 服务器并存储在数据库中，同时根据阈值控制喷水装置或控温装置；用户可通过浏览器查看实时或历史数据。系统结构如图 a 所示。

## 答案

**正确答案：** ① B；② A、B；③ `192.168.0.2:5000/read?type=1`；④ `sum`；⑤ `dft.at[j,"时间"][:2] == s`

---

## 解析

路由器负责无线信号和网络互联，但不处理 Web 请求，故（1）为 B。历史数据已经在服务器数据库中，读取时不需要传感器和智能终端，故（2）为 A、B；实时数据路由为 `/read?type=1`，URL 为 `192.168.0.2:5000/read?type=1`。浏览器1位于局域网内，查看稳定但受局域网范围限制；浏览器2通过互联网可远程查看，但互联网中断时无法访问。按时间分组后用 `sum` 汇总状态值为 2 的异常监测点，再按小时统计即可。
