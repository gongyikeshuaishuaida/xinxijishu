# 题目 06

下列关于网络通信的说法，不正确的是（   ）

- A. HTTP 协议可用于浏览器与服务器之间的通信
- B. IP 地址是同一网络中设备的唯一标识
- C. 局域网中的设备通过 TCP/IP 协议动态分配 IP 地址
- D. 路由器将局域网内的私有 IP 地址转换为公网 IP 地址

---

## 答案

**正确答案：** C

---

## 解析

HTTP 可用于浏览器与 Web 服务器通信，IP 地址可用于标识网络中的设备，路由器可通过 NAT 把局域网私有 IP 转换为公网 IP。局域网设备动态获取 IP 地址使用 DHCP 协议，不能说是由 TCP/IP 协议动态分配，因此 C 不正确。
