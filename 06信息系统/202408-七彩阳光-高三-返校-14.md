# 题目 14

学校图书管理系统通过校园卡、终端和Web服务器收集、传输、处理读者与图书数据。

第14题图a：

![[attachments/202408-七彩阳光-高三-返校-14_横排1_2.png]]

（1）使用RFID技术采集数据的是 ______①______（单选，填字母：A.电子标签；B.条形码；C.二维码）。

（2）录入实际存在的图书编号后无法获取图书数据，下列描述不正确的是 ______②______（单选，填字母）。

- A. 若访问服务器的其他页面也出现异常，则可能是终端与Web服务器通信异常造成的
- B. 若Web服务器与数据库连接异常，也可能无法获取图书数据
- C. 无法获取图书数据的故障，是由于终端录入设备与终端浏览器通信异常造成的

（3）关于系统设计与搭建，说法正确的是 ______③______（多选，填字母）。

- A. 选择B/S模式开发该系统属于前期准备中的需求分析
- B. 读者还书时要求进行身份认证，以提高系统便捷性
- C. 可以选择SQLite数据库管理系统为该系统提供数据存储服务
- D. 信息系统初步搭建后需要进行软硬件测试、网络测试

（4）写出一种身份认证方式及其关键传感器设备：______④______。

（5）统计高三各班借阅数量并按数量降序绘图，方框中应填入的语句依次为 ______⑤______（选2项，填数字序列）。

```python
import pandas as pd
import matplotlib.pyplot as plt
df = pd.read_excel("data.xlsx")
df1 = df[df["年级"] == "高三"]
# 方框处
plt.bar(df1["班级"], df1["书名"])
# 设置绘图参数并显示柱形图，代码略
```

- ① df1按班级分组计数
- ② df按年级分组求和
- ③ df1按书名数量降序排序
- ④ 取df1前5行

（6）筛选类别为“历史”的全校数据：`df2 = df[______⑥______]`。

---

## 答案

**正确答案：** ① A；② C；③ CD；④ 人脸识别—摄像头，或指纹识别—指纹传感器；⑤ ①③；⑥ `df["类别"] == "历史"`

---

## 解析

电子标签使用RFID。录入已成功而查询失败时，终端与服务器通信或服务器与数据库连接异常都可能造成故障，录入设备与浏览器通信不是直接原因。B/S开发模式属于开发模式选择而非需求分析，还书身份认证的主要目的不是便捷性；SQLite可作数据库，系统还需软硬件与网络测试。统计时按班级计数并按书名数量降序排序，筛选条件直接作用于类别列。
