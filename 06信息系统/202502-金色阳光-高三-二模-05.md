# 题目 5

某学校引入了在线点餐系统，学生在教室门口的电子班牌上刷校园卡登录点餐系统，登录后可选择套餐并下单。食堂收到订单后，会通过系统通知学生到相应窗口取餐；学生还可以通过手机 APP 查看自己的点餐记录、消费情况以及食堂的最新优惠信息。关于该系统功能与软件设计的描述，正确的是

- A. 通过手机 APP 查看消费情况需要 HTTP 协议支持
- B. 电子班牌上的点餐 APP 属于系统软件
- C. 学生是通过刷校园卡登录系统的，所以在设计系统时无需考虑信息安全
- D. 该系统中的点餐数据需保存到服务器中

## 答案

**参考答案：** D

## 解析

在线点餐涉及多个终端与服务器之间的数据交互，订单等数据需要保存到服务器中。点餐 APP 属于应用软件，系统设计仍须考虑信息安全；通过手机查看消费情况不必限定为 HTTP 协议这一说法。
