# 题目 5

以下关于该智慧校园系统网络的说法，正确的是

- A. 同一年级的电子班牌需设置为同一个 IP 地址
- B. 云服务器无需安装操作系统
- C. 路由器是组建校园网络的重要设备之一
- D. 智慧校园中的数据通信必须通过移动通信网络实现

## 答案

**参考答案：** C

## 解析

路由器是组建和连接校园网络的重要设备。同一网络中的设备需要有可区分的 IP 地址，服务器需要操作系统，数据通信也可以通过局域网、光纤等多种网络实现。
