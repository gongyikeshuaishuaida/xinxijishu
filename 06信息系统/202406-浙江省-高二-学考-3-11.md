# 题目 11

小明搭建了教室环境温湿度监测系统。系统可实时监测温湿度，数据由智能终端经 IoT 模块发送到 Web 服务器；超过阈值区间时控制执行器调节温湿度，用户可用浏览器查看实时数据。服务器 IP 为 192.168.0.1，端口 5000，网站功能页面规划如图所示。

![[attachments/202406浙江省3_11_环境温湿度系统图表.jpg]]

（1）上述页面规划属于搭建信息系统前期准备的 ______①______ 阶段（单选，填字母：A. 需求分析 / B. 可行性分析 / C. 概要设计 / D. 详细设计）。

（2）根据系统功能要求，图中①②处的设备分别为 ______②______、______③______。

（3）若要查看温湿度统计数据，在客户端浏览器要输入的 URL 为 ______④______。

（4）教室里学生最舒服的温度范围是 tmin～tmax。若温度 t 正常时状态 sta=0，偏高或偏低时 sta=1，下列 Python 程序段中符合要求的有（多选，填字母）：

![[attachments/202406浙江省3_11_温度状态选项图.jpg]]

（5）系统正常工作一段时间后，网页端没有最近 2 小时的温度数据（期间教室温度发生了变化，智能终端没有问题），请说明系统中可能造成问题的原因（回答 2 项）。

---

## 答案

**正确答案：** （1）C；（2）传感器、执行器；（3）http://192.168.0.1:5000/count；（4）B、C；（5）传感器故障、Wi-Fi 故障等。

---

## 解析

页面规划属于概要设计。图中智能终端左侧的输入设备是传感器，右侧的输出设备是执行器；统计页面路径为 /count，完整 URL 需包含服务器 IP 和端口。温度正常区间应使 sta=0，超出区间使 sta=1，B、C 均能实现。智能终端无故障而无数据，可能是传感器或 Wi-Fi 等数据链路环节故障。
