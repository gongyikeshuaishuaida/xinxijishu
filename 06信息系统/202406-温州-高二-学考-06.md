# 题目 06

材料背景：小明搭建自动浇花系统。土壤湿度传感器采集的数据由智能终端传送给 Web 服务器并存入数据库，Web 服务器处理后将状态码传送给智能终端以控制水泵；通过浏览器可以查看历史土壤湿度、历史浇水记录，也可以控制水泵。系统结构图如下。

下列选项标注了图中虚线框内的智能终端、传感器、执行器与无线网络之间的数据传输关系，正确的是（   ）

![[attachments/202406温州_06_系统结构图.jpg]]
![[attachments/202406温州_06_四组选项图.jpg]]

- A.传感器向智能终端传输，智能终端向无线网络传输并控制水泵
- B.智能终端向传感器和无线网络传输，水泵向智能终端传输
- C.传感器向智能终端传输，智能终端与无线网络双向传输并控制水泵
- D.传感器向智能终端传输，水泵向智能终端传输，智能终端与无线网络双向传输

---

## 答案

**正确答案：** C

---

## 解析

传感器把湿度数据送给智能终端，智能终端把数据上传并接收服务器控制状态码，因此与无线网络是双向传输；智能终端再向水泵发送控制信号。图 C 的方向关系完整正确。
