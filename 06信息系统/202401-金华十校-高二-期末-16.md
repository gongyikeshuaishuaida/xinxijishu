# 题目 16

花园喷灌系统由智能终端、传感器、浇灌控制设备、服务器和数据库组成，用户通过浏览器查看运行状态和历史数据。系统截图如下：

![[attachments/202401-金华十校-高二-期末-16_横排1_2.png]]

（1）下列说法正确的是（多选）：A.至少有温湿度传感器；B.智能终端处理浏览器访问请求；C.服务器需连接数据库存储数据；D.要架设无线路由器；E.没有执行器。

（2）若重点考虑升级和维护方便性，应选择的网络应用软件架构为 ______①______。

（3）Flask程序中查看系统运行状态的路由为`/js`，服务器地址如下。查看系统运行状态的网址为 ______②______。

```python
@app.route('/js')
app.run(host="10.190.11.131",port=500)
```

（4）筛选温度30度及以上数据，并以15分钟为间隔提取数据，补全代码。

```python
time=[]; temp=[]
df=df[df.温度>=30]
p=0
for i in df.index:
    s=df.at[i,'时间']
    t1=int(s[3:5])
    t=(______③______)%60
    if t>=15:
        time.append(df.at[i,'时间'])
        temp.append(df.at[i,'温度'])
        p=t
plt.scatter(______④______)
```

---

## 答案

**正确答案：** （1）ACD；（2）B/S架构；（3）`http://10.190.11.131:500/js`；（4）③ `t1-p+60`；④ `time,temp`

---

## 解析

（1）温湿度传感器用于监测环境，服务器连接数据库保存历史数据，智能终端与服务器之间需要无线网络及路由设备；浏览器请求由服务器处理，系统还需要浇灌执行器，所以A、C、D正确。

（2）B/S架构把主要逻辑集中在服务器，客户端使用浏览器，便于统一升级和维护。

（3）URL由协议、主机地址、端口和路由组成；默认HTTP端口为80，题目给出的500端口应写入地址，因此为 `http://10.190.11.131:500/js`。

（4）`p`保存上一次满足条件的分钟值，当前分钟与其间隔不足时通过加60处理跨小时情况，填 `t1-p+60`；散点图横纵坐标分别为`time`和`temp`。
