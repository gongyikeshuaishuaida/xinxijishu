# 题目 13

大棚智能管理系统可以监测温度、光照、湿度等环境数据，并实现智能补光和自动浇灌；智能终端通过 IoT 模块与 Web 服务器通信，用户可通过浏览器查看数据并远程控制执行器。

![[attachments/202407金华十校_13_大棚系统结构图.jpg]]

请回答：
（1）传感器、智能终端和执行器之间的数据传输关系，正确的是（单选）：A. 从传感器到智能终端；B. 从补光灯到智能终端；C. 从水泵到传感器。
（2）关于该系统支撑技术，正确的是（多选）：
- A. 光线传感器属于输入设备
- B. 智能终端不具备数据处理功能
- C. 系统搭建完成后所有软件不能再被修改
- D. 网络应用软件的实现架构为浏览器/服务器架构
（3）温度传感器 id=1、tmp=25 时提交 URL 为 http://192.168.0.101:8080/input?id=1&tmp=25；若湿度传感器 id=3、mois=70，提交 URL 为 http://192.168.0.101:8080/________。
（4）白天 6—18 点关闭补光灯，其他时间仅在 light 小于 lightmin 时打开。请补全：

```python
if start <= t <= end:
    sta = 0
    ______
    sta = 1
else:
    sta = 0
```

（5）服务器数据正常但补光灯一直不亮（通信系统、传感器与智能终端连接均正常），请写出 2 项可能原因。

---

## 答案

**正确答案：** （1）A；（2）A、D；（3）input?id=3&mois=70；（4）elif light < lightmin；（5）lightmin 阈值设置不合理（过低），或补光灯本体/补光灯与终端之间的控制线路故障。

---

## 解析

传感器采集数据后送入智能终端，光线传感器属于输入设备，系统采用浏览器/服务器架构。湿度数据沿用 input 路由并更换 id、mois 参数。白天直接关灯，非白天只有光照低于阈值才开灯；阈值过低或补光灯及其控制线路故障都可能造成一直不亮。
