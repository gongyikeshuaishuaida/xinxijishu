# 题目 13

13.某室内环境监控系统采用 Flask Web 框架开发。传感器每分钟采集 1 次湿度数据（0~100），智能终端通过 IoT 模块将采集到的数据传输至 Web 服务器并存储，系统根据采集到的数据与设定的阈值控制除湿机。客户端可通过浏览器查询实时和历史数据。请回答下列问题：

（1）该网络应用软件的实现架构是 ______①______（单选，填字母）。

- A. B/S 架构
- B. C/S 架构

（2）系统正常工作一段时间后，发现当前湿度值超过了阈值但除湿机未启动，下列解决问题的方法合理的是 ______②______（单选，填字母）。

- A. 调整湿度阈值，查看除湿机是否正常工作
- B. 更换湿度传感器，判断是否是湿度传感器故障
- C. 更换除湿机，判断是否是除湿机故障

（3）下列关于该系统支撑技术的说法，正确的有 ______③______（多选，填字母）。

- A. 智能终端中的接口只能用于连接传感器
- B. 信息系统只能通过串口从传感器获取信息
- C. 在 Flask 中，一个路由只能绑定一个视图函数
- D. 开发完毕后，部署到生产环境中使用时应关闭调试模式

（4）收集一个月的湿度数据处理后得到该月的日平均湿度值，存储在列表 `h` 中，现要找出相邻两天最大湿度差，部分 Python 程序如下，请在程序中划线处填入合适的代码。

```python
def findmax():
    n = len(h)
    imax = 0
    i = 0
    while i < n - 1:
        ch = ______④______
        if ch > imax:
            imax = ch
        i = i + 1
    return imax
```

---

## 答案

**正确答案：** ① A；② C；③ CD；④ `abs(h[i] - h[i + 1])`（或`abs(h[i + 1] - h[i])`）

---

## 解析

（1）客户端通过浏览器访问 Web 服务器，属于 B/S 架构。

（2）当前湿度超过阈值而除湿机没有启动，应先检查执行设备是否故障，选 C。

（3）Flask 路由与视图函数的绑定关系以及生产环境关闭调试模式的要求，使 C、D 正确；接口不只用于传感器，信息系统也不只通过串口获取信息。

（4）相邻两天的湿度差为 `abs(h[i]-h[i+1])`，逐项比较并更新最大值即可。
