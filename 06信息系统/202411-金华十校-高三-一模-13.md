# 题目 13

某校使用教室二氧化碳监测系统，教室内安装传感器用于监测二氧化碳浓度，智能终端将检测数据传输到 Web 服务器（一个智能终端连接两个教室设备），服务器处理数据后发送指令给智能终端，实现通风设备控制。若室内二氧化碳浓度大于等于设定阈值且当前通风设备处于关闭状态，则开启；若连续两次室内二氧化碳浓度均低于阈值，则关闭。该系统的所有检测数据及通风设备状态均可登录相应平台随时随地查看。

（1）若服务器故障，智能终端是否可以正常采集传感器数据 ______①______（单选，填字母：A.可以 / B.不可以 / C.不确定）。

（2）服务器端的部分代码如下：

~~~python
@app.route("/show")
def disp():
    # 实现在网页查看系统数据，代码略

@app.route("/input")
def input():
    # 从数据库获取阈值mco、前一时刻二氧化碳浓度preco和通风设备状态s，代码略
    # 从智能终端获取二氧化碳浓度newco，代码略
    # s = 0表示通风设备关闭，s = 1表示设备开启
    if s == 0:
        if newco >= mco:
            s = 1
        else:
            if ______②______:
                s = 0
    preco = newco
    # 保存preco的值，并向智能终端发送s指令，代码略
~~~

①访问查看系统数据网页的URL是 http://______③______。

②请在上述程序中划线处填入合适的代码。

（3）下列关于该系统设计的说法，正确的有 ______④______（多选，填字母）。

- A. 二氧化碳浓度、通风设备状态等数据存储在数据库
- B. 从系统的安全性考虑，可以在服务器端增加防火墙
- C. 所有的二氧化碳传感器均需连接着同一个智能终端
- D. 智能终端通信必须要通过无线网络

（4）系统调试期间，某一时刻甲教室连续两次测得的二氧化碳浓度均小于阈值，乙教室二氧化碳浓度大于阈值，此时甲教室通风设备开启，而乙教室通风设备关闭。在所有设备功能均正常的情况下，请你分析造成此现象的原因。

---

## 答案

（1）① A

（2）② newco < mco and preco < mco；③ 2.58.11.23:8088/show

（3）④ AB

（4）甲、乙两个教室的智能终端与传感器连接反了；或智能终端上甲、乙两个教室控制器连接反了；或智能终端中的控制代码逻辑错误等合理原因。

---

## 解析

传感器由智能终端采集，服务器故障不影响终端本地采集。连续两次浓度低于阈值对应当前 newco 和前一时刻 preco 同时小于 mco；查看数据的路由为 /show，主机和端口为 2.58.11.23:8088。数据库、防火墙属于合理设计，传感器不必全部连接同一终端，通信也不必只能使用无线网络。甲乙设备或控制通道对应错误，会导致采集数据和控制指令错配。
