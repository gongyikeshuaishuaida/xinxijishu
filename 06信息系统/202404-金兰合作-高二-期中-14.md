# 题目 14

小明为家里搭建了“环境温湿度、烟雾监控系统”，该系统结构示意图如下。Web服务器端程序采用Flask Web框架开发。传感器采集的数据由智能终端经IoT模块发送到Web服务器，执行器用于实现温湿度及烟雾异常时的报警。请回答下列问题。

![[attachments/202404金兰合作_14_系统结构图.jpg]]

（1）下列选项标注了图中虚线框内的浏览器、服务器和数据库之间的数据传输关系，其中合理的是 ______①______（单选，填字母）。

![[attachments/202404金兰合作_14_浏览器服务器选项.jpg]]

（2）该系统采用的实现架构是 ______②______（单选，填字母：A. B/S架构；B. C/S架构）。

（3）小明基于Flask Web框架编写服务器端的程序，部分代码如下。编写完成后，若要通过浏览器显示当前最新采集的数据，则应访问的URL是 `http://______③______`。

```python
# 导入Flask框架模块及其他相关模块，代码略
app = Flask(__name__)

@app.route('/')
def index():
    # 从数据库读取当前温湿度和烟雾数据，并返回页面，代码略
    pass

@app.route('/input', methods=['GET'])
def insert():
    # 将传感器编号、传感器采集的数据和当前时间存入数据库，代码略
    pass

# 服务器其他功能，代码略
if __name__ == '__main__':
    app.run(host='192.168.1.108', port=5000)
```

（4）下列关于该信息系统的说法，正确的有 ______④______（多选，填字母）。

- A. 智能终端有程序存储和数据处理能力
- B. 智能终端只能通过IoT模块以无线方式连接服务器
- C. 完成该系统的搭建需要编写服务器端程序和智能终端程序
- D. 系统搭建完成后，运行程序观察蜂鸣器能否发出声音属于动态测试

（5）系统搭建完毕后，目前使用者仅能通过蜂鸣器得知有参数达到预设阈值，但无法具体识别是温度、湿度还是烟雾浓度超标。现在要增设执行器来实现对不同类型参数超标的分类处理功能。写出增加的执行器名称及实现的功能：______⑤______。

---

## 答案

**正确答案：** ① A；② A；③ `192.168.1.108:5000/`；④ ACD；⑤ 增加风扇和除湿机，当温度达到阈值时风扇自动打开，当湿度达到阈值时除湿机自动打开（其他合理答案亦可）

---

## 解析

浏览器和服务器、服务器和数据库均需双向通信，故（1）A；浏览器访问服务器是 B/S 架构，故（2）A；根路由对应服务器地址和端口；无线和有线均可连接，因此 B 错，正确项为 ACD；分类处理可增加风扇、除湿机等执行器。
