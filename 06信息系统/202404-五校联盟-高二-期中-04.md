# 题目 04

在游客管理信息系统情境中，下列关于网络技术的说法，正确的是（   ）

- A. HTTP 协议负责管理被传送内容的完整性
- B. 不同的终端进行通信，必须连接到计算机网络
- C. IP 是网际协议，负责将信息从一个地方传送到另一个地方
- D. 系统服务器与终端必须在同一个局域网中，该系统才能正常运行

## 答案

**正确答案：** C

## 解析

IP 负责在网络中寻址并将数据包从源地址传送到目的地址。HTTP 主要规定 Web 通信，可靠性和完整性由传输层等机制保障；终端通信不必限定在同一局域网，也不能据此断言必须连接某种计算机网络。
