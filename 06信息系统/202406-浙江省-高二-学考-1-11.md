# 题目 11

小明为叔叔家的草莓大棚搭建了温湿度控制系统。土壤湿度传感器和温度传感器采集的数据由智能终端经 IoT 模块传送到 Web 服务器，执行器用于控制水泵和电暖器的开关。小明通过浏览器可以在家实时查看大棚的温湿度数据。系统结构如图所示。

![[attachments/202406浙江省1_11_温湿度控制系统结构图.jpg]]

（1）小明选择嵌入式开源数据库 SQLite 作为系统的数据存储，这属于搭建信息系统前期准备过程中的 ______①______ 阶段（单选，填字母：A. 需求分析 / B. 开发模式选择 / C. 概要设计）。

（2）该系统采用 B/S 架构搭建，与 C/S 架构相比，下列不属于 B/S 架构优点的是 ______②______（单选，填字母：A. 对服务器性能要求较低 / B. 无需开发专门的客户端应用程序 / C. 升级和维护较为方便）。

（3）Web 服务器端程序采用 Flask Web 框架开发，部分代码如下：

```python
app = Flask(__name__)

@app.route("______③______")
def uploadData():
    # 获取智能终端提交的数据，并将数据存入数据库，代码略
    return "ok"
```

若智能终端提交数据到服务器的 URL 为 `http://192.168.30.12:8000/upload?id=s01&temp=25`，则 ③ 处应填入：______④______。

（4）草莓适宜生长的温度范围为 t1～t2（含 t1、t2），服务器接收到的温度值存储在变量 `temp` 中，若符合条件，将状态变量 `f` 设为 1，否则设为 0。下列程序段能实现该功能的是（多选，填字母）：

![[attachments/202406浙江省1_11_温度判断选项图.jpg]]

答案填写：______⑤______。

（5）系统运行一段时间后，最近两天的湿度数据都小于系统设定阈值，水泵未启动；经检查，相关执行器、水泵及连接均无故障。结合结构图，简要说明系统中可能造成问题的原因（回答 2 项）。

---

## 答案

**正确答案：** （1）C；（2）A；（3）`/upload`；（4）B、C；（5）智能终端2故障、IoT模块2故障，或智能终端2与 IoT 模块2之间的连接故障等。

---

## 解析

选择数据库属于概要设计；B/S 架构的主要优势是无需专门客户端、维护升级方便，但服务器端承担更多任务，对服务器性能要求通常更高。Flask 路由对应 URL 的路径 `/upload`，查询字符串不写入路由。温度范围含端点，B、C 均能正确判断。控制链路中水泵执行器无故障而未启动，应继续检查智能终端2、IoT模块2及其通信连接。
