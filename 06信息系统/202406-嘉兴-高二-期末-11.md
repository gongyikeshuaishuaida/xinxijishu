# 题目 11

11.某图书馆管理系统包括图书、用户和借阅管理模块。借书卡植入电子标签，图书贴有条形码。

（1）读取借书卡信息用到了 ______①______（A.图像识别技术 / B.射频识别技术 / C.文字识别技术）。

（2）服务器端采用 Flask Web 框架：

~~~python
app = Flask(__name__)
@app.route("/input")
def add():
    suid=request.args.get("uid")
    sbid=request.args.get("bid")

~~~

用 URL http://192.168.1.2:88/add?uid=9001&bid=247102 提交时出现 Not Found：

![[attachments/202406嘉兴_11_URL运行截图.jpg]]

URL 中错误的位置为 ______②______（①、②、③），应修改为 ______③______。

（3）关于该系统的说法，正确的是 ______④______：

- A.借书卡中植入的是有源电子标签
- B.该系统中 Web 服务器采用 POST 方式接收终端上传的数据
- C.借书终端与服务器之间的数据只能由借书终端传输到服务器
- D.断网后将无法进行图书借阅，说明该系统对外部环境有依赖性

（4）判断图书是否需要增订：上月库存低于总量 20% 的天数超过 15 天即增订。方框代码选项如下：

![[attachments/202406嘉兴_11_增订代码选项.jpg]]

---

## 答案

**正确答案：** ①B；②②；③input；④D；（4）BC

---

## 解析

电子标签通过无线射频识别借书卡。路由装饰器注册的是 /input，而 URL 使用了 /add，所以错误在第②处，应改为 input。系统示例使用 URL 查询参数，题目没有要求 POST；数据可以双向传输，断网会影响借阅，体现对外部环境有依赖性。增订判断需要连续累计低库存天数，选项 B 能在累计超过 15 天时提前结束，选项 C 能在循环结束后判断，均正确。
