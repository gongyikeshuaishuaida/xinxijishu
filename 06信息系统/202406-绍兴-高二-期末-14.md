# 题目 14

14.基于 B/S 架构搭建自习教室噪声检测系统。

![[attachments/202406绍兴_14_噪声系统图.jpg]]
![[attachments/202406-绍兴-高二-期末-14_横排2_3.png]]

（1）图中 ①② 设备为 ______①______（A.执行器、传感器 / B.传感器、执行器）。

（2）以下不是 B/S 架构必要组成部分的是 ______②______（A.浏览器 / B.服务器 / C.客户端应用程序 / D.数据库）。

（3）请求 URL 为 http://192.168.1.2:5000/input?uid=10101&bid=2023，路由设置为：

~~~python
@app.route("______③______")
~~~

（4）页面能打开但数据不再更新，可能原因是 ______④______（多选）：

- A. 浏览器与 Web 服务器联网异常
- B. 传感器损坏
- C. Web 服务器死机
- D. 智能终端损坏

（5）日期数据转为日字符串并筛选分贝超过阈值：

~~~python
for i in range(len(dft)):
    t=str(dft["日期"][i])
    dft.at[i,"日期"]=______⑤______

dft=dft[______⑥______]
dft=dft.groupby("日期").count()
plt.bar(dft.index,dft.分贝值)
~~~


---

## 答案

**正确答案：** ①A；②C；③/input；④BD；⑤t[7:9]（或 t[7:]）；⑥df.分贝值>L（或 df["分贝值"]>L）

---

## 解析

系统结构为传感器采集、智能终端上传、服务器处理和浏览器展示，故①选 A；B/S 必须有浏览器、服务器和数据库，客户端应用程序不是必要组成部分，②选 C。Flask 路由与 URL 的路径是 /input；页面可开但数据停止更新，浏览器链路、传感器、服务器或智能终端任一环节都可能异常，按参考答案选 BD；日期取日部分 t[7:9]，筛选条件为分贝值大于 L。
