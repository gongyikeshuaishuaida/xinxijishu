# 题目 14

小华要搭建座椅加热系统，该系统结构示意图如下。系统智能终端将传感器采集到的温度数据传输至服务器并存储到数据库中；智能终端接收服务器返回指令并控制加热器；用户可通过手机查询实时和历史数据，进行开启与关闭加热器、设置温度等操作。其中，手机端网络应用软件为C/S架构。温度传感器和执行器接入智能终端，智能终端通过IoT模块连接到服务器，手机通过移动网络远程登录系统。请回答下列问题。

![[attachments/202404绍兴高三_14_座椅系统图.jpg]]

（1）有关该系统搭建的前期准备工作的说法，正确的是 ______①______（单选，填字母）。

- A. 需求分析阶段，应当考虑系统中技术与业务应用的可扩展性
- B. 概要设计阶段，系统物理配置包括选择何种数据库管理系统
- C. 详细设计阶段，需要确定手机端网络应用软件为B/S架构还是C/S架构

（2）利用手机中的应用软件远程开启加热器操作时，数据的传输过程为 ______②______（单选，填字母）。

- A. 由智能终端直接到服务器端
- B. 由手机端直接到智能终端
- C. 由手机端到服务器端，再由服务器端到智能终端

（3）根据题意，下列功能需要在智能终端程序中实现的是 ______③______（多选，填字母）。

- A. 采集温度传感器上的数据
- B. 处理浏览器访问请求
- C. 接收服务器指令
- D. 给手机用户发送警报
- E. 打开或关闭加热器

（4）请通过增加传感器和执行器对该系统功能进行一项扩展，写出增加的传感器和执行器名称及实现的功能：______④______。

（5）温度数据和曲线如下：

![[attachments/202404-绍兴-高三-二模-14_横排2_3.png]]

小华将系统中当天1小时以内的温度数据导出，部分数据如图所示（其中存在温度值为0的噪声数据）。为评估系统的座椅加热性能，小华更新了服务器端程序，增加功能为绘制某一时段内温度变化过程的曲线：选定`t`时刻，首先剔除噪声数据，再提取`t`时刻及之前时间相距最近的至多30条有效温度数据，最后绘制曲线。更新的部分程序如下。

```python

df = pd.read_csv('data.csv')
```

其中第⑥空应填入下列哪组代码？______⑥______（单选，填字母）。

- A. `dft = df[df['温度'] != 0]`；`dft = dft[dft['时间'] <= t].head(30)`
- B. `dft = dft[dft['温度'] != 0]`；`dft = dft[dft['时间'] <= t].head(30)`
- C. `dft = dft[dft['温度'] != 0]`；`dft = dft[dft['时间'] <= t].tail(30)`
- D. `dft = df[df['温度'] != 0]`；`dft = dft[dft['时间'] <= t].tail(30)`

某时段内温度变化曲线如图所示，从温度变化速率来看，此时段中的前10秒比后10秒变化更 ______⑦______（选填：快/慢）。

---

## 答案

**正确答案：** ① A；② C；③ ACE；④ 示例：增加压力传感器和LED灯，实现有人就座自动加热并点亮指示灯、离座自动关闭；⑤ `时间`；⑥ C；⑦ 快

---

## 解析

需求分析要考虑可扩展性；C/S远程控制需经过服务器转发。智能终端负责采集、接收服务器指令和控制执行器。数据处理先按时间升序，再删除温度0并用`tail(30)`取距离t最近的有效数据；曲线前10秒斜率较大，变化更快。
