# 题目 14

小丁同学设计并搭建了一个光线监测系统，传感器采集光线值，由智能终端经 IoT 模块发送到 Web 服务器；当光线值低于阈值时蜂鸣器播放音频，小丁和路灯管理人员可以通过浏览器查看历史数据。

第14题图 a 的系统结构如下：

![[attachments/202403宁波十校_14_系统结构.jpg]]

（1）图中①和②处的设备依次为 ______①______（单选，填字母：A.执行器、传感器；B.传感器、执行器）。

（2）关于该系统的说法正确的是 ______②______（多选，填字母）：A.浏览器可直接访问数据库来获取历史数据；B.该系统软件架构的优势之一是方便升级和维护；C.在硬件搭建时需要考虑智能终端与IoT模块之间的接口匹配问题；D.根据数据的存储要求确定数据库的结构，该过程属于前期准备中的概要设计。

（3）小丁基于Flask Web框架编写服务器端程序。若要通过浏览器获取视图函数`hello()`返回的页面，应访问的URL是`http://______③______`。

（4）系统每隔5分钟采集一次数据，测试时光线值一直高于阈值。请设计两项使小丁能立刻观察光线值低于阈值时蜂鸣器是否播放音频的可行方案：______④______。

（5）2024-01-01 到 2024-01-07 每天 17:00—18:00 的数据保存在 `light.csv` 中，部分数据如下：

![[attachments/202403宁波十校_14_光线数据.jpg]]

统计每天该时间段内光线值小于 100 的次数，并绘制线形图。请在划线处填入代码。

```python
df = pd.read_csv("light.csv")
day = []
for data in df["上传时间"]:
    day.append(data[8:10])
df.insert(0, "日期", day)
df = ______⑤______
df1 = df.groupby("日期").count()
plt.plot(______⑥______)
```

## 答案

**正确答案：** ① A；② BC；③ `192.168.43.17:8080/show`；④ 将光线传感器置于黑暗环境中、将程序阈值调大到足够大；⑤ `df[df["检测值"] < 100]`；⑥ `df1.index, df1.检测值`

## 解析

①号设备位于智能终端上方，连接蜂鸣器，属于执行器；②号设备采集光线，属于传感器。浏览器应通过 Web 服务器访问数据库，B/S 架构便于维护，硬件接口需要匹配；数据库结构设计属于更具体的设计阶段。URL 由协议、主机地址、端口和路由组成。测试时可把传感器置于黑暗环境或临时提高阈值，立即触发低光判断。先筛选检测值小于 100 的记录，再按日期统计，折线图横轴为日期索引、纵轴为计数。
