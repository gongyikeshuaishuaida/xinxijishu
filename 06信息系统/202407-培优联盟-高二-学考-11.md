# 题目 11

小明为多猫家庭设计智能猫砂盆：小猫进入时传感器识别身份并启动通风，离开五分钟后关闭；系统记录进入时间、时长和体重并上传服务器，管理员可通过浏览器查看数据和设备状态。系统架构如下：

![[attachments/202407培优联盟_11_猫砂盆系统结构图.jpg]]

（1）以下对传感器的描述不正确的是（单选）：
- A. 传感器是智能猫砂盆的输出设备
- B. 通过红外传感器可以检测小猫是否进入猫砂盆
- C. 可在项圈中内置 RFID 标签，用于识别不同小猫的身份信息

（2）服务器运行在 192.108.10.2:8000，视图函数路由为 /view。若要通过浏览器获取 get() 返回页面，应访问 URL：http://________。

（3）利用 Pandas 分析 cat.xlsx，部分数据如下：

![[attachments/202407培优联盟_11_猫砂数据表.jpg]]

请补全代码：

```python
import pandas as pd
df = pd.read_excel("cat.xlsx")
df1 = df.drop(["入舱时间", "当前体重"], axis=1)
df2 = df1.groupby(________①________, as_index=False)
print(df2.mean())
```

①划线处填入合适代码；②与加框处功能一致的代码为（单选）：
- A. df1.mean()
- B. df2[“入舱时间”].mean()
- C. df2[“入舱时长”].mean()

（4）浏览器可以正常访问服务器，但页面仍显示前一天数据，已知猫砂盆传感器和执行器正常运行。问题可能是什么？

---

## 答案

**正确答案：** （1）A；（2）192.108.10.2:8000/view；（3）① “名字”；② C；（4）猫砂盆网络连接断开、服务器未将新数据正确写入数据库，或浏览器缓存了旧页面数据（写出一项即可）。

---

## 解析

传感器是输入设备，红外传感器可检测小猫进入，RFID 标签可识别身份。Flask 路由为 /view，访问地址由主机、端口和路由组成。删除入舱时间、当前体重后按名字分组，求平均时长应选择入舱时长列。服务器数据没有更新可能是网络、数据库写入或浏览器缓存问题。
