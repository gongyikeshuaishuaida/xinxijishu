# 题目 11

11.小强为某信息查询系统制作用户登录模块。访问 Web 服务器主页打开用户登录界面，用户输入账号和密码并提交；若用户数据库中存在该账号且密码匹配，则进入数据子页面，否则返回出错信息。系统结构和用户数据表如下。

![[attachments/202406-9+1-高二-学考-11_横排1_2.png]]

![[attachments/2024069+1_11_登录界面.jpg]]

服务器端程序采用 Flask Web 框架编写，部分代码如下：

```python
DATABASE = "data/user.db"
app = Flask(__name__)

@app.route("/", methods=["GET", "POST"])
def index():
    form = Newform()
    name, ps = "", ""
    if form.validate_on_submit():
        name = form.username.data
        ps = form.password.data
        db = sqlite3.connect(DATABASE)
        # 从数据表中查询账号为 name 的记录，存入 data，代码略
        # 关闭游标和数据库，代码略
        if ______⑤______:
            return redirect("/shuju")
        else:
            return "输入账号或密码有误！"
    else:
        return render_template("denglu.html", form=form)
```

（1）分析程序，回答下列问题：

①该信息系统采用的架构模式是 `______①______`（单选，填字：B/S 或 C/S）。

②该信息系统存储用户数据的数据库名为 `______②______`。

③合法用户跳转进入数据子页面的 URL 是：`______③______`。

④用户登录模块对于该信息系统安全的作用是 `______④______`（单选，填字母：A．身份认证 / B．访问控制 / C．数据加密）。

（2）加框处代码有错误，请改正 `______⑤______`。

---

## 答案

**正确答案：** （1）① B/S；② user.db；③ http://192.168.16.98:8080/shuju；④ A。
（2）`data!=[] and data[0][1]==ps`（或 `data and ps in data[0]`）。

---

## 解析

浏览器访问 Flask 服务器主页，属于 B/S 架构；`DATABASE` 的文件名是 `user.db`，路由 `/shuju` 与主页地址组合成完整 URL。登录模块先核验用户身份，属于身份认证。查询结果为空时不能直接访问 `data[0][1]`，所以还要先判断 `data` 非空，再比较密码。
