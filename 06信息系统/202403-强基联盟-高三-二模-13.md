# 题目 13

小陆要搭建电梯吸烟报警系统。智能终端从服务器获取烟雾浓度阈值，根据阈值和传感器采集的空气烟雾浓度值控制蜂鸣器，并将传感器 ID、烟雾浓度值等数据传输至 Web 服务器，存储到数据库中。网络应用软件的实现架构是 ______①______ 架构；硬件搭建方式是烟雾传感器和蜂鸣器接入智能终端，智能终端通过 ______②______ 模块连接到服务器。

（1）要完成系统搭建，下列在服务器中无须安装的是（单选，填字母）：

- A. 服务器操作系统
- B. 传感器驱动程序
- C. 网卡驱动程序

（2）下列关于系统支撑技术的说法，正确的是（单选，填字母）：

- A. 服务器可以通过视图函数的返回值向智能终端发送指令
- B. 作为服务器的计算机无法使用浏览器访问该系统
- C. 数据可以从数据库传输到浏览器，但不能从浏览器传输到数据库

（3）系统设有 4 个烟雾传感器，编号存储在列表 `names` 中。现从数据库中提取某时段一小时的历史数据存储在字典 `dic` 中，求 4 个传感器采集数据中的最大值和次大值。部分程序如下，请在划线处填入合适的代码。

```python
m1 = 0
m2 = 0                         # 最大值 m1，次大值 m2
for item in names:
    ______①______
    for i in range(0, len(tmp), 2):
        if tmp[i] < tmp[i+1]:
            tmp[i], tmp[i+1] = tmp[i+1], tmp[i]
        if tmp[i+1] > m1:
            m1 = tmp[i]
            m2 = tmp[i+1]
        elif ______②______:
            m2 = m1
            m1 = tmp[i]
        elif tmp[i] > m2:
            m2 = tmp[i]
```

（4）系统正常运行一段时间后，浏览器能正确显示数据，但电梯内无人吸烟、浓度未超过阈值时蜂鸣器却一直报警。请写出两项可能原因。

## 答案

**正确答案：** 网络应用架构为 B/S，连接模块为 IoT；（1）B；（2）A；（3）① `tmp=dic[item]`；② `tmp[i]>m1`；（4）蜂鸣器故障、智能终端与蜂鸣器连接异常（答其他合理原因亦可）。

## 解析

服务器端采用 B/S 架构，智能终端通过 IoT 模块联网，服务器无需安装传感器驱动。视图函数可以返回页面或指令，服务器本机也可以用浏览器访问，数据可双向传输。代码先把每一对样本按降序放置，再更新最大值和次大值；当当前值超过最大值时，原最大值下移为次大值。误报警可由蜂鸣器本体故障或终端与蜂鸣器的连线、接口异常造成。
