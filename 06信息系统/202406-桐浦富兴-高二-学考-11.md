# 题目 11

11.某校使用“学生信息系统”管理学生：校门口自助机读取校园卡并通过网络将进出校园数据传输到服务器保存，教师录入学生信息，家长通过系统 APP 查看报告。请回答下列问题。

（1）该信息系统的网络架构是 ______①______（填字母：A.B/S 架构 / B.C/S 架构）。

（2）自助机读取校园卡信息采用的技术是 ______②______（填字母：A.图像识别 / B.射频识别 / C.蓝牙）。

（3）学生刷卡后在自助机上显示学生信息，主要体现信息系统的 ______③______（填字母：A.查询功能 / B.存储功能 / C.数据采集功能）。

（4）从数据库导出数据并统计“08:00”之前各班进校人数，完善代码：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_excel("xs.xlsx")
df = ______④______
dfc = df.groupby('班级').count()
plt.title('8 点前各班进校人数')
plt.bar(dfc.index, dfc.进校时间)
plt.show()
```

图 1 是原始进校数据表，图 2 是统计图。

![[attachments/202406-桐浦富兴-高二-学考-11_横排1_2.png]]

---

## 答案

**正确答案：** ①A；②B；③A；④`df[df.进校时间<"08:00"]`

---

## 解析

家长通过浏览器或 APP 访问服务器，属于 B/S 架构；校园卡采用射频识别。刷卡后按卡号查询学生信息，体现查询功能。筛选条件应保留进校时间早于 08:00 的记录，再按班级计数。
