# 题目 13

小李为恒温恒湿仓库搭建环境监测系统，实时监测仓库的温湿度。系统通过智能终端将传感器数据传输到 Web 服务器并存储在数据库中；温湿度超出阈值时，蜂鸣器报警，相应执行器（如空调、加湿器）工作。

![[attachments/202405Z20_13_环境监测系统图.jpg]]

（1）服务器与数据库之间的数据传输方向是 ______①______（单选：A.只能由服务器传输至数据库 / B.只能由数据库传输至服务器 / C.服务器与数据库之间相互传输）。

（2）补全 Flask 服务器端程序：

```python
app = Flask(__name__)
@app.route('/input')
def add_data():
    id_1 = int(request.args.get('id'))
    temp = float(request.args.get('w'))
    # 获取温度阈值上下限，分别保存在 maxv 和 minv 中，代码略
    if ______②______:
        # 启动空调，代码略
        pass
    else:
        # 关闭空调，代码略
        pass

if __name__ == '__main__':
    app.run(host='192.168.1.76', port=8080)
```

（3）若温度传感器编号 `id=1`、温度值 `w=25`，提交数据到 Web 服务器的 URL 是 `http://______③______?id=1&w=25`。

（4）下列关于智能终端功能的描述，不正确的是 ______④______（单选：A.利用温湿度传感器采集环境数据 / B.存储程序和数据库文件等相关数据 / C.控制空调、加湿器等执行器的开关状态）。

（5）温度超出阈值时蜂鸣器1报警、空调工作；同一时间湿度如何变化，蜂鸣器2始终不报警、加湿器也未工作。假设代码正确、阈值合理、连接正常，从硬件角度写出两个可能原因： ______⑤______、 ______⑥______。

---

## 答案

**正确答案：** ① C；② `temp>maxv or temp<minv`；③ `192.168.1.76:8080/input`；④ B；⑤ 湿度传感器故障；⑥ 蜂鸣器2和加湿器同时故障

---

## 解析

服务器和数据库需要双向读写，所以选 C。温度超出上下限时应使用或条件 `temp>maxv or temp<minv` 启动空调；请求 URL 由主机、端口和路由 `/input` 组成。智能终端负责采集和控制，但数据库文件应由服务器侧管理，B 不正确。温度支路正常而湿度支路完全无响应，可能是湿度传感器故障，也可能是蜂鸣器2和加湿器同时故障。
