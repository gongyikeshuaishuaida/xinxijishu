# 题目 13

某市在部分公交站台搭建了客流与环境监测系统。智能终端连接两个红外客流计数传感器（分别统计站台的到达人数和上车人数）、噪声传感器和 PM2.5 传感器，每 10 分钟通过 5G 网络发送至 Web 服务器，并存储到数据库中。系统采用 B/S 架构，服务器端程序基于 Flask Web 框架开发。当站台候车人数过多或 PM2.5 浓度超标时，站台电子显示屏发布提示信息。请回答下列问题：

(1)增加"站台温度监测,温度过高时自动开启喷雾降温设备"的功能,并且该功能实现不依赖5G网络,那么开启喷雾降温设备的程序在______。(单选:A.智能终端/B.服务器端)

(2)下列关于该系统数据处理的说法正确的是 ______ (多选,填字母)(注:全部选对的得 2 分,选对但不全的得 1 分,不选或有选错的得 0 分)

- A. 各站台上传数据需包含本站台的编码信息

- B. 该系统数据处理均在服务器端完成

- C. 智能终端与传感器的数据流通是双向的

- D. 该系统历史数据也有价值,需定期备份.

(3) 查看客流与环境数据的服务器端部分程序如下，该页面的 URL 是 `http://10.60.12.5:8000/______`。

```python
# 导入Flask框架模块及其他相关模块，代码略
app = Flask(__name__)
@app.route('/station')
def show():
    # 从数据库读取客流与环境数据，并返回页面，代码略
# 服务器其他功能，代码略
if __name__ == '__main__':
    app.run(host='10.60.12.5', port=8000)
```

(4) 下列关于系统可能出现的故障及原因，说法正确的是______（多选，填字母）（注：全部选对的得2分，选对但不全的得1分，不选或有选错的得0分）

- A. 某站台其他数据都正常，只有噪声数据无法获取。原因：噪声传感器故障

- B. 候车人数过多正常提示，PM2.5浓度超过阈值，站台电子屏没有提示消息。原因：智能终端故障

- C. 某站台数据候车人数和PM2.5浓度数据同步出现时有时无的现象。原因：5G模块不稳定

- D. 可以正常查看某站台历史数据，但无法查看实时数据。原因：服务器端程序停止运行

(5) 系统运行一段时间后，管理员发现某站台连续多天的“上车人数”都大于“到达人数”。请指出一种可能由传感器引起的故障，并设计一种能由服务器自动发现此类异常的校验方法（可利用系统已有数据）。

---

## 答案

**正确答案：** (1) A；(2) A、D；(3) `station`；(4) A、C；(5) 示例：到达计数传感器漏计，导致到达人数偏小；服务器定期比较同站台同一统计时段的上车人数和到达人数，若连续多期上车人数大于到达人数，则报警。

---

## 解析

不依赖5G的控制须在终端完成。上传需携带站台标识，历史数据应备份。路由为/station。单传感器故障可只影响一种数据，通信模块不稳定可同时影响多种数据。第(5)问需同时写出可解释现象的故障与可自动执行的判断规则。累计历史候车人数可进一步用于排除跨时段等候造成的正常差异。
