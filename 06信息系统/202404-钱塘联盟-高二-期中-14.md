# 题目 14

某厨房环境监测系统通过温度传感器和烟雾传感器实时监测厨房温度和颗粒物浓度，并显示在厨房安装的电子显示屏上；用户也可通过浏览器查看实时监测结果和历史数据；当出现异常时系统控制蜂鸣器发出警报，预防火灾发生。系统结构如下图所示。

![[attachments/202404钱塘_14_厨房监测系统图.jpg]]

（1）图中①②处缺少的设备为 ______①______（单选，填字母：A.①服务器、②智能终端；B.①智能终端、②服务器）。

（2）该系统网络应用软件的实现架构是 ______②______（单选，填字母：A.B/S架构；B.C/S架构）。

（3）若温度传感器编号`id`为1、温度值`t`为25，提交数据到Web服务器的URL为`http://192.168.1.0:8080/trans?id=1&t=25`，则服务器端应用实例`app`中与该URL关联的路由设置语句是`@app.route('______③______')`。

（4）智能终端每隔15秒从传感器获取1次温度值，当连续4次检测到温度值大于60℃时，判断为温度过高，打开蜂鸣器报警。请在划线处填写代码，并指出温度传感器连接在智能终端上的接口。

```python
# 导入相关库，代码略
k = 0
while True:
    t = pin2.read_analog()
    if t > 60:
        k += 1
        if k == 4:
            for freq in range(880, 1760, 32):
                music.pitch(freq, 8)
            for freq in range(1760, 880, -32):
                music.pitch(freq, 8)
    else:
        ______④______
    sleep(1000 * 15)
```

其中温度传感器连接在智能终端上的接口为 ______⑤______。

（5）小华外出时通过移动终端查看厨房环境监测数据，页面正常运行一段时间后不再变化，刷新后仍不变，但电子显示屏能实时显示正确信息。造成此结果的原因可能是 ______⑥______（多选，填字母）。

- A. 智能终端损坏
- B. IoT模块损坏
- C. 传感器与智能终端连接异常
- D. 移动终端与服务器通信异常

---

## 答案

**正确答案：** ① B；② A；③ `/trans`；④ `k = 0`；⑤ `pin2`；⑥ BD

---

## 解析

①是连续计数被打断时的复位语句，②由程序中的 `pin2.read_analog()` 可知；URL路径为 `/trans`，系统通过智能终端—IoT—服务器—浏览器组成B/S架构。电子显示屏正常而网页不更新，说明本地采集和显示仍可工作，IoT上行链路或移动终端与服务器通信可能异常。原卷卷末参考答案页属于另一套试题，未采用。
