# 题目 11

11.班级植物区自动浇水系统根据土壤湿度定时浇水，传感器经智能终端和 IoT 模块向 Web 服务器发送数据，湿度异常时执行器浇水。

![[attachments/202405县域高二_11_浇水系统结构图.jpg]]
![[attachments/202405县域高二_11_条件代码选项.jpg]]

（1）选择 B/S 架构属于（填字母）：A.需求分析 / B.可行性分析 / C.开发模式选择。

（2）可作为调节土壤湿度设备的是（填字母）：A.IoT 模块 / B.水泵 / C.湿度计。

（3）URL `http://192.168.1.10:8080/input?id=1&val=20` 对应的 Flask 路由为 `@app.route('______')`。

（4）当 `hum<20` 且 `tem<=30` 时浇水量 `w=200`，当 `hum<20` 且 `tem>30` 时 `w=230`，其他情况 `w=0`。从图中程序选出符合要求的代码。

（5）写出两种可用于进门身份识别的技术。

---

## 答案

**正确答案：** （1）C；（2）B；（3）`/input`；（4）CD；（5）指纹识别、语音识别、虹膜识别、人脸识别等任答两项

---

## 解析

选择 B/S 是开发模式选择；水泵是调节湿度的执行设备，湿度计只负责检测。Flask 路由对应 URL 路径 `/input`。条件程序必须在低湿时区分温度不超过30和高于30两种情况，参考答案为 C、D。身份识别可采用指纹、语音、虹膜或人脸等生物特征技术。
