# 题目 2

在建设智慧校园时，不少学校引入电子班牌系统。该系统用于签到、请假、家校沟通、信息发布等，学生可以通过电子班牌与家长通话，教师可以发布班级公告，所有数据都存储在云服务器上。电子班牌的主要参数和功能如下表所示。

![[attachments/202502G12名校协作体_02_电子班牌参数表.jpg]]

下列关于该信息系统组成与功能的描述，不正确的是

- A. 安卓属于该信息系统的系统软件
- B. 该信息系统的用户包括教师和学生等
- C. 多点触摸显示器不具备数据输入功能
- D. 该系统具有数据处理、存储及传输等功能

## 答案

**参考答案：** C

## 解析

多点触摸显示器既可以显示信息，也可以通过触摸完成数据输入，因此 C 项不正确。安卓属于系统软件，教师和学生是系统用户，电子班牌系统也具有数据处理、存储和传输功能。
