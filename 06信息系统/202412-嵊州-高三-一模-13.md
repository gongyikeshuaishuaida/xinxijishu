# 题目 13

某研究小组拟采集博物馆的温湿度、光线值、空气质量等数据，以实现对展品环境监测。该小组在实验室搭建一个模拟系统，该系统的智能终端获取温湿度传感器数据，并传输至 Web 服务器。智能终端根据从服务器获取的阈值判断出异常情况后，控制执行器进行干预。请回答下列问题。

（1）该系统配置了多个智能终端，下列说法正确的是 ______①______（单选，填字母）。

- A. 传感器采集的数据只能存储于服务器的数据库
- B. 传感器采集的数据可存储于连接的智能终端

（2）下列功能需要在服务器程序中实现的是 ______②______（单选，填字母）。

- A. 采集和提交传感器数据
- B. 根据阈值控制执行器
- C. 存储传感器数据至数据库

（3）下列关于该系统设计的说法，正确的有 ______③______（多选，填字母）。

- A. 智能终端可以通过无线网络连接服务器
- B. 支撑该系统运行的所有软件，都必须在搭建过程中开发完成
- C. 温度、湿度等数据的采集时间间隔不能相同
- D. 智能终端与服务器的数据传输是双向的

（4）智能终端上的程序每分钟获取1次湿度值并将湿度值和除湿机状态数据传输到服务器：除湿机处于关闭状态时，若最近5次的湿度值中有3次高于阈值 h，则打开除湿机；除湿过程中，若连续5次湿度值均不高于 h，则关闭除湿器。部分 Python 程序如下，请在程序中划线处填入合适的代码。

~~~python
# 导入相关库，并从服务器获取阈值，保存在 h 中，代码略
lasth=[0,0,0,0,0]  # 保存最近5次湿度值，初始状态为均不高于 h
s=0
while True:
    # 从传感器获取湿度值，保存在 newh 中，代码略
    ______④______
    if newh<=h:
        lasth[-1]=0
    else:
        lasth[-1]=1
    if s==0:
        if ______⑤______:
            s=1
            # 打开除湿机，代码略
    else:
        if sum(lasth)==0:
            s=0
            # 关闭除湿机，代码略
    # 将 newh，s 等数据传输到服务器，代码略
    sleep(1000*60)  # 延时1分钟
~~~

（5）为进一步完善该模拟系统功能，请写出一种扩展方案并详细阐述实现的功能及所需增设的传感器与执行器的名称。

## 答案

**参考答案：**

- （1）① B
- （2）② C
- （3）③ AD
- （4）④ lasth[:4]=lasth[1:]（或 lasth=lasth[1:]+lasth[0:1] 等价写法）；⑤ sum(lasth)==3（或 2sum(lasth)>2 等价判断）
- （5）示例：光线达到阈值时关闭窗帘，增加光线（光敏）传感器和舵机（电机）。

## 解析

传感器数据可以暂存在连接的智能终端，服务器程序负责把传感器数据存入数据库。智能终端可通过无线网络与服务器通信，数据上传和服务器下发阈值或控制信息构成双向传输，所以（3）选 AD。每次得到新湿度值后，先删除最旧值并把新值放到列表末尾，故 ④ 可写 lasth[:4]=lasth[1:]；关闭状态下 1 表示高于阈值，最近5次中有3次高于阈值时 sum(lasth)==3，故 ⑤ 可写该条件。扩展方案需要同时说明功能、传感器和执行器，例如用光敏传感器检测光线，用舵机或电机控制窗帘。
