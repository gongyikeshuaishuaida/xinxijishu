# 题目 14

某充电站有 6 个充电桩（编号 0～5），设备每秒采集一次各充电桩档位，采集的数据存入列表 level。其中 0 代表待机状态，1～3 为充电档位，如第 14 题图所示。功能一：档位跳变，即同一充电桩前后两次档位差值大于 1，则进行提示；第一次开机采集不判断跳变。功能二：待机超时，即充电桩待机时长每超过 600 秒，进行一次提示。

![[attachments/202608Z20_14_状态档位表.jpg]]

（1）上一次记录为 `[1, 0, 2, 1, 0, 3]`，本次记录为 `[1, 3, 2, 2, 0, 1]`，出现档位跳变提示的充电桩数量是 ______。

（2）实现上述功能的部分 Python 程序如下，请在程序划线处填入合适的代码。

```python
limit = 600
last = [-1] * 6  # 关机状态
wait = [0] * 6
first = True
while True:
    # 读取本次充电桩档位存入 level，代码略
    for i in range(len(level)):
        if __________:  #①
            # 输出第 i 个充电桩档位跳变提示，代码略
            wait[i] = 0
        if level[i] == 0:
            wait[i] += 1
            if __________:  #②
                # 输出第 i 个充电桩待机超时提示，代码略
                wait[i] = 0
        else:
            wait[i] = 0
        __________  #③
    first = False
    # 延时 1 秒，代码略
```

---

## 答案

**正确答案：** （1）2；（2）① `not first and abs(level[i]-last[i])>1`（或 `last[i]!=-1 and abs(level[i]-last[i])>1`）；② `wait[i]>limit`；③ `last[i]=level[i]`

---

## 解析

上一次与本次档位相比，逐项比较 `[1,0,2,1,0,3]` 与 `[1,3,2,2,0,1]` 可知第 1 号由 0→3、第 5 号由 3→1，差值均大于 1，共 2 个提示。第一次采集不判断跳变；待机时 `wait` 每秒加 1，超过 600 后提示并清零。每轮结束把本次 `level` 保存到 `last`。
