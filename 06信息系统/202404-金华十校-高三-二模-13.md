# 题目 13

小辰设计了一个“智能控灯系统”。该系统使用光线传感器和红外传感器来监测室内的光线亮度和人体活动。网络应用软件采用B/S架构，用户可通过浏览器查询室内光线亮度和人体活动的实时和历史数据。硬件按如下方式连接：光线传感器、红外传感器和LED灯接入智能终端，智能终端通过IoT模块连接到服务器。请回答下列问题。

（1）下列关于该信息系统中数据存储的说法，不正确的是 ______①______（单选，填字母）。

- A. 智能终端有程序存储和数据处理的能力
- B. 智能终端获取室内光线亮度的数据存储在光线传感器中
- C. 智能终端传递给服务器的数据一般存储在数据库中

（2）智能控灯系统的服务器端部分程序如下。若某次提交数据的URL为`http://192.168.1.101:5050/update?id=1&val=98`，则路由设置语句中的划线处应填入 ______②______。

```python
# 导入相关库文件，代码略
app = Flask(__name__)

@app.route("/")
def index():
    # 从数据库读取数据并显示，代码略
    pass

@app.route("______②______")
def add_data():
    # 将提交的传感器数据存储到数据库，代码略
    pass

if __name__ == "__main__":
    app.run(host="192.168.1.101", port=5050)
```

（3）该系统可以实现“人来灯亮、人走灯灭”的效果：当环境亮度低于阈值且检测到人活动时开灯；没有人活动或亮度值大于等于阈值时关灯。部分Python代码如下，请补全程序。

```python
# 导入相关库，并从服务器获取阈值，保存在h中，代码略
s = 0
while True:
    # 获取亮度值light和人体活动状态red，代码略
    if ______③______:
        s = 1
    else:
        s = 0
    # 打开或关闭LED灯，将s、light和red传输到服务器，代码略
    sleep(100)
```

（4）若系统运行一段时间后，光线传感器出现故障，可能出现的现象是 ______④______（填一个现象）。

---

## 答案

**正确答案：** ① B；② `/update`；③ `red == True and light < h`；④ 实际亮度低于阈值且有人活动时灯未自动打开等

---

## 解析

（1）传感器采集的数据应由智能终端或服务器存储，不会存储在传感器中，故不正确的是 B。

（2）URL 的路径部分是 `/update`，因此路由填 `/update`。

（3）只有光线低于阈值且检测到人活动时开灯，条件为 `red == True and light < h`（或 `red and light < h`）。

（4）光线传感器故障可能造成亮度判断异常，例如实际低于阈值且有人活动时灯未自动打开。
