# 题目 14

图书馆智能座位管理系统持续记录学生每日的选座位置（包括：“窗边”“走廊边”“中间”）。系统分析学生连续 n（n>2）天的选座偏好：当 n 天内某位置出现次数不少于 n-1 次，且与当前偏好不同时，系统自动更新偏好为该位置；若没有位置满足次数条件，则保持原偏好。

（1）设 n=4，某学生当前偏好为“中间”，接下来连续 7 天的选座记录为：“窗边、窗边、窗边、走廊边、窗边、中间、窗边”。系统从第 1 天开始，依次以每连续 4 天为单位进行分析，系统最终偏好将更新为 ______。

（2）实现上述功能的部分 Python 程序如下，请在划线处填入合适的代码。

```python
n = 4
current = "中间"
choices = ["窗边", "窗边", "窗边", "走廊边", "窗边", "中间", "窗边"]
for start in range(len(choices) - n + 1):
    w = __________  #①
    for loc in ["窗边", "走廊边", "中间"]:
        cnt = 0
        for i in range(n):
            if w[i] == loc:
                cnt += 1
        if __________:  #②
            if loc != current:
                __________  #③
            break
print("最终偏好：", current)
```

---

## 答案

**正确答案：** （1）窗边；（2）① `choices[start:start+n]`；② `cnt>=n-1`；③ `current=loc`

---

## 解析

按每连续 4 天统计，前 4 天窗边出现 3 次，偏好由中间更新为窗边；后续窗口中没有其他位置达到条件，因此最终偏好为窗边。程序中 w 取当前 n 天切片，cnt 至少为 n-1 时满足次数条件，再把 current 更新为 loc。
