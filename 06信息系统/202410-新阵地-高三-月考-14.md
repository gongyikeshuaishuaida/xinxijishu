# 题目 14

某全屋智能系统提供全面的智能家居解决方案。其照明子系统可根据用户情况进行灯光调节。小明在实验室搭建智能照明模拟系统：智能终端获取传感器数据并通过无线通信传输到 Web 服务器；服务器根据传感器数据判断场景并向智能终端发送指令信号，用户可访问服务器查看光线强度变化。

（1）小明根据系统功能需求，选择采用 B/S 架构，相较于 C/S 架构，其主要优势体现在 ______①______。（单选：A. 开发难度较低　B. 升级、维护方便　C. 系统的通信开销较小）

（2）下列关于搭建该系统前期准备的说法，正确的有 ______②______。（多选）

- A. 需求分析时，需要确定具体的传感设备型号
- B. 数据库管理系统选择应在开发模式选择之前
- C. 云服务器可以实现异地检测、实施互联
- D. 该系统仅需确保运行安全，无需关注数据保密

（3）若传感器编号 ID 为1，光线值 LX 为550，服务器端应用实例 `app` 中与该功能关联的路由设置语句是 `@app.route('/toserv')`，则提交数据到 Web 服务器的 URL 为 `http://192.168.1.2:5000/______③______`。

（4）若 IoT 模块损坏，系统运行时可能会出现的问题有 ______④______。（多选）

- A. 光线传感器无法获取光线强度数据
- B. 用户访问服务器查看时光线强度无任何变化
- C. 智能终端无法向执行器发送指令
- D. 服务器无法发送指令到智能终端

## 答案

**正确答案：** （1）B；（2）AC；（3）`toserv?ID=1&LX=550`；（4）D；（5）① `s+=j`；② `mean()`

---

## 解析

B/S 架构便于集中升级和维护。需求分析需确定设备需求，云服务器支持异地互联；系统还要保障数据保密。IoT 通信模块损坏时，服务器指令不能下发到终端。解析时间字符串时累加冒号前字符；按小时分组后用 `mean()` 求平均值。
