# 题目 13

13.某养老中心搭建智慧环境监测系统，服务器通过无线网络连接智能终端，终端连接传感器和执行器，在服务器端设置舒适阈值并进行报警。

![[attachments/202406丽水_13_环境监测系统图.jpg]]

（1）完成软件开发需要编写 ______①______（A.客户端程序 / B.服务器端程序）。

（2）关于系统数据管理，正确的是 ______②______：

- A.数据可以从服务器端传输至传感器
- B.智能终端有程序存储和数据处理的能力
- C.用户通过浏览器查看监测数据不必访问数据库

（3）Flask 程序中报警条件应填：

~~~python
@app.route("/")
def index():
    # 从数据库读取数据并返回页面

@app.route("/input")
def add_data():
    t=float(request.args.get("val"))
    # 写入数据库并读取阈值 minv、maxv
    if ______③______:
        return "1"
    else:
        return "0"
~~~

（4）若浏览器查询温度等数据，访问 URL 为 http:// ______④______。

（5）噪音数据显示缺失，从硬件角度写出两项可能原因：______⑤______。

---

## 答案

**正确答案：** ①B；②B；③t<minv or t>maxv；④192.168.1.1:8000；⑤声音传感器与智能终端连接异常、声音传感器损坏（或等价答案）

---

## 解析

系统主要在服务器端完成网页和数据管理；智能终端仍具有程序存储和数据处理能力。超出舒适阈值时报警，因此条件是 t<minv 或 t>maxv；浏览器根路径对应服务器地址和端口。噪音缺失可由传感器本体损坏或连接异常导致。
