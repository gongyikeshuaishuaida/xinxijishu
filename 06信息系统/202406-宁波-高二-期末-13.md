# 题目 13

13.某智能汽车配备简易胎压监测系统，传感器采集压力、温度，经智能终端和网络发送到 Web 服务器并存入数据库，服务器按阈值触发预警。

![[attachments/202406宁波_13_胎压监测系统图.jpg]]

（1）选择数据库管理系统，属于前期准备中的 ______①______ 阶段（A.需求分析 / B.可行性分析 / C.概要设计 / D.详细设计）。

（2）压力由 pin1 采集、温度由 pin2 采集，警报代码如下：

~~~python
if resp == "1":
    pin12.write_digital(1)
    sleep(5 * 1000)
    pin12.write_digital(0)
~~~

① 蜂鸣器接在 ______②______（A.pin1 / B.pin2 / C.pin12）。
② 发声持续 ______③______ 秒。

（3）Web 服务器端：

~~~python
@app.route(______④______, methods=['GET'])
def judge():
    data = float(request.args.get('bar'))
    temp = float(request.args.get('temp'))
    value1 = 200; value2 = 120
    if data < value1 or temp > value2:
        ______⑤______
    else:
        alarm = "0"
    return alarm
~~~

① 路由应填 A."/input" / B."/judge" / C."/errno"。
② 条件成立时填入触发警报的代码。

（4）若 id=1、胎压=235、胎温=130，上传 URL 为：

http://____________________________

---

## 答案

**正确答案：** ①C；②C；③5；④A；⑤alarm="1"；（4）192.168.1.100:8080/input?id=1&bar=235&temp=130

---

## 解析

选数据库管理系统属于概要设计；蜂鸣器由 pin12 控制，sleep(5×1000) 持续 5 秒；终端请求的 input 路径对应 Flask 的 /input 路由，异常条件成立时赋值 alarm="1"。服务器地址、端口、路径和查询参数拼接后得到题中 URL。
