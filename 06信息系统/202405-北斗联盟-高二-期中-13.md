# 题目 13

13.小张搭建智能楼道灯控制系统：楼道内光线不足且检测到声音时开灯，持续一定时间后关灯。系统结构示意图如下：

![[attachments/202405北斗联盟_13_楼道灯系统图.jpg]]

（1）请在图中虚线框内用箭头标出智能终端与传感器、楼道灯和 IoT 模块之间的数据传输关系。

（2）程序每隔0.5秒获取光线值 `Light`、声音值 `Sound`；当 `Light < L` 且 `Sound > S` 时开灯，亮灯超过 `h` 后关灯。请补全：

```python
flag = False; Lasttime = 0
while True:
    # 获取当前时间 Newtime、传感器值 Light 和 Sound 的代码略
    if not flag:
        if Light < L and Sound > S:
            flag = True
            ______①______  # 打开楼道 LED 灯
    elif Newtime - Lasttime > h:
        ______②______      # 关闭楼道 LED 灯
    # 数据存入数据库，代码略
```

（3）浏览器提交阈值和亮灯时间的 URL 为 `http://192.168.1.98:5000/upload?L=200&S=1000&h=15`，路由设置语句是 `@app.route("____")`。

（4）系统运行一段时间后，晚上经过楼道时灯未打开；实时监测数据显示光线值正常。结合系统图，说明可能原因（回答两项）。

---

## 答案

**正确答案：** （1）传感器→智能终端；智能终端→楼道灯；智能终端与 IoT 模块双向通信；（2）① `Lasttime=Newtime`；② `flag=False`；（3）`/upload`；（4）声音传感器故障、楼道灯故障、传感器与智能终端连接断开、智能终端与楼道灯连接断开等任两项。

---

## 解析

开灯时应记录开灯时刻，超过设定时长后复位状态并关灯；URL 路径只取查询参数前的 `/upload`。光线数据正常但未开灯，问题可能出在声音传感器、智能终端、楼道灯或它们之间的连接。
