# 题目 14

小王制作了一个“蔬菜大棚温控系统”：温度传感器每 10 分钟采集一次数据，实时发送到智能终端，经物联网模块上传至服务器数据库；服务器分析数据并控制风机、遮阳设备等，用户可通过浏览器查看温度和报警信息。

（1）服务器通过无线网络连接智能终端，连接在智能终端上的设备有 ______①______（多选，填序号：①服务器 ②传感器 ③客户端手机 ④执行器）。

（2）关于该系统，下列说法正确的是 ______②______（多选，填字母）。

A．测试并观察该系统运行是否有问题，属于静态测试

B．选择 SQLite3 作为该系统的数据库软件，属于概要设计

C．搭建系统前对该系统所需的费用和效率进行评估，属于需求分析

D．该系统采用了 B/S 架构

（3）网站框架示意图如下，若要查看当前的实时温度信息，需访问的URL是`http://______③______`。

![[attachments/202402新阵地_14_路由表.jpg]]

（4）系统正常运行一段时间后，发现服务器网页正常显示，但温度高于阈值时执行器没有启动。请从硬件角度写出造成问题的两项可能原因：______④______。

（5）将 6、7 两月每天温度数据导出到 `wd.xlsx`，分析 7 月每日平均温度并统计平均温度最高的 5 天。部分程序如下，请填空。

![[attachments/202402新阵地_14_温度数据表.jpg]]

```python
df = pd.read_excel("wd.xlsx")
dfw = ______⑤______  # 筛选出 7 月温度值
dfwg = dfw.groupby("日期", as_index=False).mean()
dfwgs = dfwg.sort_values("______⑥______", ascending=False).head(5)
plt.bar(dfwgs.日期, dfwgs.数值)
```

## 答案

**正确答案：** ① ②④；② BD；③ `192.68.1.100:8080/view`；④ 执行器故障、执行器与智能终端连接故障、智能终端故障、IoT模块故障等任答两项；⑤ `df[df.月份 == 7]`（或`df[df["月份"] == 7]`）；⑥ `温度`

## 解析

传感器负责采集、执行器负责控制，因此连接在智能终端上的设备为②④。观察运行属于动态测试，选择数据库软件属于概要设计，费用和效率评估属于需求分析，故正确选项为 B、D。实时温度页面的路由为 `/view`，服务器地址和端口由图给出。硬件故障可来自执行器、连接线、智能终端或 IoT 模块。筛选 7 月记录后按日期求均值，应按“温度”降序取前 5 条。
