# 题目 11

小明搭建家庭厨房安全系统，根据温度、烟雾浓度判断是否发生火情，出现火情时自动报警并启动灭火设备。传感器采集的数据由智能终端传送到服务器，服务器处理后将状态码传送给智能终端以控制灭火设备和蜂鸣器。请回答以下问题。

（1）下列不属于智能终端应实现的功能是 ______①______（单选，填字母）。

- A.读取传感器的数据
- B.将采集数据存入数据库
- C.将控制指令发送给执行器
- D.接收服务器返回的状态码

（2）若智能终端提交数据的 URL 为 `http://10.136.130.59:8080/get?temp=30&smoke=100`，则服务器端应用实例 `app` 中与该 URL 关联的路由语句是 `@app.route("______②______")`。

（3）服务器接收温度和烟雾浓度数据，若任一数据高于对应阈值就将 `state` 设为 1，否则设为 0。符合要求的程序段有 ______③______（多选，填字母）。

- A. `state=0; if temp>tempT: state=1; elif smoke>smokeT: state=1`
- B. `if temp>tempT: state=1; if smoke>smokeT: state=1; else: state=0`
- C. `if temp>tempT or smoke>smokeT: state=1; else: state=0`
- D. `state=0; if temp>tempT: if smoke>smokeT: state=1`

（4）请通过增加传感器和执行器对该系统功能进行一项扩展，写出增加的传感器和执行器及其实现的功能。

---

## 答案

**正确答案：** ①B；②`/get`；③A、C；④示例：可燃气体浓度传感器＋排气扇，检测燃气泄漏并自动通风

---

## 解析

智能终端负责采集、通信和执行控制指令，数据库写入由服务器完成；URL 的路径部分是 `/get`。任一阈值超限应使用逻辑或，A 的初值配合 `if/elif`、C 的 `or` 均正确。扩展应说明传感器、执行器及联动功能，例如检测燃气浓度超限后启动排气扇。
