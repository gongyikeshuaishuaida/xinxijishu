# 题目 05

读者普遍反映通过“数字馆员”查阅信息时响应速度较慢，以下解决问题的方法不可行的是（   ）

- A. 提高“数字馆员”的屏幕分辨率
- B. 升级服务器端的软件
- C. 提升图书馆的网速
- D. 为服务器更换性能更好的 CPU

## 答案

**正确答案：** A

## 解析

屏幕分辨率主要影响显示效果，不能直接改善系统的数据处理或网络响应速度；升级服务器软件、提高网络带宽或更换性能更好的 CPU 都可能改善响应速度。
