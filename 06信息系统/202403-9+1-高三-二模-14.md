# 题目 14

小明要搭建仓储中心智能温控系统。智能终端从服务器获取温度阈值，根据阈值和传感器采集的室内温度控制空调，并将温度等数据传输至 Web 服务器存储到数据库，用户可通过浏览器查看实时和历史温度数据。

![[attachments/2024039+1_14_系统结构.png]]

（1）初步完成信息系统搭建后，还需要根据用户需求进行软件测试。其中目前还处于初级阶段、但对未来软件可能产生深远影响的是 ______（单选，填字母：A．正确性证明 / B．静态测试 / C．动态测试）。

（2）温度传感器编号为 1、温度值为 25，提交数据到 Web 服务器的 URL 为 `http://______`。

（3）关于该系统的说法，正确的是 ______（多选，填字母）。

A．通过浏览器查看温度历史数据需要访问智能终端

B．该系统中的温度传感器属于输入设备

C．若 IoT 模块与智能终端连接故障，则用户将无法查看实时温度数据

D．该系统中智能终端与服务器之间的数据传输只能由智能终端到服务器

（4）Web 服务器采用什么方式（GET/POST）接受传感器数据？请说明原因。

（5）将 11 月 4～10 日数据导出到 `temperature.xlsx`，制作每天平均温度图表，部分程序如下，请填空。

![[attachments/2024039+1_14_温度数据与折线图.png]]

```python
df = pd.read_excel("temperature.xlsx")
day = []
for date in df["时间"]:
    day.append(date[8:10])
df.insert(1, "日期", day)
dfx = df.groupby("日期").______①______
plt.title("11月4-10日一周气温变化")
plt.plot(______②______, dfx.温度)
plt.xlabel("日期")
plt.show()
```

## 答案

**正确答案：** （1）A；（2）`6.163.193.200:8000/input?id=1&val=25`；（3）B、C；（4）GET，通过 URL 传递参数；（5）① `mean()`；② `dfx.index`。

## 解析

正确性证明在软件测试领域仍处于初级阶段但具有长期影响。Flask 路由为 `/input`，主机和端口由服务器代码给出，参数通过查询字符串传递。温度传感器是输入设备，IoT 模块断开会使实时数据链路中断；历史数据由服务器数据库提供。使用 GET 是因为程序用 URL 查询参数携带 `id` 和 `val`；按日期分组后用 `mean()` 求每日均值，横轴使用分组结果的索引。
