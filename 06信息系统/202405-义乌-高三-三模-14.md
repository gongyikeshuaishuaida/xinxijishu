# 题目 14

小华搭建家庭环境监控系统，智能终端连接空气质量传感器和空气净化器，并通过 IoT 模块经无线网络连接服务器；用户通过浏览器查看实时监测结果和历史数据。

（1）传感器采集的数据应存储至 ______①______（A.服务器；B.智能终端；C.浏览器）。

（2）服务器端 Flask 网站的功能规划如下：

![[attachments/202405义乌高三_14_网站功能表.jpg]]

正确的说法有（多选）：

- A.该信息系统采用 B/S 架构模式
- B.若智能终端与服务器处于同一局域网，则不需要配置路由器
- C.实现查看室内实时监测数据功能的视图函数名称必须和路由名称 `viewall` 相同
- D.考虑系统是否需要具备可扩展性需求，该工作一般在需求分析阶段完成

（3）筛选 1 号传感器且数值超过 50 的数据。下列代码组合中可以填入的是（多选）：

![[attachments/202405义乌高三_14_筛选代码框.jpg]]

- A.`df=df[df.编号==1]`；`df=df[df.数值>50]`
- B.`df=df[编号==1]`；`df=df[数值>50]`
- C.`df=df[df.数值>50]`
- D.`df.编号==1`；`df.数值>50`

（4）每分钟记录空气净化器是否运行（1/0），统计各小时运行时长：

![[attachments/202405义乌高三_14_净化器运行表.jpg]]

```python
count = {}
hour = a[0][0][:2]
count[hour] = a[0][1]
for i in ______②______:
    if a[i][0][:2] == hour:
        ______③______
    else:
        hour = a[i][0][:2]
        count[hour] = a[i][1]
print("统计结果为", count)
```

（5）陌生人可直接登录、查询数据并控制净化器，请说明可能原因并给出一项安全改进建议。传感器数据示例如下：

![[attachments/202405义乌高三_14_传感器数据表.jpg]]

---

## 答案

**正确答案：** （1）A；（2）ABD；（3）A；（4）②`range(1,len(a))`；③`count[hour]+=a[i][1]`；（5）可能未设置身份认证或权限控制、使用默认/弱密码等；应启用强身份认证并按角色设置访问权限（或采用加密通信、定期改密等）

---

## 解析

传感器数据需要集中存入服务器，浏览器通过服务器查询历史记录。B/S 架构和需求分析阶段的可扩展性判断正确；路由与视图函数可通过装饰器关联，名称不必相同。筛选时必须先用 `df[df.编号==1]` 再用 `df[df.数值>50]`，A 是完整有效组合。统计代码从第二条记录开始遍历，同一小时累加运行值。陌生人可操作通常源于缺少身份认证、权限控制或密码策略，应强化认证、授权和通信安全。
