# 题目 13

小明为草莓大棚搭建温湿度控制系统：智能终端将传感器数据经 IoT 模块传送到 Web 服务器，并根据服务器处理的反馈控制执行器；用户可用电脑或手机浏览器查看实时和历史数据。系统结构如下。

![[attachments/202406浙南_13_温湿度系统结构图.jpg]]

（1）数据库设计应在前期准备的 ______①______ 阶段完成（单选，填字母：A. 需求分析 / B. 可行性分析 / C. 概要设计 / D. 详细设计）。

（2）关于该信息系统，正确的有 ______②______（多选，填字母）：
- A. 采用 B/S 架构搭建
- B. 开关执行器的决策由智能终端做出
- C. 智能终端与 Web 服务器是双向通信
- D. 采集到的温湿度数据全部存储在智能终端中

（3）服务器端程序采用 Flask Web 框架，服务器运行在 192.168.10.36:8080。请回答：
1）温度 23、湿度 54 时，智能终端向服务器提交的 URL 为 ______③______。
2）下列程序段能实现温湿度阈值比较功能的是（多选，填字母）：

![[attachments/202406浙南_13_比较结果选项图.jpg]]

（4）系统响应较慢，在不更换服务器的前提下，请从服务器主要硬件着手提出 2 项提升性能的措施。

---

## 答案

**正确答案：** （1）D；（2）A、C；（3）1）http://192.168.10.36:8080/upload?temp=23&hum=54；2）A、B、C；（4）增加内存；更换性能更好的 CPU；更换容量更大或读写速度更快的硬盘等。

---

## 解析

数据库设计属于详细设计。系统采用 B/S 架构，智能终端与服务器之间既上传数据又接收控制反馈，属于双向通信。Flask 路由为 /upload，参数通过查询字符串提交。A、B、C 的分支均能分别正确表达温度和湿度低于阈值时的两位状态码。服务器性能可从内存、CPU、硬盘等主要硬件升级。
