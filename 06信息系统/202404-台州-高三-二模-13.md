# 题目 13

小明搭建楼道灯光控制系统：人体红外传感器和光敏传感器采集数据，智能终端经 IoT 模块和 Wi-Fi 将数据传到 Web 服务器；服务器根据是否有人且光线是否不足控制 LED 灯。

![[attachments/202404台州_13_楼道灯系统图.jpg]]

（1）请标注数据传输关系。

（2）服务器程序部分如下：

```python
@app.route('/input')
def upload():
    # 初始化 h、flag=False
    while True:
        # 当前时间保存在 new
        # 获取红外 P、光线 L
        if not flag:
            if P == 1 and L < 200:
                flag = True
                ______①______
                # 打开 LED 灯
        elif new - last > h:
            flag = False
            # 关闭 LED 灯
```

① 填空。若 LED 灯关闭，红外值为 0、光线值为 100，提交数据 URL 为 http://192.168.1.98:5000 ______②______ ?peo=0&lig=100，上传成功后 LED 灯 ______（会/不会）开启。

（3）页面光线值正常但有人经过时 LED 灯没有开启，请回答两项可能原因。

## 答案

**正确答案：**

- （1）光敏传感器→智能终端；人体红外传感器→智能终端；智能终端→LED 灯
- （2）① `last = new`；② `/input`；不会
- （3）LED 灯/执行器故障或其与智能终端连接故障；人体红外传感器故障或其与智能终端连接故障。

## 解析

传感器负责采集环境数据，智能终端把传感器数据上传并向 LED 执行器发送控制信号。灯开启时记录 `last = new`，只有人体红外值为 1 且光线低于阈值才会开启；题设红外值为 0，所以不会开启。页面光线值正常时，故障重点应排查 LED/执行器及其连接，或人体红外传感器及其连接。
