# 题目 14

小华要搭建仓库温湿度监控系统，分布在仓库各处的智能终端（编号 0～9）每隔一定时间将传感器采集的温湿度数据，经过处理后通过无线方式发送到服务器并保存到数据库中。系统若检测到温湿度异常，则发出报警信息，管理员可以通过浏览器查看相关数据。

（1）搭建该系统时，下列 ______（单选，填字母）设备不能与智能终端直接连接。

- A. 温湿度传感器
- B. IoT 模块
- C. 蜂鸣器
- D. 无线路由器

（2）下列关于该系统支撑技术的说法，正确的是 ______（单选，填字母）。

- A. 智能终端具有一定的程序存储和数据处理的能力
- B. 服务器端运行的软件均为系统软件
- C. 在服务器端无法使用浏览器访问该系统

（3）小华基于 Flask Web 框架编写服务器端程序。编写完成后，若要通过浏览器获取视图函数 `index()` 的返回页面，则应访问的 URL 是 `http://______`。

```python
# 导入 Flask 框架模块及其他相关模块，代码略
app = Flask(__name__)
@app.route("/select")
def index():
    # 从数据库读取温湿度数据，并返回页面，代码略
    pass

if __name__ == "__main__":
    app.run(host="192.168.1.1", port=8000)
```

（4）服务器接收到的数据中包含一个状态信息码，状态信息码由 3 个数字组成，第 1 个为智能终端编号，第 2、3 个为温度、湿度状态（0 为偏低、1 为正常、2 为偏高），如 `"101"` 表示 1 号终端的温度偏低、湿度正常。如果某终端的状态连续异常称为一个异常段，异常段内的状态个数称为长度，服务器将接收到的所有状态信息码按接收时间顺序保存到列表 `res` 中，如 `["111","012","211","901","100","211",……]`，编写程序统计各智能终端异常段长度超过阈值 `m` 的次数，请在划线处填入正确代码。

```python
# 数据保存到 res，阈值保存到 m，代码略
size = [0] * 10
c = [0] * 10
for code in res:
    k = ______①______
    if code[1:] != "11":
        size[k] += 1
    else:
        if size[k] > m:
            ______②______
            size[k] = 0
for i in range(10):
    if size[i] > m:
        c[i] += 1
for i in range(10):
    print("编号为" + str(i) + "的智能终端异常段长度超过阈值次数：" + str(c[i]))
```

（5）请对该系统功能进行一项扩展，写出实现的功能及所需的硬件设备。

## 答案

**参考答案：**

- （1）D
- （2）A
- （3）`192.168.1.1:8000/select`
- （4）① `int(code[0])`；② `c[k]+=1`
- （5）示例：增加防火功能，所需硬件为烟雾传感器；或增加防盗功能，所需硬件为摄像头/红外传感器等合理方案

## 解析

温湿度传感器、IoT 模块和蜂鸣器可以直接作为智能终端的输入、通信或输出部件，无线路由器负责网络连接，通常不作为终端的直接外设。智能终端具有一定的存储和处理能力；Flask 默认访问地址由主机、端口和路由组成。统计异常段时先用状态码第 1 位转为终端下标，在遇到正常状态时检查并累计已经结束的异常段。
