# 题目 13

小明搭建食用菌大棚智能控制系统：温湿度传感设备和智能终端通过 Wi-Fi 将数据传到云平台，系统根据适宜温湿度控制环境调节设备，用户可通过手机 APP 或网页端查看并远程控制。

（1）温湿度传感器属于该信息系统的 ______①______（单选，填字母：A.硬件/B.软件/C.数据）。

（2）可做环境调节设备的是 ______②______（单选，填字母：A. Wi-Fi模块/B.排气扇/C.湿度计）。

（3）服务器端使用Flask，代码如下。若通过浏览器获取温湿度数据，应访问的URL是`http://______③______`。

```python
from flask import Flask
app = Flask(__name__)

@app.route('/env')
def main():
    # 从数据库中读取最近3小时的温湿度数据，并返回页面
    pass

if __name__ == '__main__':
    app.run(host='192.168.4.1', port=8080)
```

（4）终端每隔 5 分钟读取一次温湿度，若温度或湿度发生变化则上传。划线处应填入：

```python
while True:
    temp = pin0.read_analog()
    hum = pin1.read_analog()
    if ______④______:
        # 将温度 temp、湿度 hum 数据传输到服务器
        pass
    templ, huml = temp, hum
    sleep(1000 * 60 * 5)
```

（5）系统正常工作一段时间后，网页端没有最近2小时的温湿度数据（期间温湿度发生了变化），请简要说明可能原因（回答2项）：______⑤______。

## 答案

**正确答案：**

- （1）A
- （2）B
- （3）`192.168.4.1:8080/env`
- （4）`temp != templ or hum != huml`
- （5）例如：Wi-Fi 模块或网络故障导致数据无法上传；智能终端程序/硬件故障导致未上传；温湿度传感器故障导致读取不到变化。

## 解析

传感器属于硬件，排气扇是能够执行环境调节的设备。Flask 路由由主机地址、端口和 /env 路径组成；只有温度或湿度相对上次采样发生变化时才上传。网页端缺少数据可能来自网络、终端程序或传感器等环节的故障，回答任意两项即可。
