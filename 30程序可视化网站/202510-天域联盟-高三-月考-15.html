⑥ 每一空是怎么推理出来的？

先看整段程序要完成的核心任务： 把图形从左往右分成一条一条竖直小块，每一块的面积 = 宽 × 这一块中实际被矩形盖住的总高度。
程序只是把“什么时候有矩形加入 / 什么时候有矩形离开”“这一竖条有多高”用数组记录下来。 所以下面的每一空，都可以直接从代码前后关系推出来。

（1）总面积为什么是 54？

答案：54
  1. 第三个矩形改为 [8,2,10,8] 后，关键横坐标为 2、3、7、8、10。
  2. 从左到右分成 4 个竖条：[2,3]、[3,7]、[7,8]、[8,10]。
  3. 每条只求“这一段横向范围内，被覆盖的总高度”。
竖条宽覆盖总高面积
[2,3]144
[3,7]4832
[7,8]166
[8,10]2612
所以总面积 = 4 + 32 + 6 + 12 = 54。

（2）sort 中的空怎么推？

item[j] = item[j - 1]
  1. 循环条件 item[j - 1][0] > tmp[0] 表示：前面的元素横坐标更大。
  2. 目标是按横坐标升序，所以这个较大的元素必须往右挪一格。
  3. “把 j-1 位置搬到 j 位置”就是 item[j] = item[j - 1]。
  4. 接着 j -= 1 继续往左找位置，最后 item[j] = tmp 把 tmp 插进去。
看到“先保存 tmp → 大元素右移 → 最后放回 tmp”，就能判断这是插入排序。

（3）① 二分查找的循环条件怎么推？

hx[m] != key
  1. 函数最后 return m，说明它要返回 key 在 hx 中的位置。
  2. 什么时候说明已经找到？就是 hx[m] == key。
  3. 那么“还要继续找”的条件就是反过来：hx[m] != key。
  4. 本题key来自矩形纵坐标，保证存在，因此此写法可用。与题库的 i <= j and hx[m] != key 在本题前提下等价；查无此值时还须另行设计返回值，不能把return m当作未命中标记。
先问“什么时候停止？”——找到就停；因此没找到时继续。

（3）② 为什么是 h += hx[j+1] - hx[j]？

h += hx[j + 1] - hx[j]
  1. if hgt[j] > 0 表示第 j 个纵向小区间当前被至少一个矩形覆盖。
  2. 这个小区间的上下端点是 hx[j] 和 hx[j+1]。
  3. 所以它的真实高度是 hx[j+1] - hx[j]。
  4. h 要保存“所有被覆盖小段的总高度”，因此每遇到一段就要继续累加，而不是把前面的 h 覆盖掉。
区间长度是否覆盖对 h 的贡献
[2,3]1是+1
[3,5]2是+2
[5,8]3是+3
所以 h 是“总高度”，不是“某一小段高度”，因此一定是 +=。

（3）③ range 的两个端点怎么推？

item[i][1], item[i][2]
  1. item[i] 的格式是 [x, y1_idx, y2_idx, delta]。
  2. 所以纵向影响范围从 item[i][1] 开始，到 item[i][2] 结束。
  3. 但 hgt[j] 存的是区间 [hx[j], hx[j+1]]，不是一个坐标点。
  4. 例如 y1_idx=2、y2_idx=4，实际要改的是 j=2、3，也就是 range(2,4)。
  5. 因此右端不能写 item[i][2] + 1，否则会多改一个区间。
关键：hgt 存的是“小区间”，不是“坐标点”，所以右端不取到。

把整段程序翻译成人话

  1. 每个矩形有一个“开始位置”和一个“结束位置”。
  2. 把所有开始 / 结束位置按 x 从小到大排好。
  3. 每到一个新的 x，先算“从上一个 x 到这里”的竖条面积。
  4. 竖条面积 = (当前x - 上一个x) × 当前覆盖总高度h。
  5. 面积算完，再处理当前边界：左边界让对应覆盖数 +1；右边界让对应覆盖数 -1。
  6. 然后继续往右处理下一个 x。
理解整段程序时，只要抓住一句：竖条面积 = 宽 × 高。
做代码填空时的推荐顺序： 先看“变量表示什么 → 这一行前后要保持什么关系 → 循环结束希望得到什么”。 本题几个代码空分别对应：插入排序右移、二分找到即停、区间长度累加、左闭右开的 range。
